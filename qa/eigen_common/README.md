# 固有抽出の共通認定を基準化する

固有値backendを呼ばず、製品の原残差・正規化・Gram認定が返す上界を16進浮動小数点で保存するQA-03のケース。入力と尺度は固定し、成分別後退誤差の追加要求を未達のまま通さないことも検査する。

| 入力 | 独立に確認できる性質 |
|---|---|
| A=diag(5,1)、λ=5、v=(1,2⁻⁸⁰)、尺度1 | norm残差は2⁻⁷⁸、成分別後退誤差は2/3。通常のnorm要求は合格し、追加予算1e−12は拒否する。第2成分は独立な微小成分であり、TwoWordの低位planeとは別である |
| Q=I₂、T=diag(2,3)、AQ=T | 原Schur残差とGram誤差は厳密零 |
| M=diag(1,4)、K=diag(−1,16)、Φ=diag(1,1/2)、λ=(−1,4)、質量尺度1 | 原一般化残差とM正規化・直交誤差は厳密零 |

正規化の保存値は、真の誤差そのものではなく丸めを含む保守上界である。基準は`tools/qa/results.py accept`で作り、`check --case eigen-common --run <executable>`でプラットフォームごとに照合する。他のプラットフォームの実測値を、名前の付け替えで作らない。

このケースは、完全スペクトル・Arnoldi・物理mode被覆・実務受入の検証ではない。
