# 一般作用Arnoldiの実結果を基準化する

QA-03の固定ケース。実8次作用の先頭2成分は回転ブロック、残りは相異なる二進係数の対角作用とする。支配的な固有値は解析的に ±4i であり、製品の明示seed・Spectra抽出・実返却pairの元作用再認定を通す。

実返却した2値の実部・虚部と、それぞれの原残差・正規化の認定上界を、丸め直さず16進浮動小数点で8量保存する。固有vectorの非一意な位相そのものを基準値にはしない。元作用の積は既存two-productで両語を返し、包絡できない積は成功にしない。

基準はclean commitの実行ファイルから `tools/qa/results.py accept --case eigen-arnoldi --run <executable>` で登録する。別OSはそのOSでの実測出力を使い、既存基準と異なる場合は結果変更記録を付ける。他OSの値へ名前だけを付け替えたり、桁を丸めて一致させたりしない。

このケースの合格は固定作用の代数的な部分抽出を検査するもので、全スペクトル・物理modeの被覆・実務でのflutter判定を認定しない。
