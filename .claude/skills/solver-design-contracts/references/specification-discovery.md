# 何を決めるかを導く

## 1. 観測から逆算

「層別応力が欲しい」なら、測度・材料軸・層順・厚さ位置・界面両側・現在／基準体積・回復時刻・特異点の扱いが必要になる。「flutter速度が欲しい」なら、平衡枝・背景流・同じ離散状態の線形化・mode対応・不安定領域の被覆・速度区間・成長率の不確かさが必要になる。

要求する量ごとに `量 → 評価作用素 → 必要状態 → 必要未知量／履歴 → 入力／物理仮定` を書く。途中で説明できない矢印が未決定事項である。クラス図から始めてこの欠落を隠さない。

## 2. 物理・離散・実装を往復

| 境界 | 洗い出す質問 |
|---|---|
| 幾何→運動学 | 参照／現在、物質座標、実距離と厚さ座標、向き・面測度、正則性、近似曲面の誤差は何か |
| 材料→エネルギー | 3D／縮約仮定、仕事共役、材料軸、初期ひずみ、工程・層状態と時間履歴をどう保持するか |
| 局所→大域 | 共有しているのは位置・勾配・frame・全トレースのどれか。接合後の許容空間・rank・反力は何か |
| 運動→力 | 位置・速度と双対力が同じ写像か。偏心moment、状態依存力の幾何接線は何か |
| 連続→時間離散 | 位置・物理速度・加速度・循環微分のどれが未知か。初期履歴・誕生・イベント・境界輸送は何か |
| 平衡→安定性 | 実際の時間写像の固定点か。拘束・後流・履歴を摂動へ含むか。寄生根・零根・枝切替はどう分類するか |
| 演算子→求解 | 元系・尺度・対称性・正定値性・rankの根拠、分解再利用、必要精度、転置作用、停止・予算は何か |
| 解→消費者 | 保持表現・投影・丸め・再開後にも精度が成立するか。誰が値を所有し、何で無効になるか |
| 外部格子→内部模型 | 単位・回転DOF・offset・材料不足・再格子化で何を保存し、何を認定／拒否するか |
| 確定→保存→再開 | 同じ次状態・現在荷重を再現する最小の十分状態は何か。途中候補や破損をどう拒否するか |

式の各依存変数から微分の必要性を導く。たとえば写像が状態に依存するなら、Jᵀfの微分にはJの変化とfの変化がある。片方だけを「全Jacobian」と名付けない。状態依存慣性・拘束写像・反力の曲率も同様にたどる。

## 3. 敵対的な小例で契約を補う

最も単純な例に加え、符号・所有権・時間が間違うと結果が変わる例を選ぶ。候補は非零内力平衡、大回転＋偏心、非一致面、層反転、動く支持、後縁共有、誕生直後、負の剛性、zero RHS、全履歴の姿勢変更、cacheの同寸法別世代。

数を埋めるために全てを作るのではない。各例がどの未定義／誤実装を識別するかを説明する。成功経路の値だけでなく失敗後に何が変わらないかも契約にする。

## 4. 数学的同値と実装方法

縮約・KKT・Schur・matrix-free・局所条件付けは、元の物理問題と未知空間を保つ場合だけ実装選択になり得る。小特異方向の削除、対角正則化、接線の対称化、後流短縮、支持の追加は問題自体を変える場合がある。名前を「数値安定化」にして済ませない。

参照コードで可能だった全体密RREF・密nullspace・全状態行列が製品規模で必要かを確認する。局所／大域の境界、作用だけで十分な演算、因子と一時配列の費用を先に定義する。
