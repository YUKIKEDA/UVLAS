# 長引く研究を制御する

## 着手・再開時の地図

現在の目的、採用済み、棄却済みと理由、未解決の核心、依存する後続作業、次の採否条件を一つの入口へ集約する。履歴文書を読み進めないと現在地が分からない構造にしない。中断後は会話の記憶でなく保存物と実行中プロセスから復元する。

## 候補の台帳

`候補 / 未達 / 変える構成 / 変えない要求 / 決定的反例 / 採否 / 再検討条件`を残す。
新候補が以前の不可能条件をどう変えるか説明できなければ、名前や次数が違っても同じ経路の再試行として扱う。既存方式の一候補の棄却を「全ての既存方式は不可能」という証明にしない。

## 文献・公開実装を候補へ変換する

原論文から、運動学／補間、材料・応力仮定、体積・面の求積、安定化・混合場／消去、接続・境界条件、成立を示した問題を一組で抽出する。論文にある対策を省いた実装の未達を、原方式全体の限界と呼ばない。逆に平坦・等方で示された結果を曲面・積層へ無条件に広げない。

公開コードは版・実式・有効option・精度・既定値を原資料と照合する。原本、計測だけ加えた版、式を訂正した版を識別し、計測前後の通常出力が変わらないか確認する。外部コードを参照へ採用するときも、対称性、原残差、保存、格子・核等の感度と参照不確かさを審査する。ビルドできたことや引用実績だけで正解扱いしない。

比較表には、必要条件に対する「既に成立／反例あり／未確認」と、その条件を変える具体的な違いを記す。文献収集の網羅率を採用判断にせず、残る判断を変えない候補・計算を増やさない。

## 終わらせ方

| 状態 | 次の行動 |
|---|---|
| 方式の決定的条件を満たす根拠が揃った | 適用／拒否域、必要微分・状態・参照を固定し、実装または次の設計へ移す |
| 閾値近傍で算術／求積が支配 | 同じ問題の精密評価を資源枠内で比較。物理モデルの棄却と混同しない |
| 近似空間の下限・構造的欠落を確認 | その条件を変える案だけを検討。無関係な細分化を続けない |
| 複数原因が未識別 | 原因の共通部分を断定せず、識別実験を選ぶ |
| 必要データや機材に到達できない | 影響する判断を未解決と明示。品質基準の変更・外部連絡等が必要なら選択肢と推奨・長短をまとめて聞く |
| 資源予算を超えた | 超過を記録し、計算法／資源計画を改版。打切りを成功としない |

予算は判断価値と費用から決める。過去の実験の180秒や格子数を他案件の普遍的上限にしない。承認済みの範囲で採否まで続け、実験ごとのroutine確認待ちを置かない。

## 進捗の説明

「前回何が分からず、今回何を除外でき、未解決集合がどう減ったか」を示す。反例を追加しただけなら方式採用が近いとは言わない。監査のファイル数、文書数、実験数を品質や製品完成率へ変換しない。

誤った説明・比較条件・fixtureを訂正するときは、元の未達、訂正箇所、なぜ結果の解釈が変わるか、変えなかった閾値を記す。誤りを全て物理方式の失敗と呼ぶことも、fixture修正で既存の科学的不合格まで消すことも避ける。

確認質問は製品範囲・品質・外部行動等の利用者決定に限定する。相互依存のない質問はまとめ、選択肢・推奨・メリット／デメリットを示す。未解決の技術的な事実を、利用者の好みで決めさせない。
