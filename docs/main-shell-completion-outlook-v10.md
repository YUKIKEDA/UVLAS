# 主シェル終了見通し：曲面有限厚さで現仕様不採用

2026-11-04。[前回](main-shell-completion-outlook-v9.md)から曲面の有限厚さへ進め、[検証・採否](verification/mixed-mean-stress-finite-curved-results.md)を記録した。

**現MMS-1仕様は主シェルとして不採用。採用時期は見通せていない。** 有限厚さの正則曲面n4は最細1%以内・格子誤差減少を満たしたが、薄肉増幅はエネルギー29.95〜34.56倍、位置27.00〜38.99倍で、2倍以内が未達だった。採用直前という状態ではない。

曲面n2の4条件と正則n4の2厚さは資源を含む数値検査を通過。曲面n2の薄い2条件は独立の非縮約求解とも一致した。歪みn4の厚い条件は数値・別求積の条件が成立したが183.032秒で180秒上限を超え、薄い条件は未実施。主系列全8条件完了とは扱わない。正則での精度不合格と歪みでの資源停止を区別する。

残る採用条件を[4つの判断](main-shell-adoption-exit-plan.md)に整理した。既存条件の対応表であり、新しい製品要求ではない。

| 採用判断 | 現在地 |
|---|---|
| S1 曲面有限厚さ・格子・薄肉 | **不合格**。現仕様を採用しない。原因分解が次の主作業 |
| S2 物理荷重・反力・仕事 | 未完了。値入力の回復はあるが、荷重転置・PDE平衡は未検証 |
| S3 一般曲面・材料／積層 | 未完了。解析放物柱面の大域証拠を一般化できない |
| S4 非線形・慣性・状態・接続・数値契約 | 局所証拠／既存契約は保持。現要素の大域統合・疎解法／費用は未完了 |

次は保存された3条件の誤差を厚さ変動・混合平均応力・全面安定化へ分解し、同じMMS-1の有限厚さでどの仕事が増幅に対応するか確認する。新候補の自動追加、次数や重みの探索、閾値緩和、同じ条件の無変更再求解はしない。確認待ちは不要。

先頭曲げの必要条件、位置回復、平坦の有限厚さ二経路比較は成立した成果として保持する。ただし、それらを理由に今回の不採用を保留へ言い換えない。新しい仕様を採用へ進めるにはS1の未達を解消する根拠が必要であり、日付や残りチャット回数を約束できない。

全体は[ロードマップ](roadmap.md)の1.1にある。主シェルの後にも構造1.2〜1.5の統合、2 UVLM、3連成、4数値基盤／I/F、5実務ケース、6実装開始審査と、本体実装・受入が残る。総残工数が未見積もりであり、試験数を全体の完成率に換算しない。
