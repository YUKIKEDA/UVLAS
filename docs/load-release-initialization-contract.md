# 保持荷重平衡からの解放・初期化契約案

版：0.1、2026-10-30。INIT-RELEASE、TM-01、OP-08/09/12を具体化する。固定線形支持・一定質量の構造部分から定義し、一般拘束・UVLMの同時初期化は残す。

## 1. 荷重と平衡の識別

持続荷重 $f_b$ と解放対象 $f_h$ を別の入力IDとし、保持中の平衡 $q_h=q_*+Px_h$ を求める。 $q_*$ は同じ初期ひずみを含む持続荷重の平衡である。

$$
P^T\{f_{int}(q_h)-f_b-f_h\}=0,\qquad
r_b(x)=P^T\{f_{int}(q_*+Px)-f_b\}.
$$

平衡求解の反復で作った試行状態を初期状態として返さず、残差・支持・幾何を確認した確定平衡から初期化する。荷重IDには分布、物質座標、軸、測度、単位、評価時刻、死荷重／追従荷重、保持期間と除去則を含める。支持の変更がある場合は別の拘束イベントを定義する。

## 2. 有限な力を瞬時除去する場合

以下は変位・速度を瞬時変更する衝撃を含まないモデルである。解放時刻 $t_r$ の左右の位置・速度を連続にし、物理加速度を各側の運動方程式から求める。

$$
x(t_r^+)=x_h,\quad v(t_r^+)=v(t_r^-)=0,
$$

$$
M_r a^-=-r_b(x_h)+P^Tf_h\simeq0,\qquad
M_r a^+=-r_b(x_h)\simeq-P^Tf_h.
$$

変位と速度が連続でも加速度・反力は不連続になり得る。保持時のゼロ加速度を解放後の初期加速度としてコピーしない。時間刻みをイベント時刻に合わせ、除去前後を平均した荷重でイベントをまたがない。有限時間で除去する場合は別の指定荷重履歴として評価する。

## 3. エネルギーと初期状態の意味

解放瞬間に位置・速度が変わらなければ、構造のひずみエネルギーと運動エネルギーは連続する。一方、死荷重を含むポテンシャルの定義は保持側 $\Pi^- =\Pi_b-f_h^Tq$ から解放側 $\Pi^+=\Pi_b$ へ切り替わる。この定義の差を衝撃による運動エネルギー増加と扱わない。解放後の保存・仕事評価は解放後の同じ荷重集合で行う。

保持荷重から求める平衡は、任意の初期変位を修正する操作ではなく、異なる準備条件である。元のINIT-IVPの結果・未達と、INIT-RELEASEの結果・初期形状・エネルギーを別に保存する。保持荷重や準備履歴を実験応答へ無根拠に合わせない。

## 4. 返却・保存する状態

| 分類 | 内容 |
|---|---|
| モデル | 参照形状・材料軸・層・初期ひずみ・支持・質量・持続荷重の識別 |
| 準備条件 | INIT-RELEASE、保持荷重ID、保持平衡と残差・反力・幾何判定 |
| イベント | 解放時刻、除去対象、除去則、確定した左右の荷重集合、完了フラグ |
| 動的状態 | 解放後の確定位置・速度・物理加速度、方式別の算法履歴 |
| 精度 | 平衡・初期化・時間積分それぞれの尺度と判定、評価窓・標本時刻 |

一般化α法を解放直後から始める場合、最初の算法加速度は解放後の物理加速度で初期化する。既に積分中のイベントを扱う場合は、その方式のイベント再初期化・次数・履歴規約が必要であり、途中の算法加速度を無条件に再生成しない。イベント直前／直後の保存を区別し、解放済みの再開で保持荷重を復活させたり、解放を二重適用したりしない。

## 5. 適格性と決定

平衡の自由残差、拘束、初期加速度、全体の力・モーメント、幾何、初期エネルギーと荷重集合を検査する。初期状態が整合しても時間精度の合格ではない。解放後の変位・速度・加速度・応力・反力を指定時間窓で照合する。

- RELEASE-D01：保持荷重と持続荷重、イベント左右、初期化型を明示し、有限力の除去で位置・速度を連続にする。
- RELEASE-D02：解放後の加速度・方式初期履歴を同じモデルから構築し、保持時の履歴を無検査で流用しない。
- RELEASE-D03：準備条件・イベント完了状態・精度判定を保存し、別初期値問題としての証拠を保持する。

限定仕様と結果は [保持分布荷重・解放応答試験](verification/q9-load-release-experiment.md) に記す。

積分途中の既知解放時刻については [イベント確定契約](transient-event-transaction-contract.md) に左右の確定・算法履歴再初期化・保存単位を具体化した。[移動中の途中解放試験](verification/q9-event-transaction-experiment.md) で4か所からの再開と一度だけのイベント適用を限定確認。今回の第2節の静止解放式は初期化のケースであり、途中の移動状態では非ゼロ速度を連続に引き継ぐ。
