# 実数基底行列・複素後縁列更新による空間収束診断

版：0.1、2026-10-30。NU-02、AE-02/04の限定設計。圧力場・観測区間・参照・しきい値を固定する。

## 1. 変更するのは保持・分解方式

[残差とトレース診断](verification/uvlm-residual-trace-experiment.md) で求解精度は成立したが、1024→2048の局所平均差2.319%は未達だった。追加細分化では、複素密行列と複素LUの同時保持を避ける。基準幾何は同じcosine物理パネル・P0束縛場、連続指定後流、L=160c。

束縛行列の後縁列と定数後流を解析的に相殺した実数行列をA₀とする。その最後の列は $H(x^v_{M-1})-H(c+L)$ 、他の列は前回と同じ。非定常補正ベクトルは

$$
v_i(k)=\int_c^{c+L}f_i(s)\operatorname{expm1}[-i\omega(s-c)/U]ds.
$$

後縁抽出ベクトルeを使えば $A(k)=A_0+v(k)e^T$ 。各成分をfloat64へ丸めた有効複素行列は前回と同じでなければならない。単に数式が等価なだけでなく、既存2048分割の行列・右辺ハッシュで確認する。

## 2. 実数LUと複素更新

[Cornell・Bindelの講義資料](https://www.cs.cornell.edu/~bindel/class/cs4220-s16/lec/2016-02-17-notes.pdf) のrank-one更新を、後縁列へ適用する。逆行列を作らず、A₀の実数LUを複数右辺へ適用する。

$$
Q=A_0^{-1}B,\quad q=A_0^{-1}v,\quad d=1+e^Tq,\qquad
\Gamma=Q-q\frac{e^TQ}{d}.
$$

複素右辺の実部・虚部を実数LUで別々に解く。式の転置はTであり、更新を無断で別の共役演算へ置換しない。 $|d|/(1+|e^Tq|)\le10^{-12}$ なら今回の経路を拒否する。この検査だけで安定性を保証せず、最終の補償残差を必須とする。

この更新式は三角求解・更新の丸めを含むため、残差に基づく反復改良を行う。対象は前回同様の有効float64複素係数。複素係数を行ブロックで復元してTwoProduct残差を計算する。代数上の低ランク表現だけを高精度の真値と扱わない。

## 3. 保持表現と記憶量

主要な二乗配列は実数A₀と実数LUの二つ。4096分割ではそれぞれ128 MiB、合計256 MiB。行ブロックの複素係数・補償積和と右辺・解・補正が追加される。全体ピークを実測し、512 MiBを超えたら停止する。

float64保持で最大4補正。未達なら初期解から高低2配列の経路を最大4補正し、同じ有効係数への残差とfloat64投影後の残差を区別する。高低経路を使った場合、圧力も両配列から評価する。製品数値型の採用とはしない。

ブロック化で通常積和の演算順は変わりうるため、通常残差と補償残差の評価方法を識別する。選択行は80桁Decimalと照合する。行列のハッシュは行順に復元した複素係数を連結して計算し、前回の全行列と同じ定義にする。

## 4. 論理I/Fとキャッシュ条件

RealBaseは幾何版・パネル配置・幅・有限後流長・A₀世代とハッシュを持つ。LUキャッシュはA₀の係数・順序・精度構成に対応し、周波数が変わるだけなら再利用できる。後流長や格子を変えて同じキャッシュを使わない。

ColumnUpdateは補正ベクトルv・右辺B・運動条件ID・要求精度を入力に取る。qと分母はvごとの作業状態であり、前の周波数から流用しない。返値には保持表現（float64／高低2配列）、補償残差・後退誤差・分母の診断、実際の補正数、float64投影後の適格性を含める。

分母拒否・補正停滞・精度未達では、通常の適格解として返さない。観測側は返された保持表現を消費するか、未対応として拒否する。高低配列を保存せずfloat64投影を返した場合、投影の検査結果をその返値の状態とする。入力A₀/v/Bと前の確定状態は変更しない。

## 5. 決定と範囲

- RCU-D01：同じ有効複素係数を、実数基底・複素1列補正として保持する。
- RCU-D02：更新分母・保持表現・補償残差・投影を照合し、同値性を数式だけで済ませない。
- RCU-D03：解法の保持変更とP0圧力の空間収束を分け、区間端点・物理参照を固定する。

[事前仕様・結果](verification/uvlm-column-update-convergence.md) に限定証拠を保存する。この1列構造は今回の幅一列・固定基準幾何だけの性質であり、一般3D・複数面・自由後流のソルバー方式とはしない。
