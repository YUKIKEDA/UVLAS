2 Pa載荷の最初の試行を受理した状態で、8体積すべての接線を誤差付きで組み立てた。独立の整数演算で仮想仕事を積分し、後退誤差の認定が残っていた106行の右辺が厳密にゼロであることを確認した。その106成分をゼロとした補正候補は、全216行で絶対残差と成分別後退誤差の条件を満たした。

この補正を刻み1で適用した候補は、独立計算でポテンシャルの十分減少条件と全8体積の向きの保持を確認した。自由残差の最大絶対値は約 $1.88\times10^{-1}$ N から $4.05\times10^{-5}$ N に下がった。

更新後の接線で後続2回の補正を求め、独立計算で各回とも全216行の絶対残差と成分別後退誤差を確認した。いずれも刻み1で十分減少条件を満たし、全8体積の向きを保持した。自由残差の最大絶対値は約 $1.87\times10^{-12}$ Nを経て $5.20\times10^{-27}$ Nまで下がり、最後の指定点変位差は約 $1.09\times10^{-15}$ mだった。同じ候補で、独立に積分した元力327成分から支持レンチを回復し、外力の合力・モーメントと釣り合うことを確認した。

保存した4配置の接線全成分を、求積と丸めの誤差を含めて囲い、製品の疎行列検査で正定値性を認定した。誤差幅を広げた対照では認定を拒否した。最終候補で求め直した補正は最大約 $6.83\times10^{-32}$ m。接線作用を独立に積分したところ、補正式の最大絶対残差は約 $2.14\times10^{-41}$ N、成分別後退誤差の上界は約 $1.22\times10^{-14}$ で、全216行が試作の許容値を満たした。同じCaseの整合質量は、総質量0.1 kgと参照位置の一次・二次モーメントを平板の解析積分と厳密に照合した。

この載荷対照では、右辺が厳密に零だった106自由行すべてで、持ち上げた方向が厚さ中央面に対して反対称で、外力の仮想仕事も厳密に零だった。配置と方向の対称性を全8体積の係数で照合した。ローカルの構造実装では、元力から得た区間が零を含む場合にこの条件を調べ、証明できた右辺を厳密に零とする。力の区間を広げたアフィン載荷対照で、全216行のうち該当する106行に適用できることを確かめた。

後続試行の接線は、体積ごとに組み立てた誤差包絡を固定チャートで縮約し、補正の検査に渡す。ローカルのアフィン2 Pa載荷対照では、全8体積の接線を組み立て、縮約接線の正定値性と全216行の補正を認定した。

保存した最初の非アフィン載荷配置では、元力の包絡に256ビットの二進格子を使い、保存済みの接線包絡と組み合わせて全216行の補正を認定した。接線の計算でも、配置の勾配を丸めたときの誤差を接線包絡に加える経路を組み込んだ。実体積1つで非零42成分と零36成分を独立参照と照合した。

参照配置から始める2 Pa載荷の通常求解でも、組み立てた接線包絡を使って2回目の補正を認定した。処理回数の診断用上限を2,400万回とした実行は、補正後の候補を作る工程で資源上限に達した。

R-05の矩形について、パラメトリック、Gmsh、Nastranの3経路で固定チャート、材料、全厚の側面牽引を準備した。外部経路では元データと対応表を認証した。パラメトリック経路の通常求解を参照配置から実行し、2回目の補正と観測評価まで確認した。3経路で平衡を確定し、同じ確定状態を先端変位・支持反力の独立照合と固有振動へ渡す工程が残る。R-05に続いて、梁、非線形接続・圧力・粘性、およびV-PG／V-RECOVERの全配置を進める。

矩形のパラメトリック経路も、2回目の補正後の候補更新で資源上限に達した。GmshとNastranでは2回目の補正と観測評価を通した。非アフィン載荷の状態と補正を使った別の再現実験では、2体積の線探索係数の計算に使った総課金演算数の97%以上を、ひずみ係数の二進格子への射影が占めた。勾配を先に射影してひずみとエネルギーに誤差を伝える変更案は、7億回の同じ演算枠で8体積すべての係数を約1.13億回で包絡した。従来の処理は6体積目で演算枠に達した。Caseの通常求解に変更案をつないで検証している。

勾配射影の変更を構造の作業ブランチの `0fca6d5e` に反映した。修正を含む通常求解では、3入力経路とも参照配置から最初の候補を受理し、2回目の補正と観測評価まで通した。別の2体積の候補再評価では、エネルギーに同じ射影を適用し、内力との合計演算数を約1.53億回から約7,814万回へ減らした。Linux Releaseで弾性試験が通過し、求積試験の9ケース、32,735アサーションも通過した。求積の初回登録は60秒で打ち切られたため、構成別の上限に更新し、Releaseの通常のCTest経路で71.97秒で通過した。

勾配射影を含むパラメトリック経路で、2回目の候補更新を通って次の接線組み立てに進んだ。勾配射影を含まない比較実行は、診断用に演算枠を12.5億回に広げても、4回目の補正後の候補更新で資源上限に達した。

勾配の各成分から行列式のBernstein係数の正値を証明する経路を構造の作業ブランチに反映した。保存した載荷配置と次の候補の計4体積で、従来の展開と同じく分割なしで認定した。Linux Releaseの関数前後の計測では、向きの判定が1体積32.3〜37.1秒から4.5〜9.3ミリ秒に減った。Linux perfは権限設定で採取できなかった。向き判定と求積の回帰試験が通過し、この変更を含むCaseの通常求解を実行している。

先行版では3入力経路とも4回目の補正後に16,384ビットの有理数の幅上限に達した。要求値は16,397ビットだった。線探索で厳密ひずみを作る段階の幅超過からも、勾配射影による係数包絡へ切り替えられるようにした。分母801ビットの独立対照では、ひずみ形成に必要な幅が1,024ビットの上限を超えたが、修正後は二次・三次・四次のエネルギー係数をすべて解析式の値を含む区間で返した。弾性と求積の回帰試験は通過した。実際に停止した候補が同じ箇所で幅を超えたかは、工程ごとに記録する通常求解で確認している。

確定平衡と同じ固定チャートを使い、自由方向を元座標に移し、整合質量を作用させてから自由座標へ戻す処理を追加した。無載荷矩形では、総質量0.1 kgと軸方向変位に対する質量二次形式 $1/30$ kg m²が解析積分と厳密に一致した。別の行列世代、方向の長さ違い、取消も照合し、Linux Releaseの試験で78アサーションが通過した。固有対を認定するには、同じ状態の接線の包絡を元固有残差に伝え、質量正規化尺度 $m_0$ と物理的なモード対応を定める必要がある。載荷矩形の第一軸モードの独立参照は631.867089 Hz。 [一般化固有対の認定条件](../specs/foundation/eigen-extraction-contract.md)

梁の断面・接続について、凍結した参照記録の原本と生成ソース7件のハッシュを照合し、全3ケースを別ディレクトリで再実行した。断面入力と方向微分・接続の値を抽出した検証データは、別の出力先でもバイト一致した。偏心点の仮想仕事は別の同次行列Log／Expと三つの差分幅で照合し、最大差は約 `1.76e-12` だった。材料基底のモーメントを世界基底の値として扱う対照は不一致になった。Caseの梁を製品で準備し、静的作用と構成依存慣性に接続する工程が残る。

## IM-03 空力

共有する後流形状が一致する初回では、凍結した1パネル対照の離散非貫通行列を有理数で解いた。退役による循環差は約 $6.17\times10^{-3}$ m²/sで、退役源の直接誘導から求めた上界は約 $2.39\times10^{-2}$ m²/sだった。同じ親履歴からBDF2で時間微分を評価し、鉛直の非定常力だけで約0.208 Nの差が生じることを独立に照合した。保持点が移動した後の行列変化と、構造応答を含む誤差伝播が残る。

同じ1パネル対照の全6回で、離散循環差を、退役源、保持源による右辺の差、先頭後流の形状変化による行列の差から再現した。6回目の循環差は約0.0215 m²/sで、保持源による右辺の差はそのうち約0.00238 m²/sだった。保存した2配置の間で三角形を補間し、各作用の差を囲ったときの循環差の上界は約0.0931 m²/s。BDF2の3時刻履歴から得た6回目の鉛直非定常力差は約0.0376 Nだった。構造応答を含む採用J1の軌道に沿って誤差を伝播させる工程が残る。

矩形の観測参照9成分を解析値と厳密に照合し、確定観測の後段比較に使う有理数の境界例63件を作った。Caseの許容値と受入上限の片方だけを超える例、包絡の上端・下端、参照の不確かさだけで失敗する例を含む。製品での照合には、確定状態と同じ準備済みモデルから得た観測と、適用する零近傍の尺度を結び付ける工程が残る。

構造側の確定結果は、Case、チャート、求解時のモデル・レイアウト・試行・世代と時刻、Caseから換算した観測許容値を保持する。無載荷の通常求解で、認証済み参照の点変位と支持モーメントをそれぞれ比較し、指定成分だけが判定されること、Caseの許容値と固定上限の片方だけを超える場合、および別の試行や成分指定が拒否されることを確認した。

R-05載荷ケースの3入力経路について、独立参照の変位3成分と支持レンチ6成分を、各Caseの条件とSHA-256で結び付けた。CLIのファイル検査とPythonのファイル読込みを通し、同じ検査済みCaseと参照グラフから、固定チャート・材料・側面牽引の準備まで確認した。Gmsh用の参照をパラメトリックCaseに割り当てると、参照ファイルのSHA-256が正しくても解析条件の不一致で拒否された。

同じファイルをPythonの`float`で辞書化すると、全厚0.00254 mを含む入力が丸まり、元ファイル向けの参照と条件が一致しなかった。現行の辞書入力は`Decimal`も拒否する。このケースの十進値を保つPython経路はファイル読込みで確認した。辞書から同じ条件を再現するには、十進値を保持して渡す表現が必要になる。物理準備では、SI変換に渡す全数量の尺度と絶対・相対許容差が必要になる。試験で用いた一律の要求値を製品の既定値に置くことは、[SI変換契約](../specs/foundation/si-precision-conversion-contract.md#3-許容差はsi尺度で無次元化して明示する)が認めていない。

長さ単位にmmを使うCaseで、観測参照の変位・力・モーメントの不確かさ9成分を異なるSI係数で照合した。各種類で単位係数を一つ誤った対照を拒否し、元に戻すと通過した。使用した入口はCLIのCase検証で、載荷平衡の観測比較は引き続き別の工程である。

観測参照PRのWindows CIで失敗した文字列バッファと、回帰追加で変わった追跡表を修正した。Linuxの対象3試験と追跡表の検査は通過した。 [観測参照PR](https://github.com/YUKIKEDA/UVLAS/pull/420)

Caseのファイル入力では親ディレクトリ、Python辞書入力では明示した参照ルートを起点に参照先を検査する。 [#403](https://github.com/YUKIKEDA/UVLAS/pull/403)
