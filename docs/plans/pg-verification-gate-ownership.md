# V-PGの検証をIM-01とIM-02に割り当てる

[開始審査3節](implementation-start-review.md#3-後続パッケージと依存)の「IM-01のV-PG」と「IM-02の開始条件」を補足する。現行のV-PGは、参照幾何と拘束に加えて、全3Dの材料、質量、荷重に対する構造応答を要求する。構造応答を実装するIM-02は、IM-01で検証した参照と拘束を入力に使う。そこで、V-PGの各観測を、製品で計算できるパッケージの完了条件に割り当てる。 [A5-01とA5-02](../requirements/practical-acceptance-plan.md)

## IM-01の終了とIM-02への引継ぎ

IM-01では、R4とR5の参照入力に対し、次の製品証拠をそろえる。

- 各凍結入力の格子と厚さで、曲面、歪み、切断、変厚、層・境界の位置、法線、物理厚さ、体積測度を照合する。R4の支持と非整合接続を含め、製品が採用する $n=1,2,4$ の適格性も確認する。
- 局所基底の構成、正則性、条件付け、必須場の保全と、局所・大域の資源上限。失敗後は元入力と準備済み状態を保持する。
- 固定・剛体・指定運動の全厚元拘束と、固定チャートの位置、接線、転置、反力。既知荷重に対する参照写像と転置の仮想仕事を照合し、実接続グラフの準備とfill、世代・片側の扱いを確認する。
- WindowsとLinuxの検証記録、元データの来歴、許容差、独立な正常例と負対照。A5-02に従って凍結ソースからCaseへ展開し、元ソースのハッシュと使用したパラメータを記録する。IM-02が同じ参照・基底・拘束を消費できることを終了審査で確認する。

この証拠と [#17](https://github.com/YUKIKEDA/UVLAS/issues/17) の残る子Issueを確認した後、IM-01を終了する。IM-02の開始は、従来どおりIM-00と、このIM-01の製品検証完了に依存する。

## IM-02で完了するV-PG

IM-02では、その準備済み参照と拘束を使った実モデルについて、同じ層と材料の全3Dエネルギー、整合質量、トレースと独立荷重を比較する。凍結R4・R5の格子・求積ごとに、変位、仕事、層別応力、対象固有モードと振動数を確認する。V-PGの製品側の完了は、IM-01の証拠とこの全観測の双方を照合した時点とする。これを [#18](https://github.com/YUKIKEDA/UVLAS/issues/18) のIM-02終了条件に加える。V-MAT、V-BEAM、V-JOINT、V-LOAD、V-RECOVERを含む既存の他の終了条件も適用する。

A5-01／02のケース、独立参照、状態フラグ、観測、数値予算、製品目標をそのまま使う。例えば、参照位置と拘束に合格しても、全3D質量と応答の結果がそろうまではV-PGの製品検証は続く。変位と仕事に合格した時点で応力や対象モードが欠けていれば、IM-02の終了審査は未達となる。外力は凍結参照に基づく独立荷重を使う。製品の係数に剛性を掛けて右辺を作る方法は、独立荷重の観測を満たさない。

## 審査と状態の更新

開始審査の凍結原本とA5の要求文書を保持する。現行の実装計画と終了審査では、本稿で示した担当を使う。採用後、#17と#18の完了条件をそれぞれの担当に合わせる。検証記録は各担当の範囲と結果を名指しし、A5のケース状態は実際の証拠がそろった時点で更新する。
