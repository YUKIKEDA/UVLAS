# 成分別共変空間による中央面射影

2026-11-04。前の共変対称勾配152次元案と幾何生成案は不採用。前者は曲面歪みの四次誤差をほとんど改善せず、正則曲面の独立積分で核の一致を満たさなかった。後者は局所rank219を満たしたが、共有rank・核の一致を満たさなかった。

[Bucalem–Bathe, 1993, pp.3732–3735, Fig.3](https://web.mit.edu/kjb/www/Publications_Prior_to_1998/Higher-Order_MITC_General_Shell_Elements.pdf)のMITC16では、三次変位に対して共変11/13成分をGauss3×4点、22/23を4×3点、12を3×3点で結ぶ。図を描画して確認した。これは変位の対称勾配空間への射影ではなく、成分ごとに異なる補間である。

本試験は原MITC16の再現ではない。ANCF EL2 Q4、3D材料、厚さ二次場を維持し、この成分別次数のパターンを四次へ拡張した空間を、既定の物理C直交射影に使う独自案である。原論文の適格性・収束証明を本案へ移さない。

共変成分の基本空間を次に固定する。Qabは親座標sの次数a以下、tの次数b以下。

| 共変成分 | 空間 | 次元 |
|---|---|---:|
| 11,13 | Q34 | 各20 |
| 22,23 | Q43 | 各20 |
| 12 | Q33 | 16 |
| 33 | Q88 | 81 |

基本177次元に、先行案と同じ3回転場・6物理一定場の商空間補完を加える。80桁／120桁の独立係数構成、rank一致、一定応力仕事と二次・三次正対照の許容値は変更しない。エネルギー・双対は[共変中央面案](covariant-projection-formulation.md)と同じで、膜・せん断の試験空間だけを変える。

局所、4共有配置、非多項式曲率の検査を先に実施する。全必要条件と両曲面の四次誤差1%以上改善を満たした場合のみ、既定n4歪み共有と有限厚さ4条件へ進む。不合格時に許容差や補間次数を調整しない。
