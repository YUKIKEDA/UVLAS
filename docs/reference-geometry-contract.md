# Q9参照幾何・厚さ座標・境界面の契約案

版0.1、2026-10-29。ST-01/02/08、CV-01/02、OP-01/02/03に関する案。単要素の幾何・荷重試験を根拠に意味と不変条件を具体化する。一般曲面接続、入力形式、製品APIの採用完了ではない。

## 1. 座標と幾何の意味

$$
\mathbf X_h(\xi,\eta,z)=\sum_iN_i(\xi,\eta)\left(\mathbf r_i+z\mathbf d_i+\frac{z^2}{2}\mathbf c_i\right).
$$

rはz=0の参照基準面上の位置[m]、dはzに関する一次微分[無次元]、cは二次微分[1/m]。回転角ではなく、r/d/cを同じ物理直交基底で保持する。dの長さ1や基準面との直交は、上式自体から自動的には成立しない。

一定の厚さ座標範囲 $z\in[-h/2,h/2]$ について、補間後のr/d/cを使うと

$$
\mathbf X_+-\mathbf X_-=h\mathbf d_h,\qquad
\frac{\mathbf X_++\mathbf X_-}{2}=\mathbf r_h+\frac{h^2}{8}\mathbf c_h.
$$

従ってhを無条件に物理法線厚さと呼ばず、rもcが非ゼロなら上下表面の幾何学的中央とは限らない。材料の中立面と一致することも仮定しない。層の範囲・積層順は参照zで指定するのか物理距離で指定するのかを明記する必要がある。

## 2. 幾何生成と評価を混ぜない

外部格子の「板厚＋法線」から参照体積を作る処理と、明示されたr/d/cの体積補間を評価する処理は、異なる責任である。法線オフセット面を近似して得た節点dは、補間後の全点で単位・法線となる保証はない。

明示された体積補間の評価途中でdを再単位化したり、cをゼロにしたりしない。それは幾何・材料点・質量・厚さ・境界面を変え、元のモデルとは別になる。法線オフセット面を直接使う候補を採るなら、その写像・近似誤差・微分・接続を別仕様として定義する。

今回のNORMAL-C試験は「節点で単位化したdをQ9補間し、内部で再単位化しない」明示体積モデル。実務用の板厚入力の既定解釈を、この試験から確定しない。

## 3. 入出力と評価処理

| 区分 | 論理契約 |
|---|---|
| 入力 | 要素ID、9節点のr/d/cと成分順・基底・単位、層境界、厚さ座標写像、参照モデル世代、評価親座標 |
| 評価 | X、必要な親座標微分、J、detJ、物理勾配への変換。zと正規化厚さ座標ζの係数を区別 |
| 境界出力 | 面ID・向き・評価点・有向面積ベクトル、必要な単位法線と面積。外向き法線と利用者の圧力符号を区別 |
| 精度情報 | 全域の適格性証拠、求積点でのdet・条件数、近似／厳密な証拠の対象となる格納値・世代 |
| 可変性 | 評価は参照モデルを変更しない。試行変形のJを参照Jへ書き戻さない |
| 所有権・寿命 | キャッシュはModel/Workspace世代と対応させる。返却ビューの所有・寿命とPython境界は未確定 |
| 失敗 | 範囲外座標、未対応写像、非有限、反転・退化、全域証明未成立を区別。絶対値detで反転を隠さない |

親座標を全て無次元とする場合の体積測度は $\det\mathbf J_0\,d\xi\,d\eta\,d\zeta$ 。厚さ係数がJに含まれるので重複乗算しない。面積も同じ参照写像の列外積から評価し、厚さ面・側面で別の近似幾何を黙って使わない。

## 4. 全域適格性の証拠

今回のQ2×Q2×厚さ二次写像では、detJは各軸高々5次の多項式。格納値を有理数へ正確に変換したdetJのtensor-product Bernstein係数が全て正なら、全域の正値性を示せる。[曲面荷重試験](verification/q9-curved-load-experiment.md) で20ケースへ適用した。

これは十分条件で、係数が非正でも直ちに反転の証明にはならない。追加の区間細分化等で審査するか、その方式では未確認として停止する。実際に非正のdetを検出した場合と、証明手続きが未成立の場合を混同しない。

正のdetだけで実用的な格子品質を保証しない。薄さに由来する縦横比と、不正な歪みを区別し、用途別の条件数・角度・感度の基準が必要。サンプル点の条件数最大値を全域上界と称さない。Fractionによる全域判定の実験を、そのまま製品の高速幾何検査方式へ採用した判断ではない。

## 5. 隣接要素の適合条件

同じ物理界面について、対応する面内座標と厚さ座標で、位置写像と許容変位のトレースが一致することを求める。節点番号が同じという理由だけでr/d/cを共有しない。Q9×厚さ二次の適合変位による経路では、界面の同じ物理z・同じ方向・同じ原点へ変換した係数の整合を確認する。

一般に、一方の座標が $z_e=\alpha z_f+\beta$ と対応するなら、同じ物理点を表す係数は

$$
\mathbf r_f=\mathbf r_e+\beta\mathbf d_e+\frac{\beta^2}{2}\mathbf c_e,\quad
\mathbf d_f=\alpha(\mathbf d_e+\beta\mathbf c_e),\quad
\mathbf c_f=\alpha^2\mathbf c_e.
$$

これは同じ二次多項式の再パラメータ化で、離れた基準面を強制的に同じ面へ押し付ける条件ではない。微小変位・仮想変位の係数にも同じ線形変換を適用し、力は仕事共役な転置写像で対応させる。要素ごとの厚さが異なる場合や厚さ方向が逆の場合に、d/cを無条件に等置しない。

多要素収束試験では平坦・一定h・共通厚さ座標を用いた。続く [界面契約](thickness-coordinate-interface.md) と [二要素試験](verification/q9-interface-reparameterization-experiment.md) で、定数の厚さ座標再パラメータ化・適合変位・仮想仕事・層帰属を照合した。実際の可変厚さ・異なる法線を持つ接続、シェルと梁・剛体結合の数値照合は未実施で、ST-08の採用条件として残す。

## 6. 不変条件・キャッシュ

- 座標系をQ・aで変換するとr→Qr+a、d→Qd、c→Qc。増分・仮想変位は全成分へQのみを作用させる。材料軸・荷重・拘束・評価点も対応させる。
- 無応力参照配置の有限剛体運動ではF=Q・Greenひずみ0。ただし小ひずみ線形内力へ有限回転不変性を要求した試験と混同しない。
- キャッシュは参照幾何・層範囲・厚さ写像・求積・評価面・モデル世代に依存する。試行変形だけを変えたときの参照キャッシュ再利用と、参照幾何変更後の無効化を区別する。
- 幾何の適格性、材料点・層の帰属、体積／面積測度、対応する拘束・荷重が同じ写像を使う。失敗時はモデルと確定状態を変更しない。

## 7. 残る決定

物理板厚からの標準幾何生成、厚さ変化・層境界の写像、初期曲面と材料軸の構成、メッシュ品質の全域基準、界面の自由度変換、一般曲面荷重での収束、Nastran/Gmsh取込み、型・所有権・性能を確定する。本契約案の作成を要素採用や実装開始判定へ置換しない。
