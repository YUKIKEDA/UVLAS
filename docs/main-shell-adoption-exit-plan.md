# 主シェル採用までの残作業と判断境界

2026-11-04。既存の[構造採用審査](structural-model-adoption-review.md)、[製品要求](product-requirements.md)、[有限厚さへの引継ぎ](mixed-mean-stress-finite-next.md)を、1.1の採用判断へ対応させる。新しい製品要求や公開API制約を追加する文書ではない。

**採用可能日は未確定。現MMS-1仕様はS1の薄肉増幅未達で不採用となった。** [今回の結果](verification/mixed-mean-stress-finite-curved-results.md)を正とする。以下を通過した時点で主シェルの採用式・適用条件を固定する。局所検査や一つの曲げ診断の合格を、その代用にしない。

| 順序 | 閉じる判断 | 今回着手時の状態 | 採用へ渡す成果 |
|---|---|---|---|
| S1 有限厚さの曲面精度 | 同じ全自由度・原作用素で曲面／歪み・厚さ・格子に対して精度が成立するか | 平坦二条件の比較のみ成立。正則／歪み曲面n2→n4・二厚さを実行する | 数値基準、独立観測、最細1%・薄肉増幅2倍、独立再求解の結果。未達なら現仕様を採用しない |
| S2 物理荷重との整合 | 回復位置、ひずみ、物理外力が同じ仕事・平衡を与えるか | 全モーメント回復の値作用は成立。効率的な荷重転置・大域PDEは未完了 | 体積・全外面・共有面の仕事、合力／モーメント、支持反力、製造解からの平衡と格子収束。投影診断の右辺を物理荷重と読み替えない |
| S3 実務幾何・材料への拡張 | 解析放物柱面用の空間を一般曲面・材料・積層へ定義できるか | 一般四次参照での回復・局所仕事の証拠と材料点契約はあるが、MMS-1大域で統合していない | 幾何依存の応力空間の一般定義、求積・適用／拒否条件、層別消去と回復、初期ひずみ、曲面／積層の独立参照。特殊曲面の厳密rankを一般の安定性証明へ転用しない |
| S4 採用する力学・数値契約 | 非線形・慣性・状態・接続・解法が同じ要素に対応するか | 増分保持の局所U/f/K等は成立。一方で大域・動的整合、疎解法・費用は未完了 | 一貫内力／接線、質量の正値性・剛体特性、全自由度の動的意味、位置・速度・反力I/F、増分保持／再開、境界・接続条件、代表規模での疎構造・費用見積り |

S3の材料点契約やS4の既存基盤を捨てて一からやり直すものではない。ただし、異なる要素の試験をMMS-1の合格には数えない。梁の最終採用・構造全体の1.5統合・UVLM・連成・製品実務受入は、その後の別の判断として[ロードマップ](roadmap.md)に残る。

S1が不合格なら、S2〜S4を進めて採用に見せかけず、まず不合格が数値処理か離散化かを切り分ける。離散化の未達なら現仕様の不採用を記録し、変更する仮説と、必要条件を満たす根拠を先に定める。次数・重み・格子を手当たり次第に変更する探索には戻らない。

採用時期を日付へ換算するには、少なくともS1・S2の成立とS3の一般定義が必要。それまでは「あと数回」「数日で採用」という見積りを提示しない。ここにある4項目は残る判断の分類であり、4ターン・4日という意味ではない。実装開始に必要な理論・I/F・不変条件と、その後の製品受入を混同しない。
