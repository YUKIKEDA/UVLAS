# 対称静的参照の縮約：実装前設計案

2026-10-31、版0.1。[全翼N320の実施結果](verification/avl-span320-results.md) を受けた計算経路の事前設計。以下の1〜4節は実行前の要件と見積もりを保持する。実施状況は5節を参照。製品ソルバーの対称性制約を追加するものではない。

## 1. 適用範囲と数学的条件

今回の2翼はy=0に関して対称で、横滑り・回転速度0、迎角だけの静的線形応答である。鏡映R=diag(1,−1,1)では、負側の有限辺端点をR b、R aの順に入れ替えて正のスパン方向を保つ。対応する循環は同符号になる。

理想的に同じ離散幾何を対にして未知量を並べると

$$
A=\begin{bmatrix}B&C\\C&B\end{bmatrix},\qquad
b=\begin{bmatrix}r\\r\end{bmatrix},\qquad
g=\begin{bmatrix}q\\q\end{bmatrix},\qquad
(B+C)q=r.
$$

これは同じ線形問題の対称部分空間への制限であり、結果の鏡映平均や横力0化で不適合を隠す処理ではない。入力幾何のfloat64鏡映誤差が0でない場合、上のブロック等式を無条件に厳密成立と扱わず、座標差と係数差を別々に測る。非対称部分空間の適格性・動的不安定性の証拠にはしない。

## 2. AVL参照での候補経路

AVLの既存y対称条件と正側の半翼を候補にする。物理断面・コア・後流・S/B/c・軸・原点・出力量は元の全翼を維持する。半翼の面積へ基準量を変えない。既存計測の対称性拒否を無条件に外さず、今回の条件だけを受け入れる別計測版として設計する。

半翼データから全物理領域へ戻すときは、RC・法線・力点・既知／誘導速度・力をRで変換し、有限辺端点と左右脚の所有を入れ替える。Γ/Uは同符号、モーメントは軸性ベクトルとして扱う。倍化した合力だけでは帯荷重・元点モーメントの照合を省略しない。

反射面を横切る帯、ゼロでない横滑り／回転、非対称形状・荷重、複数成分、鏡像の追加等を勝手に支持範囲へ含めない。条件外は拒否する。

## 3. 採用前の必須試験

1. 原ソースの対称処理、コア・自己項・力／モーメントの倍化・高精度出力を監査し、半翼計測・物理全翼展開の契約を実行前に固定する。
2. 小規模で全翼の係数ブロックと半翼行列を独立照合する。法線・辺の向きと右辺の変換も確認する。
3. 既存の全翼複数格子、とくに今回のN320まで、全循環・元点力・全域／帯観測・残差を照合する。相違を平均や幾何投影で取り除かない。
4. 正常／不適格入力・入力不変性・元出力の回帰を検査した後だけ、さらに細かい対称ケースを計算する。

具体的な照合しきい値・対象格子・予算・保存形式は、上記原本監査を行ってから別の事前仕様へ固定する。現在の案だけで全翼参照の代替を許可しない。

## 4. 規模と失敗保証

物理的な全翼N640・M24を半翼で扱えば、未知量は7680、半翼のスパン帯は320となる。これは現容量8000・NSMAX500の範囲内に収まる算術見積もりであり、メモリ・時間の実績ではない。今回の全翼N320の測定値をそのまま半翼計算の性能と扱わない。

出力には幾何・基底・対称モード・展開規則の世代と物理全翼／半翼の区別を必須とする。元参照と新計測版のソース・実行体・入力・結果を分離する。適格性が成立しない場合は全翼結果を残して未達を返し、参照精度・UVLASの一般非対称用途の受入を更新しない。

## 5. 実施追記（2026-10-31）

[縮約の実施結果](verification/avl-symmetry-reduction-results.md) を追加した。初回の6幾何照合は未達で保存し、原因をSPACERのπ精度へ特定した。別版で全翼／半翼双方を修正し、独立分点検査4条件、6全翼・2小行列を含む照合8条件が成立した。条件を満たした対称静的2翼だけで使用する。

[N640の実測](verification/avl-symmetry-fine-observation-results.md) は各7680未知数・物理全翼15360パネルで約91〜94秒、ピーク約3.42GBだった。保存観測の処理検査は成立したが、モーメントのスパン収束条件は未達。縮約経路の使用と参照精度の採用を区別する。次のN1280候補は未知数・帯数の両容量を超えるため、別の容量・資源・回帰仕様が必要である。

[N1280の実施結果](verification/avl-span1280-results.md) を追加した。全体容量に加えて格子生成の局所KSMAXも別版で拡張し、全入力読込み・8回帰の完全一致を確認した。最細は各15360未知数・物理全翼30720パネル、約681／715秒・ピーク約13.47GBで成立。ただし新しいスパン窓では5観測量が両翼とも次数条件未達で、合算予算は全て未評価。N2560の同じ密配列経路は容量・資源を超えるため、既存データの次数変動の診断と次の計算経路の設計が必要である。
