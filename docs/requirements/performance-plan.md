# 性能受入計画

版：0.1、2026-10-29。目標は確定、試験の詳細は設計案。

## 1. 確定した目標

| 要求 | 目標 |
|---|---|
| PERF-01 | 単一PC・CPU、メモリ32〜64GB程度を設計基準とする |
| PERF-02 | 空力約5,000パネル（後流を除く全揚力面の合計）、構造約10万自由度（拘束適用後） |
| PERF-03 | 複数風速の平衡計算と安定性評価を含むフラッタ速度探索全体を一晩8〜12時間程度で完了 |

現状の性能実績ではない。品質条件を満たした同一問題について性能を評価する。未収束の打切り、対象モードの脱落、後流の無検証な短縮で時間目標を満たしてはならない。

## 2. 代表ケースの設計案

性能ケースIDはPERF-FL-01とする。複数揚力面、後退・テーパ、積層材を含む外板・桁・リブ、弾性支持を持つモデルを候補にする。まず再生成可能な形状・材料・接続仕様を作る。性能ケースは実験比較ケースとは別に管理し、計算規模を満たすことを物理的妥当性の証拠にしない。

以下を固定するまで、PERF-03の合否を判定しない。

| 固定項目 | 決定方法 |
|---|---|
| 形状・材料・質量・支持・格子 | 版管理したケース生成条件と実際のパネル数・自由度を保存 |
| 風速・迎角・密度・臨界値の判定 | 一つの荷重条件に対する速度探索を基本単位とし、速度区間、分岐追跡、臨界速度の精度を指定 |
| 探索点数・再試行上限 | 初期走査と臨界近傍の追加探索を含めたルール・上限を設定。点数を減らすだけの性能改善は認めない |
| 後流 | 保持時間・空間分解能・コア・移流方式を感度試験で選定。パネル数と状態数も保存 |
| 構造の線形化・縮約 | 保存するモード・演算子・近似の条件と誤差を指定。縮約する場合は対象モードと臨界値の収束を確認 |
| 収束・精度 | 非線形平衡、線形系、固有対、連成、臨界速度の各許容差を事前指定 |
| 減衰 | 材料・支持の物理減衰、数値減衰の設定とその評価を分離して指定 |
| 出力 | 履歴・診断と、選択した平衡状態の格子・層別結果の書出し量を固定 |
| チェックポイント | 保存間隔・保存対象・圧縮等を固定し、通常運用で発生する保存時間とメモリも総計測へ含める |
| ハードウェア | CPU型、コア数、物理メモリ、OS、電源・スレッド設定、ストレージを記録 |
| 実行条件 | コンパイラ・最適化・依存版・初期化・キャッシュ・スレッド数を指定 |

風速を変える際の平衡解・分解・写像等の再利用は許可するが、同じ探索内で生成したものか、事前計算物かを記録する。事前計算の時間を別枠へ隠してはならない。

## 3. 測定範囲

総経過時間はプロセス開始から入力・モデル構築、初期化、各風速の平衡・線形化・安定性、必要な再試行、結果・診断出力の完了までとする。ビルド・依存の取得と、独立した全V&Vケースの実行は含めない。臨界近傍の過渡照合を探索手順に組み込む場合、その時間も含める。別の検証工程として行う過渡照合は別計測し、実施を省略しない。

主指標は総経過時間、ピークメモリ、完了した探索点数、臨界速度・周波数・成長率の精度とする。内訳として空力組立・分解、後流評価、構造組立・分解、平衡反復、線形化、固有値計算、出力を測る。

Q25 Aの再開に必要なチェックポイント書出しも、固定した運用設定で計測する。性能をよく見せるため保存を無効化しない。通常の連続探索の時間と、別に行う中断・再開試験の再計算・復元コストは分けて報告する。

合格条件の案は総経過時間12時間以内、指定したメモリ環境内で完了、全品質条件を満たすこと。8時間は余裕を持つ運用の目安とし、8時間未満を失格としない。32GBと64GBのどちらを受入測定機とするか、OS等の余裕を含むピークメモリ上限は未確定。

## 4. 初期の容量見積もり

倍精度の5,000×5,000行列は要素データだけで200,000,000バイト（約191MiB）。構造10万自由度を単純な大域密行列として持つと80,000,000,000バイト（約74.5GiB）になる。したがって構造系の疎行列化を前提に、分解時の追加メモリを測定する。これらは配列サイズの算術見積もりであり、プログラム全体のピークメモリや速度の予測ではない。

後流の状態量を含む完全な連成状態行列の記憶量も別途見積もる。疎構造、演算子作用、縮約の候補を比較し、無検証な近似を導入せず目標内に収める方法を判断する。

## 5. 実施順

1. 小規模の正しい基準経路を作り、工程別の計測を組み込む。
2. 中間規模で組立・分解・後流・線形化・固有値の支配項を確認する。
3. 代表ケースを固定し、メモリと時間を測定する。
4. 品質目標を保った改善を行い、代表ケースで再測定する。

試験条件や数値方式を変更した場合は、性能の差と品質の差を併記する。
