# 受入精度・証拠条件

版：0.2、2026-10-29。状態：Q24 Aにより製品精度目標を確定。ケース別の指標詳細・絶対許容差・不確かさ評価は設計中。以下の数値はUVLASの製品要求であり、外部規格の要求値、公開データの測定精度、達成済み性能ではない。

## 1. 判定を分ける

1. 実装検証：規定した数式・単位・符号・接線・写像・状態管理の正しさ。
2. 計算解の検証：格子、時間、後流、反復、固有値・縮約等による数値誤差。
3. 実験妥当性確認：特定の条件・出力量について現実と比較した誤差と不確かさ。
4. 実務適用の受入：対象用途に必要な範囲・精度・運用条件を、上記の証拠が満たすか。

この区別はNASAのV&V解説を参考にするが、本書の数値基準や判定式がNASAによる認証・要求であるとは扱わない。

- https://www.grc.nasa.gov/www/wind/valid/tutorial/verassess.html
- https://www.grc.nasa.gov/WWW/wind/valid/tutorial/valassess.html

## 2. 製品精度目標（Q24 A、確定）

モデル仮定と入力条件を揃えた、事前に定める受入ケース群に適用する目標。任意の形状・運転条件に対する一律保証ではない。

| 出力量 | 製品誤差目標 | 数値誤差・数値不確かさの予算目標（製品目標の20%） |
|---|---:|---:|
| 静的な合力・モーメント・変位 | 5%以内 | 1%以内 |
| 静的ねじれ角 | 0.25度以内 | 0.05度以内 |
| 対象モードの固有振動数 | 2%以内 | 0.4%以内 |
| フラッタ臨界速度・対応周波数 | 5%以内 | 1%以内 |
| 周期応答の一次調和振幅・位相 | 振幅5%、位相3度以内 | 振幅1%、位相0.6度以内 |
| 層別ひずみ・応力（同じ連続体モデルの解析解／独立FEMとの比較） | 5%以内 | 1%以内 |

製品目標が確定しても、現時点の公開データで全項目を判定できるとは扱わない。ケースごとに参照品質と適用条件を確認する。目標に達しない場合は不合格または判定保留として記録し、結果に合わせて許容差を緩めない。

実務で区別したい差がこれらの誤差目標と同程度以下なら、その用途に十分な精度とは扱えない。追加の用途固有要求を設ける。

## 3. 指標と比較条件

- スカラーの相対誤差は $\operatorname{abs}(S-D)/Q_{\mathrm{ref}}$ 。非ゼロの参照値を使うケースでは $Q_{\mathrm{ref}}=\operatorname{abs}(D)$ とする。ゼロ近傍では事前指定した絶対許容差・基準量を使い、分母を結果を見て調整しない。
- 変位は絶対位置ではなく、共通の基準配置に対する指定点の変位を比較する。ねじれ角は定義する翼断面・軸・弦方向から求める。
- 分布荷重は合力の一致だけで判定せず、同一座標上の分布誤差と断面力を確認する。分布の重み・指標・絶対許容差はケースごとに定める。
- 周期応答は同じ励振・時刻基準、定常化後の事前指定区間で調和成分を抽出する。振幅がノイズ床以下の成分の位相は判定対象としない。対象外条件も事前指定する。
- 過渡応答はピーク、ピーク時刻、指定窓の時系列誤差をケース別に指定する。周期応答の基準だけで全過渡応答を合格としない。具体的な過渡許容差はケースの時間スケール・目的から追加する。
- 固有特性は同じモード／部分空間を追跡し、単純な固有値の並べ順で比較しない。対象範囲は低次だけに固定せず、対象の不安定機構に影響するモードまで収束を調べる。
- 臨界速度は指定した平衡分岐の微小擾乱に対する安定限界として定義する。有限振幅の振動開始・ヒステリシス・質量切離しを、そのまま同じ臨界値として比較しない。
- 層別応力は材料軸、応力・ひずみ測度、層、厚さ位置、評価点・平均化規則を揃える。特異点近傍や非収束の最大応力を一つの相対誤差で合格にしない。評価領域の除外は結果を見る前に定め、除外した領域の精度を主張しない。

上表の層別結果の基準は数値モデルの検証に関するもの。材料モデルと実構造の局所応力が実験で確認されたことを意味しない。センサーが測るひずみと、材料定数から求めた応力も証拠を分ける。

## 4. 数値誤差の予算

数値誤差・数値不確かさの目標は、対応する製品誤差目標の20%以下とする。各出力量の値は第2節に示す。位相・角度等も同じ単位で予算を割り当てる。

これは複数の誤差項へそれぞれ20%ずつ割り当てる意味ではない。空間、時間、後流、反復、縮約等を合計した影響を評価し、相関と誤差の相殺に注意する。特異な部品の単体試験や解析解との比較に、製品の5%をそのまま許容しない。

評価手順：

1. 少なくとも3段階の格子・時間等で傾向を確認し、独立に変えられる条件を明示する。
2. 漸近性が確認できる場合は次数・外挿等で評価する。非単調・非漸近の結果へ機械的に適用しない。
3. 最終2段階の差が小さいだけでは十分な誤差上限とみなさない。後流保持、モード数、反復等の別の支配誤差も調べる。
4. 履歴・減衰・不安定分岐の切替を含め、評価対象の定義が細分化中に変わっていないことを確認する。

## 5. 実験比較の証拠条件

各ケースで、参照値の不確かさ、入力・パラメータの不確かさ、数値不確かさ、比較誤差を別々に記録する。測定精度をサンプリング周波数や他コード間の標準偏差から推定してはならない。

判定方法の提案は、同じ単位の差 $E$ と、その評価に関する不確かさ $U_{\mathrm{val}}$ 、許容誤差 $T$ を使い、保守的に $\operatorname{abs}(E)+U_{\mathrm{val}} \le  T$ を要求する方式。 $U_{\mathrm{val}}$ の合成・カバレッジ・相関・確率分布の扱いはケースごとに根拠を示す。独立性を確認せず二乗和を使わない。モデル不一致そのものを、比較結果を包含するよう後付けした不確かさに入れて合格にしない。

不確かさが未確認なら0として代入せず、妥当性確認の判定は保留する。参照の不確かさが大きいことを、目標精度を満たした根拠にしない。

判定は合格／不合格／判定保留／参考比較を区別する。生の差と、どこまでの証拠が揃ったかを併記する。必須用途の証拠が判定保留なら、その用途の実務適用受入は未完了。

## 6. 参照データの現状

S10説明書・モデル・小規模結果を取得し、版・チェックサム・公開ライセンスとモデル構成を確認した。ただし、生データと測定不確かさは未精査。Q23 Aにより梁を直接扱い、集中質量・偏心慣性・剛体結合を含める方針を確定した。要素・接続・入力変換の詳細と三角形の扱いは設計中。

採用審査は [S10調査記録](../../rd/acceptance/s10/records/s10-resource-audit-2026-10-29.md)。公開比較論文が示す計算平均との差は数％の参考情報だが、全出力量の許容差を規定する標準や、S10の測定不確かさを示すものではない。

## 7. 決定事項と次の設計作業

- Q23 A：梁要素を対応対象に追加する。集中質量・偏心慣性・剛体結合も対象とし、構造モデルの変換前後で質量特性・静剛性・固有特性を検証する。
- Q24 A：第2節の精度目標を採用する。実装検証、数値誤差評価、不確かさの証拠条件と組み合わせる。

次に、ケースごとの比較点・領域・時間窓・基準量・ゼロ近傍の絶対許容差、モード対応、過渡指標、不確かさ評価、参照取得手順を定義する。要素・接続の設計と参照品質の確認は継続する。数値目標が決まっても、すべてのケースをこの時点で採用済み・判定可能としない。
