# PG-ANCFの物理荷重・反力・仕事の内部契約

2026-11-04。R4.1の処理境界。内部の数式と責務を定める。C++公開API、全荷重種の採用、一般面の採用は本書では固定しない。

## 1. 測度と作用素

固定参照の位置写像x=Sqを共通入力とする。参照体積当たりの物理力b₀、参照面積当たりの物理力T₀に対し

$$
Q_{ext}(q,t)=\int_{V_0}S^Tb_0(q,t)\,dV_0+
\int_{\Gamma_{0,applied}}S^TT_0(q,t)\,dA_0.
$$

S、参照体積、面積ベクトル、材料点は同じ幾何・基底の版に属する。b₀の単位は力／体積、T₀は力／面積。一般化座標qᵢの単位に対してQᵢはエネルギー／qᵢの単位であり、厚さ勾配の成分まで一律に「節点力N」と呼ばない。座標スケールを変更した場合は荷重を転置で同時変換する。

現在体積・現在面積で指定された荷重は、測度と向きを明示して参照へ引き戻す。圧力の現在面積ベクトルは試行配置の表面勾配から作り、その配置微分を外力接線へ含める。単に参照法線へ圧力値を掛けて追従荷重を実装したことにしない。

同じ物理外力評価器は任意の許容仮想場vに対する仕事L(v)を返せることを要求する。求解の粗い基底に対する右辺もLから作り、製造変位のK倍や参照ひずみの内積を外力入力へ置き換えない。

## 2. 適用面と反力の区別

境界の固定／自由と、荷重のApplied／ReactionReferenceを別に保持する。今回の製造問題のx=0におけるσnは**反力参照**であり、既知の外力として自由平衡へ足さない。一方、ユーザーが拘束面へ明示した実際のApplied荷重は、拘束されていることだけを理由に削除しない。その荷重を含めて反力を回復する。

面ID、側、積分向き、荷重領域、役割を一意にする。内部の適合面を外表面へ二重に数えない。指定された内部面荷重・接合力は明示的な別項とする。異なるパッチの面を同じ物質面として扱うには、その対応とトレース拘束が必要。

線形静的／ゼロ指定変位での残差と反力は

$$
r=Q_{int}-Q_{ext},\qquad Z^Tr=0,
$$

とする。Zは同じ座標・同じ拘束の許容増分写像。rの拘束成分を一般化反力とし、係数の単純な和ではなく並進・回転の仮想仕事から物理合力とモーメントを回復する。現在の試験のモーメントは線形理論に対応する参照位置についての値。

## 3. 主要I/Fと失敗保証

| 処理 | 入力 | 出力・保証 |
|---|---|---|
| 荷重点評価 | 参照点／面・測度、試行位置と必要表面微分、時刻、荷重IDと役割 | b₀／T₀、配置微分の有無、有限値・単位・向き。入力点を暗黙に変更しない |
| 外力組立 | 同じ版のSと参照積分則、荷重集合、試行状態 | Qext、必要なKext、荷重別の寄与・精度診断。共通外力仕事を保持 |
| 粗い仕事評価 | 同じ荷重と同じ幾何、参照だけから選んだ仮想場 | L(v_coarse)。製造解は入力しない |
| 平衡・接線 | Qint/Kint、Qext/Kext、拘束Z、尺度 | r、Zᵀr、Kint−Kext。追従荷重の非対称接線を対称化しない |
| 反力・仕事回復 | 同じ確定状態のr、S、拘束と適用荷重の役割 | 支持仕事、合力、モーメント、外力仕事と内力仕事。参照反力と計算反力を別に保存 |

不明な面、重複所有、非有限値、無効な単位／向き、参照反転、荷重評価の失敗、古い基底・拘束・試行世代の混在を成功として返さない。組立途中の失敗で確定状態を更新しない。死荷重のキャッシュと配置依存荷重の試行キャッシュを区別し、同じ時刻だけをキャッシュキーにしない。

## 4. 相殺と求積精度

薄肉の製造問題では体積力と上下面力のO(h)項が相殺し、一般化曲げ荷重がO(h³)になる。各項を低精度で丸めてから差し引く方法では、荷重が同じでも計算結果が変わる。

今回の専用評価器は、連続体σとdivσの厚さ級数を用い、体積力と上下面力の係数の相殺を荷重側で先に行う。側面の力と固定面の反力参照は別に積分する。独立な80桁の直接積分により照合する。FEのBや剛性を使ってこの荷重を定義していない。

これは製造荷重専用の安定評価器であり、任意の実荷重の汎用積分器の採用ではない。汎用経路では荷重の不連続位置、厚さ・層の尺度、和の相殺、積分次数差と仕事の尺度を診断し、要求精度に達しなければ未収束として返す。独立参照用の80桁計算を製品の標準型とする判断もしていない。

## 5. 受入不変条件と今回の範囲

任意のδqについてδqᵀQext=L(Sδq)。並進を代入すると合力、回転を代入すると対応するモーメントと一致する。同じ拘束で支持反力仕事が指定変位と共役になる。線形のゼロ指定変位では、参照との差の係数u_q=q−q₀について、平衡時にu_qᵀQint=u_qᵀQext=a(u,u)となり、弾性エネルギーUはその半分。絶対位置係数qそのものを変位仕事へ代入せず、検査値がa(u,u)かUかも区別する。

今回の成立範囲は、解析放物柱面、均質等方の線形3D弾性、既知の体積力と全外面力、片端固定。PGの全自由度を残す。一般面・多パッチ、材料／積層・初期ひずみとの要素結合、追従荷重の非線形平衡、慣性と時刻・履歴、汎用荷重の精度保証は、それぞれR4の残作業へ渡す。
