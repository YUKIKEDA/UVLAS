## 0. 本文書の位置づけ

本書は、ソルバーの目的、数値モデル、開発工程、検証・妥当性確認（V&V）、レビュー体制、OSS運営、リリース条件を一つにまとめた初期計画である。実装済み機能や検証実績を示すものではない。

本文の「必須」は、本計画を採用する場合のプロジェクト内ルール案であり、外部規格による一律の要求を意味しない。「推奨」は初期実装の提案、「未決定」は着手前または対応段階の開始前に決定すべき項目を示す。言語、要素定式化、時間積分法、ライセンス、許容誤差は未決定とする。

開発対象はコードだけでなく、数値モデルの説明、再現可能な検証ケース、適用範囲を示す証拠を含む。ソルバー全体に対する無条件の正確性を主張せず、用途・条件・出力量ごとに検証状況を公開する。

## 1. 目的と段階的な適用範囲

### 1.1 目的

薄い柔軟翼の定常・非定常空気力と構造応答を予測する、再現可能で拡張可能なOSSを開発する。UVLM単体とANCFシェル単体を独立して利用・検証でき、その上に連成機能を構築する。

### 1.2 初期スコープ（推奨）

| 分類 | 初期対象 | 後続拡張・対象外 |
|---|---|---|
| 空力 | 非圧縮・非粘性・付着流、薄い固定翼 | 失速・動的失速・衝撃波・粘性抵抗の直接予測は対象外 |
| 翼形状 | 矩形翼から開始し、薄い揚力面へ拡張 | 胴体・翼厚の排除効果は別モデル |
| 後流 | 指定速度で移流する後流 | 自由後流、後流削減・高速近似 |
| 構造 | 等方弾性の片持ちANCFシェル | 積層材、材料非線形、ヒンジ、多物体 |
| 運動 | 剛体翼の指定運動、柔軟翼の応答 | 自由飛行、制御系連成 |
| 連成 | 静的平衡、小振幅非定常応答 | フラッタ、大振幅応答・LCO |
| 主出力 | 揚力、モーメント、分布荷重、変位、振動数・減衰率 | 各追加出力は別途検証 |

ANCFが大回転・大変形を扱えても、空力モデルの有効範囲は拡張されない。迎角の一律上限を正しさの保証として置かず、形状・運動・流れの条件と検証証拠から適用可能性を判断する。

### 1.3 用途の定義

各用途に、予測対象量（QoI）、使用条件、必要精度、判断への影響、必要な検証証拠を設定する。例として、突風時の翼端変位の予測とフラッタ境界の予測では、必要な位相精度・減衰評価・実験比較が異なる。研究用の公開と、設計判断に使用可能とする範囲を区別する。

## 2. 信頼性を支える基本方針

1. **コードの検証**：定めた方程式・離散化を正しく実装したか確認する。
2. **計算解の検証**：対象計算の格子・時間刻み・反復・後流打切りなどの数値誤差を評価する。
3. **妥当性確認**：対象用途に対して、実験と比較し現実の再現精度を評価する。
4. **不確かさ評価**：材料、減衰、実験条件、測定値などの不確かさを扱う。

解析解への一致、他コードとの一致、実験との一致、過去版との一致を区別して記録する。他コードや過去版との一致だけで現実に対する妥当性を主張しない。格子収束も、採用した物理モデルの正しさを保証しない。[R1, R2]

校正用データと妥当性確認用データを分ける。同じ実験に合わせて渦コアや減衰を調整し、その一致を独立した予測能力の証拠として扱わない。実験にも不確かさがあり、誤差の相殺による見かけの一致に注意する。

## 4. ANCFシェルの数値モデル仕様

「ANCFシェル」という方式名だけでは要素を特定できない。要素ごとに以下を固定し、採用論文と実装上の変更を明記する。

| 項目 | 文書化する内容 |
|---|---|
| 自由度 | 節点位置、勾配ベクトル、自由度の並び・単位 |
| 形状関数 | 自然座標、参照形状、厚さ方向の表現 |
| 運動学 | 薄肉／厚肉、横せん断、厚さ変形、大回転・ひずみの範囲 |
| 材料・応力 | 構成式、応力・ひずみ測度、材料座標 |
| 行列・内力 | 質量行列、内力、整合接線、重力・外力 |
| 数値積分 | 面内・厚さ方向積分、低減積分、安定化 |
| 要素品質 | ロッキング、ゼロエネルギーモード、形状歪みへの依存 |
| 拘束 | 固定・ヒンジ、位置と勾配への拘束、拘束反力 |
| 動力学 | 時間積分、初期加速度、物理減衰、数値減衰 |

構造方程式は、採用する拘束形式に応じて、例えば次の形で整理する。

\[
\mathbf M\ddot{\mathbf q}+\mathbf f_{\rm int}(\mathbf q)
+\mathbf f_{\rm damp}(\mathbf q,\dot{\mathbf q})
+\mathbf G(\mathbf q)^\mathsf T\boldsymbol\lambda
=\mathbf Q_a+\mathbf Q_{\rm other},\qquad \mathbf c(\mathbf q)=0.
\]

これは仕様整理用の一般形であり、拘束消去や別の時間離散化を排除しない。減衰を入れない基準系を確保し、後から追加する減衰モデルの効果を独立に評価する。ロッキング等の注意はANCFの要素ごとに異なる。[R6]

## 5. 空力・構造インターフェース

### 5.1 運動の写像

空力点の位置を構造一般化座標から定義する。

\[
\mathbf x_a=\mathbf g(\mathbf q,t),\qquad
\mathbf J=\frac{\partial\mathbf g}{\partial\mathbf q},\qquad
\mathbf v_a=\mathbf J\dot{\mathbf q}+\frac{\partial\mathbf g}{\partial t}.
\]

明示的な時間依存がなければ最後の項はゼロである。指定された基準運動を含める場合、全体運動の定義と速度の追加項を明記し、慣性系と移動座標系で二重計上しない。

空力格子頂点、非貫通点、荷重作用点、後縁点を個別に定義する。構造上の物質座標と空力点の対応を保存し、初期の最近傍探索を毎時刻やり直して写像が不連続に変わる設計は避ける。ANCF形状関数で直接表せる配置を第一候補とする。

### 5.2 荷重の写像

荷重作用点の集中力ベクトルを \(\mathbf f_a\) とすると、同じ作用点の運動写像から

\[
\mathbf Q_a=\mathbf J^\mathsf T\mathbf f_a
\]

と定義し、任意の許容仮想変位に対して

\[
\delta\mathbf q^\mathsf T\mathbf Q_a
=\delta\mathbf x_a^\mathsf T\mathbf f_a
\]

を満たす。面荷重の場合は形状関数と面積積分に基づいて一般化荷重を作り、圧力からパネル合力への変換で面積を二重計上しない。独立な偶力を出力する場合は、その回転運動との仕事共役関係も別途定義する。[R7, R8]

ANCFの勾配自由度を通常の回転角自由度と同一視し、節点モーメントを機械的に代入してはならない。拘束反力を含む収支の取り方も明記する。

仮想仕事の一致に加え、剛体並進・回転の再現性、合力、合モーメントを確認する。瞬間仕事率は、明示的な時間依存がなければ \(\dot{\mathbf q}^{\mathsf T}\mathbf Q_a=\mathbf v_a^{\mathsf T}\mathbf f_a\) となる。指定運動を含む場合は、その運動が供給する仕事率も収支に加える。

空間的な仕事整合性だけで、時間離散化を含む全体系のエネルギー整合性が保証されるわけではない。

## 6. 連成アルゴリズムと状態管理

### 6.1 初期方針（推奨）

独立した空力・構造ソルバーを用いる分割型とし、最初は同じ時間刻みで連成する。弱連成を動作確認・比較用に実装し、動的応答・安定性評価では同一時刻内で反復する強連成を基本候補とする。一体型やサブサイクルは追加機能として検証する。

### 6.2 時間ステップの概念手順

1. 時刻nの確定済み状態を保持し、n+1の構造状態を予測する。
2. 試行中の構造状態から空力格子、法線、翼面速度を更新する。
3. 規定の後流処理とUVLM方程式を評価し、試行荷重を求める。
4. 一般化荷重へ変換し、構造の離散方程式を解く。
5. 構造・空力・連成残差を確認し、必要なら緩和して反復する。
6. 収束時のみ、構造、循環、後流、時間微分履歴を一度だけ確定する。
7. 非収束時は試行状態を破棄し、規定に従って刻みを縮小するか停止する。

この手順は概念図であり、実際の積分法のステージ・時刻と整合する詳細擬似コードを実装前に作成する。後流を反復内で更新するか固定するか、その近似の範囲を明記する。反復回数に応じて後流を重複放出したり、履歴を進めたりしない。

### 6.3 収束・失敗規約

位置、荷重、構造残差、非貫通残差について基準量で無次元化した条件を定義する。荷重がゼロ近傍でも評価できるよう、相対・絶対許容差を組み合わせる。最大反復回数、緩和、最小刻み、再試行回数を記録する。未収束の時間ステップを通常の成功結果として出力しない。

計算状態は、確定済み／試行中／出力用を区別する。中断・再開には後流、循環履歴、構造状態、積分法の内部状態を含める。

## 8. 数値収束・誤差・不確かさ

### 8.1 独立に調べるパラメータ

- 空力格子：翼弦・翼幅の分割、配置。
- 構造格子：要素数、積分則、厚さ方向表現、要素品質。
- 時間：時間刻み、積分法、数値減衰。
- 後流：保持時間・長さ、コア半径、移流・遠方近似。
- 連成：反復許容差、緩和、弱／強連成、サブサイクル。
- 解法：線形・非線形残差、近似高速化の精度。

時間刻みを変えると後流パネル長も変わり得る。時間誤差と後流空間分解能の影響を切り分けられない場合、その結合を明記する。渦コア半径を単にゼロへ近づける収束試験とせず、モデル選択と数値分解能を区別する。

各ケースに、U∞Δt/c、換算振動数k=ωc/(2U∞)、コア半径／基準翼弦、物理的後流保持時間、評価周期数を記録する。複数段階の細分化で漸近傾向を調べ、必要時に観測収束次数や外挿を使う。非単調な結果に形式的な外挿を適用しない。

### 8.2 評価指標

| 対象 | 指標 |
|---|---|
| 定常 | CL、CM、分布荷重、翼端変位、ねじれ |
| 周期 | 平均値、一次調和振幅・位相、高調波 |
| 過渡 | ピーク、到達時刻、正規化した時系列誤差 |
| 動力学 | 固有振動数、モード、減衰・成長率 |
| 数値品質 | 非貫通・構造・連成残差、循環受渡しの整合性 |
| 仕事 | 荷重伝達の仕事誤差、構造への入力仕事と応答の収支 |

UVLM後流を含む開放系を、構造だけの閉鎖系エネルギー保存で判定しない。仕事収支では外部流、指定運動、物理・数値減衰の寄与と評価範囲を説明する。

### 8.3 許容差

許容差は用途、参照値の不確かさ、数値誤差をもとに結果を見る前に設定する。振幅2％・位相2度などの数値は、採用する場合もプロジェクト固有の目標であり、一般的保証値ではない。ゼロ近傍では絶対誤差も使う。未確定の許容差を合格扱いにしない。

## 9. 実験データと妥当性確認

### 9.1 データ採用審査

形状、翼型、厚さ、材料、質量分布、根元・支持装置、流速、密度、Re・Mach、運動軸・振幅・周波数、同期・位相基準、風洞壁補正、測定不確かさ、反復試験、原データ、利用条件を確認する。

図からのデジタイズは抽出手順と追加誤差を記録し、原測定データと区別する。条件が欠けるデータは探索的比較として扱い、厳密な合否の根拠にしない。

### 9.2 公開資源の候補

| 資源 | 使い方・注意 |
|---|---|
| Theodorsen原報 [R4] | 理論検証。実験による連成妥当性確認の代替ではない |
| NASAのAR=2矩形翼強制ピッチ測定 [R5] | 剛体翼空力の候補。条件・不確かさを本文精査後に採用 |
| SHARPy [R3] | UVLM・空力弾性の相互比較候補。独立な実験とは区別 |
| Project Chrono [R6] | ANCF定式化・実装比較候補。要素の一致を確認 |
| NASA HVAB [R9] | 将来のロータ拡張候補。固定翼初期スコープ外 |

上記を挙げたことは、ANCFシェル連成全体の公開実験ベンチマークを確保したことを意味しない。初期の柔軟翼連成実験の選定は未決定とする。

### 9.3 自前実験を行う場合

同一供試体について、寸法・質量測定、材料／剛性試験、無風固有振動・減衰測定、通風静的変形、非定常応答の順に取得する。構造パラメータの同定と連成の評価を分け、通風結果に合わせて構造剛性や減衰を無制限に調整しない。

可能なら複数風速・複数周波数を用意し、一部を校正に、残りを事前予測の評価に使用する。風洞試験の実施は別途、設備側の手順と担当者の判断に従う。

## 10. フラッタ・大振幅応答の追加要件

1. 各風速で変形後の静的平衡を求める。
2. 平衡周りの微小擾乱応答から周波数と成長・減衰率を推定する。
3. 時間刻み、連成収束、後流、構造・空力格子、数値減衰の感度を確認する。
4. 可能なら同じ離散モデルの線形化による安定性解析と比較する。
5. 数値発散、フラッタ、静的ダイバージェンスを区別する。

フラッタ境界への一致だけで大振幅応答やLCOを検証済みとしない。大変形で空力格子が不適切となる条件、剥離が支配的になる条件では、ANCF側が計算可能でもUVLMの適用性を再評価する。

## 11. ソフトウェア構成と再現性

### 11.1 モジュール境界（推奨）

| モジュール | 主な責任 |
|---|---|
| 数値基盤 | 線形代数、積分、残差、精度設定 |
| 空力 | 格子、誘導速度、循環、後流、荷重 |
| 構造 | ANCF要素、材料、拘束、組立、時間積分 |
| 写像 | 運動・荷重伝達、作用点、仕事整合性 |
| 連成 | 予測・反復・確定・ロールバック |
| 入出力 | ケース形式、結果、チェックポイント |
| V&V | 参照データ、評価、図表、報告生成 |

UI・可視化からソルバーを分離し、CLIまたはライブラリAPIで自動再実行できるようにする。単体ソルバーを連成ドライバーなしで試験できる構成とする。

### 11.2 実行記録

各結果に、ソルバー版・コミット、入力とハッシュ、単位・基準量、格子、全数値設定、依存ライブラリ、実行環境、スレッド数、収束履歴、警告、終了状態を付ける。図表は実行記録と元データに追跡可能とする。

基準実装は逐次・直接計算を第一候補とし、並列・GPU・高速近似との差を定量化する。再現性はビット一致、許容差内一致、統計的一致などの水準を定義し、演算順変更を理由なく完全一致扱いにしない。チェックポイント再開と連続実行の比較も行う。

## 12. 体制・責任・意思決定

| 役割 | 責任 |
|---|---|
| 空力責任者 | UVLM数式、荷重、後流、適用範囲 |
| 構造責任者 | ANCF要素、材料、拘束、積分、減衰 |
| 連成責任者 | 写像、仕事、時刻、反復、履歴 |
| 実装担当 | 実装、部品テスト、性能、障害対応 |
| V&V担当 | 参照値、合否、収束、実験、報告 |
| リリース担当 | 証拠・既知問題・公開範囲の確認 |

小規模チームでは兼任可能だが、重要な数式・荷重・時刻の変更は実装者以外が確認する。連成変更は空力と構造の両視点でレビューする。1人開発では外部レビューを節目に設け、独立レビュー未実施の項目を明記する。

数値方式の変更は設計決定記録（ADR等）に、問題、候補、採用理由、精度・性能への影響、証拠を残す。合否基準の変更は実装変更と同じ厳しさでレビューする。

## 13. OSSの運営規約

### 13.1 公開前に決めること

- プロジェクト名、保守者、意思決定方法、対応範囲。
- ソースコードのライセンス。依存関係・配布形態との互換性を確認して選ぶ。
- 文書と実験データのライセンス。コードと同じとは仮定しない。
- 貢献条件。DCOまたはCLA等の必要性を検討し、採用理由を示す。
- 対応OS、コンパイラ／ランタイム、依存ライブラリ方針。

公開資料であっても再配布可能とは限らない。参照データは出典・版・取得日・利用条件を記録し、再配布不可なら原データ取得手順と加工スクリプトを提供する。互換性不明のコードや論文添付物を無断で取り込まない。

### 13.2 リポジトリの最低限の案内

README、LICENSE、CONTRIBUTING、行動規範、保守者一覧、サポート方針、セキュリティ報告窓口、変更履歴、理論仕様、V&V手順、既知制約、引用方法を用意する。CITATION.cffやリリースDOIは任意の整備候補とする。

ユーザー報告の最小再現ケースには、版、入力、環境、期待した根拠、実際の結果を含める。未発表・機密データを公開Issueへ投稿することを要求しない。

## 14. 変更管理・CI・不具合対応

### 14.1 PRに必要な情報

目的、対応要求、式・アルゴリズムの変更、影響する出力量、確認ケース、数値差、性能差、制約・文書更新を示す。高速化と物理・数値モデルの変更は可能な限り評価可能な単位に分ける。

### 14.2 実行段階

| 段階 | 検証 |
|---|---|
| PR | 部品、符号、対称性、写像の仕事、短い空力・構造・連成ケース |
| 定期 | 格子・時間収束、長時間後流、自由振動、反復感度 |
| リリース前 | 対象範囲の全V&V、対応環境、再開、性能・再現性 |

テストが実装と同じ式を再計算するだけにならないよう、独立式、対称性、解析解、実験などを組み合わせる。参照結果の更新には根拠を要求し、CIを通すためだけの基準値更新・許容差拡大を禁止する。

### 14.3 不具合の扱い

クラッシュと、誤った数値を正常終了で返す不具合を分けて記録する。数値不具合は影響版、条件、出力量、回避策、再計算の必要性を調べる。修正には再発防止ケースを追加し、重要な影響はリリースノートと既知問題一覧に公開する。

## 15. 開発段階と完了条件

| 段階 | 到達点 | 次へ進む条件 |
|---|---|---|
| M0 | 用途・数値仕様・V&V計画 | 未決定事項と責任が明確 |
| M1 | 定常VLM | 誘導速度、符号、定常理論・収束を確認 |
| M2 | 指定後流UVLM | 非定常理論、時間・後流感度を確認 |
| M3 | ANCFシェル単体 | 静的・動的、剛体運動、薄肉挙動を確認 |
| M4 | 写像・片方向連成 | 仕事・合力・モーメント・指定運動比較が成立 |
| M5 | 静的双方向連成 | 平衡・反復・両格子の収束を確認 |
| M6 | 動的双方向連成 | 位相・減衰・履歴・刻み・連成感度を確認 |
| M7 | 実験妥当性確認 | 用途別の精度と制約を報告 |
| M8 | 自由後流・フラッタ等 | 追加機能ごとの証拠と適用範囲を承認 |

M2とM3の独立開発は可能だが、連成前に各単体の証拠を確保する。研究用の早期公開は可能であり、その場合は未検証範囲と実験未実施を明示する。機能追加の完了と妥当性確認の完了を別々に管理する。

## 16. リリースの判定と配布物

対象範囲について次を満たしたときに、対応する検証済み状態を付与する。

- 必須ケースが合格し、未確定の合否条件がない。
- 必要な数値収束と感度評価を完了している。
- 重大な数値不具合、未収束の既知ケースへの扱いが明確である。
- 入力・参照・比較・図表生成を再実行できる。
- 数値モデル、適用範囲、既知問題、変更履歴が更新されている。
- 対応環境の確認と、ライセンス・データ利用条件の確認が済んでいる。

配布物にはソース、利用手順、理論仕様、ケース、V&V報告、既知制約、変更履歴を含める。報告はUVLM単体・ANCF単体・写像・連成系に分ける。実験未確認の範囲を「Validation済み」と表現しない。

ソルバー版、入力形式版、参照データ版を追跡し、デフォルト設定の変更や数値結果を変える変更を明記する。API互換性と数値結果の互換性は別に説明する。
