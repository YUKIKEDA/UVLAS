# ソルバー開発・レビューの共通Rules

2026-11-06。科学技術計算の設計・R&D・実装レビューで適用する。プロジェクト固有の物理式・許容差・言語選択を上書きする規則ではない。適用する領域と例外の根拠を明示する。[由来と実例](lessons-and-evidence.md)、[UVLAS固有規約](uvlas-review-profile.md)。

| ID | 守ること | 判断に使う確認 |
|---|---|---|
| SE-01 | 製品の目的・品質・範囲を、研究の都合・学習目的・簡単な例へ置き換えない | ユーザーの決定と技術仮説を区別。要求変更が必要なら選択肢・推奨・長短をまとめて示す |
| SE-02 | 要求合意、設計採用、実装検証、数値認定、実験妥当性、実務受入を別状態にする | 「何が、どの条件・量・版で完了か」を記す。ファイル数・被覆表・hashで品質や完成率を作らない |
| SE-03 | 新しい実験・候補を、既存未達の原因と結ぶ | 何を変え、どの結果で説明を識別し、いつ採否を決めるか。核心の後回しを解決と数えない |
| SE-04 | 比較する物理問題・離散作用素・観測を同定する | 核の実式、自己項、境界、荷重点、基準点、測度、時刻、観測区間。名前や同じパラメータ値で同一性を推定しない |
| SE-05 | 局所成立から共有後の空間・全体系成立を推論しない | 接続・支持後のrank、必要場、薄肉／歪み・境界仕事、元KKT、対象modeを確認 |
| SE-06 | 原系と実際の消費表現で精度を検査する | 組立・求解・積和・保持・投影・下流kernel・保存後を区別。小残差を前進精度の保証にしない |
| SE-07 | 運動・力・微分を同じ定義で閉じる | 物理点と双対仕事、幾何接線、状態依存慣性・拘束、全陰的依存。非対称成分・負固有値を都合よく消さない |
| SE-08 | 時刻・輸送座標・誕生・算法履歴を明示する | 物理／算法微分、初期／受理後、同じ離散平衡、実IDの過去、全履歴のchart変更を区別 |
| SE-09 | 失敗した試行は親確定状態を変えない | 親世代・資格・一回確定、cache失効、所有権、再開の十分状態、破損・非互換拒否を検査 |
| SE-10 | 参照の独立性と不確かさを主張の範囲に合わせる | 自己整合と独立PDE／実験を分離。未知不確かさを0にせず、sampling rateを精度にしない |
| SE-11 | 採否に使った証拠を後から書き換えない | 対象版・入力・判定・出力を追跡。訂正は別版とし、旧未達と変更点を保持。未公開の作業メモ全てを凍結する規則ではない |
| SE-12 | 性能は実際の仕事と品質を揃えて判定する | 実graph／fill、後流・全履歴、固有抽出、一時領域、精度fallback、I/O、全探索・再試行。合成行列と単一分解は容量証拠に限定 |
| SE-13 | 開始判定の依存閉包と、実装後の停止gateを明示する | 式・I/F・入力・参照が未決定なら該当処理を保留。全製品を別言語で先に完成させる条件にはしない |
| SE-14 | レビューは仕様自体も審査対象にする | コードが文書どおりでも物理・時刻・単位が矛盾すれば仕様欠陥。重大指摘には発生条件・影響・証拠・再検証を付ける |

原理的に問題を変える操作（rank方向の削除、人工支持、接線対称化、未認定の縮約・コア／後流変更等）を単なる実装最適化と呼ばない。適格な数値変更なら、元問題との同値性または近似誤差と適用域を示す。

疑問の事実確認と利用者の意思決定を分ける。実装担当者が調べるべき単位・微分・データ不足を、好みのQAで決めさせない。routine作業のたびに確認を挟まず、既存の許可と依存条件に従って進める。
