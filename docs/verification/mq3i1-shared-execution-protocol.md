## 使用前に閉じる参照セル

既存局所検査はκ=0/.4の正則1セルと歪み2×2各4セル。正則2×2の8セルは新しい参照写像なので、先に同じ3厚さ・24局所条件を検査する。可解性・全制約・rank138・一定場・剛体・保持成分・膜4場・座標軸変更・零次／一次の基準は前回のまま。膜の重みや条件を変更しない。追加24条件を別結果へ保存し、QR核上の局所最小二乗・物理テンソル膜場・体積対外表面の仕事で別評価する。未達なら共有組立へ入れない。

元の10セルと追加8セルの固定係数系をSHA256で照合する。共有配置で必要な16セルだけを選ぶ。保存セルのキーが一致しない場合に未検査セルを自動生成しない。

## 共有零次／一次写像

固定KKTのh=0解と一次微分を再構成し、11³でも、一定場・剛体・辺・密度微分込みの仕事・c零次ゼロ・零次ζ非依存・一次ζ線形・複素厚さ直接解の差を既存1e−9基準で検査する。正負.0001の基底rank・制約rankとspan、全制約残差も確認する。検査済み局所係数系と零次／一次写像を保存する。

共有のr/d核は9²／11²、相対1e−9/10/11、列尺度共通で比較する。既知二次方向を用いる基底構成は以前の仕様と同じとし、次元を増やさず、新旧射影差1e−7・直交差1e−10・核残差1e−10以下を必要とする。二次／四次のH¹球制約最小二乗と残差・求積差の基準は主契約のまま。
