# 1.2 材料点・層積分の追加代数検査

2026-11-03、実行前に固定。既存のQ9材料接線試験を再実行せず、[材料・層採用契約](../material-layer-adoption-contract.md)で追加した要素非依存の境界を検査する。

合成定数E=(130,10,8)、G23/G13/G12=(3.5,4.5,5)、ν12/ν13/ν23=(.28,.25,.32)を同じ単位で使用する。実材料の校正値ではない。seed20261103で小さいMandelひずみ・初期ひずみを作る。

固定6群：工学／Mandelのエネルギー・compliance、曲面接線からの軸と回転変換、法線平行繊維の拒否、法線Schur補元とcomplianceからの別回復、異なる2層の厚さモーメントとテンソル直接2点求積、均質材の3分割不変性。各誤差はmax(1,参照ノルム)で正規化し1e−10以内。Schurを省略したCaaとの差が1e−4より大きい負の対照も要求する。

軸の曲面点はκ=.4、x=.31、z=.003、w=(1,.2,.1)。厚さ範囲[-.01,.01]の2層分割は−.003、材料軸角は.3／−.61、上層剛性は.7倍、E0は下e0／上−e0/2。均質分割点は−.002／.004。モーメント法はMandel行列、直接求積は対称テンソル→工学成分の別経路で求める。

これは材料点・層積分の代数照合。材料カーネルの平面応力縮約が要素の厚さ運動学と整合すること、主シェルの材料／層別応力精度、実測材料の妥当性は示さない。失敗時に入力・閾値を変更して同じ結果名を上書きしない。
