# 最良近似の上下界による後続検査

2026-11-02。初回8配置・152問題は実行可能性と独立観測を通過したが、厳しいせん断条件のKKTが未達だった。原結果・閾値を保持し、最適性成立へ読み替えない。

後続はSADDLE/NORMAL-C,n=2/4,h=0.001、w11、H¹上限2倍、相対せん断許容値1e−4/1e−6の8問題。元の保存行列・解・非負乗数λを使う。任意の点x=(r,p)におけるL=f+λ(||Wr+Dp||²−ε²)/2と勾配g_r,g_pから

$$
f_{\min}\ge L(x)-\tfrac12g_r^{\mathsf T}G_r^{-1}g_r
-B\|H_p^{-1/2}g_p\|-g_p^{\mathsf T}p
$$

を使う。これはλ≥0と凸性、位置目的のG_r強凸性、pのH¹球の支持関数から得られ、xがKKTを満たすことを必要としない。計算では第2項を||g_r||²/(2 g_min)で保守的に上から押さえる。g_min,h_minは行列の正定値下界。

行列積は明示したpairwise加算とbinary64の単位丸め誤差から包絡を計算する。Gramの下界は任意の可逆変換QによるQᵀGQのGershgorin下界とQᵀQの上界を使い、行列積の誤差も差し引く。H¹双対ノルムは近似線形解の残差とh_minから上界を付ける。正規化前の目的に上下界を付けてから、位置相対誤差へ変換する。これは保存した離散binary64行列の問題についての包絡で、連続積分や幾何表現誤差の厳密証明ではない。

上界は元の解を必要に応じて共通に縮小し、9³・11³双方のせん断上限とH¹上限を誤差包絡込みで満たした点から計算する。縮小後の位置誤差も再計算し、元の上界を流用しない。

解析解のある小問題（せん断上限のみ有効、せん断とH¹上限が有効、非最適な実行可能点、制約なし最適点）で、上下界が既知解を含むことを先に確認する。実データでは上下界の順序、正定値下界、上界点の実行可能性を確認する。幅は結果として報告し、合格させるための幅を事後設定しない。300秒・1GiB。親と成果物・ソース・本条件のSHA256を保存する。
