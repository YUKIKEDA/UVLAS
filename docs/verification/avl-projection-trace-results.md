# 製造投影・後縁差の符号相殺：実施結果

2026-10-31。[事前仕様](avl-projection-trace-experiment.md) を固定して実施し、[結果JSON](avl-projection-trace-result.json) と [証拠監査](avl-projection-trace-artifact-audit.json) に保存した。追加AVL計算、元循環・物理翼・荷重点・元の収束条件の変更はない。

## 処理検査

8検査項目すべてが成立した。

| 項目 | 結果 |
|---|---|
| 一様格子の解析値 | 4解像度×2場の8件。ψ₁の既知L2誤差・積分、2場の後縁誤差を照合。最大差8.68e−19 |
| 独立多項式積分 | 12台形×10多項式の120照合。5×5Gaussとの差最大4.00e−15 |
| 80投影の直交残差 | 返却float64係数の実際の累積値で最大3.54e−17。前線上流の制約領域は別扱い |
| 投影観測の保存 | 解析積分と固定320領域の合計の差最大8.89e−16 |
| 実トレースの再現 | 36隣接比較の揚力差が元台帳と最大9.37e−16以内で一致 |
| 帯・領域分解 | 正負、符号付き、L1、L2二乗を保存。全域との差最大1.12e−16 |

| 資源 | 245.1秒、ピーク134,533,120 bytes、結果JSON 6,296,615 bytes |

厳密有理数で幾何と多項式モーメントを計算し、投影定数をfloat64へ変換した後の場を評価した。製造場と実流れの精度を混同しない。

## 前線移動による方向条件の未達

現前線上の製造投影は、24系列すべてで既知場へのL2誤差が4段階を通じて減少した。一方、全域の隣接差について既存の方向条件を含む漸近候補は0、固定セル平均も候補0だった。物理ソルバーの誤差がなくても、同じ前線配置で方向条件の未達が起きることを確認した。

FW-V01の対角系列の例を示す。次数は隣接する既知誤差の比から計算したもの。格子差だけから推定した真の誤差ではない。

| 格子族・製造場 | 既知誤差の観測次数3段階 | 隣接差の方向余弦2段階 |
|---|---|---|
| 元・ψ₁ | 0.895、0.952、0.978 | −0.418、−0.408 |
| 元・ψ₂ | 0.913、0.960、0.982 | −0.411、−0.406 |
| 帯適合・ψ₁ | 0.846、0.925、0.966 | −0.428、−0.429 |
| 帯適合・ψ₂ | 0.860、0.910、0.965 | −0.457、−0.481 |

スパンだけを細分する系列では弦方向を固定しているため、既知場への総誤差は弦方向の表現誤差の床へ近づく。そこで得た小さい次数を、全面的な非収束と読み替えない。

この結果は実流れの全誤差が表現誤差だったという証拠ではない。別の製造場の投影差を実流れの差から引くこともしない。[責任境界](../field-representation-and-observation-contract.md) に、表現誤差・物理誤差・格子差・観測差の区別を定義した。元の判定結果は保持する。

## 揚力差が非単調になる仕組み

実際の後縁差の絶対量は減っていても、正負の相殺の強さが変わると、符号付き積分である総揚力差は増えたり符号を変えたりする。FW-V01・弦系列の結果を示す。

| 格子族・比較 | 後縁差のL1 | 相殺比L1/絶対積分 | 一次揚力傾斜の変化 |
|---|---:|---:|---:|
| 元 M4→8 | 0.0185072 | 24.42 | +0.00018048 |
| 元 M8→16 | 0.00771634 | 2.289 | −0.00080252 |
| 元 M16→32 | 0.00457390 | 1.038 | −0.00104882 |
| 帯適合 M3→6 | 0.0254876 | 8.234 | +0.00073703 |
| 帯適合 M6→12 | 0.0126427 | 12.37 | +0.00024334 |
| 帯適合 M12→24 | 0.00502980 | 1.979 | −0.00060515 |

元格子はN96、帯適合はN160を固定。L1は速度正規化された後縁差を物理yで積分したm²、揚力傾斜変化はrad⁻¹。相殺比の分母床は全36比較で状態として記録した。表の有限値は実測の正負積分から得ている。

最後の弦比較のL1寄与では、元格子は中央34.2%・内部64.1%・両翼端計1.68%、帯適合は中央38.4%・内部56.2%・両翼端計5.39%。この比較を翼端だけの誤差として扱うことはできない。領域の大きい寄与を、独立参照なしに物理誤差の原因と断定もしない。全翼・全方向の区間別記録をJSONへ保持した。

## 判断と次の仕様

全域P0場の方向条件だけから物理精度不良を断定すること、符号付き総揚力差だけで空間誤差を判断することの限界を確認した。これは参照精度の受入ではない。

次は [定常有限翼の保存観測・誤差評価案](../finite-wing-observation-error-contract.md) に従い、後縁トレースτと弦積分Kで揚力・有限辺モーメントを保存する式を検証する。元RVの偶力も維持する。固定帯の0次・1次モーメントとノルム上限を検査し、真の解への誤差評価と単なる格子間差を区別して、残る参照誤差予算と追加格子を定義する。精度目標を緩めるものではない。
