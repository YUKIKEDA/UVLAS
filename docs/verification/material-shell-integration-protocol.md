# 材料1.2：主シェル統合・等価入力の検証仕様

2026-11-05。R4/R5と既存材料点の証拠を維持する。新しく閉じる対象は、材料入力から採用主シェルの層別評価への接続と、STR-01の等価入力の定義。

1. 等方のE/ν、3D直交異方性9定数、明示的な全3D等価Mandel剛性6×6を受理する。正の密度、初期Greenひずみ、固定参照軸、物理全厚、層区間を必要とする。等価剛性から不足する厚さ定数を推測しない。
2. 共通の固定軸を持つ平坦断面で、ひずみe=a+zb+z²cに対する18×18仕事行列・初期項と、二次速度場の質量を、解析的な0〜4次厚さモーメントと独立テンソル直接積分で照合する。相対誤差1e−10以内。初期エネルギー定数項も保存する。
3. 同じ面内ABD・横せん断・密度情報を持つ異なる3D則を構成し、法線ひずみで異なる仕事となることを示す。ABD単独入力は不足として拒否し、STR-01の任意ABD復元が不要である既定要求を維持する。厚さ・基準面・単位が異なる場合も同値としない。
4. 採用済み非二次曲面・変厚、同じfull V（n1、h=.05）で、不均等な3層（等方・直交異方性・一般SPD等価則）を評価する。入力経路を明示dense則へ変換した場合のC/E₀/ρの点別同値、U/f/Kの複素方向微分、層界面両側の回復を確認する。代数・方向微分1e−8以内。無効な層所属や暗黙平均を許さない。
5. 密度を含む同じ整合Mと、独立厚さ求積・解析物理Xの剛体速度から得る空間慣性を照合する（1e−9）。均一剛体速度場を回復し、Mに現在qを含めない。既存R4の均質層再分割・客観性・平衡復帰は再利用する。
6. 単位／成分／測度、定数不足、非対称／非SPD剛性、密度、E₀自然計量、層の隙間・重複・逆順・ID重複、繊維特異、基準面変換・証明値不一致を負対照で拒否する。失敗時は入力・確定状態を変更しない。材料の正定値性の数値診断は対角尺度化後λ_min>1e−12、対称性誤差≤1e−12。丸め範囲の対称化は量を記録する。

等価入力は明示された3Dの有効則（単層または有効層列）である。断面モーメントの一致は上記の平坦な試験族に関する同値で、曲面の全3D応答の同値とはしない。曲面で同じモデルと言う場合はC/E₀/ρ/軸の物理点での一致を要求する。実材料の校正・ひずみ範囲・実験不確かさは実務ケース5へ明示的に引き継ぐ。
