# R4.1：独立な体積力・面力による線形平衡

2026-11-04。PGの基底・材料・支持・閾値を変更せず、製造連続体のb=−divσ、全外面t=σnから右辺を組む。Kと既知変位の積を外力として与えない。参照ひずみは求解後の誤差観測と照合だけに使う。

σ=Σₘσₘzᵐ、N=R+zD+z²C/2とすると、j=g−κz、a=(1,0,κx)、d=(−κx,0,1)。体積力と上下面力の厚さモーメントを別々に丸めて差し引かず、次を外力評価器内で組み合わせる。

$$
W_l=\frac1{l!}\sum_m[-\sigma'_m a M_{m+l}+l\sigma_m d M_{m+l-1}-\kappa(l+1)\sigma_m e_zM_{m+l}],\quad M_p=\int_{-h/2}^{h/2}z^p dz.
$$

これは物理体積力と上下面力の係数の相殺を解析的に行った式。x/y外側面は別に全て積分する。固定x=0面は反力参照として分ける。この式の一致を、独立な応力発散・面積ベクトル・数値積分と検査する。固定側面を許容変分の外力に加えない。

求解は参照だけで決める滑らかな8曲率モードから粗い初期場を作り、全自由度補正を解く。粗い右辺も同じ物理外力から作る。滑らかな粗い場を使い、内部応力ジャンプの分布荷重を落とさないようにする。全列QRの二つの三角求解を使い、剛性Gramを形成しない。製造ひずみ評価器を求解中に呼んだ場合は失敗とする。

先に正則n2・h=.01/.0001・独立曲率3場を検査。数値条件を通過後、歪みn2、正則／歪みn4へ進む。既存投影解との差は物理場・エネルギー・位置で相対1e−8以内、自由平衡・線形残差・独立積分差1e−8、rcond≥1e−10、支持1e−9。反力仕事、外力仕事と弾性仕事、合力・モーメントも照合する。既存の1%／薄肉増幅2倍は維持する。

原級数14項と18項、面内13次と15次で荷重を照合する。初回2配置は1配置180秒・計360秒・2GiB。不合格なら数値原因と定式化の原因を分け、同じソース／結果を上書きせず次版で対応する。一般面・積層・非線形・慣性・実務性能の採用はこの検査だけでは閉じない。
