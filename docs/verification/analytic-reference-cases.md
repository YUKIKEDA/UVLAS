# 最初の解析的参照ケース

版：0.1、2026-10-29。実装前のケース仕様。以下の数値は検証用に設計した入力・解析的期待値であり、ソルバーの実行結果ではない。採用する要素・APIとの接続前なので、これらだけで実装開始判定を通さない。

## REF-V01：有限渦線の誘導速度と符号

- 対応：PHY-01、CV-01、AE-03、OP-05、INV-09、PR-A01。
- 入力：I内でA=(0,−1,0) m、B=(0,1,0) m、P=(1,0,0) m、有向渦A→B、Γ=2π m²/s。無限空間、非正則化の理想有限渦線。
- 独立参照：Biot–Savartの線積分をこの幾何で直接積分する。 $u_z=-\frac{\Gamma}{4\pi}\int_{-1}^1(1+s^2)^{-3/2}\,\mathrm ds=-\frac{1}{\sqrt2}\,\mathrm{m\,s^{-1}}$ 。x、y成分は0。
- 期待値：u=(0,0,−0.7071067811865475) m/s。Γだけ反転、またはA/Bだけ交換すると速度は反転。両方変更すると元に戻る。
- 事前許容差案：各成分の絶対誤差1e−12 m/s。非特異・倍精度のこの入力専用の基準であり、近接・退化ケースへ流用しない。
- コアモデルを選ぶ場合：コア付き式の別ケースを作る。この理想値を有限コアの厳密参照値として使わず、コア→0の極限と分ける。
- 未完了：採用カーネルとのI/F対応、独立数値積分による解析参照の照合、近接・退化・座標変換ケース。

追記： [UVLM時刻・接続試験](uvlm-time-topology-experiment.md) で、この一点の有限渦線式と解析値、別の離れた評価点の渦輪式と64点線積分を限定照合した。正則化・近接・自己項、全ての符号反転・座標変換、製品カーネルの採用は未完了。

## REF-V02：偏心点の仮想仕事と明示的時間依存

- 対応：QUAL-05、TR-01/02、OP-04/07、INV-07/08、PR-T01〜03。
- 参照運動学： $q=(r_{x},r_{y},r_{z},\theta )$ 、 $g=r+R_{z}(\theta )d$ 、d=(0.2,0,0) m。このθは解析参照用の一軸回転座標であり、ANCFの勾配DOFと同一ではない。
- 評価入力：r=0、θ=π/2 rad、点力f=(10,−20,30) N、座標速度v=(1,2,3,4) [m/s,m/s,m/s,rad/s]。
- 独立参照：g=(0,0.2,0) m、 $J=[I_{3}, (-0.2,0,0)^{\mathsf T}]$ 、一般化荷重Q=(10,−20,30,−2)。θ成分はN·m。
- 合力モーメントの参照：原点周り $g\times f=(6,0,-2)$ N·m。一軸回転座標の $\mathbf Q_{\theta}$ が表すのはz成分。x/yモーメントを同じ一自由度で表したとはしない。
- 速度・仕事： $\mathbf v_{a}$ =(0.2,2,3) m/s、 $v_{a}\cdot f=v\cdot Q=52 W$ 。仮想変位δq=(0.001,−0.002,0.003,0.004)なら線形化された仮想仕事は0.132 J。
- 明示的時間依存の副ケース：上記gに $(0,0,0.5(t-t_{0}))$ mを加え、t= $t_{0}$ で評価。JとQは同じ、 $\mathbf v_{a}$ =(0.2,2,3.5) m/s、流体荷重のパワー67 W、一般化座標へのパワー52 W、指定運動分15 W。
- 事前許容差案：位置1e−12 m、速度1e−12 m/s、荷重1e−11 N／N·m、パワー1e−10 W、仮想仕事1e−12 J。それぞれの入力・単位に限る。
- 未完了：ANCF／梁の実際のg・DOFとの接続、非一致格子、独立モーメント、Jおよび荷重接線の方向微分ケース。

## REF-V03：参照補間を含む剛体運動のひずみ

- 対応：GEO-01、STR-01、ST-02/03、OP-02、INV-01/02/03、PR-S01。
- 入力の構成：採用する参照補間 $\mathbf X_{h}$ (ξ)について、全ての位置DOFを $r_{i}\to R r_{i}+c$ 、全ての勾配DOFを $d_{i}\to R d_{i}$ として変換する。R= $R_{z}$ (π/3)、c=(0.3,−0.4,0.5) m。回転の能動／受動の規約はCV-01へ照合。
- 独立参照：補間が上記変換を再現するなら $\chi_{h}$ =R $\mathbf X_{h}$ +c。従って非退化点で $F=(R X_{h,\xi }) X_{h,\xi }^{-1}=R$ 、 $E=0$ 。曲面参照配置でも同じ導出が成立する。
- 適用条件：無応力参照配置、外力・支持・初期ひずみなし。材料W(0)=0、∂W/∂E(0)=0。剛体回転で変化しない内部変数処理も含める。
- 期待値：全評価点でE=0、弾性エネルギー・弾性内力0。位置へcを加えるが勾配へcを加えない。
- 未完了：要素選定後の具体的な節点座標・勾配・層・求積点、内力・エネルギーの尺度と許容差。従って現時点では解析的構成法までの仕様であり、実行可能ケースは未完成。

## REF-V04：動く支持に対する受動減衰

- 対応：BC-01、ST-09、OP-03、INV-06、PR-S03。
- 入力：一次元粘性要素、c=2 N·s/m、構造点速度v=0 m/s、支持速度 $\mathbf v_{s}$ =1 m/s。抵抗を左辺へ置く規約で $f_{d}=c(v-v_{s})$ 。
- 期待値： $\mathbf f_{d}$ =−2 N。相対散逸は $(v-v_{s}) f_{d}=2 W\ge 0$ 。構造点のv $\mathbf f_{d}$ =0だけを見て散逸ゼロと判定しない。
- 独立参照：粘性要素の両端への力は構造側− $\mathbf f_{d}$ =2 N、支持側 $\mathbf f_{d}$ =−2 N。両端へする仕事率の和は−2 Wで、上記の散逸と符号が逆になる。
- 事前許容差案：力1e−12 N、仕事率1e−12 W。
- 未完了：多次元支持・回転支持への拡張、採用DOFへの写像、過渡の解析解との照合。

## 適用上の注意

Q27 Bの初期ひずみ・予荷重の追加ケースIS-V01〜05は [指定初期ひずみ設計](../initial-strain-design.md) に置く。特に初期応力が非ゼロの場合、REF-V03の無応力条件を適用せず、IS-V02の回転不変性・共変性で比較する。

式・期待値の導出とソルバー実装の結果を分けて保存する。許容差案は採用カーネル・評価法との整合を点検してから基準化する。REF-V01/02/04の具体値があっても、他の参照や全体系の開始条件が揃ったことにはならない。
