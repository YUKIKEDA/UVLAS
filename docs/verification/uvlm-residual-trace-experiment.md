# 空力細格子の残差・反復改良・局所圧力トレース試験

版：0.1、2026-10-30。1〜6節はコード作成・実行前に記載。

## 1. 対象と仮説

[精度契約](../uvlm-residual-and-trace-accuracy.md) と [前回結果](uvlm-local-pressure-refinement-result.json) に従う。同じM=1024/2048、k=.1/.5/1、上下・2回転軸ピッチ、c=1、B=10000、U=8、ρ=1.2、L=160、連続後流・厳密微分の行列を再構築する。格子・圧力区間・トレース・物理参照は固定。

仮説は、補償残差・補正による観測変化と局所圧力の格子差が分離できること。後退誤差と物理残差、標準BLASと補償評価を同じ量として扱わない。

## 2. 補償評価の適格検査

TwoProductを、固定seedの50組（指数±20）について100桁Decimalで積の高低分解と照合。既知の積丸め反例 $(1+2^{-27})(1-2^{-27})-1=-2^{-54}$ と、総和の相殺反例も検査。有限値・指数範囲を守る。

各行列・右辺について行0/1/M÷2/M−2/M−1、3運動の残差を80桁Decimalで計算し、補償値との差/右辺列ノルム≤ $10^{-18}$ 。最終解も同じ選択行で検査する。高低保持が必要ならDecimalも両配列の和を評価する。

## 3. 反復改良と精度要求

LU初期解の標準BLAS・丸め済み積のfsum・TwoProduct補償残差、成分別後退誤差を記録。補償残差の相対ノルム≤ $10^{-11}$ を対象表現の基準とする。float64で最大4補正、未達・停滞なら高低2配列経路で最大4補正。各経路の保持表現、補正量、履歴、停止理由、float64投影後の残差を残す。

最終の対象表現で補償残差≤ $10^{-11}$ 、成分別後退誤差≤ $10^{-12}$ 。行列・右辺のSHA256が補正前後で同一であること。標準BLASの旧残差条件を遡って合格へ書き換えず、評価方法の違いを表示する。

## 4. 物理観測と空間差

前回と同じ11圧力区間、F/Mを補正前後に評価し、同じ基準量で正規化した変化≤ $10^{-6}$ を検査する。この基準が成立すれば、補正による変化は前回の2.319%の格子差より十分小さいと判断する。

補正後のM=2048の局所平均誤差≤5%、1024→2048変化≤2%も元の条件のまま再判定する。未達は保存し、低い補償残差だけで圧力を受け入れない。

## 5. トレースの独立参照と分解

独立圧力から得るμ参照は128点／256点Gaussのθ積分で比較し、差/ $\{U(|H|+c|\alpha|)\}$ ≤ $10^{-10}$ 。全圧力区間の両端、各下端を含むセルの中心と端点、後縁cで評価する。

補正後の局所平均誤差を区間積分項・右トレース項・左トレース項へ分け、3項の和と直接圧力差が尺度付き $10^{-11}$ 以下で一致すること。左端のセル内位置も記録。有限幅・有限長と2D無限後流参照の差も内訳に含むため、全てをP0配置だけの誤差と断定しない。内訳の大きさは診断とし、物理合格の追加閾値は置かない。

## 6. 保存・停止

180秒・512 MiB。積和は行ブロック処理し、全行列のDecimal化はしない。source／依存と旧結果ハッシュ、入力A/Bハッシュ、epsilon、残差・補正・投影の履歴、選択行照合、観測変化、圧力誤差内訳と位置、判定・未達、時間・メモリを別JSONへ保存。異常・予算超過は部分結果を保存する。製品の数値型やソルバー採用にはしない。

## 7. 積和・Decimal照合の結果

[実験コード](../../tools/design-experiments/check_uvlm_residual_trace.py)、[結果JSON](uvlm-residual-trace-result.json)。6系×3右辺の初期・最終解を検査した。NumPyのfloat64とlongdoubleのepsilonはいずれも $2.220446049250313\times10^{-16}$ 。

固定50組の積は高低分解と100桁Decimalが一致。積丸めの反例は、丸めた積のfsumでは0だが、TwoProductを含めると厳密値 $-2^{-54}$ を得た。総和相殺の反例も既知値1と一致した。したがって「和だけを補償した」評価とは区別できている。

各系5行×3右辺の初期・最終、計180行の照合は、補償値と80桁Decimalをfloat64へ丸めた残差が一致した。選択行での検査であり、全行列の区間演算による厳密保証ではない。実行中の指数範囲・有限値条件は成立した。

## 8. 残差と反復改良

以下は3右辺中の最大補償相対残差。

| M | k | 初期解 | 最終解 | 補正回数 |
|---|---|---|---|---|
| 1024 | .1 | $9.34\times10^{-12}$ | 同左 | 0 |
| 1024 | .5 | $7.34\times10^{-12}$ | 同左 | 0 |
| 1024 | 1 | $1.90\times10^{-12}$ | 同左 | 0 |
| 2048 | .1 | $4.41\times10^{-11}$ | $6.56\times10^{-12}$ | 1 |
| 2048 | .5 | $1.96\times10^{-11}$ | $1.21\times10^{-12}$ | 1 |
| 2048 | 1 | $1.64\times10^{-11}$ | $1.10\times10^{-12}$ | 1 |

M=2048、k=.1の初期標準BLAS残差は最大 $4.3640\times10^{-11}$ 、補償評価でも $4.4015\times10^{-11}$ だった。初期未達を積和誤差だけで説明できず、格納された同じ系の解に補正の余地があった。1回の補償残差による反復改良で全右辺が基準を満たした。

最終保持表現は全6系でfloat64。高低保持への分岐は今回発動せず、その経路や製品の数値型を検証済みとはしない。最終float64解の標準BLAS残差も全系最大 $9.79\times10^{-12}$ で基準内。成分別後退誤差は最大 $1.06\times10^{-15}$ 。後退誤差と右辺で正規化した残差は別指標として記録した。行列・右辺のSHA256は補正前後で一致した。

## 9. 局所圧力との分離

補正による圧力の変化は最大 $2.95\times10^{-11}$ （既存の圧力尺度で正規化）。力・モーメントも同様に小さく、観測変化の $10^{-6}$ 基準を満たした。M=2048の最大局所平均誤差は約0.4406%のまま、1024→2048の最大変化は2.3193%のまま。求解精度を改善しても、2%の空間変化条件の未達は解消しない。

独立μ参照の128点／256点積分の差は最大 $2.75\times10^{-14}$ で基準内。区間平均誤差の3項分解も直接圧力差と最大 $3.41\times10^{-16}$ の尺度付き差で一致した。

最悪の格子間変化に対応する、k=1・四分の一弦ピッチ・区間[.975c,c]を示す。値は区間の圧力尺度に対する各複素寄与の**振幅**。複素数の和なので、振幅同士を足して総誤差とはしない。

| 内訳 | M=1024 | M=2048 |
|---|---|---|
| 区間積分項の差 | 0.2526% | 0.1269% |
| 左右トレースを合成した差 | 2.4082% | 0.1772% |
| 左トレース単独 | 3.9794% | 2.7429% |
| 右トレース単独 | 5.7976% | 2.9117% |
| 左端のセル内位置（0〜1） | 0.24313 | 0.73368 |
| 滑らかな参照のセル中心→左端位置項 | 1.0825% | 0.4936% |

粗格子では合成トレース項が区間積分項より大きかった。左右の誤差の相殺、固定観測端点のセル内位置の変化が局所平均に影響することを定量化した。一方、μ係数自体の離散誤差、有限幅・有限長の差も含むため、全誤差をセル内位置だけへ帰属させない。これらの値で圧力を補正したり、区間端点を移動したりしていない。
