# 独立参照のコアモデル差の診断

2026-11-05。複数面調和比較の初回は1e−9の同一作用素条件を満たさず、最大行列差6.86e−8だった。初回結果を保存する。Ptera5.1.0原本の `_aerodynamics_functions.py` を再確認すると、端点距離r1/r2は正則化せず、分母の外積二乗へL²ε²を加える。主方式のRosenhead–Moore線積分では端点距離も√(r²+ε²)となる。**同じεの数値は同じ正則化核を意味しない。** 既存の有限ε比較は、このモデル差も含んだ独立コード比較として解釈する必要がある。

原因を切り分けるため、初回と同じ6格子・4運動を、両側ε=0の非接触条件で再実行する。自己移流は含めず、同一の理想核で行列／循環／共通観測1e−9以内を要求する。閾値を緩めない。理想核で成立しても、有限εの核差が自動で零になったことにはしない。既存の大格子1e−5m比較の値・判定は変更しない。

実務ケースの精度認定には、主方式自身の格子・コア収束が必要である。参照モデルの差を持つ比較だけで、理想流体や任意の有限ε解の誤差上界を与えない。現在の周波数比較の判定は、この差を明示した検証指標として扱い、NumericallyQualifiedへの昇格には該当する誤差群の証拠を要求する。
