# 全厚側面の面力を矩形で照合する

[Case の全厚側面の規約](../../../specs/structure/pg-case-lateral-traction-contract.md) に対する独立な有理参照である。矩形シェルは中央面 $x=1\,\mathrm m$、$y\in[2,4]\,\mathrm m$、$z\in[3,5]\,\mathrm m$、全厚 $127/50000\,\mathrm m$ とする。$y=2\,\mathrm m$ の断面を固定し、$y=4\,\mathrm m$ の側面全体に世界 $+Y$ の一定面力を与える。Young 率を200 GPa、Poisson 比を0とし、軸伸び $\lambda=1025/1024$ での参照面積当たりの牽引を $t_Y=E\lambda(\lambda^2-1)/2=102550048828125/524288$ Pa とする。

面積は $127/25000\,\mathrm{m^2}$、面心は $(1,4,4)\,\mathrm m$ である。$F_y=4167633984375/4194304\,\mathrm N$。原点 $o=(2,1,3)\,\mathrm m$ 回りのモーメントは $(-F_y,0,-F_y)$ [N m] となる。仮想並進 $(1/2,-3/4,1)\,\mathrm m$ と仮想回転 $(1/4,-1/2,3/4)$ に対する仕事は $-7F_y/4$ [J]。載荷端へ一様に $1/512\,\mathrm m$ を与える仮想仕事は $F_y/512$ [J] である。

軸方向に $(y-2\,\mathrm m)/(2\,\mathrm m)$ 倍した $+Y$ の1 m の仮想変位には $F_y\cdot1\,\mathrm m$ を返す。反対側の固定断面へ荷重を移すと、この仕事は零になる。厚さ方向に $\zeta^2$ 倍した同じ仮想変位の仕事は $F_y\cdot1\,\mathrm m/3$ である。厚さの中心線に面力を集中させると、この仕事も零になる。

独立式は、Cartesian の面積と面心、および各変位・荷重の積分から得た。別に、側面の1片と非等分に切った2辺片×2層に有理 Simpson 則を適用した。全観測は厳密一致し、対称なこの積分則では辺の局所向きを反転しても一致した。順序の対照には別に非対称な節点を使う。元線分の $z=5\to3\,\mathrm m$ に沿う $u=1/3$ は、面片の $z=3\to5\,\mathrm m$ に沿う $u=2/3$ と同じ $z=13/3\,\mathrm m$ を指す。向きを直さずに $u=1/3$ を評価すると $z=11/3\,\mathrm m$ になる。 [有理参照](oracle.py)

有理参照で、面片の欠け・二重計上、符号、線を積分測度とする誤り、異なるモーメント原点、載荷端、厚さ中心線、辺の反転漏れを検出した。

```bash
python3 -B docs/verification/IM-02/pg-lateral-traction/oracle.py > /tmp/pg-lateral-traction.json
```

Ubuntu 24.04.5 の Python 3.12.3 で通常実行と `-O` の出力が一致した。SHA-256 は `b8143b88b0eef704c16d2a85b44c10cddd33cb667033a7350d5cc0ed2c3c58f4`。隔離した版では、面積の厚さ幅を外した変異と、辺の座標反転を外した変異をそれぞれ `-O` で検出した。

## 製品試験へ渡す判定

- 元基底の各列の荷重は、既知の面片上の元形状多項式をモノミアルの積分式で積分する。保存された基底変換を最後に適用し、製品が返す各列の包絡が独立値を含むか調べる。積分する元形状には、製品経路の節点評価から独立した係数を使う。平面・一定厚の側面で21次以下の辺方向多項式を照合できるよう、22個の固定二進有理節点の Lagrange 多項式を厳密積分して正の重みを得た。次数0〜21の全モーメントが $1/(k+1)$ に一致し、分子・分母の最大幅は378 bitである。同じ面の深さ方向は2次以下なので Simpson 則を使う。
- 元列から合力、モーメント、剛体仕事と二つの位置検査を回復する。N、N m、J のそれぞれの SI 単位で、各出力包絡は独立値を含み幅が $10^{-18}$ 以下とする。辺向きを逆にしたときは非対称な有理節点を使い、各面片の元点順と物理位置を照合する。同一 Load の二重計上と、異なる Load の明示的な和を区別する。
- 面片の被覆、別の Case・基底、取消、資源、未対応の測度、不正な節点・重みを試し、元試行が再利用できることを確認する。平衡へ接続する試験では、元残差の自由行と固定断面の反力の総和 $-F_y$ を別々に検査する。三つの入力経路の比較には同じ物理 Case の荷重を使う。

## 型付き Case から元列へ

`CasePgLateralTraction::prepare` は型付き SI Case と、その Case が所有する条件付け済み Shell パッチを受け取る。
Shell 自身の荷重を宣言順に読み、同じ Shell を対象とする静解析の荷重を続ける。
各積分点は Load ID、境界番号、元線分、原子辺、側面片、層、局所座標、厳密重みを保持する。
`evaluate` は同じ所有を確認し、宣言した精度で外力 `newtons[column][axis]` を囲う。
平衡と反力は拘束消去前の共通元列でこの値を残差から引く。
固定参照面積と世界方向の面力なので、固有対が使う状態微分への寄与は厳密に零となる。

[製品試験](../../../../tests/coupling/case_pg_lateral_traction_test.cpp) は、回転・移動した矩形に逆向きの名付き境界と非等分の2層を設定する。
2つの Load ID から、3原子辺×2層×22辺節点×3深さ節点の順で計792点を準備する。
各元列の独立値には節点評価を使わず、未条件付けのモノミアルを面上で積分した後に、保存された基底変換を適用する。
出力は世界 XYZ の全成分で比較し、合力、移動した原点回りのモーメント、剛体仕事、軸方向と厚さ方向の仕事を同じ元列から回復する。
曲面では、Cartesian の面方程式を直接微分して同じ6点則を評価し、非有理な面積を含む外力の包絡を調べる。
この曲面の照合対象は指定した有限則の外力である。

```bash
cmake --build --preset linux-release --parallel 1 --target uvlas_test_coupling_case_pg_lateral_traction
ctest --preset linux-release -R '^coupling\.case_pg_lateral_traction$'
```

Ubuntu 24.04.5 LTS の GCC 14.2.0 Release で3ケース、8,260件の検査が通った。
元列を含む矩形の包絡幅は各観測の SI 単位で $10^{-18}$ 以下だった。
隔離した製品の変異では、辺の向き判定を反転すると側面座標の検査が落ちた。
参照面積測度を1に置き換えると、曲面の合力の独立包絡に対する検査が落ちた。
