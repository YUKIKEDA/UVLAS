# 非定常参照：連続極限の推定と有限解の区別

2026-11-05。M64/N192の有限解同士の差は1%内に入ったが、先行の各0.25%の空間配分は未達。ここで有限解の精度を合格へ書き換えない。連続極限の独立参照を適格化できるかを、追加の小さい格子M8/N96・M16/N192で評価する。

弦のM8/16/32/64・幅のN48/96/192/384から、方向ごとに複素増分のノルムの収縮率と方向を保存する。3水準外挿の補正量、隣接する3水準から得た外挿値の差、M/Nの交差差をすべて報告する。収束次数が安定しない場合や増分が相殺している場合は外挿を受け入れない。

外挿の不確かさは、隣接外挿値の差の1.5倍に、方向を組み合わせたときの交差差と求積・コア・後流の感度を加算して見積もる。これは数学的な厳密上界ではなく実測に基づく推定。独立コードの推定極限同士の差、有限解と推定極限との差、有限解自身の差は別々に出す。有限格子の空間配分未達を外挿で消さない。

最終M64/N192の参照については、近接の幾何尺度に合わせた区間分割＋Gauss16を追加し、既存のGauss12の不足を検査する。両端の閉鎖とL128mは保持する。

製品の誤差制御・適用可否は、実際に返す有限解の誤差推定に基づく。ここで参照の連続極限が推定できても、任意の粗格子を1%精度と認定するものではない。
