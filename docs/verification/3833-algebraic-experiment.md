# 3833型・自由単要素の代数試験仕様

版：0.1、2026-10-29。実行前に定めた仕様と実施結果。実装前設計計画第7節の限定試験で、製品要素・CLI・APIの実装ではない。[再現用スクリプト](../../tools/design-experiments/check_3833_rank.py) は設計実験として分離し、作業結果は `build/analysis/` に置く。

## 仮説・入力・独立な判定根拠

- 幾何：平坦な正方形、a=b=1 m、h=0.1 m、標準8節点、全初期d=(0,0,1)、全初期c=0。無応力、無拘束、初期ひずみゼロ。
- 材料：等方体積弾性、Y=1 Pa、ν=0.3、ρ=1 kg/m³。実材料の同定値ではなく、ランクとエネルギーを調べる入力。
- 基準は適合Greenひずみの参照状態での線形化。ANS/EAS・粘性・縮約・集中質量・時間積分は含めない。
- 質量の独立根拠：24個のスカラー補間関数が独立なので正の体積積分のGram行列はrank72。面内3点・厚さ2点では厚さの二次場が二点でしか観測されず、質量rank48となる。
- 接線の独立根拠：適格な無応力の体積弾性場で、ひずみゼロの運動は6個の剛体運動。完全積分のrank66を期待する。2×2×2のひずみ観測行列は48行なので、rank66にはなり得ない。
- 調べたい未確定事項：3×3×2の弾性経路で、余分な零モードが生じないか。rank66が得られても薄肉精度の証拠とはしない。

## 試験手順

形状関数と面内一次微分、厚さの1,z,z²/2から、質量の重み付き補間行列と、弾性エネルギーの重み付きひずみ行列を作る。行列の二乗で小さい特異値を失わないよう、ランクはGram行列ではなく元の観測行列のSVDで評価する。

質量は5×5×5、3×3×3、3×3×2。弾性は5×5×5、3×3×2、2×2×2を比較する。

剛体基底は3並進と3回転。回転では位置速度をω×r、厚さ一次速度をω×d、厚さ二次速度をω×cとして、全座標を同じ運動学から与える。

厚さ2点の質量反例にはQ8-V04と同じ速度場を使う。今回のρでは厳密エネルギーは $2.77777777777778\times10^{-8}\,\mathrm J$ 。

## 事前の判定・打切り条件

- SVDのランク閾値は最大特異値の $10^{-10}$ 倍。閾値の10倍・1/10倍でランクが変わる場合は不明として基準化せず、尺度・条件を再検討。
- 剛体基底の独立性はrank6。正規化したひずみ観測残差は $10^{-12}$ 以下。
- 解析的な質量エネルギーの相対差は $10^{-12}$ 以下。厚さ2点でゼロを期待する反例の絶対エネルギーは $10^{-20}\,\mathrm J$ 以下。
- 完全積分経路がrank66・rank72や剛体条件を満たさなければ、低減積分の採否へ進まず、微分・材料・座標・閾値を再点検。
- 非有限値・形状関数恒等式の不一致・不適格な材料分解があれば中止。結果へ合わせて閾値を動かさない。

## 結果の用途と限界

補間・質量・求積・零モードの設計判断に使う。独立FEM比較、曲面・薄肉・積層・初期ひずみの精度、非線形接線、時間応答、フラッタ、製品の実装開始判定を代替しない。

結果欄は実行後に追記する。成功・失敗・不明を分け、数値実験が確認できた仮説だけを採用根拠にする。

## 実施結果（2026-10-29）

Python 3.12.14、NumPy 2.3.5で実行。 [機械結果](3833-algebraic-result.json) に入力・SVD特異値の境界・閾値感度・残差を保存した。ランクは行列次元72に対して評価する。

| 求積 | 質量rank／零空間次元 | 弾性接線rank／零空間次元 | 解釈 |
|---|---|---|---|
| 5×5×5 | 72／0 | 66／6 | 今回の基準条件を満たす |
| 3×3×3 | 72／0 | 66／6 | 平坦・一定密度の質量条件を満たす。曲面の5点基準を置換する証拠ではない |
| 3×3×2 | 48／24 | 66／6 | 弾性はこの状態で余分な零モードなし。質量へは不採用 |
| 2×2×2 | 24／48 | 48／24 | 弾性に剛体以外の18零モード。安定化なしの経路は不採用 |

ランクは事前の3閾値すべてで一致。剛体残差は全条件で $1.6\times10^{-17}$ 以下。基準質量の反例エネルギーは $2.7777777777777784\times10^{-8}\,\mathrm J$ 、3×3×2では $2.63\times10^{-39}\,\mathrm J$ 。事前に定めた11判定はすべて成立した。

設計判断：質量の高次基準と弾性の低減経路を分ける。3×3×2の弾性経路は次の比較候補に残すが、今回の条件で零モードがないことを、薄肉・歪み・曲率・非線形応答の精度や安定性の証明へ拡張しない。

再現コマンドはPython・NumPy環境で `python tools/design-experiments/check_3833_rank.py` 。出力は `build/analysis/3833-rank-result.json` 。基準経路の判定に失敗すると非ゼロで終了する。製品のCMake・CTest・CLIには登録していない。
