# 同一疎因子による転置求解の検証

[転置求解の契約](../../specs/foundation/sparse-transpose-contract.md)に沿って、同じ準備済み疎因子で前進と転置を求め、方向ごとの原残差でそれぞれを認定した。

| 照合 | 独立参照と拒否 |
| --- | --- |
| 非対称の疎LU | 4次の整数行列から前進の右辺1列と転置の右辺2列を固定した。解析上の解に加え、前進右辺と転置解の仕事、前進解と転置右辺の仕事がともに $-45$ となることを照合した。 |
| 物理尺度と所有 | 方向ごとに配置、尺度、単位を変え、同じ所有者で交互に解いた。別試行、右辺の別配置、同じ世代の別係数・別尺度、前進専用因子への転置と結果の予算不足を拒否した。成功済みの値と認定を保持し、再利用後の同じ求解はビット一致した。 |
| 両語と原残差 | 非対称の2次行列で右辺の低位語に $3\cdot 2^{-60}$ を渡し、両語を厳密に照合した。丸めた射影が許容を外れる場合は `PrecisionUnresolved` を確認した。別のbinary64右辺では、解 $[1/3,-2/3]$ の反復改良による昇格と、十進200桁相当の独立演算による原転置残差を照合した。 |
| LLTと資源 | 元の行列を認定した上で、同じLLTの両方向を厳密な固定解と照合した。前進・転置の三角代入を続けて行った間にC++確保はなかった。転置の反復改良を含む入口の確保は、前進と同じ所有結果用の8件だった。 |

## 対象試験

MSVC 19.51.36260のReleaseとDebug、およびUbuntu 24.04のGCC 14.2.0 ASan/UBSanで、対象6 CTestがそれぞれ通った。UBSanは最初の違反で停止させた。

| CTest | ケース | アサーション |
| --- | ---: | ---: |
| `numerics.sparse_spd` | 8 | 35 |
| `numerics.sparse_triangular` | 3 | 61 |
| `numerics.sparse_solve` | 15 | 152 |
| `numerics.sparse_allocation` | 2 | 20 |
| `numerics.dense_solve` | 11 | 153 |
| `numerics.gmres_solve` | 5 | 39 |

clang-tidy 21.1.1では変更対象の5翻訳単位を検査した。

負対照では、転置の三角代入を保ったまま原残差に行列の前進作用を使った。GCC14の隔離実行で、前進の照合を通過した後、非対称系の転置が `LinearUnconverged` で拒否され、想定した成功を検出する試験が失敗した。

この求解入口は、固定ピボットチャートが同じ拘束Jacobianを前進と転置で使うための基盤になる。閉路での原行の優先規約、指定値の時間係数とその評価は、実際の原拘束とチャート準備の契約で定める。
