# 複数面：物理右辺による独立比較

2026-11-05。製造右辺の全相互組立に加え、既知一様流と二枚の後退テーパ翼の物理荷重をAeroSandbox 4.2.10へ照合する。主翼はFW-V01、尾翼は半幅2.5m・根元弦1m・翼端弦0.4m・後退20度、中央前縁(5,0,0.6)m。双方のねじり・上反角は0。密度1.2、速度20、一次迎角微分、閉後流L1024m、原点周りMyを使用する。

初回はM/N=2/12、4/24、8/48の3格子。自側と独立コードで同じ定義の各翼・全体系のFz、Myを比較し1%以内を要求する。主翼・尾翼の独立単体計算も行い、相互作用を削除した負対照との差が非零であること、独立コード同士でその差も1%以内となることを確認する。

自側は理想核を使える指定定常後流に限定。独立コードは1e−9m。両翼の面と後流は異なるzにあり、接触しない。幾何座標を相互照合し、渦輪循環の弦差と馬蹄循環の区別を保つ。三格子の一致を格子収束の総量認定へ読み替えず、干渉作用素・物理右辺・荷重の接続の限定検証とする。
