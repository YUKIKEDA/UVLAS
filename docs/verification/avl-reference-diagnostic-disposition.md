# AVL参照診断の終了判定

2026-10-31。対象：FW-V01／FW-V02の静的対称翼・一次荷重、AVL3.52から派生した監査版。**今回の診断は終了。現経路は数値精度の受入参照として採用しない。** 元データ・診断結果は保存し、有限翼の精度根拠不足は未解決として後続の採用審査へ引き継ぐ。

## 採否の対象

AVL一般の正しさや適用性を判定するものではない。今回の入力・派生実行体・保存観測・資源条件による経路が、[有限翼比較仕様](finite-wing-load-reference-specification.md) の精度受入参照になるかを判定する。公式原本、安定核修正版、対称縮約・容量拡張版、求解診断版を同一の実行体とみなさない。

独立配分対照は実行段階472.21秒・ピーク約4.91GB、後処理22.39秒・約221MB。全6処理検査と成果物監査が成立した。元点モーメント分布の翼端効果ノルムは合成効果の約0.957倍、内側は約0.338〜0.340倍。K帯平均では内側が約1.009倍、翼端が約0.199〜0.203倍で、観測量ごとに感度が異なる。有限辺モーメントの全域傾斜では、内側と翼端が約1e−7の逆符号となり、合成は約1.36e−10〜6.33e−10へ相殺された。これらのノルム比を足して1になる寄与率や真の誤差と解釈しない。

この追加結果はM12の配分応答を切り分けたが、N1280系列のM24スパン漸近性を成立させていない。係数生成誤差を排除したり、次数変動の原因を完全解明したりした結果ではない。数値精度の受入条件が未達であることを理由に、この経路の診断を終了する。

## 確定した判断

1. 数値精度の受入参照は、既定の条件が成立した範囲だけを採用する。現経路の未評価の予算を0と扱わず、N640の条件付き推定やM12の配分感度で代替しない。
2. 検査済みの保存出力は、同じ入力・実行体・観測定義による再現性／回帰と、有限格子間の比較・診断に利用できる。ただし、UVLASの連続解への精度、物理妥当性、実務適用の合否の独立根拠にはしない。
3. 原因の完全解明と参照の採否を区別する。未解決の次数変動が残っても、必要な精度根拠が成立しない経路を受入参照として保留する判断は可能。診断終了を、原因解明済みやE-AERO完了へ読み替えない。
4. 合否しきい値、製品要求、固定20帯の観測、元点／有限辺モーメントの区別を変更しない。

## 追加計算を再開する条件

この系列を既定の次作業として延長しない。新しい調査は、必要とする評価量・要求ID、既存証拠では不足する理由、独立した精度の根拠を得る方法、打切り条件、資源予算を別仕様として確定してから行う。

同じ7枚相当の密行列方式によるM24N2560は、配列だけで約53.41GiBとなり現環境を超える。現在の実行体のまま細分化を続けない。別の計算経路や別参照を選ぶ場合も、同じモデル・荷重定義との対応と、その参照自体の誤差を審査する。

## 後続設計への影響

- RF-03／E-AERO／VV-03：有限翼の精度受入参照に関する不足を残す。参照を失った要求を閉じた扱いにしない。
- AE-01〜06：今回の診断だけでUVLM方式を採用しない。定常・非定常、複数面、局所分布、モーメントそれぞれの根拠を対応させる。
- J1：後流・荷重・時間積分・強連成・同一離散系の線形化は別の採用審査で閉じる。
- 製品本体：実装開始条件は解除しない。初回実務適用の要求と公開方針も変更しない。

ユーザーが指定した順序で、次は1.構造モデル、2.UVLM、3.J1、4.数値処理・I/F、5.実務ケース・受入根拠、6.実装範囲の着手審査を進める。順序は審査の主対象を示すものであり、後続の設計との整合確認が不要になることを意味しない。構造審査を進めるためにAVLの精度受入を偽って閉じる必要はない。
