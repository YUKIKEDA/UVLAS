# 誘導抗力：極限の順序を分離する有限計画

2026-11-05。前回の正則化Trefftzエネルギーは区分一定循環の節点渦の自己項を厳密に含む。一方、採用した近傍荷重は有向辺中点で定義した離散Joukowski力である。固定したP0幅格子で一方のコアだけをゼロへ近づけて、両者の一致を要求しない。

まず次の三つを別の名前で保持する。

1. `near_midpoint`：採用2.2の全誘導・全対象辺の力の迎角二乗係数。自身の直線辺だけは厳密に零。後流端は閉じたL1024m。
2. `trefftz_midpoint`：遠方の流下渦列から帯中点の速度を求め、帯循環と幅を掛ける離散観測。遠方速度を使うため係数はρ/2。理想核を使い、幅の連続極限を別に検査する。
3. `trefftz_regularized_energy`：前回の対数積分。固定幅格子での自己エネルギーを含む有限コアの量として保存し、上の二つの精度参照とは無断で同一視しない。

遠方速度と係数を、指定した楕円循環の解析抗力πρΓ₀²/8、別の直接積分、剛体断面回転・尺度・向き変更で検証する。これは有限弦楕円翼の厳密解を主張する試験ではない。

有限翼はFW-V01/V02を維持する。まず幅N96固定でM16/32/64、N192でM16/32/64の近傍荷重を測り、弦方向の収束と外挿補正を保存する。M32までの既存循環・独立荷重を再利用する。新たな定常解は左右対称な物理配置に限り代数を半減し、粗格子全体系との照合と元の残差検査を行う。必要な場合だけM128/N192を各翼1回追加。1ケース1200秒・24GiBを上限とする。

遠方観測は既存N96/192/384とN768を使用し、M16/32による後縁循環の弦方向差も評価する。AeroSandbox原本のN768・半径1e−9/1e−10mについて後縁循環を追加保存し、参照コアによる抗力感度を直接測る。既存の帯揚力感度を抗力の感度へ読み替えない。

目標は近傍の弦極限と、同じ幅格子の遠方中点観測の差、および幅を連続化した独立参照との差をそれぞれ1%以内にすること。相対差が1%を超えた有限解を外挿で合格へ書き換えない。外挿は収束率・補正量・異なる水準での差を伴う推定として区別する。未達の場合は主因を特定し、方式の変更が必要かを判断する。

根拠：近傍力と遠方抗力の数値的な収束の違いは [MIT AVL User Primer](https://web.mit.edu/drela/Public/web/avl/AVL_User_Primer.pdf)、Joukowski荷重の弦方向収束と非定常抗力は [Lambert–Dimitriadisの原論文](https://orbi.uliege.be/handle/2268/200767) を参照。終了したAVLの数値参照系列は再開しない。
