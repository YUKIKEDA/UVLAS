# PG-ANCFの候補適格性検査

2026-11-04。[対のスカラー位置補完](../paired-geometry-ancf-definition.md)は正則n4・独立曲率の棄却検査を通過。基底を変更せず全面の候補適格性を判定する。以前のGCの不合格を取り消さない。

条件と閾値は[GC適格性仕様](geometry-compatible-ancf-qualification-protocol.md)を引き継ぐ。正則／歪み・標準3参照場・n2/n4・2厚さの8配置、追加曲率a=2/4/6・n4・2厚さの4配置、計12配置。元点13×7と独立15×9、元作用素停留・圧縮／独立差1e−8、rcond≥1e−10、正の整合質量、共有／固定1e−9、代表自由パッチの剛体6のみ、一定F・剛体回転・体積／全外面仕事・材料＋幾何接線、代表薄肉n2の別SVDを要求する。

最細相対誤差1%、薄肉増幅2倍、標準場のn2→n4減少（1e−12以下は数値床として識別限界を記す）。標準場の数値床だけを改善の証拠にせず、追加曲率の数値床より大きい誤差でも判定する。1配置300秒・系列1800秒・2GiB。1024点逐次評価は同じ点と重みを使用する。

追加曲率4条件を先に実行し、不合格なら停止。通過後、標準8配置を実行する。12配置を今回の基底で評価し、以前の異なる基底の合格を移用しない。r/d対の係数、基準場と補正、参照基底、ハッシュを保存する。高精度基底の空間／導関数／連続性と、基準場が実際にSの空間に入ることを別に照合する。

全検査通過で判定するのは、この範囲で最終採用審査へ進める候補の成立。主シェル最終採用、一般面、物理PDEの受入、積層／初期ひずみ、非線形過渡・性能の成立や人による独立レビューは意味しない。
