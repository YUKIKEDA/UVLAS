# 影響係数の独立高精度照合：実施結果

2026-10-31。[事前仕様](avl-aic-generation-experiment.md) の1〜6節を固定して実施した。収束判定・参照翼・元の解・既存係数は変更していない。[結果JSON](avl-aic-generation-result.json)、[全記録の監査](avl-aic-generation-artifact-audit.json) を保存した。

## 結果

8系、合計296,832係数の7条件すべてが成立した。48/192未知量の小系は全係数、大規模6系は既存の選択8行・8列の重複を除いた和集合である。大規模系の標本外係数は今回評価していない。

| 検査 | 結果 |
|---|---|
| 現Fortran核のfloat64再現 | 検査した全係数で保存Aとの差0 |
| 保存AとDecimal80 | 絶対差最大1.092e−13 m⁻¹、事前の絶対＋相対許容値に対する比は最大1.49e−4 |
| Decimal80→160 | 誤差上位・幾何的接近上位の和集合251ペア、差最大2.32e−77 m⁻¹ |
| 独立な数値線積分 | 対角を含む16ペアで成立。係数差最大2.39e−12 m⁻¹で、各係数の事前絶対＋相対許容値内 |
| 選択全行の係数差作用 | 保存IR2解へのΔA·gは絶対最大2.27e−14（基準速度で無次元化） |
| 小系の全係数変更 | 高精度係数をfloat64へ投影して別行列を解いた荷重差は尺度付き最大2.36e−16 |
| 標本和集合の一次出力欠陥 | 22随伴に対し絶対最大1.06e−16。大規模系では部分和であり、全出力誤差の推定・上界ではない |
| 資源 | 26.0秒、ピーク128,290,816 bytes、追加35,033,486 bytes |

係数の差はDecimalで減算してから記録した。高精度係数をfloat64へ投影した後の差だけで80桁精度を検証したものではない。251ペアの自己監査は両精度の数値文字列も保持する。

## 解釈と次の対象

今回調べた係数に、前回の格子差に匹敵する生成誤差は見つからなかった。全係数を変更できた小系でも荷重への影響は小さい。ただし大規模系の全係数作用・全出力誤差を評価したわけではなく、組立全体の精度を保証した結論にはしない。参照の格子収束受入とUVLASとの比較は引き続き保留する。

次の比較では [馬蹄渦／渦輪の比較場契約](../steady-horseshoe-ring-comparison-contract.md) に従い、未知量の基底を区別する。個々の馬蹄渦係数の配列比較を避け、弦方向の累積場・後縁トレースを同じ物理領域で積分する。モーメントは有限辺の分布寄与と元力点への補正偶力を別々に調べる。契約案の代数関係と共通細分の製造試験はまだ実行していない。

## 保存した未完了試行と監査修正

初回は8系の係数出力後、求積比較のNumPy真偽値をJSONへ保存する処理で停止した。[初回状態](avl-aic-generation-initial-status.json) にソース・途中19ファイル・進捗8系のハッシュを保持した。真偽値を標準boolへ明示変換し、各系の詳細を都度保存する形へ修正後、同じ数値処理を再実行した。数式・しきい値・入力は変更していない。

証拠監査の最初の実行では、圧縮NumPy配列を係数ごとに再展開して時間を浪費したため停止した。各配列を一度だけ読み込む形に直し、全296,832行について、ID・保存float64・80桁値・Decimal差と診断配列の一致を監査した。元の係数計算は再実行していない。
