# 曲面還元の辺における追加診断

2026-11-02。一定場・仕事の審査後に定義した追加診断。元の結果と基準は変更しない。二案の欠損を、境界を変えない補正で修復できるか切り分ける。

## 境界の一定場

元の5形状×2厚さについて、s=±1／t=±1の4辺で、接線方向9点・厚さζ=-1,0,1を評価する。6つの一定物理ひずみの最大テンソル相対差を記録する。体積内部だけの値再現と区別する。基準は1e−10。

## 二要素の共有トレース

X方向に二要素、Y方向に一要素を置き、物理パラメータx∈[-0.5,0.5]、y∈[-0.5,0.5]の5×3節点で同じr/d/cを共有する。各形状は既存の解析式をこのx,yへ適用する。新しい格子で荷重平衡は解かない。

共有辺のs=+1（左）／s=-1（右）、t=-0.8,-0.1,0.6、ζ=-0.6,0,0.7で、還元後の物理テンソルを実際の共有接線gₜと厚さ接線gζへ戻し、gₜᵀĒgζの全135節点仮想変位に対する作用素を比較する。tの向きは共通で、物理支持を緩めない。相対Frobenius差1e−10以内をトレース成立基準とする。

入力幾何・接線自体の一致1e−12以内も要求し、原始の非還元ひずみの同じトレースも1e−10以内で一致することを正の対照とする。還元だけがトレースを変えるか確認する。

## 判断に使う条件

一定ひずみの欠損が辺に残れば、辺で0となる内部bubble補正だけでその値を直せない。一方、中心基底案で共有トレースが不成立なら、平均仕事だけを内部bubbleで補正しても辺の不一致は残る。有限の辺検査を一般曲面の全域証明とは呼ばない。
