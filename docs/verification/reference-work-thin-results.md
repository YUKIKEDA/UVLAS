## 結論の範囲

対象は、保存されたx/y隅点を二進有理数として構成した**解析的な平面／放物柱面**と、有界な正則整数べき展開q(h)=q0+hq1+h²q2+…に対する先頭問題である。丸め済みr/d/c節点補間面と解析曲面の差を測定しているが、h→0の特異問題ではその差を無条件に無視できない。

したがって、今回の値は、保存float補間面の厳密な薄肉極限、有限h最小誤差の14.68%下界、76.04倍の唯一原因の証明ではない。有界正則展開の成立や最小化と極限の交換も一般には未証明。有限hの小さい誤差と今回の先頭誤差を同じ厚さの結果として比較しない。

q1の上下面制約と、鉛直面の先頭安定化を区別した。q2は内部を最小化して消去し、共有トレースと支持を残した。

## 欠ける位置場と次の一組

双一次写像x=a+bξ+cη+dξηで、四次曲げの接線位置u0x=−κx⁵/15にはξ⁵η⁵の係数−κd⁵/15が現れる。κd≠0なら現在の35場には入らない。平坦κ=0や正則d=0で四次場を再現できても、この欠落を検出できない。これは解析曲面上の表現不足の具体的な証拠である。

[次の設計仮説](../reference-work-missing-moment-proposal.md)は、Ψ=P5ξP5ηの内部位置1スカラーモーメントと、発散がΨ・全6面法線が零の二つの対称fluxを組にして加えるもの。[代数検査](reference-work-missing-moment-result.json)ではmidplane36場の観測rankが35→36、非定数勾配の観測rankが34→35となった。内部位置3座標の追加で、共有トレースはこの代数変更だけでは増えない。

これは新要素の採用ではない。局所N−6、全微分、有限h、非線形、材料／積層に加え、内部高次位置と共有トレース、支持、位置・法線の一意な回復、外力／UVLM仕事の契約を閉じる必要がある。「共有DOFが増えない」を、実務で使う幾何が一意である証明にしない。
