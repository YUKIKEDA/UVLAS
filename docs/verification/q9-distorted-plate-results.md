# Q9の歪み格子・非一様薄肉曲げ：実施結果

2026-10-31。**薄肉一様性の事前基準が未達で、全体判定は不合格。補正なし完全積分Q9の最終採用は保留する。** 最細の精度や最後の観測次数が成立しても、別の必須条件の不合格を打ち消さない。

[事前仕様](q9-distorted-plate-experiment.md) の8ケースを実施した。[主結果](q9-distorted-plate-result.json) と [観測・成果物監査](q9-distorted-plate-artifact-audit.json) を保存。従来の矩形格子の結果は上書きしていない。

## 数値処理の確認

面内7／9点の共通尺度の剛性差は最大2.397528e-09、荷重差は最大9.845163e-14、観測量とr/d/c別応答の求積感度は最大3.863173e-08で、事前条件内。70／90桁の観測用物理変位は今回全ケースで同じ倍精度値になった。これは無限精度への誤差0を意味しない。

保持解の残差・2種の後退誤差、対称性、正対角、全域幾何、X²補間、矩形への回帰、反転幾何の拒否、誤ったヤコビアンの負の対照が成立した。

監査は保存場から別のQ9評価・11点積分・物理点逆写像・4変数参照を再計算し、最大L2差2.303960e-11で判定が一致した。監査成立と主試験不合格を両方保存する。疎行列と保持解自体は保存していないため、保持残差は記録とソースの監査で、残差全量の独立再計算ではない。

実行は53.03秒・ピーク443,011,072 bytes、監査は20.83秒・ピーク62,296,064 bytes。NPZ合計は849,634 bytes。いずれも事前の資源条件内。

## 設計判断と次の作業

数値処理の必須条件が成立した範囲で、歪みと薄肉に関する採用上の不足を追加した。係数生成・表現の全誤差を上界評価したわけではない。単一の比だけからせん断ロッキングが唯一の原因と断定しない。

[双一次写像の無せん断適合性](../q9-distorted-shear-compatibility.md) で、Q9のたわみに必要な無せん断方向場が同じQ9へ含まれない解析的反例を整理した。この別の反例は、今回の平衡誤差の全量を説明したものではない。次は同じ物理問題のひずみ・エネルギー成分を分離し、対策する成分と補間／投影／内部変数の式を確定して候補比較へ進む。

一般曲面、積層、梁、偏心質量、接合、支持・減衰、出力回復の採用条件は残る。J1・製品本体の開始・初回実務適用の受入は解除しない。
