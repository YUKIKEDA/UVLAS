# 材料面の元荷重点と拘束後の別名照合

Case の材料面に、組立で割り当てた物理面 ID を翼弦・翼幅順で渡す。接触検査済みの幾何から元の四辺形、D2 の二子 facet と元頂点を取り出す。準備済みの材料写像から、各頂点の翼弦列、翼幅節点、寄与元の翼幅区間を求める。共通の正準頂点でも、荷重の転置には寄与元の材料サイトを使う。

物理面を重複して指定した場合や、指定した物理面を持たない場合は準備に失敗する。元の参照頂点の保持語は Case の幾何誤差で照合する。異なる格子頂点を一つの正準頂点へまとめることは認めない。二つの独立な面の登録済み別名を照合する入口では、両方の元頂点が同じ検査済み幾何の同じ正準点を参照することを確かめ、Case の構造支持所有者を用いる。

## 拘束後の形状行と指定運動

構造の固定拘束チャートに元の形状行を転置して、自由座標への係数と、拘束の元行への係数を得る。厳密な有理数と一つの平方根で表された各形状行を、この二成分に分けて既存の疎チャート転置へ渡す。自由座標の各係数、固定指定項、および各剛体支持運動の並進係数と回転係数を厳密に比較する。これらの係数が一致すれば、同じ支持姿勢を入れた指定項とその片側時間微分も一致する。独立群の係数が異なり、特定の履歴の組合せでだけ一致する対応は、この照合では拒否する。

## 回帰の範囲

二つの実四辺形を使い、非連番の物理面 ID から共通の正準頂点の両側を取り出した。材料座標・層・片側は従来の明示サイトと一致した。指示順の入替えと面の重複を拒否した。

同じ物理後縁を持つ別の Case Shell では、疎拘束チャートの自由行が独立だと照合に失敗した。両側の辺を固定した場合と同じ支持運動の生成項に束縛した場合は通過し、別々の運動へ束縛すると失敗した。演算上限を零にしても準備済みの構造支持は保持された。空力の実荷重から構造へ返す入口は、所有荷重と元 facet・局所頂点・物理面・正準点を照合し、従来の包絡付き転置を使う。

Case の表面格子から物理面 ID を採番する規則と、複数表面の面割付・別名を一括して認定する入口は別工程に残る。今回の入口で物理面 ID の由来を担うのは既存の幾何組立である。

ソースを固定して MSVC 19.51 Release と GCC 14.2 Release で `coupling.case_pg_support_motion` と `coupling.case_uniform_flow` を実行し、両環境で2件が通過した。材料面と別支持の絞り込みでは両環境とも計443アサーションが通過した。固定したソースと試験の指紋を [検証マニフェスト](im03-case-material-original-binding.json) に記録した。
