# 凍結有限翼の5迎角と固定20帯の荷重

FW-V01（上反角0度）と FW-V02（5度）について、迎角 $0,\pm1,\pm2$ 度で定常循環、非貫通の原残差、風軸の揚力・抗力、基準点まわりの全モーメントを比較した。翼弦2列・翼幅4列、下流長32 m、有限コア半径0.001 m、流速20 m/s、密度1.2 kg/m³ は [既存の有限コア比較](../finite-wing-steady-v1/verification.md) と同じである。Case の区画から翼面・後流・照会点を組み立て。各迎角では、既知流れの速度として $U(\cos\alpha,0,\sin\alpha)$ を与える。

## 定常循環と風軸荷重

同じ形状で定常行列を製品作用の8つの基底応答から組み立て、同じ形状の5迎角で共有する。両翼面の翼弦接線は +x に平行なので、法線の x 成分は厳密に零となる。迎角を変えたときの右辺は、既知流れの z 成分の比を +1度の製品右辺へ掛ける。製品密行列ソルバーで循環を求め、対応する後縁循環を保持下流トレースへ入れる。既存の製品荷重入口で循環を再度求め、各迎角の保持解、原残差、合力とモーメントを独立参照の有限コア閉渦輪と比較する。迎角0度では全力と全モーメントの無次元絶対値が $10^{-9}$ 以下であることも検査する。

残差の絶対比較幅は $2\times10^{-10}$ m/s。各力・モーメントの成分比較幅は $10^{-11}$ に $\rho U^2S$ または $\rho U^2Sc_{ref}$ を掛けた値である。基準点は $(0.375,0,0)$ m。力を風軸へ射影してから、±1度と±2度の中央差分を rad 単位で求める。幾何 +y まわりのモーメント符号を使う。

| 上反角 | $\delta$ | $C_{L\alpha}$（rad⁻¹） | $C_{M_y\alpha}$（rad⁻¹） |
| ---: | ---: | ---: | ---: |
| 0度 | 1度 | 4.4973024186 | -4.8387059386 |
| 0度 | 2度 | 4.4960327432 | -4.8357583296 |
| 5度 | 1度 | 4.4882505692 | -4.8279908555 |
| 5度 | 2度 | 4.4869850533 | -4.8250497740 |

## 固定20帯への保存集計

採用された中点荷重の観測として、製品の18個の束縛辺力を $y=-4,-3.6,\ldots,4$ m の固定20帯へ入れる。点が境界上にあるときは +y 側、最終端は最終帯へ入れる。各辺のモーメントを力と同じ帯に入れ、各帯の力・モーメントの和を製品の全量と絶対 $10^{-10}$ N または N m で照合する。各迎角の20帯に含まれる力・モーメント、各帯の風軸揚力、両 $\delta$ の揚力傾斜を独立参照と成分ごとに比較する。

同一離散格子と同一コアの比較で、揚力傾斜と規定尺度の幾何 +y モーメント傾斜に各1%、固定帯の幅で重み付けした傾斜分布に2%の上限を適用する。成分ごとのより狭い比較に加え、保持包絡の半径を足した最悪差でこれらの条件を検査する。

[新しい参照プログラム](reference.py) は元の形状 fixture、旧定常参照と生成プログラム、R&D 原本と荷重観測仕様の SHA-256 を検査し、75桁 Decimal で5迎角と20帯を再計算する。+1度の旧参照の循環・全荷重と一致させ、[派生 fixture](../../../../tests/aero/fixtures/finite-wing-polars-v1.json) に収録した。元の記録は保持した。

1%・2%の照合対象は、この固定格子と有限コアの離散参照である。格子と下流長・コアの収束、理想核の独立参照と不確かさ、一次荷重を線分に再構成した別観測、非定常の Heave・Pitch は V-AERO に残る。[A5-02](../../../requirements/practical-acceptance-plan.md#a5-02-部品部分系の必須入力と参照)。

## 実行結果

MSVC 19.51 Release は `coupling.finite_wing_steady.fw_v01` と `.fw_v02` の2件が通過した。各5,032アサーション、順に63.37秒と73.71秒だった。
GCC 14.2 Release も同じ2件が通過した。各5,032アサーション、順に55.13秒と59.10秒だった。GCC のコンパイルデータで両構成の試験ソースを clang-tidy でも確認した。
CTest は形状ごとに一つとし、中央差分に必要な5迎角を同じ実行に含めた。各試験の制限は Release 150秒、Debug 720秒。MSVC Debug では2件のビルドと登録を確認した。

GCC 14.2 Release の作業複製で境界点を −y 側へ入れるよう変更すると、上反角0度・迎角−2度・帯4（0始まり）の y 方向力が独立参照との照合に失敗した。ソースを SHA-256 が一致する元の状態へ戻し、同じ seed 23 で5,032アサーションが通過した。
