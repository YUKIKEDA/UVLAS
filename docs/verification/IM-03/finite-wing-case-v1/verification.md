# 有限翼の8本の非貫通式を凍結参照と照合
<!-- verification: V-AERO AE-02 UW-D03 N4-06 -->

FW-V01（上反角0度）と FW-V02（5度）の各8行で、製品の原残差と束縛循環の第1列を独立参照と照合した。格子は翼弦2列・翼幅4列、直線後流は32 m、有限コア半径は0.001 m、流速は20 m/s、迎角は+1度。原残差の包絡全体が、流速に対する許容値 $10^{-11}$ から得た $2\times10^{-10}\,\mathrm{m/s}$ の範囲に入ることを確認した。第1列は単位循環方向で評価し、原残差と同じ絶対幅で比較した。

## 同じ格子とコアを独立に計算した

[元の有限翼特化記録](../../../../rd/aero/finite-wing/records/finite-wing-specialization-result.json)の SHA-256 を確認してから、[参照プログラム](reference.py)が両形状の有限コア解を生成する。標準ライブラリの75桁 Decimal 演算を使い、正則化した直線の核を解析積分する。閉じた渦輪から行列を作り、Gauss–Jordan 消去で各循環と束縛循環の第1列を求める。製品や元の研究実装を呼び出さない。[凍結 fixture](../../../../tests/aero/fixtures/finite-wing-case-v1.json)に Case の形状、全頂点と照会点、接線、比較値を保存した。

試験は型付き Case から既知流れと指定移流を実際に準備し、移流が厳密な $(20,0,0)\,\mathrm{m/s}$ であることを確認する。左右の翼面は Case に面境界の共有を登録する。Case の区分多項式と明示離散格子の対応は参照生成時に各格子線の座標で照合した。製品の接触・非貫通入口には明示格子を渡す。各スパン列の付着後流の下流強度は独立定常解から与え、束縛循環方向を適用する間も保持する。

## 製品の包絡と負対照

Windows Release の [実行記録](observed.json) は、Catch2 の `--success --rng-seed 23` が表示する有理数から算出した。比較の左辺が中心の絶対誤差、右辺から比較幅を引いた値が製品の半径である。両者の和の行最大を示す。照合の検査幅はどちらも $2\times10^{-10}$。

| 上反角 | 原残差の包絡上界（m/s） | 第1列との差の包絡上界 |
| --- | ---: | ---: |
| 0度 | $8.841644\times10^{-16}$ | $7.263515\times10^{-16}$ |
| 5度 | $8.203887\times10^{-16}$ | $7.974210\times10^{-16}$ |

負対照は0度の最初の下流循環を $0.7052762142909859\,\mathrm{m^2/s}$ から零へ置き換えた。原残差の8行すべてで中心比較に失敗した。fixture の元バイト列を復元すると251件が通過した。

fixture は次のコマンドで空の出力先へ再生成できる。保存版の SHA-256 は `0fa3597ffecbddba915652af463b5475a98e32a625d0cba2c3ab5b56093c6e01`。

```text
python -X utf8 docs/verification/IM-03/finite-wing-case-v1/reference.py --output out/finite-wing-case-regenerated.json
```

同じ統合に含む [自由後流の R-03 計測](../free-wake-cost-v1/verification.md)は、元の計測・検証コミットを記録している。その固定証拠の SHA-256 は当時のツリー `49fd9c0a1d921e172d0222dc4b8831ce2ff1f7c0` から検査した。

## V-AERO の終了判定に残る観測

Case から物理格子を構築する入口、後流を含む定常解の全列、両形状の $\pm1$ 度・$\pm2$ 度の合力と基準点まわりモーメント、保存的な20帯の荷重は引き続き必要である。格子・後流長・コア半径の収束と、理想核の独立参照の不確かさも残る。非定常の Heave・Pitch については、採用された $k=0.05,0.2,0.8$ の鉛直力とモーメント12観測が別に必要である。誘導抗力と過去の未達も受入計画どおり確認する。[V-AERO 受入計画](../../../requirements/practical-acceptance-plan.md#a5-02-部品部分系の必須入力と参照)。
