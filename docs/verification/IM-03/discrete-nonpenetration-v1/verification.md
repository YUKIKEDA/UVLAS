# IM-03 離散コロケーションの原非貫通残差

対象ソースは `e33c3d49eaf3375e69cb0df180110bb718ce968c`。接触検査済みの四辺形と、明示した離散コロケーションから原残差を評価する。[採用仕様](../../../specs/aero/uvlm-wake-adopted-specification.md)

## 評価した行

原残差は \(n\cdot\{u_b(\Gamma)+u_w(T\Gamma,\mu_{\mathrm{old}})+U-V_c\}\)。同じ行で、旧後流を固定した循環作用 \(A_{\mathrm{eff}}\,\delta\Gamma\) を評価する。

- 後流の先頭は、四辺形の有向辺が大域後縁の実体と一致する場合に、その行の \(T\) と循環列を使う。各後縁には一つの先頭を要求する。残りの列は親状態ID付きの入力履歴から読む。
- 物質接線として渡された2方向の外積から法線を正規化し、固定分割の両子面に対する向きを確認する。面速度と接線の有限性を確認する。既知流れの発行元・世代・選択側と、幾何が保持するbinary64時刻の厳密な時間を照合する。
- 既知流れ・誘導の包絡を投影と加減算に伝播させる。各行の準備予測を合算してから誘導核を評価し、完了した行と試行来歴を返す。

## 独立試験

平面束縛輪、正則化された隣接後流、型付き \(\mathrm{ft/min}\) 一様流を使う。96点のテンソルGauss–Legendre求積で後流面積積分を直接評価し、端点から計算した独立な束縛線積分を加える。[参照計算](reference.py)

- 48点から72点への原残差差は \(4.87\times10^{-23}\)、72点から96点への差は \(4.75\times10^{-34}\)。差は収束確認に使った。固定比較許容は \(10^{-24}\,\mathrm{m/s}\) と計算包絡の和。束縛循環の低語 \(2^{-60}\) を含む。
- 物理的に同じ流れを、後縁 \(T=+1\) と、向きと履歴符号を同時に反転した \(T=-1\) で再現した。旧後流には独立な非零値を使い、原残差と循環作用の両方を照合した。
- 時刻、既知流れの側、親状態、先頭指定、法線向き、NaN、予算の異常を拒否した。失敗時に既知流れの所有が呼び出し元に残り、成功した結果が幾何と試行の来歴を保持することを確認した。
- 分離コピーで正向きの陰的先頭を旧後流係数に差し替えた。対照は76項目合格。変異は原残差と循環作用の照合2項目が失敗し、Catch2の終了値は42。

## 実行と適用範囲

- MSVC 19.51のDebug・Release、GCC 14.2のReleaseで対象各4件を合格。対象は `coupling.case_uniform_flow`、`aero.p1_shared_action`、`aero.global_geometry`、`aero.uniform_flow`。新規検証は各構成で1ケース76項目合格。
- clang-format 21.1.2、Windows・Linuxのclang-tidy 21.1.1、要求追跡表と証拠ハッシュの整合検査を実施。

この結果は明示した離散コロケーションと数値式の包絡を持つ。採用PG-ANCF物理写像から法線・面速度・移動点を作る接続、確定履歴の生成と更新、循環の求解・適格性認定、幾何や時間に関する全微分が後続に残る。

## 束縛循環IDと独立履歴IDの追試

正符号の後縁係数では、束縛循環の型付きIDを明示して先頭後流と共有する。負符号では、独立な後流IDの使用済み値を避けて一時列を発行し、循環とその方向の符号を反転する。履歴表や後方列に束縛IDを渡す入力を拒否する。

正符号では同じ数値の束縛循環と既知履歴が共存し、負符号では既知履歴のID 0を一時列が避ける対照を追加した。両符号の非貫通残差と循環作用が同じ独立参照に一致した。対象ソースは `20d19133804a5bd5ab58ebfc9feee778abdd3bdd`。MSVC Debug・ReleaseとGCC 14.2 Releaseで対象各4件、独立試験1ケース80項目が合格した。Windows・Linuxの変更翻訳単位はclang-tidy 21.1.1を通過した。前段の混合誘導で束縛列を同じ数値の独立後流へ差し替えた変異は、対照82項目中25項目の失敗で検出した。

## 厳密イベント時刻の追試

幾何準備に渡した正準な厳密SI時刻を所有し、かつbinary64時刻の最近接・偶数丸めと整合することを確認する。明示時刻を指紋に含める。旧binary64入口には従来の指紋と照合を適用する。参照接続の互換性は試行時刻に依存しない。現在の照会は、厳密時刻を所有する幾何に結び付く。

0.1秒のPCHIPイベントを右側で評価し、同じbinary64に丸まる0.100000000000000001秒と左側の評価を別々に拒否した。座標・世代・binary64時刻が一致しても、厳密時刻が違えば指紋が変わる。入力limbの書き換えと寿命終了後にも、所有した厳密時刻は保持される。旧入口で成功する予算でも、約分・中点比較と指紋の追加作業を含めると不足する場合を確認した。

対象ソースは `45d3c8e1eb33880d890c76777a4b346a85339406`。MSVC Debug・ReleaseとGCC 14.2 Releaseで `coupling.case_uniform_flow`、`aero.p1_shared_action`、`aero.global_geometry`、`aero.geometry_snapshot`、`aero.geometry_snapshot_resources` を各5件合格。非貫通フィルタの2ケース109項目が各構成で合格。Windowsの変更翻訳単位でclang-tidy 21.1.1を確認した。
