# IM-03 指定剛体運動の厳密な時系列評価

製品・試験ソースは `365519a7a807f0a1482647dd59ef99faf42f564e`。

型付き `Motion` から並進と回転ベクトルを準備し、同じ厳密時刻と左右指定で値・速度・加速度を返す。時刻と並進は SI の有理数とし、回転は有理数と共通の π 指数で保持する。準備結果は元のケースの識別情報、宣言への出典、入力版、曲線とイベント時刻を所有する。再評価時に現行入力と照合し、準備した区間外の時刻、入力版の相違、資源上限の超過を拒否する。[開始契約](../../specs/aero/prescribed-rigid-motion-start-contract.md)

## 独立照合

- 多項式の入力は時刻を ms で記述した。$q=(t-1)/2$、$d=3+4q+5q^2$ から、$t=1.5$ s での値 $69/16$ m、速度 $13/4$ m/s、加速度 $5/2$ m/s² を直接求めた。度指定の定数回転 $(90,-45,0)$ を $(1/2,-1/4,0)\pi$ rad と照合し、同じ数値のラジアン指定では係数と π 指数の違いも確認した。
- 等間隔の PCHIP 標本 $(0,1,3)$ は、節点の導出傾き $4/3$ を共有する。Hermite 多項式を微分して得た左右の加速度 $1/3$ と $5/3$ を照合した。角度標本 $(0,90,270)$ の回転にも同じ時刻と側を用い、π の係数として $1/6$ と $5/6$ を照合した。側を省略すると二階値が一意に定まらず、照会は失敗した。
- Hold の始端では外側の零加速度と内側の $14/5$ を照合した。周期曲線を負時刻へ繰り返した境界では、回転ベクトルの値と一階値を接続したまま π の二階係数が $2$ と $-2$ に分かれることを確認した。
- 元の `SiCase` と変換時の計画を破棄した後も準備結果を再評価した。準備に許す厳密数の上限を16にすると受理し、15では `ResourceExceeded` を返した。

## 実行結果

Windows 11 x64 の MSVC 19.51.36260 Debug と Ubuntu 24.04.5 の GCC 14.2.0 Debug（ASan・UBSan）で `coupling.case_motion_time_series` が各1件、Catch2 が各3ケース・84アサーション合格した。各環境でソースのコミットと未変更状態を生成ヘッダで照合した。両環境で同じ製品ソースと試験を CMake の一時登録からビルドした。Linux側で clang-tidy 21.1.1 の検査を製品・試験の翻訳単位に適用した。

分離コピーで、二階微分の時間尺度を $\sigma^2$ から $\sigma$ に変えた。多項式の試験が1ケース中1件失敗し、26アサーション中1件が加速度の分母の不一致を検出した。変異を戻し、上記の固定ソースで全件合格を確認した。

フレームの認定と SO(3) 合成、複数の場を合わせたイベントと再開点の確定は、この検証の後段で扱う。
