# IM-03 循環の陰解を含む全ベクトル荷重の転置

対象ソースは `c4d401f64735d6649fd034b06e9956ce7e74aa56`。[後流・全ベクトル荷重の採用仕様 §4](../../../specs/aero/uvlm-wake-adopted-specification.md)

荷重の位置・力・節点力・合力・モーメントの重みから無次元の観測量の双対を求める。値の循環を一度解き、保持した非貫通の影響係数と荷重の各面の循環双対を包絡のまま転置へ渡す。\(A_{\mathrm{eff}}^{\mathsf T}\lambda=\partial L/\partial\Gamma\) の解を求め、保持語を元の転置式へ代入した残差を検査する。

同じ接触・時刻・点所有・後流移送を使い、保持した循環で照会行の核と法線を評価する。\(-(\partial R/\partial x)^{\mathsf T}\lambda\) を荷重の直接の点座標・一様流双対に足す。自由照会点、照会接線、面速度、荷重辺の中点速度、外部入力の \(\dot\Gamma\) の双対を返す。基準点、密度、半径、旧後流強度を固定する。

転置の行列、尺度、RHS、保持値の世代と双対の配置 ID を最初に照合する。RHS の投影と転置の原残差検査が終わり、荷重の出力と全ての双対が揃った時点で流れの所有を移す。後段で失敗した場合も、準備中に成功した割付けは累積資源計画に計上される。

## 検証

[独立参照](reference.py)は幾何、流れ、面速度、接線、荷重の中点速度・循環時間微分を摂動し、直接線積分と Gauss–Legendre の面積分で循環を両側から解き直す。65桁十進算術で荷重の観測量の中心差分を比較した。

| 接触配置 | 観測量の方向微分 | 72点・刻み \(10^{-15}\) と96点・刻み \(10^{-18}\) の差 |
| --- | ---: | ---: |
| 一面と付着後流 | −0.0552599357049885265356 | \(8.24\times10^{-34}\) |
| 逆向き別名で辺を共有する二面 | −0.0753320247028545422098 | \(1.01\times10^{-32}\) |

製品の接線求解から荷重の前進微分へ保持語を渡し、双対仕事を有理数で照合した。独立参照および前進との比較幅は算術包絡に \(5\times10^{-15}\) を加え、照合に使った。早期の世代衝突と中断、後段のRHS投影・原残差の拒否を試験し、試行の流れと既存結果を保持して再試行できることを確認した。

GCC 14.2 Release の分離コピーで循環から一様流への加算を落とすと、一面・二面ともに前進との照合と独立参照との照合が失敗した。4アサーション、Catch2終了値42。

MSVC 19.51 Debug・Release、GCC 14.2 Releaseで、`coupling.case_uniform_flow`、`aero.p1_shared_action`、`numerics.dense_solve` が各3件合格した。Release の荷重ケースは両環境で5274アサーション合格、乱数種23。clang-format 21.1.2と、Windows・Linuxのclang-tidy 21.1.1を変更した製品・試験コードに適用した。

固定接触の実数の離散未定常荷重が対象。時間積分で決まる循環時間微分、PG-ANCFの材料写像、接触切替えの双対はそれぞれ後続の I/F で扱う。
