# 有限翼で使う区間の積・商・平方根の費用

P1 の積と商では、各端点の組の厳密な積、または整数商と剰余を一度だけ求め、下向き・上向きの丸めに共用する。四隅の評価順、上下端の選び方、零を含む分母の拒否、区間演算の仕事量は従来と同じ。`64ea6a77` が比較対象である。

同じ種の疑似乱数で生成した256ビットの端点と指数、零、指数の境界を用い、従来版と比較版の端点・失敗・総仕事量を別プロセスで採取した。12,319行がバイト単位で一致した。出力の SHA-256 は `ff3bc86c49a35c229b6f39c40e4d27cfda82b49c405b8a4b60b635b2e81a826e`。負の商の下端を内向きに丸める変異は、この比較で検出した。

製品の試験では、符号の異なる区間、零、subnormal の尺度、256ビットの丸め境界を独立な有理数で計算した。丸めの余裕は各端点の1単位以内だった。四隅の極値の包含、零を含む分母の拒否、同じ区間を二乗した場合の下端も検査した。

GCC 14.2.0 Release では172アサーションが通った。Windows 11 の MSVC 19.52.37029 Release では、局所核、共有作用、Case 一様流、水平翼 M2/N4 の4件が合格した。変更していない JSON パーサーには MSVC 19.51 の既存オブジェクトを使った。

## 平方根の整数試行

P1 の区間平方根と局所幾何の有理数平方根は、従来と同じ順序で257回の整数試行を行う。採用済みの整数を $s$ とすると、試すビット $i$ を立てたときの二乗は $s^2 + (s \ll (i+1)) + (1 \ll 2i)$ となる。局所幾何では $A/B$ の整数商と剰余を先に求め、候補の二乗を整数商と比較する。整数商が候補の二乗に一致し、剰余が零のときに限り、上下端は一致する。

GCC 14.2.0 の別プロセス比較で、P1 の4,173出力行と局所幾何の1,073出力行がそれぞれ従来版と一致した。P1 の端点と仕事量を含む出力の SHA-256 は `58ef937f99ecc9d6bc2bae44be07484ea0bc0b793ed724a53f4bd88acae7b635`。局所幾何の高位部、低位部、半径、指数、失敗、仕事量を含む出力の SHA-256 は `99b0adf8fd57c6dd926b38b00df1e10b88693eb42acdb84d7061ea721e3094ed`。

回帰試験では、P1 の両端を独立な有理数に展開し、二乗で根を囲むこと、隣接端点との関係、厳密な平方でのゼロ幅、端点ごとの257試行を確認した。局所幾何では、厳密な1の半径が零で、$(2^{600}+1)/2^{600}$ の平方根に $2^{-256}$ の半径が付くことを確認した。隔離した局所幾何の実装から剰余の判定を除くと、後者の半径が零になり、独立試験が失敗した。

両方の変更を含む GCC 14.2.0 と MSVC 19.52.37029 の Release ビルドで、局所幾何とP1の資源試験を含め、共有作用、Caseの一様流、水平翼 M2/N4 までの7件がそれぞれ合格した。前節と同じく、Windows の無変更の JSON パーサーには既存オブジェクトを使った。

## 遠方の共通ジェット

正規化した面・照会・半径から決まるジェットを、同じ遠方評価の208点で共用する。形状と法線の微分、核半径の微分を保持し、両次数ともすべての観測を計算する。遠方の容量は共通部と1点分の命令から、仕事の上限は共通部1回と求積点ごとの命令から算出する。

従来と変更後の式を別々にビルドし、3種類の座標・半径で、両次数の点数に相当する208組の二進有理座標と重みを入力した。値と全13微分の区間端点は78,624行で一致した。SHA-256 は `1067b0685a5689698a1543afae254688fcf54b5fc9ebc319fb66611108dcbdfa`。この比較の仕事量は2,470,573から1,624,651ステップに減った。

求積座標 $u$ の読取りを共通部へ移す変異は、端点比較の1行目で検出した。

GCC Release ではP1と資源、共有作用、Case一様流、水平翼 M2/N4 の5件が通った。MSVC Release では局所幾何と資源の2件を含む7件が通った。

## 局所幾何の事前見積もり

局所準備の予算は、照会と三角形の読取り、述語、包絡を足して求める。中点の場合を覆うため、入口と三辺の確認、元facet索引の二分探索も計上する。呼出し側の幾何予算が小さい場合はその値を使う。

M128/N192で後端の閉鎖1行を含むと49,536三角形になる。このとき局所幾何は三角形ごとに最大3,164 step。照会1件の予約のうち、幾何だけに対応する項は、呼出し側が許す20,000,000 stepを積んだ990,720,000,000から156,731,904 stepに縮む。別にP1評価、組立て、循環・荷重などにも上限がある。

局所幾何の呼出し予算を5億 stepまで増やし、P1にはその演算列から求めた上限を指定した。近接と遠方の混合作用で同じ予約を返し、その予約の範囲で通常の準備に成功した。旧局所幾何見積もりへ同じ回帰試験をリンクすると、近接の照会で `ResourceExceeded` を返した。

局所幾何、P1、共有作用、Case一様流、水平翼M2/N4の対象7件は、GCCとMSVCのReleaseでそれぞれ通った。

### M128/N192 の製品幾何と照会予約

凍結参照が使う `grids` を75桁の十進演算で実行し、両翼の弦・幅分割、節点、照会点を再生成した。[幾何入力の生成器](finite-wing-drag-refinement-v1/formal_geometry.py)が書き出すLF版の SHA-256 は `d6a18a7b4334ea09fcb76aaec43d6ae61cbaee6eeb9b310f1f9d98538a5e511b`。先に採取したCRLF版 `510966fa571fb6448e6ba9de2df72c574a639fc8b46e043efa2953d9c8ee8576` は、改行を揃えて比較すると一致する。

GCC Releaseの隔離実行で、各翼の25,090節点と49,536三角形を準備した。座標を独立値と絶対差 $2\times10^{-14}$ mで照合し、固定対角線、接触と後縁所有を検査した。

先頭、中央、末尾の照会で、束縛循環と後端の強度に対応する共有作用を予報した。1照会の総予約上限は150,000,000,000 step、外部メタデータ枠は8 MiB。両翼で149,365アサーションずつが通った。

## 局所座標の完全一致による再利用の調査

[幅方向細分の独立参照](finite-wing-wide-admission.md)の座標をbinary64に射影し、同じ対角線で四辺形を分けた。各三角形の最初の点から二つの辺と照会点へのベクトルを厳密な二進有理数で比較し、束縛面と後流面も区別した。

水平翼・斜翼とも、M4/N12 は5,760組、M8/N24 は82,944組で、同一の組はなかった。この独立入力では、異なる照会と三角形の間で平行移動だけを使う再利用に利得を見込めない。
