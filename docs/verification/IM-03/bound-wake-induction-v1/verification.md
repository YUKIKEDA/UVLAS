# IM-03 束縛P0と後流P1の誘導作用

対象製品ソースは `f864312fb8d7c0ff76d2e2f4a0cbbdc072ae1542`。同じ大域接触済み形状・照会定義・半径を使う束縛渦輪と後流作用を検証した。[採用仕様](../../../specs/aero/uvlm-wake-adopted-specification.md)

## 確認した離散作用

- 束縛四辺形ごとに物理面IDで識別した独立循環列を持つ。人工対角線を解析式の計算前に消去し、共有渦辺では大域の辺IDと向きに従って循環を加減してから、一つの線分核を掛ける。後流側は既存の近方解析と遠方P1面積求積を使う。束縛側は距離にかかわらず解析線分を使う。
- 照会点が平面束縛パネルの内部または人工対角線上にある場合は、正則化半径と半径ゼロの両方を評価できる。物質点IDの裏付けのない渦辺接触は拒否する。
- 試験は、端点座標を直接用いたBiot–Savart線積分を100桁演算で計算する。方向微分はステップ \(10^{-25}\) の中心差分とし、製品の式グラフ、正規化、三角形分割、微分演算を共有しない。混合作用から同じ後流だけの値を引いた包絡と、独立参照を比較した。遠方の後流には既存の求積診断が付く。
- 対照は異なる循環列が同じ大域辺を逆向きにたどる場合を含む。一方の循環に \(2^{-60}\) の低語を残したまま速度を照合し、両列の随伴も照合した。分離コピーで共有辺の向きを無視すると、対照で通った6項目中3項目が失敗した。Catch2の終了値は対照0、変異42。
- 面の役割の取り違え、循環列の欠落、準備メモリが1バイト不足する場合、および既存経路に束縛列を渡す場合を拒否した。

## 実行結果

- MSVC 19.51のDebugとReleaseで対象5件を各5件合格。各構成で新規検証3ケース96項目を合格。対象は `aero.p1_shared_action`、`aero.p1_induction`、`aero.p1_induction_resources`、`aero.local_geometry_packet`、`aero.global_geometry`。
- GCC 14.2のReleaseで対象4件を合格。MSVCと同じうち `aero.p1_induction_resources` を除いた4件。新規検証は3ケース96項目合格。
- clang-format 21.1.2、変更翻訳単位のclang-tidy 21.1.1、追跡表検査を実行した。

既存P1の近方・遠方評価枝と数値演算の訪問数を維持した。準備するファセットの管理情報が増える。製品規模の時間・メモリは今回の受入対象外。

非貫通と循環の適格性には、PG-ANCFの同一物質写像に基づく法線・面速度、後縁の陰的先頭係数と親履歴、既知流れを同じ試行で評価する接続が必要となる。今回の作用は、大域接触と座標を検査済みの離散形状を入口とする。
