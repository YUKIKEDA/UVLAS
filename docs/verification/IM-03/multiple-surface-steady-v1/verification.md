# 凍結した主翼・尾翼の定常相互作用

[V-MULTI の凍結条件](../../../../rd/aero/multi-surface/records/uvlm-multiple-surface-reference-protocol.md) のうち、各翼が翼弦2列・翼幅12列の条件を使った。主翼は FW-V01、尾翼は中央前縁 $(5,0,0.6)$ m、半幅2.5 m、根元弦1 m、翼端弦0.4 m、後退角20度。流速20 m/s、密度1.2 kg/m³、閉後流長1024 m、モーメントの基準点は原点。製品には正のコア半径 $10^{-5}$ m を与えた。

## 二翼を同じ作用に載せる

翼と閉後流の72四辺形を一つの所有幾何に準備し、二翼の接触と24本の後縁の所有を検査する。各後流の定常係数は、認定された同じ翼の束縛面の循環から左右両端に与える。主翼と尾翼から受ける誘導を同じ呼び出しで組み立て、受け点ごとに製品混合作用の転置を +z の種で一度評価する。得た48×48の全係数を独立参照に照合し、各行で同じ作用の正方向を独立な行列積と比較した。

48列の製品行列から、零迎角の一様流方向 $(0,0,20)$ m/s/rad を用いて循環の傾斜を求める。保持語を同じ製品作用に戻し、物理右辺を足した原残差を照合した。行列と原残差の成分比較幅はそれぞれ $2\times10^{-10}$ 1/m と m/s。二翼に異なる符号と強さを与えた正方向と転置で、同じ内積の仕事を比較した。翼間作用を無効にしたときの荷重は独立計算の単独翼と照合した。準備済み作用を別コアまたは尾翼の異なる幾何へ適用すると拒否された。

## 各翼の荷重傾斜

零迎角では基準循環とその時刻微分が零なので、傾斜の荷重は束縛辺の循環差と既知流れから求まる。$M_y$ は幾何 +y まわり。表は独立参照で、同時作用から単独翼の値を引いた差も比較した。

| 翼 | 同時 $F_z$（N/rad） | 単独 $F_z$（N/rad） | 同時 $M_y$（N m/rad） | 単独 $M_y$（N m/rad） |
| --- | ---: | ---: | ---: | ---: |
| 主翼 | 8,893.651020 | 8,771.711259 | -13,746.737746 | -13,549.478322 |
| 尾翼 | 2,753.680037 | 3,919.242311 | -15,389.940863 | -21,899.338609 |

主翼の揚力傾斜は単独時より1.390%大きく、尾翼では29.739%小さい。独立した荷重試験では、Case から投影した零迎角の既知流れと、固定幾何で独立に求めた同じ48成分の循環傾斜を、製品の荷重 JVP に与えた。各物理辺の荷重の向きと作用点を保ったまま翼別に力とモーメントを合算し、製品の全量と照合した。両翼に別々の鉛直並進と幾何 +y 回転の仮想変位を与え、節点力で求めた仕事と翼別の合力・モーメントから求めた仕事を比較した。荷重、モーメント、仕事の絶対比較幅はそれぞれの SI 単位で $2\times10^{-8}$。

## 参照の来歴と適用範囲

[独立参照プログラム](reference.py) は75桁 Decimal の有限閉渦輪で行列と物理右辺を計算する。凍結 R&D の M2/N12 のAeroSandbox側各翼 $F_z,M_y$ との差は最大相対 $9.27\times10^{-7}$。この差には独立コード間の核の差が含まれる。試作データは改行を LF に統一すると、[今回のフィクスチャ](../../../../tests/aero/fixtures/multiple-surface-steady-v1.json) とバイト単位で一致する。元のR&D記録、別条件の系列、試作データは保持した。

この検証は2枚の固定平面と正のコアを使う M2/N12 の定常一次荷重の範囲である。M4/N24・M8/N48、振動する多面の調和作用、理想核の参照不確かさと全連成での受入は [V-MULTI](../../../requirements/practical-acceptance-plan.md#a5-02-部品部分系の必須入力と参照) に残る。

## 実行結果

MSVC 19.51 Release は `coupling.multiple_surface_steady` と `coupling.multiple_surface_loads` を通過した。順に60.07秒と284.40秒、12,242と2,122アサーション。先行の荷重単独計測では141.73秒だった。
GCC 14.2 Release も同じ2件を通過した。順に55.57秒と278.21秒で、両試験のアサーション数は同じ。両構成の対象 clang-tidy も通過した。
行列と仕事の試験はDebugにも登録し、720秒の制限を置く。MSVC Debug はビルドと登録を確認した。全荷重点に資格付き作用を適用する荷重試験はReleaseで直列に実行し、同時負荷で284.40秒を要した実測を踏まえて420秒とした。

GCC の別リンクで、正方向作用に入力する相手翼の全強度を零とした。独立行列との照合は主翼の受け行0で失敗し、元のバイナリは seed 23 で12,242アサーションを通過した。
