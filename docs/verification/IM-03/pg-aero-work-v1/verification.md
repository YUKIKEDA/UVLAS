# PGの構造追従点から空力荷重を構造列へ戻す

固定した材料点を準備済みPGで評価し、同じ形状行から空力の位置と速度を求める。非貫通点では、材料対応の偏微分を参照Jacobianと物理勾配に作用させて、現在配置の接線を得る。層の面と内部で、選択した分割・層の参照を使う。 [構造と空力の仕様](../../../specs/aero/uvlm-wake-adopted-specification.md)・[実装](../../../../src/coupling/pg_aero_attachment.cpp)

## 曲面の非貫通と節点荷重

厚さ2 mの平板PGに、独立に積分した曲率モード $s^2/2$ を加えた。上面で $X_z=1+s^2/2$、$V_z=s^2$ とし、非貫通点 $(s,t)=(3/4,3/8)$ の高さ $41/32$ m、速度 $9/16$ m/s、接線から求めた法線の比 $n_x/n_z=-3/4$ を照合した。非貫通点はそのまま照会に渡した。曲面点も厳密な平面点も、空力の区分一次補間に由来するという情報を付けずに処理した。

層内の例には $\zeta=(s-3/4)/4$ を使った。非貫通点は参照中央面にあり、変形後の高さは $9/32$ m。厚さ方向の偏微分 $1/4$ が $X_{,\xi}$ の鉛直成分を $3/4$ から $1$ に変える。型付きケースの風速 $2$ ft/min を $127/12500$ m/s として、原残差を $(127/12500-9/16)/\sqrt{2}$ と照合した。

既存の循環求解と全ベクトル荷重を実行した。登録した別名の位置は正準点と一致し、荷重は四つの正準頂点へ一度ずつ集約された。保持した荷重包絡を $N^T$ に渡し、構造列と空力の両側で速度との仕事が一致することを確かめた。 [試験](../../../../tests/coupling/case_uniform_flow_test.cpp)

## 取り違えと検証範囲

異なるPGパッチ、幾何世代、基準の頂点対応を拒否した。荷重は試行世代と保存された幾何の実内容を照合するため、同じ世代を指定して位置だけを変えた試行にも流用できなかった。作業上限が零のときは試行を作らない。

MSVC 19.51のDebugとRelease、GCC 14.2のReleaseで対象CTest各4件が通過した。重点試験は各構成で2,492件のアサーションに通過した。MSVC Debugの空力試験は最終実行で73.64秒だった。MSVC Releaseで運動のFrameと時系列を保存・復元する既存2件も通過した。

隔離したLinuxビルドで厚さ成分だけを鎖則から外すと、中央面の接線と非貫通残差の照合が失敗した。ソースを同じバイト列に戻し、重点試験が再び通過することを確認した。

入力には一つの準備済みPGパッチと明示した材座標、空力の接続、各軸の精度予算を使った。Caseから多項式を取り出して役割ごとの材料点を生成する処理、複数パッチの大域自由座標と別名の資格、J1の受理や履歴は対応する後続工程で確認する。 [検証票](../im03-pg-aero-work.json)
