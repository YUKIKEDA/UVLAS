# PG空力点の投影予算

PGの位置、速度、接線の作用は、親の残り予算と個別上限の小さい方を使う。
成功した作用が返す仕事数は、入力の高位語・低位語の検査数、出力成分数、縮約項数の和である。
親はこの数だけを消費する。
作用の失敗や取消では、保持済みの数値と最後に成功した仕事数が残る。

境界面と層内の両方で総上限を固定し、位置・速度・接線の個別上限をそれぞれ総上限まで増やした。
幾何の内容指紋、照会点の厳密座標、速度と接線が一致した。
個別の位置上限を1まで下げると、上限不足で失敗した。
構造側の直接試験では、準備済み行列の大きさから順方向・転置の消費を独立に求めた。
個別上限を増やした再評価でも消費数が一致し、失敗後の値と消費数も一致した。

MSVC Release の対象CTest 2件と、重点2,587件が通過した。
旧来の個別上限を全額計上する処理に戻すと、同じ総上限の回帰は `ResourceExceeded` で失敗した。
修正のバイト列を復元して再ビルドすると、重点2,587件が再び通過した。

対象はPGの三つの投影作用である。
幾何スナップショット準備と照会解決の上限計上は、各入口の作業報告から別に検証する。
