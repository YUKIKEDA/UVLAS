# IM-03 明示離散幾何からの循環の方向微分

対象ソースは `316202bca8c6d46fda7e50c3b917796b03b8e34c`。接触検査済みの同じ試行の束縛面・後流・照会点を使う。[後流と循環の採用仕様](../../../specs/aero/uvlm-wake-adopted-specification.md)

## 原残差の方向と循環の陰解

同じ試行で値の循環を解き、得た高語・低語と後縁符号付きの先頭トレースを誘導核の JVP に渡す。旧後流トレースは固定する。面ごとの接線2本を \(t_\xi,t_\eta\)、法線を \(n=(t_\xi\times t_\eta)/\|t_\xi\times t_\eta\|\) とする。法線の変化は外積と正規化の両方を微分する。原非貫通の固定循環方向は次式で組み立てる。

$$
\delta R\big|_{\Gamma\ \mathrm{fixed}}
 =\delta n\cdot(u+U-V_c)
 +n\cdot(\delta u+\delta U-\delta V_c).
$$

- 正準の点IDと面IDに沿って位置・接線・面速度の方向を照合する。自由照会点は独立の位置方向を要求する。物質照会点は保存した頂点・辺・三角形の写像を使う。一様流の速度方向は固定時刻で明示する。
- \(\delta R\) の区間をそのまま、既存の \(A_{\mathrm{eff}}\delta\Gamma=-\delta R\) の右辺へ渡す。独立に指定された投影誤差と原残差の予算で接線を判定する。値と接線の両方が認定されるまで、入力流れは呼び出し元に残る。
- 同じ手順メーターで値と接線の周辺計算を計上する。結果は値の循環、面ごとの固定循環方向、接線と原残差の包絡を所有する。正準点の方向と面の方向は同期呼び出し中に借りる。

## 独立参照と負対照

[参照計算](reference.py)は束縛線を直接積分し、変形後の正則化後流面を Gauss–Legendre テンソル求積で積分する。65 桁の十進算術で、固定循環の原残差と解き直した循環に中心差分を別々に適用した。48・72・96 点の求積と \(10^{-12},10^{-15},10^{-18}\) の刻みを組み合わせた。72 点から 96 点への比較で、自由照会と物質照会の \(\delta R,\delta\Gamma\) の変化は最大 \(1.8\times10^{-33}\)。この差は収束確認に用いた。

- 自由照会と後縁 \(T=\pm1\) の両方で \(\delta R=0.09458459395910891749\ldots\)、\(\delta\Gamma=0.12677370359047272530\ldots\) を照合した。三角形に載る物質照会では \(\delta R=0.08634352256936112445\ldots\)、\(\delta\Gamma=0.11572802376143543357\ldots\) を照合した。比較許容は原残差方向が \(10^{-16}\) と算術包絡の和、循環方向が \(10^{-15}\)。後者の原残差上限も検査した。
- 点の順序、照会の種類と方向の有無、非有限な流れ方向、接線の行列世代の異常を拒否した。接線の右辺投影を誤差ゼロに制限した試行は、値の循環を解いた後でも失敗し、元の流れを保持した。

- GCC 14.2 Release の分離コピーで法線方向を除く変異と誘導の方向を半分にする変異を試した。それぞれ自由照会の両後縁符号と物質照会で $\delta R$ と $\delta\Gamma$ の計6項目が失敗した。誘導の方向を完全に除く変異は誤差ゼロの右辺投影を誤って通過したため、失敗の判定を検出した。いずれも Catch2 の終了値は42。

## 実行環境

MSVC 19.51 の Debug・Release と GCC 14.2 の Release で、`coupling.case_uniform_flow`、`aero.p1_shared_action`、`aero.global_geometry`、`numerics.dense_solve` の各4件を合格した。離散非貫通と循環の絞り込みは3構成とも3ケース378項目合格した。乱数種は23。変更した翻訳単位は両 OS の clang-tidy 21.1.1 を通過した。

## 適用範囲

現在の実数離散試行の、接触と点所有の同じ分岐で微分する。半径と時刻を固定し、旧トレースの変化や履歴輸送を含めない。PG-ANCF 物質写像から変位・接線・速度の方向を作る接続と、接触や別名の切り替えは別の工程に残る。
