# 非一様な既知流れを循環と中点荷重に接続

同じ接触済み試行で循環を一度解き、束縛辺の厳密な中点で既知流れを評価する。循環式のコロケーションと荷重の中点は、それぞれの位置で同じ入力・時刻・片側を使う。各中点の既知流れの値と偏微分を結果に保持する。面速度と循環時間微分は呼び出し元が明示する。 [離散荷重の採用式](../../../specs/aero/uvlm-wake-adopted-specification.md)・[実装](../../../../src/coupling/discrete_nonpenetration.cpp)

## 循環接線と中点の連鎖を同じ荷重へ渡す

循環力に $\rho\kappa_e\{[U(x_e,t)+u_b+u_w-V_e]\times\ell_e\}$ を使う。既存の自己直線辺除外を保持する。接線では $U_x(\delta x_a+\delta x_b)/2+U_t\delta t$ を中点速度の変化に加え、保持された循環接線は誘導と辺強度に渡す。合力、基準点モーメント、節点分配へ同じ荷重の方向を使う。

転置では $U_x^T$ の作用を中点の両端に等分する。循環への荷重の双対を既存の陰解へ戻し、コロケーション経由の位置と時刻の双対を中点からの寄与へ加える。時刻方向は既知流れにのみ作用する。非定常荷重には独立の循環時間微分と各三角形の面積ベクトルを使う。

## 一枚の束縛面を独立した閉形式で検証

正方形の束縛面、コア半径 $1/8$ m、密度 $5/4$ kg/m³ を使う。照会点の突風位相は $135$ 度。四辺の中点では、流速の垂直成分が $1,2,1,2$ m/s になる。80桁の十進算術で有限核の各辺を閉形式積分し、循環、辺の力、非定常力、合力、合モーメントを計算した。試験は実際の中点の力と、合力 $F_z=15/32$ N を参照と照合した。

形状と自由照会点を同じ向きに並進し、既知流れの時刻と循環時間微分も独立に変化させた。誘導行列は並進で変わらないので、閉形式で循環の方向と荷重の方向を求められる。時刻だけ、循環時間微分だけを動かす二つの解析方向は、対応する転置の成分と比較した。合力・モーメント・辺の力への同じ種で、前進と転置の仕事も照合した。 [独立参照](reference.py)・[試験](../../../../tests/coupling/case_uniform_flow_test.cpp)

## 対象試験

MSVC 19.51 Debug・ReleaseとGCC 14.2 Releaseで、既存の循環と荷重、幾何、誘導、密求解の対象5件が各構成で合格した。新しい独立例は217アサーション。MSVC Debugで統合試験は52.78秒だった。中点にコロケーションの既知流速を使う変異では5アサーションが失敗し、元のソースで全件が合格した。 [検証票](../im03-discrete-known-flow-loads.json)

## 独立な循環レートへの転置

陰的に解いた循環 $\Gamma$ の寄与は、位置や既知流れの時刻の双対に伝わる。
公開する `circulation_dual()` は独立入力の循環レート $\dot{\Gamma}$ に対応する。
合力とモーメントの種から得るレート双対は $3(5/4)+(1/8)(25/32)-(1/4)(-5/16)=1005/256$ となる。
面IDとこの有理数を照合し、範囲外の添字を拒否した。
同じ種を使った前進と転置の仕事も一致した。
MSVC Releaseで重点221件と通常の `coupling.case_uniform_flow` が通過した。

## 適用範囲

接触と材料対応を固定した有限実数の離散入力が対象。PG面からの物理点の生成、指定SE(3)運動、時刻法から循環時間微分を作る処理、自由後流とJ1への接続は残る。
