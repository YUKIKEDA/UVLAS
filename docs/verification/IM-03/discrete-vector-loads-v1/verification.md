# IM-03 同じ離散試行の全ベクトル荷重

対象ソースは `b47c6b53046e8ef303417229c1b5204c3b8f153a`。[後流・全ベクトル荷重の採用仕様 §4](../../../specs/aero/uvlm-wake-adopted-specification.md)

## 循環・非循環と荷重の分配

接触を検査した同じ離散試行の既知流れと確定旧後流から束縛循環を解く。元の非貫通式を再検査し、得た循環の高語・低語と後縁の符号付き先頭を荷重点の誘導へ渡す。

- 正準束縛辺の向きに、各面の循環を符号付きで集約する。同じセル内の人工対角線は打ち消し、宣言後縁は力の行から除く。後縁の誘導と陰的な後流先頭は残る。
- 各力対象辺の中点は、正準辺の物質座標 \(1/2\) から求める。その正準辺を使う全ての束縛直線出現を誘導式から除く。逆向きの明示別名には、同じ厳密な局所辺所属を使う。他の束縛辺と全後流の有限核を残す。
- \(f_e^c=\rho\kappa_e^F\{(U+u_b+u_w-V_e)\times\ell_e\}\) を評価する。中点速度 \(V_e\)、密度 \(\rho>0\)、基準点は、SI の値を明示する。値の循環と同じ試行・数値世代の \(\dot\Gamma_p\) を受け、束縛渦セルの正向き三角形に \(f_\tau^u=\rho\dot\Gamma_p a_\tau\) を適用する。作用点は各三角形の重心。
- 辺力を端点にそれぞれ \(1/2\)、三角形力を頂点にそれぞれ \(1/3\) 配分する。正準点で合算し、力と任意基準点モーメントを包絡付きで返す。値の循環と全荷重の成功を確認してから、入力流れの所有を結果へ移す。

## 独立試験

[参照計算](reference.py)は、60 桁の十進算術の直接線積分と、平面後流の Gauss–Legendre 面積分で循環を解き、荷重点の誘導を再評価する。正負両方の後縁符号で一面と後流を照合し、非対称な隣接二面で共有正準辺の強度差と自己直線の2出現を照合した。隣接二面は同じ辺を参照する場合と逆方向の別名で参照する場合の両方を使った。

- 48 点から72点への最大変化は辺力 \(9.65\times10^{-25}\,\mathrm{N}\)、合力 \(4.77\times10^{-25}\,\mathrm{N}\)、モーメント \(1.99\times10^{-25}\,\mathrm{N\,m}\)。72点から96点への最大変化は順に \(9.00\times10^{-36}\)、\(4.45\times10^{-36}\)、\(1.86\times10^{-36}\)。差は収束確認に用いた。
- 参照と個別の辺力、重心・中点、合力・基準点モーメントを比較した。比較許容は各成分の算術包絡と SI \(4\times10^{-15}\) の和。三角形力は \(\dot\Gamma_p\) の低語 \(2^{-57}\) を含めて別に厳密計算と比較した。節点から合力と基準点モーメントを組み直し、各成分を \(10^{-24}\) 以内で照合した。
- 欠けた循環時間微分、旧い循環世代、非有限の時間微分、力対象へ混入した後縁、密度ゼロ、正則化半径ゼロを拒否した。早期取消時に新規割付がなく、失敗時に流れが呼び出し元に残ることを確認した。

- 分離した GCC 14.2 Release で自己辺の代わりに束縛輪郭全体を除くと38項目、後縁を力の行へ含めると1項目、辺力を端点ごとに (1/3) ずつ配分すると30項目が失敗した。いずれも Catch2 の終了値は42。

## 実行環境

- MSVC 19.51 の Debug・Release と GCC 14.2 の Release は、実装コミット `dbee15a4b8a8db3b91130a0ba34a82432223de68` で対象6件を各構成で合格した。対象は `coupling.case_uniform_flow`、`aero.p1_shared_action`、`aero.global_geometry`、`aero.local_geometry_packet`、`aero.p1_induction`、`numerics.dense_solve`。
- 試験の列挙型と件数の型を明示した対象ソースでは、MSVC Debug と GCC Release の組み合わせで `coupling.case_uniform_flow` を再実行して合格した。絞り込みは4ケース2039項目に合格し、荷重の1ケースは1101項目。乱数種は23。両OSで変更した翻訳単位の clang-tidy 21.1.1 を実行した。

## 適用範囲

接触検査済みの離散渦セル、正の半径、明示した中点速度と循環時間微分の値を対象とする。流れ場の PG-ANCF 物質写像、採用時間法からの \(\dot\Gamma_p\) の生成、構造への転置と荷重微分、連続後流の物理積分精度は後続に残る。
