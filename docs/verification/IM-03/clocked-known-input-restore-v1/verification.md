# 共通時計と既知入力を一括で保存・復元

`CaseClockedPrescribedInputs` から、区間の始端・終端、刻み、節点数、再始動種別を保存する。同じ所有結果に、世界座標の既知流れ、自由・指定の後流モード、指定後流の入力、選ばれた指定剛体運動を保持する。復元時は独立に準備した現行ケースを使い、時計と後流モードを照合した後に各入力を再認定する。 [製品入口](../../../../src/coupling/case_flow_clock.cpp)・[指定運動単体の検証](../prescribed-motion-resume-v1/verification.md)

## 到着側と出発側で同じ値と微分を再現

$[0,1]$ s と $[1,2]$ s をそれぞれ $1/2$ s 刻みに分けた。イベント $t=1$ s の到着側は初回区間の終端Left、出発側は次区間の始端Rightを使う。並進PCHIPの一階は $4/3$、二階は左 $1/3$、右 $5/3$。角速度係数は両側で $1/2$。既知一様流の速度と時刻微分は $4$ と $3$、指定移流の速度と時刻微分は $6$ と $2$ になる。元のケースと準備結果を破棄してから復元し、運動の原点・姿勢は二階まで、既知流れは値と時刻・空間偏微分、指定移流は値と時刻微分を各保持語、指数、誤差半径で連続評価と照合した。

同じ形で刻み、再始動種別、既知流れ係数、指定移流係数、運動標本を一項目ずつ変え、各入力の照合段階で拒否することを確認した。自由モードも保存・復元し、指定モードと相互に置き換える場合を拒否した。 [試験](../../../../tests/coupling/case_motion_time_series_test.cpp)

## 統合検証と残る再開境界

MSVC 19.51 Debug・ReleaseとGCC 14.2 Releaseで、指定運動、既知流れ、PCHIP、SI変換の対象8試験が各構成で合格した。時計付き復元の焦点回帰は626アサーションで、指定運動単体との合計は968件。隔離したLinuxで保存済み時計の照合を省く変異と、既知流れ・指定移流の照合を省く変異を別々に実行した。どちらも意図した照合段階に到達せず2件が失敗し、元のソースに戻すと626件が合格した。

この入口は、一つの選択運動を含む共通時計付き既知入力の再認定を完了する。複数の運動と励振を統合した時刻表、J1のファイルチャンクへの割付、確定した時計アドレスと履歴を同時に復元する処理は、それぞれの採用契約に従う後続作業である。 [保存ファイルの境界](../../../specs/foundation/checkpoint-manifest-contract.md)・[検証票](../im03-clocked-known-input-restore.json)
