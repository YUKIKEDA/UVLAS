# 一様流の厳密値を、誤差を検査した有限表現へ渡す

型付き SI ケースから得た一様流の速度と時間偏微分を、指定された Binary64 または TwoWord の中心、外向き半径、2 進指数で返す。結果は元の厳密値、入力世代、時刻、片側指定を保持する。空間ヤコビアンの全 9 成分は厳密にゼロである。

## 実際に返す二語から誤差を検査した

各成分の尺度と絶対・相対予算は呼出側が指定する。速度の尺度は m/s、時間偏微分の尺度は m/s²。返却する中心と真値の差を包む半径を作り、尺度付きの絶対項と真値に対する相対項の和以下か判定した。丸め包絡の上端と許容値の下端を比較する。許容値を超えると以前の厳密結果を保持したまま失敗する。 [精度契約](../../../specs/foundation/precision-contract.md)・[SI 精度の判定式](../../../specs/foundation/si-precision-conversion-contract.md#3-許容差はsi尺度で無次元化して明示する)

フィート毎分で入力した PCHIP の値と微分を、独立に求めた有理数で照合した。通常の Binary64 では届かず TwoWord で届く予算、一語で届く絶対予算、最後の成分だけが不合格になる予算を試した。1 に 2 の −900 乗を加えた値と、2 から最小の正の binary64 非正規化数を引いた値では、TwoWord が半径ゼロを返した。指数 ±1100 の保持と、誤差が正の予算とちょうど一致する場合も検査した。

## 独立試験が低位語の欠落を検出した

Windows の Debug・Release で関連 CTest は各 3 件通過した。接続試験は各 8 ケースの 701 アサーションで、うち投影は 2 ケースの 246 アサーション。認定後に低位語をゼロにした隔離ビルドでは、厳密値が返却半径に収まるかを確認する 5 アサーションが失敗した。 [試験条件とソース版](../im03-uniform-flow-projection.json)

この投影で検査したのは返却値と元の厳密値の差である。循環や荷重の誤差への伝播は各消費側で扱う。突風の評価には、位相の引数還元と三角関数の保証を採用仕様として定める必要がある。
