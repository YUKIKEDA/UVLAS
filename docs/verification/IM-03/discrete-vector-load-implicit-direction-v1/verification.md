# IM-03 循環の陰接線を含む全ベクトル荷重の前進微分

対象ソースは `2408fbcc9e8c4e13bd633414de1ff1431dec3088`。[後流・全ベクトル荷重の採用仕様 §4](../../../specs/aero/uvlm-wake-adopted-specification.md)

値の循環と同じ保持影響係数から \(A_{\mathrm{eff}}\delta\Gamma=-\delta R\) を解く。右辺は固定した循環で計算した非貫通行の変化量で、ネイティブ包絡のまま投影と原残差の検査に使う。接線の高語と低語を渡し、辺力と中点での誘導速度を微分する。点の変位と一様流の方向は循環と荷重で共用し、辺の中点速度と \(\dot\Gamma\) の方向を別途受ける。

接線は値と同じ行列・試行の配置を使い、RHSと保持結果には別の世代を要求する。尺度世代を共用する場合は、値の求解証明書が持つ尺度と単位を比較する。RHS投影、接線の原残差、荷重の微分の順に検査し、全て成功したときに流れの所有を移す。

## 検証

[独立参照](../discrete-vector-load-implicit-pullback-v1/reference.py)は、65桁十進算術で幾何、流れ、面速度、接線、荷重の中点速度・循環時間微分を摂動して、循環を正負両側で解く。付着後流を持つ一面と、逆向き別名で辺を共有する二面について、中心差分の方向微分 `−0.0552599357049885265356` と `−0.0753320247028545422098` を比較した。前進と転置の双対仕事は、双方の包絡に \(5\times10^{-15}\) を加えた範囲で一致した。独立参照とも同じ比較幅で照合した。

一面の接線で非ゼロの低語を確認し、同じ両語を明示入力の荷重微分へ渡した結果と、双方の包絡だけで比較した。GCC 14.2 Releaseの分離コピー（`7627441d41bb67cf63d5d671e8a7fad99175a901`）で、固定ソースと同一バイトの対照は5518アサーション合格。荷重へ渡す保持語の低語だけを落とすと両語の比較1件が失敗し、Catch2は42を返した。

行列、RHS、保持値の世代衝突、循環時間微分の方向列の欠落、中断を早期に拒否した。同じ尺度世代への別尺度、未達のRHS投影と原残差を拒否し、流れ・元の循環の所有と再試行を確認した。

MSVC 19.51 Debug・ReleaseとGCC 14.2 Releaseで `coupling.case_uniform_flow`、`aero.p1_shared_action`、`numerics.dense_solve` の各3件が合格した。Releaseの荷重ケースは両OSで5518アサーション、乱数種23。clang-format 21.1.2と両OSのclang-tidy 21.1.1を変更した翻訳単位に適用した。

適用範囲は時刻、接触と点所有を固定した実数の離散荷重。時間積分から得る循環時間微分、PG-ANCF材料写像、接触切替えは後続の経路で扱う。
