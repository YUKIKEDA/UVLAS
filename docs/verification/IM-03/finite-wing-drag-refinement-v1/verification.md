# 凍結有限翼の抗力と空間細分

水平翼 FW-V01 と上反角5度の FW-V02 について、[線分荷重と遠方抗力](../finite-wing-span-lines-v1/verification.md) の検証を次の空間格子へ拡張した。閉後流長を1024 m、近傍の有限コア半径を $1.114285714285714\times10^{-5}$ m に固定した。旧観測は閉後流長32 m、コア半径0.001 m なので、今回の条件で元の翼弦2列・翼幅4列も計算した。弦と各半幅の境界は [凍結系列](../../../../rd/aero/finite-wing/records/induced-drag-common-limit-protocol.md) と同じ余弦分割とした。

## 力と比較式

近傍は製品の元の有向辺中点荷重を風軸に射影した。固定格子では循環が $U_z/U$ に比例する。迎角 ±1度の結果を合計し、誘導の $z$ 投影を打ち消して $2(U_x/U)(U_z/U)^2$ で割った。遠方は後縁の帯循環とその節点差を用い、理想核の中点速度を $\rho/2$ で積分した。遠方の二次係数は両迎角の和を $2(U_z/U)^2$ で割って求めた。

製品経路に型付き Case の参照面と分割を通し、全頂点とコロケーションを照合する。先行検証では後流の末端強度を独立な定常解から与え、製品の離散循環・荷重入口で固定末端の問題を求解した。現在の試験は `SteadyWakeClosure` を指定し、後流の末端強度を符号付きの後縁循環と同時に求める。保持された製品循環の両語と後縁の向きから独立な固定末端強度を設定し、従来のP1経路で全行の原非貫通残差を再評価する。循環の全成分、両方の元残差、自己辺の除外、近傍と遠方の二次係数は同じ独立参照と比較する。残差の許容幅は速度尺度20 m/sに対して相対 $10^{-11}$。力の許容幅は従来どおり $2\times10^{-11}\rho U^2 S/2$ で、二次係数へ変換するときは同じ除数で換算する。

[独立実装](reference.py) は75桁 Decimal で閉渦輪の行列を直接組み、後縁の未知量を後流の前後で共有する定常系を解いた。近傍では各物理辺の強度を有向渦輪から組み直し、照会辺自身だけを外した誘導力の $x$ 成分を直接求めた。遠方は前回と同じ独立中点式を使用した。二次係数の独立値には ±1度の差商を使っていない。

## 空間細分で観測した差

近遠差は $|D_{\mathrm{near}}/D_{\mathrm{far}}-1|$。連続参照指標は [凍結判定](../../../../rd/aero/finite-wing/records/drag-common-limit-assessment-policy.md) に従い、$|D_{\mathrm{near}}/D_{\mathrm{ref}}-1|$ に参照の相対不確かさ指標を加えた。二つの指標がそれぞれ1%以内で、かつ元残差と資源上限を満たすことが共通極限の条件である。正式な有限候補はM128/N192。参照不確かさは実測系列から得た指標である。

## 実行結果

Windows 11、MSVC 14.51 Releaseの新旧6件が通過した。M2/N4は各563検査、水平13.58秒、上反角5度18.86秒。M4/N8は各1,647検査、水平103.69秒、上反角5度137.87秒。従来の定常2件は各13,447検査。

Linux、GCC 14.2.0 Releaseの新旧6件が通過した。M2/N4は水平7.69秒、上反角5度10.07秒。M4/N8は水平81.66秒、上反角5度94.40秒。数値検査数はWindowsと一致し、従来の定常・コアと今回の細分の代表3構成でclang-tidyが通過した。

WindowsのMSVC Debugでは、先行版 188ba705 の上反角5度・M4/N8が1,647検査を通過し、単独起動で1320.50秒を要した。最終版c7b7b178との差はテスト配列の事前確保、寸法型、用途属性である。この実測からM4/N8のDebug上限を1800秒に設定した。残り約479秒で、実測の36%に当たる。M2/N4と全Releaseは1200秒を維持する。

格子別に比較した係数の表示値は両OSで一致した。M4/N8の累積payloadはWindowsで590,792,708、590,872,360 bytes、Linuxで594,232,748、594,312,400 bytesだった。確保済みpayloadの累計と、OS側の全プロセスのピークは測定対象が異なる。

同じ数値条件の先行版 188ba705 から作った隔離複製で、元残差を再評価するときの製品保持尾端だけをゼロにすると、水平翼M2/N4の原残差が約 $2.50\times10^{-4}$ m/sとなり、$2\times10^{-10}$ m/sの許容幅を超えた。元の試験は同じ seed 23 で563検査が通過した。

## 正式格子の資源条件

M128/N192は未知数24,576。現行の循環入口は、LUへ投影する元の係数を全て区間で保持する。GCC 14でこの区間1個は320 bytesだった。原係数603,979,776個の配列だけで193,273,528,320 bytes（180 GiB）を要し、採用上限24 GiBを超える。射影後のbinary64行列も1枚4.5 GiBを使う。小格子の残差・係数一致とこの単一配列の計数から、正式格子の実行時間や総ピークは推定していない。
