# 凍結有限翼の閉後流長とコア半径の感度

FW-V01（上反角0度）と FW-V02（5度）を、凍結された翼弦2列・翼幅4列、迎角+1度で比較した。Case の翼区画、既知流れ、密度、基準点を [5迎角の比較](../finite-wing-polars-v1/verification.md) と揃えた。閉後流を流下方向へ伸ばした系列ではコア半径を $10^{-3}$ m に固定し、$L=32,256,512,1024$ m を比較した。長さは検証格子の閉端座標に与え、半径は型付き Case から読み取る。コア半径の系列では閉端を $L=512$ m に固定し、半径 $10^{-3},10^{-4},10^{-5}$ m を比較した。

各条件で後流を含む8×8の定常作用を製品の8つの基底応答から組み立てる。製品密行列ソルバーで求めた循環を後縁と対応する後流に設定し、別の製品荷重入口で循環と非貫通の原残差を再評価する。行列の全成分、循環、残差、風軸の揚力・抗力、合力と基準点まわりの全モーメント、固定20帯への保存集計を独立参照と照合した。成分比較幅は [5迎角の比較](../finite-wing-polars-v1/verification.md) と同じである。

## 同じ有限閉端での独立理想核

[参照プログラム](reference.py) は旧凍結資料の SHA-256 を照合し、75桁 Decimal で閉じた渦輪の解析式を評価する。実際の荷重作用点は束縛辺の中点とし、束縛辺と後流の直線延長の境を保つ。互いに逆向きの共有辺を強度の段階で足し合わせ、作用点を持つ直線自己辺を速度の和から除く。理想核では、残る源線分の外側にある厳密共線点の誘導を零とし、源線分内に重なる点はエラーにする。70桁と75桁で全3,402個の数値を照合し、最大絶対差は $9.83\times10^{-54}$ だった。

$L=512$ m の半径0の値は、独立参照だけで求めた。正のコアを持つ製品荷重の包絡と同じ有限閉端の理想値との差を、独立参照が予測する差と保持精度の範囲内で照合した。参照差が成分比較幅を超える観測では、保持包絡を含めた差の符号も確認した。最小コアと理想核の抗力差はこの成分比較幅を下回る。

## 観測した感度

下表は後段の値を分母とした絶対相対差で、各欄は2形状の大きい方。20帯は各帯幅で重みを付けた揚力の相対L2差とした。閉端差を求める間は半径を固定し、コア差を求める間は閉端を固定した。

| 変化 | 揚力 | 幾何 +y モーメント | 風軸抗力 | 20帯揚力 |
| --- | ---: | ---: | ---: | ---: |
| 後流長 32 → 256 m | 0.07056% | 0.07164% | 0.34122% | 0.07036% |
| 後流長 256 → 512 m | 0.000859% | 0.000861% | 0.004315% | 0.000859% |
| 後流長 512 → 1024 m | 0.000215% | 0.000216% | 0.001084% | 0.000215% |
| コア $10^{-3}$ → $10^{-4}$ m | 0.001219% | 0.001359% | 0.002309% | 0.001235% |
| コア $10^{-4}$ → $10^{-5}$ m | 0.00001219% | 0.00001359% | 0.00002309% | 0.00001235% |
| コア $10^{-5}$ m → 理想核 | $1.231\times10^{-7}$% | $1.372\times10^{-7}$% | $2.333\times10^{-7}$% | $1.247\times10^{-7}$% |

この格子で最も大きい観測差は、32 m から256 mへ伸ばしたときの風軸抗力である。近傍抗力の符号と荷重作用点は同じまま比較した。差は固定格子・有限閉端・+1度の感度であり、閉端の無限遠極限や理想核連続解の不確かさの上限には使えない。

凍結 R&D の独立系列は [幅収束の有限追加](../../../../rd/aero/finite-wing/records/finite-wing-span-extension-protocol.md) と [最終抗力比較](../../../../rd/aero/finite-wing/records/drag-common-limit-assessment-policy.md) にある。R&D の固定感度系列 M16/N192 は束縛未知量が3,072あり、今回の8より細かい。零迎角傾斜の空間・遠方後流・コア誤差予算、近傍と Trefftz の共通極限、非定常12観測は [V-AERO](../../../requirements/practical-acceptance-plan.md#a5-02-部品部分系の必須入力と参照) の受入に残る。

## 実行結果

MSVC 19.51 Release は既存の迎角系列と新しい感度系列の6件が通過した。合計24,750アサーション。新規の最長は上反角5度の後流長系列で81.44秒だった。
GCC 14.2 Release も同じ6件が通過した。合計24,750アサーション。新規の最長は同じ系列の61.57秒だった。6構成のコンパイルデータで対象ソースの clang-tidy も通過した。
MSVC Debug で条件数が最多の上反角5度・後流長系列を計時した。計時に使ったソースは `b7f4c31c` で、4,347アサーションが583.87秒で通過した。CTest の制限は各 Release 150秒、Debug 720秒。最終ソース `c06ac1e3` では全呼び出しで明示する試験条件に既定初期化を加えた。

GCC の隔離複製で、幾何に渡すコア半径だけを10倍にした。FW-V01、閉端512 m、入力半径 $10^{-4}$ m の定常行列の係数(0,0)で独立参照との差を検出し、同じ seed 23 の原本で2,998アサーションが通過した。独立理想核では自己辺の除外を外す負対照で源線分内の照会を拒否した。
