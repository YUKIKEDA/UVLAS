# ケースから局所軸の指定運動を評価する

型付き `Motion` から基準 Frame と SI 時系列を準備し、世界座標の原点、姿勢、基準物質点の位置を、同じ厳密時刻と片側で二階微分まで評価する。Frame の右手直交性は元の有理成分で検査する。角度が度なら π の係数を保持してから回転を合成する。評価点の列は、一つの姿勢とその微分を共有し、入力の順序を保つ。

## 回転した Frame で左右の加速度を照合する

基準姿勢を世界の $x$ 軸周りの90度回転にした。局所 $y$ 方向の並進標本は $0,1,3$ [m]、局所 $z$ 軸周りの回転標本は $0,90,270$ [deg]。いずれも時刻 $0,1,2$ [s]。Hermite の係数を独立に求め、1秒での並進速度 $4/3$ [m/s] と左右加速度 $1/3,5/3$ [m/s²] を照合した。回転の角速度は $2\pi/3$ [rad/s]、角加速度は左右 $\pi/6,5\pi/6$ [rad/s²]。

基準Frameの原点から局所 $x$ 軸に沿って1 m離れた点は、1秒時点の運動中の原点から世界の $z$ 軸に沿って1 m離れる。姿勢、原点、2つの物質点の位置・速度・加速度が、独立な円運動の式から得た値を包絡した。許容誤差は成分ごとに各単位で $2^{-81}$、保持表現は TwoWord。左右指定を省いた二階評価、別の基準原点、許容誤差を零にした非有理角速度は拒否した。

## 零角、半回転、変化する回転軸

零角で $E=I$、$\dot E=\dot A$、$\ddot E=\ddot A+\dot A^2$ を照合した。90度と180度では、局所軸の姿勢合成の順序と、同じ向きでの速度・加速度を独立に確かめた。軸が変化する場合は、Rodrigues の係数とは別に、100桁演算で歪対称行列の指数を144項まで展開した。軸と角速度が非平行な2例で、全9成分と二階までの包絡が独立値から $10^{-70}$ に収まった。

Frame に行転置を入れる変異は3比較が失敗した。時系列の二階微分で時間尺度の因子を一つ欠く変異も、独立検証で失敗した。詳細は[時系列の検証](case-motion-time-series.md)に記録した。

## 試験の構成

Windows MSVC 19.51 と Linux GCC 14.2 の Release で、`9252b58468035c6168e5d6cfd0f0d735ad82f8af` を検証した。対象 CTest は各6件。運動の行列と微分は361項目、時系列と世界座標への結線は203項目、Frameは96項目が両OSで通過した。運動の合成とその試験は clang-tidy を通過した。時系列とFrameは個別の GCC 14 ASan・UBSan でも検証した。

この入口が所有するのは、指定された時刻・片側の姿勢と物質点の結果。空力の取付モデルへの登録、時間積分のイベント合流、J1の確定履歴と再開の照合は後段の受入条件に属する。
