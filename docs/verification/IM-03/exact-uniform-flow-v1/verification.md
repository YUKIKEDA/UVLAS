# 一様流の速度・微分・再開を厳密値でそろえる

定数・多項式・PCHIP の一様流を同じ内部入口で準備し、慣性座標の XYZ 順に速度と時間偏微分を返す。空間ヤコビアンの 9 成分は厳密にゼロになる。準備結果と評価結果がそれぞれ必要な入力を保持し、保存後は別に準備した現在の入力と照合して再開する。対象は [AE-07 の既知入力](../../../specs/aero/uvlm-integrated-specification.md#5-既知入力ae-07) と [FD-06](../../../specs/foundation/case-schema-fields.md#fd-06-空力既知流れ) の一様成分である。

## 時刻尺度と実係数を検証した

多項式の例には、原点を 1/3 秒、尺度を 2 秒とする三次式を用いた。時刻 4/3 秒の速度は (17/8, −1, 9/8) m/s、時間偏微分は (13/8, 2, 7/8) m/s²。期待値は各項の展開と微分から求め、分子と分母を許容差ゼロで照合した。閉区間の両端を受け付け、範囲外を拒否した。

PCHIP では、第一成分が最初の区間で 3t²/2−t³/2 となる標本を用いた。節点の左右で一階微分が一致し、端値保持と負時刻の周期正規化も宣言に従った。保存した係数を一つ変更すると、元の標本が同じでも復元を拒否した。多項式では、入力世代が同じでもイベント列を変えると復元を拒否した。各試験の期待値は [試験ソース](../../../../tests/aero/uniform_flow_test.cpp) に固定している。

## 確保失敗と取消の後も以前の評価結果を保持した

Windows 11 x64、MSVC 19.51.36260.0 の Debug と Release で、関連する CTest は各 3 件通過した。一様流は各 5 ケース、731 アサーション。確保監査は各 1 ケース、268 アサーションで、多項式準備の 7 確保点と評価の 4 確保点に失敗・取消・再入を挿入した。

時刻尺度で割る処理だけを外して Debug で別にビルドすると、多項式試験は時間偏微分の 9 アサーションで失敗した。確保量、実行ステップ、作業整数幅、付随メモリの上限も検査した。追試には `ctest -R '^aero\.(uniform_flow|pchip_(curve|coefficients_resources))$'` を使う。製品・試験の版と照合用ハッシュは [検証記録](../im03-exact-uniform-flow.json) にある。

## ケース入力と物理ソルバーの接続が残る

一様流の入口は SI の厳密な有理数を受け取る。ケースの SI レシピをこの数値形式へ移す変換、突風を含む空間分布、構造の支持運動、循環計算が用いる有限精度への投影は、採用済みの後続作業で扱う。この検証は [IM-03](https://github.com/YUKIKEDA/UVLAS/issues/19) の一様流に対応する。
