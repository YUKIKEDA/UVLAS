# 指定剛体運動から空力の離散照会点と点速度を作る

型付きの `AeroAttachmentPrescribed` から運動入力を読み、フレームと時系列を所有する。指定剛体運動を厳密な時刻と片側で一度評価し、参照物質点の位置と速度を同じ姿勢から求める。接触検査済みの離散幾何と、同じ点の速度を持つ `DiscreteCollocation` を非貫通式に渡す。 [指定運動の式](../../../specs/aero/prescribed-rigid-motion-start-contract.md)・[取付の実装](../../../../src/coupling/case_aero_attachment.cpp)

## 参照材料式と点の所有者を保つ

参照四辺形の位置と固定材料照会を、元の点とfacetのIDで読む。既存の有理計算は参照位置に適用し、姿勢行列の丸め値から幾何の資格を作らない。移動点集合は、指定された束縛四辺形の正準頂点に一致させる。登録済みの別名は同じ正準点の位置・速度を使い、移動集合に属さない点の現位置は保持する。

投影の許容差は呼び出し側が明示する。投影した座標は既存の幾何スナップショットで所有し、既存の大域トポロジーとの来歴照合と接触検査を通す。丸め済みの幾何から得た照会位置も、同じ参照物質点の運動結果と照合する。幾何の原時刻と既知流れの片側は、下流の非貫通式で照合する。

## 60度の回転で位置と原残差を照合

参照照会点は $(3/4,1/2,0)$ m。$x$ 軸に速度 $1$ m/s で並進し、同じ軸を毎秒600度で回る。$t=1/10$ s の照会位置は $(17/20,1/4,\sqrt{3}/4)$ m、速度は $(1,-\omega\sqrt{3}/4,\omega/4)$ m/s。$\omega=10\pi/3$ rad/s。誘導と外気を零にした原残差は、面法線への速度投影から $-5\pi/3$ m/s と求まる。試験は位置、速度、既存非貫通入口の残差をこれらの値に照合する。

同じBinary64に丸まる異なる厳密時刻、逆側の既知流れ、登録別名を正準入力として再指定した場合、移動集合に属さない点の混入を拒否した。同じ世代で係数を変更した入力も拒否し、成功済み試行を読み取れることを確認した。 [試験](../../../../tests/coupling/case_uniform_flow_test.cpp)

## 二語の丸め済み頂点から直接接線を求める

面の向きには同じスナップショットから取った三頂点を使う。頂点差は非貫通式の内部の区間算術で求め、差を二語へ再投影する手順を省いた。Binary64とTwoWordは同じ60度の運動で試した。別の二面の例では、同じ名目接線を座標差と明示語の両方で表し、値と接線解が一致することを確認した。接線方向を非零にして、転置の対応成分と仕事を照合した。

## 検証と適用域

MSVC 19.51 Debug・ReleaseとGCC 14.2 Releaseで、指定空力取付、指定運動、幾何と共有辺誘導の関連7試験がすべて通った。対象2ケースは計239アサーション。隔離したLinux環境で参照座標を過去の現座標に置き換えると、照会位置が4 mずれて1アサーションが失敗した。元のソースに戻すと、指定取付の67アサーションが通った。

対象は明示した固定材料式と、既存の接触検査を通る有限実数の離散面。空力参照面をPG構造の物質座標から生成する処理、未丸め形状の接触保証、荷重の構造への返却、J1での確定と再開は後続に残る。 [検証票](../im03-discrete-prescribed-aero-attachment.json)
