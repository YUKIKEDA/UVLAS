# IM-03 全ベクトル荷重の固定配置プルバック

対象ソースは `9d5da8c90dd257ff2b319691bf3ccfdbf2f3933a`。[後流・全ベクトル荷重の採用仕様 §4](../../../specs/aero/uvlm-wake-adopted-specification.md)

## 荷重の出力から明示入力への双対

現在の離散非貫通式を満たした値の循環を使う。無次元の実スカラー観測量に対して、辺・三角形の位置と力、集約した節点力、合力、基準点まわりのモーメントの重みを受ける。重みが参照する試行と循環世代を値と照合する。

- 節点力の双対を、値の配分と同じ \(1/2\) と \(1/3\) で荷重点へ戻す。モーメントの双対 \(s_M\) は、力に \(s_M\times(x-o)\)、作用点に \(f\times s_M\) を加える。辺・三角形それぞれの直接の重みと合力の重みも合成する。
- 辺力では循環の集約、相対速度と辺ベクトルの外積を転置する。辺強度の双対を正準辺の符号付き束縛循環へ戻す。中点の誘導は自己直線を除いた同じ共有核を使い、座標軸の厳密な単位双対を包絡のまま重み付けする。旧後流の強度を固定し、束縛と符号付き先頭後流の循環双対を面ごとに集約する。
- 三角形の重心は頂点へ均等に戻し、面積の双対を外積の両因子へ戻す。非循環荷重の \(\dot\Gamma\) 双対も同じ束縛面へ足す。幾何、相対速度、一様流、循環と循環時間微分の双対包絡を返す。
- 共用の資源計画と仕事量上限を使い、元の荷重と全ての双対の評価が完了してから流れの所有を移す。荷重の微分は明示入力に対して評価する。

## 独立試験

[参照計算](reference.py)は65桁十進算術の直接線積分と後流面積分で、荷重を重み付けしたスカラー観測量を作ってから中心差分を取る。Gauss–Legendre 72点・刻み \(10^{-15}\) と96点・刻み \(10^{-18}\) の差は一面・後流で \(4.24\times10^{-33}\)、隣接二面で \(2.12\times10^{-34}\)。収束確認に使った。

- 付着した先頭後流の両符号と、非対称二面が正準辺を直接共有する場合・逆向きの別名で共有する場合を確認した。低語を含む荷重の重みを使い、前進微分との仕事を正確有理数で計算した。前進と転置の仕事は双方の算術包絡の和で照合し、独立な観測量差分は包絡と \(10^{-16}\) の和で照合した。
- 別の循環世代、三角形と節点の重みの欠落、NaN のモーメント重みを拒否した。世代が一致しない場合に割付けを追加せず、失敗時に入力流れを保持した。

- GCC 14.2 Release の分離コピーで、節点の双対を除くと8項目、モーメントから力への双対を除くと8項目、先頭後流の符号付き散布を崩すと2項目、誘導から点への双対を除くと8項目が失敗した。全ての Catch2 終了値は42。

## 実行環境

MSVC 19.51 Debug・Release と GCC 14.2 Release で、`coupling.case_uniform_flow`、`aero.p1_shared_action`、`aero.global_geometry`、`numerics.dense_solve` が各4件合格した。離散非貫通と循環に絞った実行は3構成とも4ケース5083項目、荷重の1ケースは4145項目が合格。乱数種は23。両 OS の clang-tidy 21.1.1 を変更した翻訳単位に適用した。

## 適用範囲

接触・点所有・核の分岐を固定した実数の離散荷重。密度、半径、時刻、基準点、旧後流強度を固定する。荷重から明示した循環・循環時間微分へ戻す。時間離散や循環の陰解をさらに転置する接続、PG-ANCF の材料写像、接触の切替え、連続後流の物理精度認定は後続に残る。
