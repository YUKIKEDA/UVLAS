# 構造追従の材料座標、実 PG 行と面別荷重

型付き SI Case の構造追従面から、同じ Case の Shell が所有する PG を準備する。固定材料多項式を全パネルで認定し、採用位置の翼端・後縁・非貫通照会を実 PG 三角形と層面に結ぶ。平らな二層の独立例では、実 conditioned 基底から位置・速度・接線を Binary64 と TwoWord で得て、寄与元の形状行の転置で仮想仕事を再現した。

## 全パネルと層界面を厳密に調べる

片の接続では境界に制限した一変数多項式の係数を比較する。座標、層端との差、ヤコビアン行列式に厳密な Bernstein 包絡を使い、各閉パネルの範囲を調べる。内部層の端に接する位置は許されたパネル境界に限る。必要な箱は呼出しの明示上限まで二分し、人工分割線と交点でも層条件を確認する。

試験では $s=1/4+\xi/2,\ t=\eta,\ \zeta=\eta-1/2$ とし、$\eta=1/2$ の上側・下側の材料参照を同じ渦頂点から別々に取り出した。隣接片のずれ、誤った層端、PG 多角形から外れる角、パネル内部の零ヤコビアンを拒否した。正の二次ヤコビアンを持つ別例は、粗い一箱での判定保留から、細分による証明へ進んだ。

## 実基底の作用と独立薄面を照合する

薄面と支持先は同じ Case の原入力から別々に準備する。原点 $(3,-4,5)$ m、基準長さ2 m、全厚 $1/4$ m の平面 PG で、照会 $(3/4,3/4)$ の世界位置は $(17/4,-5/2,161/32)$ m。翼弦接線は $(1,0,0)$ m、翼幅接線は $(0,2,1/8)$ m となる。支持側では実三角形の座標と層から計算し、薄面との位置差、パネル幅を掛けた接線差、法線内積を Case の幾何誤差と比較した。位置を一致させたまま接線を変えた負対照も拒否した。

同じ物理位置の PG 候補には実基底の全形状列を確認する。必要な方向微分まで一致した行だけを残す。試験では $q_0$ を構造座標に入れ、並進速度 $(1,-2,3)$ m/s を同じ行で評価した。寄与元の頂点への $(0,0,2)$ N を転置すると、速度との積は6 W になった。元荷重の半径を含む仕事包絡も検査した。

## 構造へ返す前に面別の寄与を保持する

登録済み別名の共有辺では、各物理面の符号付き循環から辺力を作り、両端へ1/2ずつ与える。三角形は各元頂点に1/3を与える。正準頂点の合力とは別に、選択した呼出しで物理面・facet・局所頂点を保つ。既存の別名付き2面例で、共有辺の2面が逆符号の寄与を各2件持ち、その和が凍結した辺力に一致した。全寄与の和も既存の合力に一致した。

負対照は Linux の隔離複製で実行した。荷重半径を零にする変異は、両保持精度の仕事包絡2件を失敗させた。共有辺で負の循環寄与の符号を消す変異は、符号・辺力・全体の合計に関する6件を失敗させた。

ここで検証した構造転置は、寄与元の材料サイトを指定して、その準備済み元構造行へ返す入口である。Case の全 facet/局所頂点からこのサイトを組み立てる入口、異なる支持先どうしの拘束後の行・指定項の恒等性、全表面の再開所有が残る。[採用契約](../../specs/aero/structural-attachment-material-map-contract.md)。
