# IM-03 固定された離散配置における全ベクトル荷重の方向微分

対象ソースは `4331b612800dfb725dac228db2f7e612681092db`。[後流・全ベクトル荷重の採用仕様 §4](../../../specs/aero/uvlm-wake-adopted-specification.md)

## 荷重点から力とモーメントまで

現在の離散非貫通式を満たした循環を値に使う。呼び出し元は、その試行の \(\delta\Gamma\)、\(\delta\dot\Gamma\)、正準点の変位方向、各中点の速度方向と一様流の速度方向を与える。入力の試行の発行元と世代、循環の数値世代とすべての面・辺・点の識別子を照合する。旧後流の強度は固定し、付着先頭の係数方向を \(T\,\delta\Gamma\) で伝える。

- 正準辺の物質中点は端点と一緒に移動する。共有誘導の JVP では正準自己辺の束縛直線出現だけを値と同じ指示で除く。他の束縛辺と後流シートを保持する。辺力で \(\kappa\)、相対速度 \(U+u-V_e\)、有向辺 \(\ell_e\) の3因子をそれぞれ微分する。
- 三角形の重心方向は3頂点の平均。面積ベクトルは2辺の外積で、両辺の方向を微分する。非循環力は \(\rho\,(\delta\dot\Gamma\,a+\dot\Gamma\,\delta a)\) で求める。
- 辺力と三角形力の方向は、値と同じ \(1/2\)、\(1/3\) で正準節点へ配分する。モーメントは基準点 \(o\) を固定し、\(\delta x\times f+(x-o)\times\delta f\) を各作用点で積算する。
- 値と方向は同じ資源計画と仕事量上限で計算し、両方に成功してから流れの所有を結果へ移す。各方向の包絡と元の荷重は同じ順序で対応する。

## 独立試験

[参照計算](reference.py)では、元の循環を独立な直接積分で解き、明示した循環・循環時間微分と幾何を変えて荷重式を評価する。65桁十進算術で線積分・後流面積分を計算し、中心差分を採った。Gauss–Legendre 72点・刻み \(10^{-15}\) と96点・刻み \(10^{-18}\) の比較で、合力方向の最大変化 \(4.12\times10^{-33}\,\mathrm{N}\)、モーメント方向の最大変化 \(8.11\times10^{-33}\,\mathrm{N\,m}\)。この差は収束確認に使った。

- 付着先頭の正負両符号と、非対称な二面が正準辺を直接共有する場合・逆向きの別名で共有する場合で、中点・重心、辺力・三角形力、合力、任意基準点モーメントの方向を照合した。各成分は算術包絡と SI \(4\times10^{-15}\) の和で比較した。
- 三角形力の方向は \(\delta\dot\Gamma\) と \(\dot\Gamma\) の低語を含む有理数参照と照合した。節点の移動と節点力の方向から力・モーメントを再構成し、成分ごとに \(10^{-24}\) 以内で照合した。
- 別の循環世代、欠けた位置方向、並びの違う中点方向、NaN の循環方向を拒否した。世代が一致しない場合は追加割付がなく、失敗時に流れを呼び出し元に保持した。

- GCC 14.2 Release の分離コピーで、先頭の符号を省くと8項目、有向辺の方向を除くと54項目、三角形の面積ベクトルの方向を除くと46項目、モーメントの作用点移動項を除くと24項目が失敗した。すべて Catch2 の終了値は42。

## 実行環境

MSVC 19.51 Debug・Release と GCC 14.2 Release で、`coupling.case_uniform_flow`、`aero.p1_shared_action`、`aero.global_geometry`、`numerics.dense_solve` の各4件が合格した。離散非貫通と循環の絞り込みは3構成とも4ケース3211項目、荷重の1ケースは2273項目が合格。乱数種は23。変更した翻訳単位は両OSの clang-tidy 21.1.1 を通過した。

## 適用範囲

同一の実数離散モデルの接触・点所有・核分岐を固定した前進微分。密度、半径、時刻、基準点、旧後流強度を固定する。時間法から循環・循環時間微分の方向を生成する接続、接触の切替え、PG-ANCF 物質写像と構造への逆伝播は後続に残る。
