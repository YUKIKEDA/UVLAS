# IM-03 固定離散循環の接線・転置求解

対象ソースは `8dafe13aa84573b6e6ac9731e18d2039177062d3`。正則化した束縛渦と陰的先頭後流に対する、同じ離散循環作用を使う。[後流の採用仕様 §3](../../../specs/aero/uvlm-wake-adopted-specification.md)

## 問題と失敗の境界

- 原非貫通残差を満たした循環結果が、後縁の符号を含む \(A_{\mathrm{eff}}\) の投影前の包絡を所有する。接線は同じ行順で与えた固定循環の残差方向 \(\delta R\) に対して \(A_{\mathrm{eff}}\delta\Gamma=-\delta R\) を解く。
- 転置は実数の \(A_{\mathrm{eff}}^{T}\lambda=g\) を解く。無次元のスカラー観測量の共変量 \(g\) は \(\mathrm{s/m^2}\)、解 \(\lambda\) は \(\mathrm{s/m}\)。仕事の関係は \(g^T\delta\Gamma=-\lambda^T\delta R\)。転置の行列世代と二つの成分レイアウトIDを明示し、元の識別子の再利用を拒否する。
- 各入力の行を束縛面IDで照合する。投影の絶対誤差と各成分の物理尺度、LU と原残差の精度を呼び出し元が指定する。保持した解の高語・低語を投影前の係数と右辺に戻して原残差を判定し、解と面ごとの残差包絡を所有する結果を返す。
- 投影前行列の保持は \(O(n^2)\) で資源計画に計上する。接線と転置の密分解は標準の求解器の容量・反復補正上限に従い、周辺の包絡計算には明示の手順上限を適用する。固定幾何の接線と転置を解いても親の循環、流れ、後流履歴は変わらない。

## 独立試験

[参照計算](reference.py)は、束縛線と正則化後流面を直接積分した[先行参照](../discrete-circulation-v1/reference.py)から \(A_{\mathrm{eff}}\) を求め、60桁十進算術で行列式を使って解く。

- 一面の後縁付き系では正負両方の後縁符号で独立接線 \(0.1675401065384917440\ldots\) と比較した。非対称な二面系では接線と転置を別々に比較し、双対仕事を照合した。二面の独立解との比較許容は \(10^{-14}\)、双対仕事は \(10^{-16}\)。
- 二面系の右辺に \(2^{-57}\)、\(2^{-58}\)、\(2^{-59}\) の低語を与えた。投影誤差予算ゼロと原残差予算ゼロがそれぞれ拒否され、右辺が厳密なゼロのときは両予算ゼロでも成功した。返した結果は入力列の変更と元の所有者の移動後も使える。
- 面IDの順序と行数の不一致、NaN、不正な双対単位、試行と行列世代の不一致、重複した成分レイアウト、移動済みの所有者、キャンセル、資源不足を試した。

- GCC 14.2 Release の分離コピーで転置の添字交換を除いたところ、転置の独立参照の2成分と双対仕事の計3項目が失敗した。原残差の包絡をゼロに置き換えた変異では、原残差予算ゼロで成功したため1項目が失敗した。双方の Catch2 終了値は42。

## 実行環境

- GCC 14.2 Release は `coupling.case_uniform_flow`、`aero.p1_shared_action`、`aero.global_geometry`、`numerics.dense_solve` の4件を合格。
- MSVC 19.51 の Debug・Release は各4件が先行コードで合格した。レイアウト識別子の修正を含む対象ソースでは、影響がある `coupling.case_uniform_flow` を各構成で再実行して合格した。
- 最終ソースの離散非貫通と循環の絞り込みは、3構成とも3ケース293項目を合格した。乱数種は23。変更した翻訳単位は Windows と Linux の clang-tidy 21.1.1 を通過した。

## 適用範囲

固定した実数離散幾何の循環作用を対象とする。元の値を固定した残差方向は外から渡す。PG-ANCF物理写像、時間と幾何の微分、後流輸送による履歴変化、連続積分の物理精度の認定は別の工程に残る。
