# IM-03 明示離散コロケーションの循環求解

対象ソースは `f82eafdc67867a4449544f5f4c2919f57ffbf94a`。接触検査済みの束縛面、明示的なコロケーションと面速度、親状態にひも付く後流と既知流れを使う。[後流の採用仕様](../../../specs/aero/uvlm-wake-adopted-specification.md)

## 解と原残差の判定

- 行列は固定された離散幾何とクリアランスから組み立てる。3方向の核の随伴作用で全循環列を回収し、後縁の符号を含む陰的先頭を対応列に加える。右辺は循環をゼロにした行から求める。
- 行列と右辺の包絡を binary64 に投影し、呼び出し元が指定した絶対誤差予算で判定する。採用済みの実密部分ピボット付き LU を使い、物理スケールを明示して代数系を認定する。[密線形求解の契約](../../../specs/foundation/dense-solve-contract.md)
- LU の認定後に解の高語と低語を束縛面と陰的先頭後流へ戻す。前進作用で原式 $n\cdot\{u_b(\Gamma)+u_w(T\Gamma,\mu_{\mathrm{old}})+U-V_c\}$ を再評価する。投影前の右辺と指定された物理スケールから、最大ノルムまたは 2 ノルムで包絡を判定する。原残差も予算内に収まった場合に解と各行の包絡を返す。
- LU と原式の判定を別に設けたため、代数系の認定後にも原残差予算で失敗しうる。いずれの失敗でも既知流れの所有は呼び出し元に残る。

## 独立試験

[参照計算](reference.py)は 60 桁の十進算術で束縛線積分と後流面積積分を直接計算する。後流のテンソル Gauss–Legendre 求積は、48 点から 72 点で約 $1.02\times10^{-24}$、72 点から 96 点で約 $9.49\times10^{-36}$ だけ変化した。差は求積の収束確認に使った。

- 1 行の系では、正負両方の後縁符号で約 $-0.0101036605441377546843\,\mathrm{m^2/s}$ の循環を得た。初期の束縛循環には無関係な非零値を渡した。解の低語が保持され、再評価した原残差が指定予算内にあることを確認した。
- 相互誘導のある非対称 2 行の系は独立な行列式で解いた。明示した非単位スケール、2 ノルム、逆順の入力行を使い、結果の循環と行順を照合した。コロケーションを重ねた退化系はランク未解決で失敗した。
- 行列投影予算ゼロ、原残差予算ゼロ、試行来歴の不一致を拒否した。原残差予算の試験では、同じ代数認定条件を通過することを確認した。

- GCC 14.2 Release の分離コピーで、原残差の包絡に代えてゼロを認定へ渡した。変異は原残差予算ゼロでも成功し、試験が失敗を検出した。対照は179項目合格、変異の Catch2 終了値は42。

## 実行環境

MSVC 19.51 の Debug・Release と GCC 14.2 の Release で、`coupling.case_uniform_flow`、`aero.p1_shared_action`、`aero.global_geometry`、`numerics.dense_solve` が各4件合格。離散非貫通と循環に絞った実行は各構成で3ケース179項目合格した。乱数種は23。変更した翻訳単位は Windows・Linux の clang-tidy 21.1.1 を通過した。

## 適用範囲

対象は明示入力による有限実数の密な循環系。PG-ANCF 物理写像からのコロケーション生成、履歴の生成・更新、循環の幾何微分、連続後流に対する物理的な求積認定は後続工程に残る。
