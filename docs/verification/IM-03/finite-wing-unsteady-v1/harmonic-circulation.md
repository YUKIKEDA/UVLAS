# 有限直線後流の調和循環

製品の複素循環入口は、現在配置で認定した閉輪郭を実数の基底作用素 $A_0$ に使う。物理後縁ごとの更新 $W(\omega)$ を、同じ後縁を所有する束縛面の列へ符号付きで加える。複素右辺の各成分は束縛面ID順の法線速度を受け取る。解法の定式化は $A_0+W E^T$ とし、$E$ は後縁所有面を選ぶ。

実LUと複素Schurで求めた循環の高語・低語を、閉輪郭の実部・虚部それぞれの誘導評価へ戻す。有限後流補正を足して元の右辺を引き、各行の複素残差を包絡する。残差の判定には複素絶対値を使う。

回帰試験の定常係数は、正則化した線分核の原始関数で計算した。時計回りの $[0,2]\times[0,1]$ の輪郭を、点 $(3/4,1/2,0)$、コア半径 $1/8$ で評価する。非零周波数では同じ試験の独立な後流補正値を加え、法線速度 $0.25-0.125\mathrm{i}$ に対する複素解を比較する。後縁の両方向で周波数ゼロと $4\,\mathrm{rad/s}$ を検査し、解の絶対差を $10^{-12}\,\mathrm{m^2/s}$、元残差の各成分の包絡を $10^{-13}\,\mathrm{m/s}$ 以内とする。更新階数不足と射影の精度不足も検査する。 [製品試験](../../../../tests/coupling/case_uniform_flow_test.cpp)

GCC 14.2.0 Releaseの `coupling.case_uniform_flow` は29ケース、13,762アサーションに合格した。

## 調和荷重と水平翼

循環の実部と虚部を同じ作用に渡し、無迎角の一様な移流速度 $U$ に対する辺の力 $\rho\Gamma(U\times\ell)$ を求める。辺の寄与は正規辺と束縛面の向きで集約し、四辺形の内部対角と物理後縁を外す。二つの子三角形には循環の時間微分 $\mathrm{i}\omega\Gamma$ と有向面積を掛ける。辺中点と面重心の両方で、指定した基準点に対するモーメントを計算する。循環解の両語を使い、力とモーメントの各成分を包絡する。

単一の正方形では、物理後縁を外した一様流の寄与と面の時間微分を独立に積分した。前縁から $3/8\,\mathrm{m}$ を基準とする鉛直力とピッチングモーメントの解析値を、複素循環、元残差と合わせて照合する。後縁の両向きについて、周波数ゼロと $4\,\mathrm{rad/s}$ を試す。

水平翼M2/N4では後流長を128 mとし、物理後縁からの並進が全帯で厳密に128 mとなるよう下流端を二語で保持する。独立参照は同じCaseの位置を入力に、正則化線分の原始関数、後流年齢のGauss則、直接複素求解と独立の荷重和を使う。3周波数の年齢区間数は22、30、70。16点則から24点則へ変えた際、上下動・ピッチの鉛直力とピッチングモーメントの相対差は最大 $2.58\times10^{-16}$ だった。 [独立参照生成](small_reference.py) · [試験fixture](../../../../tests/aero/fixtures/finite-wing-harmonic-m2n4-v1.json)

小格子の製品試験では、各運動の法線速度を実際の照会位置から計算する。循環の相対差は $10^{-9}$、力とモーメントは各複素成分の包絡全体を独立値の絶対値に対して $5\times10^{-10}$ で比較する。原残差は全照会を再計算し、相対L2の $10^{-11}$ を照合する。 [水平翼の製品試験](../../../../tests/coupling/finite_wing_steady_test.cpp)

uv run --python 3.12 --no-project --with-requirements rd/requirements-reference.txt python -B -X utf8 docs/verification/IM-03/finite-wing-unsteady-v1/small_reference.py out/finite-wing-harmonic-m2n4-replay.json
ctest --test-dir <build> --output-on-failure -R '^coupling[.](finite_wing_drag_refinement[.]fw_v01[.]m2n4|case_uniform_flow)$'

局所核の循環の向きから物理後縁の向きに移す際に符号を変換し、後縁の伝達係数を適用する。変換前の経路では、水平翼の循環48成分と荷重24成分の照合が失敗した。独立行列で後流補正だけを反転すると、その循環の差を再現した。

GCC 14.2.0 Releaseでは、単一面を含む試験が14010アサーション、水平翼M2/N4が1607アサーションで合格した。

同じ環境で二度生成したfixtureのSHA-256は `1eb0480838d5d6e01b16f7ed6fbba91647f21baf1599d20762705f51565d5876` で一致した。

## 反射する水平翼の縮約と正式格子の試験

高周波のM256/N192では、全49,152未知数の実数基底行列だけで18 GiBを要する。
水平翼では、$y=0$ について反射する面の組を指定すると、対称な上下動・ピッチの循環を24,576未知数で解く。
面IDの全組、D2の向きを反転した面と固定後流の四隅、照会位置、法線の向き、法線速度、成分尺度と単位を照合する。
移流速度の $y$ 成分が零で、同じコア、後流年齢、周波数を全行に使い、後流は反射する後縁所有面に付着する。
このとき、各代表行から見た面の組の二列の包絡を足し、後流の補正列にも同じ操作を適用する。
縮約した行列で二語解を求め、元の面ID順に展開する。
元残差には両側の照会位置で計算した閉輪郭作用と、それぞれの位置で計算した後流補正を使う。
荷重も展開した全翼の二語解から求める。

水平小格子では、全系と縮約系のそれぞれについて、独立参照の循環、元残差と荷重を照合する。
反射する相手の入替えと、片側だけの法線速度の変更を拒否する。
後流補正は、全系では1作業域、縮約系では2作業域を使って照合する。

GCC 14.2.0 Releaseで `coupling.case_uniform_flow` と `coupling.finite_wing_drag_refinement.fw_v01.m2n4` が通った（14.46秒、5.26秒）。
Ubuntu 24.04.5・GCC 14.2.0 Release では同じ2件を実行し、14,010および1,845アサーションを確認した。
公式の凍結入力はそのまま使った。Ubuntu で小格子参照を再生成したときの複素値の最大相対差は、循環48成分で $3.74\times10^{-16}$、荷重12成分で $2.63\times10^{-16}$ だった。

正式格子の初回3件では、区間の開始点列に後流終端まで含めたため、求解前に `InvalidInput` を返した。
開始点を、幾何から求める後流終端の外向き下限より手前に限定した。最後の区間の終端には、製品が保持する後流幾何を使う。
この修正後の $k=0.05$ では、一次解が代数許容差を満たしたため、密求解が Binary64 を返した。以降の元残差と荷重の経路が必要とする TwoWord を取り出せず、`PrecisionUnsupported` になった。
改良を0回にした単一面試験で同じ失敗を再現した。右辺を上位語と低位語ゼロで保持して密求解に渡し、初回の解が通る場合にも循環の両語を保持する。

正式試験は[凍結入力と参照値](reference.py)から生成したファイルを読む。
M128/N192の2周波数とM256/N192の高周波について、上下動とピッチを別々に求解する。
元残差の全行の複素包絡で相対L2上限 $10^{-11}$、鉛直力とピッチングモーメントの計12観測で参照不確かさ $0.25\%$ 未満と、製品結果との差を含む合計 $1\%$ 未満を検査する。
参照値をJSONの二進値に読む丸めも観測の比較に含める。

cmake -S . -B <build> -DUVLAS_FORMAL_HARMONIC_FIXTURE=<absolute-path-to-input>
