# 凍結有限翼の辺荷重・線分分布・遠方抗力

上反角0度と5度の凍結翼について、翼弦2列・翼幅4列、閉後流長32 m、有限コア半径0.001 m を用いた。迎角は $0,\pm1,\pm2$ 度。Case から作る格子と製品の循環・荷重は [従来の5迎角比較](../finite-wing-polars-v1/verification.md) と共通である。

## 製品辺の力と線分観測

各迎角の18本の束縛辺について、両端の正準IDで製品荷重を対応付けた。製品が保持した作用点と三方向の力を、独立な閉渦輪の誘導と有向辺の荷重から求めた値と比較した。製品は照会辺自身の束縛寄与を除外し、独立参照は同じ直線源を足し合わせる前に除く。後縁の誘導は保持し、後縁自体を荷重辺の集合から除く。力の成分比較幅は $10^{-11}\rho U^2S$、作用点は $2\times10^{-14}$ m とした。

[線分観測契約](../../../../rd/aero/avl-reference/spanwise-load-observation-contract.md) に従い、$y$ に幅のある辺は一定の力密度と補正偶力を $y=-4,-3.6,\ldots,4$ m の固定20帯へ積分した。$y$ が一定の流下辺は元の作用点を所属帯へ入れる。製品辺から作る観測では辺パラメータの重なりを求める。[独立参照](reference.py) は物理 $y$ 座標で力とモーメントの一次関数を解析積分する。帯ごとの力、基準点モーメント、風軸揚力、±1度と±2度の揚力傾斜を比較した。幅で重み付けした傾斜分布には2%の照合条件を適用し、帯の総和は製品の合力・モーメントと $10^{-10}$ N、N m 以内で照合した。

上反角0度・迎角+1度の帯7（0始まり）では、線分観測の揚力は約9.054 N、点観測は約45.268 N。この違いを保ったまま総量を保存する。元作用点が辺中点からずれた厳密な対照では、補正偶力、辺を逆向きにたどったときの不変性、基準点を移したときの帯ごとのモーメントを確認した。線分観測は検証試験で行い、既存の構造転置は製品が保持した点荷重を使う。

## 同じ循環から求める遠方抗力

[遠方中点の定義](../../../../rd/aero/finite-wing/records/induced-drag-common-limit-protocol.md) を用いた。製品の後縁所有を照合し、各帯の保持循環から節点の循環差を作る。遠方の中点速度は $yz$ 平面で理想核を評価し、抗力は帯循環と幅方向の速度に $\rho/2$ を掛けて求める。近傍側では製品の全辺力を風軸へ射影した。両観測の各迎角の値と、±1度および±2度の有限角二次差商を同じ凍結条件の独立参照へ照合した。

固定形状では循環と誘導速度が $U_z/U$ に比例する。既知一様流による力の風軸成分は零で、反対符号の迎角の平均では誘導力の $z$ 投影が打ち消し合う。製品近傍値の平均から $(U_x/U)(U_z/U)^2$、遠方値の平均から $(U_z/U)^2$ を除いて零迎角の二次係数を求めた。独立参照は循環傾斜から誘導のみの辺力と遠方抗力を直接計算した。

| 上反角 | 近傍（N/rad²） | 遠方（N/rad²） | 遠方を分母とした差 |
| ---: | ---: | ---: | ---: |
| 0度 | 1290.82420 | 1364.61023 | 5.407% |
| 5度 | 1284.68511 | 1357.58681 | 5.370% |

この粗格子での近傍と遠方の差は1%を超える。表はL=32 mの有限閉端と固定格子の観測値である。別の幅・弦格子、閉後流長、コアの個別誤差、理想核連続解の不確かさと非定常観測は [V-AERO](../../../requirements/practical-acceptance-plan.md#a5-02-部品部分系の必須入力と参照) に残る。

[フィクスチャ](../../../../tests/aero/fixtures/finite-wing-span-lines-v1.json) は75桁 Decimal で生成した。生成時に凍結した入力・生成元と遠方式の SHA-256 を検査し、旧5迎角の循環・全力・全モーメントを再現した。

## 実行結果

Windows 11、MSVC 14.51 の Release で定常の2件が通過した。各13,447検査、水平42.78秒、上反角5度53.01秒。

Linux、GCC 14.2.0 の Release で定常・後流長・コア半径の計6件が通過した。定常は各13,447検査、水平21.44秒、上反角5度29.38秒。clang-tidy は各系列の水平翼構成で通過した。

Windows の Debug では、最終差分のうち定常専用ヘルパーの属性を加える前の `646706a4` で2形状をコンパイルした。上の実行記録は最終差分で実行した Release を対象とする。

数値条件が同じ先行版 `0f910609` の別複製で、線分配分を点配分に置き換えると水平翼・−2度の帯0で失敗した。補正偶力を外すと厳密解とのモーメント差8を検出した。元の試験は同じ乱数seed 23で13,447検査が通過した。
