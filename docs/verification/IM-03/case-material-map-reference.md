# Case の材料座標対応と薄面の厳密参照

構造追従面の `material_map` を型付き Case に取り込み、薄い参照面の世界位置と解析接線を別の製品入口から求める。係数を有理数のまま保持し、入力の `SiCase` が破棄されても参照面を評価できる。

## 入力の被覆と層を検査する

[型付き Case の正規辞書](../../specs/foundation/case-schema-fields.md#fd-06-空力既知流れ)から、製品とは独立に194型・815欄の監査表を再生成した。従来の `host` のみの構造取付も検査を通る。新しい材料座標対応では、旧来と同じ資源計画で片と項を保持する。負対照はセルの隙間、総面積を変えずに作った重複と隙間、格子点の個数を使った範囲超過、空の対応、別の Shell が所有する有効な層、重複項、総次数超過。製品が返した JSON Pointer も照合した。

## 凹形状と独立有理式で薄面を確認

Case の `GeometrySurfaceGraph` を通常の解析・SI 変換で読み、mm で書いた基準長さと原点を換算した。採用グラフの高さを $f(\xi,\eta)=\xi^2\eta/2-\eta^3/3$ とし、基準長さ2 m、原点 $(4,-2,3)$ m、$z$ 軸回り90度の Frame を与えた。照会 $(1/4,1/2)$ の位置は $(3,-5/6,283/96)$ m。翼弦接線は $(0,3,1/4)$ m、翼幅接線は $(-2,-1/2,-7/16)$ m。どの成分も独立に求めた有理数と一致した。凹多角形の斜辺上は評価でき、外接矩形の内部でも多角形から外れる点と反射 Frame は拒否した。取消と資源不足の後も既存の所有面から同じ値を得た。

Linux の隔離複製で翼幅接線の高さ微分を零に置くと、第3成分の照合に失敗した。製品ソースを元バイト列へ戻すと18件が通過した。

構造側との照合には、同じ Case から得た Shell の準備済み PG、材料多項式の全域と層の片側、選んだ点の形状行が必要である。さらに共有渦頂点を使う荷重には、寄与元ごとの行を保持した転置が必要である。[構造追従の採用契約](../../specs/aero/structural-attachment-material-map-contract.md)。
