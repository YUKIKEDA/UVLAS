# 共通時計で全ての指定運動と励振の境界を照合

共通時計は、型付きケースで空力面に指定された運動と、点支持、トレース支持、弾性支持の参照運動を調べる。空力の照会対象に選ばれていない運動も検査する。既知流れ、突風振幅、指定移流、過渡外力の時系列にも同じ時刻表を使う。 [実装](../../../../src/coupling/case_flow_clock.cpp)・[指定剛体運動の契約](../../../specs/aero/prescribed-rigid-motion-start-contract.md)

## 絶対イベントと周期節点で区間を分ける

宣言イベントは元の絶対時刻をSI有理数に変換する。PCHIPの周期節点は $t_i+kP$ で調べ、最初と最後の同じ継ぎ目を重ねて数えない。区間の内側に境界があれば準備を拒否する。受理した区間の到着側はLeft、出発側はRightを使う。

連成ケースの未選択空力面、点支持、トレース支持、弾性支持、重力のいずれか一つに周期曲線を設定した。区間 $[-3.5,-2.5]$ s は全例で拒否され、生成された継ぎ目 $-3$ s で分割すると復元後も両側を照会できた。トレース支持だけに加えた絶対イベント $-13/4$ s も両側を照会した。追加の宣言イベント $5/4$ s は周期複製の対象外で、$[-2,-1.5]$ s は受理した。

同じ時刻表で非選択トレース支持の標本だけを変えた現行ケースは、元の保存結果と照合すると拒否された。時計の全区間、流れ・指定移流・選択運動の実内容も、既存の一括復元で照合する。 [試験](../../../../tests/coupling/case_motion_time_series_test.cpp)・[一括復元](../clocked-known-input-restore-v1/verification.md)

## 検証と適用範囲

Windows MSVC 19.51のDebugとRelease、Linux GCC 14.2のReleaseで、対象CTestは各8件が通過した。重点試験は各環境で1,102件のアサーションに通過し、うち134件は今回追加した時計の回帰で確認した。

変更した翻訳単位をWindowsとLinuxのclang-tidyで検査した。

隔離したLinuxビルドで、未選択の空力取付を走査しない変更と弾性支持の参照運動を走査しない変更を別々に試した。いずれも区間を誤って受理し、回帰試験が失敗した。元のソースとバイト列が一致することを確かめ、各変更を戻すたびに134件が通過した。

共通時計と既知入力の準備、照会、再開時の入力照合が対象。構造支持の反力と全微分を組み立てる経路、J1で確定した時刻・履歴、ファイルへのチャンク割付は、それぞれ構造・連成・入出力の後続ゲートで確認する。 [検証票](../im03-all-motion-clock-events.json)
