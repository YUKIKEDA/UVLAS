# 指定剛体運動の保存入力を再認定する

指定剛体運動の保存結果は、元の型付きケースと準備結果を破棄しても、厳密な入力と実係数を読み出せる。復元では、独立に準備した現行ケースと保存値を照合し、全項目が一致したときに新しい運動の所有結果を返す。 [採用契約](../../../specs/aero/prescribed-rigid-motion-start-contract.md#所有資源失敗)・[実装](../../../../src/coupling/case_motion.cpp)

## 式版と全成分を確認してから再評価する

Frameは世界原点の3成分と行優先の回転9成分を、有理数の符号・分子・分母で保持する。時系列は元ノードと世代、絶対イベント、要求区間、角度成分の $\pi$ 指数を保持する。定数・多項式は原係数と時間領域を照合する。PCHIPは節点、標本、境界政策、周期と式版を既存の復元入口へ渡し、現行入力から再計算した実係数を全項目で比較する。姿勢・時間多項式の式版も照合し、認定した $\pi$ の包絡を再構成する。

## 元の保存結果を壊さずに独立な改変を拒否

保存結果の同じ形と来歴情報を保ち、実係数、原標本、端政策、Frameの原点、正しい別の右手回転、多項式の定義域、$\pi$ 指数、式版を一項目ずつ変えた。絶対イベントには、Binary64で同じ値へ丸まる $1$ s と $1.000000000000000001$ s を使った。すべての拒否後に元の保存結果を復元できた。

復元した運動を $t=1$ s の左右で評価した。独立なHermite基底に基づく並進の一階 $4/3$、二階は左 $1/3$、右 $5/3$。回転角の一階は $\pi/2$。姿勢と原点の値・一階・二階を、連続して評価した結果とTwoWordの各語、指数、誤差半径まで照合した。 [試験](../../../../tests/coupling/case_motion_time_series_test.cpp)

## 検証結果と再開境界

MSVC 19.51 Debug・ReleaseとGCC 14.2 Releaseで、指定運動、既知流れ、PCHIP、SI変換の対象8試験が各構成で通った。復元の焦点回帰は342アサーション。隔離したLinuxでPCHIPの再認定を通常の準備に置き換えると、改変された保存実係数が拒否されず、1アサーションが失敗した。元のソースに戻して342アサーションの合格を確認した。

この入口で保存と復元を行うのは運動入力の認定済み内容である。復元入口はファイル読込み側で組み立てられる型付きレコードを受け付ける。J1のチャンク割当、受理済みの時刻アドレス・全履歴の保存、異なる実行環境での再開検証は後続のゲートに残る。 [検証票](../im03-prescribed-motion-resume.json)
