# Case の全構造追従面と正準頂点の一括認定

検査済み空力幾何と、幾何組立で割り当てた物理面 ID の所有表を使い、型付き Case の表面を全件照合する。面を重複して引き受ける表や、割付先のない束縛面を拒否する。Case の各パネルは、指定された順序の物理面と一対一に対応する。四辺形の D2 子 facet と局所頂点は既存幾何から取り、束縛面に混在する独立三角形は拒否する。後流面は束縛面の所有表に含めない。

## 元の荷重点と正準点

構造追従面の各パネルで、その参照頂点と非貫通点を Case の薄面と実 PG に照合する。元 facet の局所頂点ごとに、翼弦列、翼幅節点、寄与元の翼幅区間と構造パッチを保持する。荷重はこの元頂点へ返し、正準点を共有する面でも元の荷重経路を保持する。

正準点の各グループでは、同じ材料サイトの重複だけを省き、異なるサイトをすべて照合する。照合では同じ Case が用意した構造支持を使い、自由座標への作用と時変指定項が一致する場合だけ認定する。指定運動側と構造追従側が一つの正準頂点を共有する場合は、この段階では証明できる共通写像がないため拒否する。

## 実二面の検証

二つの構造追従面が一つの二層 PG パッチを使う。実空力幾何で非連番の物理面 ID を使い、接触検査から二面の共通正準点と片側の材料行を得た。型付き Case から名付き支持境界と時間入力を読み、実の拘束チャートを用いた。片面の登録欠落、二面への同じ物理面の指定、未割当の束縛面、別名照合予算の枯渇を拒否した。

別の例では片面を $2^{-23}$ m だけずらす。ずれは Case の幾何許容差 $10^{-6}$ m より小さく、両面はそれぞれ同じ幾何に対して単独で準備できる。登録された正準点の形状行を比較する全表面入口では不一致を検出した。

GCC の隔離複製で別名の厳密照合だけを省くと、近接した二面を誤って認定し、負対照が1件失敗した。ソースの指紋を戻して再ビルドすると、一括準備の20アサーションが通過した。

今回の入口は幾何組立の物理面 ID を使う。Case の格子から新しい ID を生成する処理、指定 Motion を伴う支持がない Case の構造支持所有者、全状態の再開は後続段階に残る。

固定したソースに対し、MSVC 19.51 Release と GCC 14.2 Release で `coupling.case_pg_support_motion` と `coupling.case_uniform_flow` の2件が通過した。材料面と構造支持の焦点試験は両環境で計463アサーションが通過した。元頂点単体の観測は [前のソース固定記録](case-material-original-binding.md) に残し、この段階の指紋は [検証マニフェスト](im03-case-material-surface-model.json) に記録した。
