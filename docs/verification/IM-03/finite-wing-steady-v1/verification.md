# 凍結有限翼の定常循環と全ベクトル荷重

FW-V01（上反角0度）と FW-V02（5度）の迎角+1度で、各8本の定常非貫通式を全列組み立てた。翼弦2列、翼幅4列、直線後流32 m、速度20 m/s、有限コア半径0.001 m は第1列の試験と同じである。元の凍結記録と fixture を保持し、全列の係数、右辺、循環、合力、基準点まわりのモーメントを [新しい fixture](../../../../tests/aero/fixtures/finite-wing-steady-v1.json) に固定した。

## 型付き Case から定常式まで

試験の変換部は、各固定参照面の翼弦と翼幅の分割、前縁と後縁の境界を SI Case から読む。採用位置の1/4翼弦の渦頂点、3/4翼弦の非貫通点を既存の薄面評価へ渡し、位置と接線を求める。左右翼根の点を照合し、後縁に指定長の直線後流を付ける。この変換で扱うのは、凍結二形状の直線境界と共有翼根である。既存の全域接触と非貫通の入口へ渡す物理座標は、独立 fixture の座標と比較した。

試験で定常の下流トレースを同じ帯の後縁循環に結ぶ。零循環と8本の単位循環による製品原残差から、右辺と8列を抽出する。独立な全列の値を製品ソルバーの入力には使わない。既存の密行列ソルバーで解き、保持語を原式へ差し戻して各行を検査する。絶対幅は第1列の記録に合わせて $2\times10^{-10}$ とした。

## 有限コアの荷重

同じ定常解の後縁循環を保持下流トレースとし、静止翼で各面の循環時間微分を零として、既存の循環と全ベクトル荷重の入口を実行する。密度とモーメント基準点を Case から読み、この経路が得た循環を定常解と、原残差を零と照合する。

独立参照は75桁 Decimal で閉じた直線渦輪を積分する。束縛辺の符号付き循環を集約し、後縁の構造力を除いた全辺の中点で力を作る。辺の中点に同じ直線が作る自己寄与は零となる。参照モーメントの基準点は $(0.375,0,0)$ m。比較幅は $10^{-11}$ に Case の $\rho U^2S$ または $\rho U^2S c_{ref}$ を掛けた値を用いる。これはこの有限コア・離散格子で独立計算と照合するための幅である。

| 上反角 | $F_x$（N） | $F_z$（N） | $M_y$（N m） |
| ---: | ---: | ---: | ---: |
| 0度 | -2.368645 | 158.224113 | -189.711513 |
| 5度 | -2.364955 | 157.917490 | -189.676543 |

参照は [生成プログラム](reference.py) が元の凍結 fixture、旧生成プログラム、R&D 原本の SHA-256 を確認してから生成する。二つの旧第1列と循環を照合してから、新規ファイルに保存する。

```text

```

## 製品での検証

MSVC 19.51 Release と GCC 14.2 Release で `coupling.finite_wing_steady` が通過した。両方で1314アサーションを実行した。観測した実行時間はそれぞれ32.56秒と22.18秒。GCC のコンパイルデータで対象試験の clang-tidy も通過した。MSVC Debug の同じ対象は279.75秒で通過した。CTestの制限は Release 90秒、Debug 480秒とした。

GCC の隔離複製で、保持下流トレースの割当だけを隣の帯へずらした。上反角0度の第5列、第1行で誤差が約 $3.54\times10^{-3}\,\mathrm{m}^{-1}$ となり、全列比較が失敗した。復元後のソースをバイト照合し、同じ試験の1314アサーションが通過した。

迎角-1度と±2度、保存的な20帯の分布、格子・後流長・コア半径の収束、理想核との誘導抗力比較、非定常の Heave・Pitch は V-AERO の後続観測に残る。[A5-02](../../../requirements/practical-acceptance-plan.md#a5-02-部品部分系の必須入力と参照)。
