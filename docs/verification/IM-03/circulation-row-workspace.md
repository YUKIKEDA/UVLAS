# 循環の求解と接線・転置で照会の作業領域を再利用する

循環の係数行は、束縛面と後流の誘導を照会点ごとに計算する。求解と元残差の再評価、確定した入力を使う接線・転置の行再生では、照会のたびに同じ寸法の作業配列を用意していた。各経路で照会を順に処理し、準備した作用とその結果の利用を終えた後に、次の照会へ領域を渡す。

初回に、facet・局所パケット・基底、厳密三角形判定1件、点から列への対応、点と強度のID、有向辺の整列領域2本を確保する。同じ寸法で初回が成功した後は、これらの領域を確保し直す必要がない。辺の整列結果は作用が所有し、最後の参照が解放された時点で作業領域へ戻る。入力の点・辺・区間は各照会で再認定する。確保上限の判定には最初の費用と残る行数分の増分を使い、作業量には再初期化分も含める。直列再利用を予算で認められない場合は、従来の個別確保も判定する。

## 強度の転置から元の係数行を作る

係数行に必要なのは、三つの直交する速度方向の実強度への転置である。以前はそれぞれについて、点・照会・コア半径を含む全随伴を構成していた。新しい経路では、同じ有向辺の散布順で三方向の強度成分を加算し、全随伴と同じ精度へ丸める。強度数の3倍の区間を一度確保し、照会ごとに使う。点やコア半径の微分を消費する物理荷重の転置では、従来どおり全随伴を使う。

有限翼の回帰では、密な元区間を作る既存の検証経路と、一行ずつ再計算する接線・転置を比較する。独立した有限翼参照では循環、非貫通の元残差、元辺の力の近傍抗力、Trefftz抗力を照合する。局所回帰では全随伴の上下端が強度専用経路と厳密に一致することに加え、初回と再利用の見積もり、予算ちょうどと1 B不足、取消、数値資格で拒否した後の再準備を調べる。 [有限翼の入力・許容差](finite-wing-drag-refinement-v1/verification.md)・[独立な元区間と行再生](finite-wing-native-row-replay-owned-v1/verification.md)

## 密入力の余分な確保を除く

循環の線形系は、最終バッファへゼロを直接入れてから係数を書き込む。元の実装では全部をゼロにした別配列を作り、最終バッファへ複製した。未知数24,576の正式格子では、元行列と右辺を合わせたこの複製分は4,832,034,816 Bになる。これは寸法から計算した累積確保の削減量である。正式格子の因子・荷重・後流を含む総資源、実稼働時間、近傍と遠方の1%条件は検証が残る。

## 二つの有限翼で参照値を保つ

GCC 14.2.0 Releaseで、同じ凍結入力の水平翼M2/N4を比較した。循環と荷重の試験で計上した累積payloadは、`main` の50,507,686 Bから32,814,614 Bへ35.0%減少した。元残差と行再生の検査を含む573件が両版で通り、近傍抗力係数と包絡半径、Trefftz抗力係数の表示値が一致した。GCCでは同じ翼のM4/N8も1,647件が通った。実行とビルドが同じホスト上で重なったため、前後の時間から速度比は算出していない。
