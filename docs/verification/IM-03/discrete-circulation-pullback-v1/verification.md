# IM-03 実数離散循環の入力へのプルバック

対象ソースは `52f903c12a458723455a441a342f963c09fce186`。接触検査済みの同一配置で、非貫通残差の方向に対する実数転置を使う。[UVLM 統合仕様](../../../specs/aero/uvlm-integrated-specification.md)

## 転置と入力ごとの双対

循環に関する無次元スカラー観測量の種 \(g\) に対応する \(A_{\mathrm{eff}}^T\lambda=g\) を解く。値の循環と転置の両方で原残差を検査する。固定循環の入力方向を \(\delta x\) とすると、そのプルバックは次式で与える。

$$
g^T\delta\Gamma=-\lambda^T\left.\frac{\partial R}{\partial x}\right|_\Gamma\delta x.
$$

- 法線で重み付けする前に、誘導核へ実数の各座標単位ベクトルを渡す。その双対包絡を実際の高語・低語の \(-\lambda\) と元の法線で合成する。入力へ戻す際にも値の循環の両語と後縁符号、固定旧トレースを使う。
- 全ての照会が寄与する正準位置の双対を、一つの配列へ集約する。物質照会は頂点・辺・面の保存済み写像へ散布する。自由照会は独立の位置双対を返す。
- 正規化法線の双対は \((I-nn^T)/\lVert t_\xi\times t_\eta\rVert\) と外積の両方を適用し、元の接線2本へ戻す。面速度の双対と一様流の双対は符号が逆で、一様流には全行の寄与を加える。
- 種の面IDと、元の試行および転置用の行列・レイアウトを照合する。共有する資源計画と仕事量の上限を使い、値・転置・双対がすべて成功した時点で流れを消費する。

## 独立試験

自由照会の正負両方の後縁符号と、物質三角形照会で、正準位置、照会位置、接線、面速度、一様流の各双対と同じ方向の内積を正確有理数で合算した。一面の種は \(3/8+2^{-58}\)。後縁を含めた65桁の直接積分と中心差分で得た独立の \(\delta\Gamma\) に種を掛けた仕事、および製品の前進接線の仕事と照合した。比較許容は双対包絡と \(10^{-16}\) の和。[独立参照の入力と計算](../discrete-circulation-direction-v1/reference.py)

- 面速度と一様流の逆符号、および元の接線2本の法線方向成分を解析式で個別に照合した。非対称二面の一様流への寄与は、独立に持つ2つの転置成分の和で検査した。
- 欠けた種、面IDの不一致、非有限の種、古い行列世代、種の投影誤差ゼロを拒否した。キャンセル時は割付がなく、呼び出し元の流れを保持した。

- GCC 14.2 Release の分離コピーで、接線への外積順を反転すると個別の双対と仕事の8項目、正準点の誘導双対を除くと仕事の6項目、二面の流れ寄与を加算せず上書きすると1項目が失敗した。いずれも Catch2 の終了値は42。

## 実行環境

- MSVC 19.51 Debug・Release と GCC 14.2 Release は実装コミット `d546cb8bf3f0c1b23d2c62c9374ed95cba3db45e` で `coupling.case_uniform_flow`、`aero.p1_shared_action`、`aero.global_geometry`、`numerics.dense_solve` の各4件が合格した。所有と lint の修正後は、影響のある `coupling.case_uniform_flow` を3構成で再実行し、各1件が合格した。
- 最終ソースで離散非貫通と循環に絞った実行は3構成とも3ケース938項目が合格。乱数種は23。両OSの clang-tidy 21.1.1 を変更した翻訳単位に適用した。

## 適用範囲

現在の接触・別名・核の分岐を固定した実数離散式を対象とする。時刻、固定半径、過去のトレースへの双対や輸送の逆伝播、PG-ANCF 物質写像への接続、連続積分の物理精度認定は別の工程に残る。
