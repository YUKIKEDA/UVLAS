# 観測帯境界へ適合する参照格子族：事前比較仕様

版0.1、2026-10-31。[一次荷重・保存再構成試験](avl-linear-load-wrench-experiment.md) の初回10判定は7成立・3未達。有限迎角の影響を除いても弦方向の非漸近性が残り、支持辺再構成では分布のN48→96差が約0.21%まで小さくなったが、差ベクトルの方向・次数の安定性は未達だった。元結果は変更しない。

今回は観測の不連続な帯境界と格子の関係を変えた**別の格子族**を定める。物理翼・観測境界・力の式・しきい値を変えず、結果を見る前に以下を固定する。

## 1. 物理幾何と分割

FW-V01/V02の全形状・翼幅・後退・テーパ・上反角・基準量・直線後流は同じ。固定20帯の全21境界y=−4+0.4jをAVLのSECTIONとして明示する。区間ごとのxLE、c、zは既存の同じ解析式から作る。区間内は元と同じ直線補間で、物理翼の形状・法線・面積を変えない。

各0.4m区間をk=[1,2,4,8]のcosine配置で分け、全幅N=[20,40,80,160]とする。弦M=[3,6,12,24]。最大3840未知量で元のNVMAX=5000と2GiB条件を守る。弦系列はN160固定、スパン系列はM24固定、対角系列も保存し、重複除外10格子／翼を使う。M32N160は上限を超えるため採用しない。以前の格子族の未達を置換・削除しない。

各有限束縛辺の支持が固定20帯のいずれかに完全に含まれる構成となる。従って点観測とspan-wrench-P0-v1は帯ごとに同じ合力・モーメントとなるはずであり、両者の係数差≤1e−10を要求する。端点の丸め許容は既存1e−9m、元点を移動しない。翼面流下脚は従来どおり点観測で一致させる。

## 2. 実行・検証条件

同じUG出力対応のAVL3.52/DP/zero-core-exterior-stable-v1実行体を使う。新たな数値ソース変更やビルドはしない。2翼×10格子×α=[−2,−1,0,1,2]度の100条件を実施する。U・ρ・Mach・フラグ・軸は既存と同じ。1格子5迎角で分解を再利用し、UG前後FTの同一性を検査する。

元の断面式との全SECTION座標・弦・法線の整合、xy投影面積8.4、MAC・原点が同じことを入力段階で検査する。実出力の帯境界が固定帯境界に適合することも確認する。非貫通残差≤1e−11、合力／モーメント保存≤1e−10、全寄与3MNの分類を既存と同じ条件で判定する。

## 3. 収束条件を変えない

総量の予算0.30%、分布の準備予算0.5%、角度感度0.10%、観測次数0.5〜6・次数変化≤0.5、分布差ベクトル余弦≥0.9は前回のまま。系列の細分化比も2とする。非単調・非漸近は推定未確定のまま保存し、帯境界適合だけを理由に合格としない。

結果は元の格子族と別JSONで保存する。成立してもこの格子族と観測量に対する参照準備であり、任意の格子の点荷重から連続分布を正確に復元できるとはしない。

## 4. 資源・後処理

翼ごと1800秒、1格子300秒、ピーク2GiB、合計出力2GiB。実行体・入力・源・出力・コードハッシュを記録する。後処理180秒・512MiB。初回未達を保持し、追加格子も未達ならそのまま記録する。UVLASとの比較・構造荷重伝達・J1は本試験に含めない。

## 5. 入力・出力の監査結果

[別格子族の入力](avl-band-aligned-inputs.json) と [入力監査](avl-band-aligned-input-audit.json) を保存した。2翼20入力の各21断面は元の同じ解析形状に一致し、端・中央断面、投影面積・基準量も元と同じ。元の入力マニフェストは変更していない。

[全100条件の実行](avl-band-aligned-grid-runs.json) と [集計・収束判定](avl-band-aligned-convergence-result.json)、[点観測／再構成の照合](avl-band-aligned-observation-audit.json) を保存した。実行・解析コードは `run_avl_band_aligned_grids.py`、`check_avl_band_aligned_grids.py`、`audit_avl_band_aligned_observation.py`。

新たな数値ソース変更・ビルドはなく、前回のUG対応実行体をそのまま使用した。UG前後FTは全条件で同じバイト列。保存・全寄与の分類・元帯の被覆・残差・製造入力・角度感度は成立し、初回と同じ10判定は8成立・2未達。元の `all_criteria_pass=false` を保持する。

合力の最大係数差1.12e−16、モーメント差8.33e−17、非貫通残差最大相対1.13e−14。支持辺が固定帯境界をまたぐ件数は0。元の点観測とspan-wrench-P0-v1の帯ごとの係数差は、力最大2.07e−19、モーメント最大1.49e−18だった。単なる全体総和だけでなく、各帯で一致した。

計算213.726秒、最大ピーク894,119,936 bytes、全出力162,057,800 bytes。集計1.765秒・73,994,240 bytesで予算内。

最終差は小さくなったが、総量・分布とも事前の漸近性条件は未達。FW-V01・δ=1では弦方向の揚力差が0.00075756→0.00025398→0.00060016となり、単調に減少しない。スパン方向の揚力の観測次数も約3.01→1.15と変化した。

帯分布の最終差ベクトルの余弦は約0.929で方向条件内だったが、スパン観測次数は約3.49→1.30。前の段階の粗い格子から安定した漸近域へ入ったとは判定しなかった。最後の差だけを使って0.5%予算へ合格させていない。

## 7. 切り分けられたことと次のゲート

今回の格子族では、点観測と支持辺再構成の違い・帯境界を切る再集計の影響がなくても、総量／分布の漸近性条件は未達だった。従って、残る問題を帯の分類方法だけで説明することはできない。元の循環解と荷重評価の格子依存、および求解感度を分けて診断する必要がある。

元格子族の未達、再構成候補の未達、この適合格子族の未達をすべて保持する。小さい最終差や、異なる格子族の最細値の近さを厳密な誤差上限としない。次は一次循環の二方向格子依存と線形系の感度を検査し、必要な追加分解能と誤差推定法を根拠付きで決める。参照精度の受入・UVLASとの比較・J1は未完了。
