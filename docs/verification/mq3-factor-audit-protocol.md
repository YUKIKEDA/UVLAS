# M-Q3因子比較：保存解の別評価仕様

2026-11-03、実行前に固定。主仕様は[2×2切分け](../mq3-constraint-factor-diagnostic.md)。最大20条件のうち必須数値条件が成立した条件だけを監査する。停止条件も含めて一次結果に記録し、未実行条件の因子効果は結論しない。

一次場は固定KKT微分公式とは別に、h=0と複素h=i×1e−25の一般LU直接解から構成する。全セル11²点の保存核、二次／四次の保存解に対し、零次残差1e−9以下、物理テンソルのλtr²+2μE:Eによる一次誤差ノルム差1e−8以下、別Vandermonde微分によるH¹相対差1e−8以下を要求する。ソース・写像・核・解のSHA256も確認する。

幾何、対象空間、選択した固定制約行を共有する別評価であり、独立実装による係数構成や全体SVD・最適化の独立再求解ではない。仕事条件を削除した組は、監査に合格しても製品候補として採用しない。準備時のハッシュを一次結果へ引き継ぎ、数値条件未達は保存して診断する。
