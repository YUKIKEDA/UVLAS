# 固定20帯：連続極限の有限追加

2026-11-05。N192→384で最大帯変化は約1.3%。両コードの区間値は一致するが、各帯の連続極限の不確かさは未認定。翼端帯で幅方向差が支配的なので、M8/N384とM8/N768を各翼・各コードへ追加する。最大6144未知量を保持し、既存M16/N384との弦差を別に加算する。N192/384/768の収縮率と帯ごとの符号も保存する。

自側は指定直線後流の理想核ε=0で実行できる範囲だけを使い、既存の固定正則化半径との差も別に保存する。自由後流のε>0条件を変えるものではない。参照は原本の1e−8mを保持。後流は閉じたL1024m。近似予算は先行計画を維持し、20帯の比較2%を緩和しない。

結果は最大帯差・L2・弦差・核差・後流差を個別に保存し、外挿を用いた場合は有限格子値と補正量を明示する。この追加が不足すれば不足を記録し、自動で次の倍分割へ進まない。
