# 非定常参照：周波数計算での分離

2026-11-05。Ptera 5.1.0の時間計算はM2/N8、64→128→256分割の複素荷重に数%の差があり、時間精度0.20%は未達。原本の結果と監査用コア系列を保持する。

独立参照の周波数計算ではPtera自身の薄翼メッシュ・法線・物理面積・非定常作用点と、原本の4本線分のリング誘導関数を使用する。自側の位置生成、誘導、荷重評価コードは使用しない。束縛後端はdt→0の実TEとする。コア配列は明示入力、年齢0で誘導を評価し、ゼロ粘性・ゼロ振幅の極限を扱う。Ptera時間計算の小さい粘性・振幅の感度は別の実測で維持する。

年齢τ以降、固定した閉端Tまでの単位閉渦輪をG(τ)とすると、変動後流はμ(0)G(0)+∫μ′(τ)G(τ)dτ。調和μの微分は−iωμ。この表現は閉端G(T)=0を保持する。自側は半無限帯Hの導関数−∫μH′を使っており、実装も求積する関数も異なる。両経路の一致だけで独立性を主張せず、原本時間計算が周波数結果に収束することも確認する。

M2/N8の時間分割512/1024を追加し、周波数極限への差と収縮を保存する。周波数側はM2/N8、M4/N24、M8/N48、M16/N48、M16/N96の有限系列とし、必要な方向だけ追加する。Gauss8/12/16、後流128/256/512m、半径1e−4/1e−5mを分離。先行の1%と内訳予算は維持する。原本時間計算と異なる作用点・力の定義へ無断変更しない。
