# 歪み板曲げ結果の監査仕様

2026-10-31。[事前仕様](q9-distorted-plate-experiment.md) の実行後、独立な観測再計算を実行する前に固定する。主試験の閾値と結果を変更しない。

1. ソース・4依存・元仕様・NPZのハッシュ、8ケースの組合せ、実行時間・メモリ・64MiB保存上限を確認する。
2. 保存頂点を格子式から再生成し、保存Q9節点を双一次写像から再生成する。位置差1e−13以内。各セル隅のヤコビアンをQ4の明示式で再計算し、正値・無次元下限・面積和を検査する。
3. 保存された各70／90桁経路の記録について、保持解の相対残差・2種の後退誤差と反復回数を確認する。保持解自体や疎行列はNPZに保存していないため、これは記録と条件の監査であり残差の独立再計算ではない。NPZの物理変位は倍精度へ投影された観測用データである。
4. 既存の要素・観測ヘルパーを使わず、1次元Lagrange式からQ9を再構成する。中心の物理点をセルの双一次写像で探索し、同じ荷重との仕事をfsumで求める。L2は11点積分で再計算し、元の9点の値と比較する。中心・仕事は参照尺度で差1e−10以内、L2誤差は差1e−8×max(元値,1e−12)以内を監査基準とする。
5. 同じ厚さ二次連続問題の4係数を、別の7点厚さ積分で再計算する。元の参照係数・圧力・中心・仕事と、非ゼロ対象の相対差1e−10以内を確認する。
6. 独立な観測値から最細3指標・次数・薄肉一様性を再判定し、主結果と一致することを確認する。未達が正しく記録されていれば成果物監査自体は成立し得る。監査成立を要素採用の合格と混同しない。

監査120秒・ピーク512MiB。人による独立審査、格納係数の全独立検証、真の前進誤差保証は実施しない。監査結果と数値観測を保存し、元結果を上書きしない。
