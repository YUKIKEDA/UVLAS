# 配分感度の元点モーメント：事後の成分診断

2026-10-31。4計算と配分感度結果を確認した後の補足診断として、未知の尾部や仮説の盲検検証とは区別する。新しいAVL計算は行わない。

帯平均に保存された既知の恒等式を使い、元点モーメント密度の配分差を有限辺の項と補正偶力の項へ分ける。

$$
\Delta J_{c,b}=\Delta J_b-\frac{\Delta C_{y,b}}{2h_b},\qquad
\|d_c\|^2=\|d_J\|^2+\|d_{\mathrm{couple}}\|^2
+2\langle d_J,d_{\mathrm{couple}}\rangle.
$$

各ベクトルには既存の平方根帯幅重みを用いる。基準対tip-rich、基準対tip-poor、tip-rich対tip-poorの両翼6組で、成分ベクトルと元点モーメント差を再現し、各ノルムと交差項を保存する。交差項は符号付きであり、各項の比を非負のエネルギー分担率とは呼ばない。補正偶力の項には循環と元作用点の両方が含まれ、幾何だけの因果効果とは扱わない。

スカラーについても元点モーメント傾斜差＝有限辺モーメント傾斜差＋補正偶力係数差を確認する。再構成許容差は1e−12×max(1,尺度)。処理60秒・128MiB・出力1MiB以内、親JSONとソースのハッシュを記録する。配分感度やM24の誤差予算・参照採用の判定は更新しない。
