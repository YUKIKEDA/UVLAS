# 対称静的参照の縮約・全翼照合：事前仕様

2026-10-31、版0.1。[縮約設計案](../symmetric-reference-reduction-design.md) に従う限定試験。以下1〜7節を追加コード・ビルド・実行前に固定する。元の全翼・未達結果・しきい値を変更しない。

## 1. 原本監査と対象

原aic.fのVVORは、y鏡像の端点順を入れ替え、符号IYSYMを使って誘導を加える。SETUPの制御点行列では有限辺を含める。力点の自己項は元の規約を維持する。aero.fのAEROはSFFORC/BDFORC/TPFORC後、IYSYM=1で対称成分を倍化し、横力・ロール・ヨー等を0に置く。したがって、FTのゼロだけを等価性の証拠にしない。

対象はFW-V01/V02、Mach0、横滑り・回転0、迎角+1度、y=0対称、単一翼・成分1、body/control/designなし、全後流あり、粘性OFF・翼面流下脚力ON、原点y=0、S=8.4・c_ref=1.1142857142857143・B=8。2翼以外、非対称／動的用途の検証ではない。

## 2. 別計測版と適格性

source-core0-grid8000の別コピーを作り、既存UGを変更せずUH命令と専用出力を追加する。数式・核・容量・元計測は変更しない。UHはIYSYM=0の全翼対照とIYSYM=1の適格な半翼だけを受け入れる。半翼は全RV1_y≥0・RV2_y>RV1_y、最大y>0を必須とする。

実行で使う同じ適格性関数を局所入力で検査する。正常半翼／全翼と、別対称モード・z鏡像・body・control・design・複数翼・別成分・不適格境界／オプション・Mach・横滑り・回転・反射面／原点移動・負側／退化半翼・基準量変更・NaNの拒否を保存する。拒否時は計算状態と出力ファイルを変更せず、状態を返す。通常計測は別配列・既存LUへの読取だけとする。

UHは倍化前の各渦線力と力点、全RC・法線・有限辺・GAM/U・既知／誘導速度・残差、帯境界と明示的なnative-half/native-fullメタ情報を保存する。小系NVOR≤256ではWC_GAMから元Aをbinary float64で保存する。LU配列を元Aと呼ばない。

## 3. 入力と全翼照合

既存21断面の正側11断面だけを同じ有効数字で取り出し、入力の対称フラグを1にする。全翼のS/B/c・原点・軸・流速・密度は維持する。既存の断面を補間・丸め直し・鏡映平均で合わせない。正側断面を取り出したことと物理幾何差を別々に監査する。

2翼×M6N40、M24N160、M24N320（Nは物理全翼）の6半翼を計測する。各々を未改変の親実行体でも実行し、同じ半翼条件のFT/FS/FEが新計測前後とバイト一致することを要求する。さらにM6N40の2全翼対照をUHで計測し、旧FT/FS/FE・UG行／力／帯がバイト一致することを要求する。

半翼データを物理全翼へ展開する。負側はスパン順を逆にし、辺端点をRb/Ra、RC・法線・力点・速度・力をRで反射、GAM/Uは同符号、脚種別1/2を交換する。モーメントは力点から再計算する。展開結果はrawとは別ディレクトリに保存し、derived-by-symmetryと親ハッシュを明示する。

対応する全翼データとの幾何・法線・力点差は絶対1e−11、Γ/Uは絶対1e−11または相対1e−10、速度差は絶対1e−10、各F/q差は絶対1e−10（元と同じ基準速度・長さ単位）。全域／固定20帯の保存観測・力／モーメント係数差は絶対1e−10、元非貫通残差は基準速度で相対1e−11以下とする。ゼロ横力への上書きではなく、各成分を元の全翼力と照合する。

## 4. 行列・右辺の縮約

M6N40の全翼240未知量と半翼120未知量で、対応する正側制御点・源帯を比較する。全翼の正／正ブロックBと正／負ブロックC（負側の源を鏡映順へ対応）に対し半翼A=B+Cを照合する。係数差は絶対1e−10＋相対1e−10以内、右辺差は絶対1e−12以内。全翼のブロック対称性差も保存するが、有限精度幾何の差を0として扱わない。

上記6照合・2全翼対照・適格性・出力不変性がすべて成立するまで、次のN640は実行しない。未達なら原因と途中結果を保存して停止する。

## 5. 追加N640

成立した場合だけ、同じ正側断面のスパン分割を各区間32へ増やし、2翼の物理N640を実行する。未知量は半翼7680、物理パネルは15360、スパン帯は半翼320で容量を超えない。原本の対称処理を使うが、一般の非対称解を近似したものではない。

元の残差・全域力／モーメント保存・UH前後出力不変・適格性を同じ条件で検査する。物理全翼へ展開した場をτ/K観測へ接続し、N80/160/320/640の4段階を診断する。旧N20/N40を含む未達は残す。

## 6. 観測・誤差予算

既存と同じ5チャンネルと次数0.5〜6・次数変化≤0.5・方向余弦≥0.9・丸め床を使う。仮定付き外挿・端点移送・未評価の混合項を区別し、総量0.3%／固定帯0.5%の目標を変更しない。十分な推定がない成分は未評価で返す。成立しても参照受入や非対称・動的・連成用途へ自動昇格させない。
