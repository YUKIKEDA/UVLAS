# τ/K保存観測・帯モーメント・荷重差上限：事前仕様

2026-10-31、版0.1。[定式化案](../finite-wing-observation-error-contract.md) の1〜4節に対応する。以下1〜6節を実装・実行前に固定する。元の参照翼・循環・荷重点・収束結果・精度目標は変更しない。

## 1. 対象と保存する量

元／帯適合の2族×2翼×10格子、α=+1度の既存40場を使う。保存された馬蹄渦強さからτ、K、元RVへの補正偶力を構成する。τは帯内P0、Kは帯内P1で、幾何と積分の算術は既存の厳密有理数方式。強さと元力点のfloat64値を正確に読むが、元の求解を高精度化したとは呼ばない。

固定20帯でT₀=∫τ、T₁=∫(y−y_c)τ、K₀=∫Kを保存する。補正偶力は元の有限辺支持上へ一定密度で分配する。これは既存span-wrench-P0-v1と同じ一次荷重観測であり、元point-force-v1の帯分類と黙って置き換えない。

τ/Kと偶力からの合力・モーメントを、(a)全前線の直接和、(b)前回台帳、(c)独立な有限辺分布＋偶力の帯観測と絶対1e−10以内で照合する。各帯のP1再構成がT₀/T₁を保存することも同じ許容差で検査する。

## 2. 製造解と負の対照

y∈[0,1]、x_LE=y/10、x_TE=1+2y/5の台形翼を使う。前線は弦比1/5と3/5、スパン分割0、1/3、3/5、1。係数は(1,1/2)、(1/2,1/4)、(3/4,3/4)の3帯とし、定数倍・符号変更した場も検査する。観測帯0、1/5、11/20、9/10、1は元帯と非整列である。

補正偶力0のケースと、各有限辺の25%点に元点荷重を置くケースを使う。T₀/T₁/K₀、線積分モーメントと元点モーメントを、帯と源帯の交点で分けた独立4点Gauss積分と絶対1e−11以内で照合する。Kは前線間のψをx方向に積分して別経路で計算する。

T₁を省く場合と偶力を省く場合、それぞれモーメント係数差1e−5超を少なくとも1ケースで検出する。折れ線を内部に含む単一観測帯は、一次重みが一つに定まらないので拒否する。領域／基底不一致、退化・逆順の観測帯、非有限な偶力、偶力の寸法不一致も拒否し、入力を変更しない。

## 3. 場間荷重差の上限

既存12系列×3隣接比較で、同じ物理領域におけるτ/K差のL2、x_TE−O_xのL2、元点偶力の差を評価する。既存のCauchy–Schwarz上限で、揚力・有限辺モーメント・偶力を含む元点モーメントの差を検査する。上限違反の許容は係数で絶対1e−10。

固定帯へのτのP1射影Q₁とKのP0射影Q₀は、それぞれ今回の荷重の重みを保持する。そのため上記の上限のτ/K差を射影後の差で評価する経路も検査する。射影によるL2ノルムの非増大は二乗ノルムで絶対1e−10以下の丸め差を許す。これらは2保存場の差の上限であり、未知の真の解への誤差保証ではない。

帯の有限辺モーメント密度をJ̄=[(x_TE(y_c)−O_x)T₀+x'_TE T₁−K₀]/h、元点対応をJ̄_c=J̄−C_y/(2h)とする。線積分／元点モーメントの差に対して、2√B/(Sc_ref)×それぞれの密度差L2という保存観測上限も検査する。真の流れへの上界とは呼ばない。

## 4. 収束診断と誤差予算の状態

各40場で、τの帯P0平均、τの帯P1射影、Kの帯P0平均、J̄、J̄_cを別チャンネルで保存する。τのP1ノルムはΣh(τ₀²+τ₁²/3)、他はΣh平均²。単位の違う量を一つの生ノルムへ混ぜない。各族・翼・弦／スパン／対角の12系列に既存の次数・方向・丸め床条件を適用する。

漸近候補でのみ1.25×最終差/(2^p−1)を仮定付き外挿値として記録する。真の誤差上界と呼ばない。弦＋スパンの両方が適格でないチャンネルは誤差予算を未評価とし、不足分を0にしない。旧仕様の総量0.3%／固定帯0.5%の参照予算を変更しない。今回の結果だけでは参照を受け入れず、残る方向・観測・評価仮定を台帳に列挙する。

## 5. 保存と不変条件

親JSON・元入力・依存ソース・本仕様のSHA-256、製造積分、拒否結果、40場の帯観測と照合差、36対の上限・実差・射影ノルム、12系列のチャンネル別診断と未評価理由を保存する。元の点観測と未達は残す。誤差評価種別（場間差の上限／仮定付き外挿／未知の真の解への誤差未評価）を保持する。
