# 理想核参照に対する有限解の判定

2026-11-05。有限半径のPteraと主方式の核が同一ではなかったため、最終精度比較の参照は別途取得したPtera原本由来の理想核系列とする。同じ半径値を同じ核と呼んだ旧説明は、この判定には適用しない。主方式M128/N192・ε1e−5mの実際の値は変えず、参照理想核との差に主方式の有限コアの影響も含める。どちらも有限閉端128m。

幅は参照M16・N48/96/192/384、弦はN192・M8/16/32/64。既存の一般誤差認定関数の4水準・方向・次数条件を変更せず使う。参照推定値はN192の弦極限へM16のN192から幅極限までの補正を加える。参照の不確かさは弦と幅それぞれの隣接外挿差の1.5倍、M16/32弦差のN96/192間の変化、Gauss16/24差の2倍（M16/N96とM64/N192の大きい側）を加算する。厳密上界とはしない。

参照不確かさ0.25%以内、主方式の有限値との差に参照不確かさを加えて1%以内を必要とする。3周波数×2運動×2観測量を個別に判断し、未達を集計平均で隠さない。先行する0.25%の自側配分未達は別の実験のまま保持する。無限後流への精度認定、非線形自由後流、実務妥当性はこの試験には含めず、同じ数値認定規約で個別に要求する。
