# AVL原本・計測版・コア監査版の事前比較仕様

版0.1、2026-10-30。[有限翼荷重比較](finite-wing-load-reference-specification.md) の参照準備。以下1〜5節をビルド・計測変更・数値実行前に固定する。UVLASとの物理比較は本試験に含めない。

## 1. 原本と三つのビルド

公式AVL 3.52ソースの既存SHA-256を固定する。原本を安全な相対パスで展開し、元のFortranを保持したbaseline、出力計測だけを加えたmeasured、measuredの同一成分コア半径 `0.0001*DSYZ` を0へ変えたcore0を別フォルダに作る。外部参照であり製品へ組み込まない。元の著作権・GPL告知を保持し、変更差分・原本／変更後のファイルハッシュを記録する。

WSLの専用ローカル環境でGNU Fortran/CとX11依存を用意する。原本のgfortranDP設定を起点に通常REALを8 bytesとし、LAPACK補助の倍精度との整合を確認する。fast-mathを使わない。ソースの式・離散化・配列上限・解法を変更しない。ビルド設定の変更、コンパイラ・全依存版、明示ロック、コマンド・ログ・実行体ハッシュを保存する。

ビルドは依存準備後600秒／版・ディスク2GiB以内。Fortran/Cの互換性問題があればエラーを残し、設定修正は数式変更と分ける。ビルド成功だけで原本再現を宣言しない。

## 2. 計測I/Fと単位

原本AEROが実際に計算した束縛辺と翼面上の左右流下脚について、渦ID・帯ID・種別、作用点、FGAMの3成分を記録する。作用点は既存RV、または既存RROT+XYZREF。FGAMは原本の $2\,GAM\,(V_{eff}\times\Delta l)$ をそのまま読む。流下脚へ誘導速度を新たに加えない。

AVL内のVINFは基準速さで規格化された向き、GAMの単位は長さ、物理循環は $\Gamma=U_{ref}GAM$ 。FGAMの単位は面積で、物理力は $F=q_{ref}FGAM$ 。通常の力係数はFGAM/S。出力にこの区別を明記し、U=20をもう一度内部VINFへ掛けない。

計測は明示したUD命令だけで有効化し、無指定時の通常出力を変えない。UDでは同じ確定済み循環・速度でAEROを再評価し、元のFGAMを記録する。記録のON/OFFで既存FT/FS/FEが同じ値を返すことを別に確認する。

コロケーション点・法線・束縛両端・GAM・既知速度・誘導速度・非貫通残差を行ごとに保存する。支持対象は今回の単翼・対称画像なし・機体なし・制御／設計変数なし・通常の後流ありに限定する。対象外を黙って同じ式で出力しない。

## 3. 元の作用素による残差

LUで上書きされたAICNは保存対象にしない。元のWC_GAMと法線から $A_{ij}=n_i\cdot WC\_GAM_{ij}$ 、 $b_i=-n_i\cdot(VINF+VROT)_i$ を別ファイルへ出力する。行の残差は原本の総誘導WCと既知速度から再計算する。

Python側でも出力A・b・GAMから補償和で残差を計算し、既知速度尺度で相対1e−11以下を要求する。原本内残差と再計算の差は絶対1e−12以下。LU残差と物理式の一致を確認し、行列の因子化後値やFEのdCpを代用しない。いずれも今回の原本作用素に対する検証であり、独立空力理論への一致ではない。

## 4. 入力と合否

FW-V01/V02のM4・N12とM8・N24、α=[−2,−1,0,1,2]度。U=20、ρ=1.2、Mach=0、幾何軸の向きと機体幾何軸周りのモーメント、流下脚力ON、機体・粘性OFFは前回と同じ。3版各20条件、計60条件を計測する。公式Windowsバイナリの前回+1度・粗格子2翼も参照する。

- baselineとmeasuredの通常FT/FS/FEが全条件で同じ丸め出力となること。UDで再評価後も同じこと。
- baselineと公式Windowsの+1度粗格子の荷重係数差は絶対1e−7または相対1e−6以下。ゼロ近傍の分母は1として絶対差を使い、数値出力の丸めは別記する。バイナリのビルド条件は不明なので、これはビット再現条件ではない。
- measured/core0の全行が第3節の残差条件を満たすこと。
- 計測の力の和/Sが幾何軸CFTOTと一致し、作用点からのモーメントの和をSとb/c/bで規格化した値が幾何軸CMTOTと絶対1e−10以内で一致すること。
- 各渦につき束縛辺1件と流下脚2件、すなわち3×NVの記録が揃うこと。FGAM=0の寄与も保持する。全数値が有限であること。
- measured/core0の一次揚力傾斜とモーメント傾斜の差は、既定の共通尺度で0.05%以下。全2格子・2翼・δ=1度／2度を評価し、都合のよい組だけを選ばない。

コア差の成立を4系列の収束や実務翼全体の採用としない。固定20帯への保存的集計は、ここで取得する力・作用点と実際の帯境界を使う次の検査で実施する。粗格子の帯重心だけを移して合格にしない。

## 5. 実行資源・失敗保存

計算実行は合計300秒、各30秒、ピーク2GiB／プロセス、合計出力256MiB。元ソースの静的・動的な最大配列は変更せず、実際の作業集合を測る。浮動小数例外・非有限値・残差未達・計測による出力変化・予算超過は保持し、しきい値を緩めない。全ログ・セッション・入力・計測ファイルのハッシュと解析コードを保存する。

## 6. 初回の計測不適合と追加実行前の修正条件

初回は3版×20条件を完走したが、計測40条件で力の記録が0件だった。行と行列は出力されたものの、3×NV件数の条件に不適合であり参照計測の合格とはしない。[初回実行記録](avl-source-measurement-runs.json)、[停止・不適合記録](avl-source-measurement-initial-status.json)、元パッチ・ソース・実行体を保持する。

原因は、AEROと同じファイルにある別ルーチンSFFORCで力を計算しているのに、計測フラグのCOMMON宣言をAEROだけに挿入していたこと。修正実行前に、宣言をSFFORCへ移すだけの別計測版・コア0版を作り、同じ40条件を再実行すると定める。baseline20条件は元の記録を再利用する。入力・解法・コア条件・荷重式・しきい値は変えない。

追加実行は40条件合計300秒、各30秒、ピーク2GiB、合計出力256MiB。初回の値・停止・未達を上書きしない。修正後も力件数・残差・力／モーメントの和・通常出力不変性・コア感度をすべて判定する。

## 7. 実施・保存した成果物

[初回準備](avl-source-preparation.json) と [修正準備](avl-source-corrected-preparation.json) に原本・変更後ハッシュ、差分を保存した。計測アダプタは [参照専用Fortran](../../tools/design-experiments/reference_avl_measurement.f)、準備・ビルド・実行・解析は `tools/design-experiments/` の `prepare_avl_measurement*`、`build_avl_reference*`、`run_avl_source_measurement*`、`analyze_avl_source_measurement*` に分離した。

専用ツールチェーンはGNU Fortran/C 14.4.0。原本の通常REALを8 bytesとする設定と、LAPACK補助をそのフラグなしでコンパイルする設定を維持した。初回はX11/X.h不足で描画ライブラリのビルドが停止し、初回ログを保存して専用環境へxorg-xorgprotoを追加した。Fortranの数式や配列上限は変えていない。ビルド・依存ロック・原本／修正後のソースと実行体は `build/reference-avl/` に保持する。初期化・描画・固有値ライブラリも別精度に取り違えない。

[修正実行](avl-source-measurement-corrected-runs.json) はbaseline20条件を再利用し、修正2版の40条件を追加した。[修正解析](avl-source-measurement-corrected-result.json) の事前14判定はすべて成立。初回の力0件は未達のまま保持する。

| baseline対measured | 20条件のFT/FS/FEがすべて同じバイト列 |

| baseline対公式Windows | +1度・粗格子2翼、荷重係数の最大絶対差2.78e−17 |

追加40条件の実行は約60.0秒、再利用分を含む最大ピーク作業集合11,243,520 bytes、列挙された全出力47,371,963 bytes。各実行の資源とファイルハッシュも保存した。これは格子収束やUVLASとの一致を示す値ではない。

解析時にNumPyのboolをJSONへ直接保存して停止した。[保存停止記録](avl-source-analysis-initial-status.json) と変更前コードを保持し、NumPyスカラーの変換だけを修正して既存の計算結果を再解析した。数値計算・式・しきい値の変更や再実行はしていない。

## 8. 全分量の観察で残った採用上の問題

[コアと横方向対称性の観察](avl-core-symmetry-observation.json) を追加した。事前の一次揚力・幾何+yモーメント条件は満たしても、core0では左右対称の翼に横力とヨーモーメントが残った。最大絶対値はCY=1.776e−4、Cn=1.608e−4。微小コアを残したbaseline/measuredではそれぞれ5.28e−14、2.03e−14以内だった。

これは事後に14条件を緩めたり書き換えた結果ではなく、別の出力分量から見つかった未解決事項である。**core0は現時点で受入参照として採用不可**。計測が原本の力・残差を正しく取得できることと、0コアの数値評価が全分量で適格なことを区別する。

ほぼ同一直線上の渦線延長と力評価点における0コア核の相殺誤差を原因候補とするが、まだ切り分けていない。次は鏡映する幾何・循環・誘導・辺力の対応と、有限線分核の直線上／直線近傍極限を別の事前仕様で検査する。横力や抗力を0へ上書きして対称性を作らない。原本の微小コアを無断で別コアへ変更して参照と称さない。

固定20帯への保存的変換、全格子系列、一般3D近接各基底、UVLASとの荷重比較・J1も引き続き未完了。

後続の [直線近傍核の切分けと修正候補](avl-collinear-kernel-experiment.md) で、横力／ヨーを有限辺延長近傍の桁落ちに特定した。元コア0版は書き換えず、安定等価式を使う別候補で高精度照合・回帰を確認した。未修正版の不適格と、修正候補の限定成立を区別する。
