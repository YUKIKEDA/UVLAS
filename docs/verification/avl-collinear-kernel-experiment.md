# AVLコア0の鏡映対称性と直線近傍核：事前切分け仕様

版0.1、2026-10-31。[前回の観察](avl-core-symmetry-observation.json) の原因候補を検査する。以下1〜5節を追加計測・コード・数値実行前に固定する。元の14判定とコア0採用保留を変更しない。

## 1. 問題と追加計測

FW-V01/V02、M4N12／M8N24、α=+1度の既存コア0解4件を使う。力の記録点RROT+XYZREFは、元RVと最下位桁が異なる可能性があり、直線近傍の再現には不十分。元RV・GAM・VINF・VV・WVと、力評価点での元の影響係数WV_GAMを**計算し直さず**書き出す参照専用サブルーチンを追加する。

元の修正コア0版から別ソース・実行体を作る。UDの最後に追加出力を呼ぶだけとし、元の式・コア・配列・解法に変更を加えない。通常FT/FS/FE、既存行／行列／力のファイルが元4件と同じバイト列となることを適格条件とする。追加出力と実行体・ソース・依存のハッシュを保存する。追加ビルド600秒、追加4計算60秒・各20秒、ピーク2GiB、出力64MiB以内。

## 2. ペア核と独立参照

元ソースVORVELCのε=0・Mach=0の有限辺と2本の半無限脚を別成分としてPython float64で再現する。元のPI4INV=0.079577472を共通化し、定数の丸め差を今回の原因と混ぜない。i=jでは有限束縛辺を除外し、2本の脚は維持する。全ペアの和からVVと束縛辺力を再構成し、元のVVと速度尺度1で絶対1e−10以内、力係数の全成分も1e−10以内で再現する。再現できなければ原因確定を保留する。

独立参照は入力float64をDecimal.from_floatで正確に読み、精度80桁で評価した同じ非正則化Biot–Savart式。4件の全ペアを評価する。元floatと参照の差が大きい上位16ペアを各件で160桁でも計算し、80→160差が絶対1e−20または相対1e−20以内を要求する。Decimalをfloat64へ投影した後の一致を160桁精度の証拠にはしない。

## 3. 安定な等価式の候補

有限辺長L、単位接線e、 $q=(p-a)\cdot e$ 、 $r_\perp=p-a-qe$ 、端点距離 $r_a,r_b$ とする。速度のPI4INVを除いた有限辺項は $(e\times r_\perp)I$ 。q<0またはq>Lの場合、差の桁落ちを避ける等価式

$$
I=\frac{L(2q-L)}{r_a r_b\{q r_b+(q-L)r_a\}}
$$

を使う。0≤q≤Lは $I=[q/r_a-(q-L)/r_b]/\|r_\perp\|^2$ 。除外していない有限辺そのものへの接触は失敗とし、速度0で代用しない。延長上で有限辺外なら有限なIと0の外積から0へ戻る。

半無限脚も上流側で $1-x/r=\rho^2/[r(r+x)]$ と有理化できる。有限辺のみの置換と、脚も含む置換を区別し、どちらが差を説明するか保存する。ε>0への拡張やコアモデルの置換は今回行わない。

安定式は各ペアでDecimal参照と絶対1e−10または相対1e−10以下を要求する。単なる横力0化・鏡映平均化・幾何の丸めや投影では直さない。参考として元の影響係数の循環重み付き差を合計し、実際の束縛辺力の差を説明できるか検査する。

## 4. 鏡映・製造極限と診断条件

鏡映はR=diag(1,−1,1)。帯jとN−1−j、同じ弦番号を対応させる。渦の向きを保つため、鏡映した両端は入れ替える。幾何の最大差≤1e−9m、循環の差をmax(|GAM|,1m)で尺度化して≤1e−9を入力の対称性条件とする。

同じ元循環に安定核を適用して得る力で、CYとCnの絶対値≤1e−9を要求する。これは後処理での原因切分けで、参照ソルバーを修正・採用したことを意味しない。元核との差はペアごと、有限辺／脚、線分への射影位置・最短距離・渦／評価点IDを記録する。横方向の破れがどの項に集中するかを確認する。

製造線分a=(0,0,0)、b=(1,0,0)、p=(x,d,0)、x=[−.1,.5,1.1]、d=[1e−2,1e−6,1e−10,1e−14]について有限辺だけを評価する。安定式と80桁参照が同じ絶対／相対条件を満たすこと。延長上d=0のx=−.1/1.1では0、内部x=.5では接触として拒否すること。元式が不正確となる点も保存し、点やしきい値を変更しない。

## 5. 判定と残るゲート

仮説は「ほぼ同一直線上の非自己有限辺の評価で、非正則化核の差の相殺が大きな誤差となり、コア0の横力・ヨーを生む」。再現・Decimal自己比較・安定等価式・力の再構成・鏡映・製造極限を個別判定し、説明できた範囲だけ結論する。有限辺で説明できない誤差を消して合格にしない。

後処理は180秒・512MiB。初回の未達・例外・予算超過を保持する。既存コア0や原本を書き換えない。原因が確認できても、Fortran側の修正候補の独立検証・出力回帰・参照コア監査・全格子系列・固定20帯保存・UVLAS比較は別ゲートとして残す。

## 6. 原因確認後のFortran修正候補：追加実行前の条件

第1〜5節の初回10判定が成立したため、元の非正則化核での桁落ちを修正する**別候補**を追加する。既存の原本・計測・コア0版は変更しない。

VORVELCの有限束縛辺に対し、RCORE=0かつMach=0、かつ射影点が有限線分の外側にある場合だけ第3節の安定等価式を使う。他のコア・Mach・線分内の式、自己辺の除外、半無限脚は元のまま。幾何投影・平均化・しきい値付き速度0化は行わない。元のPI4INVも維持する。端点接触や自由後流の自己誘導一般を解決したとはしない。

同じ差分を、微小コアを残す計測版とコア0版の別コピーに適用する。前回の2翼×2格子×5迎角、各版20条件を実行する。微小コア版は元20条件とFT/FS/FEが同じバイト列であること。0コア修正候補は通常出力の計測前後不変、非貫通残差≤1e−11、元行列との残差差≤1e−12、合力／モーメントの和の係数差≤1e−10、3×NVの力記録を要求する。

全20条件でCY・Cnの絶対値≤1e−9、鏡映する循環差をmax(|GAM|,1)で規格化して≤1e−9とする。元コア0版とのGAM差も同じ尺度で≤1e−10を要求し、循環を変更して横力を調整した結果としない。修正候補の+1度4件の力評価行列は、独立Decimal参照に合格したPython安定有限辺＋元の半無限脚と、各ペア絶対1e−10または相対1e−10以内で一致すること。

原本微小コア対修正0コアの一次揚力／ピッチ傾斜は前回と同じ0.05%以下。修正による抗力・横力・ヨー等の変化を全分量で保存し、一次量だけで採用しない。40計算300秒、各30秒、ピーク2GiB、出力256MiB。ソース差分・コンパイラ・依存ロック・実行体・全出力ハッシュを保存する。

この回帰が成立しても、全格子系列・固定20帯・UVLASとの比較は別途必要。元コア0の不適合を上書きせず、参照は原本／修正候補を識別して使う。
