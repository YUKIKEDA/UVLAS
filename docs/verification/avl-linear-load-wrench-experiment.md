# 一次荷重の切分けと保存再構成候補：事前検証仕様

版0.1、2026-10-31。[固定帯の未達](avl-fixed-band-convergence-experiment.md) の追加切分け。[観測契約](../spanwise-load-observation-contract.md) に従う。以下1〜6節をコード・実行前に固定する。元の点観測・判定・結果は変更しない。

## 1. 追加空力解を使わない一次荷重

既存の2翼×10格子×5迎角の100条件を使用する。Mach=0、固定幾何、ねじり・キャンバ・回転なし、法線x成分0であることを確認する。これによりAは迎角に依存せず、既知流れは $V=\cos\alpha e_x+\sin\alpha e_z$ 、接線方向のeₓに対する循環は0。AVLのGAMをgとすると

$$
g(\alpha)=\sin\alpha\,g_z,\qquad
g_z=\frac{g(+\delta)-g(-\delta)}{2\sin\delta}.
$$

α=0の|g|≤1e−12、|nₓ|≤1e−12、δ=1度／2度で得たg_zの差をmax(|g_z|,1)で尺度化して≤1e−10を要求する。入力条件が成立しない場合にこの縮約を使わない。

有限束縛辺の単位迎角あたりの力/qは

$$
f'_{0,i}=2g_{z,i}\,[e_x\times(b_i-a_i)].
$$

翼面流下脚は+xと平行なので一次の力は0。元の作用点でのO周りモーメント、有限辺への一定力密度の線積分、両者の差を埋める補正偶力をそれぞれ保存する。元Γや実行体・格子は変えない。

## 2. 有限迎角の荷重分解との整合

幾何+yの中央差分モーメントは、一次モーメントにsinδ cosδ/δを掛けた値と絶対1e−10以内で一致すること。これは元の力が循環と速度の積であるという代数的分解の整合検査で、独立な空力理論への一致ではない。

揚力は風軸の回転も含む。力係数の二次x成分を $C_{X2}=[C_X(+\delta)+C_X(-\delta)]/(2\sin^2\delta)$ とすると、中央差分は

$$
C_{L\alpha}(\delta)=\frac{\sin\delta\cos^2\delta}{\delta}C'_{L0}
-\frac{\sin^3\delta}{\delta}C_{X2}.
$$

両δ・全20格子で絶対1e−10以内を求める。直接一次荷重、有限迎角、線積分モーメント、補正偶力の各系列を並べ、前回の差がどの成分に残るか診断する。漸近判定の次数・安定性・予算は前回と同じにして、一次荷重に変えても未達なら保持する。

## 3. 再構成の独立単体照合

製造の支持辺a=(0,−1,0)、b=(2,1,1)、作用点x*=a+.25(b−a)、力f=(1,2,3)。元点と辺中点の差から補正偶力を作る。固定20帯への解析的重なり積分と、帯で切ったパラメータ区間ごとの8点Gauss線積分の力／モーメント差≤1e−12を求める。

全合力・モーメントと元点の差≤1e−12。O変更d=(.3,−.2,.4)、Rz(.4)Ry(−.3)と並進(.3,−.2,.5)に対し帯ごとの共変性≤1e−12。観測軸も変換する。支持の逆順、t=.3での分割で力・偶力密度を保った子2源は同じ帯値になること。

偶力を省く対照はモーメント差>1e−3。非剛体の並進速度u_z=y²に対する**力の仕事だけ**は元点と辺分布で差>1e−3を検出し、一般の構造荷重伝達へ転用できないことを具体化する。独立回転のないANCFへの偶力写像を仮定しない。

支持外、ゼロスパン幅、非有限、境界非単調、退化観測軸は拒否。元点を無断で支持へ投影しない。失敗時に入力・呼出側出力を変更しない。

## 4. 解析分布の合力・一次モーメント

前回と同じ楕円荷重 $l(y)=\sqrt{1-(y/4)^2}$ を使用する。元の各AVL帯の合力と一次モーメントを厳密に与える。合力の原始関数Pは前回どおり、一次モーメントの原始関数は

$$
J(y)=-\frac{16}{3}[1-(y/4)^2]^{3/2}.
$$

支持はy軸上の各実帯、力は+z。元点のyを厳密な荷重重心(J差/P差)として与え、補正偶力を保持する。元の分布の厳密20帯合力・一次モーメントを参照とし、N96で両方の重み付き相対L2≤1%、総和の差≤1e−12を要求する。2翼×4スパン格子、同じ帯幅で評価する。

これは既知の連続荷重に対する再構成精度であり、実際のUVLM圧力分布を復元できたことを意味しない。

## 5. 既存空力荷重の再観測

全100条件の有限束縛辺にspan-wrench-P0-v1を適用する。翼面流下脚は元の点観測を維持する。元の合力／O周りモーメントと係数差≤1e−10。支持適格性、源・帯の被覆、補正偶力の大きさを保存する。元の点観測も併記し、再構成値で上書きしない。

δ=1度／2度の再構成帯揚力の系列を前回と同じ次数条件と参照分布0.5%予算で判定する。合格しても異なる観測量として記録し、元の点測度の21.2%差と未達を消さない。2翼・20格子の直接一次荷重にも同じ再構成を適用する。

独立な8点Gauss線積分の照合は、前回の2翼×2格子（M4N12/M8N24）の+1度で全有限辺について実施する。モーメントには観測契約の偶力を含め、係数差≤1e−11。全格子の線積分を独立に再検証したと称さない。

## 6. 資源・保存・用途

追加空力計算なし。後処理180秒・512MiB。単体・解析分布・空力荷重の結果、式・観測版、元ファイル・コード・依存ハッシュ、時間・ピークを保存する。前回の結果は不変。非漸近、精度未達、例外は保持し、しきい値を緩めない。構造の一般仮想仕事・本体実装・UVLAS対参照比較・J1は別途必要。

## 7. 一次荷重・保存則の実施結果

[コード](../../tools/design-experiments/check_avl_linear_load_wrench.py) と [全結果](avl-linear-load-wrench-result.json) を保存した。初回10判定は7成立・3未達。未達は一次総量、一次帯分布、有限迎角の再構成帯分布の収束条件であり、元結果の `all_criteria_pass=false` を保持する。

| 照合 | 結果 |
|---|---|
| 既存循環のsinα則 | 全20格子で成立、δ=1度／2度のg_z差は尺度化最大2.23e−16 |
| 有限迎角の揚力・モーメント分解 | 40比較、揚力差最大1.78e−15、モーメント差最大2.67e−15 |
| 一次荷重の独立線積分 | 全20格子で事前条件成立 |
| 支持辺＋偶力の保存 | 全100条件、合力／O周りモーメントの係数差最大1.12e−16 |
| 空力源の独立8点Gauss照合 | 2翼×2格子の4件で事前条件成立 |
| 製造源の剛体変換・原点変更・逆順・分割 | 10単体条件が成立、剛体仮想仕事差1.12e−16 |
| 偶力を省く負の対照 | モーメント差1.677を検出 |
| 二次非剛体速度場の力の仕事 | 点と辺分布で差0.25。一般の構造荷重写像へ転用しない根拠 |

製造楕円荷重では元帯の厳密な合力と一次モーメントを入力し、N96の固定20帯の誤差は合力0.0377%、一次モーメント0.0630%。両翼で同じ条件を満たした。これは解析分布に対する候補観測の精度であり、実際の空力圧力場を復元した証拠ではない。

後処理2.453秒、ピーク104,960,000 bytesで予算内。新たな空力計算は行っていない。

## 8. 何が切り分けられ、何が未達か

最細M32N96の直接一次揚力傾斜はFW-V01で4.22141848/rad、FW-V02で4.21528746/rad。一次の幾何+yモーメント傾斜は−4.34488129/rad、−4.33689465/rad。これらはまだ収束済み基準値ではない。

一次荷重でも弦方向の揚力差は増加し、FW-V01で0.00018048→0.00080252→0.00104882。有限迎角の高次項を除いても、前回の非漸近性は残った。迎角の近似だけが原因ではない。

再構成した一次帯揚力のN48→96差はFW-V01で約0.2094%、FW-V02で約0.2097%。元の点分類の約21.2%より大幅に小さい。ただし、スパン系列の差ベクトルの最終余弦は約0.44で、次数も約1.92→1.38と変化した。最終差の小ささだけでは0.5%予算の確定に使わず、元の方向・次数条件を維持して未達とした。

有限迎角の再構成帯分布も同じ問題が残る。点分類の初回結果を再構成値で上書きせず、物理的意味の異なる観測として別に保存した。

## 9. 次の切分け

観測帯境界が元の要素支持を切ることと、空力格子自体の誤差を分けるため、[帯境界適合格子の別仕様](avl-band-aligned-grid-experiment.md) を定めた。同じ物理翼・同じ観測境界・同じ荷重式・同じ収束条件を保ち、格子族だけを別にして評価する。元の未達を消さず、適合格子でも漸近性が得られなければそのまま保持する。
