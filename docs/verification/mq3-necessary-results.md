# M-Q3：辺・厚さ・仕事の必要条件診断結果

2026-11-03。ロードマップ1.1「主シェル選定」で、**14問題と別評価を完了**。必要条件をすべて加えても、歪み柱面2×2の四次一次場の緩和値は約1.78%で、同じB₁の全零次核上の約59.63%との差が残った。辺・厚さ・仕事だけでは現仕様の大きな近似不足を説明できず、次の再設計対象を内部条件の成分へ絞る。

これは主シェルの採用結果ではない。必要条件だけの解は全零次ひずみをゼロにしない。内部条件の一括削除が適切である、という結論にもしていない。

## 何を固定し、何を緩和したか

κ=.4、n=2、歪み0/.2、共変ノルムの仕事あり／なし、計4作用素を前回保存場から再利用した。新たな候補方式や次数は追加していない。r/d自由列252に対し、生のひずみから以下を直接組み立てた。

- N：保持される中立面共変zz成分。
- M：膜の辺接線接線モーメント12行／セル。
- S：せん断辺モーメント36行／セル。厚さ方向の従属行も含めて検査。
- W：物理ひずみ6成分のセル体積平均。仕事ありの方式にだけ追加。

入れ子の核上で、対応する保存済み一次作用素B₁を固定し、四次場の一次ひずみを近似した。cは一次近似で独立未知量として戻し、方向・厚さ二次座標のH¹上限は連続参照の2倍を維持した。

仕事ありの正則柱面では、必要条件NMSWの1.57381%に対し全零次核は32.9983%。歪み柱面では1.78310%に対し59.6333%。それぞれ約21.0倍・33.4倍の差がある。仕事なしでもNMSの1.47266%／1.65200%に対し全零次核は3.72267%／59.6333%で、特に歪み側の差が大きい。

膜辺条件の追加は、Nだけの約0.0231%／0.0312%を約1.457%／1.624%へ増やした。せん断辺と仕事も追加の制限を与えるが、この順序で見た増分は比較的小さい。制約の追加順序に依存するため、これを原因の寄与率や相互作用を除いた割合とは呼ばない。

必要条件だけでも誤差はゼロではない。一方、現方式の全零次条件がさらに強い制限を与えることが確認できた。内部条件は膜・せん断の物理剛性も支えるので、差が大きいことだけで「不要な制約」「除けば実用要素になる」とは判断しない。

## 成立した数値条件と解の限界

全14問題で、9²／11²求積・相対1e−9/10/11の3閾値のrank一致、核残差、二次方向を用いる基底構成、求積間射影、元のM-Q3核の包含、二次再現、四次最適化・球制約・H¹・単調性が基準内だった。包含残差最大5.22e−17、求積間射影差5.66e−13、新旧基底射影差3.99e−14。

必要核は元の核より広く、H¹計量に零方向がある。正則側では目的関数にも零となる非一意方向がNで6、NM/NMSで4、NMSWで2残った。歪み側の目的関数の非一意方向は0。これらを罰則で潰さず分離して解いた。保存解は最適値を与える代表であり、正則側で一意な節点場を得たとは述べない。

H¹上限はrそのものを制限していない。緩和解には全零次場の残差も残るため、低い緩和値を実際の薄肉精度へ読み替えない。各保存解に全零次残差を診断値として記録した。

別評価は明示的な6成分ひずみ行列と厚さモーメントの解析積分から必要行列を作り直した。行列差最大2.61e−16。一般LU・複素厚さの直接解、物理テンソル内積、別VandermondeのH¹評価による一次誤差ノルム差は最大1.17e−15、H¹相対差7.78e−15。幾何・形状関数・固定係数系を共有し、全体SVD・最適化の完全独立再求解ではない。

主計算4.969秒、保存ピーク約196MB、別評価6.125秒。必要行列、核、スペクトル、二次／四次の28保存解、再利用写像とソースのSHA256を保持する。

## 仕事と競合する保存方向

前回の「共変ノルム・仕事なし」の四次最適解を、生の零次ひずみの物理平均6成分へ作用させた。正則柱面ではxx/zzとMandel-xzを中心に最大絶対値約7.83e−8が残る。歪み柱面の同量は約1.12e−16で、既にほぼゼロだった。

節点変位から変位勾配・対称ひずみテンソルを直接作る別積分との差は最大1.35e−16。正則側の小さい非零仕事差と、歪み側で仕事を外しても改善しなかった結果を区別して保存した。この値は荷重誤差率ではなく、仕事条件を緩和する根拠にも使わない。セルごとの全6成分と共有W作用は一次・別評価JSONに残す。
