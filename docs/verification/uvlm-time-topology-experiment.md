# UVLM時刻・渦輪接続・循環履歴の限定試験

版：0.1、2026-10-30。1〜5節は実装・実行前に記載。

## 1. 範囲と入力

[時刻・データ契約](../uvlm-discrete-time-contract.md) を、製品コアから分離したPythonで照合する。2揚力面（2×2と1×3、計7束縛面）と、各2列の非ゼロ初期後流を用いる。第1面は $x\in[0,1],y\in[-0.5,0.5]$ 、第2面は $x\in[0.2,1.2],y\in[1.5,2.5],z=0.5$ m。各面は $R_y(0.05t)$ の既知回転とZ並進 $0.02t$ mを与える。渦格子と荷重面を同じ平板格子に置く比較であり、製品の四分の一弦配置の選定ではない。

後流は指定一様移流 $(8,0,0)$ m/s。初期の自由列は時刻−0.02、−0.04の後縁を移流して作る。循環の製造履歴は面・弦・スパン順の通番 $p=0..6$ について $\gamma_p(t)=1+0.1p+(0.3+0.02p)t+(0.2+0.01p)t^2$ m²/s、初期過去時刻−0.02。受理刻みは0.02、0.013、0.027 s。製造履歴と初期後流は検証入力であり、定常平衡と呼ばない。

## 2. カーネルと循環解

非特異有限渦線の解析式をBiot–Savartの64点Gauss線積分と照合する。REF-V01は絶対 $10^{-12}$ m/s、離れた3評価点での2渦輪は $10^{-10}$ m/s以内。正則化・自己誘導・近接の採用試験ではない。

全7コロケーション点で全束縛・後流渦輪の法線影響を組み立てる。既知の製造循環を満たす法線右辺を作り、線形求解で回復する。循環誤差・尺度付き非貫通残差 $\le10^{-12}$ 。物理的な一様流・翼運動だけによる空力参照ではなく、行列・時刻・相互作用組立の製造右辺試験である。

追加の組立照合を実行前に定義：製造右辺にも同じ解析行列を使う自己確認を避けるため、全影響係数を64点線積分で別に作る。係数の最大差 $\le10^{-10}$ m⁻¹、数値線積分側の行列から作った右辺による循環回復も上記 $10^{-12}$ 基準で判定する。面間影響を落としたブロック対角行列を負の対照とし、循環差 $>10^{-12}$ を検出する。過去の物理空力参照未完了という区分は変更しない。

## 3. 時刻・接続・分配の基準

- 面境界の整数接続で $D_1D_2=0$ を厳密確認。後縁+y辺の誘導強度が旧束縛−新束縛と一致し、定常循環なら共有辺が消える。
- 新後流列の循環は旧受理束縛循環、旧列は循環と物質IDを保って一列移動。最終各面5列、全25後流面。新しい付着境界と切り離した物質列のIDを分ける。
- BDF2不等刻みの二次製造履歴微分が絶対 $10^{-12}$ m²/s²以内。BDF1の二次履歴で生じる既知の誤差 $-c_ph$ も照合。冷始動の線形履歴はBDF1で厳密、履歴欠落でBDF2を要求する入力は拒否する。
- 辺の処方相対速度 $(8+0.1x,0.2y,0.05z)$ m/s、密度1.2 kg/m³に対し、共有辺集約と面ごとの辺力和を照合。後縁の構造力は除外するが誘導辺は保持する。非定常項は物理+法線で加える。これは処方速度に対する荷重分配試験で、自己誘導を含む物理空力荷重の検証ではない。
- 辺力の1/2分配、非定常面力の1/4分配で合力・モーメント・剛体仮想変位仕事を絶対 $10^{-10}$ N、N·m、J以内で保持する。後縁力を除外することと、面力分配時の後縁頂点を削除することを混同しない。

## 4. 取引と負の対照

各試行で5回の再評価を行い、同じ確定状態から同じ候補後流を作る。反復で受理状態を変えず、新列の二重追加・旧自由列の二重移流を起こさない。試行棄却後に再試行し、3ステップ連続経路との一致、二重確定拒否、2ステップ後のJSON往復再開と最終状態一致を確認する。

負の対照：新後流へ新束縛循環を渡す、BDF2へ固定刻み係数を使う、法線反転を非定常力だけへ混入、面力分配で後縁頂点を捨てる、反復ごとに後流前進、過去循環欠落を検出する。差が対応する事前許容差を超えることを確認する。

## 5. 停止・保存・用途

120秒・1 GiB。事前閾値の緩和はしない。ソース・結果と参照URLを保存する。全ての限定判定が成立しても、自由後流のコア・自己誘導、物理揚抗力、曲面格子、ANCF強連成、二次方式、フラッタ、製品実装の採用証拠にはしない。構造と循環・後流を含む取引の次段階へ進むための接続・時間履歴の証拠とする。

## 6. 実施結果

[結果JSON](uvlm-time-topology-result.json) の20判定が成立した。2揚力面の全束縛・全後流の影響を7×7束縛行列と可変長後流行列に組み立てた。全係数を別の64点線積分と照合し、最大差は $3.11\times10^{-15}$ m⁻¹。数値線積分側の行列から作った製造右辺による循環回復誤差は最大 $2.00\times10^{-15}$ 、尺度付き非貫通残差は $2.90\times10^{-16}$ 以下。

| 対象 | 結果 |
|---|---|
| 接続 | 整数 $D_1D_2=0$ 、後縁の旧−新循環差、定常時の相殺が成立 |
| 物質後流 | 独立な放出時刻と一様移流の式に対する位置差 $2.23\times10^{-16}$ m以下、循環差 $2.00\times10^{-15}$ m²/s以下 |
| 後流列 | 各面2→3→4→5列、最終25面。付着境界と物質列IDを分離し、放出区間も保存 |
| 不等刻みBDF2 | 二次履歴の微分誤差最大 $1.79\times10^{-13}$ m²/s² |
| BDF1 | 二次履歴の既知誤差と一致。冷始動の線形履歴も事前基準内 |
| 荷重分配 | 合力・モーメント・剛体仮想仕事の差が各 $1.07\times10^{-14}$ 以下（各単位は3節） |
| 試行 | 同じ親から5回評価して候補が一致、確定状態不変。最後の候補だけを確定し二重確定拒否 |
| 再開 | 2ステップ後の循環二時刻・実刻み・物質後流をJSON往復し、3ステップ連続経路の最終状態ハッシュと一致 |

有限渦線REF-V01の一点は解析的期待値と事前基準内で一致し、離れた点での渦輪は64点線積分と事前基準内で一致した。特異点・コア・自己誘導の試験へ一般化しない。

### 負の対照

- 面間影響を落とした行列では、数値線積分側の製造右辺に対する循環差約0.0159〜0.0185 m²/sを検出。
- 新後流へ新束縛循環を渡すと、正しい旧循環との差は各ステップで約0.00564〜0.01199 m²/s。
- 2段目の不等刻みへ固定刻みBDF2係数を使うと、微分差約0.11357 m²/s²。
- 非定常力だけの法線反転で合力差約1.80〜1.89 N。
- 面力の1/4分配で後縁頂点を捨てると、合力差約0.354〜0.371 N。これは本比較の平面中心力の分配規約に対する反例であり、別の格子・荷重定義を持つ外部コードの不具合と断定したものではない。
- 同じ旧列を反復ごとに5回移流する誤処理は、1回移流との差0.864 mを検出。
- 循環履歴を欠いたBDF2要求を拒否。

## 7. 再実行・採用前に残ること

```powershell
build/design-fem-env/Scripts/python.exe tools/design-experiments/check_uvlm_time_topology.py
```

結果にソースSHA-256、全ケースの指標、最終循環・過去値・刻み、全後流の座標・循環・物質ID・放出区間を保存した。所要約0.8秒。処方速度・製造右辺・小規模格子の参考値であり、実務性能の証拠ではない。

この試験では循環は製造右辺、後流は一様指定移流、辺力は処方相対速度による。ANCFの運動方程式と空力を反復して解いた試験ではなく、物理的揚抗力や空力応答の次数も検証していない。B1の時刻表とB2の微分演算子を別々に確認したもので、自由後流・強連成・全体二次の採用判断にはしない。

次はAE-03の渦コア・自己項・近接と、AE-04の後縁・荷重点・循環符号を同じ渦格子候補へ閉じる。非特異点の正解だけで近接を通さず、曲面・キャンバを含む物理荷重の独立参照と格子・刻み収束を事前定義する。構造との一括確定はデータ契約まで具体化した段階であり、J1全体は未選定。
