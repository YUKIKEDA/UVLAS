# R1：保存した有限厚さ解の誤差と仕事の分解

2026-11-04。[現行計画](../roadmap.md)のR1。現MMS-1の不採用を維持したまま、R2が変更する必要条件を絞る。新候補・格子・厚さ・重み・再求解は追加しない。

対象は保存主結果のκ=.4、n4、(amp,h)=(0,.01),(0,.0001),(.2,.01)の3条件。全3場を再評価し、五次・指数を主診断、四次を数値対照とする。元の13²×7求積・固定応力空間・同じ係数場を使い、解と元ソースのハッシュを確認する。

残差ひずみをe=B_hu−E*とする。MMS-1射影から、厚さ変動成分H(e)、混合平均応力の平方根成分L(e)、平均応力の点値M(e)を得る。誤差二乗は次の4つの非負項へ分ける。

$$
Q_H=\int H(e):C H(e)\,dV,\quad Q_M=\|L(e)\|^2,
\quad Q_{TB}=j_{TB}(u,u),\quad Q_V=j_V(u,u).
$$

Q_H+Q_M+Q_TB+Q_Vを同じ参照ノルムで正規化し、元の点仕事による誤差と照合する。各項をh³で除した値、参照正規化値、全誤差中の比率を保持する。元の位置誤差は別の観測量として引用し、エネルギー4項へ分解したとはしない。

各項の半勾配を、Bᵀ(w C H(e))、Bᵀ(w M(e))、面ジャンプの転置から計算する。共有面基底を正しく変換し、内部全座標と固定端を除く共有全座標へ組み立てる。列尺度は元の完全平方根作用素のものを用い、各項のノルム、項間の内積／角度、和の原停留指標を記録する。

同じ固定端・共有を満たす決定的な仮想変位2組で、点ひずみの分解から直接評価した各仕事と勾配の内積を照合する。全応力S(e)から直接組み立てた勾配とも比較する。圧縮QRの残差を原因診断の基準へ流用しない。

検査は、再構成誤差／元誤差差≤1e−8、原停留≤1e−8、点仕事と勾配仕事の尺度付き差≤1e−8、勾配和と全応力勾配の尺度付き差≤1e−8、同じ参照からのQ合計と∫e:S(e)の一致≤1e−8。数値ゼロ近傍の成分は角度を解釈しない。保存時の元停留値との差と、初回圧縮系の既知残差は区別する。

1条件300秒・系列1200秒・ピーク2GiBを診断の資源枠とする。既存180秒の求解系列を再実行するものではない。各セルの再準備・評価時間を保存する。未達は保持し、閾値を変えず原因を分ける。

判断は、(a)平均応力の拘束と曲げ側の釣合い、(b)面安定化と体積仕事の釣合い、(c)厚さ変動側の近似不足を区別する。エネルギー比率だけで因果関係や独立な主因を断定しない。残る成分間の釣合いを説明できた場合に、R2で変える作用素／接続と保持すべき仕事を指定する。説明できなければ足りない識別条件を明記し、新候補コードへ進まない。面項や平均応力仕事を削除したモデルを採用解として解くことはしない。
