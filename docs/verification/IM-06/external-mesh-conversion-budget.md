# 元面の位置と法線を Case の変換予算で照合

<!-- verification: FD-03 IO4-03 IO4-04 R-05 -->

認証済みの元面を Sidecar のチャートで準備し、全域の位置差と単位法線の差の上界を変換予算と照合する。Gmsh は Case の `fit`、Nastran は対応表の `conversion` を使う。両者の距離は Case の長さ単位から SI に厳密変換する。結果には元面、元節点順、許容値、変換観測の ID を保持する。観測量の独立評価と実務受入は [R-05 の条件](../../specs/foundation/external-mesh-sidecar-contract.md)に従う。

元の二つの三角形は平坦な単位正方形を覆う。対応する PG の高さは $f(s,t)=(s-s^2)/10$ m で、四隅は元面と一致する。両面の内部を通る $s=1/2$ で位置差は 1/40 m になる。Case の 26 mm を SI の 13/500 m として保持し、各面の上界が 1/40 m 以上でその予算内に収まることを確かめた。24 mm の指定は、元面の ID を示して認定不成立を返した。

同じ曲面の $s=0$ では、PG の単位法線の $x$ 成分の絶対値は $1/\sqrt{101}$ である。元の法線の $x$ 成分は零なので、法線差の予算 0.01 で認定は成立しない。Nastran ではこの予算だけを詰め、距離予算を保持した負対照を確認した。

MSVC 19.51 と GCC 14.2 の Release で、統合コミット `5036c935` の `io.reference_input`、`io.external_planar_pg`、`io.nastran_laminate_cards` が各3件通った。元ファイルを使う対応表試験は546アサーション、Nastran積層の試験は8ケース710アサーションだった。

GCC の隔離コピーで、計算した面の上界が許容値を超えても拒否しない変異を入れた。距離と法線の負対照が各1件失敗し、元の処理に戻すと対応表試験の546アサーションが再び通った。
