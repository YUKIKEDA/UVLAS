# IM-06 二つのメッシュ形式で同じ平面 Shell を照合する

一つの SI Case に、同じ Shell を指す Nastran と Gmsh の実ファイルと対応表を用意した。四辺形の元要素 ID は両形式とも 701、元節点 ID は 10、20、40、99。Gmsh の物理グループは (2, 7)、Nastran の物性カードは PSHELL 90 である。Case の識別を照合し、各参照ファイルを SHA-256 で認証した。ファイルを削除してから所有された参照グラフだけで二つの準備入口を呼んだ。

## 独立式と比較した観測

局所軸を世界の $+Y,+Z,+X$ に対応させ、原点を $(1,2,3)$ m とした。平板は一辺 2 m、厚さ $1/4$ m。その位置は、Case の材料座標を使うと次の式になる。

$$
P(s,t,\zeta)=(1+\zeta/8,\ 2+2s,\ 3+2t)\ \mathrm{m}
$$

元四辺形の全節点でこの式の中心面を照合した。どちらも同じ四隅を持つ双線形写像のため、中心面は面内全域で一致する。Gmsh の `fit` は位置差と法線弦長に上界 0 を返し、Nastran は同一チャート上の厳密一致を認定した。明示厚さは、共通細分で照合した無次元のチャート面積の合計が 1 であることと、SI の $1/4$ m が厳密に一致することを両形式で確認した。

体積と面積の比較には、Case が準備した各チャート三角形の頂点を読む。頂点から内点の座標と符号付き面積を独立に求め、全積分セルの位置・法線・測度と照合した。体積では $+X$ の法線と正規化厚さ座標 $\zeta$ に対する Jacobian $1/2$ m³ を確認した。層内の積分深さは $\eta\in[0,1]$ で、$\zeta=2\eta-1$ とおくと Jacobian は 1 m³ になる。面積・体積とも三角形内で一定なので、測度に標準三角形の面積 $1/2$ を掛けて足し、上面の面積 4 m²、体積 1 m³ を得た。下面の外向きは $-X$ である。

## 元欄の不一致と再準備

Case を保持したまま、Gmsh では物理グループの厚さを 250 mm から 500 mm に、Nastran では PSHELL の厚さを 0.25 m から 0.5 m に変えた。両方が元面 701 と Case 三角形を示して失敗した。Gmsh は元の `full_thickness` 宣言、Nastran は PSHELL 90 の厚さ欄のバイト位置・行・列まで照合した。続けて正常版を同じ認証済み Case と作業領域で再準備し、元と同じ PG の識別を得た。

この試験が扱うのは平面幾何・明示厚さ・測度である。材料の応答、質量特性、剛体仕事、固有モード、`supplied` の参照ファイルには、それぞれの受入検証が必要となる。

## 検証に使った構成

対象ソースは `8477e6701b1757470a4c46e696f079e94c03ed65`。Windows 11 の MSVC 19.51.36260 Debug・Release と、Ubuntu 24.04 の GCC 14.2.0 Debug（ASan・UBSan）で、`io.external_shell_cross_format`、`io.gmsh_shell_reference_set`、`io.external_planar_pg`、`io.external_pg_regional_thickness` が各4件合格した。新規試験は各構成で705アサーションだった。変更した翻訳単位の clang-tidy と clang-format 21.1.2 も通過した。
