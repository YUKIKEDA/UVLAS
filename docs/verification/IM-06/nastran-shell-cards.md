# Nastran シェルの節点順とプロパティ参照を検査する

SHA-256 照合済みの Nastran デッキから、CTRIA3 と CQUAD4 の節点順、シェルプロパティ参照、材料軸、オフセット、節点ごとの厚さ指定を型付きで取り出す。結果は元のデッキを所有し、各欄の原文を物理行・欄の位置からたどれる。[IO4-03](../../specs/foundation/io-execution-adoption-specification.md#io4-03-nastran)

## 接続と参照を照合する

CTRIA3 は3節点、CQUAD4 は4節点をカードの順序で保持する。一つの要素内の節点番号はすべて異なり、各番号に GRID が必要である。EID は 1 以上 100,000,000 未満で、採用カードの CBEAM、CONM2、RBE2 と同じ名前空間で重複を検査する。EID は外部シェルの識別子として保持する。

PID の空欄は EID を参照する。参照先には PSHELL または PCOMP が必要で、二種類の間でも PID を一意にする。該当する番号のプロパティが PBEAM にしかなければ、シェルの参照先として拒否する。PBEAM の本文と PSHELL・PCOMP の物性欄は元のカードから後段が読める。

## 材料軸と厚さ指定を保つ

THETA の実数欄は度の正確な十進値として読み、整数欄は MCID として照合する。空欄の既定 THETA、明示的な実数 0.0、基本系を指す整数 0 を区別する。ZOFFS は符号付きの十進値で保持する。

両カードとも継続行の第3欄が TFLAG、第4欄以降が T1 からの厚さ指定である。空欄または 0 は絶対厚さ、1 は基準厚さに対する比率を表す。明示した絶対厚さは非負とし、すべての隅に明示した値が零なら拒否する。明示した比率は正とする。空欄の隅は後段で参照元の厚さを照合できるように残す。シェル面の幾何、材料・積層の物性、参照厚さ・単位の決定は別の段階で行う。[MSC Nastran 2022.1 Quick Reference Guide、pp.1609–1611・1667–1669・2764–2768・2901–2902](https://help-be.hexagonmi.com/bundle/MSC_Nastran_2022.1_Quick_Reference_Guide/raw/resource/enus/MSC_Nastran_2022.1_Quick_Reference_Guide.pdf)

## 検証

同じスナップショットから字句、数値、座標、シェルの順で試験し、small・large・free の欄と継続から節点順・参照先・元の欄位置を照合した。重複 EID・PID・節点、参照先の欠落と種類違い、予約欄、範囲外の ID と厚さ欄を拒否した。成功時に元のバイト列を移し、失敗時に呼出し元の所有を保つことも検査した。要素とプロパティの件数、作業量、確保量の上限と取消を試験した。

Windows の MSVC 19.51.36260.0 Debug と Linux の GCC 14.2.0 Debug（ASan・UBSan）で、Nastran の字句・数値・座標・シェルの対象4件がそれぞれ通過した。シェルカードは各4ケース・241アサーション。Linux の clang-tidy 21.1.1 で本体の通常構成・確保計測構成と試験を検査した。
