# 偏心CONM2とCase剛体質量の参照照合

認証済みの元デッキと対応表から、同じ平面シェルの中心面にある元GRIDとCase材料点を特定する。Caseの取付フレームの原点をこの点に合わせ、右手直交の回転 $R$ を厳密に検査する。[剛体慣性の式](../../specs/structure/connection-adopted-specification.md#5-粒子偏心剛体と慣性)に従い、取付点 $p$ と局所重心位置 $c$ から $p+Rc$ を、重心慣性 $I_c$ から基本軸の $R I_c R^\mathsf T$ を有理演算で求める。

CID 0の位置欄は元GRIDからの偏心、CID -1の位置欄は基本座標系での絶対位置として照合する。元の十進字句をSIへ変換した値と認定済みのGRID座標を使うので、0.1 mのようなBinary64で割り切れない位置も比較できる。慣性は元の重心と同じ点で比べ、Nastranの慣性乗積から変換済みの符号を使う。認定結果は、元カード・取付点の出典、質量、重心位置、重心慣性を所有する。

## 実デッキで確かめたこと

CONM2 906の2 kgを、Caseのz軸まわりに90度回転したフレームで照合した。局所の偏心 $(0.125,0.25,0.375)\,\mathrm{m}$ は基本座標系で $(-0.25,0.125,0.375)\,\mathrm{m}$ になる。対照では元GRIDと取付点を0.1 m上げ、CID -1の絶対重心高さ0.475 mを受理した。重心慣性は、行順の下三角 $(4,-0.25,3,-0.75,0.5,5)\,\mathrm{kg\,m^2}$ と六成分すべてを照合した。取付フレーム位置、偏心の符号、慣性乗積をそれぞれ変えると、対応する元カード欄を示して拒否した。 [検証コード](../../../tests/io/reference_input_test.cpp)

GCC 14とMSVC 19.52のReleaseで `io.reference_input` と `io.nastran_shell_cards` が各2件通った。粒子質量、CONM2の慣性変換、外部面対応の既存例も検証した。

ここで検証したのは参照配置の物理量の同値性である。運動エネルギー、質量台帳の組立て、実変位とモードは構造の実行経路で検証する。 [外部メッシュ対応表](../../specs/foundation/external-mesh-sidecar-contract.md)・[粒子質量の検証](nastran-particle-mass.md)
