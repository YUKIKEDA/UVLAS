# GRID と CORD2 の識別子と参照系を検査する

SHA-256 照合済みの Nastran デッキから、GRID と CORD2R／CORD2C／CORD2S の型付きレコードを作る。結果は元のデッキ、物理行と欄、正確な十進値を所有する。座標系は参照先を先に処理できる順序で取り出せる。[IO4-03](../../specs/foundation/io-execution-adoption-specification.md#io4-03-nastran)

## 位置系、変位系、定義元の系を区別する

GRID の点番号は通常の MSC Nastran 2022.1 の範囲である 1 以上 100,000,000 未満とする。位置の CP と変位の CD を別に保持し、GRDSET の指定がない場合はそれぞれ空欄または明示 0 を基本直交系とする。X1–X3 の空欄は 0.0 として読み、元欄の有無も保持する。PS は外部の成分番号の集合として記録する。流体点の CD=-1 と非零の SEID は未対応として返す。

CORD2 は正の CID と、参照系 RID 内で定義された A・B・C 各3成分を保持する。三点の欄に値が必要であり、RID の空欄と 0 は基本系を指す。CID 0 の定義は拒否する。直交・円筒・球の区別と元の字句は保持し、後段へ渡す。三点からの物理基底構築、座標・ベクトル変換、単位は後続の範囲である。[MSC Nastran 2022.1 Quick Reference Guide、pp.1578–1583・2078–2080](https://help-be.hexagonmi.com/bundle/MSC_Nastran_2022.1_Quick_Reference_Guide/raw/resource/enus/MSC_Nastran_2022.1_Quick_Reference_Guide.pdf)

## 参照先を確認してから結果を返す

点と座標系の番号をそれぞれの名前空間で照合する。座標系の重複は CORD2 の種類をまたいで検出する。CP・CD・RID の参照先がなければ元の欄で失敗を返す。循環も拒否し、既に検査した親系を経由する場合も基本系までの深さ全体を上限に含める。

採用済みの PSHELL などの構造カードは、後段で扱えるよう元デッキに残す。GRID の既定値や座標系の定義に影響する GRDSET や CORD1 系を含むデッキは未対応として拒否する。成功で元デッキの所有を移し、失敗した呼出しでは元の字句データを保持する。

試験では、実際のスナップショットから三種類の CORD2 を読み、先に宣言した子の参照を後続の親に結び付けた。大きい ID、D 指数と省略 E、負の零、明示した基本系と空欄を照合した。未解決参照、重複、循環、宣言順を変えた深さ上限、確保と作業の上限、取消も検査した。

Windows の MSVC 19.51.36260.0 Debug と Linux の GCC 14.2.0 Debug（ASan・UBSan）で、Nastran の字句・数値・座標カードの対象3件がそれぞれ通過した。座標カードは各5ケース・233アサーション。Linux の clang-tidy 21.1.1 で本体の通常構成・確保計測構成と試験を検査した。
