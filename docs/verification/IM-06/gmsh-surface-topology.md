# Gmsh の明示面集合の位相を検査する

取得時に SHA-256 を照合し、MSH 4.1 ASCII として読んだメッシュを入力とする。呼出し側が選んだ三角形・四辺形のタグを順に照合する。出力は元メッシュの来歴、面のタグと所属、元の節点順、向き付きの辺と隣接関係を所有する。[IO4-04](../../specs/foundation/io-execution-adoption-specification.md#io4-04-gmshと外部面からの参照構築)・[Gmsh メッシュ入力契約](../../specs/foundation/gmsh-mesh-input-contract.md)

## 共有辺と各頂点まわりの接続を検査する

未定義の面タグ、面以外の要素、選択の重複、同一面内で繰り返す節点を拒否する。節点順を巡回または反転して一致する面は重複とする。辺を二つの面が共有する場合は、各面の節点順が逆方向に辺をたどることを要求する。三つ以上の面が接する辺と、同じ向きで共有する辺は拒否する。

頂点では、その頂点を含む共有辺を介して面の角を結ぶ。一つの頂点に集まる角がこの関係でつながることを要求する。辺に接する面が二つ以下でも、ひとつの頂点のまわりに互いにつながらない面の並びがある場合は拒否する。

## 連結成分と自由境界を返す

共有辺でつながる面を同じ連結成分とし、最初に現れる選択面の順に成分を返す。反対側の面がない辺は自由境界として保持する。各辺の `next` は同じ面の輪郭上にある次の辺を指す。明示選択が空なら、面と連結成分が空の結果を返す。すべての照合に元の整数タグを使うため、座標が同じでもタグの異なる節点は別の節点として残る。

面、向き付きの辺、自由境界、連結成分と、確保量・作業量の上限を検査する。成功・失敗・取消の後も入力メッシュを再利用できる。部材の物理的な割当、自己交差、曲面・厚さと共有面の適格性は後段で扱う。

## 検証

MSH を取得・照合してから位相検査へ渡し、疎なタグを持つ三角形と四辺形の共有辺、自由境界、選択順と入り交じる連結成分を照合した。閉曲面、部分選択、同位置の別タグ、辺でつながっていても頂点まわりに分断がある面を試験した。未定義のタグ、同じ面または節点の重複、辺の向きと非多様体、各資源上限と取消の失敗を確認した。

Windows の MSVC 19.51.36260.0 Debug と Linux の GCC 14.2.0 Debug（ASan・UBSan）で、Gmsh の対象2件がそれぞれ通過した。位相検査は各5ケース・165アサーション。Linux の clang-tidy 21.1.1 で本体の通常構成・確保計測構成と試験を検査した。
