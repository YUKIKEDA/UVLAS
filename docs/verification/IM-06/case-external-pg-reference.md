# Case から外部面を照合する PG 参照を準備

<!-- verification: FD-03 IO4-01 IO4-03 IO4-04 R-05 -->

認証済み対応表が指す Shell と同じ SI Case から、所有 PG 参照を準備する。平面の厳密照合と曲面の変換予算の両方がこの参照を使う。成功時にだけ参照と照合結果を一緒に返し、後続は両方を読取り専用で参照できる。

実ファイルの統合試験では、手で構成した PG を Case の読取りから準備した PG に置き換えた。曲面の変換予算は Case の mm から厳密に SI へ変換し、面の内点差と法線差の負対照を維持した。平面側は元面の対応と一様全厚、PSHELL・PCOMP の明示物性を照合した。各結果が参照する PG の識別子は、同時に返された所有参照の識別子と一致した。

Gmsh の元ファイルと対応表を固定し、Case の原点だけを 50 mm 移動すると、物性比較に入る前に幾何の不一致を返した。GCC の隔離コピーで全座標成分に原点の第1成分を使う変異を入れると、この負対照が失敗した。元に戻すと実ファイル試験が再び通った。

Gmsh の全厚は元の物理グループ全域に適用する。同じグループの別行へ宣言を伝え、矛盾する値は元宣言の位置を示して拒否する。物理グループに明示厚さがある元面を Case の厚さ三角形と共通細分し、正面積片の全頂点で差を厳密に照合した。隣接する未宣言領域と辺だけで接する場合は成功し、同じ面が変厚領域へ正面積で入る場合は失敗した。元面の順序反転でも比較領域は一致した。

統合コミット `1a64bbe0` で、MSVC と GCC 14 の Release は元面、区分厚さ、認証済み参照、Nastran 積層の対象4件ずつが通った。MSVC Debug でも区分厚さと認証済み参照の2件が通った。
