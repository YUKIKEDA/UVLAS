# 観測CSVの検証

対象は [IO4-05の観測CSV](../../specs/foundation/observation-csv-contract.md) とN4-02の確保上限。
認定済み観測の内部シリアライザーを検証した。
物理回復、CLIでのファイル公開、実ケースの結果認定はIM06-0の実行経路で検証する。

| 確認 | 独立な参照と結果 |
|---|---|
| CSVの形式と観測の識別 | 期待するバイト列を手書きし、ヘッダー、UTF-8、引用符、改行、最大の `uint64_t`、層界面の上下、確定番号と区間番号を一致で比較した。欠けた低位語の空欄と負のゼロも比較した |
| 浮動小数点語の保持 | 最大の有限binary64と最小の非正規化数を別々の欄から読み戻し、時刻、中心、誤差半径を完全一致で比較した |
| 不正値と確保 | 重複成分、順序違反、値欠落、観測成分のない試料、層と面側の不一致、不正UTF-8、非有限値、負の半径を拒否した。上限が必要量と等しければ通り、件数、文字列、出力、共有確保量の上限をそれぞれ一つ下げると失敗した。開始前の中断では確保量ゼロを照合した |
| 負対照 | GCC 14の別のチェックアウトで観測IDを32ビットへ狭める変異を入れた。手書き参照との差を1アサーションが検出した。ソースを戻して、同じ試験が通ることを確認した |

Windows MSVC 14.51 Release、Linux GCC 14.2 Releaseで `ctest -R '^io\.(observation_csv|reference_input)$'` を実行した。
観測CSVと、共通UTF-8検査を使う既存の参照入力試験が両環境で通過した。
観測CSVは5ケースで120アサーション。数値の許容差はゼロとした。
Windowsのコンパイル設定で、シリアライザー、参照入力、観測CSV試験の3翻訳単位にclang-tidy 21.1.1を実行し、エラーはなかった。
