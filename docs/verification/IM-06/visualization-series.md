# 確定した可視化標本を層側・区間ごとに出力する

計算側で適格とした binary64 の標本から、VTU と PVD の UTF-8 バイト列を生成する。層界面では座標が一致する両側を別の VTU に保存する。供給された応力が両側で異なるときも、それぞれの値を取り出せる。[IO4-05](../../specs/foundation/io-execution-adoption-specification.md#io4-05-結果) [成分と測度の定義](../../specs/foundation/case-schema-fields.md)

## 同じ界面でも層の側を保つ

部材・層・側ごとに可視化用の三角格子を受け取る。現配置を格子の座標とし、参照配置、両配置の法線と物理厚さ、層内の厚さ方向の位置も保持する。層区間の下端・上端はそれぞれ0・1、内部はその間として検査する。この三角形は標本を表示するための接続であり、PG の未知量とは独立している。

供給済みのテンソルには測度、基底、単位を配列名に付ける。応力は合計・弾性・粘性の別も保持する。対称テンソルの6成分は VTK の9成分へ展開し、第一 PK は現在の力成分を行、参照面法線成分を列とする9成分をそのまま保存する。供給されなかった応力・ひずみの配列は出力しない。[VTK XML 形式](https://docs.vtk.org/en/v9.6.1/vtk_file_formats/vtkxml_file_format.html)

## 区間が変わっても同じ物理時刻を参照できる

PVD は区間ごとに一つ生成し、同じ時刻の VTU を部材・層・側ごとの part として参照する。ParaView は PVD の時刻を binary64 として読むため、再始動で同じ時刻を通る区間には別の PVD を割り当てる。各 VTU には物理時刻、確定番号、区間番号を入れる。識別子は UInt64 のまま保持する。[ParaView の PVD 読み取り実装](https://raw.githubusercontent.com/Kitware/ParaView/v6.1.0/VTKExtensions/IOCore/vtkPVDReader.cxx)

二層・三時点の試験で、同一座標の両側に異なる応力を与え、同じ時刻を再び通る二つ目の区間も含めた。入力と資源計画の破棄後に全出力を照合した。時刻・識別子・接続・測度の不整合、非有限値、時点数・ファイル件数・点数・三角形数・出力容量の超過、取消では出力を返さないことも確かめた。

Windows の MSVC 19.51.36260.0 Debug と Linux の GCC 14.2.0 Debug（ASan・UBSan）で、同じ3ケース・230アサーションが通過した。生成した2本の PVD と6本の VTU を Python 標準の ElementTree で読み直し、全参照、時刻、最大の UInt64 識別子、両側の座標と別々の応力を照合した。Linux の clang-tidy 21.1.1 で実装と試験を検査した。

この入口は、供給済み標本から所有バイトを作る範囲を検証した。物理モデルからの格子生成、未認定の応力や梁の局所回復、高精度からの射影、CLI での保存は後段が担う。
