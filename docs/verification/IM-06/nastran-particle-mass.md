# Nastran の粒子質量を同じ Case の取付点で照合する

認証済みの一つの CONM2 を、対応表で指定した Case の `Mass.particle` と比較する。照合する値は SI 質量、元 GRID と Case の材料点、重心と GRID の一致、零の重心慣性である。二つの元カードが同じ Case 質量を指した場合は、一対一の証拠を作れないため拒否する。

材料点は対応表と同じ Case の認定済み平面シェルに属し、中心面の元 GRID 角を指定する。元 GRID タグとチャート座標は認定済みの角から比較する。オフセットで角を移した面では、移動前の元 GRID が同じ位置であることも厳密に確認する。この比較には元 GRID の厳密な有理座標を使う。元カードを区間へ投影したときに丸め幅が生じる座標でも、対応を証明できる。

照合結果は、デッキと対応表の指紋、元 EID と GRID、Case のシェル、認定済み PG の識別子、元面と質量を所有する。位置や質量が異なる場合は元 CONM2 の該当欄を返す。重心の偏心を零と証明できない場合は、区間が零から離れていれば不一致、零を含む幅が残れば精度未解決とする。

## 実デッキで確かめたこと

実デッキの CONM2 906、GRID 10 を Case のシェル1の原点側の角へ対応付け、2 kg、元面701と二つの入力指紋を照合した。デッキと Case を同じ量だけ 0.1 m 移した対照も受理した。Case 質量を3 kgに変えた入力、Case 材料点を別の角へ移した入力、元重心だけを0.125 m偏心させた入力は、質量・GRID・偏心の元欄をそれぞれ示して拒否した。参照走査の上限が零の試行では、確保課金ゼロで拒否した。

固定ソース `b74bd8928b743dcc911299ba8bc24d59c95090fa` の変更した実装2ファイルと試験1ファイルは、実行ソース `fc95c71ce49d8a0dce5c7196e9f8aec6fe2d4e17` の同じファイルと一致する。MSVC Release と GCC 14 Release で `io.reference_input` と `io.nastran_shell_cards` が各2件通った。 [実デッキ試験](../../../tests/io/reference_input_test.cpp)・[元の質量と慣性の検証](nastran-basic-mass-geometry.md)

この記録は同じ取付点における粒子質量の照合を扱う。偏心剛体のフレーム、重心慣性と運動エネルギー、全体モデルの質量台帳と実運動は、対応する構造準備で認定する。
