# 終了状態と来歴を所有する結果出力

[IO4-05](../../specs/foundation/io-execution-adoption-specification.md#io4-05-結果) に沿って、内部の終了状態から `status.json` と `provenance.json` の UTF-8 バイト列を生成する。状態と来歴を一つのバッファーで所有し、`status.json` は来歴の正確なバイト列を SHA-256 で参照する。

終了コード0には成功だけを対応させる。失敗では呼出し元が処理の文脈に応じて採用済みの終了区分を選び、元の `Failure` の原因・処理・診断を保持する。取消と資源超過にはそれぞれ130と5を対応させる。同じ `Nonfinite` でも、入力と評価のどちらで起きたかによって終了区分が異なる。

実際の確定状態を渡すと、状態 ID、モデル世代、数値世代、モデルの fingerprint を値として取り出す。失敗側にも最後の確定 ID がある場合は一致を確かめる。失敗側で ID だけが分かる場合は、その ID を記録する。不明な項目は `null` とし、ゼロと区別する。識別子と資源の整数は10進文字列で保持し、uint64 の最大値を丸めない。

来歴は実行バイナリの `uvlas.build-info/1`、判明している元ケースの ID・長さ・SHA-256 と、供給された解決後ケースの SHA-256 を保持する。解決後の digest だけを指定した入力は拒否する。本文と来歴の合計出力バイト数を確かめ、所有バッファーに一度だけ計上する。JSON ライブラリの一時領域は固定構成のメタデータ用で、出力バッファーの課金とは別に扱う。

今回の対象は現在の C++ 状態と来歴の内部射影である。CLI によるファイル公開、公開 JSON 版と互換性、解決後設定の完全な生成、物理時刻と segment、実際の解析は後続の接続で扱う。
