# IM-06 領域厚さの報告が所有する有理数の見積り

定数厚さの宣言を比較した結果は、面ごとに厚さとチャート面積の二つの有理数を所有する。報告を一面ずつ準備しても、先に照合した面の値は報告を返すまで生存する。照合を始める前に、固定の作業領域と面数の二倍を算術の見積りに入れる。

## 固定予算での対照

平板を二つの三角形で表した実 MSH を通常の予算で認証した。比較だけに一面分の予算を渡すと、厚さとチャート面積を所有した報告を一面分返す。同じ予算のもとで面を二つにすると、報告の確保前に資源超過を返した。一面の予算を一バイト減らす対照でも、共有 ResourcePlan への追加の計上はなかった。十分な予算を戻すと、同じ認証済み幾何と Case から二面の報告を得た。

## 検証に使った構成

対象ソースは `9dd1f01d19f040b2e335944d03fa6a6a891ae033`。Windows 11 の MSVC 19.51.36260 Debug と Release、Ubuntu 24.04 の GCC 14.2.0 Debug（ASan・UBSan）で、`io.external_planar_pg`、`io.external_pg_regional_thickness`、`io.reference_input` が各3件合格した。領域厚さは71アサーションだった。

GCC の隔離複製で、報告に一面あたり一つしか計上しないようにすると、二面が通り、回帰試験は失敗した。元バイトに戻してハッシュを照合し、再構築した試験で当該12アサーションが合格した。変更した翻訳単位の clang-tidy と clang-format 21.1.2 も通過した。
