# PGの混合偏微分だけで決まる距離上界を検査する

Nastranの元デッキから一枚の `CTRIA3` を読み、単位長さのPG参照面に対応させた。元の三角形は $(s,t,0)$、PGは $(s,t,st)$ で、材料領域は $s,t\ge0,\ s+t\le1$ とした。三頂点の位置は一致し、高さの純二階偏微分はともに零。斜辺の中点 $(1/2,1/2)$ で同じ材料座標に対応する二点間の距離が最大となり、独立な解析値は $1/4$ m になる。返った上界がこの値以上であることを有理比較で確かめた。 [レビュー指摘](https://github.com/YUKIKEDA/UVLAS/pull/350#discussion_r4680201565)

MSVC Debug と GCC 14.2 Debug（ASan・UBSan）で `io.external_planar_pg` が各7ケース・168アサーション通過した。Linuxの分離コピーで混合項だけを零にすると、追加した距離比較が失敗した。同じ変異で従来の6ケース・165アサーションは通過した。元の実装に戻して再リンクすると、追加ケースの3アサーションが通った。 [先行する曲面検証](nastran-curved-pg-bounds.md)
