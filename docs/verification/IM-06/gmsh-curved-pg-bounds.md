# Gmsh 元面と曲面PGの全域誤差を測る

認証済みの Gmsh MSH 4.1 ASCII と面選択から、明示された PG 参照面との距離と向き付き単位法線の差を有向丸めで上から抑える。
[IO4-04](../../specs/foundation/io-execution-adoption-specification.md#io4-04-gmshと外部面からの参照構築) と R-05 の幾何評価に用いる。
距離の単位はメートル、法線差は二つの単位ベクトル間のユークリッド距離とする。

## 元の四辺形の歪みを保持する

Gmsh の三角形には重心補間、四辺形には元の節点順の双線形補間を使う。
四辺形は四隅が非共面でも評価する。
節点タグ、元の座標欄の位置、十進字句から厳密に SI へ変換した座標、明示された有理チャート座標を結果が持つ。
元の面の entity、参照位置と SHA-256、照合先の PG 指紋も保持する。
[Gmsh 公式 MSH 仕様](https://gmsh.info/doc/texinfo/gmsh.html#MSH-file-format)

双線形面を $P(u,v)=A+Bu+Cv+Duv$ と置くと、元の接ベクトルの外積は $B\mathbin{\times}C+u(B\mathbin{\times}D)+v(D\mathbin{\times}C)$ になる。
各成分はアフィンなので、四隅の外積で面全域を包絡できる。
元の順序は保存し、宣言の向きに従って法線の符号だけを合わせる。
PG 法線の全域を一つの区間包絡で覆い、すべての元節点の外積をこの同じ区間に射影する。
射影に正の下界を示せれば、同じ下界が内部に成り立つ。
この正の下界で面の向きと退化の有無を確かめ、外積の正規化にも使う。
射影が非正と確定した場合は元節点を示して拒否し、符号を確定できない場合は精度未達を返す。

## 四隅の照合に内点の誤差を加える

元面と明示チャートには同じ非負の補間重みを使い、チャートの向き・重複・領域・全域被覆を有理数で照合する。
PG は次数4以下の明示参照グラフを使う。
位置差の上界は元節点での最大残差に、PG の高さを四隅から補間する誤差を加えた値となる。
チャート座標の範囲幅を $\Delta_s,\Delta_t$ とすると、補間誤差は
$(\Delta_s^2\sup|f_{ss}|+2\Delta_s\Delta_t\sup|f_{st}|+\Delta_t^2\sup|f_{tt}|)/8$
に長さ尺度を掛けた値で抑えられる。
各座標の補間重みによる分散が幅の二乗の $1/4$ 以下であり、Taylor 剰余に係数 $1/2$ が付くためである。
PG の一次導関数から評価した法線との差も、元面全域の上界として返す。

## 解析値と元の MSH で比較した

元の四辺形を $(s,t,st/10)$ m とし、PG を $(s,t,(st+s^2-s)/10)$ m とした。
四隅の位置は一致する。面内では $s=1/2$ で差が最大となり、厳密値は $1/40$ m になる。
同じ元四辺形を平面と比べた場合、最も傾く隅の法線は $(-1,-1,10)/\sqrt{102}$ である。
対角線で作った二つの三角形なら、それぞれの傾きはこれより小さい。
元の四辺形を使う場合と、元の MSH に実際に三角形が二枚ある場合の両方を照合した。

元の節点列を逆順にして宣言の向きも反転した対照では、二つの上界が一致した。
元面の射影だけが反転する入力、別の MSH に属する面選択、元の節点順との不一致、チャートを一部しか覆わない選択を拒否した。
有向丸めの作業上限は実際に使った量とその1単位手前で照合した。
結果の位置・元欄・ハッシュは、元のメッシュ、面選択、PG の各所有者を破棄した後も利用できる。

幾何の上界は、[R-05 の独立観測と数値予算](../../specs/foundation/io-execution-adoption-specification.md#io4-04-gmshと外部面からの参照構築)に渡す。
外部メッシュの離れた面どうしの自己交差、材料・全厚・接続を含む変換の受入、Case sidecar との結合は後段で扱う。

## 両OSで固定ソースを検証した

ソースコミットは dd47268f4bb9860b6988a8f9e94b75f64ec3321d。
MSVC 19.51.36260 Debug と Ubuntu 24.04.5 の GCC 14.2.0 Debug（ASan・UBSan）で、
CTest の `io.external_planar_pg`、`io.gmsh_mesh`、`io.gmsh_surface_topology` が通った。
共通の面検査は各OSで9ケース・238アサーション。
clang-format 21.1.2 と Linux の対象 clang-tidy 21.1.1 も通った。

Linux の分離コピーで、四辺形の外積を最初の隅だけで評価すると、法線差の過小評価と射影反転の見逃しを検出した。
高さ補間の剰余係数を $1/8$ から $2^{-20}$ に縮めると、内点の距離が試験の下界 $1/40$ m を下回った。
二つの変異でそれぞれ2アサーション、1アサーションが失敗した。
製品ソースのバイトを復元して再ビルドすると、抽出した Gmsh の4ケース・95アサーションが通った。
