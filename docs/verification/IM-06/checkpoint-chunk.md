# チェックポイントの型付きチャンク

[IO4-06](../../specs/foundation/io-execution-adoption-specification.md#io4-06-checkpoint) のうち、単一チャンクの書出しと読戻しを検証する。書出しは形状と型付きの値列を受け取り、バイト列とその SHA-256 を所有する。読戻しは宣言した型、形状、バイト数、SHA-256 を検査してからバイト列を所有し、独立した型付き配列へ展開できる。

| 検査 | 対照 |
|---|---|
| 型とバイト順 | IEEE 754 の負のゼロ、1、1 の直後の表現、符号付き64ビットの最小値、2⁵³を超える符号なし整数を固定バイト列と比較する。読戻しはビットまたは整数の完全一致で判定する。 |
| SHA-256 | 固定バイト列と65544バイトのゼロ列について、Python の `hashlib.sha256` で得た固定値と比較する。 |
| 拒否と資源 | バイトの反転、欠落、余剰、宣言と形状の不一致、未知の型、負の軸、乗算の上限、確保の予算不足、取消を検査する。破損入力の拒否までにチャンクを確保しないことも確かめる。 |
| 境界と所有 | スカラーと空配列、処理ブロックの末尾、入力の書換え後の所有データ、移動元の無効化を検査する。 |

`io.checkpoint_chunk` がこの検証を行う。TwoWord を使う呼出し側は hi と lo をそれぞれ f64 チャンクへ渡す。マニフェストの解析とモデルの指紋照合、ディレクトリの確定、J1 の履歴と実行再開は後続の容器・状態の検証で扱う。
