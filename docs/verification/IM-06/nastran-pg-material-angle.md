# IM-06 Nastran と Case の材料軸の角度を厳密に判定する

一定全厚の認証済み平面で、元デッキと Case の材料軸を照合する。両側の基準方向は同じ層面にある有理ベクトルで、角度は厳密な度の値または零である。元面の法線が反対向きなら、Case 法線を採用して元の回転角の符号を反転する。[材料軸の準備と四分回転の検証](nastran-pg-material-axes.md)

## 内積の二乗と両方の符号を比べる

元と Case の基準方向を $u,v$、指定された角度差を $\delta$ とする。両方向の幾何学的な角がこの差と一致するなら、$\cos^2\delta=(u\cdot v)^2/[(u\cdot u)(v\cdot v)]$ は有理数である。$\delta$ が有理数の度なので、$z=\exp(i\pi\delta/90)$ は1の冪根になる。$x=z+z^{-1}$ と置き、$P_0(x)=2,\ P_1(x)=x,\ P_{k+1}(x)=xP_k(x)-P_{k-1}(x)$ とすると $P_k(x)=z^k+z^{-k}$ になる。$z^n=1$ を満たす $n$ で $P_n(x)-2=0$。これは最高次係数が1の整数係数多項式であり、有理数の根は整数に限られる。

$x=4\cos^2\delta-2$ は −2 から2までの整数のため、一致の候補は30°または45°の整数倍に絞られる。実装は厳密な度を360°周期で扱い、$4(u\cdot v)^2$ と対応する係数を掛けた $(u\cdot u)(v\cdot v)$ を照合する。内積の符号と、Case 法線 $n$ に対する $n\cdot(u\times v)$ の符号も照合し、角度の向きと象限を区別する。幾何変換の距離・法線予算と材料軸の照合は別に扱う。

## 実デッキで符号と象限を別に確かめる

傾平面 $z=x-y$ では、CORD2R の方向 $(1,1,0)$ を元の基準にした。Case の第一軸 $(2,1,1)$ に対して $\cos^2\delta=3/4$、法線に沿った外積の成分は負となる。PCOMP の −30° を受理し、+30° は同じ余弦二乗でも拒否した。同じ元方向と Case の $(1,0,1)$ では $\cos^2\delta=1/4$ となり、−60° を照合した。

別の平面では、元の +x と Case の対角 $(1,1,0)$ に対して $\cos^2\delta=1/2$ となる。THETA 15° と ply 角30°の合成を受理し、THETA 105°と ply 角30°の合成は同じ余弦二乗と法線に沿った外積の正の成分でも、内積の符号が違うため拒否した。この有理な基準方向では一致し得ない15°の差も、入力不一致として元欄と Case 層を報告した。

現在の照合が対象とするのは、一定全厚の認証済み平面、一定の Case 軸、および採用した矩形座標の元軸である。

## 検証に使った構成

対象ソースは `20e8749d617c0a3d812d69eab039934756caf2c4`。Windows 11 の MSVC 19.51.36260 Debug と Release、Ubuntu 24.04 の GCC 14.2.0 Debug（ASan・UBSan）で、`io.external_pg_regional_thickness`、`io.external_planar_pg`、`io.nastran_laminate_cards`、`io.reference_input` が各4件合格した。各構成で、実ファイルの対応表試験は1593アサーションだった。

隔離コピーで正弦の正負を省くと符号が逆の −30°／+30° の対照を誤って受理した。余弦の正負を省くと象限が異なる45°／135° の対照を誤って受理した。両方を元へ戻すと、対応表試験の1593アサーションが再び合格した。変更した翻訳単位の clang-tidy と clang-format 21.1.2 も通過した。
