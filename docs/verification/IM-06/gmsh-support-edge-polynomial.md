# IM-06 曲面の Gmsh 支持線を辺上で厳密に照合する

元の一次線を Case の名前付き外周に結び付ける。線が接する認証済み面で位置差の上界が零なら、そのまま辺の一致に使う。上界が正の場合は、認証済み面の元節点が保持する SI 座標から一次線を作り、同じ端点順のチャート線分上に Case の PG を制限する。どちらの経路を使ったかは、元線ごとの結果に残す。[支持線の所属と全域被覆](gmsh-case-support-boundary.md)

単位区間で元線に沿うパラメータを $u$ とする。$s(u)$ と $t(u)$ はチャート上の両端を結ぶアフィン式である。中心面の世界位置は、Case の原点 $o$、回転 $Q$、参照長 $L$ を使うと次の有理多項式になる。

$$
X_0(u)=o+LQ\,(x_0+w\,s(u)+k\,t(u),\ t(u),\ f(s(u),t(u)))^T
$$

$x_0$、幅 $w$、スキュー $k$ は Case のチャートに属する。高さ $f$ の次数は4以下で、制限後も有理係数を保つ。世界座標の各成分で、元の二点を結ぶアフィン位置との全係数を厳密に比較する。差があれば、元線と面に加えて異なる世界成分を診断する。

## 非零の面上界を使った実ファイル対照

元 MSH は試験内で生成する。対象の試験名は `A Gmsh support group covers the exact named Case boundary`。[元 MSH の生成](../../../tests/io/gmsh_case_support_boundary_test.cpp#L28)・[試験の定義](../../../tests/io/gmsh_case_support_boundary_test.cpp#L118)

両対照で同じ元 MSH を用いた。Case の参照長は 2 m、原点は $(1,2,3)$ m、局所軸を世界の $+Y,+Z,+X$ に対応させた。両面とも `fit` の距離上界は正である。

- $f(s,t)=s(1-s)/10$ の曲面では、元面の内部に 1/20 m の位置差がある。支持線501と502を置く $s=0$ では高さが恒等的に零になるため、両線を全区間で受理した。501 の元節点順は逆向きのまま保持した。
- $f(s,t)=t(t-1/2)(t-1)/10$ の曲面は、チャートの $t=0,1/2,1$ にある全ての元端点と一致する。501 の区間内の $t=1/4$ では世界 $X$ に 3/320 m の差があり、元線501・元面701・世界 $X$ を示して拒否した。

名前付き外周の被覆、内辺と重複の拒否、取消、元線数上限も同じ入口で検査した。ここで証明するのは中心面の位置と所属である。外部側の全厚拘束、拘束成分、支持運動の照合には、それらを表す物理宣言が必要になる。

## 検証に使った構成

対象ソースは `e3ee88c57c16a1d8e62890cf77ad061a7a709d1d`。Windows 11 の MSVC 19.51.36260 Debug と Release、Ubuntu 24.04 の GCC 14.2.0 Debug（ASan・UBSan）で、`io.external_planar_pg`、`io.gmsh_shell_reference_set`、`io.gmsh_case_support_boundary`、`io.external_shell_cross_format` が各4件合格した。支持境界は各構成で137アサーションだった。

GCC の隔離複製で両端点の位置だけを比較すると、三次の負対照が通り、回帰試験は失敗した。元バイトへ復元してハッシュを照合した後、再構築した同じ対照で17アサーションが合格した。変更した翻訳単位の clang-tidy と clang-format 21.1.2 も通過した。
