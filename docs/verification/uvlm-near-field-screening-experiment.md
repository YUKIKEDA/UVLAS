# 近接求積の固定次数診断：事前仕様と記録

版0.1、2026-10-30。[近接評価契約](../uvlm-near-field-quadrature-contract.md) の必要性を調べる限定診断。適応評価器の実装・採用試験ではない。以下1〜4節をコード作成・実行前に固定する。

## 1. 入力と独立参照

3D W-P1の平面セル[(1,−.6,0),(1,.6,0),(1.4,.6,0),(1.4,−.6,0)]、ε=0、L/R単位基底。基準弦c=1m、観測点p=(1−d,0,0)、d/c=[1,.5,.1,.01,.001,.0001,.00001]。全点は有限面の外側で、接触／自己評価を含まない。

参照Aは既存の幅一列の解析L/R重み。参照Bは同じ連続後流密度 $f(s)=b/[2\pi(s-x)^2\sqrt{(s-x)^2+b^2}]$ にL/Rを掛けた一次元積分を、 $s-x=d\exp(t)$ 、 $0\le t\le\log(1+0.4/d)$ で変換し、SciPy quadで評価する。Bはepsabs=1e−10、epsrel=1e−12、分割上限200。2倍厳しい指定でも確認する。解析A／B差とBの指定変更差は基底ごと相対1e−11以下、警告なしを要求する。単なる固定面求積の高次数値を真値としない。

## 2. 固定次数の検査

既存3D式の境界・面内次数をそれぞれ24/48/96へ同時変更し、7距離×2基底の全3成分を保存する。符号・コア・面分割・値は変更しない。親長ℓは最大辺長、列目標は $10^{-10}/\ell+10^{-8}\|K\|_2$ 。各次数の実誤差と目標達否を記録する。

固定次数96の暫定画面判定として、48→96差の16倍が列目標以下、かつ未分割の全境界／面が $h/d\le2$ のときだけ `eligible` とする。距離は有限要素までの距離。最大辺長をセル全体へ使う保守的な簡略画面判定も保存する。これは分割木・最終監査・丸め床を持つ候補評価器の代替ではない。

## 3. 仮説と合否

1. 2つの参照と参照Bの自己比較が第1節を満たすこと。
2. 最遠点d/c=1で96次の両基底が列目標を満たすこと。
3. d/c≤.01のいずれかの基底・次数で実相対誤差>1e−3を検出すること。近接でも固定次数で十分だった場合はこの仮説を不成立として保持する。
4. 暫定画面判定で受理した列の実誤差が列目標を超えないこと。受理列0件なら成功判定せず、遠方で両基底を受理することも求める。
5. L+Rの和と一定μの評価が尺度付き1e−10以下で一致すること。大きな相殺の絶対誤差は相対差だけで隠さない。

この診断の合格から、任意幾何の誤差推定が信頼できるとは結論しない。未達を保存し、しきい値や距離を結果に合わせて変更しない。

## 4. 資源・出力

60秒、256MiB。入力、全速度・参照・求積推定誤差・距離尺度・達否、NumPy/SciPy、ソース／依存ハッシュ、時間・ピーク作業集合をJSON保存する。生じた警告・例外は停止記録へ残す。外部FEM・本体C++は実行しない。

## 5. 実施結果

[診断コード](../../tools/design-experiments/check_uvlm_near_field_screening.py) と [全結果](uvlm-near-field-screening-result.json) を保存した。事前の参照・遠方精度・近接未達検出・画面判定・基底和について6判定が成立した。これは固定次数評価自体の全面合格ではない。

| d/c | 96次Lの実相対誤差 | 96次Rの実相対誤差 | 暫定画面判定 |
|---:|---:|---:|---|
| 1 | 1.94e−14 | 1.91e−14 | 両基底を受理 |
| .5 | 1.10e−14 | 8.66e−15 | 幾何条件で拒否 |
| .1 | 3.01e−13 | 7.34e−15 | 幾何条件で拒否 |
| .01 | 20.9% | 0.733% | 拒否 |
| .001 | 99.1% | 20.2% | 拒否 |
| .0001 | 100.1% | 42.2% | 拒否 |
| .00001 | 100.1% | 55.9% | 拒否 |

解析式と対数変数変換した一次元参照の最大相対差は1.16e−15、参照Bの指定変更差は今回のfloat64出力で0、警告なしだった。指定変更差0を厳密誤差0とは扱わない。暫定画面判定は遠方の2列だけを受理し、受理列に目標超過はなかった。一方、.5/.1では実際には十分な精度でも保守的に拒否した。これは分割・再評価の必要性であり、拒否された値をそのまま成功として渡す根拠にはしない。

全次数・全距離で最大相対誤差は約101%。96次という固定値でも近接時には不足することが解析参照で確認された。今回の点群は面外／有限面外であり、自己誘導は扱っていない。

実行は0.250秒、ピーク81,833,984 bytesで予算内。次は [近接契約](../uvlm-near-field-quadrature-contract.md) の分割木・監査・丸め床・失敗保証を備えた評価器候補を事前仕様に従って検証する。今回の保守的画面判定はその評価器の代替ではない。
