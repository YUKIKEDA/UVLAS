# G-EM1の一般場・双対・非線形微分

2026-11-02。一般場を受ける幾何専用の還元と双対を別試作し、固定参照Greenひずみ・初期ひずみ・内力・接線作用まで接続した。[事前条件](q9-edge-moment-field-experiment.md) の40配置は全基準を満たした。主シェルの採用は引き続き保留する。

## 対象と実装

[一般場試作](../../tools/design-experiments/q9_edge_moment_fields.py) は、[場と双対の契約](../q9-edge-moment-field-interface.md) のvolume/ties/edgesを独立入力とする。旧87列試作と旧不採用記録は変更していない。5形状×2厚さ×回転有無×厚さ再表現有無の40配置、5³構築求積と5×5辺観測を使用した。7/9点構築・11点観測で行った[従来の線形可解性審査](q9-edge-moment-results.md) と、今回の微分検査の求積次数を区別する。

参照キャッシュは入力場に依存しない変換・補間・辺の擬似逆・体積測度・bubbleだけを持つ。試行ごとの平均・辺係数・モーメントは呼出しのローカル変数で、キャッシュへ保存しない。配列を読み取り専用とし、入力不変性・キャッシュ配列不変性・形状違い／非有限値／複素入力の拒否を検査した。これは製品の所有権・例外保証・世代番号・並列実行の完成を意味しない。batch入口と追加観測点の入口も未実装。

実装を一般場の線形写像に分解すると、補正前の場は次となる。

$$
r_{1p}=A_p v_p+T_p\beta+L_p c_V+\sum_e G_{ep}c_e,
\qquad c_V=\sum_p a_p v_p,\quad c_e=P_e e_e.
$$

ここでβは物理Mandelのtie入力から参照共変せん断へ変換した36値、aは正規化した参照体積重み。Lには辺拡張によるcVの差引きを含む。最後に

$$
m=\sum_p a_p(r_{1p}-v_p),\qquad r_p=r_{1p}-b_p m
$$

を適用する。双対は同じ行列の転置を逆順に作用させ、入力3配置へ返す。体積重みはエネルギー側のcotangentに一度だけ含める。

## 一般場と微分の結果

[主計算JSON](q9-edge-moment-field-result.json)、[実行コード](../../tools/design-experiments/check_q9_edge_moment_fields.py)。有限要素の補間から作らない乱数場を3入力に与えた。独立な入力群ごとの双対性も確認した。

| 検査 | 最大誤差 | 事前上限 |
|---|---:|---:|
| 線形性 | 3.57e−16 | 1e−12 |
| 双対内積・入力群別を含む | 3.74e−15 | 1e−12 |
| 体積平均保持 | 4.16e−15 | 1e−12 |
| 旧87列試作との作用差 | 4.70e−16 | 1e−10 |
| 適合初期ひずみの自然状態と有限回転 | 2.12e−16 | 1e−10 |
| エネルギー方向微分と内力 | 1.21e−16 | 1e−9 |
| 内力方向微分と接線作用 | 1.05e−15 | 1e−9 |
| 方向部分空間での接線対称性 | 5.06e−16 | 1e−10 |

自然状態は非零のアフィンGreen初期ひずみから構成した。微分検査は、それに非一様な有限変形を加えた状態で、等方材と固定参照軸の異方性SPD材料について各3方向で実施した。複素ステップは検証用の内部経路で使用し、一般場の実数入口からは受け付けない。

内力は双対と一次変分から、接線作用は材料項とGreenひずみの二次変分による幾何項から求めた。辺の二次変分も含む。幾何項を故意に省くと最大約5.70%の相対差が生じ、負の対照の1e−6条件を満たした。単に材料接線だけを返す経路を許容しない。

主計算は29.50秒、ピーク73,105,408 bytesで資源条件内。

## 別経路監査

[事前条件](q9-edge-moment-field-audit-protocol.md) に従い、10基準配置について別の形状微分と物理Greenテンソルを用いる。辺入力は計量式の直接評価に代えて物理テンソルの辺基底射影で再計算し、エネルギーから全81成分の内力を複素ステップで照合する。全81列の接線も照合する。還元R自体は主試作を使うため、方式全体の独立実装とは数えない。

[監査JSON](q9-edge-moment-field-audit.json)、[監査コード](../../tools/design-experiments/audit_q9_edge_moment_fields.py)。全10配置で成立した。入力場の相対差は最大6.30e−15、エネルギーからの全81成分内力差は3.68e−15、接線全81列の差は5.50e−16、対称性誤差は4.15e−16。使用した全観測点でdetFの最小値は約0.9927だった。これは要素内全域の正値証明ではない。58.094秒、ピーク64,843,776 bytesで資源条件内。親記録・契約・事前条件・依存ソースのハッシュ照合も成立した。

## 閉じた範囲と残作業

線形87列だけに限定していた処理を、3系統の一般入力場と双対に拡張できた。固定参照・適合初期ひずみ・試験用の全6成分弾性則について、内力と幾何項を含む接線作用の計算経路を確認した。

次は曲面で要素を共有した後のせん断拘束の許容空間と、その格子・厚さ依存性を審査する。その後に大域解の薄肉一様性と収束を判定する。今回の自由要素rankや微分一致を、その証拠へ移さない。

実材料の適用限界、曲面での材料軸生成、積層・層別初期ひずみ・応力回復、可変厚さ、製品のbatch／追加観測／失敗・並列保証は未完了。主シェル最終採用、構造採用審査全体と製品計算本体の開始条件は解除しない。
