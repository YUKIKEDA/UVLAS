# P-S36の局所ゲート・板曲げ比較の監査仕様

2026-10-31。独立監査前に固定する。主試験と局所ゲートの閾値を変更しない。

- 局所3ケースの保存M,H,Kn,Kp,Kfullを読み、尺度化M正定値・条件数、別直接解のSchur凝縮、Kpの対称性・rank75・6剛体モード・パッチ内力、エネルギー順序を再計算する。値と判定が一致することを確認する。元Kfullは既存の別の体積評価経路とも共通尺度1e−10以内で比較する。反復して良い結果を選ばない。
- 主試験のソース・依存・候補仕様・局所ゲート・元結果・NPZのハッシュを確認し、8ケースの数値処理・保持解の記録を監査する。保持解自体・大域行列は保存していないので、保持残差の独立再計算とは呼ばない。
- 既存の独立観測監査と同じく、別の1次元Lagrange評価、11点L2積分、物理点中心の逆写像、fsum仕事、別7点厚さの4変数参照を使う。中心・仕事は参照尺度で差1e−10以内、L2は差1e−8×max(元値,1e−12)以内。
- 最細精度・最後の次数・薄肉一様性の合否を独立観測から再判定して一致を確認する。合格を一般曲面・異方材・非線形の採用にしない。
- 局所監査120秒・512MiB、板曲げ監査120秒・512MiB。保存した行列・観測の別計算であって、人による独立審査ではない。
