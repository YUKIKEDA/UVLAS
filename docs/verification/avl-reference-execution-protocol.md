# AVL 3.52：実行・出力取得の事前プロトコル

版0.1、2026-10-30。[有限翼比較仕様](finite-wing-load-reference-specification.md) の参照環境整備。物理比較・格子収束・コア監査コピーの品質判定ではない。

公式Windows実行体 `avl352.exe` をHTTPSで取得した。1793164 bytes、SHA-256 `443520d255408491222a8df9060bd000f78da95a68845a2f6efdbc67e203f07a`。公式ソースアーカイブ内のWindows実行体名は3.51であり、3.52実行体の代用にしない。実行時のバナーも確認する。

## 1. 実行範囲と保存

最初はFW-V01/V02のM4・N12、α=+1度を各1回。FW-V01を別の空ディレクトリで1回反復する。原入力をコピーし、実行体は別プロセス、シェルなし・Windows非表示で起動する。グラフ命令は使わない。参照計算の既存結果を上書きせず、試行ディレクトリは新規作成する。

実行体・入力・セッション・全stdout/stderr・総量FT／帯FS／幾何軸帯FSB／要素FEを保存する。オプションは初期状態と最終状態をログへ残す。幾何軸の向き、機体幾何軸周りのモーメント、流下脚の力ON、粘性と機体力OFFを明示する。既存設定ファイルを置かない空の作業ディレクトリで起動し、トグル後の表示を必ず確認する。

取得したソースのOPER MRFは「full-precision machine readable format」へ切り替える。数値出力前にMRFを指定してFT/FS/FEを取得し、FSBも保存する。MRFの有無と各出力の実際の桁数を確認する。MメニューでV=20、D=1.2、MN=0を明示設定する。

1試行20秒、ログ8MiB、取得ファイル合計32MiB。上限超過時は自分が起動した子プロセスだけを停止し、ログと停止原因を保存する。入力終了を成功と誤認せず、終了コードと必要出力を検査する。全3試行180秒、512MiBを上限とする。

## 2. 整備の合否

- バナーが3.52、入力は48束縛要素・12スパン帯、形状・基準点・S/c/b・Mach・αが指定どおりであること。
- 最終オプションで流下脚力ON、粘性／機体力OFF、幾何軸の向きと機体軸周りのモーメントを確認できること。
- 正常終了し、FT/FS/FSB/FEの4出力が空でなく有限数を持つこと。未知コマンド、入力読込失敗、非有限値、失敗終了がないこと。
- 出力の係数・帯数・要素数を機械読取でき、FW-V01反復は同じ丸め出力を返すこと。元のテキストを保持し、丸め桁数も記録する。

U・ρを実行パラメータへ設定できたかも記録する。係数はU・ρによらないが、既定値を指定値として記載しない。定量残差・全循環・要素の荷重ベクトルと作用点・固定20帯への保存的集計が取得できなければ未確保として明記する。限られたテキスト出力から足りない情報を推定して物理比較を開始しない。

初回の失敗・不明オプションは保存し、手順修正はセッションを別名にして記録する。このプロトコルの合格は参照環境の疎通までで、FW-V01/V02やJ1の合格ではない。

## 3. 初回のオプション不適合と修正前の追加条件

初回3試行は終了・ファイル取得・反復一致の疎通条件を満たしたが、最終オプションで粘性フラグがONだったため第2節の整備条件は未達。初期化ソースだけからトグル数を決めたのが原因で、実際の入力読込後は粘性OFFだった。出力CDvis=0でもフラグ不適合を合格へ読み替えない。[初回記録](avl-reference-execution-result.json) とコード・ログを保持する。

修正実行前に、同じ実行体・入力・迎角でVトグルだけを除き、ログの最終フラグ・軸・U/ρを機械検査する3試行を別結果へ記録すると定める。原本3試行と同じ予算。初回の未達は上書きせず、反復一致は修正試行内で判定する。機体力・流下脚・軸の他のトグルは初回の実表示から確認済み。輸送的成功と意味的適格性の両方を要求する。

初回実装では参照子プロセスのピーク作業集合を取得していなかった。修正試行はWindows GetProcessMemoryInfoのPeakWorkingSetSizeを取得し、512MiB条件を確認する。初回のメモリ値は未計測として残す。

## 4. 実施結果・取得できた情報

[初回コード](../../tools/design-experiments/run_avl_reference_smoke.py) と [初回結果](avl-reference-execution-result.json) を保持した。[修正コード](../../tools/design-experiments/run_avl_reference_smoke_corrected.py) と [修正結果](avl-reference-execution-corrected-result.json) では3試行とも正常終了し、軸・フラグ・48要素／12帯・基準量・α／Mach・U／ρの8意味検査も成立した。FW-V01の反復は4出力のSHA-256がすべて一致した。最大ピーク作業集合10,579,968 bytes、各試行約0.063秒で予算内。

修正コードの最初の実行は3試行を完了した後、結果の保存先が初回結果のままで上書き防止により停止した。[保存停止記録](avl-reference-execution-corrected-initial-status.json) と変更前コード・実行ログを保持し、保存先だけを修正して別ディレクトリで再実行した。初回結果も数値設定も上書きしていない。

| 出力 | 取得・確認内容 | 残る制限 |
|---|---|---|
| FT（MRF） | 全係数、基準量・原点・軸、48渦、12帯、α・Mach。ES23.15表記 | 表記15桁を内部演算の精度保証としない |
| FS（MRF） | 12帯の面積・断面量・揚力／抗力・モーメント、ES23.15 | 固定20帯への保存的変換は未実施 |
| FSB | 機体幾何軸の帯荷重 | MRFに切り替えても従来の固定小数点書式。全精度の要素力出力の代替にしない |
| FE（MRF） | 48行の渦中点座標・DX・Slope・dCp、帯情報 | 見出しVortex Strengthsでも、各行はΓそのものや全要素力ベクトルではない |
| コンソール | オプション遷移、U=20・ρ=1.2、実行結果 | 定量的な非貫通残差・全循環・行列は未取得 |

原本の出力精度切替MRFにより、FT/FS/FEについて単純な5桁表示の問題は回避できた。CSV化等の後処理でもこの桁を落とさない。原本バイナリのビルド条件・演算精度は不明として残し、出力形式から推測しない。

## 5. 参照比較を始める前に残る作業

疎通と最終設定は確認できたが、[有限翼比較仕様](finite-wing-load-reference-specification.md) の本比較はまだ開始しない。原本に対応するソースのビルド、微小コアを0へ変えた監査コピーとの比較、非貫通残差・全循環・評価点と全要素力の取得、帯変換の保存則を整備する。FEのdCpからΓや全力を未導出の式で逆算して不足情報を埋めない。

後続の [ソースビルド・計測試験](avl-source-measurement-experiment.md) で原本と計測版から残差・全循環・渦線力と作用点を取得できた。ただしコア0監査版の横方向対称性が未解決であり、受入参照の採用や有限翼比較の完了ではない。
