# 有限翼の定常荷重：独立コード比較仕様

版0.1、2026-10-30。E-AERO/E-MAP、AE-01〜06の比較設計。対象は非圧縮・非粘性・付着流の薄い揚力面。実務翼全体の妥当性確認や初回製品リリースの代用ではない。

## 1. 比較を三段に分ける

| 段 | 参照・目的 | 合格から言えること |
|---|---|---|
| FW-V01/V02 | AVL 3.52と同じ形状・直線後流を用いた定常揚力・モーメントの一次応答 | 有限幅、後退・テーパ・上反角における非貫通と荷重演算の独立コード比較 |
| FW-D01 | 後流遠方の誘導抗力と近傍荷重の二次成分 | 遠方／近傍定義と流下方向の力の扱いを揃えた後の別ゲート。V01/V02合格だけで通過としない |
| 実験比較 | Weber–Brebner、S10等の公開データを個別審査 | 厚さ・粘性・支持・不確かさ等を含む適用性。現在は採用保留 |

有限ARの楕円平面形に揚力線の解析式をそのまま厳密解として課さない。揚力線と有限弦VLMのモデル差を離散誤差へ混ぜない。長方形の単体試験だけで本比較を完了しない。

## 2. 独立参照の版と監査

[MITのAVL公式配布](https://web.mit.edu/drela/Public/web/avl/) から3.52のソースを取得した。1769840 bytes、SHA-256 `0b588ecea9222f5b625d0af0c87ae31daf3cdba1532cf0bbb36f93d6e854849b`。キャッシュは `build/reference-avl/avl3.52.tgz` 。[入力・監査マニフェスト](finite-wing-reference-inputs.json) にファイル別ハッシュ・原本のアーカイブ内位置を保存する。**参照側の全格子系列は実施済みだが収束条件は未達。UVLASとの比較は未実施**。

公開Webの [User Primer](https://web.mit.edu/drela/Public/web/avl/avl_doc.txt) は3.40表記だった。取得アーカイブには `avl_doc-AVL350-04242025.txt` があり、3.52の挙動は同梱ソース・変更履歴を優先して確認した。

後続の [実行・出力取得](avl-reference-execution-protocol.md) で公式Windows実行体と2翼・3修正試行の疎通を確認した。入力マニフェストの実行体未取得という状態は、準備時点のハッシュ固定記録として維持する。この疎通時点では収束・コア監査・UVLASとの物理荷重比較は未実施であり、疎通出力を受入参照として採用していない。

| 監査点 | 原本で確認した挙動 | 比較での扱い |
|---|---|---|
| 渦の後流方向 | 同梱説明書は全馬蹄渦の流下脚を+xとする | UVLASもこの比較では+xの指定直線後流。迎角で自動回転しない |
| 翼面上の流下脚の力 | `avl.f` の `LTRFORCE=.FALSE.`、`aoper.f` のOptions Tで切替 | 必ずONを確認し、実行ログへ保存。ユーザー既存設定の暗黙継承を禁止 |

| コア | `aic.f` は同一コンポーネントでも幅の0.0001倍。核はUVLASのRosenhead–Mooreと異なる | 同じ数値のεで一致と称さない。下記の参照コア感度を必須とする |
| 軸 | 初期 `LNASA_SA=.TRUE.` | 幾何軸モーメントへ明示切替。+x後方・+y・+z上方の右手系へ正規化し、オプションと元出力を保存 |
| 荷重評価点 | 渦上の補間点がUVLASの辺中点と必ずしも一致しない | 同じ粗格子の完全一致を要求せず、両コードの空間収束と作用点感度を記録 |

AVL原本を別プロセスの参照として扱い、UVLAS製品へソースを組み込まない。公式ページのGPL表記に従い、参照物を再配布する際は配布物の条件を確認する。今回、原本アーカイブ・抜粋はbuild内の監査キャッシュに保持する。

## 3. 二つの物理形状と共通入力

両翼とも全翼を明示し、対称画像を使わない。単位m、原点は中央断面前縁。 $-4\le y\le4$ 、 $\eta=|y|/4$ とし、

$$
x_{LE}=|y|\tan35^\circ,\qquad c(y)=1.5-0.9\eta,
\qquad x=x_{LE}+\xi c(y).
$$

FW-V01はz=0。FW-V02は $z=|y|\tan5^\circ$ 。薄い平面断面、キャンバ・ねじり・仮想迎角補正・操舵・機体・壁なし。AVLのAincは0、断面揚力傾斜補正CLAFと粘性CDCLを追加しない。物理形状と法線を明示計算し、上反角を法線だけへ二重適用しない。

共通値はρ=1.2kg/m³、U=20m/s、Mach=0、β=0、回転速度0。 $U_\infty=U(\cos\alpha,0,\sin\alpha)$ 。α=0、±1、±2度。形状をさらにαだけ回転しない。圧縮性・翼型厚さ・寄生抗力の補正を使わない。

基準量は全翼のxy投影面積 $S=8.4\,\mathrm{m^2}$ 、投影幅b=8m、平均空力弦 $\bar c=\frac{2}{3}(1.5)\frac{1+.4+.4^2}{1+.4}=1.114285714285714\,\mathrm m$ 。上反角でもこれらを変えない。基準点O=(.375,0,0)。荷重は風軸 $e_L=(-\sin\alpha,0,\cos\alpha)$ 、 $e_D=(\cos\alpha,0,\sin\alpha)$ 、モーメントは幾何+yの右手則で比較する。ピッチの数値符号を慣用名から推測しない。

## 4. 離散化と後流

UVLASは `dual-quarter-v1` を維持する。弦の物理境界はcosine、渦前端とコロケーションは各実パネルの1/4・3/4。中央の後退折れと上反角折れを共有境界にする。左右半翼のスパンcosine配置を個別に生成し、帯IDは全翼+y順。

AVLも同じ断面区間ごとにcosineを指定する。ただし同名のcosine指定だけで渦頂点が同一とは扱わず、実際の渦・評価点座標を保存する。

空間比較は弦M=[4,8,16,32]、全幅N=[12,24,48,96]。弦を変える系列はN=96固定、スパンを変える系列はM=32固定。対角4系列も保存して誤差相殺を確認する。最大3072束縛未知量。独立参照も同じ4系列を計算し、双方で少なくとも3段の収束傾向を確認する。最終2値の差だけを上限とは呼ばない。

UVLASの定常後流は+xの有限閉渦輪列で長さ $L_w/\bar c=[20,40,80,160]$ 、各帯の全列μを後縁μに等しくする。これでW-P1の面内渦層は0となり、内部列は相殺する。**定常試験は変数μの面内渦層を励起しない**。分割を変えても一定μなら同じ場を返すことを別に確認する。AVLの無限後流との差は長さ系列で分離し、末端閉鎖を無断で削除しない。

UVLASの主系列はε=0、辺上自己寄与は既存の有向辺ID除外だけ。面外後流には [近接求積契約](../uvlm-near-field-quadrature-contract.md) を適用する。先頭の束縛後縁と後流前端が同一点でも、後縁辺力は既存規約で除外する。

AVL原本には微小コアが残るため、参照監査用コピーで同一成分の `RCORE=0.0001*DSYZ` だけを0へ変更した系列も計算する。1行差・ソース／実行体ハッシュ・コンパイラを保存し、原本の結果も保持する。双方の一次荷重の差が共通尺度0.05%以下であることを採用条件にする。超えたら参照コア差を未解決として保留し、UVLASの核を変更して合わせ込まない。

## 5. 保存出力と指標

各αについて、全循環・法線・評価点、非貫通残差、全辺力と作用点、O周りの3成分モーメント、風軸L/D、基準量、後流端・コア・オプションを保存する。AVLの総量FT・帯量FSに加え、元出力・全セッション・単精度／倍精度と出力桁数を記録する。丸めによる出力不確かさが比較予算の10%を超える場合は出力精度を上げ、その差分を保存する。

主比較は角度radに対する中央差分

$$
C_{L\alpha}(\delta)=\frac{C_L(+\delta)-C_L(-\delta)}{2\delta},\qquad
C_{M_y\alpha}(\delta)=\frac{C_{M_y}(+\delta)-C_{M_y}(-\delta)}{2\delta}.
$$

δ=1度と2度の両方を比較し、δ差を0迎角極限の非線形影響として記録する。差分の分母にはradへ変換した値を使う。結果を見て都合のよい角度を選ばない。合力・モーメントの原値も保存し、傾斜だけの一致で有限迎角全体の品質を主張しない。

分布は固定y境界[-4,−3.6,…,4]の20帯へ保存的に再集計する。点値やc_lの単純補間で合力を変えない。辺中点の力を属する帯へ割り当て、境界上は+y側、最終端だけ最終帯へ入れる。AVLも同じ帯境界へ要素荷重を集計できる出力を用意し、FS重心の帯全体を別帯へ丸めて移さない。要素出力が足りない場合は原出力からの保存的再構成規則を先に追加し、分布の判定を保留する。

帯の傾斜荷重 $B_{j\alpha}=L_{j\alpha}/(qS)$ に対して

$$
e_{dist}=\frac{\sqrt{\sum_j(B^{UV}_{j\alpha}-B^{ref}_{j\alpha})^2/\Delta y_j}}
{\sqrt{\sum_j(B^{ref}_{j\alpha})^2/\Delta y_j}}.
$$

合計帯荷重と全体荷重の差も機械精度・出力丸めの範囲で照合する。先端を除外せず、点の特異性を帯積分として扱う。

## 6. 合否と誤差予算

入力版・形状・軸・荷重オプションが一致しない結果は数値比較前に不適格とする。最終比較の目標は次のとおり。いずれも今回の数値モデル照合用に事前指定する値で、公開データの実験精度ではない。

| 対象 | 条件 |
|---|---|
| 揚力傾斜 | 両δで独立参照差1%以下 |
| 幾何+yモーメント傾斜 | 両δで差を $\max(|C^{ref}_{M_y\alpha}|,0.1\,\mathrm{rad}^{-1})$ で規格化して1%以下 |
| 固定20帯の分布 | 両δで $e_{dist}\le2\%$ |
| α=0の値 | 左右対称の全力・全モーメントの絶対無次元値≤1e−9。外部出力丸めは別記 |
| 非貫通残差 | 各コードで既知速度尺度の相対1e−11以下。外部コードで算出不可なら残差証拠を追加するまで保留 |
| 保存的な帯集計 | 差≤1e−10、または明示された元出力の丸め上限以内 |

一次荷重の共通尺度に対する数値誤差予算は合計1%以下。配分上限はUVLAS空間0.30%、AVL空間0.30%、有限後流長0.15%、求積0.05%、参照コア0.05%、角度の極限差0.10%、線形求解・和・出力0.05%。相殺を期待して二乗和にしない。分布には空間系列を別に確認し、総量用の予算を分布精度の証拠へ流用しない。

非漸近・非単調で誤差が見積もれない系列は判定保留。予算内でもコード間差が上記条件を超えれば未達のまま保持する。共通尺度がゼロ近傍なら後付けの分母変更をせず、表の既定尺度を使う。

## 7. 誘導抗力・非定常・実験へ進む条件

FW-D01は別途、遠方後流の式・因子・積分・近傍との関係を導出する。AVLのCDiとUVLASの近傍Dをそのまま比較して片方を誤りとしない。流下方向の翼面力の誘導速度省略が二次量へ影響するため、既知速度のみを使う参照と全誘導候補の違いを分離する。抗力をゼロや負値へクリップしない。

規定運動の非定常比較は独立UVLM参照の版・起動履歴・後流・微分・調和抽出を別仕様で揃える。AVLの定常値や幅一列Theodorsenを有限翼の厳密な非定常参照へ流用しない。

[FLOWUnsteadyの45度後退翼例](https://flow.byu.edu/FLOWUnsteady/examples/wing-4p2aoa/) はWeber–Brebnerの実験条件を紹介しているが、その値をそのままUVLASの妥当性確認に使わない。原報の厚さ・迎角・壁／支持補正・圧力の上下面差・座標・不確かさを確認する。現時点では原データ監査未完了、実験合否は未設定。既存 [S10審査](s10-resource-audit-2026-10-29.md) も継続する。

## 8. 実行前ゲートと予算

この文書と入力マニフェストは比較準備であり、参照実行の完了ではない。AVL実行体の取得／ビルド・ハッシュ、原本とコア監査コピーの差分、オプションの記録手段、分布再集計・残差の取得、UVLAS近接評価器の独立検証を揃えてから数値比較へ入る。上限は1コード・1形状の全系列で1800秒、ピーク2GiB、全出力2GiB。上限を超えた系列を小さい格子へ置換して合格としない。

FW-D01：独立モデル差を軸・後流・コア・荷重則まで監査する。FW-D02：後退テーパ翼と上反角翼を、固定帯分布と合力／モーメントで比較する。FW-D03：一次荷重・二次抗力・非定常・実験妥当性を別ゲートで判定する。

後続の [原本ビルド・参照計測](avl-source-measurement-experiment.md) で残差・循環・全渦線力と作用点の取得と、計測前後の出力不変性を確認した。一方、コア0監査版が不要な横力・ヨーモーメントを出すことを発見した。第4節の一次傾斜感度条件内でも、この対称性問題が解決するまでコア0を受入参照として採用しない。固定20帯の保存的変換・全格子系列・UVLASとの比較は未実施。

[直線近傍核の追加検証](avl-collinear-kernel-experiment.md) でコア0の問題を切り分け、安定等価式の別Fortran候補を検証した。以後の比較準備ではAVL3.52/DP/zero-core-exterior-stable-v1を原本／未修正版と区別して扱う。今回の2格子・20条件での成立を全格子収束・固定20帯やUVLASとの比較の完了とはしない。

[全参照格子と固定20帯の検査](avl-fixed-band-convergence-experiment.md) で100条件を実施した。合力／モーメント保存は成立したが、総量の弦方向漸近性と固定帯分布の収束が未達。参照精度の受入・UVLASとの比較は引き続き保留する。製造分布による追加診断は元の点測度の結果へ置き換えずに保持する。

[一次荷重の分解](avl-linear-load-wrench-experiment.md) と [帯境界適合格子の別100条件](avl-band-aligned-grid-experiment.md) を追加した。力・モーメントの再構成は [別の観測契約](../spanwise-load-observation-contract.md) として扱い、元点の荷重と構造写像を変えない。観測・有限迎角を分離しても漸近性条件は未達であり、参照精度の受入とUVLAS比較は未完了。
