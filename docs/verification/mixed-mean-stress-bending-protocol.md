# MMS-1：先頭曲げエネルギーの実行前仕様

2026-11-04。[導出](../mixed-mean-stress-leading-energy.md)を用い、同じMMS-1空間・τ=2.5を維持する。前段は[位置近似・局所検証](mixed-mean-stress-results.md)。

まず有限厚さの線形化エネルギーと先頭係数を照合する。平坦正則・曲面正則・曲面歪みのn2各最初のセル、固定seedの全q0/q1核の2方向、q2=0。t=.04/.02/.01/.005のU(t)/t³を先頭値と比較する。全相対差1e−8以下なら丸め域の恒等式、それ以外は最終差1e−3以下かつ連続する半減の観測次数が1.8〜2.2を要求する。別15²×9の先頭値の差1e−8。この係数照合を有限厚さ大域精度の試験とは数えない。

大域は平坦／解析曲面×正則／歪みn2の4配置と歪み曲面n4の計5。q0/q1は前段で得た全混合制約核、q1同次核を保持する。q2内部は値域を直交消去し、共有q2も組み立てる。ζ奇の目標に対してq1奇・q2偶を残し、既知の零方向だけをゲージとして商に取る。小剛性を足さない。

目標は四次b=x⁴/12、五次b=x⁵、指数b=exp(x)−1−x。曲率はそれぞれx²、20x³、exp(x)。元の全面・TB安定化条件、A0q0=0、混合応力仕事、全3次数の共有・固定端を復元場で検査する。E0を点ごとに零に戻さない。

主13²×7、別15²×9。制約・共有・支持残差1e−9、停留と主／別誤差差1e−8。q2値域・共有制約・目的関数rankは1e−9/10/11の一致を要求する。共有q2を値域消去した後のq0/q1目的関数は全列rankを要求し、先頭の新たな零モードを見逃さない。応力空間の厳密rank証明と丸め参照形状の差1e−12も再確認する。

独立監査では保存した全次数・全位置成分から、3Dテンソルの等方エネルギー・鉛直面安定化・全共有／支持・混合仕事を別に評価する。独立な大域再求解を行ったとはしない。

必要精度条件は、全配置の四次エネルギー誤差と先頭位置L²誤差1e−8以内。歪み曲面n2→n4で五次・指数のエネルギー誤差と位置L²誤差がともに減少し、n4では両指標とも1%以下。位置は最良近似ではなくエネルギー最小解で評価する。いずれか未達なら有限厚さ採用検証へ進めない。

診断用資源は1問題900秒、系列1800秒、ピーク2GiB。停止や未達を保存し、未実施を合格にしない。製品の有限厚さ最細1%・薄肉増幅2倍は維持する。解析曲面・参照線形化・有界正則展開の条件付き結果であり、一般非線形薄肉極限・一様inf-sup・有限厚さ誤差下界は主張しない。
