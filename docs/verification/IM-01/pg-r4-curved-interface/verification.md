# 凍結R4の曲面接続と全厚固定支持

凍結R4の曲面を幅 $1/2\,\mathrm m$ の2パッチに分け、同じ厚さ $H=1/20\,\mathrm m$ とした。左端を全厚固定し、接続の分割数を $(1,1)$ と $(1,2)$ で比較した。入力は[凍結実験](../../../../rd/structure/main-shell/paired-geometry/experiments/check_mass_paired_interface.py)から取り、幾何と分割を製品の型付き入口に渡した。[凍結結果](../../../../rd/structure/main-shell/paired-geometry/records/mass-paired-interface-result.json)から比較に使ったのは接続後の自由度と拘束ランクである。

## 独立した照合

世界座標の高さを $f(x,y)=x^2/5+y^2/10+7xy/100+x^3/30-y^3/50+x^2y^2/40$ とした。各共通辺区間の内点で、この式を直接微分して $v=(-f_x,-f_y,1)$ を作り、$g=v\cdot v$ と法線 $v/\sqrt g$ を求めた。深さ $-1/40,1/100,1/40\,\mathrm m$ の位置 $(x,y,f)+zv/\sqrt g$ を、製品の座標と $a+b\sqrt g$ の係数ごとに厳密に照合した。2構成の合計18点について、共通辺の左右と根元の固定辺を評価した。高さと法線の参照計算には製品パッチの係数や微分を使っていない。

| 分割数 | 局所基底の列数（左／右） | 共通辺の区間数 | 拘束ランク | 自由座標数 |
|---|---:|---:|---:|---:|
| $(1,1)$ | 171／173 | 2 | 116 | 228 |
| $(1,2)$ | 171／350 | 4 | 171 | 350 |

製品経路は認定基底から `PgPreparedPatch` を作り、`PgFullTrace` で接続と全厚支持を取り出し、`PgGlobalConstraints` と `PgSparseChart` に渡す。参照形状の全接続行が零になることと、一般の自由座標をリフトした後に全原行で $Cq=c$ が成立することを確認した。各試験点でリフト後の共通辺位置が一致し、固定辺の位置も独立参照と一致した。

自由座標 $r$ に対してリフトの原点との差が $Jr$ となること、$f^\mathsf{T}Jr=(J^\mathsf{T}f)^\mathsf{T}r$ と指定値を含む仕事を厳密に照合した。共通辺の内点に同じ物理力を逆符号で与え、左右の力をそれぞれの基底で原座標へ写した。$1$ と $\sqrt g$ に対応する荷重を別々に処理し、どちらの $J^\mathsf{T}f$ も零となった。同一面を同じ外向き順序で接続する負対照は、形状と厚さが一致していても `GeometryInvalid` となった。向きの判定を外す変異では、この負対照が失敗した。

## 準備条件と再実行

曲面Gramには、生の多項式の評価を素数 $1\,000\,000\,007$ 上でふるい、各体積片を覆う正の重み付き点列を与えた。面内の各点に異なる深さを3点取り、左1分割267点、右1分割270点、右2分割594点を使った。点選びは入力生成に使う。合同変換の $10^{-20}$ 上限と必須場は製品の認定を通した。Gramの作業格子と出力格子の小数部は768と704ビット、因子と変換候補の小数部は768と128ビットとした。因子の保持には3,072ビットの固定整数を使う。固定チャートの厳密値の上限は65,536ビット、演算途中の上限は262,144ビットとした。

[実行ソース](run-series.cpp.txt)を C++23 としてコンパイルする。通常の Release ビルドの `uvlas_structure`、`uvlas_numerics`、`uvlas_core` と Catch2 の試験用 main をリンクする。インクルード先は `include`、`src/structure`、`tests/structure` と依存ライブラリ。MSVC のリンクには `/STACK:67108864` を指定した。独立試験として数分以上を要するため、実行ファイルを直接実行した。確保量は、48 GiB の `ResourcePlan` が各段階までに記帳した累積値であり、RSS とは異なる。

WindowsとLinuxでは同じ有限則を使い、MSVC実行用ソースでは進捗行の改行とフラッシュを `std::endl` と書いた。 確保量は下表のとおり。

| 分割数 | 段階 | MSVC Release（B） | GCC14 Release（B） |
|---|---|---:|---:|
| $(1,1)$ | 左右 `PgPreparedPatch` | 4,213,934,912 | 4,234,859,136 |
| $(1,1)$ | 全厚接続と固定支持 | 4,376,827,016 | 4,397,751,240 |
| $(1,1)$ | 疎チャート | 4,515,395,528 | 4,536,319,752 |
| $(1,2)$ | 左右 `PgPreparedPatch` | 8,760,725,040 | 8,815,489,536 |
| $(1,2)$ | 全厚接続と固定支持 | 9,111,471,208 | 9,166,235,704 |
| $(1,2)$ | 疎チャート | 9,607,872,912 | 9,662,637,408 |

MSVC Release と GCC 14 Release で、2構成を含む1試験の286,904アサーションがそれぞれ通った。向きの検査だけを外したMSVCの変異では、同向き接続の拒否を確認するアサーションが失敗した。Clang-Tidyは実行ソース1翻訳単位を検査した。

この試験は、凍結形状の幾何・全厚拘束・共役な力の写像を製品経路で照合する。曲面の連続内積に対する有限則の誤差、3次元材料、質量・剛性、平衡変位・応力、同じ平衡状態での固有振動は範囲外である。型付きパッチは凍結実験から直接作成しており、ケースファイルの取込み経路は別の照合を要する。
