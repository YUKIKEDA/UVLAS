# 準備済みパッチから物理参照量を射影する

準備済みパッチは、認定済み基底から参照位置、形状関数、Cartesian 勾配、体積または面の正の測度を返す。Binary64 と TwoWord の両経路で、点順、基底列順、層、上下の片側と側面、パッチ識別を保持する。固定則の点と重みを使う体積の反復作用、全位置拘束の証拠は[準備済みパッチと全厚拘束の検証](pg-prepared-patch-trace.md)に記録した。

回転・並進を持つ平板で、体積、層界面の上下、側面を同じ呼び出しに含めた。厳密な参照評価と、独立に有理数へ復元した上位語・下位語を、Binary64 では $2^{-32}$、TwoWord では $2^{-72}$ の成分別絶対誤差で照合した。比較には各成分固有の物理単位を使った。位置の誤差枠を零にした要求と確保枠不足が拒否され、パッチの識別は保持された。

放物柱面の厚さ方向にずらした面では、パラメータ接線の長さを幾何式から求め、独立に面積を挟んだ。平方根の上下端は 256 bit 格子の有理数として二乗で確かめた。面積の TwoWord 値は、その区間を含む誤差 $2^{-72}$ [m²] を満たした。

面積の高位語では、1 と隣の表現の中点、次の中点で最近接・偶数が反対方向に働くことを確かめた。下位語は正・負の厳密残差をそれぞれ照合した。下位語の中点では、一方の端に丸めた後に残る $2^{-107}$ の誤差を零の要求が拒否した。

Windows MSVC 19.51 と Linux GCC 14.2 の Release で、射影の実装を含む `ce96248d5b4f37b681f53ba22fb6a473526cab0d` の統合対象が各 13 件通過した。その後の `d76bd831f87a31380a454a8172d3b9a9437464df` では、丸め中点を含む条件付けと、部分面の拘束を再確認した。
