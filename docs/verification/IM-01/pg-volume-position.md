# PG体積点の位置写像と転置の検証

[体積点位置写像の契約](../../specs/structure/pg-volume-position-contract.md)に従い、同じ基底係数を使う順方向と転置を検証した。SH-D02、SH-D05、N4-02、N4-03、N4-06、N4-08、N4-09に対応する。

## 独立照合

n=1平板の異なる材料層に1点ずつ置いた。認定後の全109列を使う。期待値は、元基底の局所単項式と厳密な変換係数から各点のNを独立に評価し、入力のBinary64語を仮数と指数から有理数へ戻して求めた。順方向は点の6成分、転置は列の327成分を各表現で比較した。合わせて666成分になる。

TwoWordでは、座標と点の共役力のそれぞれに非零の低位を与えた。低位を持つ参照にBinary64座標を渡す組み合わせも検査した。出力した各場の誤差は、Binary64で $2^{-32}$、TwoWordで $2^{-75}$ を上限とした。順方向と転置の仕事の差は、各成分の誤差上限を入力の絶対和で重み付けした値と比較した。

固定整数演算は、最大有限値同士の積の打消し、最小subnormalの復元、subnormalの中点、有限語に入らない結果、真の残差を保持する低位を別に照合した。単位係数を与え、保存Nによる積和を厳密に保持できる場合でも、準備時のNの誤差を含めると誤差枠0では拒否することを確かめた。

## 再利用と失敗

両形式で、同じ作業領域と出力を順方向、再実行、転置に使った。監査は実際の計算入口を囲み、成功9呼出しと上の精度拒否2呼出しにおけるC++確保試行を数えた。いずれも0だった。

必要作業量ちょうど、1不足、Workspaceの1 B不足、取得済みWorkspace、非有限入力、停止済みトークンを検査した。各失敗の後には直前の成功結果を照合し、同じWorkspaceで再評価した。出力を先に段階書込みした後の精度拒否でも、結果は失われなかった。

クロス項 $N_{hi}v_{lo}$ だけを省いた変異を、隔離した翻訳単位で実行した。独立照合など114アサーションが失敗し、低位の欠落を検出した。

## 実行環境

Windows 11 x64ではMSVC 19.51.36260のDebugとReleaseで対象CTestを各1件実行し、両方が通過した。Ubuntu 24.04 x64ではGCC 14.2.0のASan・UBSanで対象を実行した。7ケース、52,475アサーションが通過した。Boostは両OSとも1.92.0を使用した。clang-tidy 21.1.1は2翻訳単位を検査した。

IM-01の固定体積点に対する結果である。材料・体積積分を含む精度は、IM-02の開始条件を満たした後に検証する。
