# PG条件付けの候補生成と認定の検証

[候補生成の契約](../../specs/structure/pg-conditioning-generated-transform-contract.md)をSH-D03、N4-02、N4-08に沿って検査した。

## 実際の平板の参照

区分一次厚さを持つ $n=1$ の切断平板から、製品の共通分割、局所rank、Gram包絡を経て、変換を生成した。因子格子は512 bit、候補とGramの格子は256 bitを指定した。認定結果は元の区間に対する合同誤差上限 $10^{-20}$ を満たした。

試験では、独立積分から得た区間の中点を多倍長のCholeskyと三角解法で処理した。その結果と製品の全上三角係数を比較し、差が候補の格子1単位以内であることを確認した。さらに、返された変換と変換後の座標から、33の必須場について元の座標を厳密に再構成した。必須場の後続座標はすべて零だった。

## 独立した算術対照

対角が2と1/2、非対角が3/4の上三角因子を持つ2×2ブロックを単位行列に埋め込んだ。得た変換は既知の逆行列に一致し、認定誤差は0だった。元区間の中点を保ったまま対角区間を広げると、PrecisionUnresolvedが返った。粗い因子格子で正のピボットを得られない場合も同じ失敗を返した。

不正な形、逆順の端点、格子外の端点、過大な格子幅、事前取消を検査した。生成と認定を合わせた作業・確保について、計上値ちょうどの成功と1不足の拒否を比較した。失敗時は基底を保持し、改めて認定できた。

## 実行環境

Windows 11 x64のMSVC 19.51.36260では、DebugとReleaseの対象CTestが各1件通過した。Ubuntu 24.04 x64のGCC 14.2.0では、ASan・UBSan付きの対象4ケース、89,152アサーションが通過した。UBSanは最初の違反で停止する設定とした。GCC 14.2.0のReleaseは、既存の切断多項式に対するコンパイラ警告修正 `d24162cf` のヘッダを同じソースの別コピーに適用し、対象CTestが1件通過した。Boostは両OSとも1.92.0を使った。clang-tidy 21.1.1で3翻訳単位を検査した。

認定で元区間を中点だけの区間へ差し替える変異を試した。区間幅だけを広げた対照が予期せず成功し、1アサーションが失敗した。

この結果は供給したGram区間に対するものである。曲面や非定数高さの区分求積における区間生成は、後続の検証で扱う。
