# PG一定厚平板の切断領域における幾何内積の検証

[切断領域の内積契約](../../specs/structure/pg-flat-gram-cut-contract.md)に従い、共通分割を通した幾何内積を独立計算と照合した。対象はSH-D03、SH-D07、N4-02、N4-08。

## 斜辺切断と全被覆の照合

斜辺を $s+t=1+1/(4n)$ とする多角形を使った。全被覆セル、上側の三角形を除いたセル、下側の三角形だけが残るセルを含む。$n=1$ では、斜辺と交差する内部の細分線も与えた。試験側は共通分割の辺を使わず、既知の角の三角形を二重積分した。局所単項式ごとに、逐次積分で得た有理数を128 bit二進格子へ外向きに丸めた。

$n=1$ は全区間の両端に一致し、供給された同じ区間から合同変換を認定した。$n=2,4$ は全上三角を準備し、離れた4列の組合せの両端を独立値と比較した。格子線に沿う別の領域では、活動する1セルの全区間が矩形の公式に一致した。既存の全背景の試験にも同じ実装を使い、従来どおり全区間と合同認定を照合した。

## 資源と拒否

不足するResourcePlanで拒否した後、同じ基底を使って準備を通した。別の領域では座標分母を $2^{190}$ とし、切断モーメントの共通尺度の作業幅が8192 bitを超えることを確認した。結果はResourceExceededで、準備済み基底を再利用できた。変厚、曲面、事前取消、作業枠不足に対する従来の負対照も実行した。

## 実行環境

Windows 11 x64のMSVC 19.51.36260では、DebugとReleaseの対象CTestが各1件通過した。Ubuntu 24.04 x64のGCC 14.2.0では、ASan・UBSan付きで10ケース、84,578アサーションを通過した。UBSanは最初の違反で停止する設定とした。両OSともBoost 1.92.0を使った。clang-tidy 21.1.1で2翻訳単位を検査した。

部分セルで奇数総次数のモーメントを捨てる変異を加えた。独立照合と合同認定で4,389アサーションが失敗した。

この結果は認定済みの平板形状での幾何内積に適用する。曲面・変厚の保証付き内積、候補変換の製品生成、物理質量の認定は後続工程に属する。
