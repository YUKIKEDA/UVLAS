# R-02の補正後に全厚位置差を実空間で囲う

凍結R-02の2・3・4パッチを、元有理CSRで補正する[製品入口](../../../specs/structure/pg-chart-original-refinement-contract.md)で解いた。返った二語をそれぞれIEEEのビットから厳密有理に戻し、全原行の $c-Cq$ を再計算した。参照長と全厚がともに1 mの平板で、全共通線分の沿い範囲 $0\leq u\leq 1$ と深さ範囲 $-1/2\leq z\leq 1/2$ を元所有データと照合した。

各線分・各成分の残差を $\sum_{i,j} d_{ij}u^i z^j$ と表す。その最大絶対値は $\sum_{i,j}|d_{ij}|(1/2)^j$ 以下。全元行を正しい線分と深さ次数に振り分けて和を求めた。3成分の上界から、全厚位置差のユークリッドノルムがこの試験の $10^{-14}$ m 以下であることを有理数の二乗比較で検査した。

| パッチ／接続 | 位置差の最大成分の上界 [m] | ユークリッドノルムの上界 [m] |
| ---: | ---: | ---: |
| 2／1 | $6.652\times10^{-17}$ | $1.153\times10^{-16}$ |
| 3／2 | $6.652\times10^{-17}$ | $1.153\times10^{-16}$ |
| 4／4 | $1.867\times10^{-17}$ | $3.234\times10^{-17}$ |

同じ保持語から元力の釣合いと仕事も再確認した。未補正の候補に対する既存の負対照は元係数の上限で拒否した。物理空間の上界はこの平板系列の全点に適用する。曲面や別の厚さでは、対応する法線分母と深さの範囲が必要になる。 [未補正の実空間の差](../pg-chart-original-defect.md)

MSVC Releaseの統合製品 `d6751d51` で、順に66,097、93,801、190,800アサーションが通過した。[追加ランナー](run-physical-trace.ps1.txt)を `.ps1` としてコピーし、元の[系列ランナー](run-series.ps1.txt)と同じ引数でリポジトリルートから実行する。元の計測記録は保持し、追加した[照合](check-physical-trace.cpp.txt)は製品の求解時間に含めない。
