# 準備済みPGパッチ、全厚位置拘束と体積参照作用の検証

認定済み基底を物理座標、外周の原拘束、固定体積点の反復作用へ渡す経路を検証した。採用式と入口は[準備済みパッチ](../../specs/structure/pg-prepared-patch-contract.md)と[全厚位置拘束](../../specs/structure/pg-full-trace-contract.md)に記載した。

| 試験 | 独立照合と拒否 |
| --- | --- |
| `structure.pg_prepared_patch` | 原点、回転、参照長が自明でない平板で、解析的な物理参照位置、並進1、体積と上下面での物理Cartesian勾配を照合した。取消、作業量不足、確保不足では認定元の所有を保持した。 |
| `structure.pg_full_trace` | 左右で次数、参照長、背景幅、厚さと分割が異なる切断辺を使った。共通細分の4区間から各1点と実深さ3点を選び、全厚係数行から復元した値を、同じ深さで左右の基底を評価する独立参照と照合した。原行の転置と仕事、正規化した双対の復元、非零の固定支持位置も厳密に照合した。両側の第0層を辺の内部区間に切り出し、端点の物理深さを照合した。同じ向き、深さの非重複、別世代、取消と予算不足を拒否した。同じ支持辺を等分した2区間では、2本の非零な曲げ一次係数行が同じ一意行と元の尺度を持ち、共有行の先頭係数が1となることを確認した。 |
| `structure.pg_discrete_gram` | 放物柱面では回転と参照長を含む参照位置の再現を照合した。辺に沿って法線分子が変わり、選んだ一成分が端点で零になる接続でも、独立の点評価と全厚拘束が一致した。同じ固定則の2体積点について同じ認定基底から厳密Jacobianと全基底列を直接評価し、Binary64とTwoWordへの射影と比べた。位置6成分と転置390成分は、直接評価したNを用いる独立の有理積和で照合した。点範囲、識別、容量の失敗も調べた。 |
| `structure.pg_conditioning` | 既存の平板・切断・厚さ区分、条件付け候補と精度境界を回帰確認した。 |

外周は元の共通分割に属する辺だけを使用する。接続の試験は端点順と反対の境界向きを含む。体積点の作用は既存の整数積和と射影を使うため、Jacobianと重みは作用の入力から独立に保持される。


## 実行結果

対象ソースは 52d8af03。MSVCの全厚試験は同コミット、ほかの3本は内容が同じ a16713c7 の実行を記載した。GCC 14.2.0では ASan と UBSan を有効にし、UBSan は最初の違反で停止する。Boostは両OSとも1.92.0を使った。

| CTest | アサーション | MSVC Release [s] | MSVC Debug [s] | GCC14 ASan/UBSan [s] |
| --- | ---: | ---: | ---: | ---: |
| `structure.pg_conditioning` | 193,162 | 15.11 | 79.91 | 対象外 |
| `structure.pg_discrete_gram` | 34,073 | 23.85 | 210.17 | 421.00 |
| `structure.pg_prepared_patch` | 54 | 0.35 | 2.15 | 3.83 |
| `structure.pg_full_trace` | 1,057 | 4.17 | 36.85 | 73.94 |

初回の曲面試験は、MSVC Debugとclang-tidyの実行中にGCC14 ASan/UBSanで418.05秒で完了した。曲面試験のLinux sanitizer枠を420秒から540秒にした。通常構成の300秒、数値許容および計算の作業量上限は同じである。変更対象10翻訳単位はclang-tidy 21.1.1で検査した。MSVCのDebugでは最終追試で、重複行テストの比較に同じspan範囲の検査付きiteratorを使うよう修正し、再検証した。

負対照は `1d572dc8` の隔離ソースで $C$ の曲げ係数 $1/(2L_{ref}^2)$ から $1/2$ だけを除いた。曲げ成分が効く8点で、原拘束行から復元した値と独立点評価の比較が失敗した。892アサーション中884件が通ったので、この変異は他の零・定数場を通している。

## 後続段階への入力

固定有限則は実際に使った点、重み、共通分割を保持する。[条件付け認定](../../specs/structure/pg-discrete-conditioning-certificate-contract.md)の合同誤差上限は、この有限離散内積に適用される。曲面の連続内積を製品で認定するには、三角形の点・重みと精度、共通分割での適用、三段階の細分と独立参照に対する合否、確保と作業量の上限を定める必要がある。

ここで作る原行は局所接続と固定支持の入力になる。[局所と大域の契約](../../../rd/structure/main-shell/paired-geometry/paired-reference-local-global-contract.md#L35)で求める交点・閉路の基準点と面の優先規約は大域で必要になる。例として \(x_1-x_2=0, x_2-x_3=0, x_1-x_3=0\) はどの2行でも同じ許容空間を決めるが、同じ一般化反力を表す各原行への配分は選択で変わる。時間依存右辺の適合性を示す例として、3行目を \(x_1-x_3=t\) にすると、\(t=0\) で適合する一方、他の時刻で不適合になる。時間依存の右辺を扱う段階には、係数全体を照合できる入力契約が必要となる。
