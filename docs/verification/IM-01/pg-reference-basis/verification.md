# PG局所独立基底と物理参照点の照合

[点評価契約](../../../specs/structure/pg-reference-basis-contract.md)をWindows 11 x64、MSVC 19.51.36260、Boost 1.92.0で確認した。

- n=1の四次グラフをチャート内の正面積の部分領域に切り、厚さ勾配、参照長2 m、軸を置換する右手回転を指定した。選択したX位置列とZ方向の法線director列のNと全偏微分を、有理数の手計算と照合した。独立に計算したJacobian各列に製品Gを内積し、3方向全てで独立偏微分に厳密に戻ることを確認した。Jacobianは正則なのでこの3等式がGを一意に決める。
- n=2の平面で厚さ二次の中央C列を検査した。片側で傾きが変わるs=1/2の節で同じ物理点のNと二つの微分を照合した。内部層界面の上下の面と、外側面はそれぞれ指定した面種別を保持した。
- 順序だけが異なる元領域、予算0、取消済みの結合では両所有候補を再利用できた。結合後は無効列を確保前に拒否した。点呼出しの有理数処理・訪問・payloadは実測の等号と1不足で検査し、事前取消で確保0を確認した。

既存の局所rankおよび参照幾何の対象CTestはWindows Debug・Releaseで各2件通過した。既存の原辞書列の点評価も同じ対象試験に含む。

## 変異と静的検査

製品の幾何翻訳単位を別ディレクトリに複製し、通常のWindows Releaseと同じ警告・最適化でコンパイルした。二つの変異を一つずつ入れた。余因子を作る外積の左右を逆にすると独立Jacobianの引戻しで5件、面内微分のHの勾配項を零にするとチャートと物理の照合で4件のアサーションが失敗した。どちらも四次の選択基底試験が検出した。

Debugの参照幾何・選択基底は10ケース・1,710アサーション、局所rankは8ケース・81,063アサーションを通過した。clang-tidy 21.1.1は影響する製品2翻訳単位と試験1翻訳単位を通過した。
