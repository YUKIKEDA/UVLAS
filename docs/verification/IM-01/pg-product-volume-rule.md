# 切断曲面で正重みの積則を検証する

放物柱面 $f(s,t)=s^2/16$ を、$0\le s\le1$ で $s/4\le t\le1-s/8$ の領域に切り取った。参照長は2 m、物理全厚は $1+s/2$ m。背景格子は $n=1$、層の境界は $\zeta=-1,-1/3,1$ とした。共通分割の40体積に、同じ [積則](../../specs/structure/pg-product-volume-rule-contract.md) を写した。

## 離散点と層内モーメント

面内の単位区間則は座標 $1/4,3/4$ と重み $1/2,1/2$。層内には座標 $1/4,5/6$ と重み $4/7,3/7$ を置いた。各体積の8点について、元の番号、三角形の座標、層内位置と重みを独立の有理値と照合した。重みの総和は $1/2$、重み付きの層内一次・二次モーメントは $1/4,1/6$。第1則で一次モーメントを崩す、座標を重複させる、ゼロ重みを入れる、因子を空にする入力を拒否した。容量が不足する場合は元の基底を保持した。

## 連続体積との照合

物理Jacobianの厚さに関する奇成分は、全厚にわたる積分で相殺する。幅と全厚を実領域で積分すると、参照長の3乗で無次元化した体積は

$$
V_{\mathrm{ref}}=\int_0^1 (1/2+s/4)(1-3s/8)\sqrt{1+s^2/64}\,\mathrm ds .
$$

独立参照は平方根の二項級数32項を厳密有理数で積分し、最初に省いた項で絶対誤差を囲った。有限則側は、一定並進を表す選択基底の係数を幾何内積の両側に掛け、全体積を囲う。面内の5点Gaussの対称な有理近似と、各層で厚さの一次式を積分できる中点を使った則では、区間の両端が独立参照と $10^{-12}$ 以内で一致した。面内2点の対照は同じ幅に収まらなかった。

この比較が対象とするのは、切断曲面の幾何体積。各基底組の連続内積、荷重・剛性、解析条件からの求積次数の選択は後続の受入で扱う。

## 試験結果

`527ee840` を Windows MSVC 19.51 と Linux GCC 14.2 の Release で検証した。対象の構造 CTest は各5件が通過。追加試験は1,746項目で、試験時間は順に54.38秒と38.56秒だった。

Linuxの隔離ソースで三角形へのJacobianを省くと、最初の重みが期待値 $3/28$ に対して $1/7$ になった。層内重みを省いた変異では $3/16$ になった。どちらも最初の重みの照合が失敗し、元のソースを復元すると1,746項目が通過した。積則と新旧の試験翻訳単位を clang-tidy で検査した。
