# PG条件付け基底の片側評価

[点評価契約](../../../specs/structure/pg-conditioned-reference-point-contract.md)を、製品のn=1平板の参照・rank・離散合同認定から連続して検査した。解析積分した全5,995内積成分を使った認定で得た変換を、同じ所有者で評価した。

試験は局所単項式と変換候補の厳密有理数から、独立にNとs,t,ζ偏微分を計算した。単位参照枠、全厚2 mの平板で物理Jacobianが単位行列なので、同じ独立値でCartesian勾配を照合できる。変換に元基底2列以上が寄与し、s=1/2の左右でs偏微分が異なる列を選んだ。両側のNは共有点で一致し、各側の偏微分は独立値に一致した。層界面の上下は別の層IDと面側を返し、外側面のN・偏微分・勾配も独立値に一致した。

不正な列と面、事前取消、走査・有理数演算・確保の等号と1不足を検査した。列不正と事前取消は確保0だった。

Windows 11 x64、MSVC 19.51.36260、Boost 1.92.0で実行した。Debug・Releaseで条件付けと参照幾何の対象CTestは各2件成功した。条件付けの2ケースは18,799アサーション、参照幾何の10ケースは1,710アサーションを通過した。

条件付けの変換重みに1を加える変異を、製品翻訳単位の隔離コピーに入れた。独立した値・偏微分・物理勾配との照合で25件のアサーションが失敗し、変異を検出した。

clang-tidy 21.1.1は影響する製品2翻訳単位と試験1翻訳単位で通過した。
