# PG曲面の離散幾何内積と条件付けの検証

[曲面の離散幾何内積](../../specs/structure/pg-discrete-gram-contract.md)に従い、固定した求積点と選択基底から区間Gramを求め、同じ基底と求積点を所有する変換認定へつないだ。SH-D03、SH-D07、N4-02、N4-03、N4-08に対応する。

## 放物柱面の固定則

参照グラフは $f(s,t)=s^2/16$、参照長は2 m、全厚は1 mとした。共通分割の16体積レコードを各63点、計1,008点で覆った。各点の重みは1/126。点はこの有限則の確認用に用意した。

独立参照は放物柱面の曲率から法線オフセットのJacobianを解析的に求め、元基底の局所単項式から各点のR/P/Cを有理数で評価した。Pythagorasの恒等式を使って面内座標を選び、$\sqrt g$ を厳密な有理数にした。上三角8,515成分のうち13種類の対角・非対角成分を独立和に照合した。包絡の幅は最終格子の2刻み以下だった。

作業352 bit、出力272 bitの格子で包絡した。因子512 bitと候補216 bitを明示して変換を生成し、合同変換の行和誤差上限 $10^{-20}$ を満たした。出力176 bitの試行ではPrecisionUnresolvedが返った。独立の160桁因子から求めた変換と全8,515係数を候補格子の1刻み以内で照合し、必須33場を厳密に復元した。

## 非平方の平方根と拒否

同じ曲面の各三角形の重心と層の中点を1点ずつ選んだ。$g$ が有理数の平方でない点を含むことを確認した。256 bit格子の独立な平方根区間は両端の二乗を有理数で比較して保証した。この区間と曲率から求めた対角・非対角の2成分を、製品の区間が包絡した。この点数で変換の認定を求めるとPrecisionUnresolvedを返し、点列と包絡は再利用できた。

体積の欠落と逆行、ゼロ・負の重み、不適合な格子、確保枠と固定整数仕事量の不足、取消を検査した。準備失敗後は元の基底を保持し、変換の確保拒否後は同じ内積を使った。元の点の座標と重みを変更してから認定へ進み、認定結果の体積番号、全座標と重みが準備に使った値に一致することを調べた。

## 試験構成と負対照

曲面の2ケースは専用実行ファイルで24,063アサーションを確認した。既存の条件付け13ケースは193,162アサーションを確認した。Boostは両OSで1.92.0を使用した。

| 構成 | 既存の条件付け | 曲面の離散Gram |
|---|---:|---:|
| Windows MSVC 19.51.36260 Release | 21.85秒 | 29.72秒 |
| Windows MSVC 19.51.36260 Debug | 101.32秒 | 167.79秒 |
| Ubuntu 24.04 GCC 14.2.0 ASan・UBSan | 157.57秒 | 340.10秒 |

Linuxでは、曲面と並行した既存試験が180.15秒で時間切れになった。既存試験の表の値は単独の再実行で得た。

既存の180秒枠で曲面を含むと、Windows DebugとLinux sanitizerでは時間不足になった。専用実行ファイルへ分け、既存試験は180秒、曲面はWindows 300秒・Linux sanitizer 420秒にした。Windows multi-configとLinux single-configの生成されたCTestで実行ファイルと時間枠を確認した。

Linuxの隔離ソースで参照長の3乗による無次元化を外すと、非平方の点列で2件の区間照合が失敗した。変異の試行は6.85秒で終了し、復元したソースは検証コミットとSHA-256が一致した。clang-tidy 21.1.1はGram本体と試験2件の翻訳単位を検査した。
