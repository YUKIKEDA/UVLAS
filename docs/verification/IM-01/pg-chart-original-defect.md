# R-02 の未認定候補を元拘束と実空間で調べる

[数値候補のR-02試験](pg-chart-candidate.md)では、原拘束を使った上界が暫定の係数許容 $10^{-5}$ を超えた。原因を切り分けるため、同じ凍結データと固定ピボットで候補を作り、元の有理CSRと保持された両語から真の残差を計算した。診断実行では元行残差の許容を $10^{10}$ にして、拒否された候補の観測だけを可能にした。元の受入条件と記録は保持した。

前進は $Cq-c$、転置は $f-C^T\lambda-R^T h$ を有理積和で評価した。全厚トレースの原行には、共通線分の沿い座標 $u$ の昇冪と、法線深さ $z$ に対する三つの次数が格納されている。R-02の形状は平板、参照長1 m、固定された厚さ1 m。法線分子の尺度は1であり、曲げ場の係数には元行を作る際の $1/2$ が入っている。各原行を元区間と次数へ戻し、$0\le u\le1$、$-1/2\le z\le1/2$ で、有理なトレース誤差を再構成した。

最大成分の下界は全区間の有理点、上界は沿い方向30次、厚さ方向2次のBernstein係数で求めた。Bernstein基底の非負性と和が1であることから、係数の最大絶対値で全域を囲える。全区間で上下界は表示桁で一致した。

| パッチ／接続 | 原位置係数残差の最大値 | 実位置差の最大成分 [m] | 原力釣合いの最大残差 | 仕事の差の上界 |
| ---: | ---: | ---: | ---: | ---: |
| 2／1 | 0.793991 | 0.848192 | $3.84348\times10^{-5}$ | $1.039\times10^{-14}$ |
| 3／2 | 0.793991 | 0.848192 | $2.58620\times10^{-5}$ | $1.377\times10^{-13}$ |
| 4／4 | 0.634019 | 0.677482 | $4.88334\times10^{-5}$ | $5.441\times10^{-13}$ |

真の位置係数残差と力釣合いは、全系列で診断前の暫定許容を超えた。同じ戻り値で仕事が一致しても、位置拘束の成立は別に検査する必要がある。この結果から、係数区間を狭めて上界の保守性を下げるだけでは実接続の候補は適格にならない。同じ因子を補正に使う場合は、元の有理作用で残差を作り、補正後の全原行を再確認する。

MSVC Release。製品本体は統合時点の `834b5731`。既存[系列ランナー](pg-chart-candidate-series/run-series.ps1.txt)の元入力を使う。[計測関数](pg-chart-candidate-series/measure-candidate.cpp.txt)の `if (q && dual) {` 一行を[診断用の差込み](pg-chart-candidate-series/inspect-physical-defect.cpp.txt)で置き換え、診断用の許容を指定する。診断用の値は製品の検証や性能受入に使用しない。指定した全3ケースで型・区間・有理包絡の検査が通った。
