# 曲面Gramの次数を独立な連続モーメントで調べる

[幾何体積の試験](../pg-product-volume-rule.md)と同じ切断放物柱面を使う。4つの背景半セルの中で、局所座標の単項式の積を積分した。ねらいは、体積に使えた5点則から、基底の高次項が必要とする点数を区別すること。観測量は参照長の3乗で無次元化したモーメントとし、比較の目安を絶対差 $10^{-12}$ に置いた。

## 連続積分を三角形の積則から独立に求める

$g=1+s^2/64$、$z$ は参照長で無次元化した法線方向距離。基底の各場に掛かる因子は $1$、$z/g^{3/2}$、$z^2/2$。体積Jacobianは $\sqrt g-z/(8g)$。各因子の積にJacobianを掛け、対称な全厚で奇数べきの積分を消す。残る項は $g^{1/2}$ または $g^{-5/2}$ と $z$ の偶数べきの積になる。

厚さの積分はべきの原始関数で、面内の $t$ の積分は各半セルの切断幅で求める。残った $s$ の多項式に、$g^\alpha$ の二項級数を56項掛けて厳密に積分した。最初に省いた項と以後の項の比の上界から剰余を見積もった。半セルと基底場の積を変えた144モーメントの剰余は最大 $4.82\times10^{-90}$。別の縦断面積分との最大差は $10^{-85}$ だった。 [再現スクリプト](reference.py)

## 点数を比較する

各半セルを2三角形に分けた積則と連続値を照合した。層内方向は3点。表の点数は8三角形と全厚を合わせたもの。半セルの単項式では、合計次数18までの6種類のべきと6種類の場の積を選んだ。

| 面内各方向の点数 | 全点数 | 最大絶対差 |
| ---: | ---: | ---: |
| 5 | 600 | $1.777\times10^{-4}$ |
| 7 | 1,176 | $6.424\times10^{-6}$ |
| 9 | 1,944 | $4.352\times10^{-8}$ |
| 11 | 2,904 | $2.768\times10^{-13}$ |
| 13 | 4,056 | $2.049\times10^{-20}$ |
| 15 | 5,400 | $2.076\times10^{-27}$ |

より高い合計次数28の $(14,14)$ を含む別の96モーメントでは、14点の最大差が $6.852\times10^{-12}$、16点では $9.070\times10^{-17}$ だった。最初の候補の12点で同じ精度に達するという見込みは外れ、実際の最大差は $4.610\times10^{-9}$ だった。

この比較の対象は、放物柱面で選んだ単項式モーメント。製品の次の確認では、共通分割の各体積と実際に選んだ基底を使い、連続Gramの各成分と合同変換後の尺度を照合する。

## 採用基底の全130列で確認する

製品の参照基底と共通分割を作り、基底の係数4,008項と40体積領域を取り出した。40領域は20三角形の各2層。連続値では各層の結合を同じ全厚の積分に戻し、面内連続モーメントを上の横断面積分で求める。求積値では元の20三角形を使い、各層で深さ次数5までを厳密積分する。比較では面内各方向の点数だけを変えた。

連続Gramを $G_c=L L^mathsf{T}$、求積Gramを $G_h$ とし、元の基底と、連続Gramで正規化した基底の最大絶対行和を測った。正規化後は $L^{-1}(G_h-G_c)L^{-mathsf{T}}$。計算は85桁の十進演算を使った。$L$ の対角の最小値は約 $3.699\times10^{-18}$ だった。

| 面内各方向の点数 | $G_h-G_c$ の最大絶対行和 | 正規化した差の最大絶対行和 |
| ---: | ---: | ---: |
| 9 | $4.37166102\times10^{-9}$ | $1.40487590$ |
| 11 | $3.31127565\times10^{-15}$ | $9.64965069\times10^{-3}$ |
| 13 | $9.03167762\times10^{-23}$ | $9.73665173\times10^{-10}$ |
| 15 | $4.94056685\times10^{-30}$ | $1.17759269\times10^{-16}$ |
| 17 | $2.99639250\times10^{-37}$ | $1.06145918\times10^{-23}$ |

この試験では、元の係数の差が小さい11点でも、連続エネルギーを単位とした差は約1%に達した。次数を判定するときは、採用基底での相対的な影響を評価する。15点と17点の値はこのパッチでの観測値で、製品の認定には対象形状・分割ごとの連続内積と丸めを含む誤差上界が要る。

[係数と領域の抽出](export-basis.cpp.txt)はMSVC Releaseで実行した。抽出プログラムには製品ライブラリの `uvlas_structure` と `uvlas_core`、Catch2 3のヘッダーとテスト起動ライブラリをリンクする。ファイルをC++としてコンパイルし、実行時のスタックを64 MiB確保する。標準出力をファイルに保存して `python -X utf8 compare_basis.py <export-file>` へ渡す。 [比較スクリプト](compare_basis.py)

## 丸めと級数の剰余を含む包絡

面内17点と層内3点の節点・重みを分母 $10^{48}$ の有理数で表し、対称に配置する。中央重みで各軸の重みを1にそろえる。深さは2層の実際の節点と重みから次数5までの有限モーメントを求める。平方根は整数平方根から外向きに挟み、全基底の積に使うモーメントを $2^{-272}$ 格子に包絡した。連続側は独立な横断面積分の56項と剰余から包絡する。

有限内積の中点から作った $2^{-216}$ 格子の上三角変換 $T$ を両方の包絡へ適用した。すべての行和は整数で上下界を計算した。有限則の合同誤差の上限は $1.298\times10^{-40}$、$T^\mathsf{T}(G_c-G_h)T$ の上限は $1.062\times10^{-23}$、連続側の合同誤差の上限は $1.062\times10^{-23}$。15点則でも有限側の上限は $1.154\times10^{-40}$ に収まる。連続との差の下限が $1.177\times10^{-16}$ となり、この試験の $10^{-20}$ を外れた。 [独立包絡の検査](certify_basis.py)・[有限モーメント](finite_moments.py)

`python -X utf8 certify_basis.py <basis-export>` で17点、`--order 15` で負対照を再現する。この証拠の対象は切断した変厚放物柱面の全130列。一般曲面では、同じ決め方を採用する前に、幅・歪みと二方向の曲率を含む連続モーメントの上界を確認する。

## 基底値の計算費用

変厚放物柱面の40領域・130列に、分母 $10^{48}$ の有理数で表した3点則を面内と層内に使い、1,080点を用意した。作業格子352 bit、出力格子272 bit。Intel Core i5-13400F の同じ論理CPU、Windows MSVC Release で、基底準備を済ませた状態から離散Gramの包絡を作る時間を測った。変更前と変更後を交互に3回実行した。基底の値、測度、積和の包絡は同じ格子に保った。

| 実行順 | 変更前の準備 [s] | 変更後の準備 [s] |
| ---: | ---: | ---: |
| 1 | 83.978 | 35.384 |
| 2 | 60.623 | 37.418 |
| 3 | 87.598 | 44.060 |
| 中央値 | 83.978 | 37.418 |

点ごとの基底値・区間を作る時間の中央値は64.972秒から23.927秒に下がった。試験のCPU時間（基底準備も含む）の中央値は70.75秒から35.05秒。求積準備で確保を計上した累積バイト数は1,318,210,840から729,519,256に下がった。プロセスのピーク常駐量は各回約231 MBだった。時刻計測には前後で同じ計測点を使った。

準備では基底の偏微分を生成せず、同じ項の値を同じ順序で評価する。形状値と偏微分を必要とする既存の参照点評価では、従来の3成分を計算する。6回すべてで固定整数の積和は5,179,216,392ステップ、上三角8,515成分の上下端は同一だった。出力した `gram,<lower>,<upper>` の全行をLFで結んだSHA-256は `9e672b273a267e2751feef92f5f871264d106adbf5eecbdbabda0c0fb5a3502d`。MSVC Release と GCC 14 Release の参照幾何・離散Gram・合同変換の対象3件が各環境で通過した。

この計測の対象は1,080点の準備。実務規模・他の曲面・別の点数の所要時間は、同じ測定で確認する。
