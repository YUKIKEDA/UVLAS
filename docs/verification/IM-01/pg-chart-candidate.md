# PG固定疎チャートの数値候補を実接続で検証する

[数値候補の契約](../../specs/structure/pg-chart-numerical-candidate-contract.md)に従い、厳密チャートで決めた元行とピボットから、前進・転置に共通の疎因子を準備した。係数ごとの丸め差は上向きに格納し、元の有理CSRを参照として保持した。

## 実接続での照合

$n=1$ の平板2枚を全厚で接続し、片方の外周を固定した。候補の全座標、自由列の力、元行乗数を、固定された厳密チャートの結果と独立の有理数に戻して比較した。保持した二語と元の有理CSRから、全原行の残差と全成分の力釣合いを別に積和して、報告上界内に入ることを照合した。仕事も別の有理積和で再計算した。自由列は入力の下位語まで厳密に一致した。同じ因子で零状態の明示的なBinary64投影と元残差零も確認した。密な状態では試行したBinary64投影がMSVC Debugで未認定となったため、非零の対照はTwoWordで確認し、予算を緩めなかった。

係数誤差上限を零、元残差予算を零、訪問上限を不足にした対照と、別チャート世代および取消を確認した。下位語を読む処理を変異で除くと、自由列の厳密一致を検査する1,672番目のアサーションが失敗した。取消はバックエンドを呼ぶ前後に確認する。

## 凍結R-02系列の予算内の結果

[R-02の厳密再利用](pg-sparse-chart-series.md)と同じ2・3・4パッチの接続、固定支持、自由座標と力を使った。閉路には分割が一致しない接続を含む。MSVC Release、論理CPU 2固定で各1回。数値準備と作用の計測には `8dd743b5` を使用した。最終ソースは同じ演算に準備状態の検査を追加した。

係数差は各非零で $2^{-30}$ 以下、$B$ の絶対残差と成分別後退誤差は $10^{-12}$、元行残差と元力釣合いは $10^{-5}$ を上限に固定した。反復の訪問上限は2,000,000、バックエンド見積りは512 MiB、ResourcePlanは48 GiB。いずれも暫定の原係数単位。各標本で因子準備まで通り、両方向の求解後、元CSRの上界では認定に至らなかった。いずれも `PrecisionUnresolved`。この判定は上界に対するもの。真の誤差の大きさは別の検証を要する。

## 再実行

[系列ランナー](pg-chart-candidate-series/run-series.ps1.txt)を別名の `.ps1` にコピーし、リポジトリルートから `-Build` にReleaseのマルチ構成先、`-Dependencies` にvcpkgのx64-windowsディレクトリを指定する。凍結R-02ドライバーに、[候補の計測関数](pg-chart-candidate-series/measure-candidate.cpp.txt)を差し込んでビルドする。

検証対象は `ab9231b1`。専用 `structure.pg_chart_candidate` は、MSVC 19.51.36260とGCC 14.2.0（ASan・UBSanの最初の違反で停止）で、各2,482アサーション。CTestはMSVC Release 3.39秒、Debug 15.16秒、GCC 26.89秒。Clang-Tidy 21.1.1で関連2翻訳単位を確認した。
