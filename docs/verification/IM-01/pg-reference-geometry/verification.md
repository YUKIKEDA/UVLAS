# PG参照幾何と片側微分の製品検証

Issue #259。通常の構造ライブラリに登録した `PgReferenceGeometry` を、製品のグラフ、原辞書、共通分割から構成した。成功した準備はこれらを所有し、参照点評価で別の由来の分割を受け取る入口を持たない。採用した物理写像、微分、法線管の局所正則性を[参照幾何契約](../../../specs/structure/pg-reference-geometry-contract.md)に示す。

## 検証した値

| ケース | 独立な確認方法 |
|---|---|
| 四次の曲面、幅4/5、skew 3/20、参照長2 m、Cartesian循環回転、可変厚さ | 有理係数の単項式を階乗から直接微分し、法線、X₀、Jacobian全9成分の二次根表現を有理値へ照合した。原辞書の法線列も独立な法線の導関数と一致した |
| n=1、2、4の矩形とU形切断、2層 | 平面の厳密式から、体積の尺度、共有する層境界の反対向きの法線、全外周面の面積ベクトル・面積二乗を照合した |
| 同じ物質点での別片側 | 幅4/5、skew 3/20の平面で、原辞書の区分放物線の二階微分と、厚さ三角形の異なる勾配を手計算と照合した。位置を変えずに参照する側だけを変えた |
| 法線管の厳密境界 | 曲率非零の二次曲面で十分条件の等号・超過を拒否し、参照長の変更で境界の直前を受理した。同じ曲面の一点で正・零・負のJacobianを区別した |
| 参照の所有と予算 | 反射、非直交、異なるチャート、範囲外、移動元、取消、硬い外部limb保証要求を拒否した。累積の所有容量、算術回数、訪問数の各等号と1不足を実際の点評価で確認した |
| 非軸回転の来歴 | 3/5、4/5を含む回転を厳密に比較し、元のグラフと分割が同じでも物理フレームが変われば参照識別子が変わること、および点結果の刻印を確認した |

比較する有理値、あるいは有理係数と正の根の対の許容差は0。主シェル仕様第5節の参照再現・必要微分の目標1e−8に対し、ここでは投影前の表現を直接検査した。独立な四次fixtureは製品コードを使わず、単項式の落階階乗と、法線分子の内積による微分から計算した。

## 変異と環境

Windows 11 x64、MSVC 19.51.36260、Boost 1.92.0。警告をエラーとする製品構成でReleaseとDebugをビルドした。構造グラフ・共通分割・参照幾何の対象CTestは両構成で3件中3件成功。固定版のclang-formatと、Releaseの新規翻訳単位2件に対するclang-tidyも通過した。面の由来を返す型と正則性境界の照合を追加した後、変更の影響がある参照幾何だけを両構成で再実行した。

[変異記録](mutation-result.json)は、製品源を別のディレクトリへ複製し、指定のソース置換を1件ずつ適用した結果。MSVC Releaseでその翻訳単位だけを再コンパイルし、元の試験オブジェクトと依存ライブラリをそのままリンクした。変更しない複製は6ケース・1,603検査に合格した。厚さ勾配、物理尺度、局所微分尺度、厚さの側、側面向き、正則性の等号を変える6件は、対応する試験がそれぞれ検出した。

再現時は、Windows開発環境で `uvlas_test_structure_pg_reference_geometry` ターゲットをビルドし、`ctest -C Release -R "^structure[.]pg_reference_geometry$" --output-on-failure` を構成先で実行する。Debugも同じ対象を実行する。変異結果の `before` は、指定のソースで一度だけ出現することを確認してから差し替える。

本検証の判定は参照幾何と片側微分の実装適合である。局所独立化、条件付け後の基底・勾配、物理求積、全パッチの非自己交差、実務受入はそれぞれ既存の段階へ渡す。Linuxとsanitizerの実行結果は別途CIで記録される。
