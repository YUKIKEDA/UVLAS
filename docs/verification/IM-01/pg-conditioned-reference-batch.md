# PG条件付け基底の参照点列評価の検証

[点列評価契約](../../specs/structure/pg-conditioned-reference-batch-contract.md)を、製品経路で認定したn=1平板の基底で検証した。採用仕様のSH-D02、SH-D03、SH-D07と、資源・失敗に関するN4-02、N4-06、N4-08を対象とする。

## 独立照合

認定に使う上三角変換を、局所単項式と解析内積から試験側で求めた。点列は同じセル境界の左右、同じ材料界面の上下、外側面を含む5点とした。入力順の各点で、全109列のNとCartesian勾配3成分を、元基底の単項式を厳密有理数で直接微分してから変換した2,180成分と照合した。物理Jacobianが単位行列となる参照枠を使った。位置とJacobianに加え、体積Jacobian、水平面の符号付き面積ベクトル、外側面の面積ベクトルと面積二乗を、分割の辺と三角形から照合した。左右のセルと上下の層を別々に識別できることも確認した。

演算数・走査数・累積確保の等号と1不足を検査した。出力配列の事前照合で1 B不足、外部領域不足、事前取消の場合は確保0を確認した。空の点列は有効な列数と空の配列を返した。正しい点の後に不正な側面を置くと呼出し全体が失敗し、同じ認定結果で再評価できた。返した点列は評価用ResourcePlanの破棄後に照合した。

## 実行環境

Windows 11 x64のMSVC 19.51.36260とBoost 1.92.0で、DebugとReleaseの `structure.pg_conditioning`、`structure.pg_reference_geometry` を実行し、両構成で2件ずつ通過した。Ubuntu 24.04 x64のGCC 14.2.0とBoost 1.92.0では、同じ2つの試験をASan・UBSan付きで構成し、それぞれ180秒の上限内で直接実行した。UBSanは最初の未定義動作で停止する設定とした。条件付けの5ケース・32,089アサーションと参照幾何の10ケース・1,710アサーションを通過した。clang-tidy 21.1.1で変更に関係する3翻訳単位を検査した。

基底変換を降順から昇順へ差し替える変異を、隔離した製品翻訳単位で検査した。変異では既に変換した列を次の列の元データとして読んでしまう。独立したN・Gとの照合で1,061アサーションが失敗し、変異を検出した。

変厚・曲面・切断領域へ本入口を接続する際は、対応する幾何内積の区間と変換の認定が先に必要となる。質量・材料・荷重作用の組立と全体性能は、その後の検証で扱う。
