# 凍結R4全配置での法線・厚さ・物理測度

[R4の参照位置とJacobian](pg-r4-reference-geometries.md)と同じ7形状、各2格子、厚さ $1/100$ と $1/10000\,\mathrm m$ の28配置を使った。各配置の領域は単位正方形で、製品が採用する格子 $n=1,2,4$ を含む。変厚配置には原本の $H=h(1+s/10+t/20)$ を用いた。幾何の片側を照合するため、厚さ方向の層を $\zeta=-1,-1/3,1$ で区切った。層の追加は参照形状や全厚を変えず、材料応答の計算にも使っていない。 [凍結品質系列](../../../rd/structure/main-shell/paired-geometry/experiments/check_mass_paired_quality.py)・[凍結係数系列](../../../rd/structure/main-shell/paired-geometry/experiments/check_mass_paired_coefficient_input.py)

共通分割の全体積レコードについて、三角形内点と層内深さを一つずつ照会した。頂点から独立に符号付き面積を求め、各層の面積の和が1となることも確認した。参照計算では、入力の世界多項式をチャート係数へ展開せず、$x=s+a t,\ y=t$ で直接微分した。$g=1+f_x^2+f_y^2$、法線 $(-f_x,-f_y,1)/\sqrt{g}$、位置 $(x,y,f)+z\boldsymbol n$ と厚さを、有理数または $c+d\sqrt g$ の係数ごとに厳密照合した。

曲率の参照計算には世界多項式のHessianを使った。$A=(1+f_y^2)f_{xx}-2f_x f_y f_{xy}+(1+f_x^2)f_{yy}$、$B=f_{xx}f_{yy}-f_{xy}^2$ とすると、$z=\zeta H/2$ の体積Jacobianは

$$
\frac H2\left(\sqrt g-\frac{zA}{g}+\frac{z^2B}{g^{3/2}}\right)
$$

となる。製品のベクトル外積を使わず、三角形と層の写像による係数も含めて厳密比較した。従来どおり、先頭と末尾の体積レコードのJacobian全9成分には複素ステップを使った。

各配置で上下の外面と共通層面の両側を、同じ三角形で評価した。横外面は各層で原正方形の4辺を一つずつ選び、境界の向きを原正方形から確認した。外向き面積ベクトルとそのノルムの二乗は、独立な複素ステップ微分で作った接ベクトルから計算し、差を $2\times10^{-14}$ 未満とした。 [製品の試験](../../../tests/structure/pg_reference_geometry_test.cpp)

この試験はR4の分割各部における局所的な測度を比較した。全体積の積分と全外面にわたる荷重・仕事の比較は、別の[R5全4配置](pg-r5-swept-taper-reference.md)で確認している。曲面の幾何・全厚拘束の確認を、基底の連続内積や構造応答の判定には用いない。

## 実行結果

MSVC 19.51 ReleaseとGCC 14.2 Releaseで、R4の81,964アサーションがそれぞれ通った。参照幾何のCTest全体では、両環境で12試験・85,114アサーション。所要時間はWindowsが67.00秒、Linuxが50.36秒で、いずれも既存の180秒以内だった。Clang-Tidyで追加試験の翻訳単位も確認した。

製品の法線出力だけの符号を反転した隔離変異では、円柱面の最初の点で法線の係数が期待値 $-7950/25309$ に対して $7950/25309$ となり、照合が失敗した。位置の計算とJacobianは変異で変更していない。
