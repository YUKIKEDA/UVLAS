# PG一定厚平板の幾何内積と合同認定

[平板供給契約](../../../specs/structure/pg-flat-gram-contract.md)を検査した。製品のn=1平板参照、rank 109から全5,995区間を生成した。独立の単項式積分で求めた有理値を128 bit二進格子へ丸め、11,990端点の完全一致を確認した。同じ所有結果から合同変換を認定した後、既存の片側N/Gと全33必須場の検査を通した。容量0で合同認定を拒否した後、同じ供給結果で再試行できた。

n=2/4では、参照長3/2 m、厚さ5/4 m、幅4/3、skew 1/9、一定高さ1/7で全区間を生成した。先頭部・中間・最終の4列で作る上三角の10区間ずつを独立解析積分と照合した。変厚、切断、曲面、整数作業枠0、事前取消を拒否し、元の参照を読めることを確認した。事前取消では確保0だった。

Windows 11 x64、MSVC 19.51.36260ではDebug・Releaseで条件付け、参照幾何、局所rankの対象CTestが各3件通過した。整数枠の初期化を明示した版で条件付けを両構成とも再実行した。Ubuntu 24.04 x64、GCC 14.2.0、Boost 1.92.0ではASan・UBSanの対象CTestが1件、42.33秒で通過した。条件付けの4ケースは30,893アサーションだった。

MSVC Releaseの隔離コピーで、測度から厚さ係数hを求める乗算だけを外した。n=2/4の独立な包絡端点との照合で28件のアサーションが失敗して、変異を検出した。clang-tidy 21.1.1は直接関係する翻訳単位5件で確認した。
