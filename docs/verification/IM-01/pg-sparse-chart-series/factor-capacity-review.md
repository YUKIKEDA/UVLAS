# 4パッチの因子容量境界で疎チャートの作用を照合する

[R-02 の4パッチ閉路](../pg-sparse-chart-series.md)で、因子の上限を通常の65,000項と実保持項数の23,503項に設定し、同じ原拘束からそれぞれ準備した。固定支持、準備順、ピボット順を保ち、2つのチャートに同じ非零の独立座標と元座標の力を与えた。

全位置551組、独立力303組、元行乗数672組を、有理数の3成分ごとに比較した。通常容量では非零の外力仕事が転置の仕事と一致した。容量を23,502項にすると `ResourceExceeded` が返り、元拘束が呼出し側に残った。 [指摘](https://github.com/YUKIKEDA/UVLAS/pull/336#discussion_r4678556623)

WindowsのMSVC 19.51.36260 Releaseで検証した。製品ソースは `703ab52d`。 再実行差分の試験は1ケース64アサーション、非零成分の観測も追加した試験は1ケース67アサーションが通過した。別の観測用コピーで非零成分を数え、位置1,552成分、独立力905成分、元行乗数743成分を確認した。因子はLが4,330項、Uが19,173項であった。

## 再実行

固定した初回の [ドライバー](../pg-sparse-chart-series/run-series.cpp.txt) に [差分](run-factor-capacity.patch) を、別の作業コピーで適用する。適用時は `git -c core.autocrlf=false apply` で元ソースの改行を保つ。リンク条件は [既存の Release 手順](../pg-sparse-chart-series.md#再実行) と同じ。再利用だけで終わるプリプロセッサ定義は付けず、Catch2 フィルター `R02 four patch loop` で実行する。検査対象は因子容量を変えたときの作用と所有であり、既存の計時や基準結果を更新しない。
