# 構造追従する空力面の固定材料座標対応

[FD-06](../foundation/case-schema-fields.md#fd-06-空力既知流れ)の `AeroAttachment structural` を補足する。対象は AE-02、UW-D06、SH-D02 と V-MULTI。構造追従面は、空力面の翼弦・翼幅座標から支持先 Shell の材料座標への固定対応を Case に明示する。同じ Shell に複数の面が付く場合も、各面が自分の対応を持つ。位置、速度、接線、空力荷重の構造への返却は、この対応と同じ準備済み PG を使う。

## Case の入力

スキーマは `uvlas.case/1`。構造追従取付の `kind`、`host` に、次の `material_map` を追加する。従来の `host` だけの入力はスキーマ検査で引き続き読み取れる。物理準備では `material_map` の不足を当該面の入力位置で診断する。同じチャートを使う既存ケースには、$s=\xi$、$t=\eta$、指定した $\zeta$ を明示する。固定取付と指定運動取付の入力形式は従来どおり。

| 型 | 欄 | 条件 |
| --- | --- | --- |
| `MaterialMap` | `pieces:List<MaterialMapPiece>` | 1件以上。物理パネル格子を隙間・重複なしに覆う。 |
| `MaterialMapPiece` | `chord_cells:Vec<Index,2>`, `span_cells:Vec<Index,2>`, `layer:Ref<Layer>`, `side:Tag{interior,lower,upper}`, `terms:List<MaterialMapTerm>` | 格子の0始まり半開区間を指定。層の所有者は `host`。側は選んだ層の側を表す。 |
| `MaterialMapTerm` | `powers:Vec<Count,2>`, `coefficient:Vec<Rational,3>` | `coefficient` は $(s,t,\zeta)$ 順。次数の和は4以下。べきの組は一つにつき1項。 |

翼弦格子と翼幅格子はそれぞれ `AeroSurface.chord` と `AeroSurface.span`。例えば `chord_cells:[0,2]` は $[\xi_0,\xi_1]$ と $[\xi_1,\xi_2]$ を覆う。各片の係数は、面全体で共有する無次元の $(\xi,\eta)$ に対する

$$
\boldsymbol m(\xi,\eta)
  =(s,t,\zeta)=\sum_{i+j\leq4}\boldsymbol a_{ij}\xi^i\eta^j
$$

を表す。片の境界で両側の値は一致しなければならない。片側の接線が異なる場合は、非貫通点を所有する物理パネルの片側を使う。同じ片の中では一つの式から値と偏微分を得る。$\zeta$ は正規化厚さ座標。`interior` では選んだ層の開区間に属することを確認する。`lower`／`upper` で指定した $\zeta$ はその層端と厳密に一致する。同じパネルで層側が切り替わる場合は、格子を区切って片を分ける。

PG の $(s,t)$ は準備済み支持パッチの同じ領域に属する。物理パネル全域で $\partial(s,t)/\partial(\xi,\eta)$ の符号は零を含まず、同じ翼面内で一定とする。大小と符号の証明には有理多項式の区間包絡を使う。域外または退化が確定すれば `GeometryInvalid`、許された細分で証明できなければ `PrecisionUnresolved`。片側の PG 背景セルと層は、準備済みの分割・幾何に照らして決める。切断点で必要な接線が一意でなく、所有パネルの内側からの照会にも両側が残る場合は不適格とする。Case が製品内部の三角形番号を保持する必要はない。

次は翼弦・翼幅各1セル、Shell `4` の層 `9` が $\zeta=0$ を内部に持つ場合。対応は $s=1/4+\xi/2$、$t=\eta$、$\zeta=0$。同じチャートを明示する場合は定数項を省き、$s$ の係数を1にする。層の上端が $\zeta=1$ の上面の場合は定数項の第3成分を1とし、側を `upper` にする。

```json
{
  "kind": "structural",
  "host": "4",
  "material_map": {
    "pieces": [{
      "chord_cells": [0, 1],
      "span_cells": [0, 1],
      "layer": "9",
      "side": "interior",
      "terms": [
        {"powers": [0, 0], "coefficient": [
          {"numerator": "1", "denominator": "4"},
          {"numerator": "0", "denominator": "1"},
          {"numerator": "0", "denominator": "1"}
        ]},
        {"powers": [1, 0], "coefficient": [
          {"numerator": "1", "denominator": "2"},
          {"numerator": "0", "denominator": "1"},
          {"numerator": "0", "denominator": "1"}
        ]},
        {"powers": [0, 1], "coefficient": [
          {"numerator": "0", "denominator": "1"},
          {"numerator": "1", "denominator": "1"},
          {"numerator": "0", "denominator": "1"}
        ]}
      ]
    }]
  }
}
```

## 離散点と双対作用

$N(\boldsymbol m)$ は、同じ準備済み基底と片側で得た構造の形状行。位置・速度・接線は

$$
X=N(\boldsymbol m)q,\qquad V=N(\boldsymbol m)v,\qquad
X_{,i}=(N_{,s}s_{,i}+N_{,t}t_{,i}+N_{,\zeta}\zeta_{,i})q,
\quad i\in\{\xi,\eta\}.
$$

非貫通法線は $X_{,\xi}\times X_{,\eta}$ を正規化し、Case の `orientation` を適用する。渦頂点は翼弦区間の1/4と最終後縁、非貫通点は3/4と翼幅中点を既存の規約で作る。翼面速度は式の $V$ を使う。座標対応が固定のため時間偏微分は零であり、構造支持運動は同じ構造の $q,v$ に含まれる。

渦頂点の所有候補は、その翼弦・翼幅座標を閉区間内に含む物理パネル。通常の翼弦列では1/4点が属する区間だけ、最終後縁では最後の区間の右端を使う。翼幅の内部境界では両側のパネルを候補とする。候補を翼弦添字、翼幅添字の順で並べ、最初を所有者とし、全候補で位置・速度の形状行を照合する。非貫通点の接線はその点の物理パネルから取る。別の空力面との登録済み別名の正準所有者は既存の登録に従う。

曲面の非貫通点と平らな誘導facetは別の幾何から得られる。幾何判定では計算した非貫通点を渡し、所属が確認された場合に限り incidence を付ける。辺荷重点は渦頂点の1/2、三角形荷重点は渦頂点の1/3を使う。点の形状行、速度、方向微分にも同じ係数を使い、荷重は既存の係数で渦頂点へ分配する。

$$
F_q=\sum_a N_a^\mathsf{T}f_a,\qquad
F_q^\mathsf{T}\delta q=\sum_a f_a^\mathsf{T}N_a\delta q .
$$

登録された別名は正準頂点に力を集め、構造へ一度だけ戻す。別名では物理位置、速度と、同じ大域構造自由度での位置写像を照合する。別の支持先パッチの行は、同じ固定拘束チャートで表した自由座標の作用が恒等的に一致し、時変の指定項とその片側微分も許可された全時刻で一致することを確認する。単一状態での値の一致や包絡の重なりでは、写像の一致は確定しない。証明できない対応は準備時に拒否する。

## 準備、精度、再開

準備は、Case と支持先の準備済み参照を照合した後、片の範囲、層所有、入力の被覆、片間整合、域内と向き、参照幾何の順に確認する。対応する翼面の独立な参照幾何と $N(\boldsymbol m)q_0$ を、採用の渦頂点・非貫通点の全点で照合する。各位置の二乗距離は `numerics.patch.geometry_error` の二乗以下。非貫通点での接線差は各パネルの $\Delta\xi$、$\Delta\eta$ を掛けた長さで同じ予算に収める。参照法線の内積は正とする。区間包絡で比較し、予算超過が確定すれば `GeometryInvalid`、比較を確定できなければ `PrecisionUnresolved` を返す。この資格確認は採用点と接線に適用する。外部メッシュの連続面への変換は既存の R-05 で検査する。

入力の欠落、添字範囲、項の重複、境界の被覆不一致、別所有者の層は構文または型付き検査の診断を使い、物理準備で確認した不適合には面ID、片、セルまたは点の役割、該当欄を付ける。数、累積確保、正確な分割・包絡・投影の仕事は既存の Case 資源計画へ入れる。取消と失敗後に親を保持する。

所有結果は Case・支持先の指紋、片の範囲、層と側、元係数、点の役割と順、接線、準備済み基底と精度方針を結ぶ。変更された対応で同じ世代を名乗る要求は `StaleGeneration`。型付き再開では現行 Case と保存した対応を照合し、渦頂点は同じでも接線や側の異なる入力を拒否する。J1 のファイル再開では、同じ準備識別子を受理済み状態と一緒に照合する。

## 独立検証

同一チャートの中央面、$s=1/4+\xi/2,\ t=\eta$ の別チャート、$\zeta=1$ の上面を用意する。独立の有理多項式から1/4・3/4とその偏微分を求め、曲面上で位置・速度・法線の符号を照合する。元の全ベクトル荷重を全頂点に集約し、保持語から直接計算した仕事で構造転置を照合する。共有辺の別名は物理IDごとに一度集約する。絶対許容値は既存の各試験・観測の予算を使い、接線の比較は上の物理長さ尺度を適用する。

負対照は `host` だけ、片の欠落・重複、外へのずれ、層側の逆転、局所の向きの反転、同じ位置で接線のみ不一致、別名の下位語または構造世代の差とする。転置で片側または一つの荷重点の重みを用いない変異も、独立仕事で検出する。Binary64 と TwoWord の両方で、位置が近いだけの点に既存の正準点が割り当てられないことを確認する。
