# 指定配置の定常閉後流と閉輪郭の追加規約

[UVLM統合仕様](uvlm-integrated-specification.md)の後縁所有、非貫通、全荷重に適用する。[大域幾何の閉輪郭点照会](global-geometry-te-contract.md#正のコア半径を持つ閉輪郭の点照会)を消費する。

指定配置の定常閉後流を後縁から流下端までの四辺形1枚で表す場合、各帯の下流端に `SteadyWakeClosure` を明示できる。両端で同じ符号付き $T\Gamma$ の列を使うので、下流端は求解中の循環に従い、接線・転置でも同じ列へ寄与する。各帯は対応する後縁へ直接接続し、同じ入力に独立な履歴強度を含めない。この配置は固定した閉後流の形状を入力として受け取る。自由後流の形状決定や時間発展には既存の独立履歴を使う。

定常の実数循環には、同じ一定輪郭式を外向きBinary64区間で評価する `ClosedContour` を使える。準備では全四辺形の子facetを同じ正規辺と強度列にまとめ、反対向きの寄与を整数で引く。各照会は `ContourContactIndex` の厳密な接触資格を先に得る。係数行は法線の入力包絡を掛けた $\mathrm{m}^{-1}$、速度は入力強度の区間を使った $\mathrm{m}/\mathrm{s}$ の区間を返す。同じ確定配置で頂点距離を照会ごとに共用し、速度の集約は辺ID順の二分加算とする。荷重中点は厳密な支持確認を経て自己辺を除く。

Binary64の通常丸めと漸進的アンダーフローを確認し、各基本演算を隣接表現へ外向きに囲う。二語は両方を読み、商の分母が零を含む場合や有限区間に収まらない場合は精度未解決を返す。端点投影の符号を囲って同符号と判定できる場合に安定な商を使い、符号が確定しない場合は正のコア半径を持つ元式で包含を試みる。係数行の射影許容差と最終残差・荷重の判定は消費側が適用する。準備は計上した頂点・辺・寄与配列を所有し、照会は呼出しごとの端点作業領域を使う。照会行の出力先は借用で、失敗時は破棄する。

循環・荷重入口の `DiscreteCirculationRequest::certified_closed_contour` は、一様流と固定された定常閉後流で実数の循環を解く場合にこの評価を選ぶ。係数を符号付きの物理循環列へまとめた後、射影値と区間の最大距離を `matrix_absolute` で認定する。保持した循環の両語から元残差を再評価し、既存の判定を適用する。荷重辺の速度は同じ準備済み輪郭から得る。再生検証では同じ経路を再実行し、保持した循環と残差の語の一致を確認する。独立履歴を持つ後流、時間ステンシル、連成接線・転置を同時に求める入口は従来のP1評価を使う。

定常閉輪郭の組立て、元残差と荷重中点の照会は、1〜4個の作業域で評価できる。各工程で照会を連続した範囲に分け、全作業域と出力配列を実行前に確保枠へ計上する。工程開始時の残り演算枠を各範囲に配分し、使用量を範囲順に合算する。元残差の判定と荷重・モーメントの集約順は作業域の数にかかわらず同じとする。
