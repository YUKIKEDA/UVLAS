# 固定面・指定運動面の前縁と後縁の対応

[#390](https://github.com/YUKIKEDA/UVLAS/issues/390) は、[FD-06](../foundation/case-schema-fields.md#fd-06-空力既知流れ) の `surface_graph` を使う `fixed_reference` と `prescribed_motion` に適用する。対象は GEO-01、PHY-02、AE-02、UW-D01、UW-D03、UW-D06、V-MULTI。指定した前縁と後縁を一つの写像で結び、物理セル、渦頂点、非貫通点、後流を放出する辺の出所を同じ Case に結び付ける。構造追従面には[固定材料座標対応](structural-attachment-material-map-contract.md)を使う。

## Case が指定する境界と座標

`AeroSurface.leading` と `trailing` は、同じ `Geometry` が持つ二つの異なる境界への0始まり添字。元の順序付き頂点列を参照多角形の外周に照合する。連続した境界上を一方向にたどる列だけを認め、逆向きの記述は許す。外周上で同じ向きに進む共線点の追加や省略も許す。輪を一周する列、折り返し、零長、外周を離れる区間、両縁の接触を拒否する。

`chord` と `span` はそれぞれ無次元の $\xi_i$ と $\eta_j$。この準備入口では両列の最初を0、最後を1とし、端を含め厳密増加とする。元の十進値を有理数として扱う。物理幅が変わっても格子の値を変換し直さない。

### 共通参照チャートの翼幅座標を使う場合

下記の `edge_pairing` が省略されているとき、参照チャートの第2成分 $t$ を使う。`surface_graph` の基準 Frame 内では、その軸の物理位置は基準長さ $\ell>0$ と $t$ の積である。後退、上反角、Frame の回転や指定運動で世界座標が変わっても、この参照座標で対応を固定する。

前縁・後縁の各列は $t$ が一方向に厳密単調で、両列の端点は同じ範囲 $[t_-,t_+]$ を持つことを求める。必要なら各列を反転して $t$ の昇順にそろえる。対応は $t=t_-+(t_+-t_-)\eta$ とし、各縁の線分をその $t$ で一意に補間する。両縁の全頂点の正規化 $t$ の和集合を厳密に整列・重複除去して区分端にする。前縁と後縁は全域で異なることを確かめる。共通範囲と単調性を満たせない場合は明示対応を要求する。

### Case が対応を明示する場合

`uvlas.case/1` の `AeroSurface` に任意の `edge_pairing` を追加する。`fixed_reference` と `prescribed_motion` で使用できる。構造追従面でこの欄を指定した入力は無効。型のキーは次の表で閉じる。`Rational` は [Case の厳密有理数形式](../foundation/case-schema-contract.md)を使う。

| 型 | 欄 | 条件 |
| --- | --- | --- |
| `EdgePairing` | `knots:List<EdgePairingKnot>` | 2件以上。入力順を保持する。 |
| `EdgePairingKnot` | `eta:Rational`, `leading:Rational`, `trailing:Rational` | `eta` は0から1へ厳密増加。残る二欄はそれぞれの元境界上の無次元パラメータ。 |

元の境界で $n$ 本の線分を宣言した場合、パラメータ $p=k+\alpha$ は元の線分 $k$ の始点から割合 $\alpha$ の位置を指す。$k$ は0始まり、$0\leq\alpha<1$ とし、終点 $p=n$ は最後の頂点とする。前縁・後縁の各パラメータ列は独立に厳密増加または厳密減少とし、端の組はそれぞれ $(0,n)$ または $(n,0)$。区間内では両パラメータを $\eta$ で線形補間する。元の頂点を通過する $\eta$ をパラメータの整数交点から有理数で逆算し、明示節点と合わせて区分端とする。明示列の誤りを自動対応で補わない。

例えば元の順で前縁が1線分、後縁が2線分のとき、`knots` に $(\eta,p_L,p_T)=(0,0,0),(1/2,1/2,1),(1,1,2)$ を指定すると、前縁中央を後縁の折れ点へ対応させる。三つ組の成分は表の各キーに対応し、例えば `eta` の $1/2$ は `{"numerator":"1","denominator":"2"}` と書く。明示対応は前縁と後縁を結ぶ幾何に意味を持つ。二つのパラメータが同じ割合である必要はない。

## 参照多角形を覆うことを確かめる

前縁を $L(\eta)$、後縁を $T(\eta)$ とし、両者の点は $(s,t)$ 順の有理数2成分とする。共通の写像は $K(\xi,\eta)=(1-\xi)L(\eta)+\xi T(\eta)$。どちらの入力規則でも、各区分の正規化座標 $u=(\eta-\eta_a)/(\eta_b-\eta_a)$ に対して $L=L_0+u A$、$T=T_0+u B$ と書ける。$D=T_0-L_0$、$C=B-A$ とすると、

$$
\det(K_{,\xi},K_{,u})=\det(D,A)+\xi\det(D,C)+u\det(C,A).
$$

行列式は二変数のアフィン関数なので、閉区分の四隅を有理数で検査すれば符号を全域で決められる。四隅で厳密に同じ非零符号となること、全区分が同じ符号を保つことを要求する。自動対応では、これは共通の $t$ ごとに $s_T-s_L$ が全域で同じ非零符号を持つことに等しい。

各区分の四辺形 $(L_0,T_0,T_1,L_1)$ がその順の単純で厳密凸な閉多角形であることを確認する。正則な双線形写像はこの凸四辺形を一度覆う。四辺が線形に辺へ写り、正負いずれか一方のヤコビアン符号を閉区分全体で保持するため、内部点の符号付き逆像数は境界の巻き数と一致する。隣り合う四辺形の共通部分は同じ $\eta$ の端の線分全体だけとし、隣り合わない区分の交差や接触は許さない。線分交差と凸多角形の包含を厳密に検査する。隣接区分の共通線分は逆向きにたどる。共通線分を除いた外周は、同じ向きの共線分割、開始頂点、全体の順の反転を正規化した上で、`Geometry.domain` の単純な外周と完全に一致させる。したがって区分の和は域内を重複や隙間なしに覆う。格子点だけの検査や面積合計だけでは、この資格を与えない。

## 同じ写像が離散点と後縁の所有を発行する

参照位置は、準備済み `Geometry` の基準長さ、Frame、高さ多項式を使い、$X_0(\xi,\eta)=X_{\rm graph}(K(\xi,\eta))$ とする。固定面はこの位置と厳密な零速度を使う。指定運動面は、同じ参照点と[認定済みの同一時刻・片側のSE(3)運動](prescribed-rigid-motion-start-contract.md)から現在位置と速度を求める。参照接線は $X_{\rm graph}$ の成分微分と $K$ の偏微分を鎖則で合成する。現在接線は同じ運動の回転を作用させる。位置・接線は m、速度は m/s。非貫通点の法線は現在接線の外積を正規化し、`orientation` が `reversed` のときに反転する。入力の向きで折返しや退化を通過させない。

物理パネルの添字 $(i,j)$ は0始まり、翼弦が外側、翼幅が内側の順。既存の `dual-quarter-v1` を次の位置で生成する。[採用格子と後流](uvlm-wake-adopted-specification.md#2-物理幾何と未知量)

| 出力 | 写像の入力と出所 |
| --- | --- |
| 物理セル | $[\xi_i,\xi_{i+1}]\times[\eta_j,\eta_{j+1}]$。`AeroSurface.id` と元セル添字を保持する。 |
| 渦頂点 | $(\xi_i+(\xi_{i+1}-\xi_i)/4,\eta_j)$。最終列は $(1,\eta_j)$。内部翼幅境界では両側で位置と速度の値が一致する。 |
| 非貫通点 | $(\xi_i+3(\xi_{i+1}-\xi_i)/4,(\eta_j+\eta_{j+1})/2)$。位置、速度、接線は同じ写像から評価する。 |
| 渦セルと後縁 | 物理セルごとに対応する四つの渦頂点と採用対角線を用いる。`(AeroSurface.id,i,j)` から `PhysicalFaceId` と二つの元 `FacetId` を発行する。後縁の両端は最終列の $(1,\eta_j)$ と $(1,\eta_{j+1})$。元境界の添字と区分を保持し、各帯に正準 `EdgeId`、最後の弦列の束縛面ID、既存の後縁認定で求めた有向転写係数を関連付ける。 |

一つの `AeroSurface` の渦頂点は渦頂点列の各添字に一件を発行する。その座標を閉区間内に含む物理セルを $(i,j)$ 順に並べ、先頭を面内の所有者とする。位置と速度の一致を確かめた上で、隣り合うセルからの出所も保持する。後縁列は最後の弦区間の終端に属する。

境界の対応区分が物理格子とずれても、区分の統合で弦列、翼幅帯、元面の番号は増やさない。非貫通点が区分端に一致する場合、左・右の接線が厳密に一致するときに一意とする。内側の照会で左右接線が異なる場合は物理準備で拒否する。位置だけを照会する渦頂点は共通の値を使う。連続参照面の被覆と、有限渦格子の辺・平面三角形による近似の適格性はそれぞれ検査する。接触・同一実体・後縁転写の符号は[大域幾何と後縁所有](global-geometry-te-contract.md)に従う。

`AeroSharing` は指定境界の両端・向きを照合し、`same` なら宣言順同士、`reversed` なら相手の宣言順を反転して照合する。この向きは計算上の前縁・後縁列の反転とは別に保持する。

両側が `surface_graph` のときは、相手の Frame と基準長さの逆変換で世界位置 $X$ を局所無次元 $(x,y,z)$ に戻し、そのチャート座標を $t=y$、$s=(x-x_0-\mathrm{skew}\,t)/\mathrm{width}$ で求める。相手側の各境界頂点をこの式で自面に戻し、自面の境界線分への所属とグラフ上の高さを厳密に照合する。両側の頂点をこの方法で双方へ移し、宣言順で共通の区分を作る。各区分では自面の線分上にある世界座標の多項式を相手のチャートに合成し、相手側の一つの線分の直線条件と、世界座標三成分の一致を多項式係数で照合する。両端が相手線分の対応端にあり、各グラフのチャートが単射なので、その閉区分全体が相手側の同じ弧を同じ順に覆う。合成後の次数は16以下。この照合は境界頂点の位置だけでは見落とす曲線の違いを検出する。

後段で消費する共有渦頂点・辺を同じ宣言順で列挙し、対応する位置・順序・件数と端点の接続を照合する。両側で異なる分割は、同じ正準渦辺を一対一に同定できる場合に限る。共有宣言に対応する離散実体がなければ拒否する。指定運動を含む場合は、同じ位置・速度と必要な微分を生む運動の適格性を既存の運動学照合に渡し、一時刻の位置一致で登録を通さない。構造追従面との共有で必要な構造作用の照合は、固定材料座標対応の規約に従う。全体の正準IDを共有しても元面の出所を保持する。内部の共有境界から後流を放出しない。

## 準備と失敗時の保証

型付き Case、単位変換版、元 `AeroSurface` と `Geometry`、境界添字と頂点順、規約版、正規化した区分と両縁の係数、格子順、共有方向、点・面・後縁の元の対応を一つの読取り専用結果に結ぶ。後段はこの結果と、同じ参照・トポロジー・試行時刻および運動を受け取る。位置や面数が同じことだけで、別の元面、別の Case、別世代を再利用しない。再開の互換性には正規化した実係数とその版を残す。

| 条件 | 結果 |
| --- | --- |
| 欄の型、添字、両境界の指定、格子範囲、節点順、端点被覆が不正。または単調な共通 $t$ が得られず明示欄がない | `InvalidInput` |
| 辺や多角形の交差、折返し、零面積、域の欠け、照会で接線が不連続、成立しない共有・後縁 | `GeometryInvalid` |
| 同じ所有元・参照・トポロジー・時刻側に属さない要求 | `StaleGeneration` |
| 使用できる数値表現と消費側の誤差枠で、必要な包絡または運動学の照合を確定できない | `PrecisionUnresolved` |
| 対応外の参照 provider | `Unsupported` |
| 上限不足または取消 | `ResourceExceeded` または `Cancelled` |

診断は Case の元欄、面ID、境界の元線分または節点対、可能なら物理セルと点の役割を保持する。符号・境界一致・被覆には入力の厳密有理数を用いる。物理位置や接線・速度の数値射影は、消費側が指定する成分別の m または m/s の予算に対して、既存の明示射影と包含半径を使う。法線の符号を射影前の有理 chart の許容差で置き換えない。既存の幾何判定は受け取った保持値について行い、Case の連続写像に対する誤差は別に追跡する。

各面で前後縁の線分数、明示節点数、正規化した区分数 $K$、外周辺数 $D$、弦・翼幅のセル数 $M,N$ を検査付き整数で数える。明示時の端点候補は明示節点数と両縁の内点数の和を上限とする。資源計画は、その候補と有理数の幅、$K(K-1)/2$ 個までの区分対、外周検査、共有照合の走査に必要な仕事と作業域を持つ。生成する点・照会・元面・元facet・後縁帯の各件数 $(M+1)(N+1),MN,MN,2MN,N$ と、共有表および接続の保有量を、確保前に既存 `ResourcePlan` へ計上する。有理演算の桁、処理件数、累積確保の上限を持ち、途中の走査でも課金と取消を検査する。未認定の対一覧を全件蓄える必要はない。失敗時に部分的な所有結果を公開せず、元 Case と既存の準備結果を維持する。

## 開始審査に使う独立検証

[対応の反例と凍結V-MULTIの六条件](../../verification/IM-03/wing-edge-pairing/verification.md)は、製品の格子生成から独立に、対応則で照会位置と法線右辺が変わること、凍結幾何の全渦頂点と非貫通点を同じ翼幅座標で照合できることを確認する。実装ではこれに、同一Caseから作る固定面・指定運動面の全点、元面の順、共有境界、後縁の符号、世代不一致と確保・取消の負例を加える。主翼・尾翼の元面交換、位置を維持したまま速度が変わる運動の交換、反転、閉区分内の折返し、合計面積が同じ重複と欠けを拒否する試験を置く。製品準備と全後流の終端までの接続、四つの駆動での二翼調和求解・全元残差・翼別荷重、同じ有限核と独立理想参照の誤差配分は IM03-0 の V-MULTI 検証へ引き継ぐ。
