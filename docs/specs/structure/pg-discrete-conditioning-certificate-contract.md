# PGの離散幾何内積に対する基底変換の認定

[採用仕様の5節](main-shell-adopted-specification.md#5-求積と数値精度)と[係数構成の採用定義](../../../rd/structure/main-shell/paired-geometry/paired-reference-coefficient-definition.md#係数構成と数値座標)のうち、供給された区間Gram行列に対する変換の誤差と必須場保持を確かめる。対象はSH-D03、N4-02、N4-08である。

## 認定する入力

`PgConditioningCertificate::certify` は、[物理参照と結合した局所基底](pg-reference-basis-contract.md)、同じ基底順の対称な密度1の離散幾何内積 `M_ref` の成分区間、候補変換 `T` を受け取る。内積は固定参照長で無次元化した体積測度を使う。入力は上三角を列順に詰め、各区間の上下端および変換係数を指定の二進格子上の厳密有理数で供給する。二進格子はGram側と候補側で別に指定できる。格子への暗黙の丸めは行わない。`T` は上三角で対角成分が正とする。

呼出し側は、実際の物理参照・基底順・求積で定まる内積が入力区間に含まれることを別途保証する。結果が保証する合同誤差は、与えられた区間に含まれる全ての対称行列に対して成り立つ。製品の求積則、入力区間の来歴と生成方法、区分求積の適格性は後続の契約で定める。

## 誤差と必須場

区間行列 `M` の各成分と `T` を、指定の格子の整数単位へ変換する。`T` の列を一つずつ処理し、まず `M T` の列、次に `Tᵀ M T−I` の上三角成分を区間で計算する。負の係数を掛けるときだけ区間端点を入れ替える。対称な各成分の絶対値上限を該当する全行へ足し、最大の行和を得る。基準値10⁻²⁰との比較は整数で行う。上限が基準を超える場合はPrecisionUnresolvedを返す。

正の対角は `T` を可逆にし、上三角は各選択列までの先頭部分空間を保持する。局所rankの証明が、各必須場の元座標 `W` を必須場から選んだ先頭部分空間に収める。公開結果から、変換済み係数 `B T` と `T W_new=W` を解いた33列それぞれの座標を厳密有理数で取得できる。後続列への座標は厳密な零。係数は厳密値で返すため、この段階の半径は0で、採用上限10⁻²⁵を満たす。

## 資源と所有

最大rankは既存の局所基底と同じ933。格子に載せた入力整数は各1536 bitまでとする。行列積の幅は最初の積和で3082 bit以下、次の積和と単位行列の減算で4629 bit以下、絶対値の行和で4639 bit以下になる。整数の基準値比較を含めても4707 bitに収まり、中間値には8192 bit固定枠を使う。

rをrank、p=r(r+1)/2とする。確保前に、所有結果本体、p個の変換係数、p個の入力区間、r個の中間列区間とr個の行和を同じResourcePlanと呼出し上限に照合する。途中の列を再利用する。区間積和の回数上限は第一段でrp、第二段でr(r+1)(r+2)/6。各区間積和は整数積2回を含み、各積は両整数のlimb数の積を課金する。係数読取り、内側の項の走査と行和にも作業枠を使う。入力の借用領域と、結果から有理値を物化する呼出しの課金はこの認定の追加payloadに含めない。

Workspaceを占有してから、確保と有界な走査の間に取消を確認する。成功時に参照基底と厳密変換を所有する。形状や格子が不適合ならInvalidInput、対角が正でなければRankUnresolved、容量・ビット幅・作業枠の不足はResourceExceeded、取消はCancelledを返す。取得時の厳密演算は既存のExactLimitsに従う。実際の区分求積上での条件付け、数値係数の射影、物理参照係数への組立は後続工程に属する。
