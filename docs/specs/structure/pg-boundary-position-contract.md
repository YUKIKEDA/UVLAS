# PG面上の位置写像と転置作用

[主シェル採用仕様3・4・6・7節](main-shell-adopted-specification.md)に従い、[認定基底の参照評価](pg-conditioned-reference-batch-contract.md)から得た面上の基底値 $N_{pi}$ を位置写像に用いる。固定した基底値から位置 $x_{p\alpha}=\sum_i N_{pi}q_{i\alpha}$ と共役力 $f_{i\alpha}=\sum_p N_{pi}\lambda_{p\alpha}$ を求める。添字 $p$ は入力の点順、$i$ は認定基底の列順、$\alpha$ はCartesianのx、y、zの順である。位置には [m]、共役力には [N] の入力を渡す。

## 面の指定と準備

`PgBoundaryPositionReference::prepare` は、水平面の三角形上の点または外周側面上の点を受け取る。水平面では分割の面レコードが層と上下を決める。たとえば、同じ界面座標でも下層の上面と上層の下面は別の点として扱う。結果は各点の参照識別、セル、面レコード、層、面の種別と入力の点順を保持する。同じ点を複数回指定した場合も、それぞれの行を保持する。

各行では認定基底の値だけをBinary64またはTwoWordへ射影し、全列共通の絶対誤差枠を検査する。表面の測度、体積Jacobian、求積重みは位置写像の係数に入らない。準備の作業量と所有確保は参照評価と合わせて検査する。

すべての点の準備が成功した時点で、認定基底の所有を結果へ移す。失敗や取消後は元の認定基底を引き続き使える。

## 反復評価

`apply_pg_boundary_position` は[固定体積点の位置写像と転置作用](pg-volume-position-contract.md)と同じ精度表現、誤差上界、作業量の数え方を使う。入力は各点または各列のx、y、zを連続配置する。順方向と転置は同じ $N$ に作用するので、厳密値には $\lambda^T(Nq)=q^T(N^T\lambda)$ が成り立つ。

十分な容量の結果とWorkspaceを両方向で使い回せる。すべての出力成分を検査した後に結果へ反映し、失敗や取消では前回の出力を保持する。
