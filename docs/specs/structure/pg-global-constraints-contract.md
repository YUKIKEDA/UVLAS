# PGの大域原拘束を疎に集約する

[数値基盤 N4-04](../foundation/numerical-foundation-adoption-specification.md#n4-04-大域拘束とpgの疎性)と[局所・大域の接続契約](../../../rd/structure/main-shell/paired-geometry/paired-reference-local-global-contract.md)に従い、パッチ対の全厚位置拘束と固定支持を、共通の座標順を使う厳密な原方程式 $Cq=c$ に集約する。各接続の力と仕事を、元の行へ戻せる形で保存する。

## 座標と元の行

`PgGlobalConstraints::prepare` は、物理パッチIDを付けた準備済みパッチと、接続または固定支持を表す[全厚トレース](pg-full-trace-contract.md)を受け取る。拘束元の左右には、同じパッチ表の番号を与える。各パッチの準備済み基底IDと列数を、実際に使ったトレースの左右と照合する。パッチIDの重複、各拘束種別内のID重複、範囲外の番号、支持への右側の指定、別基底を拒否する。JointとSupportは別の名前空間であり、同じ数値IDをそれぞれ保持する。

パッチ表の順に、各基底のCartesian三成分を連続に置く。三成分組の番号を $j$、成分番号を $a\in\{0,1,2\}$ とすると、単一成分の番号は $3j+a$ になる。この列配置に同じ係数を三方向へ適用する。行も同じ三成分順を使う。

元行は、拘束元の入力順と各トレースの元順を保つ。拘束元ID、左右の物理パッチID、共通区間、元行番号、厚さ方向の場と辺上の次数、局所代表への対応と符号付き尺度、右辺 $c$ を所有する。元行の列には、局所の正規化係数に元の尺度を掛けた値を詰める。左右のパッチの大域位置が入れ替わる場合は、各側の列を大域列の昇順に並べる。零行や重複を含む各元行の位置は残す。

静止点支持の元行はトレースの後ろに入力順で追加する。点の基底IDと対象パッチを照合し、昇順の非零係数、選択した世界並進成分、右辺を所有する。点には共通区間がない。点支持と外周支持は同じSupportの名前空間に属する。点支持の成分マスクは元行と転置作用の両方に適用する。非選択成分は `apply` と `residual` で零を返し、`transpose` では元行乗数を与えても力を加えない。三成分共通の固定ピボットチャートは部分成分を持つ元拘束を拒否する。

## 作用と所有

`apply` と `residual` は、入力の列範囲、物理ID、基底IDを照合して $Cq$ または $Cq-c$ を返す。転置は元行順に与えた $\lambda$ を同じ列への $C^T\lambda$ に集める。元順を維持するので、$\lambda^T Cq=q^T C^T\lambda$ を元の接続と支持の仕事に対応させられる。

準備では、パッチ数、拘束元数、元行数、三方向に共通の非零係数数にそれぞれ上限を指定する。列と行の三成分展開の寸法も検査する。元の区間、係数、右辺はコピーし、完成した疎配列と結果は入力および作業領域の寿命から独立している。確保または作業量不足、取消、入力の不一致では既存のパッチとトレースを保持する。

従属行の選定は[固定ピボット疎チャートの契約](pg-sparse-chart-contract.md)に従う。固定右辺の適合を全原行で検査してからチャートを準備する。
