# PG曲面の離散幾何内積

[主シェル採用仕様5節](main-shell-adopted-specification.md#5-求積と数値精度)と[基底変換の認定契約](pg-discrete-conditioning-certificate-contract.md)に従い、明示した有限の区分求積則に対する幾何内積を包絡する。準備に使うのは、結合済みの物理参照と選択基底を所有する `PgReferenceBasis` である。呼出し側は使う求積則を与え、連続積分への収束を別に確認する。

## 求積点と測度

`PgDiscreteGram::prepare` に体積レコード番号、三角形座標、層内深さ、正の厳密有理重みを渡す。点を体積レコード番号の昇順にまとめ、所有する全体積レコードを1点以上で覆う。準備の入口で番号、座標、重みを厳密な値として複製し、その所有配列を積和に使う。座標は[参照幾何](pg-reference-geometry-contract.md)の三角形と層の変数変換に従う。

重みは単位三角形と単位層内深さで定義する。点の物理Jacobianには、共通分割の三角形と層幅が含まれる。$L_{ref}$ を使い $W_p=w_pJ_p/L_{ref}^3$ と無次元化する。選択基底 $N_i$ の密度1の成分を $\sum_p W_p N_i(p)N_j(p)$ とし、上三角を列順で格納する。

## 厳密な包絡と資源

各解析値は $a+b\sqrt g$ で表される。呼出し側が計算用二進格子と最終二進格子を指定する。$\sqrt g$ の作業用の小数bit数を $k$ として、下端の格子整数は $2^{2k}g$ の整数部分の平方根を切り捨てて得る。二乗と元の有理数が一致しない場合は、次の格子点を上端とする。有理係数 $a,b$ は同じ格子に外向きに丸め、区間積和で $N_i$ と $W_p$ を包絡する。

各点の寄与は $W_p$ と2個の基底値の格子整数で計算し、最終格子への外向き丸めは全点を足した後に行う。各作業端点は1536 bit以下とする。点数が符号付き64 bitに収まるので、密な積和は各端点について $3\cdot1536+63$ bit以内となる。前処理の平方根、整数除算と格子変換にも8192 bitの固定作業枠を使う。上限を超えた場合はResourceExceededを返す。

確保するのは求積点の厳密な配列、一点分の区間列、上三角の区間積和、結果の上三角である。確保前にこれらの配列を同じResourcePlanへ照合し、厳密有理演算、分割訪問、固定整数仕事量を計上する。厳密値の外部領域見積りには求積点ごとに有理数4個を加える。成功した場合に選択基底、求積点、包絡を結果へ移す。失敗や取消後も元の基底は有効である。

## 変換の認定

所有結果の `generate_and_certify` は同じ選択基底と包絡を使って候補を生成する。合同変換の行和誤差上限 $10^{-20}$ と必須場を既存の認定器で確認する。精度枠や資源枠の不足時は所有結果を保持する。認定後は `PgFixedDiscreteGramCertificate` が認定基底と準備に使った求積点配列を一体で所有する。保証の対象は、その配列が表す有限則の離散幾何内積である。
