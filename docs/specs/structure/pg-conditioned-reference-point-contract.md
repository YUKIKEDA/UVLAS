# PG条件付け基底の参照点評価

[主シェル採用仕様の3–4節](main-shell-adopted-specification.md)の位置場と物理勾配を、[離散合同変換を認定した所有結果](pg-discrete-conditioning-certificate-contract.md)から評価する。対象はSH-D02、SH-D03、SH-D07、N4-02、N4-06、N4-08。

`PgConditioningCertificate::evaluate` は選択した条件付け基底の列番号と、体積・層側・側面のいずれかの参照点を受け取る。所有する物理参照の片を呼出しで一度解決する。各選択基底の疎なR/P/Cの値と一次微分をその片で求め、認定した `T` の当該列の係数を厳密に掛けて足す。結合したR/P/Cから、[参照点評価の式](pg-reference-basis-contract.md)で無次元N、s,t,ζ偏微分、物理Cartesianの勾配G [m⁻¹] を求める。`T` は固定された参照の係数なので微分の外に置ける。厚さとその偏微分、gとその偏微分、Jacobianと測度はすべて選んだ片に従う。

結果はN、偏微分、Gと同じ物理参照点、材料層、測度、片側情報を所有する。参照識別子は物理参照の識別に用いる。基底順と変換は呼び出した認定結果に属する。セル境界の左右や層界面の上下を選ぶと、指定側を返す。

有理数演算、走査、確保、取消は一つの `PgReferenceLimits` と `ResourcePlan` に計上する。列番号jまでの変換係数を読み、零の係数は走査のみ課金する。非零の係数では、既存の選択基底の有界な局所評価に加えて、値と微分の9成分あたり最大18回の積和操作を使う。幾何と無条件付けの点処理に確保した有理数の外部容量枠に、累積9成分・厳密係数・演算途中値を含む16枠を追加する。最大rankまでの一時配列は確保しない。列や参照点が不正ならInvalidInput、枠不足はResourceExceeded、取消はCancelledを返す。

合同誤差の認定は[供給された内積区間の規約](pg-discrete-conditioning-certificate-contract.md)に従う。区分求積則と、参照に対応する保証付き内積区間の生成はその供給工程に属する。
