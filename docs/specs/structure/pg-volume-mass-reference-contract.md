# PG体積質量に渡す認定参照点

[主シェル採用仕様4・5・7節](main-shell-adopted-specification.md)の一定整合質量は、各層で $\rho_{0\ell}N_iN_j\,dV_0$ を積分する。IM-01では、積分点で必要となる無次元の $N_i$ と物理体積Jacobian [m³] を、[認定済みPG基底](pg-discrete-conditioning-certificate-contract.md)から準備する。対象はSH-D02、SH-D03、SH-D07、N4-02、N4-03、N4-06、N4-08。

`PgVolumeMassReference::prepare` は呼出し側が選んだ層内の体積点列を受け取る。[点列評価](pg-conditioned-reference-batch-contract.md)と同じ基底と分割を使い、点の順、セル、分割記録番号、材料層、物理参照識別子を保つ。体積Jacobianは入力した基準三角形座標と層内深さに対する値であり、三角形と層区間の写像を含む。固定の精度表現では、点ごとに先頭のJacobianと、それに続く認定順の全列 $N_i$ を読み取れる。Binary64の低位配列は空で、TwoWordの低位配列は高位配列と同じ形になる。

## 精度と拒否

読んだ厳密値 $x=a+b\sqrt g$ に対して、高位は最近接・偶数丸め $h=\operatorname{RN}_{64}(x)$ とする。TwoWordは厳密残差の最近接丸め $l=\operatorname{RN}_{64}(x-h)$ を保持する。実際に返す $h$ または $h+l$ と $x$ の絶対差を、呼出し側が指定した成分別の有理数上限と照合する。上限は有限非負のBinary64として受け取り、値を厳密に解釈する。無次元のNとm³のJacobianには別の上限を指定する。

丸め位置は有限Binary64のビット順と隣接値の厳密中点で決める。平方根を浮動小数点に変換せず、比較の二項が異符号なら二乗を比べる。中点では偶数の仮数を選び、最小subnormalを含める。有限の語へ丸められない値、正のJacobianを保持できない値、指定した誤差枠を超える値はPrecisionUnresolvedで返す。

## 所有と資源

認定元と点列を成功時に同じ結果へ移し、別の基底との取り違えを防ぐ。失敗時は認定元を引き続き使える。出力配列の合計寸法を先に確かめ、分割・幾何評価と投影は呼出し全体で同じ作業枠と `ResourcePlan` を使う。投影中に保持する厳密点は一つであり、その全列と投影の中間値を外部領域見積りに含める。空の点列は、認定元と列数を持つ空の結果を返す。評価と投影を済ませた配列は、以降は確保せずに読み取れる。

この入口の誤差枠は、物理値を格納する際の成分別の誤差に適用する。求積則、層密度、質量作用の評価とその誤差は後続のIM-02が扱う。
