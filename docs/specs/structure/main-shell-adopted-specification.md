# 主シェル採用仕様：参照係数PG-ANCF

版1.0、2026-11-05。R5の技術決定。採否と根拠は [R5判定](../../../rd/structure/main-shell/paired-geometry/records/paired-shell-r5-disposition.json)、成立した代表範囲は [R4全体結果](../../../rd/structure/main-shell/paired-geometry/records/paired-reference-r4-results.md) と [後退・テーパ領域](../../../rd/structure/main-shell/paired-geometry/records/paired-shell-r5-domain-v2-result.json) に対応する。製品要求は [要求仕様](../../requirements/product-requirements.md) を維持する。

## 1. 採用する一組

主シェルの定式化に**参照係数PG-ANCF**を採用する。参照の多項式から位置と厚さ勾配の対を直接積分し、独立な基本r/d/cと組み合わせる。全Cartesian位置係数、参照だけに依存する線形位置空間、一定整合質量、全3D弾性、全厚さの位置トレースを一組として固定する。旧膜Ritz解への固定案、補正なし3833/Q9、未達のMMS系を既定経路へ戻さない。

| 決定ID | 固定する判断 |
|---|---|
| SH-D01 | [参照係数の直接持上げ](../../../rd/structure/main-shell/paired-geometry/paired-reference-coefficient-definition.md) を使用。s/t両族の区分P7曲率、各φ成分を全3Cartesian方向へ展開。残る膜ひずみも評価 |
| SH-D02 | 基本rはC¹二次、基本dはC⁰二次/√g、基本cはC⁰一次。参照位置・単位法線を補完。全厚さで二次の位置場Nを使用 |
| SH-D03 | 有理係数の独立性・必須場包含を確認し、参照の離散幾何内積で同じ空間を条件付け。小さい特異方向を削除しない |
| SH-D04 | 材料の主経路は [MAT-D04〜06](material-layer-adoption-contract.md) の全3D Green/第二PK。層別積分・固定参照材料軸・指定初期ひずみを使用。法線応力Schur消去、ANS/EAS、人工安定化を既定で追加しない |
| SH-D05 | 物理位置の全トレースを拘束し、同じ作用素の転置で力を返す。一般接合・梁・剛体との条件は1.4で統合 |
| SH-D06 | 有界パッチ内の基底準備、疎な接続、局所作用の大域組立。[原KKT契約](../../../rd/structure/main-shell/paired-geometry/paired-reference-local-global-contract.md)を保持。全体密RREF・密零空間・密質量平方根を製品の必須処理にしない |
| SH-D07 | 後退・テーパ等は参照グラフ上の非矩形領域として扱える。領域境界と背景セル境界の交点で体積・面の求積を分割。覆い矩形を物理領域として積分しない |
| SH-D08 | 同じモデル・支持・平衡のM/Kを線形化へ渡す。負固有値、層界面両側、試行／確定の区別を保持。製品時間積分器と連成は3で採用 |

これは内部の数値仕様の採用である。Python試作を製品ランタイム・公開APIとして採用した決定ではない。全体の計算本体開始は6の審査に従う。

## 2. 参照モデル・適用域

固定した右手直交基底Qと原点o、参照長L_refを持つグラフチャートを用いる。無次元の局所面を次で表す。

$$
\widehat{\boldsymbol r}_0(s,t)=(x_0+w s+a t,t,f(s,t)),\quad
\boldsymbol X_0=\boldsymbol o+L_{ref}Q\left(\widehat{\boldsymbol r}_0+\widehat z\widehat{\boldsymbol n}\right),\quad
\widehat z=\widehat H(s,t)\zeta/2.
$$

初期の基準プロファイルは総次数4以下の多項式f、正の区分一次全厚H、有界な内部格子n=1/2/4、区分P7曲率とする。通常は小さなパッチを分割して全体を表現し、モデル全体の大きさをnに入れない。高次数幾何は分割・近似して幾何誤差を管理するか、別の適格性審査を通す。後退・テーパ・初期曲面という製品要求を平板へ縮小しない。

面内領域Dはチャート矩形全体、またはその中の正面積の多角形。矩形外の面積を質量・外力へ加えない。任意の切断配置の精度を今回の台形だけから認定せず、以下を入力適格性の条件とする。

- 各活動背景セルとDの共通部分を求積領域として持つ。面・辺にも同じ分割を使い、ゼロ面積・重複を区別する。
- 活動領域の係数像でrankを確認し、物理Mと剛性の適格性を検査する。全く活動しない係数を残した特異系を擬似逆で解かない。痩せた切断片で基準を満たせなければパッチを再分割・再準備し、失敗を診断する。
- 形状・厚さの局所正則性、面の物理対応、自己交差・重複領域の入力診断を幾何生成側が担う。局所detJ>0だけを全体の非自己交差証明と呼ばない。

滑らかな外板を共有する範囲では共通の物理グラフ／向きを使い、境界上の参照位置・法線・全厚を一致させる。異なるグラフ座標から作り直した離散空間の厳密な同値性は仮定しない。同じ場の座標変換ならNのpullbackと物理測度も運ぶ。折れ・交差・梁接合は別の部材接続条件であり、異なる法線のdをそのまま共有しない。

参照の幾何近似、外部格子からの変換、対応しない面の扱いは入力・接続契約から明示的に渡す。点別C² jetだけから本係数空間を準備できるとはしない。

## 3. 位置空間・係数・境界

$$
x_\alpha=\sum_{i=0}^{n_s-1}N_iq_{i\alpha},\qquad
N=R+\widehat zD+\frac{\widehat z^2}{2}C,\qquad
\mathrm{dof}(i,\alpha)=3i+\alpha.
$$

Nは無次元、qは全体Cartesian座標で長さ、速度は長さ/時間。R/D/Cは係数辞書の由来であり、条件付け後のqを「r節点[m]・d節点[無次元]・c節点[1/m]」へ再解釈しない。n_sは活動領域上の独立なr/D分子のrankと独立cの和で準備結果から得る。節点数から固定値を推測しない。原辞書の数はr=(n+2)²+1、d=(2n+1)²+3、対の補完=96n、c=(n+1)²に、必要なトレース補完を加えたもの。

生空間Sとチャートの固定辺Γ_a={s=0}について、R4で照合した次のfull Vをパッチの基準とする。

$$
V=S+L_a(T_aS),\qquad T_aL_a=I\text{ on }T_aS,\qquad
\ker(T_a|_V)=(I-L_aT_a)S.
$$

Γ_aは基底準備のアンカーであり、物理的に固定された境界という意味ではない。支持を変更してもfull Vを作り直さない。R4の同次モデルはこのVの固定端核の照合である。他の支持は同じVへの拘束として与える。全辺補完の追加や支持依存の最小空間への変更は別の空間なので、既存の採用結果を転用しない。

参照係数q₀と並進係数tはそれぞれNq₀=X₀、Nt=1を再現する。非ゼロの指定位置は適合する持上げを使い、未知増分には同次拘束を使う。幾何・基底・アンカー・活動領域・厚さ・単位尺度を参照識別子へ含める。

## 4. 必要微分と組立式

以下は物理量で記述する。z=Hζ/2、Dᵖ=D/L_ref、Cᵖ=C/L_ref²と置くとN=R+zDᵖ+z²Cᵖ/2である。ζを固定したs/t微分ではHの微分を含める。

$$
N_{,a}=R_{,a}+zD^p_{,a}+\tfrac12z^2C^p_{,a}+z_{,a}(D^p+zC^p),\quad
N_{,\zeta}=H(D^p+zC^p)/2,\quad
G_{iJ}=N_{i,\xi_b}(J_0^{-1})_{bJ}.
$$

ここでJ₀=∂X₀/∂ξは物理長さを持つJacobianなので、上式のGは既に1/長さである。無次元Jacobian Ĵ₀を使う実装ではG=N_,ξ Ĵ₀⁻¹/L_ref、体積はL_ref³ detĴ₀、面積はL_ref²を戻す。両経路を混ぜて1/L_refやH/2を二重に掛けない。

$$
F_{\alpha J}=\sum_iq_{i\alpha}G_{iJ},\qquad
E=\tfrac12(F^TF-I),\qquad P=FS.
$$

参照再現を係数上で確認した増分表現ではF=I+Σu_i⊗G_iを使用できる。q₀の大きな絶対値との差引きを精度対策として避ける場合も、参照を現在qから再生成しない。保存形式は絶対位置／参照増分の表現タグを持ち、同じ参照識別子から再構築する。

Mandel基底をA_kとすると、B_{k,iα}=A_{k,IJ}F_{αI}G_{iJ}。材料点のC_M=∂s_M/∂e_Mと同じSを使う。

$$
U=\sum_\ell\int_{\Omega_{0\ell}}W_\ell\,dV_0,\quad
f_{i\alpha}=\sum_\ell\int G_{iJ}P_{\alpha J}\,dV_0,
$$
$$
K_{i\alpha,j\beta}=\sum_\ell\int
\left[B_{k,i\alpha}(C_M)_{kl}B_{l,j\beta}
+\delta_{\alpha\beta}G_{iJ}S_{JL}G_{jL}\right]dV_0,\quad
M_{i\alpha,j\beta}=\delta_{\alpha\beta}\sum_\ell\int\rho_{0\ell}N_iN_j\,dV_0.
$$

U[J]、f[N]、K[N/m]、M[kg]。固定参照・弾性材料ではMはqに依存せず、位置座標にCoriolis型の項を追加しない。全体の非線形拘束・剛体座標変換が生む慣性は接続側で別に導出する。

要求する参照微分はr₀の一次／二次、係数持上げvの二階、dの一階、Hの一階、必要な係数微分。dの微分に必要な幾何の高階多項式微分を保持する。パッチ境界では片側を指定し、存在しない全域三階jetを平均して作らない。接線はqを微分し、参照・材料軸・初期ひずみ・求積を固定する。

## 5. 求積と数値精度

| 対象 | 固定する規約 |
|---|---|
| 基底準備 | 有理係数rankと必須場包含。幾何求積行列への合同変換誤差≤1e−20、係数組合せ区間半径≤1e−25。連続積分全体の区間保証とは区別 |
| 線形の主照合 | 面内degree(D分子)+3、独立観測+5、厚さ7／9点。全24-jet QRの全列を保持し、全3D作用差≤1e−12 |
| 質量 | 法線厚さモデルで層内密度が厚さ方向に一定なら、厚さ4点がNᵀN detJの6次以下を積分する。7点と照合。層・領域ごとに適用し、面内の非多項式因子は別途収束確認 |
| 積層非線形 | 層ごとに求積。採用根拠は面内45→49と厚さ層内5/7点等の別評価。45点を全幾何・全nの十分値へ固定しない |
| 非矩形領域・全外面 | 背景セル、幾何／層の区切り、境界交点で分割。面だけを未分割の高次Gaussで積分する代用をしない |
| 数値適格性 | 完成した剛性／質量平方根のrankを1e−9/1e−10/1e−11で確認。支持後の安定な弾性参照問題は剛性rcond≥1e−10、尺度付き質量最小固有値>1e−10 |
| 原式照合 | 原停留≤1e−8、参照再現・必要微分≤1e−8、全位置トレース≤1e−9。原力学系の基準量と尺度を報告。基底準備の精度だけで解を保証しない |

座屈・不安定な平衡で剛性正定値を要求しない。基底のrank不良、剛体方向、物理的な零／負の剛性を異なる診断として扱う。製品の数値誤差予算は [受入精度](../../requirements/acceptance-criteria.md) に従い、R4/R5の1%を全出力量・全誤差項へそれぞれ与えない。

## 6. 荷重・接続・回復・状態への受渡し

参照体積力b₀[N/m³]と参照面力t₀[N/m²]は∫Nᵀb₀dV₀+∫Nᵀt₀dA₀。境界の共変外向き法線ν_ξは参照面積ベクトルdetJ₀ J₀⁻ᵀν_ξへ写す。傾いた台形側面のν_ξも同じ式を使う。現在圧力や追従荷重は変形依存写像と荷重接線をST-09側から返し、内部Kと別に残差へ組み込む。

全位置拘束Cq=cの変分と力は同じC/Cᵀを使う。パッチごとの独立q、M、f、Kを保持し、大域の正解式は [局所／大域契約](../../../rd/structure/main-shell/paired-geometry/paired-reference-local-global-contract.md) のKKTとする。任意の閉路・交差の独立拘束選択、疎解法、前処理は1.4／4の担当であり、数値閾値で拘束を追加／削除して採用位置空間を変えない。

回復はX₀、x、F、E、S、P、σ、層ID、パッチ側、材料軸、測度を返す。層界面・部材界面の両側を平均前に保持する。参照切断面の合力は∫PN₀dA₀、基準点x_cまわりの現在モーメントは∫(x−x_c)×PN₀dA₀。切断面・軸・基準点を指定する。応力の一点最大値を収束した断面力の代用にしない。

平衡適格性・支持・外力状態と同じ識別子のM/Kを返す。保存状態は基底係数またはそれを同じ参照から復元する増分、速度、方式履歴、確定世代、荷重／イベントカーソルを持つ。幾何・活動域・基底・材料・荷重・支持・方式の不一致、破損、二重確定を拒否する。厳密modal flowの再開試験は正解器であり、時間方式の採用は3へ渡す。

## 7. 内部データ・主要I/F

公開C++/Python APIとABIは4で確定する。ここでは実装者に数式・形状・更新責任の選択を残さない。共通規約としてModelは不変、PreparedPatchが係数と参照キャッシュを所有し、作業領域は呼出しごと／workerごとに専有する。読み取りビューは所有者の存続中のみ有効。失敗時にModel・確定状態は変わらず、部分出力は有効フラグを返さず破棄する。

| 処理 | 入力・形状 | 出力・固定する責任 |
|---|---|---|
| `prepare_patch` | 係数表f(i,j)、Dの境界、Q/o/L_ref、H、層、n、アンカー、版 | 不変な基底・n_s・q₀/t・rank・正則性証拠・参照識別子。基底依存キャッシュの世代を固定 |
| `evaluate_reference` | PreparedPatch、物質点ξ[p,3]、片側タグ | N[p,n_s]、G[p,n_s,3]、X₀[p,3]、J₀[p,3,3]、正の測度、面積・領域タグ。qには非依存 |
| `evaluate_patch` | q/u[n_s,3]、材料／層、試行世代、必要出力マスク | U、f[n_s,3]、K作用または[3n_s,3n_s]、M作用、回復。G固定でqを微分。試行のみ読み取り |
| `restrict_trace` | 共通物理面、座標対応、厚さ・向き・層、両PatchId | 全位置作用T_p/T_q、転置力、接続世代、適合診断。係数等置の適用条件を検査 |
| `integrate_load` | 領域／境界、物質点荷重・単位・時刻・状態世代 | f_ext、必要な∂f_ext/∂q・明示時間微分、合力・基準点付きモーメント |
| `linearize_patch` | 適格な平衡と同じ参照／材料／支持／荷重世代 | 同じM/K、符号を保つスペクトル検査情報。全連成固有値問題はJ1が構成 |

準備費用と評価費用を区別する。n_s固定の局所密因子はO(n_s²)格納・O(n_s³)準備、点評価は係数疎性を用い、fはO(n_point n_s)、明示KはO(n_point n_s²)。K作用と疎な抽出／接続を選べる。全モデル密行列のO(N²)格納を前提にしない。キャッシュは参照・活動域・求積・材料点世代へ紐付け、現在配置に依存するF/S/接線を参照キャッシュに保存しない。

## 8. 拒否・停止と後続審査

| 診断 | 処理 |
|---|---|
| 非有限・非正厚さ・反転・退化・右手系違反・領域重複 | 入力／参照準備を失敗。勝手に法線や厚さの符号を変えない |
| 正則性を証明できない法線管 | 証明未成立として再分割／診断。反転を実測した場合と区別 |
| 活動域の基底rank不良、物理M不適格、数値条件未達 | パッチ再準備または数値失敗。擬似逆・人工質量・方向削除で続行しない |
| 不適合な位置トレース、層順の矛盾、拘束右辺不整合 | 接続／支持を失敗。平均位置へ修正しない |
| 不足する3D材料定数、不適格な材料軸・自然計量 | 材料入力を失敗。等価ABDの不足値を創作しない |
| detF≤0、未収束、原残差未達 | 当該試行を棄却し最後の確定状態を保持。負の固有値そのものは数値失敗として削除しない |

後続の担当と終了条件は [構造統合への引継ぎ](../../../rd/planning/structural-integration-after-shell.md)。主シェルの数値定式化を採用したことと、全構造モデル・J1・数値基盤・実務ケース・本体開始の判定を区別する。新しい反例や不変条件違反が出た場合はSH-Dxxへ対応させて再審査し、候補探索を根拠なく再開しない。
