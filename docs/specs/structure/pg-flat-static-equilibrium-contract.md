# 固定支持と一定面力を持つ平面シェルの静的 Case

IM02-0 の平衡と IM06-0 の R-05 に用いる最初の Case を記述する。型付き SI Case で、基準 Frame 内で高さが零の平面 PG、一定層厚・層内で一定の等方 StVK 弾性値と零の初期 Green ひずみ、固定した全厚位置支持、世界方向の一定参照面力を組み合わせる。質量を渡す層の密度も層内で一定とする。手入力、認証済み Gmsh と Nastran は同じ元 Case と基底を準備する。外部入力の元 ID と対応を出力まで保持する。 [ST-08/09](structural-adopted-specification.md)・[FD-09/10](../foundation/case-schema-fields.md)・[IO4-04](../foundation/io-execution-adoption-specification.md#io4-04-変換入力)

## 構造求積を試行の前に認定する

FD-10 の `surface_degree` と `independent_surface_degree` を指定する体積面内則の保証次数に、`thickness_points` と `independent_thickness_points` を層内則の点数に使う。体積の各三角形と層を保持し、固定の規則から正の重みを発行する。側面では面内次数を指定元境界の各原子辺にも適用し、同じ層内則と積を作る。主則・独立則とも、座標、重み、帰属、各軸の保証モーメントを準備結果に持つ。両則を非線形求解の開始前に固定する。分割や認定則を変える必要が出た場合は、新しい準備で親試行を再評価して求解を立ち上げる。基底条件付けの有限則は、物理作用の規則と別に所有する。

平面、一定厚さ、固定材料軸では、セルごとの元形状関数と Cartesian 勾配は有理式から多項式に落ちる。条件付けは同じセル・層の線形変換である。固定厚さの体積 Jacobian と側面測度を掛け、同じ材料点から作るエネルギー、元内力、接線に現れるモノミアルを採用積分座標へ変換する。StVK のエネルギーは変形勾配の高々四次、元力は勾配方向を一つ、接線は二つ含む同じ四次までの積である。平面内10次、厚さ2次までの形状関数では、構造質量に必要な次数は平面20次、厚さ4次まで。直線側面への一定面力は辺上10次、厚さ2次まで。試行位置と方向を変えても、ここで求めた次数集合を維持する。三角形に積則を使う場合は Duffy 写像の因子を含める。平面次数36を証明対象とした場合、Duffy 写像の積則に必要な二軸次数は37と36になる。厚さの次数は8。実際に採る PG の元係数に対して、これらの次数の上限を先に検査する。

ある作用成分の多項式を $p=\sum_\gamma c_\gamma u^{\gamma_1}v^{\gamma_2}w^{\gamma_3}$ とし、主則と連続積分のモーメント差を $\delta m_\gamma$ とすると、積分の差を $\sum_\gamma |c_\gamma|\,|\delta m_\gamma|$ で囲う。各係数を区間で保持する場合は、係数絶対値の上限を用いる。正の有理数則と既知の連続モーメントを厳密に作れば、保証された次数の積分則の差は零となる。近似節点を使う場合は保持した実節点と重みからモーメント差を評価する。主則と独立則の出力差も比較する。誤差の判定には、Case のエネルギー、元力、接線作用の物理尺度を使う。保持値と連続積分の差を別々に記録する。Case の上限の範囲で分割しても作用・観測の要求幅を証明できなければ `PrecisionUnresolved`。資源不足と取消は専用の失敗を返す。積分誤差と算術の包絡はそれぞれ集計する。独立則は Case が指定する別の高い面内次数と厚さ点数を使う。採用する正の有理数則を節点・係数の版付き表または決定的な構成で固定し、厳密モーメントと正値性を照合する。保証の無い組は準備で拒否する。

平面では、元の選抜基底で物理勾配を多項式として保持する。$N=N_B T$ の状態と方向を $Tq,T\delta q$ で元基底に移し、力と接線作用を $T^\mathsf{T}$ で戻す。$F=\sum_iq_i\otimes G_i$、$H=\sum_i\delta q_i\otimes G_i$、$E=(F^\mathsf{T}F-I)/2$、$S=\mathbb C:(E-E_0)$、$P=FS$ とする。接線の応力作用は $HS+F\{\mathbb C:\operatorname{sym}(F^\mathsf{T}H)\}$。成分を条件付け行列に直接展開して稠密な全体モード表を作る必要はない。

有限則の各点で得る和は、実際に使う同じ点・重みから計算したモーメントと上記多項式の係数との積和にできる。原三角形の純粋モーメントは $a!b!/(a+b+2)!$。固定厚・固定層の平面と深さのモーメントを分け、同じ背景セル・層に属する三角形の面内モーメントを所有して再利用する。主則・独立則と連続積分の三種類を分けて保持する。保存値を射影する際は丸めを外向きに囲う。全域での $\det F>0$ は積分点に加え、セル・層ごとの多項式の正値証明で認定する。候補は Bernstein 係数の下限と Case の範囲内の分割で評価する。正値が証明できない試行は短縮か失敗に進む。

面内次数36のモーメントは一つのセルで703成分、厚さ次数8は9成分である。分離形で層の積を保持できる。勾配の厚さ次数別面内上限を9、8、1としたとき、作用一回の係数積の計画は一つのセル・層あたり6,795,732組以下、R-05 の4セルでは27,182,928組以下となる。この数に形状変換、参考則の構築、exact 整数の桁、相互照合、非線形試行の回数を加え、各配列とビット幅を ResourcePlan に確保前に計上する。正の有理数を使った Duffy 積則を直接展開すると、38×37×9点を三角形ごとに使う条件では8三角形で101,232点になる。これらは作業量の上限と点数であり、実機の時間とメモリの受入は実装後に測る。 [独立検証と作業量](../../verification/IM-02/pg-flat-static-equilibrium/verification.md)

## 平衡と反力を同じ固定チャートから返す

正の物理尺度、固定拘束 $Cq=c$ と同じ所有関係から $q=\psi(r)$ を作る。参照試行は `BranchSeed.reference` の自由位置を持ち上げた値である。元残差 $R_0=f_e-f_L$ と自由残差 $g=J^TR_0$ を同じ点・精度で評価する。接線は $J^T K_e J$。固定参照面積の一定面力では外力の状態微分は零となる。対称性は同じエネルギーの二階変分から確定する。丸めた対称中心行列を $K_c$、成分半径行列を $D$ とする。上限 $\eta\ge\lVert D\rVert_2$ を用いて $K_c-\eta I$ の正定値性を認定し、元区間の正定値性を得る。補正は $K_c$ の疎 LLT を使い、右辺と作用の包絡を含む元残差から照合する。失敗時には原因と最後に受理した試行を診断から取得できる。既存の確定平衡と結果を更新しない。

収束条件を満たした試行を確定する。参照 seed には比較する直前の試行がないため、零の補正を認定した場合に限り、その配置の観測を評価して差を零とする。それ以外は比較できる試行まで求解を続ける。次の補正を行う場合は勾配と補正の双対積の包絡 $[s_-,s_+]$ を評価し、$s_+<0$ を求める。一定の参照面力では $\Pi=U-q^T f_L$ を使う。同じ方向の線探索中は $E(F+\alpha H)$ が $\alpha$ の二次、全ポテンシャルが高々四次なので、五つの係数を同じ有限則で準備し再利用できる。各候補の正値性を照合し、受理した配置の元力を改めて評価する。$\alpha$ は1から半分ずつ試し、$\Pi_{trial}^+\leq\Pi_{parent}^-+10^{-4}\alpha s_-$ を満たす候補を使う。Case の最小刻み、反復・線探索上限および N4-05 の上限を適用する。不適格な候補では親を保って短縮する。収束判定は Case の力・位置尺度を使う元拘束、自由力、補正、指定した点変位または支持反力の成分変化を含む。観測変化は同じ時刻、基底、物理点で計算し、Case の数値予算と N4-05 の配分を適用する。診断する各量と必要精度を準備時に確定させる。力の尺度付き残差と観測の反復間差は停止の条件として扱う。物理観測の前進誤差は、ゲートで独立参照と照合する。

受理した状態で `PgSparseChart::transpose` を適用すると、$R_0=C^T\lambda_{\rm dual}+E^Tg$。支持が構造へ加える元反力は $C^T\lambda_{\rm dual}$ で、$R_0+C^T\lambda_{\rm KKT}=0$ の未知量は逆符号となる。受理した状態の支持位置から作る世界剛体仮想変位で力と、Case が指す原点回りのモーメントを回復する。独立した支持所有の条件を準備時に確認し、代表乗数の選択だけで物理支持間の分配を認定しない。確定状態、変位、反力、元残差、接線・質量を同じ読取り専用の所有結果から得る。

## 独立検証

三入力経路で、Poisson 比0の矩形に全厚側面の一定牽引を作用させる。Case に既存の `sparse_llt`、点変位・支持反力の観測、対象の時刻・基底・原点、主／独立求積と誤差群の予算を明示する。別に導いた $P_{YY}=E\lambda(\lambda^2-1)/2$ と独立構造 FEM から先端変位・支持反力を比較する。初期値は無荷重参照。既知の伸長を与えた試験では三経路の元力、全自由行の残差、支持の力とモーメントが一致した。求解では、同じ状態を製品が受理することと、自由行と支持観測が予算内に入ることを確認する。

軸変位 $u_Y=a Ls\zeta^2$ は固定支持を保ち、正の Jacobian を持つ。独立な有理多項式積分では Green ひずみエネルギーに厚さ8次が現れた。厚さ3点の Simpson 則を同じ変位へ使うと 1.87587%の差が出る。体積240点の既知伸長検証と、非アフィンな試行全域の求積認定をここで照合する。Case の幅・次数・領域・層を一つずつ変え、未認定の解を確定させない。

一般化固有対は同じ確定平衡の $K,M$ と固定チャートを使う。Case の固有値尺度に対応する質量正規化尺度と、物理観測のモード対応を定める必要がある。独立した軸方向の固有対と元固有残差の比較は R-05 の完了条件に残す。
