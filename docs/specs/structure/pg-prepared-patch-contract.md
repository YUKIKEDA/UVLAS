# PGの準備済み参照パッチ

[主シェル採用仕様3・7節](main-shell-adopted-specification.md)に従い、`PgPreparedPatch::prepare` は認定済み基底と同じ係数順で、物理参照位置 $q_0$ と並進の座標 $t$ を準備する。元の認定が[固定有限求積則](pg-discrete-gram-contract.md)を所有している場合は、同じ点と重みも保持する。

## 参照位置と並進

必須場の変換後座標を $W_j$ とする。添字0〜2はローカルの中面位置、27〜29は厚さ方向の法線項、30は定数1である。原点を $o$、物理回転を $Q$、参照長を $L_{ref}$ として、各基底列 $i$ のCartesian座標を次で作る。

$$
(q_0)_{i\alpha}=o_\alpha (W_{30})_i+
L_{ref}\sum_{\beta=0}^{2}Q_{\alpha\beta}
\left((W_\beta)_i+(W_{27+\beta})_i\right),\qquad
t_i=(W_{30})_i.
$$

$q_0$ は [m]、$t$ は無次元とする。同じ列順の $N$ で $Nq_0=X_0$ と $Nt=1$ が成り立つ。物理Cartesian勾配では $q_0^T G=I$ と $t^T G=0$ になる。

## 所有と照合

三方向の$q_0$ と並進を厳密有理数で所有する。`evaluate_reference` は[認定基底の点列評価](pg-conditioned-reference-batch-contract.md)を同じ所有基底から呼ぶ。準備途中は認定結果を読取り専用で使い、成功後に所有を移す。取得済みWorkspace、資源不足、取消、移動済みの基底を拒否する。

準備済みパッチの識別には、物理参照、基底の生成と選択順、変換の格子と係数、固定則を持つ場合はその点番号・座標・重みを含める。参照座標や作用入力を同じパッチ世代に結び付けるために使う。識別子は数値精度の証明に代わらない。

有理演算と確保は呼出しに共通の予算で検査する。物理座標、並進、一列分の必須座標と演算の一時領域を同時に保持し、必須場は列ごとに再利用する。

## 同じ固定則を使う体積点の反復作用

`PgPreparedVolumeReference::prepare` は、準備済みパッチが所有する固定則から連続した点範囲を選ぶ。点番号、層と分割の記録、正の物理Jacobian、確定した列順のN、元の厳密な重みを所有する。JacobianとNは呼出し側がそれぞれの絶対誤差枠を指定し、Binary64またはTwoWordへ射影する。範囲は固定則の点番号で指定する。元のパッチはそのまま保持される。

`apply_pg_prepared_volume_position` は同じパッチ識別を要求し、既存の[体積点の位置写像と転置](pg-volume-position-contract.md)を同じWorkspaceで呼ぶ。位置とその転置に使うのはNであり、整数積和と射影誤差の契約も引き継ぐ。Jacobianと重みは後続の体積積分へ渡す。

## 物理参照量の成分別射影

`PgPreparedPatch::project_reference` は体積点、層界面の上下、外周側面を元の順序で評価する。各点に $X_0$ の3成分 [m] と正の測度を置き、認定済み基底の列順に $N$ と $G$ の3成分 [m⁻¹] を続ける。体積の測度はJacobian [m³]、面の測度は外向き面積ベクトルの正の長さ [m²]。結果はパッチ識別、層・片側・分割番号、射影要求、値を所有する。

`Binary64` は上位語、`TwoWord` は上位語と下位語を持つ。上位語は元値、下位語は元値から上位語を引いた厳密な残差を、それぞれ最近接・偶数に丸める。保持値の和が位置、形状、勾配、体積、面積それぞれの絶対誤差枠に収まることを検査する。面積 $\sqrt{D}$ は候補の正の閾値と比較する際、厳密な長さの二乗 $D$ と閾値の二乗を照合する。面積を先に丸めて判定しない。資源不足、片側の不適格、射影精度の不足、取消では結果を返さず、元のパッチを保持する。
