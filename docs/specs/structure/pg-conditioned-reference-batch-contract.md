# PG条件付け基底の参照点列評価

[主シェル採用仕様3・4・7節](main-shell-adopted-specification.md)の `evaluate_reference` を、[離散合同変換を認定した所有結果](pg-discrete-conditioning-certificate-contract.md)から呼び出す。対象はSH-D02、SH-D03、SH-D07、N4-02、N4-06、N4-08。

`PgConditioningCertificate::evaluate_reference` は体積点、層側点、側面点を任意の順で受け取る。点 $p$ の位置 $X_0$、物理Jacobian $J_0$、測度、背景セル、材料層、分割の記録番号、面側を一つの配列に所有する。すべての認定済み基底列 $j$ の無次元値 $N_j$ と物理Cartesian勾配 $G_{jJ}$ [m⁻¹] は、もう一つの配列の `p * column_count + j` に収める。各成分は点 $p$ の $g$ による厳密な $a+b\sqrt{g}$ 表現で返す。入力順と重複する点を保ち、同じ位置の別のセル側や材料層側も個別に評価する。

点ごとに分割と幾何を一度解決し、選択基底 $B$ の全列を同じ参照で評価する。$T$ は位置に依存しないので $N_{BT}=N_B T$、$G_{BT}=G_B T$ が成り立つ。出力の行にまず変換前の値を置き、上三角の $T$ を列番号の降順で掛ける。列 $j$ が使う未変換の列 $i\le j$ は、その時点で全て残っている。[単列評価](pg-conditioned-reference-point-contract.md)とは演算順が異なるが、同じ基底・片側・物理測度を用いる。

全点数と点数×rankの寸法と、二つの出力配列の合計payloadを先に検査する。有理数の外部領域見積りに、点あたり最大74枠と各列のN・Gの8枠を加える。作業枠は呼出し全体で共有し、出力配列の初期化、点・元基底・変換係数の走査、厳密な演算を計上する。結果の `call_info` は呼出し全体を集計し、各点の `call_info` はその点の評価だけを集計する。空の点列は列数を保ち、作業と確保を伴わずに成功する。

不正な点、資源不足、取消では所有結果全体を破棄する。認定済み基底は同じままで、呼出し側は再評価できる。`ResourcePlan` の累積計上には、失敗までに成功した確保も含まれる。

曲面・変厚・切断領域の保証付き区分求積と変換候補の生成は、認定済み基底を作る工程に属する。評価で返す物理値と測度は、後続の質量・材料・荷重作用が参照する。
