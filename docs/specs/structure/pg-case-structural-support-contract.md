# ケースの構造支持を共通時計と固定PGチャートに接続する

[全厚剛体支持](pg-rigid-support-motion-contract.md)の元行を、型付きケースの `Support.trace_constraint` から準備する。この入口は `Flow.none`、`Wake.none` の構造単体ケースで使える。時刻と片側は[共通時計](../aero/prescribed-rigid-motion-start-contract.md)と同じ検査を通る。空力面のMotionと支持のMotionは別の物理宣言として扱う。

## 支持宣言と共通Motion

準備に渡すパッチは、モデル側が同じケースのShell IDと幾何に解決した参照パッチとする。支持は元チャートとケースの `Support` ID、対象ShellとGeometry、境界番号を照合する。現在の対象は三つの世界位置成分全部を固定する外周の全厚辺。領域全体を覆うパッチの名前付き原境界から一辺ずつ厳密な全厚元行を作り、チャートの元行順、重なり、非零列および元尺度の有理係数と照合する。境界番号が同じでも、元の辺を部分的に切り出したチャートは拒否する。ケース内の対象パッチにある全厚支持とチャートの元支持の全てを指定グループに含める。

同じチャートに結ぶ支持は一つのMotionレシピに属する。物理IDが最小の支持を代表とする。個別の宣言ノードを保ったまま、基準点・姿勢、需要区間、イベント、単位変換、定数や多項式の係数、PCHIPの入力・条件・全係数を厳密に比較してレシピの同一性を判定する。同一グループの全時間適合には、元行の剛体生成子と固定部分が疎行列の像に属する証明を用いる。それぞれ違うMotionの偶然の整合、部分成分指定、全厚辺以外の領域は別の仕様を要する。

## 有理中心と誤差半径

物理運動の評価は既存のMotionの位置・速度・片側加速度を使う。各微分次数について、原点と3点の共有ジェットの保持語を尺度指数とともに一度ずつ厳密有理数へ戻す。これを使って相対回転・並進の有理中心を作り、厳密な元行生成子へ掛ける。全原行に同じ中心を使うので、従属関係が厳密に保たれ、`PgSparseChart::lift_rhs` が位置・速度・加速度を同じ因子で解ける。

物理的な元行の外向き半径は、共通有理中心と各原行を投影した中心の差の絶対値を既存の半径へ加えて求める。異なる原行を別々に丸めた中心は数値候補の経路でも使える。その場合は、実際に返す語に対する元CSR残差上界へ最大右辺半径を加える。仕事にも各元乗数の絶対値と対応する右辺半径の積和を加える。物理状態全体の前進誤差には、別に採用モデルでの評価が要る。全行・反力・仕事の暫定予算は呼出し側が指定し、実空間での認定は[数値候補契約](pg-chart-numerical-candidate-contract.md)に従う。
