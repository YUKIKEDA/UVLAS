# PG条件付けの候補生成と認定

[係数構成の採用定義](../../../rd/structure/main-shell/paired-geometry/paired-reference-coefficient-definition.md#係数構成と数値座標)に従い、Gram区間の中点で近似因子を作る。製品入口が返すのは、元の区間を使った[合同認定](pg-discrete-conditioning-certificate-contract.md)を通過した係数変換である。対象はSH-D03、N4-02、N4-08。

## 因子と候補の格子

`PgConditioningCertificate::generate_and_certify` は、実際の基底に対応するGram区間と、因子用および候補用の二進格子を受け取る。`PgFlatGram::generate_and_certify` では、同じ所有者が基底とGram区間を渡す。両入口とも格子の小数部は1535 bit以下。再試行時の格子は呼出し側が選ぶ。

[凍結R&Dの因子生成](../../../rd/structure/main-shell/paired-geometry/experiments/mass_paired_ancf.py)と同じく、基底順を保ってGramの中点から正対角のCholesky因子を作る。上三角の因子を $R$、因子格子の小数部を $f$ とする。区間中点を $2^{-2f}$ の格子へ写し、過去の因子の積を同じ格子で厳密に足し引きする。対角には平方根、非対角には正対角で割った値を使い、$2^{-f}$ の格子へ最近接・偶数丸めする。整数平方根は商を使うNewton反復と整数の中点判定で求める。

$R T=I$ を列ごとに後退代入する。解は因子格子で計算し、返す候補の格子へ最近接・偶数丸めする。近似因子の残差が正対角を与えない場合はPrecisionUnresolvedとなる。候補の対角が非正なら、既存の候補と同じくRankUnresolvedとなる。

## 認定と所有

実際に返す $T$ に対し、元の上下端を使って全行の合同誤差上限を計算する。上限は既存の $10^{-20}$ と比較する。正対角の上三角によって、厳密rankで証明した必須場の先頭部分空間を保持する。出力から各必須場の座標を厳密に求められる。失敗した場合は基底とGramの所有元を再利用できる。

## 幅と作業

因子の固定枠は3072 bit。行列の上三角と逆の一列分を、既存の認定領域と合わせて確保前に照合する。二つの因子単位の積は6144 bit以下で、最大933項の和をとっても8192 bitの中間枠に収まる。候補の各係数には既存の1536 bit枠を適用する。

生成と認定は一つの作業・確保上限とResourcePlanを共有する。因子と逆の範囲を決める項の走査、整数の積、両limb数に応じた除算を数える。取消は作業の各段階で確認する。格子の範囲外、固定幅、作業、確保の不足はResourceExceededで返す。
