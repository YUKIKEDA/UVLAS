# PG参照幾何・片側微分の実装契約

Issue #259。採用式は[主シェル仕様](main-shell-adopted-specification.md) 第2・4・6・8節、辞書の表現は[PG係数契約](pg-coefficient-contract.md) 第2.2・3.1節を使う。法線管の局所正則性には[技術報告](../../papers/pg-ancf-technical-report-v1.md) 第3節の十分条件を使う。対象はSH-D01、SH-D02、SH-D07とN4-02、N4-06、N4-08。

## 入力と所有

参照準備は不変の製品 `PgGraph`、`PgCoefficientDictionary`、`PgIntegrationPartition`、行優先の厳密な有理行列Q、原点o [m]、正のL_ref [m]を借りる。同じチャートの実内容を照合し、QᵀQ=Iとdet Q>0を厳密に評価する。成功した場合だけ3個の所有候補を準備結果へ移管する。準備結果は3個の実体、物理フレーム、活動域で成り立つ体積Jacobianの正の下限を所有する。失敗時は移管しない。正規化・反射の修正・厚さの符号変換は行わない。正規SHA-256はタグ、既存のチャート・分割digest、Qの行優先9成分、oの3成分、L_refを順に含む。各有理成分は符号1オクテット、分子と分母の各幅（64ビットbig-endian）と最短の絶対値オクテット列で表す。各点結果にはその参照識別子を付ける。入力の資格と正しい側の出所は引き渡した所有物が保証する。

点評価は準備結果が保持する3個の実体を使う。体積・層境界・側面の種別と分割の該当レコードを指定する。面内座標は、体積と層境界では正向きの共通三角形の重み(1−u−v,u,v)、側面では境界の正方向に沿う辺上の重み(1−u,u)から決める。体積・側面の深さは層の下端から上端までの[0,1]の割合、層境界の深さはその層側の既定端点で決まる。厚さHおよびH_s,H_tは所有片が持つ厚さ三角形から厳密に求める。半セルと厚さ区分の側は、同じ位置であっても選んだ片の所属に従う。先行処理が所有する層ID、片、分割レコードの種別と番号を結果に残す。水平面の層側も返す。

## 式と返却値

図心や点別の近似値から採用多項式を作り直さず、グラフの4階までのチャート微分を元のfから評価する。辞書のR/P/Cは選んだ片の局所(u_c,v_c)で評価し、導関数を4nでチャート尺度へ戻す。最後の3成分の順はs,t,ζ。空間ベクトルは物理Cartesian順とし、J₀は行に空間成分、列にs,t,ζを持つ。

図形の平面基底で f_X=f_s/w、f_Y=f_t−af_s/w とする。k=(−f_X,−f_Y,1)、g=kᵀk、n̂=k/√g。n̂_a=(k_a−k g_a/(2g))/√g。物理法線はQ n̂。X₀=o+L_ref Q r̂₀+HζQ n̂/2。面内のJacobian列にはL_ref Q r̂₀,aとζQ(H_a n̂+H n̂_a)/2、ζ列にはH Q n̂/2を入れる。面・体積の尺度は、その時点で物理単位を持つ。正の体積測度はdet J₀を使用し、共通三角形と層の変数変換はその面内detと厚さ座標幅を別に掛ける。層境界では∓J_s×J_t、側面では(s_u J_s+t_u J_t)×J_ζを外向き面積ベクトルとし、分割辺が示す正方向を使う。三角形/層の変数変換を面積ベクトルへ反映し、その二乗ノルムを返す。大きさは正の平方根である。

希望する原辞書列について、厚さĥ_z=Hζ/(2L_ref)、D=P/g^(3/2)を使い、Φ=R+ĥ_z D+ĥ_z² C/2とそのチャート偏微分を返す。D_a=(P_a−3P g_a/(2g))/g^(3/2)。面内微分ではζ固定のH微分項を含める。R/P/C自体の値と必要な片側微分も保持する。この段階のΦは独立化・条件付け前の列であり、係数の独立性を宣言しない。

実スカラーは同じ点の正のgに対する厳密なa+b√gを所有する。法線、位置、Jacobian、体積測度、外向き面積ベクトル、面積の二乗、列のΦ・偏微分をこの形式で表す。gを複製して列ごとの近似値を保存しない。外向き面積ベクトルの符号を元の片側で固定し、面積の平方根は正を選ぶ。符号はa,bの符号が違う場合だけa²とb²gを比べて厳密に決める。gが平方数でも意味は同じである。数値の投影は後段の明示的な精度付き処理に渡す。

## 正則性と拒否

活動片ごとに、チャート座標の非負性と片の頂点での各軸最大値を使い、グラフHessianの各単項の絶対値を上から抑える。幅・skewで平面座標に変換するときも三角不等式を使い、Frobeniusノルムの二乗の上界B²を作る。同じ片の頂点で厚さ三角形の一次式を評価し、正の下限H_minと上限H_maxを得る。元の分割で覆う領域すべてについて、q=(H_max/(2L_ref))²B²<1を有理比較で証明する。qが1以上なら証明未成立であり、反転の観測とは区別する。

1−√q≥(1−q)/2から、det J₀≥L_ref²w H_min(1−q)²/8>0を得る。全片の下限の最小値を保持する。積分用に正向きの共通三角形や層幅を掛ける前の物質座標での下限である。この局所十分条件から、法線管全体の単射性や部材同士の自己交差がないことは導かない。診断用の点評価では非正のdet J₀を厳密に検出する。準備での証明未成立はPrecisionUnresolved、点の反転・退化とQの不正はGeometryInvalid、位置・種別・範囲等の不正はInvalidInputとする。異なる正規入力はStaleGenerationを返す。

## 資源と照合

既存のResourcePlanに動的に確保する有理数の所有領域を累積計上する。各演算が所有する結果は有理数の1領域以下で、点結果内の配列は固定長である。外部多倍長領域にはExactLimitsの推定admissionを使用する。追加で生存する有理数256枠と既存精度演算1件の領域を先に見積もる。点結果は最大100個。チャート・厚さ・面写像に16個、グラフ微分と回転・Jacobianの計算に48個、原辞書列の補助量に24個、二次拡大と符号判定の積和の入れ子に32個を見込む。枠はこれらの上界の和を上回る。準備側のフレーム複製は13個で、各片の一時値は再利用し、点評価の一時領域と同時には使わない。各exact演算のadmissionに渡す外部枠にも同じ生存枠を残し、借用operandの実capacityを既存exact演算側で計上する。値幅、作業幅、累積演算、点や片の走査数には明示の上限を使う。回数は既存exact演算1件または識別子へ入れる可変長の絶対値1オクテットごとに課金する。訪問枠には準備と点診断で行う入力グラフの照合、準備側の片とその頂点出現、評価側の点を計上する。照合に入る前と、各見出し・セル・多項式項・数値の比較前に取消と残量を確かめる。正規有理数の等価比較には、比較1件と両辺の分子・分母を覆う32ビット語数を先に課金する。準備の成功報告には実際に行った照合の訪問量も入る。既存の製品入力は各producerの資源条件を持ち、参照準備の追加領域として再度確保しない。硬い外部上限を要求する入口は既存exact資源契約に従って拒否する。取消を有界な各走査および公開直前に確認する。中断・上限・例外は失敗値として返し、既存の所有物を変更しない。

四次曲面と非平坦・可変厚さ・回転・非単位の尺度を含む独立式に照合する。平面の有理結果と法線管の相対境界、切断・層・側面の向き、同じ点の半セル・厚さ両側を対照とする。数値参照との照合には主シェル仕様第5節の1e−8を用い、有理に一致する成分は許容差0を用いる。
