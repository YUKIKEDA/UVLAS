# PGの共通外周における全厚位置拘束

[主シェル採用仕様6・7節](main-shell-adopted-specification.md)と[局所／大域の原拘束](../../../rd/structure/main-shell/paired-geometry/paired-reference-local-global-contract.md)に従い、準備済みパッチの二つの滑らかな側面から原拘束 $Cq=c$ を作る。支持では一つのパッチの外周と、同じ基底での指定位置を与える。対象はSH-D05、SH-D06、N4-03、N4-08。

## 共通の位置と実厚さ

各側は、実際の共通分割が所有する外周辺を、同じ物質パラメータで増加順に渡す。明示した辺内の始終点を使い、両側の端点で共通細分する。各区間で中面のCartesian多項式の一致と、同じ向きの法線を厳密に検査する。境界の領域側は反対向きとする。

全厚または指定した層の物理深さを、元の厚さ三角形から求める。下端と上端は各共通区間のパラメータの一次式である。深さが重なる開区間を、双方の下端が相手側の上端より小さい範囲として求める。元の範囲、重なる範囲および各側の深さを所有し、厚さ段差の非重複部分は拘束に加えない。

## 全位置の係数行

共通の実厚さ座標を $z$ とし、各側の形状関数を $R+zP/(L_{ref}g^{3/2})+z^2C/(2L_{ref}^2)$ とする。正の深さ幅があるため、三つの $z$ 次数の係数を別々に検査できる。共通辺の局所パラメータへ制限した多項式の全係数を行にする。

二つのCartesian法線分子が同じ向きに平行であることを、多項式の外積と一点の内積で検査する。片側の法線分子のうち恒等的に零でない一成分を $a$、対応する他方の成分を $b$ とする。$g_{right}/g_{left}=(b/a)^2$ で $b/a>0$ となる区間から、$P$ の行は
$b^3 P_{left}/L_{left}-a^3 P_{right}/L_{right}$ の全係数を使う。選んだ成分の零点にも、多項式の恒等性と元の位置場の連続性が及ぶ。固定支持では片側の $g^{3/2}$ を共通因子として外す。

各辺の背景セルの局所基底を厳密に展開し、同じ認定変換を掛ける。元の拘束行は共通区間、厚さ次数、辺上の昇冪順で識別する。係数行を保つため、代表点の値だけでは行を選ばない。接続では原拘束に物理$q_0$を代入し、同じ位置を再現することを照合する。

## 原拘束と仕事

各非零行は先頭の非零係数で割り、厳密に等しい疎行を共有する。元の行番号と符号付き尺度を保存するので、原作用と転置を同じ係数から再現できる。正規化行の双対は、最初の原行の尺度で割ってその行へ戻す。これによって原拘束の力と仕事を一致させる。

固定支持は指定した位置係数を原行に掛けた$c$を保持する。接続では$c=0$とする。作用入力には準備済みパッチの識別とCartesian座標を渡し、別世代は拒否する。全原行の $Cq$、$Cq-c$ と $C^T\lambda$ を、所有する厳密値として返す。作業量、行・非零数、確保と取消を全呼出しで検査する。

この入口は二つの側面または一つの固定支持を扱う。複数接続を集めた固定ピボットの疎チャートと閉路全体の従属行処理は、同じ原行を入力とする後続段階に属する。
