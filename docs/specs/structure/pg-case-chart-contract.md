# CaseのPG参照から全厚位置拘束と疎チャートを準備する

`prepare_case_pg_chart` は一つの型付きSI Caseを読み、$N,G,X_0$ と正の測度を評価できる全シェルの `PgPreparedPatch` と、固定ピボット `PgSparseChart` を所有して返す。先行する[Caseからの参照幾何準備](../../verification/IM-01/vpg-case-reference.md)、[参照基底](pg-reference-basis-contract.md)、[全厚位置拘束](pg-full-trace-contract.md)を使う。対象はSH-D02、SH-D03、SH-D05、SH-D07、CN-D01、N4-04とV-PG。

## シェルと参照作用

CaseのShell順に、同じIDと有限則を一つずつ渡す。明示点列では、Caseの幾何と層が定める体積片番号と正の重みを指定する。[正の積則](pg-product-volume-rule-contract.md)では、三つの単位区間則を指定し、実際の共通分割上で体積片ごとに点と重みを作る。どちらを使うかは呼出し側が指定する。各Shellの参照幾何から辞書と分割を借りて厳密rankを求め、同じ参照とrankを `PgReferenceBasis` に移す。その所有元から有限則のGramを包絡し、[合同誤差と必須場](pg-discrete-conditioning-certificate-contract.md)を認定して `PgPreparedPatch` に移す。返す所有パッチには認定に使った点と重みを保持する。

チャートのパッチ表はCaseのShell順と物理IDを保持する。各列の基底識別と係数の数は、全厚トレースを作った同じパッチのものを格納する。IM-02はここから列順、点・重み、$N,G,X_0$ と正の測度、原位置拘束 $Cq=c$ とその消去・転置を受け取る。[各層の材料と軸](material-layer-adoption-contract.md)、積分誤差、物理質量・剛性と構造応答は、IM-02側の資格判定を経る。

## 対応と向き

対象の支持は `Support.trace_constraint` のうち、名前付き外周辺の全厚に対する世界位置3成分を固定するもの。対象ShellとGeometryを照合し、元境界の始終点と分割後の原子辺を正順でたどる。並進と回転ベクトルが全時刻で明示的に定数零の支持について、元の参照位置を右辺に使う。Motionの参照枠は既存の右手直交フレーム認定を通す。時刻依存の支持には[Case指定運動の入口](pg-case-structural-support-contract.md)がある。

対象の接着は `Joint.adhesive` のうち、異なる二つのShellの名前付き外周全辺が一つのアフィンな辺パラメータ $\eta$ を共有し、各側の厚さ座標が $\zeta$ のまま対応するもの。Caseの各 `TraceMap` が $[\eta_a,\eta_b]\times[-1,1]$ の矩形を覆い、同じアフィン写像を使うことを照合する。全矩形の和が両側の全辺を隙間・重複なく覆い、正の長さで交わる全原子辺の内側セルが宣言番号と一致し、両境界の相対向きが宣言と一致することを検査する。物理中面、法線と向きは既存の全厚トレースで厳密に照合し、さらに物理厚さが共通区間の両端で同じことを要求する。区間内の厚さは一次式なので端点の一致で全区間を覆う。

両側の位置を同じ物理点で一致させる。異なる厚さや部分深さを対応づける写像、厚さ方向に面内座標が変わる写像、辺以外の接着には個別の幾何対応規約を使う。チャートは `(種別, ID)` で元宣言を区別し、固定支持、Jointの物理ID、元行の順に既存のピボット規約を適用する。

## 同じチャート上の指定運動

動く全厚支持を持つCaseでは、`prepare_case_pg_motion_chart` が同じ参照パッチと元行から固定チャートを準備し、その所有を[共通時計の構造支持](pg-case-structural-support-contract.md)へ移す。チャートの元右辺には固定した参照位置を置く。各時刻の動く支持の右辺はMotionから求め、定数零の静止支持は元の参照右辺に残す。Jointの元行もそのまま保持する。

`CasePgChart::motion` から共通時計と元行の対応を使い、`evaluate_case_structural_pg_support` に時刻と片側を指定すると、元行順の位置・速度・加速度を評価する。この結果を `lift_case_structural_pg_support_exact` と同じ疎チャートに与えれば、指定した自由座標の各微分次数から全座標を復元できる。

## 同じ所有チャートで行う数値計算

静止・時変のどちらも、呼出し側が `CasePgChart::prepare_numerical` に正・転置の尺度、変換精度と資源上限を指定できる。数値候補ができた時点で、元CSRと固定ピボットを含む厳密チャートの所有を候補へ移す。パッチ、Caseの元行、時計と動く支持の対応はそのまま使う。取消、資源不足や因子準備の失敗を返した場合は、厳密チャートと準備済みの候補を引き続き使える。準備に成功した後は、チャートと候補の参照を取り直す。

`CasePgChart::numerical` から候補を借り、静止の元右辺、または指定運動を保持語へ変換した元右辺を使って、[数値候補の規約](pg-chart-numerical-candidate-contract.md)に従い正方向・転置・仕事を評価する。正方向で時変右辺を使うときは、同じCase所有から評価した右辺の誤差上界も加える。判断には、各呼出しで指定した原行残差と仕事の上限を使う。厳密経路も同じ所有物から引き続き呼び出せる。

## Shell IDから後続へ渡す参照

`CasePgChart::shell_reference` は物理Shell IDを使い、同じ所有チャートの元列ブロックを探す。列の範囲、基底識別、独立列数を実際の準備済みパッチと照合する。返す参照は、そのパッチ、固定則の点と有理重み、元行を所有するチャートを一つの読取り専用ビューとして借りる。呼出し側はCaseチャートを生存させ、借用中は移動・置換しない。

`PgPreparedPatch::project_fixed_reference` は同じ固定則の連続な点範囲について、所有する $N,G,X_0$ と物理Jacobianを返す。結果は元の点番号の先頭とパッチ識別を保持する。同じ点範囲を `PgPreparedVolumeReference::prepare` に渡すと、同じ順序の $N$ とJacobianに加え、物理層・点番号・厳密重みを所有できる。層面と外周側面は同じパッチの `project_reference` で評価し、体積則の番号とは区別する。列配置はCartesian三成分の組単位。

存在しないID、探索上限、不整合な列配置、範囲外の点、取消、射影の精度・資源不足は値として拒否する。この受渡しは幾何と拘束の準備に適用し、材料や荷重を評価する際の求積誤差は後続で照合する。

## 失敗と資源

Caseは読取り専用。パッチ・原拘束・チャートを全て準備し、呼出し側と各段階の取消を最後に確認した時点で所有結果を返す。明示されたCase入力走査の上限、各段階の算術上限と同じ累積 `ResourcePlan` を使う。全厚トレースの呼出し中に残る有理座標の外部領域は、呼出し先の許容枠から予約する。基底の合同認定は渡された有限則に適用する。
