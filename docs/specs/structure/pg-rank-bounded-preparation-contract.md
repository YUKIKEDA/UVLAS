# PG局所rankの有限資源による準備

Issue #264、IM01-7。対象は[局所rank契約](pg-local-rank-contract.md)で固定した候補の順序、活動域での全再構成、全背景のアンカー核、所有する基底と写像である。SH-D03、SH-D05、SH-D07、N4-02、N4-08を適用する。辞書、分割、48 GiBの実務プロファイルを引き継ぐ。

## 入力と整数行列

同じチャートの実内容を持つ `PgCoefficientDictionary` と `PgIntegrationPartition` を読取り専用で借りる。製品分割で正面積を持つセルだけを活動域に採る。行はR/P/C、セル、二変数の単項の順で識別する。活動行は原列の非零項の和集合から作る。境界が接するだけのセルは採らない。アンカー行は全背景のs=0側を別に扱い、活動域に混ぜない。

原列Aと既存写像L=[G,I,J]を構成し、行ごとの正の分母LCM d_i と写像列の正の分母LCM e_j によって M_ij=d_i (AL)_ij e_j を保持する。Jの各列は原列からR/Pアンカー補完と既存Cアンカー写像を引く。アンカーでは同じ列をu=-1で評価し、全field・全t半セル・全原アンカー核列で零を確かめる。

## 認定する順序と返却

決定的に選んだ31-bit素数で、規定の候補順に探索する。初期行の非零数で同順位を分け、同数なら正規行順とする。有理分母を割る素数を使わない。独立列は非零pivotを持つ小行列式の証明を得る。Jは基底を拡張しない。

共有した正方因子で従属列を持ち上げ、桁数1、2、4、…で有理復元を試みる。後から採った基底列の係数は厳密に零でなければならない。復元候補の全活動行を確かめるまで従属を認定しない。したがって悪い素数や桁不足が小さいrankを成功として返すことはない。所有するS/W/Zは、整数候補への座標y_kを e_{b_k} y_k/e_j に戻して既約にする。選択列のBは所有する有理係数、元辞書の全列の来歴と、全G/I/J列の元辞書写像を項順・符号付きで所有する。Tはその写像のうち選択したG/I列を参照する。3並進はスカラー写像を共有してもCartesian方向を区別する。独立証明書は生成側へ渡さず、試験で同じ出力を比較する。

## 事前計画と処理上限

n=4でも採用した行キーの全空間は23,296。固定長の印で行と列の出現量を数える。元Aの非零数と、各候補を作る写像項ごとの元非零数の和から、相殺前の容量を予約する。アンカーの一時領域、有限体探索の作業行と疎因子、元行と正方因子、復元と全行証明、返却領域を同じ `ResourcePlan` に積み上げる。同時保持と累積所有を別に記録する。

Boostにグローバル設定を加えない。固定backendの広い積はlimbごとの学校式に分ける。チェック付きスロットを越える演算、走査や桁数の予算超過、割り切れない除算、取消は失敗として返す。幅プロファイルは測った最大値から縮めない。局所rankの成果と、実結合グラフやR-02全体の性能を区別する。


### 同時領域と累積課金

形状を数える間は、既知の単項キー空間を固定長の印で扱う。確保前に、計数した非零項数の上限と、最大rank R=min(m,F)を当該処理の使用型のサイズに掛ける。実rankが判明するまでRを小さく見積もらない。確保するバッファは以下のとおり。

| 段階 | 事前算定する所有領域 |
|---|---|
| 候補構成 | AのCSC、MのCSC、行・列・アンカー行の尺度、1列の累積値、全背景アンカー評価、借用写像の索引と項からなる11配列 |
| 有限体探索 | 作業行、行密度・順序とbucket、全候補の先行列数、選択・pivot・逆元と逆引き、上下因子、縮約列の境界と非零を持つ13配列 |
| 持上げと証明 | 有界正方CSC、整数右辺と行和・幅上限、剰余・補正桁、復元・証明の作業値を持つ10配列 |
| 元入力の証跡 | 所有結果に組み込む固定長のグラフと活動面積、順序付き元Dの1配列 |
| 所有結果 | 結果本体・正規行・選択列・全候補の座標、基底の列境界・行・値、原辞書の全写像値を持つ8配列。来歴は結果本体に固定長で持ち、全写像の列境界は候補構成から所有権を移す |

Aの非零数は実体から数える。Mは各候補について写像の各元列の非零数を合算し、活動行数との小さい方を使う。pivot行列はMの項数上限とR²の小さい方で囲う。公開するBおよびTの計画にはMおよび全写像の上限を使い、選択後に実際の項数だけ確保する。従属列の座標表は一度だけ確保し、素数の再試行では同じ配列へ上書きする。用意した配列の合計を先に利用者の上限とResourcePlanの残りに照合する。確保済み課金は失敗しても返金しない。

固定整数は正規化と右辺の1,536 bitと、復元・元式検証の8,192 bitを使う。これらは実測の最大値を入力にしない。素数は2³¹未満で、試行桁数は128以下とし、剰余の法は2^3968未満で、3,968 bit以下である。復元した真の座標の幅や全行証明の共通分母は法の幅と別に扱い、数学上の中間値を格納できない場合はResourceExceededとなる。回収座標の分子・分母は符号とGCDを正規化して所有し、B・Tの戻しにも同じ検査を行う。

素数上のpivotが非零でも、それだけで飛ばした列を従属と認定しない。後に増えた座標が零であることと、全元行の残差が零であることを同時に要求する。そのうえで独立なBを同じ元列から出すため、選択順と全ての写像が成立する。分母を割る素数と復元不成立は結果を破棄して固定順で再試行できる。既知の容量・取消の失敗は素数の再試行で隠さない。

スロット内の整数の積は、小さい側のnative limbごとに進める。同符号の絶対値の累積を最後に符号化し、負のビットシフトやオペランドの書換えを使わない。有限の仕事枠では、主要な走査、有限体の更新、整数のlimb積・除算の大きさを課金単位に用いる。この回数は時間やCPU命令数を示さない。同時保持には同じPlanに既に課金した製品入力と、その生成工程の外部limb見積りもあり、検査記録では、既存の課金、追加の事前算定、実際の課金、外部見積りとプロセスの観測値を別に示す。所有済みの結果から有理値を取り出すときは、取り出し側の既存exact資源契約を使う。

### 有界な実行と証跡

活動行数をm、候補数をN、rankの上限をR、正規化候補の項数上限をT、最大試行桁数をDとする。最大4素数の各試行で、有限体の作業列初期化・pivot探しは各mN、縮約の訪問はmNR以下である。選択された列の正方CSCは高々min(T,R²)項である。持上げは各候補で最大D回行う。1桁の三角求解はR²以下の項処理、剰余更新はR、元整数による差の検査は正方CSCの項数とRに比例する。各行について初回右辺の絶対値と係数の絶対値和の大きい方をLとすると、補正桁を引いた後の絶対値はpL以下である。pで正確に割るたびに、元の上限Lを比較する。

復元は最大8回の桁境界で試みる。既約化と有理復元の剰余列は固定幅の整数のユークリッド互除法で進む。各除算をlimb寸法で課金し、次の割り切れと残差の確認に使う。先行列の条件を通った候補について、分母のLCMと各座標の整数係数を一時領域に作り、正方部と全活動行で同じ係数を証明する。全行の残差配列は再利用する。

出力には実グラフのx₀、幅、skew、高さの有理係数と版、元Dの有向辺から復元した順序付き頂点、全背景セルの正確な面積と活動フラグ、基底選択の版を保存する。元の有理係数辞書や分割が破棄されてもB/T/S/W/Zおよび証跡を読める。公開APIから各required列とanchor列の元写像を項順に読み出せる。

### 現在入力での再検証

`PgRankPreparation::validate_for` は入力factoryと既存結果を読取り専用で受け取る。Workspaceのleaseを取って取消を確認した後、辞書と分割のグラフ実値、既存結果が所有するグラフ・元Dの順序付き点・全セル面積と活動・recipeと選択規約版・全列の来歴・全G/I/J項を照合する。厚さ・層・補助cutは局所係数空間の条件に含まれない。実値が異なればStaleGenerationを返す。

現在のAとLから、同じ整数化と有界証明を同じ仕事枠で実行し、活動行、候補選択の順序、B/T/S/W/Zを既存結果と厳密に照合する。Tは実入力と照合した元写像と選択順の組で定まる。全背景アンカーも改めて検査する。照合用の一時結果は呼出し内で破棄され、成功しても既存結果を差し替えない。移動元や再入はInvalidInput、枠不足はResourceExceeded、取消はCancelled、全再構成の証明が得られなければRankUnresolvedを返す。

総仕事量には実入力比較、一時結果の生成、保存した行・成分の比較を含める。再検証の追加payloadは通常準備と同じ事前式で計画する。元結果も同時に使う場合、利用者の計画はその既存課金を含める。返却情報は一時結果の追加事前算定と実課金、再検証全体の作業量を返す。局所係数空間を再利用する際の入口として使う。
