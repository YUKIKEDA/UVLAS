# PG固定疎チャートを元の有理CSRで補正する

[数値候補](pg-chart-numerical-candidate-contract.md)の準備で選んだ疎CSCと正・転置に共通の因子を使う。ピボット、採用元行の順、自由列、元の有理CSRを保持する。呼出し側は元残差の絶対上限、追加求解の回数、走査・有理演算の予算、所有領域の `ResourcePlan` を指定する。各成分は世界Cartesian順の3列。演算予算は一回の入口から全ての補正と最終検査までの合計に適用する。

## 前進

元の $B=C_{s,P}$ と $D=C_{s,F}$ を用いる。初回は代表元行の $c_s-Dr$ を有理演算で作り、その二語を準備済みの因子で解く。自由列には呼出し側の語をそのまま置く。返す二語を有理数に戻し、従属行と零行を含む全元行で $d=c-Cq$ を評価する。上限を超える場合は代表元行の $d_s$ を同じ因子へ渡し、依存座標だけを補正する。座標と補正の加算は両語の二進和を二語に戻す。

## 転置と仕事

初回は $f_P$ を準備済み因子の転置で解く。非代表元行の乗数は零とする。各試行で有理の $v=f-C^T\lambda$ を全列に評価し、自由列 $F$ の $v_F$ から返却する二語 $h$ を作る。その二語を差し引いた $v-R^T h$ が元の力釣合いの残差となる。上限を超える場合は $v_P$ を同じ転置因子で解き、代表乗数を補正する。元行乗数の符号は[固定チャート](pg-sparse-chart-contract.md)に従う。

返す値の元残差を厳密に比べ、最大絶対値の上向きに丸めたBinary64上界を報告する。保持語の仕事 $f^Tq-h^Tr-\lambda^Tc$ は既存の `work_defect` で、前進・転置の返値を同時に用い、呼出し側の上限に照合する。

## 所有・中断・適用範囲

内側の数値求解には保持精度と代数検査を指定する。数値候補の補正を途中の物理状態として評価する要求やBinary64への投影はこの入口で拒否する。返却はTwoWord。外部の有理演算領域には一軸の座標または力釣合いに使う全列のスロットと、演算中の一時値を見積もる。列・元行・出力バッファには所有課金を行い、追加求解ごとの確保も同じ計画に加算する。返却値には補正回数と演算・領域の内訳を持たせる。

上限内で最終値が認定できない場合は `PrecisionUnresolved` を返す。作業・確保の不足、取消、世代不一致もそれぞれ失敗になる。取消は走査中とバックエンド呼出しの前後で確認する。失敗時も元因子、元拘束、呼出し側の入力を保つ。許容は元係数の尺度。位置や反力の実空間への対応と前進誤差は、採用モデルの尺度と要求から別途認定する。
