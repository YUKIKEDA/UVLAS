# J1：平衡枝の継続と連成誤差の単位

2026-11-05。採用する静的未知量zは、同じ構造座標・Γ・指定／自由定常後流を含む。F(z,U)=0はJ1の同じ残差であり、Uを変えても材料・支持・後流政策を黙って変えない。

## 平衡継続

通常の風速増分では前点と接線から予測し、同時Newtonと残差の線探索で補正する。接線や分岐が不適格なら増分を減らし、確定点を維持する。限界点では重み付き疑似弧長を使う。

$$
F(z,U)=0,\qquad
t_z^TW_z(z-z_{pred})+t_Uw_U(U-U_{pred})=0,
$$

$$
[F_z\ F_U]t=0,\qquad
t_z^TW_zt_z+w_Ut_U^2=1,\qquad \langle t,t_{old}\rangle_W>0.
$$

Wz,wUは単位と代表尺度から固定する。Newtonのための行尺度と、物理的な弧長の尺度を混同しない。接線の符号を風速増加に毎回固定すると折返しで枝を失うため、前接線との向きを保つ。支持反力・全非貫通・自由後流輸送の原残差を検査する。限界点／複数の零方向を検出したら、静的発散・分岐・未解像として記録する。擬似逆で一方向を消してフラッタへ読み替えない。

複数枝へ分かれる場合は枝IDと準備履歴を保持する。追加の分岐選択が物理的に非一意なら、その事実を結果へ返す。単一の初期推定が選んだ枝を、唯一の実現状態とは表示しない。曲線の全点・接線・増分・失敗・分岐対応も速度探索再開へ含める。

## 誤差群

BDF2とP1の後流履歴は同じhから作るので、動的／フラッタでhを変えた差は「時間＋後流年齢」の結合指標として扱う。物理保持時間Tを固定し、行数をT/hに合わせる。これを独立な時間誤差と後流年齢誤差へ重複計上せず、未評価の片方を零にも置かない。静的自由後流の同じh細分化は年齢離散化の誤差になる。

後流の長さ／保持時間はhを保って独立に変える。束縛格子、構造パッチ／厚さ／層、コア、核求積、代数／Newton、固有値抽出とモード範囲、速度探索区間幅、幾何／荷重写像の各群は比較計画で担当を定義する。結合した群にはcoversを明記し、個別上限を設けた場合は分離できなければ未認定にする。

ケース・平衡枝・初期準備・支持・入力補間・荷重作用点・観測量の定義は比較中固定する。hや後流政策を変えた安定性では対応する平衡も解き直す。前の格子の平衡を据え置いて異なる作用素だけを比較しない。

実装前の採用に必要なのは、方式と実行可能な主要I/F・不変条件・拒否・参照の整合である。全実務ケースの完成結果をこの段階で先に要求しない。実装後の出力量別の精度と妥当性確認は、既定の製品予算を維持した5の受入手順で実施する。
