# 同じ疎因子から原行列の転置を解く

[疎基準解法](sparse-solve-contract.md)の準備済み因子を、原行列と転置の両方向で使う。N4-04の拘束JacobianやN4-06の保持精度のために、前進と同じ離散行列を使う入口を定める。

[数値基盤の採用仕様 N4-04](numerical-foundation-adoption-specification.md)に従い、`SparsePrepared::prepare` の両方向入口は前進と転置の物理尺度・単位・配置を別々に保持し、原行列の分解を一つだけ作る。二つの配置は同じCacheKey、試行、評価時刻に結び付ける。尺度を値や単位の付け替えなく使うため、各方向の実データを所有し、求解時にも照合する。随伴の物理尺度と単位は呼出し側が明示する。

`solve_transposed_linear` は準備時と同じ原CSC $A$ を受け取る。$R A E^{-1}=LU$ から $E A^T R^{-1}=U^T L^T$ となるので、$E b$ に $U^T$ の前進代入、$L^T$ の後退代入を行い、最後に $R^{-1}$ で元順へ戻す。抽出済みの $L$ と $U$ の各列から必要な成分を読み、元行列の転置や第二の因子を作らない。認定済みLLTでも同じ作用を使う。

原残差は元のCSCを読み、行と列の役割を交換して $b-A^Tx$ を固定順で計算する。右辺と解の両語、後退誤差の分母、補正、明示投影はすべて同じ方向で検査する。結果は転置であることと、その配置、単位と実尺度を保持する。両方向で同じ準備領域を再利用し、同一所有者への再入は拒否する。前進専用で準備した因子への転置要求は `Unsupported` を返す。

## 検証

非対称の4次疎行列の前進と転置、双対仕事、異なる物理尺度と単位、両語保持と投影拒否を照合する。三角代入中の確保は計測する。
