# IM00-3の失敗・誤差認定の内部契約

対象はN4-02とN4-08、Issue #7。公開ABIは固定しない。物理式、受入精度、解法、保存形式は変更しない。

## 失敗を所有する

`Result<T>` は `std::expected<T, Failure>`。FailureはN4-08の17種類のcodeと処理名、モデル・親・試行・数値の識別、問題の成分とID、必要／実測資源、最後の確定状態の識別を値として保持する。モデル作成前など識別が存在しない項目はoptionalとし、不明を数値0で埋めない。

識別子は別々の強い型で、数値が等しくても種類を混用できない。物理・ファイルIDとして0を含むuint64の全範囲を値に認め、欠落にはoptionalを使う。配列添字とは区別し、符号付き64bitのIndex・checked寸法・ResourcePlanはIM00-2で実装する。状態との照合・資格付与・確定はIM00-9が担当する。識別子が一致することを、この値型自身が検証したとは扱わない。

資源のrequiredとobservedは同じResourceKindの整数である。Bytes、反復回数、作用回数、ナノ秒を区別する。まだ必要量を特定できない場合は資源情報自体を省略し、測定値を作らない。

Failureとその複製は動的確保を行わない。例外のwhat()への借用参照も持たない。これにより、bad_allocを変換するときに診断文字列の確保で再び失敗することを防ぐ。

## 入口で例外を止める

`guard_entry(operation, exception_code, details, action)` はResultを返す処理を1回呼び出す。処理が返した成功値・既存Failureはそのまま返し、bad_allocはResourceExceeded、その他の例外は入口が指定した処理固有codeへ変換する。標準例外・非標準例外をともに捕える。返却はnoexceptで、Failureの構築に確保を要しない。

exception_codeは一般例外の分類であり、通常の入力拒否・未収束・中断は各処理が具体的なFailureを返す。guard自体は入力の検証、失敗した計算のrollback、確定状態の管理を代行しない。親を読取り専用で受ける各入口とIM00-9の状態契約で保証する。

## 未評価と達成を区別する

ErrorCertificateのcontextは、観測ID、評価範囲ID、数値世代、評価した場の表現（Binary64／TwoWord）。ScopeIdは観測計画が定義する評価範囲の識別である。評価範囲を狭めた認定を、全体の認定へ読み替えない。

認定状態はUnevaluated、Achieved、Exceededのvariantである。未評価には誤差上界がなく、達成・未達には評価器が報告した上界がある。ErrorCertificateの構築は専用の関数に限る。呼出側は達成・未達を直接指定しない。

予算と上界は同じ観測・評価範囲・尺度で定義された非負有限値とする。0の予算は厳密一致の要求として認める。`unevaluated` は予算のみを受け取り未評価を作る。`assess` は上界が予算以下なら達成、超えれば未達を作る。丸め幅や隠れた許容差を足さない。

入力検査は、非有限、負値、未対応の表現タグの順に行い、それぞれNonfinite、InvalidInput、PrecisionUnsupportedを返す。診断には観測IDと数値世代を保持する。

この型は誤差上界を計算せず、解をBinary64へ変換しない。評価器が正しい範囲・世代・表現を評価し、必要な保守的上界を作る責任は各数値kernelにある。特にTwoWordのタグを付けただけでは、低位を捨てる投影や未対応のconsumerを認定したことにはならない。N4-06の保持・投影・消費の検査を継承する。

## 対応する確認

| 決定 | 実装 | 独立した確認 |
|---|---|---|
| 17種類の失敗と所有する診断 | failure.hpp | 17codeの識別、contextの複製、別種類IDの構築不能、uint64の両端 |
| 例外の値への変換 | guard_entry | 成功・既存Failure・void、bad_alloc、標準／非標準例外を注入 |
| 未評価を達成にしない | error_certificate.hpp | 未評価variantから達成値を取得できないこと、直接構築不能 |
| 予算境界と拒否 | error_certificate.cpp | 両表現で0・subnormal・通常値、予算一致・次の表現可能値、負値・非有限 |

ここで確認するのは共通型と入口の契約であり、ソルバーの精度認定や実験妥当性ではない。
