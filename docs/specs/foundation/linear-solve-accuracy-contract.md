# 線形求解の精度契約案

版0.1、2026-10-29。NU-01/02と、OP-05/08/09/10から呼ぶ線形求解に関係する共通の論理契約案。OP-09自体は時間ステップの試行・受理処理であり、線形解法へ読み替えない。C++ API、数値依存、数値型、疎形式、時間積分・連成の許容差は未確定。全項目を基準化済みとはしない。

2026-10-31追記：[非対称空力8系の求解感度診断](../../../rd/aero/avl-reference/records/avl-solve-sensitivity-experiment.md) に基づき、条件推定の種別と出力感度の責任境界を以下へ追加する。製品バックエンドの選定ではない。

| 追加する論理項目 | 不変条件 |
|---|---|
| 条件診断 | 対象演算子・尺度・ノルム・推定アルゴリズム・精度・呼出し数と、「下からの推定／保証された上界／未評価」を保持する。下からの推定を上界として消費しない |
| 出力別診断 | 重みwの世代・単位・観測位置、随伴、随伴残差、右辺摂動の尺度、解き直し・補正による出力変化を保持する。合力の成立で局所荷重やモーメントを代替しない |
| 残差計算 | 補償加算と誤差なし変換を区別し、演算順を検証する。Neumaier補正項は相殺する2項を先に括弧内で計算してから既存補正へ加える |
| 保証の範囲 | 格納Aに対する求解診断、A自体の評価精度、空間離散化精度を別項目とする。前者の成立を後二者の受入へ昇格させない |

測定は入力LU・循環・確定状態を変更せず、診断用の別配列を使う。今回の外部参照では通常出力のバイト不変性も検証した。これは製品側の並行実行・キャッシュ寿命・世代不一致の検証を済ませた意味ではない。

## 1. 根拠と責任境界

[Q9板曲げの精度切り分け](../../../rd/structure/main-shell/q9-plate/records/q9-precision-diagnostic-experiment.md) では、高精度保持解が残差基準を満たしても、倍精度投影は同じ基準を満たさなかった。このため「内部ソルバーが収束した」だけでは、返す解・次処理の入力・確定状態の精度を保証できない。

本処理は、指定された離散線形系と表現に対する解・診断を返す。構成則、境界条件、要素離散化の妥当性、全連成の収束、製品の精度を単独で保証しない。

## 2. 入力と事前条件

| 入力 | 意味と条件 |
|---|---|
| 系の同一性 | モデル・試行状態・行列・右辺・拘束変換の世代ID。分解再利用の適否を判別する |
| 演算子と右辺 | 拘束処理後の次元、未知量・残差の成分順と単位、対称／非対称・正定値性の主張と確認範囲。明示行列／作用の採否は未定 |
| 尺度・変換 | 物理未知量への写像と逆写像、正の有限な尺度、固定／状態依存、残差をどの系で評価するか |
| 評価状態 | 静的／過渡ステージ／フラッタ線形化、時刻、試行ID、固定する履歴と接線更新番号 |
| 精度要求 | 残差のノルム、相対・絶対基準、ゼロ右辺の扱い、後退誤差、補正・停滞の判定、必要な応答量と誤差予算 |
| 精度構成 | 行列保持、分解、補正、残差積和、解保持、返値・消費側の各表現。支持しない組合せは拒否 |
| 予算 | 分解・反復・再試行上限、時間・メモリ、返却表現の容量と許容する投影 |

有限値・寸法・拘束対応の整合を必須とする。剛体零モードや冗長拘束を、対角へ無断で正則化して隠さない。尺度や拘束写像の変更は、同じ線形系の解を返したことにしない。

## 3. 返値・診断の論理項目

| 項目 | 必須の意味 |
|---|---|
| 解 | 未知量の順、尺度化／物理座標、実際の保持表現、所有者・有効期間。内部表現と返値が異なる場合は両者を識別する |
| 精度の対象 | 内部保持解、返値、消費側へ投影した状態のどれを検査したか。対象ごとに達成／未達／未評価を区別する |
| 残差 | 元離散系または尺度化系、ノルム・分母・絶対値、入力A/bの世代、積和精度と演算方法 |
| 後退誤差 | ノルム・成分別、分母ゼロの規則、明示的に評価できない場合の理由。残差の別名として扱わない |
| 解の変化・感度 | 補正量、精度変更・行列摂動への応答差、利用できる誤差推定とその仮定。厳密上界と経験的比較を区別する |
| 実行記録 | 分解更新／再利用、反復数、精度構成、停止理由、時間・容量、有限性・特異性等の診断 |
| 有効範囲 | どの物理量・表現・入力世代で使用できるか。未評価の表現へ保証を拡張しない |

出力用float64投影の差が小さいことと、投影後の平衡残差が小さいことを同一視しない。後段がfloat64を消費する場合、その表現の評価結果と呼出側の精度要求を照合する。

## 4. 成功・未達と確定状態

成功は「要求された表現と検査項目を満たす解が存在する」こと。候補解が得られたが精度要求を満たさない場合は未達で返す。診断用候補を通常の確定状態として扱わない。

状態は、入力不適格、分解失敗・特異性、非有限、予算超過、残差未達、補正停滞、必要表現への投影で精度未達、必要診断の未評価を区別する。具体的な列挙型・例外方針はIF系で確定する。

求解処理は入力モデルと確定状態を変更しない。出力解とWorkspaceだけを更新し、失敗時には部分解の使用可能範囲を明示する。連成・時間積分の受理は呼出側の責任で、全系の受理条件が成立してから一度だけ確定する。

## 5. キャッシュ・寿命・並列化

分解キャッシュは行列の数値・疎パターン・拘束・尺度・精度構成・バックエンドに依存する。右辺だけの変更で再利用できる範囲は解法ごとに定義する。世代不一致をポインタの同一性で代替しない。

Workspaceは呼出側所有を候補とし、別の並行求解との可変共有を禁止する。解・診断がWorkspaceの再利用で無効になるか、所有するかはAPI確定時に明記する。Pythonビューの寿命・再入可能性は未決定。高精度残差を持つ経路の容量・通信・並列積和順も性能条件へ含める。

## 6. 概略処理と不変条件

1. 系のID・次元・成分・拘束・尺度・精度要求を検査する。
2. キャッシュ適合を判定し、必要なら分解／前処理を構築する。
3. 初期解を求め、指定された表現を保持して残差・後退誤差を評価する。
4. 未達なら上限内で補正する。保持精度・積和精度・補正精度を記録し、停滞・非有限を検出する。
5. 要求された返値・消費側表現へ変換し、その対象の検査を行う。内部解の合格で省略しない。
6. 達成・未達・未評価を含む解と診断を返す。確定状態を変更しない。

不変条件：同じA/b世代への残差であること、異なる単位の生ノルムで精度を隠さないこと、精度保証の対象表現が実際に消費される表現と一致すること、失敗時に確定状態へ影響しないこと。

## 7. 対応証拠と未完了事項

Q9の外部FEM照合・境界荷重試験、板曲げ収束、精度切り分けは、無拘束零モード・尺度混在・薄肉悪条件・解投影の正常／未達例を提供する。ただしこれらは製品の求解処理を通した受入試験ではない。

未完了：非対称空力行列・拘束付き不定系・動的有効接線・複素固有値問題の解法、ゼロ右辺・特異性・世代不一致・失敗保証の具体入力、データ型と疎形式、誤差予算と絶対相対許容差、表現変換後の受理、C++依存・性能。今回のDecimalと疎LUを製品へ自動採用しない。本契約案だけでNU系や各呼出側処理の開始条件は満たさない。

## 空力の細格子で追加された精度診断

[局所圧力・ピッチの追加細分化](../../../rd/aero/wake-loads/records/uvlm-local-pressure-pitch-experiment.md) で、2048分割の局所平均参照差は最大0.441%まで減ったが、初期LU解の通常積和による非貫通残差は最大4.36e-11で事前1e-11基準未達となった。続く [補償残差・トレース診断](../../../rd/aero/wake-loads/records/uvlm-residual-trace-experiment.md) では、同じ格納行列の初期補償残差も最大4.40e-11で、積和の丸めだけでは説明できなかった。1回の反復改良で2048分割のfloat64保持解の補償残差は最大6.55e-12となり、最終の標準BLAS評価も基準内。圧力変化は尺度付きで最大2.95e-11にとどまり、2.319%の格子差は残った。初期未達を保持し、求解精度と圧力の空間収束を別に判定する。


## 高低保持と消費側投影の追加証拠

[4096分割の後縁列更新試験](../../../rd/aero/wake-loads/records/uvlm-column-update-convergence.md) は同じ有効係数を実数基底と複素1列として保持し、メモリ予算内で追加収束を評価した。k=.1のfloat64更新は残差未達で停滞したが、高低2配列の1補正で適格となった。同じ解をfloat64へ投影すると2右辺が1e-11条件を超えた。したがってこのケースの成功対象は高低保持・両配列を消費する線形観測であり、float64返値の適格性を保証しない。製品に高低表現を採用する判断とは別に、返値・消費側の表現を契約へ含める必要性の追加証拠とする。
