# RW-3の原残差補正：縮約・復元の数値仕様

2026-11-04。FEの空間・物理エネルギー・参照配置・τを固定したまま、QR因子を前処理として原問題の欠損を補正する。[事前仕様](verification/reference-work-refined-protocol.md)・[線形検査の対応](verification/reference-work-refined-v2-protocol.md)。製品数値基盤全体の採用ではない。

局所の平方根作用素W、ターゲットb、位置uに対し、rは主求積の物理ひずみ差・安定化から評価する。g=Wᵀrを体積＋上下面の内部成分iと、共有面成分bに分ける。列尺度S=diag(s)とQR因子を

$$
WS=Q\begin{bmatrix}R_{ii}&R_{ib}\\0&R_{bb}\end{bmatrix}
$$

とする。元の勾配から

$$
z_i=R_{ii}^{-T}S_i g_i,\qquad
\widetilde g_b=g_b-S_b^{-1}R_{ib}^Tz_i
$$

を求め、面基底変換の転置で共有残差へ組み立てる。大域の列尺度Dと上三角QR因子Tを使い、

$$
\Delta u_\Gamma=D T^{-1}T^{-T}D\,\widetilde g_\Gamma,\qquad
\Delta u_i=S_iR_{ii}^{-1}\{z_i-R_{ib}S_b^{-1}\Delta u_b\}
$$

を計算する。正規行列WᵀWは作らず、全て三角求解で作用を適用する。u←u−αΔuとし、α=1,.5,.25,.125で元の尺度付き停留残差が減る更新だけを受理する。最大4更新。収束保証を仮定せず、元問題の残差・物理誤差・資源を観測して採否を決める。

合否には、元の作用素の停留条件、実際に解いた初期／補正三角方程式の残差、別積分、元のrank・条件数・H¹上限を用いる。補正後の解を初期の丸められた圧縮方程式へ代入した値は、補正の線形求解残差とは分けて記録する。
