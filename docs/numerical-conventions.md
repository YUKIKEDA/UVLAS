# 数値規約・データ契約

版：0.2、2026-10-29。T02の設計草案。以下は未基準化の提案であり、確定した実装・検証仕様ではない。[実装前設計計画](preimplementation-plan.md) と [設計決定台帳](design-decisions.md) に従い、採用式・座標・符号・時刻・処理契約・ケースとの整合を確認してから基準化する。計算機能の実装済み仕様を意味しない。

数式は本文・表で `$…$`、独立した式で `$$…$$` のLaTeX表記を使う。主要式ではベクトル・行列を太字、四階材料テンソルを別の書体で識別し、転置・逆・微分・添字を明示する。関数名・型名・ファイル名・CLI等のコード識別子はコード表記とし、数式をコードブロックで代用しない。

インライン数式は区切りの外側に半角スペースを置き、`本文 $式$ 本文` とする。日本語・句読点・表の区切りへ密着させない。独立式の `$$` は前後に空行を置いた専用行に記載する。

## 1. 単位と量の識別

内部単位はSI。角度入力は単位を明記し、内部の角度計算はradとする。無次元量でも、角度、勾配、循環係数、ひずみを型・名称・メタデータで区別する。単位系を持たない外部格子には利用者が単位系を指定し、座標・材料・断面・質量・慣性・荷重を一貫して変換する。

| 量 | 内部単位・規約 |
|---|---|
| 位置・変位・厚さ・断面寸法 | m。位置と変位は別の量 |
| 時刻、速度、加速度 | s、m/s、m/s² |
| 質量、密度、回転慣性 | kg、kg/m³、kg·m² |
| 力、モーメント、圧力、応力 | N、N·m、Pa、Pa |
| 循環、渦コア半径 | m²/s、m |
| 梁の回転・角速度 | rad、rad/s。回転の表現方式は要素選定時に定義 |
| ANCF勾配 | 参照物質座標に関する位置の微分。物質座標をmで表す場合は無次元 |

自然座標に対する微分を使う要素は、その尺度を明示して変換する。勾配の単位・意味を名称だけで推測しない。

## 2. 座標系と運動

基準の慣性系は右手系で $e_{x} \times  e_{y} = e_{z}$ 。初期の水平な翼では、xを前縁から後縁へ向かう方向、yを一方の翼幅方向、zを上向き法線方向とする。外部モデルにこの向きを強制せず、剛体変換によって対応付ける。

各揚力面・構造部材・材料は識別子と局所座標系を持てる。位置、速度、力、モーメントは座標系IDを伴い、API境界で共通慣性系へ変換する。

点の変換を $x_{I} = R_{\mathrm{IB}} x_{B} + t_{\mathrm{IB}}$ 、自由ベクトルを $v_{I} = R_{\mathrm{IB}} v_{B}$ とする。Rの列はBの基底をIで表したもの。運動する座標系の点速度には、並進速度と角速度による寄与を含める。一般の非剛体変換を回転行列Rとして扱わない。

背景流は空気の慣性系速度であり、翼の進行速度と区別する。翼面の相対速度は背景流・突風・誘導速度から翼面の慣性系速度を引いて評価する。

## 3. 迎角、力、係数

単翼・剛体・水平な初期確認ケースでは、正の迎角αに対し背景流を $\mathbf U_\infty=(U \cos \alpha , 0, U \sin \alpha )$ と定める。翼を回転して与える迎角と背景流を傾ける迎角は別入力であり、意図せず二重に適用しない。

慣性系の合力Fと基準点 $\mathbf x_{\mathrm{ref}}$ 周りのモーメントMは、各作用点の力から $\mathbf F=\sum_i\mathbf f_i$ 、 $\mathbf M=\sum_i[(\mathbf x_i-\mathbf x_{\mathrm{ref}})\times\mathbf f_i+\mathbf m_i]$ とする。 $m_{i}$ が独立に存在する場合だけ加え、作用点偏心の寄与と重複させない。

迎角だけを持つ初期ケースの風軸は $e_{D}=(\cos \alpha ,0,\sin \alpha )$ 、 $e_{L}=(-\sin \alpha ,0,\cos \alpha )$ 。抗力を $D=F\cdot e_{D}$ 、揚力を $L=F\cdot e_{L}$ と定義する。一般の三次元背景流には、流れ方向と指定した上向き基準から直交基底を構築し、退化する組合せを拒否する。

力係数は動圧 $q_\infty=\rho U_{\mathrm{ref}}^2/2$ と $S_{\mathrm{ref}}$ 、モーメント係数はさらに $c_{ref}$ または明示した基準長を使う。 $S_{\mathrm{ref}}$ 、 $c_{ref}$ 、基準点、軸、片翼／全翼の別を入力・出力に保存する。変形のたびに基準量を黙って変えない。 $U_{ref}$ =0では次元付き荷重を扱い、動圧で除した係数を未定義として識別する。

## 4. 法線と渦の向き

幾何の頂点順序・法線と、渦線の向きは別の属性として管理する。正の循環は有向渦線A→Bに対する右手則で定義する。渦輪は有向辺の閉路で表し、法線から暗黙に辺順を反転しない。

符号確認ケースは、+y方向の有向渦線と、その後方の+x方向にある評価点。正の循環は評価点に-z方向の誘導速度を生む。束縛渦の荷重の符号を確認する場合、背景流+xと渦線+yの組合せで上向き荷重となることを、採用する荷重式の適用条件に合わせて確認する。

翼上の渦配置、循環の未知量がパネル渦輪か辺循環か、荷重式、コロケーション点、後縁の接続・Kutta条件・後流放出は別の数値仕様で確定する。幾何法線の向きだけで荷重式や循環符号を決めない。

## 5. 構造の自由度と荷重

自由度には要素種別、節点ID、成分ID、量の種類、単位、拘束状態を持たせる。ANCFシェルと梁の自由度数を一律の節点6自由度へ押し込まない。梁の回転座標とANCFの勾配を直接等置しない。

一般化荷重は仮想仕事 $\delta W=Q\cdot \delta\mathbf q$ の双対として定義する。位置自由度の一般化荷重はN。無次元の勾配自由度に対する荷重はN·mとなり得るが、通常の回転モーメントをそのまま代入する根拠にはしない。拘束や要素変換を介した写像から求める。

集中質量・慣性は、質量、重心偏心、慣性テンソル、慣性を定義する基準点・基底を指定する。非対角慣性、平行軸移動、回転に伴う運動学を扱う。Nastranの慣性成分とANCFの質量行列の対応は、カード名だけから決めない。

剛体結合は位置・向きの運動学的関係として定義し、初期形状・許容仮想変位・反力・仕事を検証する。異なる法線を持つシェルの勾配を無条件に共有しない。

## 6. 材料と出力テンソル

積層順、板厚方向の正方向、各層の範囲、基準材料軸と繊維角の向きを明示する。度／radと、局所角／慣性系角を区別する。応力やひずみを匿名の6成分配列だけで外部へ出さない。

出力には最低限、テンソルの測度、基底とその配置、層ID、評価位置、成分順、せん断成分の定義を付ける。内部ひずみ・応力の仕事共役性と、利用者へ出す応力測度の変換を整合させる。

6成分へ並べる場合の論理順は `11,22,33,23,13,12` とする。工学せん断ひずみγを使う配列とテンソルせん断ひずみを型・名称で区別する。内部ライブラリの配列順序は境界で変換する。

## 7. モデル、確定状態、試行状態

Q27 Bの指定初期ひずみは材料側の参照量として保持する。初期変位・初期曲面・応力を持つ平衡状態と区別し、測度・基底・層・分布を明記する。初期ひずみを含む内力・接線・出力と初期化は [指定初期ひずみ設計](initial-strain-design.md) に整理する。平衡形状を無応力形状へ置き換えたり、再開時に初期ひずみを再加算したりしない。

Modelは接続、参照幾何、材料・断面、自由度対応、拘束、埋込みの物質座標等を保持し、構築後は原則不変。Stateは時刻、位置・速度・積分履歴、循環・後流・必要な空力履歴を持つ。Workspaceは一時配列・行列・分解・評価キャッシュを持ち、再利用できる。

各試行は確定時刻 $t_{n}$ 、目標時刻 $t_{trial}$ 、刻み幅、試行ID、連成反復番号を持つ。連成反復のたびに確定状態を進めない。受理時に構造、循環、後流、積分履歴を一度だけ確定し、失敗時は確定状態へ試行の履歴を混入させない。

荷重・位置・速度・循環の評価時刻と、積分法のステージを明示する。具体的なステージと差分履歴は時間積分方式を選定して定める。

Q25 Aにより、過渡解析とフラッタ速度探索の途中再開を必須とする。Stateと保存契約を同時に設計し、循環・後流・積分履歴・入力状態を欠落させない。再開点は受理された確定境界を基本とし、未収束の試行を通常の保存点にしない。保存対象と受入試験案は [再開・配布仕様](restart-and-distribution.md) に定める。

## 8. 収束・残差と診断

位置、勾配、回転、荷重のスケールが異なるため、生の混合ベクトルのノルムだけで収束判定しない。物理量別・自由度別のスケール、絶対・相対許容差、ゼロ近傍の扱いをケース仕様に保存する。

ソルバー反復の残差と、出力量の数値誤差予算は別に確認する。残差が小さいことだけで受入精度を保証しない。非有限値、未対応入力、特異性・未収束を正常結果として返さず、時刻・反復・該当ID・原因を診断へ含める。

[板曲げ精度試験](verification/q9-precision-diagnostic-experiment.md) の結果から、残差積和・補正・解保持・返値・消費側の精度を区別する。内部保持解の合格を、そのまま丸めた状態の合格へ移転しない。入力A/bの世代と対象表現ごとに評価し、未評価を合格にしない。具体的な入力・出力・失敗保証は [線形求解の精度契約案](linear-solve-accuracy-contract.md) に整理する。数値型・依存・全系の許容差は別途確定する。
