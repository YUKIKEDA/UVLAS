# J1の確定状態と速度探索の再開契約

2026-11-05。[初期・出力微分の最終規約](j1-initialization-output-derivative-addendum.md)と[J1共同決定](j1-discrete-equilibrium-and-chart-contract.md)を具体化する。ここでの辞書は論理スキーマであり、製品のバイナリ形式・C++所有権は4で決める。

## 確定状態

| 群 | 必須内容 |
|---|---|
| 識別 | 形式／方式版、モデル・材料・支持・拘束・入力・チャート・輸送／末端政策ID、epoch、物理時刻、実刻み |
| 構造 | 現在／前時刻のr,u、物理q,v・姿勢／twist、チャート原点と変換、初期化／再始動区分 |
| 空力 | 現在／前時刻Γ、全後流の位置・μ・物質ID／放出時刻・所有者、必要な位置履歴、閉端・退役台帳 |
| 受理微分 | 現在のD_hvとD_hΓ、使った3時刻ステンシルの値・刻み・評価順。次ステップの最小履歴と現在出力の再構成に必要な履歴を区別 |
| 出力 | 同じΓdotから作った全荷重、a_balと反力、元残差・拘束残差、数値認定状態・出所 |
| 再現 | 入力補間の実係数、イベントカーソル、参照準備版、実行環境識別、整合性検査値 |

物理状態と算法履歴の全群を一つの候補として検査し、成功時だけ一回確定する。確定後の外部配列変更が保存値へ波及しない。旧epoch・親指紋の不一致・二重確定・資格付与後の荷重改変を拒否し、失敗時は確定状態を一切変更しない。チェックサムが正しくても、ΓdotをBDF1へ置き換えた、現Γとステンシルが矛盾する、政策が違う等の意味的不整合は拒否する。

再開時は保存済み微分を保持し、ステンシルからも同じ評価順で照合する。現在の微分のためにさらに一時刻分を持つことは許可し、必要な履歴を省くために方式を変えない。同じ環境の継続／再開で次状態・次荷重がbitwise一致することを確認する。環境が異なる再開の許容条件と再現精度は4で別に定める。

## 速度探索

探索状態は、対象速度域、モデル・入力・方式・h・後流政策、完了済み点、各点の平衡枝と原残差、固有値／共通物理観測／対応部分空間、成長率不確かさ、各モードの臨界区間、未処理キュー、失敗・再試行数を含む。風速のキーは同一性が明確な表現を使い、表示用丸め値をキーへ使わない。

モード対応は共通の物理座標と質量内積でのMAC、近接モードは部分空間角。計算順・周波数ソート順をモードIDにしない。新しい点は近い適格な既存速度点を対応の基準にし、曖昧な対応は追加点またはクラスターとして処理する。

成長率の区間[g−Ug,g+Ug]が零を含む点は、安定／不安定のいずれへも決め打ちしない。必要なら区間内の追加点・固有値／時間精度の改善を要求する。両端の符号が不確かさ込みで確定した臨界区間だけを保持し、区間幅と他の数値誤差を予算へ入れる。

完了点とキュー操作・モード対応を原子的に確定し、再開で点の重複計算や脱落を作らない。計算済み点をキャッシュから再利用しても、新規計算として数えない。低い臨界値の確定には必要なモード／枝の探索範囲が覆われている必要があり、単に見つかった一モードを全モデルの最初のフラッタとしない。

検査では、実PG／自由後流の確定状態でBDF2微分・荷重の保存を照合する。探索制御は全固有値が分かる2モード製造問題で、周波数順序の交差、曖昧な成長率、複数臨界値と途中再開を検査する。実翼のフラッタ精度や大規模固有値抽出の成立はこの制御検査から転用しない。
