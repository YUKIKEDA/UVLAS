# UVLAS 製品要求仕様

版：0.1、2026-10-29。要求定義中。実装・検証済みを意味しない。

本書は製品要求を記録するもので、理論・数値設計の完了や実装開始の承認を意味しない。実装前に必要な決定と開始条件は [実装前設計計画](preimplementation-plan.md) を優先する。本書の内部マイルストーン・着手項目も、その条件を満たしてから実施する。

## 1. 目的と要求の状態

実務で利用できる品質のUVLM–ANCFシェル連成ソルバーを開発する。初回の実務適用には静的連成、非線形過渡応答、大変形平衡周りのフラッタ予測を含める。内部マイルストーンの完了と公開リリースを区別し、部分機能の早期公開を前提にしない。

以下の製品範囲はQ1〜Q27の回答に基づく。製品の精度目標はQ24 Aで確定した。受入証拠・開発順と、ケース別の比較条件・絶対許容差等は具体化中。旧計画の推奨・対象外と相違する場合は、本書に記録したユーザー決定を優先する。

STR-01は、任意の断面剛性行列を単一の材料・積層へ必ず変換できることを意味しない。等価モデルの許容入力と適用限界を定める必要がある。STR-02では、ANCFの勾配自由度を含む交差接続・拘束の定式化を検討する。部材を単に同じ節点位置に置くことを結合の定義にしない。

MAT-02は初期曲面・初期変位と別の材料入力。製造工程の解析、外部FEMの初期応力場の自動移送は初回必須に加えない。設計案・符号と接線の解析的参照は [指定初期ひずみ設計](initial-strain-design.md) を参照する。

## 3. 品質要求案

次の項目を受入条件として具体化する。ケースの比較条件や証拠が未確定のまま実務適用リリースを合格扱いにしない。

Q24 Aによる出力量別の製品精度目標と数値誤差予算は [受入精度・証拠条件](acceptance-criteria.md) に定める。実験比較の不確かさ評価やゼロ近傍の絶対許容差等は、ケースごとに具体化する。

| ID | 品質要求 | 定義する指標・証拠 |
|---|---|---|
| QUAL-01 | 出力量ごとに適用条件と必要精度を定める | 荷重、変形、振動特性、フラッタ速度・周波数等の対象指標 |

| QUAL-06 | フラッタと数値的発散・静的な不安定を区別する | 平衡・固有特性・成長率・刻み・後流・減衰・連成許容差の感度 |
| QUAL-07 | 主張する実務適用範囲に証拠が対応する | 要求→数値仕様→実装→検証ケース→結果の対応表と未確認範囲 |

公開情報だけで検証資源を構成する。独立コード比較だけを実験妥当性確認と扱わない。実験データの版・条件・不確かさ・利用条件を採用前に確認する。公開資源の候補は `verification-resources.md` に記録する。

## 4. 初回必須に含めない範囲

圧縮性補正、遷音速、剥離予測、胴体・ナセル等の厚い物体の空力干渉、材料損傷・塑性、材料強度による破損指標・余裕率の内蔵、ヒンジ・関節・自由飛行、LCO振幅・周波数の定量予測、確率的乱流の生成・統計評価の内蔵、専用GUI、GPU・クラスタ必須構成は、現時点の初回必須範囲に含めない。CAD読込みや自動格子生成は、外部格子読込みと区別して追加要求の有無を判断する。

## 8. 技術設計の初期案と採用判定

次は技術検討の方針案であり、実装済み・採用確定ではない。

| 項目 | 検討を開始する案 | 採用を判断するための試作・証拠 |
|---|---|---|
| ANCF要素 | 積層とロッキング対策を持つ既存ANCFシェル定式化を候補にする。Chrono 3423資料を比較の出発点にする | 剛体運動、薄肉化、歪んだ要素、初期曲面、積層応答、応力出力。平板の実績だけで曲面・実務形状への適合を認定しない |
| 部材接続 | 位置自由度の共有と、各シェル面の勾配・ディレクタの関係を分けて定義する | 折れ角・交差接続の剛体運動、荷重・モーメント伝達、静剛性・固有特性。法線方向が異なる面の勾配を無条件に同一化しない |
| フラッタ | 非線形静的平衡→その離散系の線形化→モード追跡・安定性→同一条件の過渡応答で照合 | 平衡残差、接線の方向微分、後流・格子・時間・物理／数値減衰への感度、臨界近傍の成長率。解析間のモデル不一致を調べる |
| 空力と写像 | 空力中立面、構造シェルの参照面、荷重作用点を別に識別する | 位置・速度写像、仮想仕事、合力・モーメント、オフセットと回転、複数揚力面の識別 |
| 基準実装 | 逐次・倍精度の経路を残し、密な空力系と疎な構造系を対象に線形代数を試す | 線形残差、条件悪化、固有値問題、ピークメモリ、主要工程時間。実務規模で必要な高速化を測定して判断 |

Chronoの技術資料は、節点位置と横方向勾配による運動学、積層材料、ANS/EASを記載している。候補調査の根拠として用い、UVLASの全要件への適合や原論文の調査完了を意味しない。

参照：https://www.projectchrono.org/assets/validations/FEA/ancfShellValidation.pdf

最初の構造試作は「等方平板での妥当な挙動」「積層での材料方向依存」「初期曲面」「直角部材接続」を別ケースにし、要素と接続の適合性を切り分ける。性能の目標規模が決まる前に、固有値解析や時間応答で巨大な密な連成状態行列を必須とする設計を固定しない。

T01のビルド基盤は2026-10-29に完了。Windows/MSVCとUbuntu 22.04/GCC（WSL）でDebug・Releaseをビルドし、各5件のCLI試験に合格した。実施範囲と環境は `verification/build-2026-10-29.md` に記録した。CIM経由のCPU・物理メモリ取得はアクセスできなかったため、性能測定機の仕様は未確認として扱う。
