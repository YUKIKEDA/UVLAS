# 指定初期ひずみ・予荷重状態の設計

版：0.1、2026-10-29。製品範囲はQ27 Bで確定。以下は材料・要素方式の比較へ渡す設計案。ST-03、ST-06、ST-10、TM-01の基準化は未完了。

## 1. 確定した範囲

MAT-02：無応力参照形状から外力・支持で作る予荷重平衡に加え、部材・層へ指定する初期ひずみに起因する内部応力を扱う。初期曲面・初期ひずみ・載荷後の変形をそれぞれ識別する。

製造工程そのものの解析、外部FEMの初期応力場の自動移送は初回必須に加えない。初期ひずみ入力を初期応力の独立入力と重複適用しない。集中質量・剛体結合へ材料初期ひずみを付けることはしない。

初期ひずみは時刻ゼロにだけ加える変位ではない。解析・再開を通じて保持する材料側の指定量で、支持が変化しても自動的に消去しない。初期変位・速度という運動初期条件とも分ける。

## 2. 入力の意味と符号

設計案では、参照材料基底で与える対称テンソル $E_{0}^m(X,\ell )$ を、無応力となるひずみの指定量として定義する。ℓは層ID。単位は無次元、正の軸方向成分は自然長を増やす向き。参照形状をそのまま保持すると、その成分は圧縮応力を生み得る。

従って、張った皮膜を参照形状で表すために常に正の初期ひずみを入れる、といった規約にはしない。入力の符号は解析ケースで実証する。

| 入力項目 | 必須の意味・検査 |
|---|---|
| 対象 | 部材・材料領域・層のID。重複指定の優先順位を暗黙に決めず拒否または明示合成 |
| 配置・基底 | 参照材料基底。空間固定基底で入力された量は初期参照基底へ変換し、その後は物質に付随 |
| 測度 | 本候補ではGreen–Lagrange型。工学ひずみ・対数ひずみ・曲率と名称だけで相互変換しない |
| 成分 | テンソル成分と工学せん断を区別。外部表現が工学せん断なら非対角成分は1/2に変換 |
| 分布 | 少なくとも部材／層ごとの定数。参照座標依存・厚さ方向分布は採用要素・求積・梁断面への写像と一緒に具体化 |
| 省略 | 初期ひずみゼロ。未定義値・取得不能値をゼロと読み替えない |
| 許容性 | 対称性・有限性・材料則の範囲。候補の自然計量 $I+2E_{0}$ は正定値を要求 |
| 永続性 | Modelの固定入力として識別・保存・ハッシュ対象。表示・再開で測度と層・軸を保持 |

要素が平面応力等で成分を縮約する場合、非対応成分を単に無視しない。縮約式に反映できる成分と拒否する成分をST-03で明示する。

## 3. 材料エネルギーと微分の候補

### IS-01：参照ひずみを差し引く弾性モデル

既存の大回転・小弾性ひずみの材料候補に対し、材料軸で

$$
\mathbf E_{\mathrm{el}}^m=\mathbf E^m(\mathbf q)-\mathbf E_0^m
$$

$$
W=\frac12\mathbf E_{\mathrm{el}}^m:\mathbb C^m:\mathbf E_{\mathrm{el}}^m
$$

$$
\mathbf S^m=\frac{\partial W}{\partial\mathbf E^m}=\mathbb C^m:\mathbf E_{\mathrm{el}}^m
$$

と置く候補を評価する。ここでSは第二Piola–Kirchhoff応力。正の $E_{0}$ を「参照状態で正の引張応力」とは定義しない。

この種のひずみと初期ひずみの区分は [COMSOLのTruss理論](https://doc.comsol.com/6.3/doc/com.comsol.help.sme/sme_ug_theory.06.160.html) の構成則・幾何学的非線形時の測度の説明と整合する。ただし同製品の全材料・断面モデルを採用するものではない。[MOOSEの材料構成の説明](https://mooseframework.inl.gov/releases/moose/2024-11-11/modules/solid_mechanics/plug_n_play.html) でもstress-free strainと追加応力は別の量である。

本候補は固定した参照配置でのモデル。有限な初期変形に対する参照配置の変更や、任意の初期応力場との等価性を保証しない。最終的なST-03比較では、自然配置の写像 $F_{0}$ を用いる $F_{\mathrm{el}}=F F_{0}^{-1}$ 型との適用範囲・体積測度・材料軸・実装負担を比較する。大きい初期ひずみまで単なる引き算を拡張しない。

### IS-02：内力と接線

Voigt成分・せん断係数を整合した表記で、 $B=\partial E^m/\partial q$ とすると

$$
\mathbf f_{\mathrm{int}}=\int\mathbf B^{\mathsf T}\mathbf s^m\,\mathrm dV_0
$$

$$
\mathbf K_{\mathrm{int}}=\int\left[\mathbf B^{\mathsf T}\mathbf C^m\mathbf B+\sum_\alpha s_\alpha^m\frac{\partial^2e_\alpha^m}{\partial\mathbf q^2}\right]\,\mathrm dV_0
$$

となる。初期ひずみは第1項のCを変えなくてもSと幾何剛性に影響する。`Cが同じだから固有特性への影響なし`とは扱わない。ANS/EASや内部変数の局所消去、厚さ応力の消去がある場合は、その依存を含む一貫接線へ置き換える。

参照材料場 $E_{0}$ はqの試行更新で変えない。空間座標で指定し直して材料回転のたびに $E_{0}$ を再生成する設計は、物質に付随する初期ひずみとは別のモデルになる。

## 4. シェル・梁への組込み

| 対象 | 閉じるべき式と条件 |
|---|---|
| 積層シェル | 層別基底・厚さ位置で $E_{0}$ を評価し、同じ材料則と求積でエネルギー・内力・接線・応力を計算。層間の差を一つの平均初期ひずみへ潰さない |
| 等価シェル | 許容する等価特性入力から初期膜力・曲げモーメントを表せる範囲を明示。任意のABD等から一意な層別初期ひずみが得られるとは扱わない |
| 梁 | 採用梁の軸・せん断・曲率等の自然ひずみを、材料初期ひずみの断面分布とエネルギーから対応付ける。無次元のひずみと1/mの曲率を同じ配列の意味にしない |
| 接続・支持 | 初期ひずみの異なる部材の拘束適合と平衡を解く。個別に無応力化してから結合し、残留応力を消してしまわない |

梁の具体的な入力成分・曲率規約とシェルの縮約はST-01/03/06の選定後に閉じる。Q27 Bの確定だけで、全要素に同じ6成分を代入できるとは判定しない。

## 5. 初期化、平衡、安定性、再開

1. 参照幾何・材料・ $E_{0}$ ・支持を読み、基底・単位・適格性を検査する。
2. 予荷重平衡から開始するモードでは、 $E_{0}$ を含む内力と外力・拘束・必要な空力を釣り合わせる。難しい場合の載荷継続は解法の経路として記録し、物理時刻の変化と混同しない。
3. 安定性解析には収束した同じ平衡と $E_{0}$ を使う。弾性接線・幾何剛性・拘束・追従荷重・空力を含める。
4. 過渡は、平衡からの擾乱か、意図して非平衡に置いた初期条件かを指定する。後者を勝手に静的緩和せず、運動方程式と拘束から整合加速度等を求める。
5. 平衡後の変形形状を無応力参照形状に置き換えない。参照の再設定は応力・密度・材料軸等の変換を要する別設計で、通常の初期化では実施しない。
6. 再開時はモデルの $E_{0}$ と解の状態を復元する。初期ひずみを再加算・消去せず、異なる $E_{0}$ のモデルを同じ再開対象として受理しない。

入力 $E_{0}$ が幾何学的に互換とは限らず、外力ゼロでも各部材が同時に無応力になるとは限らない。残留応力を持つ平衡も対象とし、未収束は通常結果にしない。

## 6. 解析的検証ケース IS-V01

これは一軸エネルギーの構成則・接線検証。棒／トラス要素を製品へ追加する要求ではなく、シェル・梁採用後の均一軸変形ケースの参照となる。

- 入力： $L_{0}$ =1 m、 $\mathbf A_{0}$ =1e−4 m²、Y=70e9 Pa、指定初期Greenひずみ $e_{0}$ =−0.001。横収縮・曲げを含まない一軸モデル。
- 軸方向自由端座標： $\lambda =1+u/L_{0}$ 、 $e=(\lambda ^2-1)/2$ 。
- エネルギー： $\Pi =1/2 Y A_{0} L_{0} (e-e_{0})^2$ 。
- 軸方向内力： $N=\partial \Pi /\partial u=Y A_{0} \lambda (e-e_{0})$ 。
- 軸方向接線： $K=\partial N/\partial u=(Y A_{0}/L_{0})[\lambda ^2+(e-e_{0})]$ 。

| 条件・評価量 | 解析的期待値 |
|---|---|
| 参照長保持u=0の第二PK応力 | +70 MPa。負の初期ひずみに対して引張 |
| 同じ条件の軸内力 | +7,000 N。左端・右端の拘束力は釣合いと作用方向から別に求める |
| 同じ条件の弾性エネルギー | 3.5 J |
| 同じ条件の軸方向接線 | 7,007,000 N/m |
| 右端の微小横変位に対する接線 | 7,000 N/m。 $e=((L_{0}+u)^2+y^2-L_{0}^2)/(2L_{0}^2)$ を同じΠへ代入して二階微分 |
| 軸方向を自由にして無外力平衡 | λ=√0.998、u=(√0.998−1) m、応力・軸内力・弾性エネルギー0 |

初期ひずみゼロの同じ参照長では軸接線7,000,000 N/m、横接線0となる。差分は初期応力の幾何剛性から生じる。この一軸モデルの横接線を、梁の曲げ剛性全体と混同しない。

許容差案：参照長保持で、応力1e−4 Pa、内力1e−7 N、エネルギー1e−10 J、接線1e−4 N/mの絶対誤差。自由平衡の位置は1e−11 m、残留軸内力は1e−4 Nを案とする。構成則の直接評価と非線形平衡の基準を分け、採用解法・誤差尺度への対応後に基準化する。接線はエネルギー・内力の方向差分でも刻み依存を確認する。
