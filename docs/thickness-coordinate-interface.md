# 厚さ座標の再パラメータ化と適合界面の契約案

版0.2、2026-10-29。ST-02/08、CV-02、OP-01/02/03、INV-03/04/11/16。共通物理基底を用いる、同じ物理界面の定数アフィン厚さ座標変換を対象とする。異なる位置の面、接着・接触、シェルと梁、折れた組立部材の結合をこれだけで定義しない。

## 1. 係数・状態・仮想変位の変換

同じ物理点について $z_e=\alpha z_f+\beta$ 、 $\alpha\ne0$ 。αは無次元、βはm。基底を $(1,z,z^2/2)$ とすると、

$$
\begin{bmatrix}\mathbf r_f\\\mathbf d_f\\\mathbf c_f\end{bmatrix}
=\left(\underbrace{\begin{bmatrix}1&\beta&\beta^2/2\\0&\alpha&\alpha\beta\\0&0&\alpha^2\end{bmatrix}}_{\mathbf H(\alpha,\beta)}
\otimes\mathbf I_3\right)
\begin{bmatrix}\mathbf r_e\\\mathbf d_e\\\mathbf c_e\end{bmatrix}.
$$

9節点の対応順序を含めた要素行列をT、界面3節点の対応を含むものをTΓとする。Tは定数・可逆。逆はαを1/α、βを−β/αとした変換。 $z_f=\gamma z_g+\delta$ をさらに適用する場合の合成順は、

$$
\mathbf H(\gamma,\delta)\mathbf H(\alpha,\beta)=\mathbf H(\alpha\gamma,\beta+\alpha\delta).
$$

辺・節点の順序変換も同じ合成順で記録する。単に行列の積順を入れ替えない。

同じTを、参照係数、現在の位置係数、変位、速度、加速度、仮想変位へ適用する。α・βを現在の変形に追従させない。状態依存とするなら速度・加速度・接線に追加項が生じるため別仕様。

## 2. 力・行列・仕事

$$
\delta\mathbf q_f=\mathbf T\delta\mathbf q_e,\qquad
\mathbf f_e=\mathbf T^{\mathsf T}\mathbf f_f,
\qquad
\mathbf K_e=\mathbf T^{\mathsf T}\mathbf K_f\mathbf T,\qquad
\mathbf M_e=\mathbf T^{\mathsf T}\mathbf M_f\mathbf T.
$$

従って仮想仕事、ポテンシャル、運動エネルギーは対応する。力を変位と同じTで変換しない。逆方向の力はTの逆転置。r/d/cの異なる単位に対応する係数を持つ変換であり、通常の回転行列と同一視しない。

## 3. 領域・層・向き

元の厚さ区間と層境界は、 $z_f=(z_e-\beta)/\alpha$ で同じ物理点へ写す。局所区間の下端・上端は昇順に保存し、α<0では層の局所順が反転する。層ID、材料・密度・初期ひずみ・材料軸の物理的な帰属を保持し、配列添字だけで再割当てしない。材料の測度や軸の別変換は別契約として必要。

本候補では体積要素の親座標を右手系とする。厚さ反転α<0だけではdetJの符号が反転するので、今回の比較では同時に $\xi_e=-\xi_f$ として向きを保つ。節点順・面ID・外向き有向面積・界面側も対応させる。abs(detJ)で反転を隠さない。一般の節点順置換は、対応する参照写像と向きを伴って審査する。

物理直交基底で定義した層別初期ひずみ等の場は、 $\mathbf E_{0,f}(z_f)=\mathbf E_{0,e}(\alpha z_f+\beta)$ のように同じ物理材料点へ対応させる。厚さ座標の符号だけで材料テンソル成分や繊維軸を反転しない。この規則の異方性・初期ひずみを伴う数値照合は残る。

β≠0なら局所区間は一般にz=0を中心としない。局所hを差し替えて対称区間と仮定しない。物理的な厚さ・形状を変える操作と、同じ領域のパラメータだけを変える操作を区別する。

## 4. 界面の適合条件と全体系

対応する辺座標と厚さ全域で参照幾何が一致し、同じ厚さ曲線を表すことが前提。物理的な隙間・異なる領域を検出した場合は、この完全適合接続として拒否する。

適合変位の条件は $\mathbf q_{f,\Gamma}-\mathbf T_\Gamma\mathbf q_{e,\Gamma}=0$ 。Q9の辺3節点×r/d/cで27条件、界面の両側54座標に対する制約行列 $[-\mathbf T_\Gamma,\mathbf I]$ はrank27。位置・許容仮想変位・速度・加速度も同じ対応を持つ。

共通全体未知量qから各要素への写像をPeとすれば、

$$
\mathbf q_e=\mathbf P_e\mathbf q,\qquad
\mathbf K=\sum_e\mathbf P_e^{\mathsf T}\mathbf K_e\mathbf P_e,\quad
\mathbf M=\sum_e\mathbf P_e^{\mathsf T}\mathbf M_e\mathbf P_e,\quad
\mathbf f=\sum_e\mathbf P_e^{\mathsf T}\mathbf f_e.
$$

Peは単なる添字抽出とは限らない。局所節点順・厚さ基底の変換を含む。これを省略した同名r/d/cの共有は一般には不適合。

界面の力は許容仮想変位に対して作用・反作用の仕事が相殺することを求める。座標が異なる両側の力配列を成分ごとに直接相殺させない。乗数法を採用する場合の反力と制約基底の対応は別途確定する。

外部支持・指定変位も同じ物理条件を保つ必要がある。 $\mathbf B_e\mathbf q_e=\mathbf g$ なら $\mathbf B_f=\mathbf B_e\mathbf T^{-1}$ として同じgを使う。β≠0でrだけを固定する操作は、別の物理位置の固定へ変わり得る。支持を「同じ名前の座標を固定する」とだけ定義しない。

## 5. 入出力・変更・診断

| 区分 | 論理契約 |
|---|---|
| 入力 | 界面ID、両要素・辺ID、節点と辺座標の対応、共通物理基底、α/βと単位、厚さ区間・層ID、参照世代 |
| 事前検査 | α非ゼロ・有限、全域幾何適格性、領域の一致、トレースの一致、層の物理帰属、向きと面対応 |
| 出力 | 係数・変位の写像、力の双対写像、局所全体写像または制約、ランク・適合性・誤差の診断 |
| 可変性 | 構築後は参照モデルと共に不変。入力参照値を接続へ合うよう無断修正しない |
| キャッシュ | 要素・界面・層・厚さ座標・順序の世代と対応。いずれかの変更で再検査 |
| 失敗 | 非可逆、向き不正、幾何不適合、層対応不適合、過剰／不足拘束、未対応の非一致格子を区別 |
| 部分出力 | 不適格界面は全体系へ混入させず、確定状態を変更しない。診断用候補と有効な接続を区別 |

型、所有権、疎パターン、並列化、一般の界面検査方式は未確定。定数α/βの範囲を超え、辺位置依存の変換を節点ごとに当てはめてよいとはしない。補間空間の閉性と接線方向微分の審査が必要。

## 6. 対応証拠と残る範囲

[接続・再パラメータ化試験](verification/q9-interface-reparameterization-experiment.md) で、2要素の荷重平衡・仕事・行列・層帰属と、誤った接続を検出する条件を照合する。厚さ座標の再表現の証拠であり、実際に厚さが変わる翼の接続、異なる法線の折れ・交差部材、非一致格子、積層異方性、非線形接続・動的応答を検証したものではない。

正常10ケースと負の対照6件の照合が成立した。これを根拠に、IFACE-D01：同一界面の係数共有は基底変換を含める、IFACE-D02：力・組立は双対／合同変換、IFACE-D03：右手系と物理層IDを保持、の3点を技術判断として採用する。特定C++型・拘束バックエンド・一般の接続方式の選定とは区別する。

本試験が直接照合したのは定数厚さ座標変換と界面適合・荷重平衡。上記の合成・支持・初期ひずみ場の規則は導出した契約であり、全てを本試験の確認済み項目へ数えない。製品実装の開始判定は未達。
