## 2. 今回の失敗から言えること

[M-Q3I1共有結果](verification/mq3i1-shared-results.md)は、局所可解性・仕事・膜の多項式再現だけでは共有曲げの品質が決まらないことを示した。歪み柱面では旧新の共有核・核上一次作用も数値的に一致し、内点モーメントの置換では検査対象の薄肉空間を変えられなかった。正則側は同一核とする基準を超える差があり、全条件での代数同一性とは言わない。

したがって、再び内点重みを選ぶのではなく、幾何・仕事の変分構造、または運動学と共有空間を変える必要がある。すべてのANCFの不可能性を結論するものではない。

### Bの式と、今回選ばない理由

具体的な比較用運動学は

$$
x_h=\sum_{i=1}^{25}N_i^{Q4}r_i
+z\sum_{j=1}^{16}N_j^{Q3}d_j
+\tfrac12z^2\sum_{k=1}^{9}N_k^{Q2}c_k.
$$

各場の節点でr/d/cは対応する物理zの0〜2階微分の値。参照配置も同じ式で作り、F・Greenひずみ・生のBからU、内力・幾何接線・質量を導く。各場の対応する辺節点を共有するので全厚さの変位トレースはC⁰となる。固定は3つの節点列の境界値へ個別に課す。

放物柱面でW=x³/6、U=−κx⁴/8、δd=(−x²/2,0,−κx³/2)、δc=0の三次曲げ場は、双線形x(s,t)なら上のr/d/c空間に入る。これは等次数Q3にない一つの適合性の改善であり、四次以上や歪み格子の収束を保証しない。参照配置と同じ補間による一定Fの再現・剛体・仕事は生の適合エネルギーから得るが、膜の厳しいゼロ条件を弱める構造は追加していない。

このBはHyldahlの48座標要素そのものではなく、ここで具体化した別案。共有辺の適合性・一般曲げへの密度が未解決であり、既に得た次数増加の失敗を踏まえ今回は試験対象から外す。Bを製品範囲から永久に除外する判断ではない。

## 4. Aを選ぶ根拠と、その限界

GSP-Q3は、一定応力仕事を追加の硬い行として押し込む代わりに、物理一定応力を局所空間に含めた変分式から保つ。一定／一次物理ひずみも幾何から再現する空間を明示した。R/R*、内力、幾何接線、厚さ微分、状態と回復の処理境界を定義したので、未定義の内点係数を実装者が補う必要がない。

変えるのは材料・変位ではなく、応力空間とエネルギーの局所消去である。全6成分の投影になるため、従来の「zzと膜厚さ差を点ごとに生のまま残す」規約は継承しない。また、還元ひずみの辺上連続を強制する代わりに、生の適合仮想変位と応力による弱い釣合いへ移す。これらは製品要求ではなく旧構成の内部条件の変更であり、保存・反力・精度の要求を緩和するものではない。規約の差と代替検査は定式化文書に明記した。

この選択は、Aの薄肉性能が既に分かったからではない。大域の運動学・共有・質量を維持しながら、失敗した拘束構造の上流を変更でき、仕事・再現・変分の根拠を先に閉じられるため、最初に検査する一組として選んだ。曲面・薄肉のlocking-free性を、ReggeやMITCの原論文から転用していない。
