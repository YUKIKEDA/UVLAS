# 判断を変える実験

## 実行前の最小記録

| 欄 | 書くこと |
|---|---|
| 判断 | 今回何を採用・棄却・識別するか。変えない製品要求 |
| 対立仮説 | H1とH2が同じ結果を予測する実験では原因を識別できない |
| 入力 | 形状・材料・支持・荷重・初期状態・離散化・精度。生成元と引数／版 |
| 比較 | 同じ物理問題、独立参照の構成法、有限参照の不確かさ |
| 観測 | 単位・基底・時刻・場所・左右トレース・ノルム・基準量 |
| 事前判定 | 何をどの精度で満たすか。ゼロ近傍、非漸近、未収束の扱い |
| 費用 | メモリ・時間・最大規模。失敗時に有効な途中出力と次行動 |
| 結果分岐 | 各結果で、どの仮説を除外でき、何を変え、何を保留するか |

全部を長い文書にする必要はない。重要なのは結果に合わせて入力・観測・判定を選び直さないこと。

## 未達の診断順を選ぶ

安価な検査から始めるが、既知の原因と無関係な順序を強制しない。

- **比較条件**：同じ方程式・正則化・境界・厚さ・荷重点・モーメント基準点か。同名モデルや同じパラメータ値で同一性を判断しない。
- **代数・算術**：原系残差、尺度、保持解と返却値、作用素評価の相殺、精度変更、別の消去／組立。縮約系だけで原KKTの成立を主張しない。
- **求積・幾何**：同じ場を別求積・別写像・別評価順で観測する。別の物理作用素にして誤差を消さない。
- **近似空間**：局所空間だけでなく共有・支持後の核、必須場包含、薄肉／非圧縮等の特異極限、偽の零モードを調べる。自由度数や局所patch testだけでは判定しない。
- **物理モデル**：離散誤差と参照差が十分切り分けられてから、モデル仮定・物性・実験適用性を再検討する。

## 独立性の段階

| 比較 | 分かること／分からないこと |
|---|---|
| 同じ関数で期待値も生成 | 配線・代数の自己整合。共通の式の誤りを検出しにくい |
| 同じ離散式の別組立／直接解 | 実装・消去・状態更新の相違。連続モデルの正しさまでは示さない |
| 解析解・独立積分・別離散化 | 対応するモデル／観測の精度。参照自体の誤差も評価する |
| 公開実験 | 特定条件の現実との比較。入力・測定・数値の不確かさと適用性が必要 |

製造解は強い検査だが、主コードのKqをそのまま荷重にして同じコードで解く検査を、独立したPDE荷重の検証と呼ばない。別コードでも同じ式・同じ欠落項を共有していれば独立性は限定される。

## 細分化と極限

誤差群を独立に変える。空間・時間・後流長・コア・求積・求解・縮約を一度に変更すると原因が分からない。複数群の交差項も確認する。最終2点の差の小ささだけを保証上界としない。

薄さを変えたときの増幅と、固定厚さの空間収束を区別する。局所応力、合力、仕事、点wise条件、有限区間平均、有限格子のエネルギー微分は別観測。極限で一致する量を有限格子で同一視しない。

厳密階数は定義した係数・幾何に対するもの。区間計算で求積Gram行列を囲っても、連続積分全体や任意格子の保証へ拡張しない。数値的な核一致と解析的な全空間証明を区別する。
