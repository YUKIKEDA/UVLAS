# 影響する数値境界をレビューする

## モデル・場・接続

- 局所の表現性と、共有・支持後の大域許容空間は同じではない。薄肉・歪み・曲面・非一致接続で必要な場が失われないか。
- 面内／厚さ座標と実法線距離、参照／現在測度、面法線・層順・材料軸をたどる。幾何の一致だけで許容変位・全トレースの一致を主張していないか。
- 運動写像と双対荷重は同じ物理点・Jacobianを使うか。合力だけでなく基準点付きmoment・仕事を確認する。偏心、回転frame、動く支持を落としていないか。
- 内力の材料接線と幾何接線、状態依存の質量／慣性・拘束曲率・追従荷重の非対称成分を残すか。非零平衡の剛体客観性と無応力の零modeは別検査。
- 外部格子の回転DOFを位置勾配へ直写ししていないか。材料定数不足、非標準剛性、offset、三角面の再構成を黙って近似しないか。

## 作用素・算術・求解

- 同名の正則化や同じコア値でも式・自己項・端点距離が違うことがある。実ソースと版を確認する。
- 元の全系で残差・拘束・反力を評価するか。Schur／縮約系の一致だけで省いたブロックを見逃さないか。
- 格納Aの誤差、LU／反復誤差、残差積和、保持解、float64投影、消費kernel、保存／復元を分離する。高精度で解いて低位を落とす出口がないか。
- 小残差は小前進誤差とは限らない。条件数の下側推定を上界と呼ばない。ゼロrhs・混在単位・相殺で分母やノルムが判断を歪めないか。
- 有理rank／区間証明が何を囲っているか。特定sectorの証明を全空間へ、求積行列の保証を連続積分へ拡張しないか。
- 微分照合は方向の物理尺度、FD刻みの範囲、独立な評価、JVPとVJPの双対を確認する。微小刻み一点の一致や同じADの二回呼出しを独立検査としない。

## 時間・連成・安定性

- 確定・試行・stageのどの値を残差、荷重、流体移流、構造速度に使うか。循環解の陰的依存を全接線へ含めるか。
- 初期化を輸送政策で分けるか。物質成長、固定年齢、指定後流、同じ離散定常列で必要な境界寄与・微分が異なる場合に同じ式を流用しないか。
- 誕生直後の点／面には過去の同一IDの履歴がない。仮の初期履歴と実履歴、zero-length stripと有限面、時間法の始動を区別するか。
- 受理後の荷重が実際の算法微分を読むか。後処理で別の初期化式／低次差分を呼び直さないか。
- 連続の定常解を、実際の有限h時間写像の固定点と取り違えていないか。位置・循環・後流・拘束を含む同じ平衡から線形化するか。
- 回転／チャートの変更で現在だけでなく必要な全履歴を運ぶか。途中刻み変更で曲がった後流や物理履歴を無検証に補間しないか。
- 離散固有値の連続成長率への変換は実際の時間写像に対応するか。周波数branch・alias・算法寄生根・wake-only・静的発散とflutterを分類するか。
- modeを周波数順だけで追わずMAC／部分空間を使うか。少数の収束Ritz対で未探索領域の安定を断定しないか。固有残差だけで臨界値の誤差を保証しないか。

## 確定・再開・所有権

- 候補の生成・失敗・取消で親確定状態は不変か。資格後の書換え、別親への確定、二重確定、同じ長さの別modelのcacheを拒否するか。
- 現在の荷重／微分の復元に、現在＋前状態だけで足りるか。多段差分のステンシル・実時刻・初期化区分を具体値で追う。
- 物理ID／TE所有／トポロジー、層・物性・初期ひずみ、入力補間、姿勢原点、探索queue・mode／枝・誤差判定も再開状態か。
- Workspaceの再利用で返値が変わらないか。Python viewが所有者より長生きする場合、GIL解放中、非連続配列、同時実行で規約を破らないか。
- 書込途中、破損、型／寸法／byte数・精度・版の不一致を拒否するか。bitwise再開の主張を異OS・異compilerまで拡張しないか。

## 規模・性能

実際の部材・拘束graph、疎分解fill、全後流の相互作用、状態×Arnoldi幅、精度昇格、一時配列、入力準備、I/O、全探索・再試行を測る。合成100kのLUだけで実PG100kや一晩の全探索を合格にしない。未実装の加速法を前提に性能成立を宣言しない。
