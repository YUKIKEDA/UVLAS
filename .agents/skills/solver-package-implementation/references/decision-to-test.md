# 決定から試験まで

実装の前に、パッケージの決定ごとに一行を埋める。空欄が残る決定は、まだ実装できない。

| 欄 | 書くこと |
|---|---|
| 決定ID | 採用仕様の条番号 |
| 式・規約 | 実装する式、符号、単位、時刻、成分順 |
| 入力 → 出力 | 型、配列の形、所有者、寿命 |
| 事前条件 | 満たされないとき、どの失敗を返すか |
| 必要微分 | 何を何で微分したものか。物理微分か算法微分か |
| 精度 | 保持する表現、消費側が受け取る表現、投影の有無 |
| 失敗時の保証 | 親状態、cache、世代が変わらないこと |
| 独立参照 | 解析解、多倍長、別定式化、凍結した試作結果のどれか。その所在とハッシュ |
| 許容差 | 数値と出典 |
| 負対照 | 入力と、期待する失敗の種類 |
| 全体系の確認 | 接続・支持の後に確かめる性質 |
| 対応ケース | 受入計画のケースID |

## 欠けやすいもの

- ゼロ次元、ゼロ右辺、無荷重のときの尺度。相対誤差の分母を結果から作らない。
- 同じ寸法で、幾何・拘束・精度・親世代だけが違う入力。cacheを誤って再利用しないか。
- 右辺だけが変わったときの、行列世代の照合。
- 成功した高精度の内部解が、返却の丸めで元残差を満たさなくなる場合。
- 転置作用。順方向と随伴の内積が一致するか。
- 資源の上限に達したとき。部分結果を正常として返さないか。
- 途中で中断されたとき。保存済みの確定状態が壊れないか。

## 一つのPRの大きさ

決定が互いに独立なら分ける。型と失敗の契約、正常経路、負対照、全体系の確認が一つのPRで閉じる単位にする。相互に依存する決定（時間法と荷重微分、後流更新と線形化など）は、片方だけを先に確定する形に切らない。
