# 構造1.4：接続・支持・質量／偏心慣性の審査仕様

2026-11-05。主シェル・材料・梁の採用を維持し、接続を仮想仕事の検査だけで閉じない。以下の有限な組で採否を判断する。

## 接続の区別

1. 同じ物理界面の全位置連続：両側のNを共通物理点へ写す。折れ／T接合では実際の有限厚さ接合面を定義し、異なる法線のdを直接等置しない。厚さ段差では共通領域だけを接合し、残りは外面とする。
2. 明示した剛体取付：宣言した範囲の全位置トレースをp+Rηへ結ぶ。剛体化する物理的な取付金具・断面を意味する。変形可能な分布結合と同じものにしない。[公式の区別](https://docs.software.vt.edu/abaqusv2025/English/SIMACAECSTRefMap/simacst-c-coupling.htm)を比較資料とするが、式・検証は独自に行う。
3. 全姿勢weldの閉路：参照相対SE(3)変換の整合を確認した上でspanning forestを選ぶ。一般の非線形拘束の従属性を、1状態のJacobian rankだけで決めない。

## 検証と採否条件

| 組 | 固定する内容と条件 |
|---|---|
| 全トレース | 参照面の一致、完成基底と必要な場合の有理数rank、1e−9/1e−10/1e−11のrank一致、独立点で全厚さ位置差1e−9以内。少数平均だけの結合を採用しない |
| 拘束・支持 | C/J/H、C_t/C_qt/C_ttと速度・加速度の鎖則を同じ運動学から確認。方向微分と転置仕事1e−8、代数保存1e−10。位置・フレームの単位を固定 |
| 反力・従属 | 原KKTと独立消去で同じ変位・反力・仕事。閉路・重複・不整合を負対照で検出。従属乗数の配分を一意な物理量として返さない |
| 付加慣性 | 粒子質量と有限剛体を分ける。シェル上の点／接線フレームと梁フレームを用い、偏心重心・重心慣性・M(q)・慣性力を物理速度と照合。誤差1e−9、M微分1e−7。重力の転置力と接線も確認 |
| 質量台帳 | MassId、所有範囲、追加／置換を明示。重複ID・出自の重複・未定義の置換を拒否し、ホストと付加物を二重計上しない |
| 梁―シェル実平衡 | 円形梁＋有限厚さシェルの剛体取付を用い、軸力の独立な直列解析解と比較。全3D StVKシェルと梁の軸則の違いを式で扱う。混合荷重・摂動からのNewtonを原KKT／独立消去で比較。原残差1e−8、拘束1e−9、物理位置差1e−8 |
| 組合せ固有特性 | 同じ拘束・平衡・M/Kを使用。原KKT零空間と独立消去の固有値／作用を比較（1e−8）。軸の対象3モードを独立な連続直列棒へ比較し、最細0.4%、モード対応を確認 |
| シェル接合 | T／折れ・交差・厚さ段差の実接合面を構成し、独立全面力の3D affine物理問題で全位置・反力／仕事・平衡を確認（1e−8） |
| 接合の非アフィン品質 | 折れた2部材、ν=0・一様幅の問題を、独立2D二次三角形連続体と比較。h=.1/.05、採用パッチ内部n1/2/4。最細平均先端変位1%、細分化と独立参照の収束を確認。これは接合方式の限定検査で、任意の接合網の実務受入ではない |

実務の拘束反り・局所溶接応力・接触をこの基準へ黙って含めない。必要精度を保つ状態・参照・拘束世代を引き継ぎ、接合による基底rankや質量の不適格を擬似逆・人工質量・無断の拘束削除で隠さない。製品の疎解法・時間積分は4／3、全実務ケースは5で審査する。
