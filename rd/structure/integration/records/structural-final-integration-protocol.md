# 構造1.5：荷重・減衰・回復・構造統合の終了条件

2026-11-05。1.1主シェル・1.2材料・1.3梁・1.4接続の固定した式を入力とする、次の有限な審査。**この文書は1.5の採用結果ではない。** 構造の全要素探索を再開しない。時間積分方式は3、具体型・疎求解・性能は4、用途別の実材料／実験受入は5に残すが、それらが要求する処理を未定義にしない。

## 決める式と主要処理

| 項目 | 固定する候補と判断対象 |
|---|---|
| 重力・時間依存dead荷重 | 同じ体積／線／点質量、同じ時刻・物質座標の転置写像。時間関数の単位・連続性・値／必要微分・不連続時刻を明示。付加質量の重力をホストに二重計上しない |
| 面圧・追従力／偶力 | 基準面積当たりの力、現面積当たりの力、現面の圧力を入力種別として区別。向き・両側・圧力差・厚さ面・作用点を明示。現配置の面積ベクトルとその変分から荷重と接線を得る。接線の非対称部分を強制的に対称化しない |
| 弾性・減衰支持 | 採用済みの物理点／相対フレームから、ポテンシャルと散逸関数を一組で定義。並進・回転・連成の単位、支持基準の運動と供給仕事を明示。有限剛性支持を完全拘束へ無断置換しない |
| 部材の物理減衰 | 主候補は材料ひずみ速度／梁の一般化ひずみ速度に対する正半定値の粘性則。剛体運動の内部散逸を零に保ち、速度接線と状態接線を同じ散逸から得る。減衰係数の実材料同定は5。負の幾何剛性をそのままRayleigh粘性へ使わない |
| 点／層応力 | 同じ参照・状態・材料軸からGreen／第二PK、第一PK、Cauchyを区別。体積Jacobianとpush-forward、界面の片側、初期ひずみ、粘性応力の区分を持つ。異材界面を平均して一意値にしない |
| 断面力・合力／偶力 | 指定した物理切断面・法線・基準点で応力を積分。梁の断面則の共役量と物理wrenchを変換する。接合・支持の反力は元の転置写像から回復。点wise／離散弱平衡の違いと切断面収支の誤差を返す |
| 構造の統合呼出し | prepare → trial → U/f/K/M・慣性・荷重／減衰・拘束 → recover → accept/reject。参照／材料／接続／状態／荷重の版と要求微分を固定し、失敗で確定状態を変更しない。再開データに物理状態と再生成可能な準備情報の境界を定める |

支持・減衰の初期候補は、剛体取付と同じ相対運動学のエネルギー／散逸に基づく。係数を結果に合わせて調整した検証はしない。初期応力による実際の負剛性と、正半定値であるべき物理散逸を分ける。

## 実施する検証と採否基準

| 群 | 対照と終了条件 |
|---|---|
| 荷重の仕事・全接線 | 非平坦・大回転・有限厚さの採用シェルと梁／点剛体で、力／偶力・転置仕事・合力／基準点モーメント、方向微分を独立照合。1e−8。面積測度・法線・作用点・荷重接線の欠落を負対照で検出 |
| 保存／非保存の区別 | 閉じた圧力面の体積ポテンシャルと仕事、開いた追従端荷重の非対称接線を別検査。圧力だから常に保存的と仮定しない |
| 支持の独立解 | 梁・シェルの有限弾性／粘性支持、動く基準を、同じ物理剛性／散逸を持つ独立な小系と比較。平衡・反力／仕事1e−8、速度接線・状態接線1e−8、正半定値の散逸とエネルギー収支 |
| 減衰の客観性 | 有限剛体運動で内部粘性零、ひずみ速度の物理仕事と一般化力のパワー一致。負の粘性・不適格な係数を拒否。初期応力と幾何剛性の負固有値を保持したまま散逸非負を確認 |
| 応力と切断面 | 独立な3Dテンソル変換、積層の両側、梁の軸／曲げ／せん断／ねじり、偏心と基準点移動を照合。物理積分・断面仕事1e−8。有限要素解からの切断面収支は細分化と独立参照へ収束させ、最細1%を維持 |
| 一組の実平衡・線形化 | 採用梁―シェルと偏心質量・弾性支持に、重力・dead・追従荷重を組み合わせる。元の平衡／拘束残差1e−8／1e−9、全残差接線の独立微分1e−8。支持・粘性を含む平衡周り演算子が同じ物理状態から得られる |
| 状態と回復の不変性 | 不適格な試行・回復要求・版不一致で確定状態がbitwise不変。同じ物理状態を保存／復元してU/f/K/M・荷重／減衰・反力／回復が規定精度内で一致。製品のファイル形式採用は4で行う |
| ST採用表の監査 | ST-01〜10/CV-03ごとに採用式・適用／拒否・必要微分・主要I/F・単位・不変条件・独立参照・数値条件・3〜6への未完了を対応。文書が存在するだけで閉じない |

この組を満たした時点で構造モデル採用「1」を閉じ、2 UVLMへ移る。過渡応答・フラッタ・実務構造全体の最終受入結果を、実装前の構造採用終了と混同しない。
