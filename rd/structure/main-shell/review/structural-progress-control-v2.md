# 構造審査の進め方v2：主シェルの根本問題を主作業に戻す

2026-11-03。[先行作業を推奨した旧提案](structural-progress-control.md)は、ユーザーの「後回しにしただけ」という指摘を受け撤回する。主シェルが採用できていない問題を解決することを主作業として続ける。優先順の回答待ちではない。品質基準・ANCF要件・初回の実務適用範囲は維持する。

材料1.2の確定済み契約と証拠は保持する。ただし、それを主シェルの採否の代替や、1全体が前進したことによる根本問題の解消として扱わない。UVLMを先行することで主シェルの未解決を隠さない。

[今回の原因診断](main-shell-root-cause.md)で、150座標案の歪み2×2の零次核が、既知の二次／三次曲げ2方向と一致することを確認した。その共有近似空間の不足を変えられない変更は次の要素候補へ数えない。

次は公開定式化の膜・せん断制約と幾何・変分・求積を一組として確認し、歪み辺をまたぐ局所曲率変化、偽の零モード、一定応力仕事、エネルギーと接線の整合を先に審査する。次数・重み・格子をその場で増やして特定の参照だけを通す試験は追加しない。

1.1の終了条件は適格な主シェルの採用根拠が揃うこと。今回閉じたのは既存案の失敗原因の切り分けであり、根本対策の実装・精度確認はまだ残る。未解決を完了に読み替えない。
