# 主シェルの終了見通しと次の判断点

2026-11-04。**主シェル1.1の完了時期も、プロジェクト全体の完成時期も、現在は見積もれない。成立性を確認した主シェルがなく、工数だけが残っている状態ではない。** [ロードマップ](../../../planning/preimplementation-history.md)の1.1を通過したことにも、計算本体の実装を開始できる状態にもしていない。

これまでの候補の不採用は適用範囲の限定であり、ANCF一般の不可能性の証明ではない。一方、試験を増やした事実だけから「あと少しで採用できる」とは言えない。工程数や合格件数の百分率を完成率として表示しない。

## 今回閉じたことと残ったこと

[RW-1／RW-2の結果](../reference-work/records/reference-work-results.md)で、体積発散・鉛直面・上下面の仕事を同時に保存する射影と混合空間を定義し、RW-2は全9局所の49場で事前の仕事条件を満たした。参照空間の包含と、物理空間のPiola仕事の関係も式で対応した。

しかし、一般四次参照の幾何補完を点値の差として作る現在の実装は、最薄条件で参照勾配と客観性を満たさず、別求積の力も再現基準を外れた。主シェル採用の見通しへ数えない。曲面での仕事の保存だけから薄肉精度を保証しない。

## 次の有限な実施単位

| 判断点 | 具体的な作業 | 通過条件・未達時の扱い |
|---|---|---|
| A 幾何補完の安定評価 | 次の修正は一案に限定し、幾何場を直交多項式係数で表す。既知のRT成分と補完成分を係数空間で分け、近い点値同士の差を基底評価に使わない。発散と法線も同じ係数から評価する | 9局所の仕事・rank・一定F/P・客観性・全微分・独立観測を元の閾値で通す。未達なら、このRW系列を追加の係数調整で継続せず、成立性の再審査へ戻す |
| B 共有・薄肉・平衡 | Aを通った場合だけ、大域8配置、有限h4条件、物理外力の非線形平衡1問題 | 曲面の対照改善、最細1%、薄肉増幅2倍、H¹・条件数・残差・資源・独立観測。未達なら採用しない |
| C 主シェル採用範囲 | Bを通った場合だけ、一般曲面・材料／層結合・非一様荷重・費用・回復・必要I/Fを統合 | ST-01/04の採用範囲と不足を明示。Bの最良近似や一定Fパッチを実務解析の受入へ読み替えない |

Aの数値実装が成功することも、Bの薄肉条件を通ることも未確認である。したがって、A〜Cを日数へ換算する根拠はない。次に終了見通しを更新する点は**Aの合否が出た時点**。A通過は実装課題の一部解消、B通過は主シェル成立性の限定的な裏付け、C通過が1.1の採用範囲確定であり、区別する。

1.1の後にも、材料・梁接続・質量／支持等の構造統合、UVLM、連成・時間・安定性、数値基盤・主要I/F、実務ケース、実装開始審査の残りがある。さらにC++23計算本体の実装・統合検証・実務受入・配布が必要である。これらを含む完成日を現時点で約束しない。主シェルを他工程へ後回しにしたり、実務品質を下げたりして終了扱いにする方針は取らない。
