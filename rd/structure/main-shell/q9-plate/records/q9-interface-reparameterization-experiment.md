# Q9二要素：厚さ座標変換・界面適合・仮想仕事

版0.2、2026-10-29。第1〜8節は実行前仕様、第9節以降は結果。[厚さ座標界面契約案](../../../conventions/thickness-coordinate-interface.md) の限定試験。製品の拘束・組立実装ではない。

## 1. 問題と独立参照

領域 $X,Y\in[-0.5,0.5]\,\mathrm m$ 、 $Z\in[-h/2,h/2]$ をX=0で2個のQ9×厚さ二次要素へ分割する。共通面内節点15、全体135座標。h=0.1・0.01m。正しい接続は各局所81座標を135座標へ写す。界面の27適合条件だけを与え、剛体6モードを除いた弾性rankは129を期待する。

下層はZ∈[−h/2,−h/6]、Young率1Pa・密度1kg/m³。上層はZ∈[−h/6,h/2]、Young率2Pa・密度3kg/m³。両層ν=0.3、材料基底は共通物理座標。等方二層の材料・密度差は層の取り違えを検出するためで、一般の積層異方性の検証ではない。

三次元線形純曲げ変位を解析参照とし、κ=0.001m⁻¹。各層の $\sigma_{XX}=-E_\ell\kappa Z$ 、他成分0。発散0で、層間法線Zに対する面力も0。外周境界へ層ごとの $\boldsymbol\sigma\mathbf n$ を与え、X=0の内部面には荷重を与えない。解析変位を指定したりKqから外力を生成したりしない。

参照エネルギーは $\kappa^2\sum_\ell E_\ell\int Z^2dZ/2$ 、質量は $\sum_\ell\rho_\ell\Delta Z_\ell$ 。重心Zは $\sum_\ell\rho_\ell\int Z\,dZ$ を質量で割る。面積は1m²。参照場から質量ゲージの6剛体成分だけを差し引いて比較する。

## 2. 再表現の系列

左要素は共通のz=Z座標。右要素だけ $Z=\alpha z_f+\beta$ へ変える。βの係数はhに対する比率。

| ID | α | β | 面内対応 |
|---|---:|---:|---|
| IDENTITY | 1 | 0 | 同じ |
| SCALE | 2 | 0 | 同じ |
| SHIFT | 1 | h/4 | 同じ |
| REVERSE | −1 | 0 | ξも反転 |
| COMBINED | −1.5 | h/5 | ξも反転 |

局所厚さ区間は変換後の両端を昇順にする。層ID付き区間も変換して昇順へ並べ、材料の物理帰属を保つ。幾何と状態にはT、外力・剛性・質量の共通未知量への集約には転置／合同変換を用いる。

## 3. 独立組立と幾何検査

各局所基底をその局所zで直接評価し、独立にJ、物理勾配、層別B・構成行列・ρ、体積・面積測度を求める。基準行列を合同変換して比較側行列を生成しない。

体積は層別7×7×7、面荷重は層別9×9。この問題では幾何はアフィン、材料は層内定数、荷重は低次多項式なので、次数から必要精度を満たす。格納幾何と厚さ範囲の正確な有理数多項式についてBernstein係数を計算し、全域detJ正値を要求する。区間の中心が0とは仮定しない。

各辺ηと共通厚さZの3×3格子点で、参照トレースと変位のトレース演算子を照合する。各軸二次のトレースなので9点でその多項式係数の対応を確認できる。幾何差は1mに対し $10^{-12}$ 以下。演算子差は、r・d・cの列をそれぞれ $(1\,\mathrm m,1\,\mathrm m/h,2\,\mathrm m/h^2)$ で尺度化して最大成分 $10^{-12}\,\mathrm m$ 以下。

## 4. 行列・質量・仕事

各hのIDENTITYを基準に、右局所行列を引戻したK/M、全体K/Mの共通対角尺度化最大成分差・相対Frobenius差を $10^{-9}$ 以下とする。局所・全体荷重の尺度化相対差も $10^{-9}$ 以下。質量・重心は解析参照に対し相対 $10^{-10}$ 以下（重心差の基準長はh）。

質量の観測行列rank135、弾性rank129は相対SVD閾値 $10^{-11},10^{-10},10^{-9}$ で不変。界面条件のrank27も確認する。界面の両側面力を別途組み立てて作用・反作用の集約が相対 $10^{-10}$ 以下となることを確認する。この面力は平衡の外力へ加えない。

仮想仕事は固定seedの非ゼロ仮想変位で、局所変換前後の仕事の相対差 $10^{-10}$ 以下。r/d/cの尺度を上と揃え、ゼロ近傍は力・変位の積の尺度で評価する。

## 5. 荷重からの求解

質量ゲージ $\mathbf R^{\mathsf T}\mathbf M\mathbf q=0$ の6剛体条件のみを除き、残る129自由度で平衡を求める。縮約系は倍精度LUとDecimal80桁の残差・解保持、補正最大5回。縮約相対残差 $10^{-10}$ 以下、観測用float64投影の全体系尺度化残差 $10^{-8}$ 以下。

層内9点体積求積位置での変位・工学ひずみは、独立な解析場との最大成分相対差 $10^{-6}$ 以下。エネルギー相対差 $10^{-6}$ 以下。IDENTITYと他の再表現との物理変位場・エネルギー差も $10^{-6}$ 以下。合格しても非線形・振動応答を解いたことにはしない。

## 6. 不適格入力・誤実装の検出

以下は期待する拒否・不一致を確認する負の対照であり、正常入力の合格件数へ混ぜない。h=0.01で各1件。

- α=0は非可逆として拒否する。
- α=−1でξを反転しない場合は負のdetJを検出し、abs(detJ)で進めない。
- COMBINEDで節点順だけを合わせ、r/d/cを生で共有すると、尺度化トレース演算子差が $10^{-4}$ を超えて検出されること。
- 変位と同じTを力へ適用した場合、非ゼロ仮想仕事の相対不一致 $10^{-4}$ 超を検出すること。
- REVERSEで昇順局所区間へ元の配列順の材料・ρを割り当てると、基準との尺度化KまたはM差 $10^{-3}$ 超を検出すること。
- 右要素の参照位置を全体的に0.01hだけZへ移すと、界面幾何差が $10^{-8}\,\mathrm m$ 超となり完全適合接続として拒否すること。

入力を合うよう修正して正常扱いにしない。正常ケースでは同じ物理領域と層を表していることが前提。

## 7. 打切り・保存

正常10ケースと負の対照6件。1ケース120秒・プロセスメモリ4GB・非有限・分解失敗で打切り。不合格は保存し、閾値を変えず原因を切り分ける。結果・ソース識別・実行環境は別記録へ残す。

## 8. 結果の使い方

定数α/β、共通物理基底、同じ界面・同じ物理厚さを持つ適合二要素の証拠。可変厚さ翼の一般的な幾何生成、異なる法線の折れ・交差部材、非一致格子、接触、材料異方性、初期ひずみ、非線形・動解析の接続は残る。主要I/Fへの反映後も製品実装の開始判定を別に行う。

## 9. 実施結果

[全結果・層対応・反復履歴・ソース識別](q9-interface-reparameterization-result.json) を保存した。正常10ケースは全て事前基準を満たし、負の対照6件も全て期待した不適格・不一致を検出した。終了コード0。

### 9.1 正常ケース

全体質量rank135、弾性rank129は全ケース・全3閾値で成立。界面制約rank27、剛体ゲージrank6も成立した。右要素の表現を変えても、同じ物理界面・層と許容変位空間を表す全体系となった。

| 指標 | 全10ケースの最大値 |
|---|---:|
| 参照界面の位置差 [m] | 6.94×10⁻¹⁸ |
| 単位別尺度を与えたトレース演算子差 [m] | 8.68×10⁻¹⁷ |
| 引戻した局所Kの尺度化最大成分差 | 1.41×10⁻¹⁵ |
| 引戻した局所Mの尺度化最大成分差 | 2.79×10⁻¹⁵ |
| 全体Kの尺度化最大成分差 | 1.35×10⁻¹⁵ |
| 全体Mの尺度化最大成分差 | 2.79×10⁻¹⁵ |
| 全体外力の尺度化相対差 | 6.87×10⁻¹⁶ |
| 仮想仕事の正規化差 | 1.87×10⁻¹⁷ |
| 界面力の集約後の正規化差 | 8.63×10⁻¹⁶ |

質量の解析値との相対差は $4.45\times10^{-16}$ 以下、重心差/hは $1.63\times10^{-15}$ 以下。下層・上層でEとρが異なるので、均質材で見えなくなる層帰属の取り違えも検出できる入力となっている。

### 9.2 境界荷重からの平衡

純曲げの境界面力を外周だけへ与え、内部面への人工的な荷重を追加せずに平衡を解いた。界面の両側面力は作用・反作用の照合だけに使用した。

解析参照に対する相対差は、変位 $4.75\times10^{-12}$ 以下、工学ひずみ $6.95\times10^{-12}$ 以下、エネルギー $3.35\times10^{-12}$ 以下。IDENTITYに対する再表現後の変位場差は $3.04\times10^{-12}$ 以下、エネルギー差は $8.69\times10^{-13}$ 以下。

高精度保持した縮約解の相対残差は $1.42\times10^{-13}$ 以下。観測用float64投影の全体系残差も $5.28\times10^{-13}$ 以下で事前基準を満たした。非線形・動解析の接続を確認したという意味ではない。

### 9.3 負の対照

| 不適切な入力／操作 | 観測した検出根拠 |
|---|---|
| α=0 | 非可逆として変換構築を拒否 |
| 厚さだけ反転 | detJ上界も負となり幾何審査を拒否 |
| r/d/cを生で共有 | 幾何差は約8.7×10⁻¹⁹mでも、尺度化トレース演算子差は約0.967m |
| 力へ変位と同じTを適用 | 仮想仕事の正規化不一致は約0.00814 |
| 反転後の局所順に元の材料配列を割当て | 尺度化最大成分差はK約0.484、M約0.947 |
| 物理的な界面の隙間 | 位置差0.0001mで幾何不適合を検出 |

幾何一致と許容変位の一致を別に審査する必要がある。また、座標の再表現と材料・領域の実変更を同一扱いにしない。ここでの拒否・検出は限定試験の判定で、製品入力検査APIの実装済みという意味ではない。

## 10. 設計への反映

係数をそのまま共有する方式は、厚さ座標が異なる界面へ一般化しない。局所全体写像、力の双対写像、幾何と変位の独立検査、層IDと右手系の保持を [厚さ座標界面契約案](../../../conventions/thickness-coordinate-interface.md) に具体化した。

次は、材料軸・層・指定初期ひずみを含む構成則と内力・接線の規約を審査する。可変厚さの実形状、一般曲面の収束、折れ・交差部材、非一致格子の接続は引き続き採用条件として残す。
