# ANCFシェル候補の一次比較

調査日：2026-10-29。ST-01〜04の資料審査。要素・ライブラリの採用決定ではない。MAT-02の指定初期ひずみも比較要件に含める。

## 比較の出発点

| 候補 | 一次資料で確認した構成 | UVLASで審査する利点・制約 |
|---|---|---|
| 3423型 | 4節点、位置＋横方向勾配、双線形、積層、ANS/EASを用いる公開資料がある | 具体式・検証例を追える出発点。初期曲面・歪んだ四角形・薄肉・交差接続・初期ひずみを含む接線への適合は未確認 |
| 3443型 | 4節点、位置＋3勾配を持つAPI。公式8.0要素一覧は現定式化のロッキングを課題として明記 | 完全な勾配表現を比較対象にできる。自由度・接続・ロッキング対策の負担を含めて比較。多数のDOFだけを精度の根拠にしない |
| 3833型 | 公式一覧・APIに加え、固定版ソースで8節点・xyzDD・72座標を確認 | 高次候補。冒頭の「4節点・3勾配」という説明と実体が不一致だが、今回の版では構成を実コードで照合。形状関数・薄肉挙動等の審査は別に必要 |

一次資料：

- [Chrono ANCFシェル技術報告（2016）](https://www.projectchrono.org/assets/validations/FEA/ancfShellValidation.pdf)：3423型の補間・材料・積分に関する出発点。
- [Chrono 8.0 要素一覧](https://api.projectchrono.org/8.0.0/manual_fea_elements.html)：候補構成とロッキングに関する記載。
- [3443型 9.0 API](https://api.projectchrono.org/9.0.0/classchrono_1_1fea_1_1_ch_element_shell_a_n_c_f__3443.html)：節点型・SetNodes・積層入力。
- [3833型 9.0 API](https://api.projectchrono.org/9.0.0/classchrono_1_1fea_1_1_ch_element_shell_a_n_c_f__3833.html)：説明文と署名の不整合を確認。

資料の版を混ぜて同一実装と見なさない。初期調査では9.0.0タグを想定したrawヘッダー取得に失敗した。その後、公式mainをrevision `d26ed26d8344ae9aee4c1d26bf6d481076750b1a` に固定して取得し、3423の補間・ANS/EAS・質量・接線、3833の節点構成を静的に照合した。[固定版ソース審査](../ancf-3423/records/chrono-shell-source-audit.md) に取得物・ハッシュ・懸案を記録する。今回のmainの確認を旧版全体の確認へ読み替えない。

## 比較を閉じるための条件

1. 各候補の形状関数と必要微分、参照ヤコビアン、質量、内力・接線、内部変数・縮約を式番号付きで抽出する。
2. 初期曲面・歪み・薄肉化・積層・指定初期ひずみについて、必要な補正と原式の適用限界を整理する。
3. シェル間・梁との接続で共有する位置と、共有しない勾配・回転を定義する。
4. REF-V03、IS-V01〜03、膜／曲げ／薄肉・曲面の独立ケースへ対応付ける。
5. 求積点・内部反復・凝縮後の自由度・大域疎構造から、代表規模の容量と組立コストを比較する。
6. 参照のみ、自作、既存実装利用を区別し、利用する場合は版・依存・ライセンスと変更責任を確認する。

技術判断：3423型を最初に式を追う候補とし、3443／3833型を比較対象に残す。これは資料調査の優先順位であり、3423採用や他候補の棄却ではない。初期曲面・初期ひずみ・接続の未確認事項を、実装後の修正へ先送りしない。

3423について [数式仕様案](../ancf-3423/ancf-3423-formulation.md) と [補間・曲面・質量の解析ケース](../ancf-3423/records/3423-kinematic-mass-cases.md) を作成した。24座標、参照写像、ANSの座標対応、EAS5モードと縮約接線を整理。参照実装のANS対応・局所終了・回復経路には懸案があり、単純な移植で要件適合と判定しない。曲面・層別EAS・接続の審査は未完了。

続く [層別EAS整合審査](../ancf-3423/eas-layer-consistency.md) で、層別αへ要素全体ζを使う案と、SH-04の曲面への単純適用をそのままの候補から除外した。層分割のエネルギー反例と、曲面の一定物理ひずみ再現性の反例による技術判断。層内座標・参照応力との直交・線形局所消去は具体化したが、3423の基礎補間に適合する曲面ANS・薄肉・接続は引き続き比較が必要。

現在の比較順序は [曲面対応シェル比較](curved-shell-comparison.md) に更新した。3833型を主比較候補へ移し、固定版CPPから厚さ二次補間と72座標の意味を照合。48座標Q8型とは区別する。最終採用には曲面・薄肉・積層初期ひずみ・接続・固有特性の証拠が必要。
