# 参照値の共有による同じ荷重経路の再開

2026-11-04。拘束後QR経路でも歪みn4厚い側の物理条件は全通過したが318.579秒で資源未達。保持する。

同じr/d/c位置値を荷重群・粗い残差荷重・次数照合で再評価していた部分を共有する。参照形状関数の版（参照／補完の係数配列ハッシュ）、セル参照、評価点、列数をキーに512MiBの読取専用LRUキャッシュを用いる。状態・荷重・時刻に依存する値を共有しない。粗い参照基底も同じ座標の重複点を一度評価し、64MiB枠で保持する。元評価との別点差≤1e−12を要求する。

拘束後QR・Z・尺度・参照基底はソースと入力のハッシュ付きで保存し、破損・版違いを拒否する。再利用時も**元の準備時間を各配置の資源判定へ加える**。キャッシュで準備費を隠した合格にしない。積分点・作用素・許容未知量・荷重・許容差は変えず、1配置300秒・残系列1200秒・2GiBを維持する。

通過済み12組を再利用し、残4組を全て再計算。元の物理場、元作用素、反力、仕事、旧投影解との一致を別に確認する。一般の配置依存荷重のキャッシュ採用とは別。
