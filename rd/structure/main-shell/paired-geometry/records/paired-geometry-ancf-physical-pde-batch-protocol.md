# 同じ6右辺を一回の幾何観測で評価する

2026-11-04。中面評価経路では歪みn4厚い側の独立曲率は通過したが、標準群まで別々に観測すると準備時間込み376.235秒で時間未達。全物理条件の通過と資源未達を分けて保持する。

同じ幾何配置の独立曲率3右辺と標準3右辺を6列として同時に解き、同じ積分点のN/Bを一度評価して6右辺を観測する。異なる右辺を混ぜたり選別したりしない。全ての荷重・状態を別々の列で保持し、結果と反力を元の3列群へ分けて保存する。製造場は求解後の観測だけに使う。

参照値・支持・行列・全自由度・積分点・重み・基準は既存仕様と同じ。元の参照行列準備時間を加算して1幾何配置300秒・残系列1200秒・2GiB。通過済み12組を再利用し、残2幾何配置の6右辺ずつを再計算する。全48右辺で物理場・平衡・反力・仕事の同じ判定を行う。
