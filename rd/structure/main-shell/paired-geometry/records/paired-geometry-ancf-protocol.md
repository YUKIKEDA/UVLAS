# 位置と厚さ勾配を分離しないCartesian補完

2026-11-04。GCの独立r/d補完とセル境界版は追加曲率の薄肉増幅で不合格。今回は補完のr/dを別々に増やす操作をやめる。

同じ曲率からφ1=−κC−zI0、φ3=b−κxzI0の**スカラー位置形状関数**を作り、それぞれに3Cartesian係数を掛ける。基礎r/d/cは独立に残す。線形S、一定質量、変形後の任意回転に対する空間の閉包、同じSからの位置と仕事を維持する。曲げ方向だけを残す固定ベクトル補完とは異なる。

放物柱面の中面では∇φ1=−I0 ez、∇φ3=I0 ex。全厚さの先頭曲げひずみはI0を含む独立なr/d補完ではなく、kから同時に定まる。φ1 ex+φ3 ezが同じ等長曲げ族を含む。全3D生エネルギーと全補正を用い、重みや閾値を緩めない。

最初に追加曲率a=2,4,6、正則n4、2厚さを15×9独立評価で棄却検査する。通過した時だけ、従来と同じ12配置の数値・物理仕事・階数・質量・精度の検査へ進む。一般曲面の同時持上げ、物理PDE、積層、非線形過渡、性能は未採用。今回の定義は解析柱面での試作であり、一般面の品質を証明しない。
