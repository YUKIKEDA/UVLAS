# 参照係数PG-ANCF：R4集約判定の条件

2026-11-05。既存の1%・薄肉増幅2倍、1e−12の数値床、原残差1e−8、rankの3閾値、参照準備を含む1配置300秒を維持する。現在の候補を同じSとして検査し、過去の異なるSの合格で穴を埋めない。
