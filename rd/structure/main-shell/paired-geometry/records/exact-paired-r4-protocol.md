# 係数空間で構成するPG-ANCF：R4の再判定仕様

2026-11-05。既存PG-Ritzの不採用を維持し、係数構成を変更した候補を検査する。品質・初回実務範囲を変えず、R4の成立が揃うまで確認待ちを挟まない。

## 変更するもの

関数値を差し引いて独立性を決める処理を置き換える。参照幾何、P7曲率の原始関数、基本補間、全トレースを有理数の区分多項式係数として組み立てる。dは多項式分子／g³ᐟ²で保持し、基本dも同じ分子辞書に置く。位置と厚さ勾配の対そのものは保持する。

参照Ritz解への固定、独立r/dの過大な拡張は採用しない。参照Ritzは幾何だけの持上げを作る処理として扱い、その係数・必要微分・停留と、最終的な物理試行空間での包含を別に判定する。現在の特解版は二次グラフの入口検査であり、一般参照面のR4合格ではない。

係数行列のrankと位置像のrankを有理数で確認する。位置を持つ座標と、位置が厳密に零の厚さ勾配座標を分離し、h/h²の尺度を後者と二次厚さ座標に与える。基底構成の近特異な逆行列は保証付き区間演算で扱い、係数区間半径1e−25以下を要求する。参照準備だけの使用であり製品ランタイムの依存採用ではない。[FLINT有理行列](https://python-flint.readthedocs.io/en/latest/fmpq_mat.html)、[保証付き実行列](https://python-flint.readthedocs.io/en/latest/arb_mat.html)。

原辞書のSVDは列選択の補助診断であり、その小さい列を閾値で捨てて空間を変えない。構成の次元は有理数rankで決め、採用の数値条件は完成した基底と作用素に課す。

## 演算経路の圧縮

全3Dの7厚さ点×6ひずみ成分は、位置の勾配・dと勾配・cと勾配の24 jetを介して分解する。全24列のQRを使い、局所特異値を一つも切り捨てない。これで42行を24行へ変換する。厚さの求積点・物理測度・全3Dエネルギーは変更しない。

元の3D勾配との点別作用素差1e−12、同じ基底での解の物理場差1e−8以内を要求する。誤差観測は圧縮した局所QRを使わず、元の物理勾配から行う。質量の厚さ4点はNᵀN detJの6次以下の多項式を厳密積分するもので、7点との差を確認する。

## R4を閉じる残りの一組

1. 一般参照面のRitz持上げ、二階微分、実法線厚さ、全トレース。非二次の代表と座標写像も含める。
2. 上の有限厚さ品質。入口で失格した候補はその先の高価な試験へ進めない。
3. 同じSによる独立な体積力・全外面力の物理PDE、反力・仕事・平衡。投影だけで代用しない。
4. 材料・積層・初期ひずみ、非線形U/f/K、層界面の両側回復。
5. 整合質量、6剛体、平衡周り固有対、同じ状態での確定・棄却・再開。
6. 局所処理／全体処理の対応、代表容量、適用・拒否条件と残る製品検証、採否の監査。

個々の合格をR4全体の合格へ読み替えない。不採用の記録は上書きしない。
