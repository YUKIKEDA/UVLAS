# R4の一般参照面・Ritz持上げから実務力学への一括判定

2026-11-05。R4.1を保持し、R4残項目を確認待ちなしで判定する。柱面のκを点ごとに置換せず、参照膜最小化と同じ場の厚さ勾配を用いる。

一般化案PG-Ritzでは荷重に依存しないC¹の区分P7曲率の二重原始関数を種とする。接線場はC¹二次テンソル空間と、原始関数b/Cに他方向の一次関数を掛けた空間で最小化。これは既存の幾何重み付き種から一般参照面へ定義を変更する案であり、既存の数値合格を新しい空間へ移用しない。単位法線を用い、hを実法線厚さとする。旧柱面への極限、二重曲面、混合曲率、正則／座標歪み、変厚を検査する。

最初に参照だけのRitz可解性・膜停留・単位法線／非退化・零次せん断／法線条件、二階微分と厚さ勾配の別微分、C¹位置／C⁰厚さ勾配を検査。rankは1e−9/1e−10/1e−11で同じ、条件数・元停留1e−8、幾何／微分／支持／トレース1e−9（独立数値微分は1e−8）。数値成立後、同じSの全3Dエネルギーで既定1%・薄肉増幅2倍と独立場を検査し、一般面の採否を決める。特殊面の成功だけで一般面を採用しない。

続いて全トレース拘束・多パッチの仕事、採用済み材料点契約の層別求積／初期ひずみ／U-f-K、質量・固有値・状態再開、参照準備と評価容量を同じSへ接続する。R4の終了は式・主要I/F・不変条件と採用を左右する代表照合が揃うこと。網羅的な製品受入を実装前に要求しない。既存の不採用、数値／資源停止は凍結し、新しい版へ分ける。
