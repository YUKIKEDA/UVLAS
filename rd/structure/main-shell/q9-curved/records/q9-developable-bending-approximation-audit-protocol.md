# 放物柱面全エネルギー近似の別経路監査

2026-11-02。主計算の全38配置と成果物・ソース・親ハッシュを照合する。n=1で歪み0/0.2の幾何と圧縮行列が同じことを確認する。

κ=0.4、歪み0.2、h=0.0001、n=2/4/8を対象に、別の形状関数微分からrawの物理ひずみを再計算する。CGの還元自体は一次実装を使うため独立再実装とはしない。解析ひずみは閉形式に代えてδJ J⁻¹の対称部分、材料エネルギーはMandel Choleskyに代えてλ(trE)²+2μE:Eで評価する。raw/CGのH¹上限2倍、n=4は4倍も照合し、エネルギー相対誤差の差1e−7以下、対象エネルギーのDecimal参照差1e−10以下を要求する。
