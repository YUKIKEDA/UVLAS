# 先頭解析から絞った次の一組：欠けた位置モーメントと零面力flux

2026-11-04。採用済み要素ではなく、今回の原因解析に対応する**一組の設計仮説**。次数や候補を一律に増やすことはしない。現在の全試験と不採用判断は保持する。

## 欠ける場

現在の先頭位置場はQ55からΨ=P5(ξ)P5(η)だけを除いた35スカラー場。双一次写像のx=a+bξ+cη+dξηで、解析放物柱面の四次曲げの接線変位u0x=−κx⁵/15には、単項式ξ⁵η⁵の係数−κd⁵/15が現れる。κd≠0なら現在の位置空間には入らない。平坦κ=0や正則d=0の四次場を再現できても、この欠落は検出できない。

## 対応する最小の組

体積位置空間へΨ（厚さζ0）の1スカラーモーメントを追加する。Cartesianの3位置座標で、要素内縮約対象とする。再構成Wにも同じζ0の1場を追加する。ζ1/ζ2の角場を今回一律には加えない。

体積だけを増やすと、既存の弱勾配がその追加モーメントを観測できない。混合空間へ、親座標の交換に対称な二つのfluxを組にして追加する。

$$
\beta_\xi=\left(\frac{P_6(\xi)-P_4(\xi)}{11}P_5(\eta),0,0\right),\qquad
\beta_\eta=\left(0,P_5(\xi)\frac{P_6(\eta)-P_4(\eta)}{11},0\right).
$$

両方とも発散はΨ、全6面の法線成分は零。したがって、DivΣ＋⊂V＋と既存面の法線仕事の条件を維持できる。共有面の未知量はこの代数的変更だけでは増えない。現在の場にはβとの勾配仕事が零、新しいΨには−∫Ψ²の仕事があり、観測不能だった位置場を識別できる。

## 採用前に残る検査

この代数的な観測可能性だけでは採用しない。追加後の局所N−6、6剛体、一定F/P、客観性、材料／幾何の全接線、安定化双対、親座標交換、全自由度の先頭曲げ近似を確認する。数値・有限h・非線形・材料結合のゲートも維持する。

さらに、内部位置場の高次面成分と共有トレースの関係、位置・法線の一意な回復、外力およびUVLM写像の仕事を定義する必要がある。「共有自由度が増えない」だけを理由に、実務で使う構造／空力の幾何が一意に閉じたとは扱わない。製品APIは確定しない。
