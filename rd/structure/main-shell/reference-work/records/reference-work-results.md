## 定式化した一組

[数式・位置／応力空間・全6面・勾配補完・安定化](../reference-work-ancf-formulation.md)。基本混合空間はQ542×Q452×Q443の280場で、発散は体積Q442に入り、鉛直面法線はQ42、上下面はQ44に入る。一定Cartesian応力の引き戻しjJ⁻¹eを幾何補完し、面位置にも対応する法線成分を含める。

全ての射影を参照測度で定義した。上下面は独立の位置トレースとし、体積位置とともに内部縮約する構成。上下面荷重もその位置へ作用する。従来のように体積位置の上下面トレースで代用して仕事保存を仮定しない。主位置は75スカラーのANCF r/d/cと可逆なLegendre係数で、局所555座標から幾何補完が必要な面だけ増える。

104ポテンシャル勾配の補完は混合空間との直交成分だけに加え、既存の全混合仕事を変えない。全6面の安定化に再構成補正を加え、面力にはその転置も含めた。τ=2.5を保持した。

RTの法線モーメントとPiola写像は[DefElement](https://defelement.org/elements/raviart-thomas.html)、発散と補間の可換性は[deal.II公式説明](https://dealii.org/9.8.0/doxygen/deal.II/classFE__RaviartThomas.html)を参照した。異方次数・幾何補完・非線形ANCFの安定性定理を継承していない。[資料と読んだ範囲](reference-work-sources.json)。
