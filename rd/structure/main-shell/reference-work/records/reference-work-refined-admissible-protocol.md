# 許容場による目的関数の上界診断

2026-11-04。n4の2条件では数値ゲートは通ったが薄肉増幅2倍を超えた。その増幅を直ちに離散化のロッキングと断定しないため、同じ原作用素で評価できる別の許容場と比較する。採否閾値を変えず、元の解も変更しない。

同じ線形化四次非伸張変位を、決めてある参照L²射影で体積／全6面へ入力する。鉛直共有面の係数を一つに揃え、x=0トレースを厳密に零とする。支持と共有が成立したこの場の主13²×7・別15²×9の離散エネルギー誤差を、求解された場と比較する。

この場は最小解ではなく、目的関数最小値への上界である。求解場より低ければ、その同じ離散化でさらに誤差を減らせることの証拠になる。高い場合には、求解精度の証明にも離散化誤差の下界にもならない。解析場をソルバーの初期値や解へ埋め込まない。比較は既存のn4・h=.01/.0001の2条件だけとする。
