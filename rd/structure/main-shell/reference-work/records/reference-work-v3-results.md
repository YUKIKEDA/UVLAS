## 前回と何が変わったか

[前回RW-1／RW-2](reference-work-results.md)では、一般四次参照で幾何補完を点値の差として作ることが数値的に不安定だった。今回は[事前仕様](reference-work-v3-protocol.md)の一案だけを実装した。RW-2の空間・全6面・未知量・エネルギー・τ=2.5を変えず、多項式係数から幾何補完、発散、法線、全モーメントを評価した。

幾何前処理だけDecimal60桁／独立80桁で節点が定める多項式を変換し、最終係数をfloat64へ戻した。FE作用素・SVD/QR・非線形計算はfloat64。小さい多項式係数を削除していない。これは製品用高精度演算の採用決定ではない。

一般四次参照・h=.0001の参照勾配誤差は1.54063e-07→7.67194e-12、回転内力誤差は1.28191e-06→2.8051e-10へ低下した。仕事・rank・独立性を失わずに前回の局所未達を解消した点が、今回の具体的な前進である。

## 大域実行v1の停止と切り分け

[大域v1結果](reference-work-v3-shared-result.json)はn2・平坦正則のh=.01と.0001まで実施し、2条件目で停止した。QR圧縮後の四次誤差2.93059e−7と保存場の別積分誤差3.16647e−7の差が、事前1e−8を超えた。残り6配置、有限h4条件、大域非線形平衡はこの実行では行っていない。[保存場監査](reference-work-v3-shared-audit.json)は2場の物理観測を再現した。

[診断仕様](reference-work-v3-residual-protocol.md)・[保存場の切り分け](reference-work-v3-residual-diagnostic.json)。新しい大域求解をせず、同じ場・同じ作用素を比較した。

## 大域評価実装v2でも必要条件未達

[変更を固定した仕様](reference-work-v3-shared-v2-protocol.md)・[実行前ソース](reference-work-v3-shared-v2-preparation.json)・[結果](reference-work-v3-shared-v2-result.json)・[独立観測](reference-work-v3-shared-v2-audit.json)。v2は同じQR求解と局所復元を使い、同じ目的関数を主求積の物理ひずみ・安定化で評価した。圧縮値も別に保存した。閾値や誤差の解析的な定義は変更していない。

二つの実行で保存解のnpzハッシュは両条件とも一致した。評価値だけを修正し、解を変えていない。主／別積分の1e−8照合は成立した。しかし、元の平方根行列と直接残差から内部・共有の全自由度について停留条件を検査すると、最薄で四次1.197095e-08／exp3.847368e-08となり、1e−8を超えた。圧縮系だけのKKT値が小さくても、元の問題の精度を受け入れなかった。

このためv2も2条件目で停止した。大域8配置の比較や薄肉増幅、物理外力平衡へ進む数値条件が未達であり、その後段は未実施。**現実装は不採用。RW-3の局所成立と、主シェル未採用を区別する。** 薄肉精度や変分原理全般が不可能だと結論していない。

## 次の対象と進捗の意味

幾何補完を再調整する、別のFE候補を追加する、閾値を緩める対応は行わない。保持するのは、今回9局所と独立観測を通した係数空間表現。次は**同じ2問題の原作用素に対する縮約・求解・復元の精度**である。圧縮系の残差だけでなく、原作用素の停留条件、主／別物理評価、解析的許容場、独立した解で判定する。

前回の幾何基底の未達を残したまま繰り返しているわけではない。一方、数値精度の未達が残り、薄肉採用条件の合否はまだ出ていない。主シェル1.1の終了日を約束できる状態ではない。[見通しと残工程](../../review/main-shell-completion-outlook-v2.md)・[ロードマップ](../../../../planning/preimplementation-history.md)・[証拠閉鎖](reference-work-v3-disposition.json)。
