# GSP-Q3基底v2：2セル先行検査

2026-11-03、実行前に固定。[限定契約](../gsp-q3-basis-v2-contract.md)の最初の2セルだけを対象とし、v1の保存済みq・中心・尺度・選択列Tを使用する。float64で保存された形状関数の逆Vandermonde係数・Mandelテンソル・Legendre正規化定数も同じ値として高精度へ移す。幾何の再フィットや切捨てをしない。

Python標準Decimalの80桁と120桁で多項式係数を作り、選択列の相殺と単項式→Legendre係数変換を準備中に処理する。np.longdoubleは使用しない。float64の係数に戻して9³のcompliance Gramを計算し、良条件のCholesky補正で同一空間を白色化する。場の評価は全て保存された有理多項式から行う。求積点のQへの置換や、独立列の切捨てはしない。

両準備の任意17点（seed20261103、各座標−.97〜.97）の相対場差≤1e−10。9³／11³で元の生成空間のrankを相対1e−9/10/11で確認し、spanと白色化Gram誤差≤1e−10を要求する。13³は誤差分離用の診断のみ。分母の正則性・幾何は元の検査を継承する。

別経路は、多項式係数の構成処理を使用せず、120桁で各任意点の形状関数・フレーム・応力輸送・物理追加場を直接計算し、元のTを掛けた場と係数評価を比較する。またClenshaw評価で保存基底の場と9³／11³／13³のGramを再構成する。各差≤1e−10。生成空間・幾何・求積は共有し、完全独立実装とは呼ばない。

最初の必須未達で保存して停止。係数構成2精度・2セルを含め900秒・ピーク2GB以内。高精度準備時間・保存係数容量を記録する。両セルが通った場合に限り局所30条件v2の実装・照合・ハッシュを別途固定して先頭から再実行する。この先行検査だけで局所30条件完了や共有・曲面の採用を主張しない。
