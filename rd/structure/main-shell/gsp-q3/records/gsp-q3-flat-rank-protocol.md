# GSP-Q3：平坦要素の厳密rank証明・事前仕様

2026-11-03。新しい応力空間案の要素試作前に、その平坦極限が余分な零エネルギー方向を持たない必要条件を検査する。曲面・共有・薄肉一様性・一般的な安定性の合格ではない。

変位の各物理成分をQ3(s,t)⊗span{1,z,z²/2}で展開し、144係数を使う。固定された異なる4点でのLagrange係数との変換は正則なので、単項式係数でrankを調べてよい。参照立方体[-1,1]³上で、応力と対称変位勾配の仕事を有理数で積分する。off-diagonal stressには対称な両成分を含め、Mandelの√2を使わず同じテンソル内積を表す。

対象の参照応力空間はss:Q2,3⊗P2、tt:Q3,2⊗P2、st:Q2,2⊗P2、sz:Q2,3⊗P2、tz:Q3,2⊗P2、zz:Q3,3⊗P1の203次元。幾何による追加場は平坦ではこの空間に入るため、追加しなくても同じrankになる。

行列L_ij=∫Σ_i:sym∇u_jのrankについて、6剛体方向が厳密に核に入り独立であることから上限138を得る。素数1000003/1000033/1000037をそれぞれ試し割りで確認し、各有限体の消去rankが138となれば有理数rankの下限138を得る。両者でrank138を証明する。浮動小数のSVD閾値は使わない。

負の対照は全6応力成分をQ2,2⊗P2へ落とした162次元。r/d/cの各物理成分にP3(s)P3(t)を置く9方向を構成し、剛体6と独立で、Lの厳密な核に入ることを確認する。有限体rankも記録し、余分な零モードを検出できる計算であることを確認する。失敗時は203次元案を合格扱いにしない。

行列・剛体方向・負の対照方向を分子／分母の整数として保存し、SHA256を保持する。階数の有限体下限と有理数核の上限を区別する。正の厚さと正則なアフィン変換への移行は、可逆な変位・応力基底の変換で説明する。厚さゼロや曲がった写像への拡張はこの証明の範囲外。
