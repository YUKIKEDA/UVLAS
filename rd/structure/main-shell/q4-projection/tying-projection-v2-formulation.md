# 共変tying作用素v2：点順序の修正

2026-11-04。[v1](tying-projection-formulation.md)は最初の平坦局所の制約付きtying rankで停止し、合格条件は得ていない。原因はQ88共変値のテンソル補間で、Gauss点列がs外側・t内側なのにt外側・s内側として補間列を組み立てた実装誤り。v1のソース・結果・実行前ハッシュを保持する。

v2は同じ式・空間・平均条件・許容差を用い、補間列を実際の点順序へ修正する。また、旧C直交射影を前提にしていた監査の双対式を、実行前にP_hᵀへ置換する。独立評価はLegendre補間・120桁の補完係数・別QR基底で構成する。v1停止を要素の不適格証明へ使わない。原MITC16の性能を本案へ転用しない。
