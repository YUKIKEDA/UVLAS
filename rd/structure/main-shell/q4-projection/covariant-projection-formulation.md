# 共変中央面射影：勾配・回転場を保持する修正版

2026-11-03。独自の中央面射影v1は、平坦のrank218（必要219）となり偽零モードを1つ持った。また、幾何に依存して生成した場のほぼ従属な列にrank不確定があった。v1を採用せず、結果とソースを保持する。

本案はその場の許容差・重み変更ではない。偽零モードに対応する横勾配の回転場を明示的に保持し、独立性が既知の共変多項式空間から基底を作る。[中央面だけへ作用し生の厚さ変化を保つエネルギーと双対](mid-projection-formulation.md)は維持する。公刊QEMそのものではなくUVLASでの導出である。

## 1. 共変ひずみの空間

参照中央面のJ0=[r_s,r_t,d]により、共変ひずみはEhat=J0ᵀEJ0、物理ひずみへの逆変換はE=J0⁻ᵀEhat J0⁻¹とする。次の多項式場を用いる。

- 膜：2成分のQ4親座標変位の対称勾配。50生成列から親座標の剛体3方向を除いた47次元。
- 横せん断：Q4スカラー場の勾配。定数を除いた24次元。
- 厚さ法線：Q8の81次元。Q4のdとQ4のδdの積による全ての生の共変法線ひずみを含む。
- 回転場：各グローバル軸Ωについて、横勾配δd=Ω(r−rc)が作る共変せん断・法線ひずみ3生成場。
- 物理一定ひずみ6場を共変へ写したJ0ᵀMαJ0。

基礎152次元と最大9幾何補完場。回転場を除くと、勾配へ直交する横勾配を失って偽零方向を作り得るため、単に場の次数を下げる設計にはしない。

## 2. 独立な基底を作る規約

基礎多項式は単項式係数の有理数消去で独立化する。回転・一定物理ひずみの共変場は参照qと形状関数から80桁で係数を作り、基礎空間を厳密係数で除いた商空間で独立化する。別評価は120桁で作る。参照qそのものを丸め直さない。

補完残差の係数ノルムが元場の1e−12以下の場合のみ数値的に従属と記録する。この数値的な包含誤差は実際の一定場・仕事検査で1e−9以内であることを必要とし、rankの基準を緩める理由にしない。残りは係数空間で正規化し、幾何係数の小ささを基底条件数へ持ち込まない。

9²／11²の物理C内積では、得た独立多項式列の全数について相対1e−9/10/11のrank一致を要求する。物理基底のSVD／別QRと80／120桁の係数経路を照合する。
