# 中央面の幾何射影：横勾配の回転場と共変せん断の保持

2026-11-03。中央面射影の物理場構成を修正する独自案。v1の平坦rank218と、曲面のほぼ従属な生成列を保持する。共変多項式案も別結果として保持し、全て同じものと扱わない。

エネルギー・双対・生の厚さ変化の保持は[中央面射影](mid-projection-formulation.md)の式と同じ。物理的な接平面ひずみ場、厚さ法線ひずみの生の像、物理一定6場を使用する。

変更1：せん断の基準を単位法線nから参照厚さ座標の共変な双対ベクトルg^z=J0⁻ᵀezへ置き換え、sym(g^z⊗∇Ni)を使う。これは長さや曲率で任意の罰則係数を付ける操作ではなく、厚さ座標と物理勾配の対応を使う場の定義。単位法線の平方根因子と一定物理場の間の近い従属を直接持ち込まない。

変更2：全グローバル軸Ωについて、δd=Ω(r−rc)が作る生の中央面ひずみ3場を追加する。対称な曲率ひずみを作らない回転型横勾配を落として偽零モードにしないための保持場。自由な安定化係数は追加しない。

これらは生成空間そのものの変更で、rankや仕事の閾値を緩めない。参照固定のC直交射影、全物理一定場の保持、一定応力仕事、Rh²、一般双対、全接線、剛体回転を再検査する。曲率が任意に小さい場合や任意の異方性を保証したとはしない。

共有曲げ・非多項式・有限厚さまで成立しない限り採用しない。前段の失敗を局所成立で覆い隠さない。
