# M-Q3の監査と共有薄肉空間への接続

2026-11-03。局所20条件の可解性と別積分が成立した後の作業。主シェル採用の条件を変更しない。

進行更新：項目1・2は独立実装監査・共有接続で完了。項目3も[厚さゼロ／一次写像の10参照セル検証](records/mq3-zero-first-map-results.md)が成立。次は項目4の[12配置の共有薄肉空間比較](records/mq3-shared-thin-space-protocol.md)。採用条件は未完了。

1. **独立実装監査**：別Vandermonde微分と単項式の候補基底を使い、同じ多項式空間・幾何追加列・モーメントを再構築する。係数の数値そのものではなく、物理再構成場・一定場・仕事・モーメント・局所rankを比較する。主実装の形状関数・基底評価を監査の計算へ流用しない。保存20条件と11点系を対象に、実験仕様を先に固定する。
2. **共有仕事とモーメント**：2×2の共有r/d/c任意場を用い、両側の大域向きに揃えた辺／側面モーメントを比較する。一定応力の共有節点力を独立外表面積分と照合し、支持反力・厚さ上下面を残す。仮定ひずみ全点の強い一致を保証した扱いにはしない。
3. **零次・一次写像の導出**：正規化厚さζを固定してh→0とする幾何・積分・制約の係数系を定義する。h=0でJ_ζを直接逆にしない。物理zのJ_zを使い、階数が安定する独立制約の下で、最小変更の係数系を微分する。SVDの特異ベクトルを形式的に微分して式としない。正負hの対称性とζ依存を検査し、零次・一次以外の人工的な厚さ依存が残らないか確認する。
4. **共有薄肉制約の比較**：導出した作用素で、以前のκ=0/.4・歪み0/.2・n=1/2/4の12配置を評価する。二次場の正の対照、全6成分のrank／核、四次一次場・H¹上限・別積分を同時に見る。小さい有限hの結果をそのまま零次核と呼ばない。

共有核の次元増加だけを合格条件にしない。仕事や安定性を失わず、実際の曲げ近似に改善がある候補だけを有限hの旧1%・2倍ゲートへ進める。未達なら条件を保持し、失敗原因と次の有限な比較範囲を記録する。材料軸・積層・非線形・汎用場／双対・実務費用は後続に残る。

膜支配側の精度も比較する。M-Q3はMITC4+の平坦膜応答をそのまま継承しない。例えば平坦なQ3変位のs³t成分の微分には、試案の面内せん断Q₂,₂に含まれないs³項が現れる。一方で全次数3以下の平坦変位の微分は空間に含まれる。この区別を、全Q3テンソル積場の厳密再現と混同せず、膜支配・曲げ支配・混合の収束で評価する。曲げだけを良くして採用を閉じない。
