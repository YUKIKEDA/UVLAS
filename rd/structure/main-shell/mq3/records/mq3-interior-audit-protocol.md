# 内部条件分解：実行・別評価の具体化

2026-11-03、実行前に固定。[主仕様](../mq3-interior-stationarity-diagnostic.md)の実行手順を補足する。

9³の対象場Gram行列HのCholeskyから白色化Kを固定し、11³でも同じKを使う。対象場の膜4成分とせん断2成分（対称成分の重みを含む）の平方根作用素から純膜／純せん断の全空間を作り、それぞれにDの核を課す。2純空間をker D内で補完して混合方向を得る。係数基底の列分類や場のサンプル一点だけによる分類は行わない。

各核計算では、行ノルムが行列内最大の1e−13以下なら数値的ゼロ行として除き、残りを単位化して全右SVDを求める。相対1e−9/10/11の3閾値でrank一致を必要とする。行数が列数より少なくても核を切り捨てない。混合空間が0次元なら空の作用素として保存する。

9³／11³の各部分空間の射影差1e−10以下も必要とする。全内部行と必要行を加えた核は、保存済みM-Q3全零次核との同値性を各作用素で先に検査し、成立した作用素だけ16問題の比較に用いる。核次元や誤差の未達時は保存して停止する。元の許容差やH¹上限を変更しない。

別評価は、保存したKと部分空間を用い、明示的な6成分生ひずみ行列を物理勾配から構成して、11³で内積右辺を再積分する。内部行列と必要行列を共有組立し、一次結果のH11との差1e−10以下、保存核・解の残差1e−9以下を要求する。対象場の基底は共有するが、主計算の生の膜・せん断場を使って右辺を再利用しない。

保存二次／四次解の一次場は、固定KKT微分とは別に、複素厚さの一般LU直接解で評価する。物理テンソル内積による誤差差と別面内微分によるH¹相対差は1e−8以下。全16問題と4作用素の核同値性の成立を確認して比較を完了する。全体SVD・最適化の完全独立再求解ではない。
