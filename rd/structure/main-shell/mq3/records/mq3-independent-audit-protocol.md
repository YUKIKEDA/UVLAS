# M-Q3の別実装監査・共有接続の事前仕様

2026-11-03。ロードマップ1.1。[接続契約](../mq3-audit-and-shared-space-contract.md)の1・2を実施する。主シェル採用、零次／一次写像の導出、共有薄肉核や有限h精度の判定は対象外。

保存20局所条件を入力とし、節点値と参照幾何のみ再利用。基底は単項式、形状関数微分は既存の別Vandermonde実装から再構成。Mandel基底と全3D等方構成則も監査側で生成する。一次実装のデータ・基底・係数構成関数は監査計算に使用しない。

係数構成は列正規化・列ピボットQRで独立空間を選び、QR直交基底へ変換する。辺と厚さのモーメントも0〜2次単項式を用いる（Legendreと同じ空間）。制約行は別のピボットQRで選択し、制約のQR零空間を使って最小変更を解く。一次実装のSVD補正公式は使わない。rankは相対1e−9/10/11の3閾値で一致を必要とする。

9³構成・11³観測で、保存一次係数による物理再構成場とのC内積・生B列尺度付き最大相対差1e−8以下を検査する。一定6場最大絶対差1e−10、全144仮想変位の一定応力仕事差1e−10、全モーメント残差1e−10、局所rank138の3閾値一致を必要とする。独立6面表面力との相対差は1e−9以下。場の比較は基底係数の直接比較ではない。

共有試験はκ=0/.4、2×2歪み.2、h=.01/.0001の4配置。監査側係数を用い、全49節点・441成分の任意r/d/c場（seed=20261103）を共有する。全4内部辺について、11点／11²点で辺接線膜3モーメントと接線－厚さ9モーメントを大域の同じ向きに揃えて比較する。入力の生場と再構成場それぞれの相対差を1e−9以下とする。仮定ひずみの全点一致は要求しない。

同じ配置で、全局所144成分の一定応力仕事を全共有節点へ組み立て、内部接合面を除く外表面の独立積分と相対1e−9以下で照合。上下面と支持反力に対応する成分を落とさず、支持前の全441成分を比較する。一定ひずみの全体パッチ最大絶対差1e−10も検査する。

ソース／一次結果／保存係数のSHA256を確認する。未達は値・スペクトル・係数を保存し停止。全体180秒・ピーク2GB以内。別実装の係数構成・場評価・共有接続の監査であり、独立格子生成・全体系の平衡再求解・人的レビューではない。
