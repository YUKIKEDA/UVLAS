## 独立に再構築した範囲

元実装のLegendre基底を単項式へ、形状関数の積の微分を別Vandermonde微分へ変更。物理Mandel基底と3D構成則も監査側で生成した。係数構成はSVD補正の流用ではなく、列ピボットQRによる空間選択と、独立制約のQR零空間による最小変更解を使用した。

9³で独立係数を構成し、11³で再構成場・一定場・仕事・rankを観測。基底係数の一致ではなく、全150入力の物理場を生場のCノルムで尺度化して比較した。一次実装は保存係数から比較場を評価するためだけに呼び、監査の基底・微分・係数求解へ使用していない。

| 局所検査 | 全20条件の最大値・結果 |
|---|---:|
| 保存一次実装との列尺度付き物理場差 | 6.16e−13 |
| 一定物理6場の最大絶対差 | 2.80e−14 |
| 全144変位への一定応力仕事差 | 1.78e−13 |
| 独立6面表面力積分との差 | 1.51e−12 |
| 辺／側面モーメント残差 | 1.46e−14 |
| 局所rank | 全条件138、3閾値で一致 |

候補空間105／106、制約行rank53／54も一次実装と一致し、3閾値で安定した。全数値条件が成立した。

## 共有試験

κ=0/.4、2×2歪み.2、h=.01/.0001の4配置。保存された各セルの参照節点から全49節点を接続し、全441成分の任意r/d/c場を共有した。各配置4内部辺、合計16辺で、大域向きを揃えた膜3・接線－厚さ9モーメントを比較した。

| 共有検査 | 4配置の最大差 |
|---|---:|
| 入力生場の辺モーメント | 9.65e−16 |
| 再構成場の辺／側面モーメント | 1.51e−14 |
| 全共有節点の一定応力仕事と外表面力 | 8.06e−13 |
| 一定ひずみの共有パッチ | 2.87e−13 |

節点力の照合は支持前の全441成分を対象とし、固定断面の反力に対応する成分、全上下面・側面を保持した。内部接合面だけを外表面積分から除外した。仮定ひずみの全点一致を保証した結果ではない。

監査・共有試験は18.829秒、ピーク358,092,800 bytes。全ソース・一次結果・保存係数のSHA256を確認し、監査係数も保存した。

## 成立したことと次の判断

同じ候補空間・拘束から、別基底・別微分・別係数求解で同じ物理再構成を得られた。局所仕事と辺モーメントは今回の共有後も整合した。一方、参照節点は再利用しているため格子生成の独立監査ではなく、全体平衡の独立再求解や人的レビューでもない。

次は[厚さゼロ写像・一次変化の導出](../mq3-zero-thickness-linearization.md)を数値検証する。係数系のh=0でのrank・微分を閉じてから、以前の12配置の共有核・曲げ近似を比較する。小さい有限hの再構成を、そのまま零次核と見なさない。旧1%・薄肉増幅2倍は未評価、主シェルは未採用。
