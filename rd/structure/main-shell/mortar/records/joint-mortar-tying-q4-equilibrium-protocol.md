# 共同tying＋mortar：非線形KKT・転置双対・全接線

2026-11-04。共同薄肉空間の歪み曲面改善は未達であり、この組合せは不採用。反力を含む共同実装の確認を、生の体積応答の結果で代用しないため、[既定の非線形平衡パッチ](mortar-q4-equilibrium-protocol.md)と同じFstar・h・形状・荷重・境界・許容差・資源上限を、共同体積応答で実施する。内部参照値の初期値流用とK ustar荷重は使わない。

全接線の幾何項にもR_hを作用させる。実体積重みを含む厚さ積分応力をt、中央面射影をP_hとすると、中央面の応力双対補正は(P_hᵀ−I)t。全3Dの幾何項に、この補正応力と中央面勾配から作る項を加える。C自己随伴や生の体積接線を流用しない。双線形接線を別の明示的な第二変分と1e−8で照合し、別11²×7の内力・荷重・物理界面反力を同じ許容差で確認する。

成功しても任意の非線形場の求積収束・薄肉精度・主シェル採用とはしない。一次の不採用を保持する。
