# Q3共有零次核・一次曲げの実行前仕様

2026-11-03。ロードマップ1.1・再比較前解析。[診断契約](../q3-thin-limit-compatibility-contract.md)に対応する。有限厚さの新候補試験や荷重平衡ではない。

κ=0/.4、歪み0/.2、n=1/2/4の12配置。n=1の歪み指定は同じ形状。x=0の全r/d/c固定、均質3D材・Q3参照形状を維持。物理厚さzに関するB₀,B₁を解析展開する。

9²と11²で中立面の全6ひずみを共有・支持後のr/d列へ組立て、9²全行列の列ノルムで共通正規化。膜3・横せん断2・厚さ1・全体の特異値を相対1e−9/10/11で判定し、各rankの3閾値・2積分次数一致を必要とする。閾値依存は保存して不確定とし、核を選んで続けない。c列のB₀ノルムは1e−12以下。

全体核は共通尺度の右特異ベクトルから構成。9²/11²核の直交射影差Frobeniusノルム1e−7以下、列正規化行列に対する核残差相対1e−10以下を検査する。個別制約の核と全6成分の核を混同しない。

核上のr/dと独立cを使い、det J₀・全3D Cの内積で一次ひずみを解析E₁*へ近似する。二次場（W''=1）と四次場（W''=x²）の2対象。H¹は同じ面積正規化・L=1、各連続参照の2倍上限。核係数とcに誘導したH¹計量をCholeskyで白色化し、SVD球制約最小二乗を解く。球外の無制約解はLagrange乗数のスカラー根を求めて制約内へ戻す。罰則係数は任意に選ばない。

二次場の節点値を正の対照としてB₀・B₁で評価し、正規化残差各1e−9以下。二次場の制約付き最適誤差1e−8以下。9²/11²の一次近似誤差の絶対差1e−8以下、H¹相対差1e−8以下、球違反相対1e−8以下、白色化KKT相対1e−8以下。四次場の誤差は診断値であり、これだけで有限hの厳密下界・採用合否を定めない。

実行は1配置120秒・全体600秒・ピーク2GB以内。必須数値条件未達を保存して停止し、四次誤差が大きいこと自体では停止しない。核・特異値・2解・節点・接続をnpzへ保存し、ソース／契約／結果SHA256を固定する。

監査では別Vandermonde微分と厚さ複素ステップ（1e−25）からB₀,B₁を再構築し、最大相対作用素差1e−10以下、全84セルを確認。保存核・保存2解の零次制約・一次誤差・H¹を別に評価し、一次誤差差1e−8以下・零次制約残差1e−9以下を要求する。人的独立レビューや全経路独立再求解とは呼ばない。
