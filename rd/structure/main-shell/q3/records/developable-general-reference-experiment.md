# 高次曲げ・連続体荷重参照の実行前仕様

2026-11-03。[次段契約](../developable-general-bending-reference-contract.md)の検証。旧二次たわみと新四次たわみ、κ=0/.4、h=.01/.001/.0001の12配置。有限要素の平衡求解や製品採用は行わない。

変位の複素ステップ微分（刻み1e−25）からδJJ⁻¹の対称部を計算し、閉形式E*=−zW''aaᵀ/jを検査（最大絶対差1e−11）。中立面ひずみ・共変横せん断・厚さ成分・固定断面変位を絶対1e−11以下とする。直接3Dひずみのエネルギーを24×12積分で求め、Decimal80桁・32点面内Gaussと厚さ収束級数による値と相対1e−10以内で照合。平坦の厳密値（二次c h³/24、四次c h³/120）も相対1e−10以内。

体積力は閉形式応力のx,z解析微分と物理逆Jacobianからb=−div_Xσを作る。独立に応力の複素ステップ微分で発散を評価し、最大成分差をmax(1,|b|)で正規化して1e−11以下。荷重にKや節点変位からの離散右辺を用いない。

連続体の弱い仕事は144仮想変位（x^a y^b z^c/c!、a,b=0..3、c=0..2、物理3方向）すべてで検査する。全体積のbと全6面のσnを独立に積分し、内部仕事と比較。固定x=0面の表面力を反力として分け、a≥1の許容仮想変位ではその仕事がゼロになることも確認する。応力上下面の力を省かない。

薄肉の体積力・表面力の相殺に対処するため、弱い仕事の計算にはlongdoubleを使用し、その実効精度を記録する。Gauss節点・重みはDecimal80でLegendre根をNewton精密化して生成する。24×4×8と32×5×12で比較する。内部仕事との全144成分相対ノルム差1e−8以下、非零ひずみを持つ各仮想場でCauchy尺度 ||E*||_C ||ε(v)||_C に対する最大仕事残差1e−10以下、積分次数間の全成分相対差1e−8以下。定数並進はゼロひずみなのでCauchy尺度から除外し、全成分仕事検査には残す。

実体積非正・非有限・必須ゲート不成立は記録して停止。上限180秒・1GB、結果既存時は上書きしない。ソース・仕様・契約・結果をSHA256で追跡する。Decimal級数・複素微分・連続体弱仕事は別計算経路だが、人的独立レビューや有限要素の独立再求解と呼ばない。

実行前の環境確認：WindowsのNumPy longdoubleはfloat64と同じ仮数53ビットだった。拡張精度とは呼ばない。上記の閾値は維持し、相殺で未達なら当該経路を保存し、同じ仕事式のDecimal80桁評価を別版で行う。精度不足と参照式の誤りを区別する。
