# Q3四次曲げ未達の残差診断・事前仕様

2026-11-03。共有近似4配置の数値条件・別経路評価・4×4のSVD再求解が成立し、精度1%・薄肉増幅2倍は未達だった。候補を変更する前に保存解の残差を分離する。再求解・閾値変更・格子変更はしない。

既存の均質3D構成則に整合する平方完成と、実体積重みでの厚さ直交分解を用い、膜型・曲げ型・高次厚さ・厚さ結合・横せん断を分ける。別軸として固定物理座標の要素平均と平均以外を分け、重複加算しない。式は[既存分離契約](../../q9-curved/q9-eas21-residual-decomposition.md)と同じで、候補作用素はQ3の生Bへ置き換える。

11³積分、保存4解、全160セルを評価。5項と全誤差の再構成相対1e−10、既存の別テンソル・厚さQRによる分離との正規化成分差1e−8、親結果との誤差ノルム差1e−8を必要とする。旧分離コードのMandel基底・CとQ3の基底・Cが一致することも確認する。監査は評価の別計算で、独立再求解や厳密下界ではない。

診断と併せて、矩形・アフィンな面内写像でU,Wが同次数pのとき、共変膜ひずみU'+κxW'の最高次係数を解析する。この限定した多項式の可解条件を歪んだ全共有空間の不可能性証明へ拡張しない。単に次の次数へ上げることを対策として決めない。
