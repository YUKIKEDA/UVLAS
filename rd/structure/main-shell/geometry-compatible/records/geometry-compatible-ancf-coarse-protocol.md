# GC-ANCF v3：同じ空間の曲げ基準場と残差保持

2026-11-04。v3の探索で四次・五次の薄い側にも約5e−8のエネルギー誤差が出た。同じ位置／勾配空間は両場を厳密に含むため、基底不足と数値表現の問題を区別する。

空間を変えず、参照幾何で定まる全B_j曲げ族（固定端を満たす先頭2係数以外）に対して、完全な有限厚さのエネルギーから小さい基準場問題を求める。そこから全自由度で残差を解く。未知量を曲げ族に制限しない。基準場と補正を別に保持し、曲げ族のひずみ・位置は同時持上げの解析式から評価して、大きい位置／勾配の差から取り直さない。

基準場係数は全B_jのGalerkin求解で荷重から決まり、四次・五次・指数の個別係数を基底へ入れない。物理荷重問題では同じ曲げ族の仮想仕事から基準場右辺を作る必要があり、その製品実装は未検証。

全3Dエネルギー・位置空間・固定端・仕事は変更しない。QR行圧縮の誤差と元の点ひずみの誤差、全自由度停留を比較する。基準場と全補正を同時に独立未知量にして重複自由度を追加するものではなく、基準場を保持した状態表現と初期化である。

正則n4の2厚さを粗求積で検査後、13次×7／15次×9と歪み条件へ進める。数値1e−8、仕事／共有1e−9、rank／rcond、最細1%・薄肉増幅2倍は維持する。旧結果を保存し、1条件300秒・系列1800秒・2GiBを診断枠とする。
