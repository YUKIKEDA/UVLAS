# GC-ANCF v2の有限厚さ適格性検査

2026-11-04。v1は正則n4の粗求積で指数の薄肉増幅が約3倍・位置は約9倍となり未達。結果を保持する。

v2は、追加B-splineのノットを基本位置のn分割ではなく、位置と二次厚さ勾配dの節点列の和集合である2n分割に固定する。次数5・積分／微分の同時閉包・3D材料エネルギーは維持。解析する変形の係数からノットや基底を決めない。より細かい物理座標で定義した同じ曲げ場を位置とdが共有し、基本セルを越える補完の解像度を厚さ勾配側と合わせる変更。

ノット横断を分割した求積を用いる。メモリを抑えるため各セルの全列＋右辺をHouseholder QRで直交行圧縮し、全未知量を残す。内部座標の消去や小特異値の切捨てはしない。元の点ひずみによるエネルギーと全自由度停留を別に評価し、圧縮系だけを根拠にしない。

7²×5の探索で必要条件を確認後、平坦n2、曲面の正則／歪みn2,n4、h=.01/.0001を13次×7と15次×9で評価する。幾何・補完基底は13次の参照から固定し、別求積では同じ物理場を評価する。

必要数値条件：自由パッチの6剛体以外の零方向なし（3閾値一致）、固定後full rank・rcond≥1e−10、線形残差／原全自由度停留≤1e−8、元点仕事と圧縮誤差差・別求積誤差差≤1e−8、質量の列尺度付き最小固有値>1e−10、幾何再現・共有・固定端・一定F／一定応力仕事≤1e−9。13次での自由rank検査を省略する場合は、同じ空間に対する低次の自由rank検査と実際の剛体場による零作用を別記する。

精度：五次・指数のエネルギー／実変位L²誤差がn4で1%以内、各厚さでn2→n4減少、n4の薄肉増幅≤2。四次は再現の数値対照で、丸め域の比を増幅判定に用いない。正則で通過しても歪みへ転用しない。1問題300秒・系列1800秒・ピーク2GiB。

適格性の結論はこの範囲の採用候補に限定。物理荷重PDE、一般曲面／積層・初期ひずみ、非線形・慣性・再開・実務規模の性能は主シェル最終採用前に残る。未達なら結果を保存し、閾値を変更しない。
