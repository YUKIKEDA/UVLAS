# GC-ANCF：安定基底・強い固定端の最終候補選別

2026-11-04。v5の基底準備は100桁で独立性を分離できたが、旧13点の固定端サンプルでは拡張されたトレース空間の全成分を拘束できないため、受入前に中断した。v6は各辺33点で拘束し、別57点で零トレースを確認する。位置・勾配・曲率空間はv4/v5と同じ。

基準場と全自由度補正を保持する。基準場のrankを3閾値で検査してから解き、元点仕事・誤差・停留は13次×7、独立観測は15次×9で検査する。各ノット横断を分割する。参照基底の準備は各幾何に対して固定し、両厚さと独立観測で共有する。

正則n4の2厚さを先に検査後、正則／歪みn2,n4の両厚さ、平坦n2を必要範囲で一括検査する。従来の数値1e−8・仕事／共有1e−9・rcond≥1e−10・自由6剛体・質量正値、最細1%・薄肉増幅2倍、1条件300秒・系列1800秒・2GiBを維持する。数値床に近い誤差の比だけで薄肉性能を認定しない。元の基準を満たしたかと、有意な誤差の識別可能性を別に記録する。

基準場・元点仕事との一致、独立観測、支持・共有・一定応力仕事が成立しないものを適格候補とはしない。元の停止・不採用は保持する。一般曲面／材料、物理PDE、非線形・慣性・実務費用は最終採用前に残す。
