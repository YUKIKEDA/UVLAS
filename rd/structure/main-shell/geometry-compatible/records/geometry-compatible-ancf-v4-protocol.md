# GC-ANCF v4：曲率の幾何双対仕事による閉包

2026-11-04。v3の安定基準場で数値誤差を除いても、指数の比率が未達。単なる曲率多項式の包含では、他の膜・厚さ法線モードと曲げ残差の幾何重み付き仕事を含められない。

放物柱面でa=(1,0,κx)、g=1+κ²x²とし、基本モードの物理z一次ひずみをE1とする。完全3Dエネルギーで同じ曲げ仕事を持つ先頭曲率は

$$
k_{dual}=-g\,(a\otimes a):C:E_1/[(a\otimes a):C:(a\otimes a)].
$$

基本の位置二次・d二次・c双一次から得られる1方向の仕事は、区分P6/g²に入る。元の三次曲率P3も維持する和空間は区分P7/g²。これを2n区間に置き、曲率k_jの積分I_m=∫t^m k_j(t)dtからb=xI0−I1、C=(x²I0−I2)/2、b'=I0を作る。同じ位置／勾配の同時閉包を全Cartesian方向に用いる。積分は各区間32点Gaussで評価し、微分はk,I0の式から直接得る。変形・荷重・特定参照解の係数を基底生成に使わない。

一般の参照チャートでは正の参照計量から同じ方向別の有理曲率族を定義できるが、今回の試作の計量は検証対象のκに対応するg_x、g_y=1に限定する。一般曲面の双対仕事の閉包が成立すると主張せず、主シェル最終採用前の残課題として明記する。
