# GC-ANCF v5：同じ関数空間の安定な基底準備

2026-11-04。v4の13次準備では、通常精度の積分閉包に対するrankが128/135/136と閾値で不一致となった。元の空間を適当に小さく切るのではなく、参照関数の近い線形関係を高精度で処理する。

P7/g²曲率・その積分／微分閉包は変更しない。区間ごとの解析積分（有理式・atan・log）を100桁Decimalで評価し、40次Chebyshev係数へ変換する。係数空間でピボット付き直交化を行い、最大係数ノルムに対して1e−50以下の残りだけを数値零とする。保持した最小値と最初の棄却値を保存する。変換後の係数をfloat64へ渡し、FEでは通常精度のChebyshev評価を使う。変形・荷重の値は基底準備に使わない。

この補足は基底準備開始時に追加した数値処理仕様で、曲げ精度・rank・仕事の判定閾値を変更しない。13次×7／15次×9で、同じ固定基底・同じ物理場の誤差と原停留を評価する。保持する基準場と全自由度補正の方式、自由6剛体・質量正値、精度1%・薄肉比2を維持。参照基底準備の時間とFE評価時間は分けて記録する。
