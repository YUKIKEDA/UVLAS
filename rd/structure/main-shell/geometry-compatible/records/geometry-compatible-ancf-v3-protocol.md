# GC-ANCF v3：曲率空間の不整合を先に解消する

2026-11-04。v2も薄肉比が未達。次数を増やす前に、基本厚さ勾配dの正則性と持上げの正則性を比較した。dはC⁰区分二次なので、その曲率∂dはセル境界で不連続になれる。一方v1/v2の次数5・単純ノットBのB''はC²であり、基本空間で利用できる曲率を持上げ側が含めない。

v3では次数5と2nノット位置を維持し、ノット重複を4としてBをC¹、B'をC⁰、B''を不連続な区分三次にする。これで同じ方向の基本曲率である不連続区分一次を含められる。位置の積分閉包と厚さ勾配の微分閉包を同時に構成し、3Dエネルギー・仕事・共有・固定端は変更しない。特定の四次・五次・指数係数から基底を作らない。

探索7²×5で今回の正則n4・2厚さを先に判定する。通過後の13次×7／15次×9、正則／歪みn2,n4、数値1e−8、仕事／共有1e−9、rcond≥1e−10、自由6剛体・質量正値、最細1%・薄肉増幅2倍はv2事前仕様を維持する。全列の直交行圧縮を用い、元点仕事の誤差・停留を別に検査する。1問題300秒・系列1800秒・2GiB。

この包含は1方向の正則基準に関する設計根拠であり、歪みや全一般曲面での適格性の保証ではない。未達は保持する。
