# T01 ビルド基盤の検証記録

実施日：2026-10-29。対象：C++コア、開発用CLI、CMake Presets、CTest。

## 環境と結果

| 環境 | コンパイラ | CMake／ビルドツール | Debug | Release |
|---|---|---|---|---|
| Windows x64 | MSVC 19.44.35229.0、VS 2022 Build Tools | CMake 3.30.4、MSBuild 17.14.60 | ビルド成功、5/5合格 | ビルド成功、5/5合格 |
| Ubuntu 22.04.5 LTS x86_64、WSL | GCC 11.4.0 | CMake 3.30.4、Ninja 1.11.1 | ビルド成功、5/5合格 | ビルド成功、5/5合格 |

新規のビルドディレクトリから構成・ビルド・試験を実行した。すべてC++20を指定。Linuxは既存WSL環境での確認であり、独立したLinux実機での性能検証ではない。

試験の内訳は `cli.version`、`cli.help`、`cli.missing-option`、`cli.unknown-option`、`cli.extra-option`。4構成で計20件合格。

別の作業用ディレクトリで `cli.version` の期待版だけを意図的に不一致にし、CTestが失敗と終了コード8を返すことも確認した。製品ソースと通常試験の期待値は変更していない。この意図的失敗は20件の合格集計には含めない。

## Linux検証ツールの取得

UbuntuにはGCCとPythonがあったが、CMake・Ninja・pipはなかった。Windowsのプロジェクト内仮想環境から、公式PyPIを指定して固定版のLinux wheelをダウンロードし、`build/linux-tools/` に展開して実行した。システムへのインストールや恒久的なPATH変更は行っていない。

| 配布物 | SHA-256 |
|---|---|
| cmake-3.30.4-py3-none-manylinux_2_17_x86_64.manylinux2014_x86_64.whl | `1b8a4b0e638ddbabd16cad8b053b5a66733ddaf652dc3d46d55b3887314022fe` |
| ninja-1.11.1.1-py2.py3-none-manylinux1_x86_64.manylinux_2_5_x86_64.whl | `84502ec98f02a037a169c4b0d5d86075eaf6afc55e1879003d6cab51ced2ea4b` |

取得時のコマンド：

```powershell
python -m venv build/tooling-venv
.\build\tooling-venv\Scripts\python.exe -m pip download --index-url https://pypi.org/simple --dest build/linux-tool-wheels --only-binary=:all: --no-deps --platform manylinux2014_x86_64 --python-version 310 cmake==3.30.4 ninja==1.11.1.1
```

wheel内の全パスが展開先配下に収まることを確認してから展開した。SHA-256は取得したファイルの識別用記録である。

展開後はWSLのプロジェクトルートで、以下のプロセス内PATHを使い、`docs/build.md` のLinux用コマンドを実行した。

```sh
chmod u+x build/linux-tools/cmake/data/bin/cmake build/linux-tools/cmake/data/bin/ctest build/linux-tools/ninja/data/bin/ninja
export PATH="$PWD/build/linux-tools/cmake/data/bin:$PWD/build/linux-tools/ninja/data/bin:$PATH"
```
