# 抗力遠方参照：同じコアによる幅・弦の収束

2026-11-05。遠方の中点観測は指定楕円循環で解析値へ収束した。実際の翼の後縁循環についても、揚力の精度を流用せず抗力の収束を測る。

AeroSandbox原本、参照コア1e−10mに統一し、M8/N96/192/384/768の幅系列とM16/N384を両翼で比較する。N768のM8・1e−9/1e−10mは取得済み。N384のM16との弦差を別に出し、M16/32・N96/192の既存差と比べて混合効果を見積もる。参照で得た馬蹄循環を幅ごとに合計し後縁循環に戻す際は、実座標による並びの検査を行う。

3水準外挿の次数・補正と隣接外挿値の差を保存し、幅系列の誤差相殺がある場合は外挿を認めない。有限N768の値、弦差、幅差、コア感度をすべて別に残す。連続極限は実測による推定で厳密上界ではない。1%の比較に使う際は参照の推定不確かさも加算する。

コアと場の2×2診断は原因の切り分け専用であり、循環と場の半径が異なる結果を合格へ採用しない。製品の辺中点荷重・仕事写像は維持する。
