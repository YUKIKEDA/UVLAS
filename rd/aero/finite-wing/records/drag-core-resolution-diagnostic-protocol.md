# 抗力：コア感度と物質自己辺の診断

2026-11-05。弦を細分化すると最小のcosineセルはMの二乗に反比例して小さくなる。一定SI半径を使った系列が理想核の抗力へ近づくかは、揚力の感度とは別に調べる必要がある。FW-V01、M16/32/64・N96で、ε=0と既存ε=1.1142857e−5mを比較する。ここは指定直線後流の定常試験だけで、自由移流のε>0条件を変えない。

診断用の高速な渦輪組立では、対象の自己辺が自身の前辺だけでなく直前セルの後辺にも現れる。両方を和の前に除外し、採用2.2の一意な物質辺IDによる厳密零と一致させる。理想核で大きな項を評価した後に引き算する方法は使わない。これは診断用高速経路の修正で、正しくID除外していた採用2.2の変更ではない。

[照合](drag-material-self-result.json)で、ε=0/0.02の双方について採用2.2の全束縛＋W-P1一定後流の場に一致し、偽の自己IDも拒否した。次にコアと分解能の作用を分けるため、理想／正則化の循環と場を2×2で組み合わせる。循環と場の半径が異なる二つは誤差原因を分ける診断であり、物理モデルの合格・採用には使わない。

同じ半径の循環と場による二つの結果だけを、近傍／遠方の共通極限の採否へ使う。元の非貫通残差1e−11を維持し、半径を変えた結果と元の未達を共に保存する。
