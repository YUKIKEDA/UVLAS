# UVLM 2.2：後流・組立・状態・荷重の審査条件

2026-11-05。2.1の採用誘導核を変更せず、有限幅・複数面の一つの空力状態へ接続する。今回のEuler移流／BDF1荷重は時刻・依存を固定する検証用経路であり、製品の連成時間積分器の選定は3。

## 一組にする定義

* 束縛はdual-quarter-v1のP0渦輪、後流はW-P1-stream/P0-span。後流先頭μ=TΓ_new、後続は親確定値を一度だけ輸送。B1一定面の旧循環放出と混ぜない。
* 核半径はモデル全体に明示した固定SI値を与える。共有辺で異なる半径を使わない。自由移流の自己評価にはε>0を要求。半径の既定値・感度予算は2.3。
* 全束縛・全後流・既知流れから移流速度を作る。指定移流は別モードとして表示。後縁境界IDと切り離した物質列IDを分ける。
* 循環力は束縛の全対象辺から作り、後縁の構造力だけを除外。誘導源や自由後流へ同じ除外を適用しない。非定常力の面積と荷重点を同じ渦セル三角形から作る。
* コロケーション位置・速度・法線と、辺中点／三角重心の荷重・構造写像を同じ準備版から得る。採用PG-ANCFへの固定物質写像を含める。
* 全域の面交差を調べ、IDで許容した共有点／共有辺の外側の交差、非接続接触を拒否する。有限コアだから接触を適格としない。

## 実施する検証

| 群 | 成立条件 |
|---|---|
| 整数トポロジー・所有 | D1D2=0、共有辺の符号、後縁・帯・物質列のID、全相互影響を確認。重複・不整合を負対照で拒否 |
| 独立組立 | 異なる二つの揚力面・変形面とW-P1後流について、別の面積分／線積分でAと後流作用を比較。1e−8または絶対1e−10、原非貫通残差1e−11 |
| 陰的先頭と循環感度 | [Abb+W0T]で求解。μ0=TΓを確認。全残差の独立微分と暗黙関数からのΓ微分が1e−8以内。先頭を旧Γにする負対照を検出 |
| 移流と輸送 | 自由／指定モード、全相互誘導・自己項、固定した親から一度だけ更新。反復／棄却で物質列・係数・履歴を重ねて進めない。速度・幾何・係数の方向微分1e−8 |
| 荷重と写像 | 全辺力／非定常面力の別積分、合力／基準点モーメント、採用PGへの仮想仕事・パワー、Γ／幾何／速度／流入の全依存を照合。代数1e−10、独立微分1e−8 |
| 初期化・再開・キャッシュ | 冷始動／明示履歴を識別。親・モデル版・コア・幾何・循環・時刻を混ぜない。成功後の変更・古い試行・不適格復元を拒否。復元後の演算子／荷重一致1e−10、失敗で確定状態不変 |
| 全域幾何異常 | 一般位置と同一平面の面交差、共有頂点／辺の許容範囲外、別面の接触・反転・退化を負対照で識別。交差を観測点だけの検査で代用しない |
| 有限末端 | 成長後流と有限窓は別モード。有限窓では退役ID・末端閉鎖・捨てる源を明示し、誤差を0としない。後流長の受入予算は2.3 |

小系の合成右辺は組立検査としてのみ使用し、有限翼の物理精度を保証したと扱わない。定常／非定常・有限幅・後退テーパ・複数面・半径／後流長の独立精度は2.3へ引き継ぐ。失敗があれば同じ条件を保存し、別版で原因を修正する。

循環辺力と非定常力の比較資料は [Lambert–Dimitriadis著者稿](https://orbi.uliege.be/bitstream/2268/200767/1/AIAAjournal_InducedDrag_accepted.pdf)。その式と今回の符号・後縁処理・W-P1の同時刻先頭・物質写像を一組で検査する。原論文の合格結果を今回へ転用しない。
