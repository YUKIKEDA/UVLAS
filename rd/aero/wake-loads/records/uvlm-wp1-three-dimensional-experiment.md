# 有限幅3次元W-P1基底・面内渦層・状態の限定試験

版：0.1、2026-10-30。1〜7節はコード作成・実行前に記載。

## 1. 問題と参照経路

[3D契約](../uvlm-wp1-three-dimensional-contract.md) に従う。単位m、係数μの単位m²/s。3種類の四辺形（前左・前右・後右・後左）は以下。

- 平面：[(1,−.6,0),(1,.6,0),(1.4,.6,0),(1.4,−.6,0)]。
- 後退・歪み平面：[(1,−.6,0),(1.2,.6,0),(1.65,.5,0),(1.4,−.6,0)]。
- 非平面：平面のzを[0,.03,.18,−.08]へ変更。

観測点は[(.65,.1,.2),(1.2,0,.45),(1.6,−.9,.25),(1.25,.9,−.4)]。ε=0/.08、係数(a₀,a₁)=(1,0)/(0,1)/(1,1)。全ケースで、境界48点Gauss＋面内Duffy24×24と、独立面積分Duffy64×64を比較する。各点の速度差は絶対 $10^{-10}$ または相対 $10^{-8}$ 以下。結果は全3成分を保存する。

一定μの渦輪は既存の解析有限線分核とも照合する。L+R=一定渦輪の差も同じ基準。非平面でも分割対角線は固定する。

## 2. 独立なP0細分化

各三角形を4等分し、段階0〜5で一定μ=三角重心値の小渦輪へ置換する。小渦輪は既存の解析核を用い、面内渦層式を使わない。変数μの2基底・3形状・2コアで比較し、4観測点のベクトルをまとめた相対誤差が最細≤0.1%、段階3→4→5で観測次数≥1.7。一定μでは内部辺が相殺するため、丸め差を収束次数へ使わない。

## 3. 変換・縮約・負の対照

非平面セルをRz(.4)Ry(−.3)、平行移動(.3,−.2,.5)で変換し、速度共変を尺度付き $10^{-11}$ 以下で確認。位置とεを2倍にしたとき速度が1/2になること、複素線形性も同じ基準。

ε=0の平面・x=1→1.4・半幅.6、観測点(x,0,0)、x=.2/.75に対し、前回の幅一列の解析L/R係数とz誘導が相対 $10^{-9}$ 以下で一致すること。平面のnや渦線の向きを理論値へ合わせて反転しない。

面内渦層の省略は、少なくとも1つの変数μケースで速度差>1%。ε=.08で柔らかい二重層ポテンシャルの勾配へ無変換で置換する対照も速度差>1%を検出する。

## 4. 共有辺・帯係数の状態

3幾何列×3スパン境界、x=[1,1.3,1.7]、y=[−.6,0,.6]、z(r,j)=.04r+.03rη_j（η=[−1,0,1]）。幾何9頂点・4セルに対してμは3列×2帯の6係数。

同じ両帯にa=[.8,.3,.1]を与えた場合、共有列・内部対角線・内部スパン辺の一次渦線係数が相殺すること。全三角形の辺を個別評価した速度と、共有辺を集約した速度の差≤ $10^{-11}$ 。

帯ごとにa=[[.8,−.2],[.3,.4],[.1,.05]]を与え、μを幾何頂点の平均へ置換する負の対照は速度差>0.1%を検出する。共有辺のε不一致、幾何頂点形状の3×3μ配列を正しい3×2として読む入力は拒否する。

旧確定状態からの2回の試行は同じμ列を作り、旧配列ハッシュを変えない。a₀は試行束縛後縁、a₁以降は旧列から1回だけ輸送する。製品I/O・障害耐久性・自由後流は今回検証しない。

## 5. 有限幅の製造非貫通問題

束縛はc=1、幅2、2弦×2スパン、既存1/4・3/4配置。後流はx=[1,1.2,1.45]、y=[−1,0,1]、z(r,j)=.03r+.02rη_j。核ε=0。未知束縛循環の指定値[.3,.5,.4,.2]、旧後流列a₁=[.2,−.1]、a₂=[.15,−.05]。

束縛P0は解析線分、後流は本候補（境界96点・面内48×48）でAを組立てる。独立参照は束縛辺96点Gauss、後流の面積分80×80から作り、指定未知量の非貫通右辺を製造する。 $A_{bb}+W_0T_{TE}$ を解き、指定循環の相対差≤ $10^{-8}$ 、残差≤ $10^{-11}$ 。これは製造右辺の演算子接続試験で、実際の有限翼の物理荷重・自由後流解の証拠としない。

## 6. 不適格入力と自己評価

面内点・辺上点・頂点の非incident接触はε=0/.08の両方で拒否。退化三角形、負のε、非有限点も拒否。自己評価要求は未選定として拒否し、全自己項0の代用はしない。この局所判定を全域の交差・折返し検査へ一般化しない。

## 7. 予算・保存・用途

180秒・512 MiB。ソース・依存ハッシュ、核・向き・分割版、幾何と係数・観測点、全比較差・収束・不正入力・製造循環解・試行不変性、NumPy/SciPy、時間とピーク作業集合を保存。未達・例外・予算超過は保持し、しきい値を事後変更しない。

合格しても一般3Dの自己誘導・自由後流・近接／交差・物理的な実務翼荷重、構造連成・全接線・再開とJ1を採用済みとはしない。既存の束縛荷重・作用点・双対写像へ速度を渡すI/Fまでを具体化し、後流に構造力を追加しない。

## 8. 初回の型処理と幅一列求積の追加条件

最初の実行は、面積分参照へ渡したPython listをNumPyのdtype推定へ直接渡して停止した。[初回停止記録](uvlm-wp1-three-dimensional-initial-status.json) と `build/analysis/check_uvlm_wp1_three_dimensional_initial.py` を保持し、入力配列化だけを修正した。式・幾何・判定基準は変更していない。

その後の [基礎試験結果](uvlm-wp1-three-dimensional-result.json) は17判定中16成立・1未達。幅一列のL/R還元の相対差は $8.15\times10^{-10}$ ／ $1.70\times10^{-9}$ で、右基底が $10^{-9}$ 条件を満たさなかった。

追加実行前に、同じ平面・観測点・ε=0・L/R係数について、境界48点は固定し、面内求積24/48/96で照合すると定める。独立面積分は96×96、幅一列解析式も従来どおり。最細96の解析L/R差≤ $10^{-9}$ 、48→96の速度変化≤ $10^{-11}$ 相対、独立面積分との差は絶対 $10^{-10}$ または相対 $10^{-8}$ 。別コード・別結果へ記録し、初回未達を上書きしない。予算60秒・256 MiB。物理位置・法線・コア・式・しきい値を合わせ込まない。

## 9. 実施結果と判定範囲

[基礎コード](../experiments/check_uvlm_wp1_three_dimensional.py) と [基礎結果](uvlm-wp1-three-dimensional-result.json)、[追加コード](../experiments/check_uvlm_wp1_planar_reduction.py) と [追加結果](uvlm-wp1-planar-reduction-result.json) を保存した。基礎17判定は16成立・1未達のまま保持し、追加3判定はすべて成立。追加をもって初回24×24求積も合格したとは扱わない。

| 照合 | 結果 | 解釈 |
|---|---|---|
| 境界＋面内渦層と独立面積分 | 3形状×2コア×3係数、最大相対差 $1.29\times10^{-12}$ | 今回の面外観測点で一致。各点の絶対／相対条件も成立 |
| 一定μの解析渦輪 | 6ケース、最大相対差 $3.13\times10^{-15}$ | 一次基底の和も一定渦輪へ戻る |
| 独立P0小渦輪への細分化 | 12系列、最細の最大相対差0.0179%、最終2段の最小観測次数1.999 | 面内渦層式を使わない経路でも二次収束 |
| 回転・平行移動、相似拡大、複素線形性 | 最大相対差 $7.08\times10^{-15}$ | 座標系と係数の線形性を確認 |
| 共有辺の集約 | 最大相対差 $5.04\times10^{-16}$ 、一致トレースの内部係数0 | 帯をまたぐ不一致トレースは残す |
| 先頭陰的項を含む製造非貫通問題 | 循環解相対差 $1.08\times10^{-12}$ 、残差 $2.02\times10^{-16}$ | 4未知束縛循環と4×2の先頭後流作用素の接続確認 |
| 不適格入力 | 10件すべて拒否 | 面上接触を有限コアで黙認しない |

面内渦層を省く負の対照は最大211%の差、柔らかいスカラーポテンシャルの勾配を既存渦線核と混用する対照は有限コアで最大7.90%の差を生じた。幾何頂点へ帯μを平均する対照も28.5%の差を生じた。この3点は表現・核・状態I/Fの禁止事項を裏付ける。確定状態は変化せず、同じ親状態からの2試行で同じ輸送結果を得た。

幅一列への追加還元では、面内96×96のL/R解析差は $1.16\times10^{-14}$ ／ $6.24\times10^{-15}$ 、48→96の変化は最大 $2.53\times10^{-15}$ 。同じ観測点で独立面積分との差も最大 $6.40\times10^{-15}$ となった。初回未達はこの設定での求積誤差として切り分けられた。ただし「96点なら任意の近接形状でも適格」という一般規則にはしない。

基礎実行は0.625秒・ピーク88,596,480 bytes、追加は0.031秒・83,853,312 bytesで、各事前予算内。NumPy 2.3.5、SciPy 1.16.3。結果JSONにソースと依存ファイルのSHA-256を保存した。

## 10. 次の設計・検証ゲート

次は有限幅翼について、独立参照を持つ物理荷重の比較仕様を作る。翼形状・翼端・後流長・打切り・コア・束縛荷重作用点と、揚力分布／合力／モーメントの参照を揃え、空間・求積・後流長の誤差を分けてから規定運動の時間応答へ接続する。特に今回の初回未達を受け、観測点と面の距離に対する求積誤差の判定、近接時の分割と失敗通知を先に定義する。固定次数のみを根拠に製品評価器を実装しない。
