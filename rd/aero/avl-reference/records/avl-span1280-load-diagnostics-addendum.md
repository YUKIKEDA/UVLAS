# 格子読込み試験の整数表示範囲

2026-10-31、読込み試験の実行前に固定。ainput.fの通常consoleは帯数・渦数をI4で表示する。N1280のM3／6／12は1920／3840／7680が表示可能だが、M24の15360は `**** Vortices` となる。これはKSMAX超過のSTOPとは異なり、読込み成功後の表示幅の制限である。通常出力の書式を今回の容量修正に混ぜない。

[局所容量仕様](avl-span1280-ksmax-addendum.md) の読込み試験では、全8件で640 Stripsと最後のメニュー帰還を確認し、小弦6件では渦数も数値一致させる。M24の2件はソースで確認したI4の表示幅に対応する星4個を記録し、consoleだけでは未知数を数値確認できないと明記する。実際の未知数15360は本計算のUH meta・行数で必須確認する。星表示を数値解の適格性や精度の証拠にはしない。
