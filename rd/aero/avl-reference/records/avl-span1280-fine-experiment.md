# N1280の実行・観測接続：追加事前仕様

2026-10-31。[容量仕様](avl-span1280-capacity-experiment.md) の資源上限・停止条件・8ケースを変更せず、専用ランナーと観測処理を定義する。新しい計算を始める前に固定する。

## 1. 入力と開始ゲート

容量回帰8件、対称等価性、保存観測の成果物監査が成立し、ソース／実行体／親入力のハッシュが一致した場合だけ開始する。今回の16000版N640入力の正側11断面を保持し、全SECTIONの分割32→64、弦分割24→M3／6／12／24だけを置換する。物理N1280、半翼640帯、未知数1920／3840／7680／15360である。小さいMから、同じMではFW-V01→02の順に逐次実行する。

本番前に、同じ監視関数を使って時間超過・RSS超過・出力超過・空き不足・swap増加・cgroup不明を製造入力で確認する。実プロセス群の時間制限停止も短いPython子プロセスで確認する。既存の資源パーサ6試験と区別する。停止時には不完全なファイルを保存し、後処理へ渡さない。

## 2. 実行・保存

各1200秒・全2400秒・群RSS16GiB・開始有効空き20GiB・残量2GiB・swap増加256MiB・出力512MiB・console各8MiBを維持する。監視は0.2秒間隔。swap増加は段階開始時とケース開始時の両方に対して測る。上限検査と記録は開始前・監視中・終了後に行う。cgroup制限不明なら開始しない。監視の停止はOSによる厳密な隔離ではない。

前回と同じ設定、α=1度の静的ケースを解き、FT／FS／FEとUHの元行・力・帯・ガード・metaを2回保存する。計測前後はバイト一致を要求する。実行中も45秒程度ごとに経過時間・群RSS・有効空きを表示し、完了ごとに部分マニフェストを更新する。未完了マニフェストを正常完了と扱わない。元の参照、回帰、旧N640結果は上書きしない。

## 3. 保存観測と予算

16000版の今回の回帰からM24・N160／320／640を採り、新しいM24・N1280を加えてスパン系列を作る。弦系列はN1280・M3／6／12／24。両翼の14場、4系列、12場対を処理する。native-halfとderived-by-symmetryを別保存し、残差1e−11、全域／帯恒等式・元力／モーメント1e−10、法線x成分0を要求する。後処理120秒・1GiB。

5チャンネルの差減少・次数0.5〜6・最終2次数の変化0.5以下・両方向余弦0.9以上・丸め床は変更しない。候補となった場合だけ条件付き尾部を計算する。同じM24N1280基準点で弦／スパンを線形和し、揚力0.3%・帯分布0.5%・元点モーメント0.3%を評価する。必要な方向が未達なら対応値はnullとする。固定された帯観測の推定であり、点ごとの相対誤差や未知の連続解への保証ではない。

二つの保存場間の上限は独立に検査する。外挿の成立、方向間尾部、モデル誤差の保証へ昇格させない。今回の結果だけで参照全体の採用を自動更新せず、残る証拠条件を結果文書で明記する。
