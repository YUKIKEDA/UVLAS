# 対称静的参照の縮約：実施結果

2026-10-31。対象はFW-V01／FW-V02の対称形状、迎角のみの静的応答。全翼との照合を経て、限定した対称参照経路を使用できることを確認した。初回の未達は保持し、参照全体の精度受入は更新しない。

## 1. 事前仕様と照合対象

[縮約事前仕様](avl-symmetry-reduction-experiment.md)、[π精度追加仕様](avl-symmetry-spacing-pi-addendum.md) に従った。半翼計測のUHコマンドは、全翼の基準面積・長さ・原点を維持し、対称面・横滑り・回転・成分・境界条件等を限定する。共通ガードの局所試験21件は正常2件と拒否19件を含む。

AVLの対称モードは総量を倍化し、横力等を明示的に0にする。その総量だけでは検証しない。元の半翼の循環・法線・辺端点・既知／誘導速度・元作用点・各渦線力を保存し、負側の辺端点と左右脚を入れ替えて物理全翼へ展開した。モーメントは軸性ベクトルとして変換する。派生ファイルはnative-halfと別保存し、親ハッシュ・実求解未知数・物理パネル数を記録した。

両翼のM6N40、M24N160、M24N320を、独立した全翼計算と照合した。小系では元の係数行列から全翼のブロックと半翼行列、右辺も照合した。対称な出力への平均や座標投影は行っていない。

## 2. 初回の未達と原因

[初回14プロセス](avl-symmetry-regression-runs.json) の結果は [初回照合](avl-symmetry-equivalence-initial-result.json) に固定した。6格子の幾何差は最大約1.79590e−11で、事前の1e−11条件を超えた。他の循環・速度・力・小行列検査が成立しても、N640には進めなかった。

原因はAVLのSPACERにある `DATA PI /3.1415926535/` だった。正負の断面から生成した分点で、このπ誤差が鏡映不一致を生む。[独立分点検査](avl-spacing-pi-result.json) はDecimalのMachin公式とTaylor展開を用い、予測1.79586568e−11 mに対して観測1.79589676e−11 mを得た。4条件は全て成立した。

元版を保存し、全翼・半翼の双方に同じSPACERのπ精度修正を施した別版を作った。識別子は `AVL3.52/DP/zero-core-exterior-stable/spacing-pi64-v1`。既存のゼロコア核修正版を基礎とし、今回の格子修正はsgutil.fのPI定数だけである。核のPI4INV定数や物理断面は変更していない。[準備記録](avl-symmetry-pi-preparation.json) にコピー間の差分と実行体を保持した。

追加仕様の初版で旧／新格子の比較にも同じ1e−11を適用した記述は、修正後の全翼／半翼計算を始める前に訂正した。[追加仕様初版](avl-symmetry-spacing-pi-addendum-initial.md) は保持している。意図した旧／新分点移動には解析包絡1.79686369e−11 mを使用し、**修正版の全翼／半翼一致条件1e−11は変更していない**。力等の旧版感度条件も維持した。

## 3. 修正後の照合

[修正版18プロセス](avl-symmetry-pi-regression-runs.json) は全翼6件・半翼の非計測基準6件・半翼計測6件。計測前後、および半翼基準版と計測版の通常出力はバイト一致した。[照合結果](avl-symmetry-pi-equivalence-result.json) の8条件が成立した。

| 照合量 | 最大絶対差 |
|---|---:|
| 幾何・法線 | 1.85824e−14 |
| 循環Γ/U | 1.31102e−15 |
| 元の渦線力F/q | 2.02583e−16 |
| 小系の半翼行列と全翼ブロック和 | 1.29674e−13 |
| 小系の右辺 | 6.93890e−18 |

全6格子の循環・速度・作用点・力・全域／固定帯観測・残差も条件内だった。旧版との差は、座標について解析包絡、その他について固定した感度条件内。回帰の合計317.87秒、ピーク3,421,511,680 bytes、保存102,147,601 bytesで資源条件も成立した。

## 4. 使用範囲と残る受入

以上を根拠に、同じπ版の [N640追加計算と保存観測](avl-symmetry-fine-observation-results.md) に進んだ。N640の全翼を直接解いた証拠ではなく、N320までで検証した対称縮約の使用である。一般の非対称形状・荷重、非対称モード、動的安定性、フラッタには適用を拡張しない。

[成果物監査](avl-symmetry-artifact-audit.json) は、初回未達・分点検査・修正版照合・追加計算のソース／入力／実行体／派生ファイルのハッシュと資源条件を照合した。縮約の成立は、未知の連続解への誤差保証やUVLAS製品実装の受入とは別である。
