# 対称照合の幾何未達とスパンπ精度：追加事前仕様

2026-10-31。[初回対称照合仕様](avl-symmetry-reduction-experiment.md) の6全翼照合は、循環・力・行列が条件内でも幾何差約1.7959e−11 mが1e−11を超えたため未達とした。初回生データ・派生データ・ソース・判定を保存し、N640は実行していない。

## 1. 原因仮説と独立確認

sgutil.fのSPACERだけがπ=3.1415926535を使い、cosineの中点が正規化座標1/2から約2.245e−11ずれる。幅0.4mの逆向き区間を鏡映すると約1.796e−11mの差になる。これは原ソースの分点生成の問題で、後処理の鏡映平均で消さない。CSPACERの弦分点は既に4*atan(1)を使っている。

SPACERを独立ドライバからN=3/5/9/17/33/65、PSPACE=1で呼び、元と修正を出力する。独立のDecimal80 Machin公式とcos Taylor級数で正規化分点を評価する。πは160桁でも照合し、80→160差は1e−75以下。修正分点の絶対差5e−16以下、正規化鏡映差2e−15以下。元の中点ずれから予測する幅0.4mの鏡映差は、初回の最大y差と絶対1e−15以内で一致することを要求する。

## 2. 変更する参照と回帰

元の容量8000親版と対称計測版のそれぞれを別コピーし、SPACERのDATA PIだけを3.1415926535897932384626433832795へ変更する。同じ8-byte REAL設定でsgutilだけを再コンパイルし再リンクする。核のPI4INV、数式、コア、入力断面、容量、UH計測・適格性関数は変更しない。版IDへspacing-pi64を含める。

修正した計測版で、6条件すべての全翼と半翼を再計算する。半翼6条件は修正した親実行体でも計算し、FT/FS/FEのバイト一致とUH前後不変を確認する（計18プロセス）。修正全翼と修正半翼は元仕様の同じ幾何1e−11・行列・循環・力・保存しきい値で照合する。

さらに修正全翼と元の全翼の違いを全6条件で保存する。この2版は意図的に分点が異なるので、座標差はcosのLipschitz性から得る区間幅×|π_old−π|/2＋演算丸め1e−14mの解析包絡と照合する。区間幅0.4mなら約1.80e−11mである。新全翼対新半翼の幾何1e−11は変更しない。循環・力・速度・係数差は元の全翼照合と同じ許容差とし、微小な幾何改善を物理精度改善や格子収束の解消と混同しない。

この区別は修正後の全翼／半翼の再実行前に明記した。[初期の追加仕様](avl-symmetry-spacing-pi-addendum-initial.md) は意図的に異なる旧格子との座標比較にも同一性の許容差を記載していたため保存して訂正した。旧格子を正解として合わせることも、旧格子の等価性を主張することもしない。修正分点自体は1節の独立な高精度基準で判定する。

## 3. ゲートと追加N640

独立分点、6修正全翼／半翼照合、2小規模行列、6元全翼との感度、適格性と測定不変がすべて成立した場合だけ、修正した半翼版でN640を実行する。初回ゲートの未達は変更せず、別ゲート・別生データにする。既存N80/160/320は元π版であり、N640と同じ版と偽らない。修正版のN160/N320を参照へ接続し、必要なN80も修正版の半翼2計算で確保してから4段階の収束を評価する。N80も元全翼と同じ許容差で照合する。
