# スパン次数変動の保存データ診断：事前仕様

2026-10-31。[N1280結果](avl-span1280-results.md) の次数変動を受けた事後の原因診断。結果の次数は既に見ているため、以下のモデル比較を未知データへの盲検予測とは呼ばない。追加AVL計算、格子・許容差の変更、尾部推定や参照受入の更新は行わない。

## 1. 対象と符号

同じKSMAX修正版のM24・N160／320／640／1280、両翼の8場を、保存された20帯から評価する。5チャンネルの重みは既存のτ/K観測と同一。差は細格子−粗格子とし、N1280観測JSONのノルム・次数・方向余弦を独立に再現する。元の場・結果は変更しない。

揚力・有限辺／元点モーメントは各帯の符号付き係数差を合計する。正負の和、絶対和、相殺比＝絶対値付き総和／絶対和を記録する。分母0は未定義とする。チャンネルのノルム二乗は帯ごとに分解し、根元（帯中心の絶対値0.8以下）、翼端（3.2以上）、その他へ加算する。τのP1は平均と一次成分のエネルギーを同じ帯へ加算する。局所次数は同符号かつ両差がチャンネル尺度の1e−12を超える成分だけに付け、符号反転と微小値を区別する。

連続する差の方向への直交分解も保存する。これにより、ノルム比の変動と空間形状の変化を区別する。元点モーメントではτの位置重み、K、補正偶力の帯寄与も別集計し、同じ元点モーメント差を再現する。

## 2. 仮説モデルの反証診断

基準格子幅を h=160/N とする。次の形だけを今回の比較対象に固定する。

$$
v(h)=v_*+a f(h)+b g(h),\qquad
(f,g)\in\{(h,h^2),(h^2,h^3),(h^2,h^4),(h^2,h^2\log_2 h)\}.
$$

最初の2格子差だけでベクトル係数a、bを求め、3番目の差を予測して実データと比較する。スカラーの合力／モーメントにも同じ演算を行い、分布全体のモデル適合と区別する。設計行列・条件数・予測相対残差・方向余弦・モデル内の2項の相殺比を保持する。整数べきとlog2 hの値は今回の4格子では有理数となるため、Fractionで予測重みを求め、float64の2×2解と独立照合する。

単一べきp=1／2／3／4、および最初の2差のノルム比から得た一定次数も比較する。仮説間の最良値を新しい外挿次数や誤差上界へ変換しない。全3差から3項を解けば一致させられる場合があるが、その当てはめを予測検証に数えない。ここでは未知の極限値を出力しない。

## 3. 製造ケースと拒否

各2項モデルの既知ベクトル列、反対符号のh／h²項による次数増加と次の符号反転、未モデル化の第3項、スカラー相殺で見えない非ゼロ分布差、一定場を検査する。4点で0だが極限で0でない既知多項式も使い、有限サンプルだけで未知の極限を一意に決めないことを明示する。非有限値、形状不整合、規定外の格子列、未知のモデル名を拒否し、入力不変を確認する。

製造列の予測誤差は1e−12×max(1,入力尺度)以内。Fractionとfloat64の予測差は1e−12×max(1,差の尺度)以内。実データの帯集計・モーメント分解・ノルム再現・領域加算も同尺度の1e−12以内を要求する。実流れのモデル残差には合格しきい値を設けず、数値そのものを報告する。

## 4. 資源・成果物

診断120秒・512MiB・出力16MiB。親JSON・入力帯・ソース・依存のハッシュ、製造試験、拒否条件、各差と帯寄与、全モデル比較を保存する。数値・空間図は保存値から作り、独立監査と数式／リンク検査を行う。新しい参照計算の必要条件を結果に記し、現段階の未評価予算とJ1の状態は維持する。
