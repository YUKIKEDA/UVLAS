# 固定帯参照：細分格子のコア極限

2026-11-05。M8/N768の帯比較では、参照半径1e−7mの感度が最大約7.6%で、先の有限追加は不合格。N192で小さかったコア感度をN768へ流用しない。原結果と不合格判定は保持する。

一方、1e−8→1e−9mの最大帯差は約0.016%。参照コードの入力半径を1e−10mまで各翼1回追加し、3水準の収束域を確認する。1e−9→1e−10の差が前差より小さく、0.05%未満なら最小側を参照値として採用候補にする。1e−7の結果を削除せず、未収束側として明示する。格子・核式・荷重式の変更は行わない。

幅N192/384の参照は既存1e−8mで評価し、N768での1e−8→極限側の補正を明示して空間差へ加算する。コア影響の不安定な大半径を精度の不確かさとして無制限に足すのではなく、独立に成立した収束域の差から見積もる。20帯2%の判定条件は維持する。
