# 保存観測の追加スパン細分化：事前仕様

2026-10-31、版0.1。τ/K保存観測の40格子診断で、弦方向は候補となったがスパン方向が未評価であることを受けた追加実験。以下1〜6節を追加コード・ビルド・数値実行前に固定する。元の入力・結果・しきい値は変更しない。

## 1. 同じ物理翼と追加2入力

帯境界適合族のFW-V01/V02、M24N320、α=+1度の2条件を追加する。既存21断面、弦24、各0.4m区間のスパン分割16・cosine配置を使う。断面座標・弦長・キャンバ0・ねじり0・密度・流速・軸・後流・コアは既存と同じ。既存M24N40/N80/N160と合わせ、N40/80/160/320の比2の4段階を作る。旧N20を含む系列は未達のまま保持する。

入力は既存生成器と同じ17有効数字・CRLFで別ディレクトリへ保存し、面積・物理断面の不変性とハッシュを確認する。既存入力や親マニフェストを上書きしない。

## 2. 参照専用の容量拡張

既存source-core0-gridの別コピーsource-core0-grid8000を作る。変更はavl_heap_inc.f90のNVXとADIMEN.INCのNVMAXの5000→8000だけ。数式・核・定数・COMMONの他パラメータ・オプション・計測処理は変更しない。全依存Fortran単位を同じGNU14.4.0／通常REAL8の設定で再ビルドし、明示DOUBLEのLAPACK補助だけは通常8-byteのままとする。

製品の上限・メモリ要件を変更したものではない。旧参照2GiB予算と結果は保持する。今回の別実験は4GiB・逐次1プロセスを上限とし、開始前に6GiB以上の空き物理メモリを確認する。今回の準備時点で約23.3GBの空きを確認した。

## 3. 既存出力の回帰

2翼について既存のM6N40とM24N160、α=+1度の計4条件を容量拡張版で再実行する。FT/FS/FE、UGの循環行・渦線力・帯境界が旧実行体とバイト一致することを要求する。追加2条件へ進む前に4回帰を完了する。全条件でUG前後の通常出力もバイト一致することを要求する。

容量拡張に伴う出力差・例外・上限超過は未達として保存し、鏡映平均・循環補正・しきい値緩和で回避しない。上限変更の差分・全ソース・ビルド・実行体・入力・セッション・資源のハッシュを保存する。

## 4. 計測と保存観測

追加2条件で有限・元の非貫通残差相対1e−11以下、全力／モーメントの和の係数差1e−10以下を要求する。既に検証したτ/K・帯P1/P0・有限辺モーメント・元RV偶力の処理を変更せず適用する。独立な有限辺分布観測との帯差は1e−10以下。

2翼のN40/80/160/320について、τの帯平均・帯P1、Kの帯平均、有限辺／元点モーメント密度の5チャンネルを診断する。既存と同じ減少・最終pが0.5〜6・次数差≤0.5・余弦≥0.9、丸め床1e−10を使用する。成立した場合の外挿は仮定付きと明示し、未知の真の解への保証に変えない。

## 5. 誤差予算の再評価

弦系列は同じ最細M24N160の既存系列、スパン系列は追加N320までの系列である。端点が異なるので、その2推定を黙って同じ基準場の誤差として足さない。

まず各推定の基準点を明記する。M24N160に対するスパン推定は最終次数pを仮定し、N320推定の2^p倍として記録する。これを弦推定と線形和する経路は、同じ漸近展開・方向分離の仮定付き評価である。仮定と端点移送、未検証の混合項を返し、参照採用を自動更新しない。既存の総量0.3%・固定帯0.5%の目標は変更しない。

不成立なら未評価理由を列挙する。成立しても角度・コア・係数精度・混合項・観測適用範囲の残課題を確認してから参照適格性を別途判断する。

## 6. 実行予算と停止

ビルド300秒。4回帰＋2新規の実行合計900秒、各300秒、各ピーク4GiB、追加出力128MiB。新規計算は逐次実行し、開始前の空きメモリ不足は停止する。後処理120秒・512MiB。途中結果と未達・初回エラーは保存する。追加AVL参照であって、UVLASの実務精度や性能の受入ではない。
