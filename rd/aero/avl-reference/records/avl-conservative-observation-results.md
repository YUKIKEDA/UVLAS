# τ/K保存観測・帯モーメント・荷重差上限：実施結果

2026-10-31。[事前仕様](avl-conservative-observation-experiment.md) に基づく [結果JSON](avl-conservative-observation-result.json) と [監査](avl-conservative-observation-artifact-audit.json)。元の循環・物理翼・力点・点集中の帯分類・過去の未達は変更しない。

## 検証結果

9検査項目すべてが成立した。

| 検査 | 結果 |
|---|---|
| 製造した非整列帯 | 4ケース、独立Gauss積分との差最大1.39e−16 |
| T₁を省く負の対照 | モーメント係数差最大0.001024を検出 |
| 偶力を省く負の対照 | モーメント係数差最大0.01190を検出 |
| 不適格入力 | 重みの折れ線・退化／逆順帯・非有限偶力・寸法・基底・領域不一致の7件を拒否 |
| 40格子のτ/K荷重恒等式 | 元の前線／力点荷重・前回台帳との差最大8.89e−16 |
| 独立な有限辺分布＋偶力の帯観測 | 20帯の係数差最大5.56e−17 |
| 帯P1のT₀/T₁保存 | 最終float64記録の差0 |
| 36格子対×8種類の荷重差上限 | すべて成立。射影L2ノルムの非増大も成立 |
| 資源 | 3.25秒、ピーク124,260,352 bytes、結果JSON 713,323 bytes |

上限は保存された2場の差に対するもの。真の連続解に対する誤差上界ではない。初回は負の対照用の前線が翼外にあり、観測帯の拒否検査へ到達する前に停止した。[初回結果](avl-conservative-observation-initial-result.json) とソースを保持し、翼内の前線に修正して同じ判定条件で再実行した。元の実データは初回停止時に未処理だった。

## 観測の意味と収束状態

τの帯平均、τの帯P1、Kの帯平均、有限辺モーメント密度J、元点対応J_cを別チャンネルとして扱った。τ/Kの単位を混ぜた合成ノルムは使っていない。帯観測は既存span-wrench-P0-v1の一次荷重と整合する保存表現であり、元point-force-v1の帯分布へ置き換えたものではない。

4つの族・翼の組合せでは5チャンネルすべてで弦方向が漸近候補となった。スパン・対角は未達。全60チャンネル系列の候補は20だった。FW-V01の最終隣接差の相対値を示す。

| チャンネル | 元・弦 | 元・スパン | 帯適合・弦 | 帯適合・スパン |
|---|---:|---:|---:|---:|
| τ帯平均 | 0.03573% | 0.2094% | 0.04062% | 0.1472% |
| τ帯P1 | 0.03607% | 0.3175% | 0.04141% | 0.1492% |
| K帯平均 | 0.1027% | 0.2051% | 0.1326% | 0.2181% |
| J | 0.04301% | 0.2573% | 0.05905% | 0.1489% |
| J_c | 0.04303% | 0.2512% | 0.05908% | 0.1634% |

方向ごとの格子差が小さくても、誤差上限として採用した数値ではない。スパン推定が未評価のため、弦＋スパンの誤差予算は4組×5チャンネルすべて未評価とした。不足分に0を代入していない。
