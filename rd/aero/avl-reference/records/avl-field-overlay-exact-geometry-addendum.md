# 共通細分の厳密有理数幾何：追加仕様

2026-10-31。[元の事前仕様](avl-field-overlay-experiment.md) の初回実行後、Decimal80で2,352,021領域のうち1,617,849領域が1e−60 m²未満となることを確認した。共有端点や一致する前線の有限桁計算により、極小領域が生じ得る。積分への寄与の小ささからL∞の適格性を推定しない。初回結果は保持する。

この追加仕様を修正コード・再実行前に固定する。元の6検査・製造解・40格子・12系列・収束判定を変更せず、幾何演算だけを以下へ強化する。

1. 元float64座標・物理翼のパラメータはFraction.from_floatで正確な有理数へ変換する。前線の係数、交点、順序、面積を有理数で厳密に計算する。近接を理由に別の線を統合せず、真に一致する幾何の零面積だけを除く。
2. 候補抽出には元と同じfloat64の交点候補と近接線対を使い、包含と交点は厳密演算で判定する。候補抽出の製造試験には、非二進表現のy=1/3相当のfloat64端点を共有する折れた2前線と、完全に同じ有理数直線を異なるスパン分割で表す場合を追加する。同値場のL∞差は厳密に0でなければならない。
3. 負の有理数面積は丸めとして処理せず全て失敗。最終的な面積のfloat64投影、係数の累積と積分のmath.fsumは元仕様どおり。変換後の正面積がfloat64で0へ落ちれば未達とする。
4. 初回と再実行のL1/L2・積分と、L∞・領域数を別々に比較する。L∞に差があれば初回の同指標は採用しない。ノルム・判定を都合よく選択しない。
5. 予算は再実行600秒、512MiB、追加64MiB。元結果・元ソース・修正後結果と依存ハッシュを保持する。厳密なのは入力された有理数幾何の演算であり、物理翼や循環解の正しさ全体の保証ではない。
