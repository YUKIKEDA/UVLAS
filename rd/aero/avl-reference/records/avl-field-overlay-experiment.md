# 基底変換・共通物理場の積分と40格子比較：事前仕様

2026-10-31、版0.1。[比較場契約](../steady-horseshoe-ring-comparison-contract.md) の限定試験。以下1〜6節を実装・実行前に固定する。過去の参照収束未達やしきい値を変更しない。

## 1. 同一幾何の基底試験

求解感度実験の48/192未知量2系で帯ごとの累積P・差分Dを作り、DP=PD=I、元循環の往復、保存行列からのA_HDと独立な閉じた4辺渦輪を比較する。最終行は後縁までの4辺渦輪＋同じ後縁からの半無限馬蹄渦。有限辺の独立実装は既存の非正則化線分核、半無限脚は独立ペア式を使用する。元PI4INVに合わせ、制御点で自己有限辺を除外しない。

行列差は絶対1e−10 m⁻¹＋相対1e−10、循環・線形出力の尺度付き差は1e−10以下。強さだけ累積し観測重みを変換しない負の対照は、出力差1e−3超で検出する。条件数の変化を物理精度の改善として判定しない。入力A、幾何、循環は不変。

## 2. 共通細分の実装範囲と精度

同じ区分線形な投影翼領域と、スパン帯ごとの直線前線・係数を入力とする。各場の内部前線は非交差・順序付き。別の場の前線との交差は共通細分に含める。帯境界、翼の折れ線、必要な観測境界と前線交点で分割し、一定値領域の面積積分を計算する。

元float64端点をDecimal.from_floatで読み、前線の係数・交点・領域面積はDecimal80で計算する。浮動小数点の交点候補抽出には近接した直線対も含め、候補の最終包含・順序はDecimalで判定する。元座標の丸め、線の統合、平滑化、細領域の無断除去をしない。80桁の演算丸めで生じる絶対1e−60 m²以下の負面積だけを数値丸めとして0へ戻し、その総量を記録する。それ以外の負面積は失敗。

面積・元場の積分保存は絶対1e−10、製造解のノルム・内積・固定セル積分は絶対1e−10以下。Decimalで求めた面積をfloat64へ投影し、各場の係数の加算と最終積分はmath.fsumを使う。全処理を高精度線形求解と称さない。差のL∞は正面積領域のみの本質的上限とし、ゼロ面積境界上の片側値は使わない。

## 3. 製造解と失敗条件

単位正方形で次を検証する。定数場、x=1/4で2へ跳ぶ段差、同じ段差をスパン／係数分割した同値表現、x=1/2とx=yの2場、x=1/2＋2⁻⁴⁰の微小移動、3場／4場の内積と差分方向。x=1/2とx=yの差はL1=1/4、L2²=1/4、両場の内積3/8。微小移動の差はL1=L2²=2⁻⁴⁰、L∞=1。定数と段差の積分は解析値で照合する。

320固定セルの面積と段差積分は独立な矩形／三角形の解析積分と照合する。単純な粗い中点標本では微小移動を0と誤る負の対照も保存する。非有限、帯の隙間・重なり、内部前線の逆順／交差、異なる物理領域／基底ID、退化帯を拒否し、入力・既存出力のハッシュ不変を確認する。

## 4. 既存40格子への適用

元／帯適合の2族×2翼×10格子、α=+1度の既存データだけを使う。有限辺の左右yとz、翼の前後縁、前線順、帯被覆を確認する。翼の参照幾何との差は絶対1e−11 m以下、帯間の隙間・重なりは認めない。元端点から前線を構成し、参照翼へ投影しない。

各格子で全域ψ積分、L1/L2/L∞、320セル平均、後縁トレースを計算する。後縁トレースからの一次揚力、有限辺線積分のモーメント＋元RVへの補正偶力を、前回の循環荷重台帳と絶対1e−10以下で照合する。有限辺と偶力は独立に記録する。

各族・翼について弦／スパン／対角の4段階系列を調べる。隣接場のL1/L2/L∞、後縁トレース差、固定セル平均差、3格子共通細分からの隣接差分の内積を保存する。全域L2の相対尺度は最細場L2、後縁L2は最細後縁トレースL2、セル平均差は面積重み付き最細平均L2。分母0では相対値なしと絶対値を返す。

## 5. 収束診断と解釈

比2の系列の差d₁,d₂,d₃からp=log₂(||d前||/||d後||)を計算する。減少・最終pが0.5〜6・2つのpの差≤0.5・隣接差の方向余弦がともに≥0.9を既存と同じ漸近候補条件とする。差が全て最細尺度の1e−10以下なら丸め床候補として区別する。0差を対数へ入れない。

この条件を全域場／後縁／固定平均へ別々に適用する。これは格子差の診断で、独立な連続解に対する物理精度の受入ではない。元の荷重収束の未達を、場の別ノルムや有限辺モーメントへ置き換えて取り消さない。基底・積分試験が失敗した場合、物理格子の診断を有効としない。

## 6. 保存と予算

親JSON・全使用入力・依存ソース・固定仕様のSHA-256、基底試験、製造解、拒否結果、40場の観測・系列差・共通細分面積／領域数を保存する。新規AVL実行や製品コード変更はない。後処理600秒、ピーク512MiB、追加保存64MiB。時間・容量・例外・未達は途中記録を残して停止し、しきい値を緩めない。
