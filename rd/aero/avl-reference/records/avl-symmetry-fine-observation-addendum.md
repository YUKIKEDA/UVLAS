# π修正版の細分化・保存観測接続：追加事前仕様

2026-10-31。[π精度追加仕様](avl-symmetry-spacing-pi-addendum.md) の修正全翼／半翼ゲートが成立した場合だけ実行する。以下を細分化コード・実行前に固定する。現在の回帰18プロセスやその判定は変更しない。

## 1. 同じ版の4段階

スパン系列N80/160/320/640を、全て同じspacing-pi64半翼版から物理全翼へ展開したデータで作る。元π版を同じ系列に混ぜない。N160/N320は新しい全翼／半翼照合の半翼計算、N80は追加アンカー、N640は追加細分化を使う。

弦系列M3/6/12/24・N160も同じπ版で確保するため、M3/M6/M12の半翼を両翼で計6計算追加する。M24は照合済みデータを使う。これら6アンカーも元全翼とのπ変更感度を記録し、座標は解析包絡、Γ／速度／力／保存観測は元仕様の許容差で照合する。

さらに同じ最細基準点で両方向を直接評価できるよう、M3/M6/M12・N640の半翼6件も追加する。全て未知量3840以下である。最終追加段階はN80の2件＋N160弦アンカー6件＋N640の8件、計16件。N80／N160アンカーはN640に先行して計算する。これは細分化実行前の追加であり、結果を見て選択した格子ではない。独立分点・6全翼照合・小行列・旧版感度・出力不変性ゲートが未達なら全て実行しない。

## 2. 物理データと判定

native-half、derived-by-symmetry、実際に解いた未知数、物理パネル数、反射規則と親ハッシュを保存する。N640は解いた未知数7680、物理パネル15360。Native FTの総量は物理全翼を表すが、行・力は半翼であることを明記する。

残差1e−11、全域／帯保存1e−10、適格性・測定前後不変と4GiBの条件を維持する。新規N640で全翼の独立直接解を計算したとは扱わない。非対称モードの正しさや安定性を主張しない。

## 3. 誤差予算

τ帯平均、τ帯P1、K帯平均、有限辺／元点モーメント密度の5チャンネルを別々に評価し、既存と同じ4段階・次数・方向・丸め床条件を使用する。条件未達のチャンネルは外挿しない。

共通の予算基準点をM24N160に固定する。スパンの最細N640からN160への移送について、(a)同じ先頭誤差項を仮定した4^p倍、(b)N160とN640の観測差ノルム＋N640の仮定付き尾部、を併記する。後者の三角不等式は正しいが、尾部の外挿を保証された上界にはしない。より大きい値を今回の保守的な仮定付き移送量とし、同じ版・同じ基準点の弦推定と線形和する。

追加したN640弦系列では、基準点M24N640で弦とスパンを直接線形和する経路も別に評価する。N160基準の端点移送結果と混ぜない。総量0.3%／固定帯0.5%の目標は変更しない。τ帯P1の推定から揚力、元点モーメント密度から元点モーメントの条件付き影響を写し、帯平均の分布推定も保存する。場間差上限、条件付き外挿、端点移送、方向間の未検証の混合項、未知の真の解への誤差を区別する。結果だけで参照採用を自動更新しない。

## 4. 資源・保存

追加16プロセスは逐次・合計600秒・各300秒・ピーク4GiB・開始前空き6GiB、出力384MiB以下。後処理120秒・512MiB。入力・ソース・ゲート・全アンカー・native／derived・系列と予算をハッシュで保持する。既存の初回未達・旧π版・旧N20/N40系列は保存する。
