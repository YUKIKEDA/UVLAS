# 配分感度試験：実行・保存・比較の追加仕様

2026-10-31、4計算の実行前に固定。[主仕様](avl-tip-redistribution-experiment.md) の4入力・数値条件・資源上限は維持する。

## 1. 開始・監視

N1280成果物監査、次数診断・入力監査を再実行する。使用する全ソース・実行体・入力と両親監査のハッシュを検証する。専用監視関数について通常／各上限／開始不足／cgroup不明の製造試験を行い、実際の使い捨て子プロセス群の停止も確認する。正確に上限と等しい値は許容、超過を停止条件とする。

caseをFW-V01→FW-V02、各翼でtip-rich→tip-poorの順に逐次実行する。各300秒・全1200秒・群RSS5GiB・開始有効空き8GiB・空き下限2GiB・swap増加256MiB・console各8MiBを確認する。段階開始／case開始に対するswap増加を両方記録する。0.2秒監視と45秒程度の進捗表示、各case完了時の原子的なマニフェスト更新を行う。終了コード0だけでは合格とせず、consoleの容量超過、期待出力と計測前後の一致を検査する。

## 2. 無損失保存と128MiB

128MiBは新規実行・派生場の保存合計の上限として維持する。通常のout一組と、計測後のafter一組の8ファイルを一旦保存してバイト一致を確認する。afterの8ファイルだけを `after.zip` に無損失圧縮し、ZIPから読んだ各バイト列のSHA256が元ファイルおよびoutに一致することを確認してから、afterの重複ファイルを個別に除去する。原本out、入力、console、資源ログはそのまま保持する。既存実験のファイルには触れない。

マニフェストにはZIP実体のハッシュ・サイズと内部8ファイルのハッシュ・非圧縮サイズを記録する。以後の独立監査ではZIPを読み出して前後不変性を再検証する。派生全翼は新規実行root内に別ファイルで保存し、段階終了時の圧縮済み保存量と後処理後の合計量を分けて記録する。出力上限を超えたら未達として停止し、上限を事後変更しない。

## 3. 6場・6場対と比較

基準の一様M12N1280の2場は既存の派生全翼を入力として再使用し、書き換えない。新規4場はnative-halfとderived-by-symmetryを区別する。元CSVの形状、有限値、UH meta、640帯・7680未知数、実際の区間別帯数、法線x成分0を検査する。入力SECTIONの11物理断面を固定し、各帯の両端が対応する区間内にあることも検査する。

基準対tip-rich、基準対tip-poor、tip-rich対tip-poorの3対×2翼を比較する。5チャンネルについて基準ノルムで割った差、帯の符号付き成分、地域別二乗寄与、合力・元点モーメントの相対／絶対差を記録する。基準相対差のモーメント分母床0.1は既存規約を維持する。tip-rich−基準とtip-poor−基準の方向余弦も保存する。

残差1e−11、保存・帯集計1e−10、6組の保存場間差上限、地域の二乗加算1e−12×max(1,尺度)を確認する。後処理120秒・512MiBと保存合計128MiBを確認する。実流れの配分感度には合格しきい値を設けない。Richardson次数・尾部・M24誤差推定は返さない。
