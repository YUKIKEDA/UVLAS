# 対称参照の循環・荷重求解感度：事前仕様

2026-10-31。[設計](../symmetric-reference-solve-sensitivity-design.md) を実行可能な仕様へ固定する。参照全体の受入やM24の尾部を更新する実験ではない。元の全翼用計測版と今回の親版を変更せず、別の対称静的計測版を作る。

## 1. 対象・順序・拒否

小系はFW-V01／02のM6N40半翼120未知数、主対象はM12N1280の一様／tip-rich／tip-poor、両翼6系の7680未知数。小系2件の実行と独立検査が成立してから主対象6件へ進む。親は `source-symmetry16000-ks1000-spacing-pi64`。新しいUQ計測コマンド、アダプターとaoper分岐だけを別コピーへ追加する。核・容量・分点・LU実装・既存UH処理は維持する。

既存の対称適格性ガードに加え、半翼モード1、法線x成分が厳密に0、迎角のsinが非ゼロ、既知流入のsin／cosとの一致を要求する。追加ガードの正常・拒否・非有限値は局所入力で試験し、COMMONを不適格状態へ変更して試験しない。

## 2. 荷重写像を先に確認する

親の元辺・元作用点から、20帯のτ平均、τ一次係数、K平均、有限辺／元点モーメント密度の100行を作る。各辺と帯の交差は入力float64幾何の有理数演算で積分する。補正偶力の係数は元作用点と単位循環の力から求め、作用点を置き換えない。

全翼循環は同符号の鏡映置換で半翼循環から展開する。W_s=WEで100行の半翼重みを作り、保存q₀と既知製造循環の全翼直接積分・対称性・転置写像を照合する。τ一次係数の負側の符号を検査する。保存値再現と製造試験は1e−12×max(1,対象行の尺度)。100行を単位混在のまま一つの物理ノルムにしない。

重み行列は圧縮NPZとハッシュ、行配置、元幾何・作用点・配分・原点・基準量の世代を保存する。準備600秒・512MiB・出力32MiB。小系の派生幾何以外、親の全翼データを再生成・上書きしない。

## 3. 読取り専用の計測

元WC_GAMとENCから、元の演算順で局所A_sを復元する。追加の局所LUスナップショットを保存し、終了時に活性LU、ピボット、GAMをbitwise比較する。GAMや元の速度・力へ補正を代入しない。元行列とLUスナップショットは7680²×8が2枚で943,718,400 bytesを追加する見積もり。これはピーク上界ではなく、下記の5GiB条件を実測する。

4循環を記録する：元q₀、同じLUで右辺を直接解いたq_direct、q₀からの反復改良q₁、続くq₂。一次右辺は−ENC_z、元循環はGAM/sin(α)とし、この対応を小系で検証する。残差は浮動小数点の積に補償和を用いて計算する。二度の改良は元q₀から開始し、直接解から開始する別の手順と混同しない。

小系では全行、大系では固定8行（1、2、N/4、N/2、N/2+1、3N/4、N−1、N）の4循環について、REAL(kind=16)で別に内積と差を評価する。小系の独立Decimal80残差とも照合する。REAL16は演算精度をメタデータで確認し、float64との比較は残差そのものを分母にせず1e−12×max(1,右辺・行の絶対内積尺度)。大系の選択行を全行への保証にしない。

小系だけ、元行列のbinaryと3種類の試験右辺に対する転置解・残差を出力する。元行列はUH binaryとbyte一致、Numpyの通常／転置解と1e−10×max(1,解の尺度)以内、Decimal80との残差差は上記条件内を要求する。大系の行列ファイル出力と逆行列ノルム推定は今回は行わない。

## 4. 元出力回帰と資源

各caseでUQ前後のFT／FS／FE・UHを取得し、8種類の元出力（小系ではUH行列も含む）を前後および既存の親結果とbyte一致させる。UQの循環・元行列は診断名で別保存する。元状態bitwise不変と新ガードの正常性も必須。診断後の重複元出力はZIPへ無損失保存し、内容を確認後に新規重複だけを個別に除去する。

ビルド300秒・2GiB。小系段階は各60秒・計180秒・RSS2GiB、主段階は各300秒・計2400秒・群RSS5GiB。両段階とも開始有効空き8GiB・実行中空き2GiB・swap増加256MiB・console各8MiB。元出力と診断の合計保存128MiB、監視間隔0.2秒。Linuxとcgroupを確認し、不明・超過・元出力変化・非有限値では未達を保存して停止する。

## 5. 後処理と解釈

q₀のW_s観測と親の100帯成分を再現し、直接解・各改良についてW_s(q_k−q₀)を直接評価する。大きな観測値を引き算した値も比較するが、微小な差の主記録は循環差への写像とする。既存5チャンネルと全域傾斜の絶対／相対変化、各系での元配分応答に対する比を記録する。分母0は未定義とする。

後処理300秒・512MiB・出力16MiB。独立の写像・小系行列・Decimal残差・状態不変・ハッシュ監査を行う。改良での変化が配分応答より小さくても、未検証の係数生成誤差、観測演算の丸め、前進誤差全体の上限を与えたとは扱わない。新しいRichardson尾部やM24予算を返さず、参照採用・J1・製品数値コアの開始は更新しない。
