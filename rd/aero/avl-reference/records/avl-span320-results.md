# 追加スパンN320と容量拡張参照：実施結果

2026-10-31。[事前仕様](avl-span320-reference-experiment.md)、[準備記録](avl-span320-preparation.json)、[生データ](avl-span320-runs.json)、[解析結果](avl-span320-result.json)、[監査](avl-span320-artifact-audit.json) を保持する。

## 容量と回帰

参照専用の別コピーでNVX/NVMAXだけを5000から8000へ変更し、全Fortran依存単位を再ビルドした。数式・核・定数・その他の配列上限は不変。製品の規模・性能目標の変更ではない。元の5000版も保存している。

2翼×M6N40/M24N160の4回帰は、FT/FS/FE、循環・力・帯境界のすべてが旧版とバイト一致した。その後にM24N320の2翼・各7680未知量を実行した。全6条件で計測前後の出力も一致し、追加条件の5処理検査が成立した。

| 項目 | 結果 |
|---|---|
| 実行 | 4回帰＋2新規、逐次実行、計232.9秒 |
| 新規1件の時間 | 平面翼95.8秒、上反角翼96.7秒 |
| ピークメモリ | 最大3,421,401,088 bytes、事前4GiB以下 |
| 保存量 | 62,970,593 bytes、事前128MiB以下 |
| 元非貫通残差 | 基準速度で尺度化した相対値最大3.84e−14、事前1e−11以下 |
| 力／モーメント和 | FTとの差最大6.94e−17、事前1e−10以下 |
| 保存観測 | τ/K・偶力・独立帯観測と場間差上限の検査が成立 |

初回の参照入力と同じ21断面を使い、各区間のスパン分割8→16だけを変更した。元ファイルの該当21行だけを置換すると新ファイルと同じバイト列になることを監査した。

## スパン系列の結果

旧N20を含む系列の未達を残したうえで、事前に固定したN40/80/160/320を診断した。両翼とも全5チャンネルが未達だった。FW-V01を示す。

| チャンネル | 最終差の相対値 | 2つの観測次数 | 差分方向余弦 |
|---|---:|---|---|
| τ帯平均 | 0.03917% | 1.295→1.909 | 0.930、0.910 |
| τ帯P1 | 0.03964% | 1.827→1.912 | 0.735、0.906 |
| K帯平均 | 0.04286% | 1.081→2.347 | 0.964、0.756 |
| J | 0.05174% | 1.332→1.525 | 0.788、0.933 |
| J_c | 0.05533% | 1.344→1.561 | 0.877、0.945 |

τ帯平均は次数変化が事前0.5を超え、τ帯P1とJ/J_cは前半の余弦が0.9未満、Kは両方の条件が不足する。小さい最終差を誤差上限へ読み替えず、総量0.3%／固定帯0.5%の予算は未評価のままとした。N160とN320で基準点が異なる推定を無断で加算していない。

追加格子の一次傾斜はFW-V01でCL′=4.2246979614、CM_y′=−4.3484790318、FW-V02でCL′=4.2185662345、CM_y′=−4.3404868781。参照として受け入れた値ではない。連続解への誤差上界は未確保。

## 次の計算経路

同じM24でさらにN640へ進めると全翼は15360未知量となり、今回の8000容量と4GiB予算を超える。閾値を緩めて採用せず、[対称条件に限定した参照縮約の設計案](../symmetric-reference-reduction-design.md) を先に検査する。全翼解との照合なしに半翼参照へ置換しない。元の全翼ケースと非対称な製品用途は維持する。

参照候補の改善であり、UVLAS荷重一致、製品性能、自由後流・連成・フラッタやJ1の受入ではない。
