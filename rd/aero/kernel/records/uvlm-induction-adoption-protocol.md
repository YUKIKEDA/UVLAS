# UVLM 2.1：有限3D W-P1誘導核の採用審査

2026-11-05。構造1の終了後の最初の有限ゲート。既存のW-P1-stream/P0-span-facet-v1、一定半径Rosenhead–Moore積分、三角分割・向き・共有トレースを維持する。2全体・自由後流時間更新・有限翼の物理荷重精度の採用判定ではない。

## 解消する不足

既存の[適応求積](../../unsteady-reference/records/uvlm-adaptive-quadrature-experiment.md)は面外点の速度を確認したが、一般3D近接の各可変μ基底、面上の正則化自己評価、点／頂点／半径に対する幾何微分は未完了。幅一列の局所平均圧力の成立はそのまま再利用し、AVLの終了済み参照診断は再開しない。

一定面内渦層の積分を辺積分と立体角へ還元し、一次の境界渦線も解析積分する。追加するのは同じ核の評価法であり、境界項・面内項・正則化項を捨てない。[FLOWPanel公式の渦層定義](https://flow.byu.edu/FLOWPanel.jl/v1.2/elements/constantvortexsheet/)と[一定二重層／渦輪の対応](https://flow.byu.edu/FLOWPanel.jl/stable/elements/constantdoublet/)を比較資料とし、式と検証はUVLASで導出する。

## 有限な検証と不採用条件

| 群 | 事前条件 |
|---|---|
| 一次3基底 | 各三角形の3基底を評価し、既存W-P1のL/Rへ正確に散布する。平面・skew・非平面四辺形、ε=0/.02/.08の面外点。独立な面積分と速度相対1e−8または絶対1e−10以内 |
| 近接した各列 | 面内・辺・頂点への接近。ε=0の面外距離1e−2/1e−3/1e−5と、ε>0で距離0。各列を比較し、一定μの和だけの一致で通さない。独立参照の細分化差も同じ精度内 |
| 正則化自己評価 | ε>0かつ明示したincident関係が参照／現在幾何と一致するときだけ許可。面内・辺・頂点の値を別の面積分と比較。渦輪全体を0へ置く負対照を検出。ε=0の面上自己評価は今回採用しない |
| 幾何Jacobian | 点3＋頂点9＋半径1の13変数、各μ基底。別の面積分の微分／高精度差分と相対1e−8または絶対1e−10。incident点では点と頂点を同時に動かす物質写像の鎖則も検査 |
| 保存・変換・共有 | 一定μで解析渦輪へ戻る。剛体移動・回転・尺度1e−3/1e3、向き／係数反転、共有対角線・同一μ共有辺・異なる帯トレースを検査。代数1e−10、幾何共変1e−8 |
| 安全な分岐 | 理想核の面外同一平面点、遠方、半径0の片側微分、退化／接触／incidence不整合を区別。式の0/0や桁落ちを有限値で隠さない。通常精度で未達なら別精度／別評価または失敗を返し、条件を緩めない |

正則化された直線自己寄与0と、閉渦輪・面内渦層全体の自己誘導を分ける。ε>0の有限値は粘性コア物理の妥当性を意味しない。[自己誘導補正の一次資料](https://arxiv.org/abs/1204.2378)の問題提起を踏まえ、今回も積分定義と数値評価を照合し、実渦核モデルの検証へ読み替えない。

既存の面外専用APIは変更せず、新しい評価契約と結果へ分ける。成功値・診断・微分・入力版を一組で保持する。非incident接触、ε=0面上、幾何不適格、数値精度未達で確定状態を変更しない。選択した分岐の前提と尺度を保存する。

## 2全体の残作業

2.1の後は、2.2で後流の自己／共有・非貫通組立・放出／移流・近接・状態と全荷重を一組にする。2.3で定常／非定常・有限幅・後退テーパ・複数面の独立参照と誤差予算を審査し、2.4でAE-01〜07の採用式・主要I/F・拒否条件を統合する。新しい小項目を無制限に増やさず、この4ゲートの証拠へ集約する。精度受入参照が不足する有限翼条件は未達のまま残し、誘導核の成功で2全体を閉じない。
