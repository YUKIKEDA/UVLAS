# UVLM 2.3：独立参照と精度予算

2026-11-05。正式比較より先に判定条件を固定する。AVLの精度参照不採用を維持し、その系列を再開しない。対象は採用した非圧縮・非粘性・付着流の薄い揚力面。製品の実験妥当性確認と区別する。

## 定常有限翼

既存FW-V01/V02の後退35度・テーパ0.4・全幅8m・根元弦1.5m・上反角0/5度、密度1.2、速度20、基準点(0.375,0,0)を保持。参照は独立環境のAeroSandbox 4.2.10。公式配布パッケージの版・全ソース・依存版を保存し、軸・翼面・法線・流下方向・荷重作用点を監査する。自コードの核を参照へ移植しない。

正弦迎角で比例する循環から、零迎角における揚力とMyの一次微分を評価する。迎角ゼロで循環ゼロ、固定+x後流・弦方向+xの両翼では、流下辺と誘導速度の一次力はゼロ。渦輪循環Γの弦方向差が馬蹄渦強度に等しい。これを粗格子の座標・行列・循環・実際の±1/±2度荷重で検証してから収束へ進む。二次抗力や自由後流の安定性へ合格を流用しない。

| 条件 | 受入 |
|---|---|
| 揚力・Myの一次勾配 | 両者の相対差1%以内 |
| 固定20等幅y区間の揚力勾配 | 各区間2%以内。辺が区間境界を跨ぐ場合は長さ比で正確に分割 |
| 元の非貫通残差 | 1e−11以内 |
| 加算誤差予算 | 自側空間0.30%、参照空間0.30%、有限後流0.15%、求積0.05%、参照コア0.05%、角度極限0.10%、解法／和／出力0.05% |

弦系列M=4,8,16,32、幅系列N=12,24,48,96,192を上限とする最初の有限キャンペーン。参照の幅分割は左右半翼ごとのcosine、弦もcosine。M32×N192まで6144未知量、ブロック評価で中間配列を制限する。M16/32×N96/192を交差確認し、隣接差だけを連続極限の厳密上界とは呼ばない。追加N384が必要なら、終了判断・計算量・予算未達の原因を記録した別の有限計画にする。無制限の自動細分化はしない。

自側は固定SIのRosenhead–Moore半径を明記し、少なくとも1e−3/1e−4/1e−5×基準弦を比較。参照は異なる核なので数値を一致させず1e−8/1e−7の感度を評価。自側有限閉後流L=64/128/256×半幅を比較。局所コア、有限長、空間差を相互に相殺して合格としない。20区間にも収束差を出す。

一定循環の直線後流だけはW-P1の面内渦層が消える。隣接する共線辺を統合した高速定常作用素を使う場合、採用2.2の全組立との粗格子一致を必要とする。この高速経路は定常精度実験専用であり、非定常W-P1をP0へ変更するものではない。

## 非定常・複数面・誘導抗力

PteraSoftwareの公開UVLMを候補として、まず版と実装を監査する。時間方式・後流P0/P1・放出時刻・開始条件・コア・座標・循環力／非循環力の差を明記し、独立な時間／空間／後流長の収束を確認してから参照に採用する。インストールや粗格子一致だけでは適格としない。一次調和応答は幅一列の既存解析証拠も維持する。

FW-D01は全辺の近傍荷重と遠方定義を個別に検証する。揚力線の楕円循環を有限弦の厳密解として使わない。多面干渉は全相互作用と単独計算との差を独立コードで確認する。

各有限キャンペーンの実数値、入力、未達、資源量、ソースハッシュを保存し、成立した範囲だけ採用する。2.3全体が未達ならその事実と次の原因別作業を示し、品質基準の変更が必要な場合のみ意思決定を求める。
