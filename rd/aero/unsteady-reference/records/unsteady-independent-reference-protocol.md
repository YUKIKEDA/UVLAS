# 非定常有限翼：独立参照の限定キャンペーン

2026-11-05。FW-V01の後退テーパ翼、平均迎角0、密度1.2、速度20、上下運動を対象とする。まず換算振動数k=0.2、微小振幅1e−4mの一次複素応答を照合する。Fzと同一点(0.375,0,0)のMyを使い、位相はh=a cos(ωt)、複素表記exp(iωt)。相対複素差1%、正規化絶対誤差も保存。後のpitch・k系列・複数面に拡張する前に、この有限キャンペーンの採否を記録する。

## 独立参照

公開PteraSoftware 5.1.0を別環境へ導入し原本ソース49件と依存版をハッシュ保存した。Webのlatest APIとは引数が異なるため、インストールした版のソースを優先する。geometry軸は+x後方、+y右、+z上。出力windのzは下向きなのでFz=-Fwz、My=Mwy、Myの参照点差は合力から移す。

原本は初期コアを各翼の標準平均弦×0.03に固定し、年齢による拡散も含む。この値を入力からゼロへ近づけられないため、原本の結果だけでは今回の理想核極限への精度参照に採用しない。

監査用サブクラスは、原本のgeometry集約直後に束縛・後流の初期コア配列へ同じ明示SI半径を設定する2文だけを追加する。誘導核・行列・放出・移流・時間差分・荷重式は原本のまま。自側の核や荷重を移植しない。元値0.03×標準平均弦を再設定した場合に原本とbitwise一致すること、半径1e−3/1e−4/1e−5mの収束、粘性1e−12/1e−13、振幅1e−4/1e−5mの感度を調べる。拡散の循環依存も振幅感度で監査する。これは公式原本とは区別した監査用参照であり、未監査の変更版を合格にしない。

PteraはP0の旧循環放出、束縛後端は実TEから刻み依存の距離だけ後方。非定常力は物理セル面積とコロケーション。自側は陰的W-P1先頭、実TE、渦セルの面積と重心。そのため粗格子・有限刻みの一致は要求せず、時間と弦分割を別々に収束させる。自側の方式を参照に合わせて変更しない。

初回系列はM2/N8で周期64/128/256分割、3/6周期。次にM4/N24とM8/N48で256分割までを測定する。参照の時間・始動・空間差を別に保存し、不足する段階だけ有限に追加する。総比較1%のうち自側空間0.25%、参照空間0.25%、時間0.20%、始動／後流0.10%、両コア0.10%、求積／解法0.10%を目標とする。予算を満たさない結果は未達として保持する。

## 自側の周波数表現

基準循環ゼロの線形化では移流形状の一次摂動と循環の積は二次になる。直線後流上の複素循環を同じW-P1の年齢関数から積分する。半無限の一定帯作用素H(τ)を使うと、閉じた有限後流の作用は−∫μ(τ)H′(τ)dτ。端の閉鎖を捨てた表現ではない。区分一次μについて採用済み3D三角形の全基底との独立照合で相対差1.66e−11を確認済み。調和μのGauss次数・有限長を別に収束させる。この周波数表現を時間方式の採用には流用しない。
