# 独立参照のスカラー化と理想核参照

2026-11-05。有限半径の核差を誤差として見逃さないため、独立参照側の理想核を別系列で取得する。反復する巨大な3成分配列の作成を省くが、主方式のRosenhead–Moore積分／点微分は再利用しない。

Ptera5.1.0原本の端点ベクトル・外積・Scully分母・1e−10相対特異判定をスカラーの法線投影へ写す。閉渦輪を同じ核の半無限馬蹄H(τ)−H(T)へ分解し、参照側だけの−iω∫exp(−iωτ)G(τ)dτを積分する。定常基底＋変動後流の式は維持する。

スカラー線と原本の全速度投影、閉渦輪／定常行列、変動後流行列を、ε=0/1e−5/.03m、平面／上反角、3周波数で照合する。相対1e−9以内が必須。主方式の核で参照を置換しない。

成立後、理想核ε=0で参照M8/N192、M16/N48/96/192/384、M32/N96/192、M64/N192を取得する。同じ4水準の弦・幅系列で漸近性を確認し、実際の主方式M128/N192・ε1e−5mと理想核参照を比較する。これなら主方式の有限コアの影響も比較差に含まれる。参照不確かさと1%基準は変えない。既存の有限半径データを上書きしない。各格子1200秒・24GiB以内。
