# 非定常の空間差：方向別の有限追加

2026-11-05。M16/N96でも自側と独立参照のMy差は約1.17%で、総比較1%は未達。差の主因は非定常面積・作用点の離散化であり、弦方向の増分でほぼ半減している。半径や後流長による差はこれより十分小さい。

追加はM32/N96、M64/N96、M32/N192、M16/N384の各6144未知量以内とし、同じ二つの作用素で実施する。M32/N96だけ3072。まず弦と幅を独立に3水準以上で評価する。必要なら両方向の最終交点M64/N192（12288未知量）を各1回だけ追加する。1ケースの実測資源を確認してから交点へ進み、メモリ24GiB・時間1200秒を上限とする。

式・核・力の規約は変更しない。評価対象の小さいTE近傍尺度に求積区間を合わせた高速経路を採用済み作用素と照合し、50方向の点微分・束縛行列・後流作用素・複素荷重が一致した範囲で用いる。高速化は実験のためで、製品の数値基盤選定ではない。

外挿は収束率・交差差・最後の値からの補正量・異なる3水準の外挿差を必ず保存し、未達の有限格子を合格へ置き換えない。空間予算0.25%を満たしたかどうかと、1%の独立比較が成立したかを別々に判定する。
