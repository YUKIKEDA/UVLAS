# W-P1適応求積候補：事前試験仕様

版0.1、2026-10-30。[近接契約](../../kernel/uvlm-near-field-quadrature-contract.md) の限定設計実験。以下をコード作成・実行前に固定する。製品C++評価器・全連成接線・任意近接形状の採用を意味しない。

## 1. 候補・予算

境界4辺の一次強度線積分と、固定分割2三角形の面内一定渦層を評価する。内部対角線の境界積分は一致トレースとして解析的に相殺する。単位L/Rを同じ木で計算する。親長で位置・εを無次元化し、辺Gauss8/16、面Duffy8²/16²、葉の差の16倍の絶対和、有限要素への最短距離によるh/ρ≤2を使う。葉は誤差最大から分割し、幾何条件未達を先に処理する。同点は永続木ID順。

推定誤差の合計が列目標以下となった木で24次を監査し、葉別16→24差のノルムの絶対和≤列目標/4を要求する。契約より保守的な監査を用い、監査の相殺に頼らない。補償和・丸め床・深さ／葉／評価点上限は契約どおり。既存の固定次数コードを変更しない。

全実験180秒、512MiB。各評価は深さ20、活動葉100000、評価点20000000が上限。失敗時は値を診断領域へ隔離し、通常の消費I/Fは例外とする。試験結果、木のハッシュ・統計、推定／監査／丸め床、全速度、入力・ソース・依存のSHA-256、時間・ピークを保存する。

## 2. 解析・独立参照

A：既存の平面[(1,−.6,0),(1,.6,0),(1.4,.6,0),(1.4,−.6,0)]、ε=0、p=(1−d,0,0)、d/c=[1,.5,.1,.01,.001,.0001,.00001]。参照は [固定次数診断](../../kernel/records/uvlm-near-field-screening-experiment.md) の解析L/Rと対数変数変換した一次元積分。前回JSONをハッシュ固定して使用し、pの丸めも同じ値を使う。14列の全3成分の実誤差が $\tau_j=10^{-10}/\ell+10^{-8}\|K_j\|_2$ 以下で、すべて成功すること。

B：3D基礎試験の平面・歪み平面・非平面3形状、ε=0/.08、観測点(.65,.1,.2)でL/Rを評価する。別経路の面積分を96²/128²で計算し、その差が列目標の1/20以下を参照の適格条件とする。6評価12列すべてについて列目標を満たすこと。参照自体未収束なら候補精度を判定保留とする。

C：同じ3形状の最初の物理三角形(0,2,1)で、重心・辺(0,2)中点・頂点0のそれぞれに、正法線方向へ親長の1e−3だけ離れた点を作る。ε=0/.02ℓで各L/Rを評価し、その和を既存の解析有限線分核による一定μ渦輪と比較する。18評価すべてで和の誤差≤ $2\times10^{-10}/\ell+10^{-8}\|K_{constant}\|_2$ 。この試験だけでは個々の変数μ列の独立精度を証明しない。

全ケースの実誤差が、推定誤差＋丸め床＋ $10^{-12}\max(\|K_{ref}\|_2,1/\ell)$ を超えないことも確認する。これは厳密上限の証明ではなく、今回の参照点群で推定が過小にならないという条件。

## 3. 共変性・線形性・木

平面Aのd=.01を基準に、回転Rz(.4)Ry(−.3)＋並進(.3,−.2,.5)、位置・コアの1e−3／1e3倍拡大を評価する。変換後速度の尺度付き相対差≤1e−8、同一入力の反復で木ハッシュ・値・状態が一致すること。正規化後の距離判断が浮動小数の違いで変化する可能性は記録し、変換をまたぐ木ハッシュ一致までは要求しない。

同じ2基底から複素係数[1+.2i,−.4+.7i]、相殺係数[1,−1]を消費し、基底積と一致すること。木の構築が係数の相殺に依存しないこと。成功結果の消費には全基底を使い、失敗結果の診断値を通常出力へ通さない。

## 4. 負の対照・失敗処理

Aのd=1e−3で深さ上限0、活動葉上限6、評価点上限1を個別に指定し、それぞれdepth_limit／leaf_limit／evaluation_limitを返すこと。Aのd=1で要求値をatol=0・rtol=1e−18へ変更してroundoff_limitedを検出すること。厳しい要求を通常要求へ緩めて成功としない。

接触点(1.2,0,0)はε=0/.08でも拒否。退化面、非有限点、自己評価要求、負のεも拒否。入力配列・確定状態・呼出側の出力バッファのハッシュは成功／失敗のいずれでも変わらず、失敗を消費すると例外になること。距離の単体確認は、三角形[(0,0,0),(1,0,0),(0,1,0)]への点(.2,.2,.3)、(.5,−.2,.3)、(−.1,−.2,.3)で行い、期待距離.3、sqrt(.13)、sqrt(.14)に絶対1e−13以内で一致すること。

一般3Dの共有辺集約、全キャッシュ世代、接線、全行列組立と荷重予算の達成は本試験の範囲外。失敗があれば結果を保持し、変更が必要なら別の事前追加仕様と結果へ分ける。

## 5. 実施結果

[候補コード](../experiments/check_uvlm_adaptive_quadrature.py) と [全結果](uvlm-adaptive-quadrature-result.json) を保存した。事前の12判定はすべて成立した。既存の固定次数コードと未達結果は変更していない。

| 照合 | 結果 |
|---|---|
| 幅一列の7距離・14基底列 | 全列が成功、解析参照への最大相対差4.75e−14 |
| 3形状×2コアの独立面積分 | 参照96²→128²の条件成立、12列の最大相対差1.11e−14 |
| 面内／辺／頂点への接近・一定μ | 18評価すべて成立、基底和と解析渦輪の最大絶対差3.63e−12（1/m） |
| 誤差推定 | 個別の独立参照を持つ26列で、実差が推定＋丸め床＋事前の余裕を超えなかった |
| 回転・並進・尺度1e−3/1e3 | 3変換すべて条件成立。同一入力の木と値は反復一致 |
| 上限・不適格入力 | 10件で期待した失敗を検出。失敗値の消費を拒否し、呼出側バッファを変更しなかった |

平面d=1e−5では399葉、最大深さ17で成功した。主試験群全体の最大活動葉は463、最大深さ17。固定96次の誤差をしきい値変更で受け入れず、元の式・点・目標を保って分割で解消できた。

実行9.562秒・ピーク87,670,784 bytesで、180秒・512MiB内。推定誤差を厳密な上限とした証明ではない。複素／相殺係数は同じ基底の消費I/Fの検査であり、新しい独立参照を持つ場の検証件数へ加えていない。

## 6. 次のゲート

固定幾何・単一セル・面外点の候補まで進んだ。一般3Dの近接した可変μの**各基底**は、今回の一定μの和だけでは確認できない。別変数変換／高精度参照による各列の精度、バッチ評価・共有辺集約・キャッシュ世代・全幾何接線、組立から循環・荷重までの0.05%予算は別途必要。

有限翼の定常基準では後流μが一定なので、内部面内渦層は相殺して解析渦輪へ戻る。この性質を使う場合も、非定常の可変μへ同じ簡略化を拡張しない。現在のPython候補を製品APIやJ1の採用済み方式としない。
