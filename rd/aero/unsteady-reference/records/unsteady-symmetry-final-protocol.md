# 非定常：対称縮約による最後の有限追加

2026-11-05。独立参照の連続極限の推定不確かさは最大約0.191%で0.25%目標内。自側M64/N192の有限解は、この参照不確かさを加えたMy差が約1.033%で1%基準をわずかに超える。基準と既存の未達判定は変更しない。

追加は自側のM128/N192を1回。物理未知量24576に対し、平面形と上下運動の左右対称性から同じ循環を対応させ、代数未知量12288へ厳密縮約する。正側の各行に、正側と鏡像側の対応列を加算する。流れ・力・コア・閉後流・求積は変更しない。座標の鏡映丸めを1e−14m以下に揃え、粗格子の全体系と循環・力・Myを1e−10以内で照合してから使用する。

最終解は元の全体系の残差も左右から抽出した行で再計算する。ピーク24GiB・1ケース1200秒を上限にする。左右対称でない問題にこの縮約を流用しない。

判定は、実際に得た有限解と適格化済み独立参照の推定極限との差に、その参照不確かさを加えて各1%以内。先行の自側有限空間配分0.25%を外挿で満たしたことにはしない。この限定比較と、製品で返す任意の有限解の誤差制御は区別する。
