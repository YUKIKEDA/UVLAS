# 周波数／pitch拡張の設定感度

2026-11-05。M4/N24、k=0.05/0.2/0.8の上下／pitchで、両経路の後流64/128/256m、コア1e−4/1e−5/1e−6m、Gauss16/24の独立な感度を取得する。基準は128m、1e−5m、Gauss16。小格子の感度を細格子の誤差上界へ転用しない。細格子の有限値と同じε・同じ128m参照モデルを比較する精度と、理想核／無限後流へのモデル差は分けて記録する。

この操作は一般誤差認定規約で必要な群を実際に作れることの確認である。生データを残し、後流・コア・求積の指標を一つのパラメータ変更へ混ぜない。各経路180秒以内。
