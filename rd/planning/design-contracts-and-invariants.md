# I/F・処理規約・不変条件の作成要件

版：1.0、2026-10-29。実装前設計で埋めるべき契約を定義する。以下の処理一覧と不変条件は設計対象の棚卸しであり、型・許容差まで確定した実装仕様ではない。

主要処理ごとに以下を全て記載する。関数名、引数名、返値のクラス名だけでは完了しない。

## 3. 状態遷移で定義すべき事項

状態遷移図と各辺の前後条件を作り、少なくとも以下を区別する。

`未検査入力 → 検査済みモデル → 整合初期状態 → 確定状態n → 試行中 → 受理候補 → 確定状態n+1`

試行中から未収束・幾何不正・中断等が生じた場合の遷移、最後の確定状態を保持した停止／再試行、保存と読込みの失敗を別に定義する。「受理候補」から確定への操作は重複実行を検出するか、別の一貫した契約で二重更新を防ぐ。

空力・構造・連成で個別に成功しただけでは確定しない。受理条件と、外部へ結果フレームを公開する時点を連成ドライバーに一意に割り当てる。未受理試行の診断ログは残せるが、受理済み履歴へ混ぜない。

## 4. 不変条件一件を完了させる条件

各INVについて、成立する仮定、数式、評価対象、検査する処理境界、誤差の尺度・閾値、独立した確認方法、対応ケース、違反時の処理を定義する。

物理的な不変性、離散化が満たす代数的恒等式、実装上の状態保証、近似としての収束性を区別する。全てを同じ閾値や「保存する」という一語で扱わない。

## 5. 不変条件カタログ

以下は仕様化する対象。式や成立条件の記載があるものも、ケースと閾値へ落とすまでは検証仕様の完成ではない。

| ID | 対象と候補条件 | 成立条件・確認の要点 |
|---|---|---|
| INV-01 | 座標系を剛体変換したときの物理結果の共変性 | モデル、材料軸、外力・背景流・支持・基準点を整合して変換。力・速度等はRで変換、スカラーエネルギー等は不変。座標だけ変えて入力を固定した別問題と混同しない |
| INV-02 | 応力のない参照配置の剛体並進・回転で不要なひずみ・内力が出ない | 位置と勾配／回転を整合して変換。固定支持・重力・初期応力等による物理的な反力は別に扱う |
| INV-03 | 保存的な構造内力とエネルギー・接線の整合 | $\mathbf f_{\mathrm{int}}=\frac{\partial\Pi}{\partial\mathbf q}$ 、 $\mathbf K_{\mathrm{int}}=\frac{\partial\mathbf f_{\mathrm{int}}}{\partial\mathbf q}$ 。内部変数・凝縮がある場合はそれを含む微分。差分の刻み依存を確認。非保存荷重を含む全接線へ対称性を無条件に要求しない |
| INV-04 | 質量・運動エネルギーと質量特性の整合 | 離散運動エネルギー、質量・重心・慣性との一致。正定値性は適切な運動自由度上で評価し、質量のないDOFや拘束付き鞍点系へ一律に要求しない |
| INV-05 | 拘束の位置・速度・加速度整合 | $C=0$ 、 $C_{q} v+C_{t}=0$ 、必要な時間微分と初期加速度。許容仮想変位は $C_{q} \delta\mathbf q=0$ 。拘束反力と指定運動による仕事も区別する |
| INV-06 | 受動的な支持・物理減衰の散逸 | 固定支持で左辺抵抗の規約なら $v^{\mathsf T} f_{\mathrm{damp}}\ge 0$ 。動く支持では相対速度と両端の仕事で散逸を評価し、構造の絶対速度との積だけを非負と要求しない。能動入力・指定運動・空力仕事と数値減衰を区別。具体例REF-V04 |
| INV-07 | 運動・荷重写像の仮想仕事と力・モーメント | 点力のみなら $\delta\mathbf x=J \delta\mathbf q$ 、 $Q=J^{\mathsf T} f$ 、 $\delta\mathbf q^{\mathsf T} Q=\delta\mathbf x^{\mathsf T} f$ 。剛体運動を表現できる写像について合力・モーメントも検査。独立モーメントは対応する回転の仮想変分を追加 |
| INV-08 | 時間依存写像の速度・仕事の整合 | $v_{x}=J v_{q}+\partial g/\partial t$ 。明示的時間依存による入力仕事を落とさない。仮想仕事の一致だけで全パワー収支が確認済みとしない |
| INV-09 | 有向渦線・循環と誘導速度の符号・座標変換 | Γ反転または辺向き反転で速度の符号が反転し、両方反転なら元に戻る。コア処理を含む採用式の成立範囲で、独立積分・対称配置等と比較 |
| INV-10 | 後縁と後流の循環受渡し・接続 | 採用する離散Kutta条件・放出規則から保存すべき関係を導出する。束縛循環単独や、向き・重みを無視した全配列の総和を保存量として代用しない |
| INV-11 | 幾何写像・積分領域の適格性 | 採用要素の参照ヤコビアン・法線・面積・有向接続。曲面・複数翼・交差部材へ「全法線が同じ方向」を要求しない。構造接続と空力面・後流の異常接触を区別 |
| INV-12 | 確定状態の不変性と一度だけの更新 | 失敗・棄却で確定状態と履歴が変わらない。受理時だけステップ・循環・後流を規定回数更新。Workspace更新・失敗診断は別契約で管理 |
| INV-13 | 連成残差の線形化・接線と過渡／安定性の整合 | 何を固定した微分か明示して方向微分と照合。連続系／離散写像の固有値、刻み、数値減衰の関係を定義し、同じモデルの摂動応答と比較 |
| INV-14 | 保存・再開で必要状態と継続結果が保たれる | 位置だけでなく循環・後流・積分・入力履歴・拘束・探索状態を検査。配列長・ID等の厳密な整合と、浮動小数点の許容差を分ける |
| INV-15 | 外部モデル変換で意味が保持される | 単位・座標・節点・部材・材料・層・支持・偏心・慣性の対応。質量特性・静剛性・固有特性を変換前後で比較し、未対応カードを黙って無視しない |
| INV-16 | 配列・作用点・物理量・出力の意味が一貫する | 並べ替えや分割・集約に対して対象量が許容差内で一致。合力と分布、絶対位置と変位、応力測度、せん断成分、係数の基準を取り違えない |

## 6. ケース仕様一件を完了させる条件

1. ケースID、対応要求・式・OP・INV、何を証明するかと比較の限界。
2. 全ての数値入力、単位、座標、初期・境界条件、材料・支持・格子・入力時系列。
3. 参照値の出典・版・取得物、独立な導出または生成手順、利用条件・不確かさ。
4. 解法・求積・刻み・コア・後流・収束・縮約等の固定条件と、変更する細分化条件。
5. 評価点・領域・層・軸・時刻・時間窓・モード、誤差指標と基準量。
6. 結果を見る前に設定する絶対・相対許容差と、ゼロ・ノイズ床・特異点・非漸近の扱い。
7. 正常／異常の期待状態、合格／不合格／保留／参考比較の判定手順。

実装式をそのまま再計算した値を独立参照と扱わない。単体カーネルの解析的・代数的確認、計算解の誤差評価、実験比較の不確かさ評価に、製品目標の5%を一律に使用しない。
